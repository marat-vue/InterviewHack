# Что такое Testing Library и чем она отличается от Vue Test Utils?

> [!summary]
> Testing Library - это семейство библиотек, которое поощряет тестировать интерфейс так, как им пользуется человек. Vue Test Utils дает низкоуровневый доступ к Vue-компоненту, а Testing Library делает акцент на DOM, ролях, label, тексте и доступности.

## Главная идея

Testing Library предлагает подход:

```text
Чем больше тест похож на реальное использование приложения, тем больше уверенности он дает.
```

Поэтому вместо проверки `wrapper.vm.isOpen` тест ищет кнопку, кликает по ней и проверяет, что пользователь увидел меню.

## Vue Test Utils

Vue Test Utils полезен, когда нужны Vue-специфичные возможности:

- `mount`;
- `props`;
- `slots`;
- `emitted`;
- `global.plugins`;
- `stubs`;
- доступ к Vue wrapper.

```ts
const wrapper = mount(BaseModal, {
  props: { open: true },
});

expect(wrapper.emitted('close')).toBeTruthy();
```

## Testing Library

Testing Library ищет элементы ближе к пользовательскому опыту:

```ts
render(LoginForm);

await userEvent.type(screen.getByLabelText('Email'), 'ann@example.com');
await userEvent.click(screen.getByRole('button', { name: 'Войти' }));

expect(screen.getByText('Проверьте почту')).toBeInTheDocument();
```

## Что выбрать?

| Задача | Инструмент |
|---|---|
| проверить `emitted` Vue-компонента | Vue Test Utils |
| проверить поведение формы как пользователь | Testing Library |
| подключить Vue plugins и stubs | оба подходят |
| проверить доступность через roles/labels | Testing Library |
| проверить низкоуровневый контракт компонента | Vue Test Utils |

## Мини-шпаргалка

- Testing Library - подход "как пользователь".
- Vue Test Utils - низкоуровневый Vue API.
- Testing Library построена поверх DOM Testing Library.
- Vue Testing Library использует Vue Test Utils внутри.
- Для собеседования важно уметь объяснить разницу: `wrapper` против `screen`.
