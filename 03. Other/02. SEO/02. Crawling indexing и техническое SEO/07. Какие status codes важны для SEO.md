# Какие status codes важны для SEO?

> [!summary]
> HTTP status code говорит поисковику, что произошло с URL. Неверные статусы могут привести к потере индексации, лишнему crawling, плохому UX и некорректной аналитике.

## Основные статусы

| Код | Что значит | Как влияет на SEO |
|---|---|---|
| `200` | страница доступна | может индексироваться |
| `301` | постоянный redirect | сигналы переходят на новый URL |
| `302` | временный redirect | старый URL может оставаться основным |
| `404` | не найдено | URL со временем выпадает из индекса |
| `410` | удалено навсегда | сильный сигнал удаления |
| `500` | ошибка сервера | поисковик не может получить страницу |
| `503` | временно недоступно | подходит для maintenance |

## Что такое soft 404?

Soft 404 - это когда сервер возвращает `200`, но страница по смыслу пустая или сообщает "ничего не найдено".

Плохо:

```http
HTTP/1.1 200 OK
```

```html
<h1>Товар не найден</h1>
```

Лучше:

```http
HTTP/1.1 404 Not Found
```

## Какой статус отдавать для пустого поиска?

Для страницы поиска без результатов обычно можно вернуть `200`, если это нормальный интерфейс:

```text
/search?q=very-rare-query -> 200
```

Но такую страницу часто закрывают от индексации, чтобы не плодить мусор.

## Что отдавать при технических работах?

```http
HTTP/1.1 503 Service Unavailable
Retry-After: 3600
```

`503` говорит, что проблема временная. Это лучше, чем отдавать `500` или пустую страницу с `200`.

## Мини-шпаргалка

- Индексируемая страница должна отдавать `200`.
- Удаленная страница должна отдавать `404` или `410`.
- Постоянный переезд - `301` или `308`.
- Временный переезд - `302` или `307`.
- Не возвращай `200` для страниц, которые фактически не существуют.
