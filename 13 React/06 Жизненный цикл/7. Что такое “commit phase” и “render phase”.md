# Что такое render phase и commit phase?

> [!summary]
> Render phase - этап, где React вызывает компоненты и вычисляет новое описание UI. Commit phase - этап, где React применяет изменения к DOM, обновляет refs и запускает layout effects. Render может быть прерван, commit должен применить готовые изменения.

## Render phase

Во время render phase React:

- вызывает компоненты;
- вычисляет JSX;
- строит новое дерево React-элементов;
- сравнивает с предыдущим деревом;
- определяет, что нужно изменить.

Render должен быть чистым:

```jsx
function Price({ value }) {
  return <span>{value} ₽</span>
}
```

Нельзя делать side effects прямо в render.

## Commit phase

Во время commit phase React:

- изменяет DOM;
- добавляет/удаляет узлы;
- обновляет attributes;
- устанавливает refs;
- запускает `useLayoutEffect`;
- позже запускает `useEffect`.

## Почему это важно?

Если написать side effect в render:

```jsx
function Page() {
  localStorage.setItem('visited', 'true')
  return <main />
}
```

React может вызвать render больше одного раза, особенно в development или concurrent rendering. Side effect выполнится непредсказуемо.

## Где выполнять side effects?

- DOM measurement до paint: `useLayoutEffect`;
- subscriptions, timers, fetch, analytics: `useEffect`;
- пользовательское действие: event handler.

## Мини-шпаргалка

- Render phase вычисляет UI.
- Commit phase применяет изменения к DOM.
- Render должен быть чистым.
- DOM доступен после commit.
- Effects запускаются после commit.
