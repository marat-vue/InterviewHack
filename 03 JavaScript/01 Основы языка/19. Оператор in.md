# Оператор `in`

> [!summary] Коротко
> `in` проверяет, существует ли ключ в объекте. Он смотрит не на значение свойства, а на наличие ключа, включая свойства из прототипа.

## Вопрос

Что делает оператор `in`?

## Синтаксис

```javascript
"key" in object;
```

Левая часть - имя свойства, правая часть - объект.

```javascript
const user = {
  name: "Anna",
  age: 25,
};

"name" in user; // true
"email" in user; // false
```

## Проверяет ключ, а не значение

Если свойство есть, но его значение `undefined`, оператор все равно вернет `true`.

```javascript
const user = {
  name: undefined,
};

"name" in user; // true
user.name === undefined; // true
```

Это полезно, когда нужно отличить "ключа нет" от "ключ есть, но значение пустое".

## Учитывает прототип

`in` проверяет не только собственные свойства объекта, но и свойства из prototype chain.

```javascript
"toString" in {}; // true
```

Если нужны только собственные свойства, используйте `Object.hasOwn`.

```javascript
const user = { name: "Anna" };

Object.hasOwn(user, "name");     // true
Object.hasOwn(user, "toString"); // false
```

Старый вариант:

```javascript
Object.prototype.hasOwnProperty.call(user, "name");
```

## Работа с массивами

Для массивов `in` проверяет наличие индекса, а не значения.

```javascript
const items = ["a", , "c"];

0 in items; // true
1 in items; // false
2 in items; // true
```

Это важно для массивов с "дырками".

Не используйте `in`, чтобы проверить наличие элемента по значению:

```javascript
const roles = ["admin", "user"];

"admin" in roles;      // false
roles.includes("admin"); // true
```

## Ошибки

Правая часть должна быть объектом.

```javascript
"x" in null;      // TypeError
"x" in undefined; // TypeError
```

Перед проверкой можно убедиться, что значение похоже на объект:

```javascript
function hasKey(value, key) {
  return value !== null && typeof value === "object" && key in value;
}
```

## Мини-шпаргалка

```javascript
"name" in user;              // ключ есть в объекте или прототипе
Object.hasOwn(user, "name"); // собственный ключ
items.includes("admin");     // значение есть в массиве
0 in items;                  // индекс есть в массиве
```
