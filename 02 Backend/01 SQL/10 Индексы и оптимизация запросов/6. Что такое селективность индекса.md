# Что такое селективность индекса?

> [!summary]
> Селективность показывает, насколько хорошо условие отбирает небольшую часть строк. Чем меньше строк подходит под фильтр, тем полезнее индекс.

## Высокая селективность

```sql
WHERE email = 'anna@example.com'
```

Email обычно уникален, значит индекс очень полезен.

## Низкая селективность

```sql
WHERE is_active = true
```

Если 95% пользователей активны, индекс по `is_active` может быть бесполезен: проще прочитать таблицу.

## Пример

```sql
CREATE INDEX idx_users_is_active
ON users(is_active);
```

Такой индекс не всегда поможет, если распределение значений слишком неравномерное.

## Что делать?

Для частого запроса может помочь partial index.

```sql
CREATE INDEX idx_users_inactive
ON users(id)
WHERE is_active = false;
```

## Мини-шпаргалка

- Селективность - способность фильтра отобрать мало строк.
- Уникальные значения имеют высокую селективность.
- Boolean часто имеет низкую селективность.
- Индекс по низкоселективному полю может не использоваться.
- Partial index помогает для редких значений.
