# Что делает SWR?

> [!summary]
> SWR - это React-библиотека для data fetching от Vercel. Название означает stale-while-revalidate: сначала показать кешированные данные, затем обновить их в фоне и заменить свежими.

## Базовая установка

```bash
npm install swr
```

## Базовый useSWR

```jsx
import useSWR from 'swr'

const fetcher = (url) => fetch(url).then((response) => response.json())

function UserPage({ userId }) {
  const {
    data,
    error,
    isLoading,
    isValidating,
    mutate,
  } = useSWR(`/api/users/${userId}`, fetcher)

  if (isLoading) return <UserSkeleton />
  if (error) return <ErrorMessage error={error} />

  return (
    <>
      {isValidating && <SmallLoader />}
      <UserProfile user={data} onRefresh={() => mutate()} />
    </>
  )
}
```

## Ключ SWR

Первый аргумент - key:

```jsx
useSWR('/api/users', fetcher)
useSWR(['/api/users', token], ([url, token]) => fetchWithToken(url, token))
```

Если key равен `null`, запрос не выполняется:

```jsx
useSWR(userId ? `/api/users/${userId}` : null, fetcher)
```

## Автоматическая revalidation

SWR умеет обновлять данные:

- при фокусе вкладки;
- при восстановлении соединения;
- по интервалу;
- при вызове `mutate`;
- при повторном монтировании.

```jsx
useSWR('/api/user', fetcher, {
  revalidateOnFocus: false,
  refreshInterval: 10_000,
})
```

## mutate

Локальное обновление и revalidation:

```jsx
const { mutate } = useSWR('/api/user', fetcher)

async function saveUser(values) {
  await updateUser(values)
  mutate()
}
```

Глобальная мутация:

```jsx
import { mutate } from 'swr'

mutate('/api/user')
```

## Optimistic UI в SWR

```jsx
mutate(
  updateUser(values),
  {
    optimisticData: (currentUser) => ({
      ...currentUser,
      ...values,
    }),
    rollbackOnError: true,
    populateCache: true,
    revalidate: true,
  },
)
```

## SWR vs TanStack Query

SWR часто выбирают, когда нужен минимальный API и простая stale-while-revalidate модель.

TanStack Query обычно сильнее в сложных сценариях:

- сложные мутации;
- infinite queries;
- развитая invalidation;
- devtools;
- сложные настройки кеша.

## Мини-шпаргалка

- SWR показывает stale data и обновляет в фоне.
- `useSWR(key, fetcher)` - основной API.
- `isLoading` - первая загрузка.
- `isValidating` - идет проверка/обновление.
- `mutate` обновляет кеш и запускает revalidation.
