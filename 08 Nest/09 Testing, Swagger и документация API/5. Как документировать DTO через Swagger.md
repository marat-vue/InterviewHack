# Как документировать DTO через Swagger?

> [!summary]
> NestJS интегрируется с OpenAPI через `@nestjs/swagger`. DTO-классы можно документировать decorators вроде `@ApiProperty`, а controllers - decorators для tags, responses и auth.

## Bootstrap Swagger

```ts
const config = new DocumentBuilder()
  .setTitle('API')
  .setVersion('1.0')
  .addBearerAuth()
  .build();

const document = SwaggerModule.createDocument(app, config);
SwaggerModule.setup('docs', app, document);
```

## DTO

```ts
export class CreateUserDto {
  @ApiProperty({ example: 'anna@example.com' })
  @IsEmail()
  email: string;
}
```

## Controller

```ts
@ApiTags('users')
@Controller('users')
export class UsersController {}
```

## Мини-шпаргалка

- Swagger module генерирует OpenAPI document.
- DTO decorators улучшают схему.
- `@ApiTags` группирует endpoints.
- `addBearerAuth` документирует JWT auth.
- Swagger должен отражать реальные DTO и status codes.
