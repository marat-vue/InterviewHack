# Как рассчитывается специфичность. Как выглядит формула специфичности?

> [!NOTE]
> **Специфичность** - это вес CSS-селектора. Она помогает каскаду решить, какое правило победит, если несколько правил задают одно и то же свойство одному элементу.

## Формула

Специфичность часто представляют как кортеж:

```text
inline styles | id | classes/attributes/pseudo-classes | elements/pseudo-elements
```

Например:

```text
0-1-2-1
```

## Примеры

| Селектор | Специфичность |
| --- | --- |
| `p` | `0-0-0-1` |
| `.text` | `0-0-1-0` |
| `#app` | `0-1-0-0` |
| `button.primary:hover` | `0-0-2-1` |
| `#app .card h2` | `0-1-1-1` |

## Пример конфликта

```css
p {
  color: black;
}

.lead {
  color: blue;
}
```

```html
<p class="lead">Текст</p>
```

Победит `.lead`, потому что класс специфичнее селектора тега.

## Inline styles

```html
<p style="color: red">Текст</p>
```

Inline-стили имеют очень высокий приоритет и обычно перебивают обычные CSS-правила.

## :where() и :is()

`:where()` всегда имеет нулевую специфичность.

```css
:where(.card h2) {
  margin: 0;
}
```

`:is()` берет специфичность самого специфичного селектора внутри.

## Мини-шпаргалка

- Специфичность помогает выбрать победившее правило.
- `id` сильнее класса.
- Класс сильнее тега.
- При равной специфичности побеждает правило ниже.
- Inline-стили очень сильные.
- `:where()` полезен для низкой специфичности.
