# Что такое двусторонняя привязка данных?

> [!NOTE]
> Двусторонняя привязка данных означает, что состояние задает значение поля, а изменение поля пользователем обновляет это состояние. Во Vue для этого используют `v-model`.

## Вопрос

Что такое двусторонняя привязка данных?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const name = ref("");
</script>

<template>
  <input v-model="name" />
  <p>Привет, {{ name }}</p>
</template>
```

Если изменить `name` в коде, input обновится. Если пользователь вводит текст, обновляется `name`.

## Что происходит под капотом

Для текстового input `v-model` примерно равен связке `:value` и `@input`.

```vue
<input
  :value="name"
  @input="name = $event.target.value"
/>
```

## Почему это удобно

Формы становятся короче: не нужно вручную писать value-binding и обработчик ввода для каждого поля.

## На компонентах

В Vue 3 `v-model` на компоненте использует prop `modelValue` и событие `update:modelValue`.

```vue
<BaseInput v-model="email" />
```

## Мини-шпаргалка

- Данные идут в UI.
- UI-события обновляют данные.
- Во Vue это обычно `v-model`.
- Для компонента: `modelValue` + `update:modelValue`.
- Модификаторы помогают обработать ввод.
