# Что такое дистрибутивное поведение union типов

> [!summary] Коротко
> Дистрибутивность означает, что conditional type применяется к каждому варианту union по отдельности, а потом результаты снова собираются в union.

## Вопрос

Что такое дистрибутивное поведение union типов?

## Базовый пример

```typescript
type ToArray<T> = T extends unknown ? T[] : never;

type Result = ToArray<string | number>;
// string[] | number[]
```

TypeScript как будто делает так:

```typescript
ToArray<string> | ToArray<number>
```

## Почему не `(string | number)[]`

Потому что условие `T extends unknown` распределилось по каждому члену union отдельно.

```typescript
type Distributed = ToArray<string | number>;
// string[] | number[]

type NotDistributed = (string | number)[];
// массив, где каждый элемент string или number
```

## Как выключить дистрибутивность

Нужно завернуть `T` в кортеж.

```typescript
type ToArrayNonDistributed<T> = [T] extends [unknown] ? T[] : never;

type Result = ToArrayNonDistributed<string | number>;
// (string | number)[]
```

## Практический пример

Так устроены многие utility-типы вроде `Exclude`.

```typescript
type MyExclude<T, U> = T extends U ? never : T;

type Result = MyExclude<"a" | "b" | "c", "a">;
// "b" | "c"
```

## Мини-шпаргалка

- Conditional type с голым `T` распределяется по union.
- `T extends U ? X : Y` применяется к каждому варианту `T`.
- `[T] extends [U]` выключает распределение.
- Это основа `Exclude`, `Extract` и многих advanced-типов.
