# Лексическая область видимости

> [!summary] Коротко
> Лексическая область видимости означает, что доступность переменных определяется местом, где функция была объявлена в коде.

## Вопрос

Что такое lexical scope?

## Определение

JavaScript использует лексическую область видимости: функция запоминает внешние переменные из того места, где она была создана, а не из того места, где ее потом вызвали.

## Пример

```javascript
const name = 'global';

function outer() {
  const name = 'outer';

  function inner() {
    console.log(name);
  }

  return inner;
}

const fn = outer();

fn(); // 'outer'
```

`inner` была объявлена внутри `outer`, поэтому видит `name` из `outer`, даже когда вызывается позже.

## Связь с замыканием

Лексическая область видимости делает замыкания возможными. Функция может продолжать использовать переменные внешней функции после того, как внешняя функция завершилась.

## Lexical vs dynamic

```javascript
function call(fn) {
  const value = 'call';
  fn();
}

const value = 'global';

function print() {
  console.log(value);
}

call(print); // 'global'
```

Переменная берется из места объявления `print`, а не из места вызова.

## Мини-шпаргалка

```text
lexical scope = where function is written, not where it is called
```
