# Для чего используется v-pre?

> [!NOTE]
> `v-pre` говорит Vue пропустить компиляцию элемента и его дочернего содержимого. Выражения внутри останутся обычным текстом.

## Вопрос

Для чего используется `v-pre`?

## Базовый пример

```vue
<template>
  <code v-pre>{{ message }}</code>
</template>
```

Vue не будет обрабатывать `{{ message }}`. Пользователь увидит текст `{{ message }}`.

## Когда полезно

`v-pre` используют для примеров кода, документации, демо шаблонного синтаксиса и редких оптимизаций статичного контента.

```vue
<pre v-pre>
  <p>{{ title }}</p>
</pre>
```

## Отличие от v-once

`v-once` компилирует и рендерит один раз. `v-pre` вообще пропускает компиляцию участка.

## Осторожно

Внутри `v-pre` не работают директивы, интерполяции и привязки Vue.

```vue
<div v-pre>
  <span :title="tooltip">{{ name }}</span>
</div>
```

`:title` и `{{ name }}` будут восприняты как обычный текст/атрибуты.

## Мини-шпаргалка

- `v-pre` отключает компиляцию участка шаблона.
- Интерполяции внутри не выполняются.
- Удобен для показа примеров Vue-синтаксиса.
- Не путай с `v-once`.
