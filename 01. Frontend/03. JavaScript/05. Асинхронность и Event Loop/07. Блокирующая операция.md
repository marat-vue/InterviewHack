# Блокирующая операция

> [!NOTE]
> Блокирующая операция занимает Call Stack и не дает JavaScript выполнять другие задачи, пока сама не завершится.

## Вопрос

Что происходит при блокирующей операции в JavaScript?

## Определение

Блокирующая операция - это синхронная работа, которая выполняется слишком долго и удерживает основной поток. Пока она идет, Event Loop не может передать в стек новые задачи.

В браузере это может привести к зависанию интерфейса. В Node.js - к задержке обработки других запросов.

## Наглядный пример

```javascript
console.log('start');

setTimeout(() => {
  console.log('timer');
}, 0);

const start = Date.now();

while (Date.now() - start < 3000) {
  // имитируем тяжелую синхронную работу
}

console.log('end');

// start
// пауза 3 секунды
// end
// timer
```

Таймер был готов почти сразу, но его callback не мог выполниться, пока стек был занят циклом.

## Типичные блокирующие операции

- долгие циклы `for` или `while`;
- `alert()`, `prompt()`, `confirm()`;
- синхронные файловые API в Node.js;
- большой `JSON.parse()` или `JSON.stringify()`;
- тяжелые вычисления в основном потоке.

## Как уменьшить блокировку

- использовать асинхронные API;
- дробить большую работу на части;
- переносить тяжелые вычисления в Web Worker;
- не выполнять большие синхронные операции во время взаимодействия с UI.

## Мини-шпаргалка

```javascript
// Блокирует поток
while (heavyCondition) {}

// Лучше для тяжелых вычислений в браузере
const worker = new Worker('worker.js');
```
