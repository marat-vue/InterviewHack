# Как вызвать статический метод?

> [!NOTE]
> Статический метод вызывается через имя класса: `ClassName.method()`.

## Вопрос

Как правильно вызвать метод, объявленный с `static`?

## Пример

```javascript
class User {
  static createGuest() {
    return new User('Guest');
  }

  constructor(name) {
    this.name = name;
  }
}

const guest = User.createGuest();

console.log(guest.name); // 'Guest'
```

`createGuest()` вызывается на классе `User`.

## Нельзя вызвать на экземпляре

```javascript
const user = new User('Ann');

user.createGuest(); // TypeError
```

Экземпляр не видит статический метод как свой метод.

## this внутри static

```javascript
class User {
  static type = 'user';

  static getType() {
    return this.type;
  }
}

console.log(User.getType()); // 'user'
```

В статическом методе `this` обычно указывает на сам класс.

## Наследование static

```javascript
class Admin extends User {}

console.log(Admin.getType()); // 'user'
```

Статические методы наследуются дочерними классами.

## Мини-шпаргалка

```javascript
class A {
  static method() {}
}

A.method();
```
