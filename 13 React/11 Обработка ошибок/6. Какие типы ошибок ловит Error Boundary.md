# Какие типы ошибок ловит Error Boundary?

> [!summary]
> Error Boundary ловит ошибки, которые происходят во время render и lifecycle дочерних компонентов. Он не ловит ошибки в event handlers, async callbacks, `setTimeout`, обычных Promise и ошибки внутри самой boundary.

## Что Error Boundary ловит?

Ошибки render:

```jsx
function UserCard({ user }) {
  return <h2>{user.name}</h2>
}
```

Ошибки в constructor class component:

```jsx
class BrokenWidget extends React.Component {
  constructor(props) {
    super(props)
    throw new Error('Constructor failed')
  }
}
```

Ошибки в lifecycle methods:

```jsx
class BrokenWidget extends React.Component {
  componentDidMount() {
    throw new Error('Mount failed')
  }

  render() {
    return <div />
  }
}
```

Синхронные ошибки во время вычисления render:

```jsx
function Chart({ items }) {
  const data = useMemo(() => normalizeItems(items), [items])

  return <ChartView data={data} />
}
```

Если `normalizeItems` бросит ошибку во время render, boundary может ее поймать.

## Что Error Boundary не ловит?

Event handlers:

```jsx
function Button() {
  function handleClick() {
    throw new Error('Click failed')
  }

  return <button onClick={handleClick}>Click</button>
}
```

Нужно:

```jsx
function handleClick() {
  try {
    dangerousAction()
  } catch (error) {
    showToast('Action failed')
  }
}
```

Async callbacks:

```jsx
setTimeout(() => {
  throw new Error('Timer failed')
}, 1000)
```

Promise:

```jsx
fetch('/api/user').then(() => {
  throw new Error('Promise failed')
})
```

Нужно обрабатывать через `.catch` или `try/catch` внутри async-функции.

## Ошибки useEffect

Ошибки внутри effect не стоит рассчитывать ловить boundary как render error.

```jsx
useEffect(() => {
  async function load() {
    try {
      await fetchData()
    } catch (error) {
      setError(error)
    }
  }

  load()
}, [])
```

Если нужно показать fallback, сохрани ошибку в state и отрендери error UI.

## Мини-шпаргалка

- Boundary ловит render/lifecycle errors ниже себя.
- Boundary не ловит события.
- Boundary не ловит обычный async-код.
- Boundary не ловит ошибку внутри самой boundary.
- Для async и handlers нужны `try/catch`, `.catch`, error state и monitoring.
