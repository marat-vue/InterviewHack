# JSON

> [!summary] Коротко
> JSON - текстовый формат для хранения и передачи данных. Он похож на объект JavaScript, но является строкой и имеет строгие правила синтаксиса.

## Вопрос

Что такое JSON?

## Основная идея

JSON расшифровывается как JavaScript Object Notation. Его используют для обмена данными между клиентом и сервером, хранения настроек и передачи структурированных данных.

Пример JSON:

```json
{
  "name": "Anna",
  "age": 25,
  "skills": ["JavaScript", "Vue"],
  "active": true,
  "avatar": null
}
```

Это текст, а не объект JavaScript.

## Чем JSON отличается от объекта JavaScript

JavaScript object:

```javascript
const user = {
  name: "Anna",
  age: 25,
};
```

JSON string:

```json
{
  "name": "Anna",
  "age": 25
}
```

Главные правила JSON:

- ключи только в двойных кавычках;
- строки только в двойных кавычках;
- нельзя использовать функции;
- нельзя использовать `undefined`;
- нельзя писать комментарии;
- нельзя оставлять trailing comma.

## `JSON.stringify`

Преобразует значение JavaScript в JSON-строку.

```javascript
const user = {
  name: "Anna",
  age: 25,
};

const json = JSON.stringify(user);

console.log(json); // '{"name":"Anna","age":25}'
```

## `JSON.parse`

Преобразует JSON-строку в значение JavaScript.

```javascript
const json = '{"name":"Anna","age":25}';
const user = JSON.parse(json);

console.log(user.name); // "Anna"
```

Если строка некорректная, будет ошибка:

```javascript
JSON.parse("{name: 'Anna'}"); // SyntaxError
```

## Что происходит с `undefined`

```javascript
JSON.stringify({
  name: "Anna",
  age: undefined,
});
// '{"name":"Anna"}'
```

В объектах свойства со значением `undefined` пропускаются.

В массивах `undefined` превращается в `null`:

```javascript
JSON.stringify([1, undefined, 3]);
// '[1,null,3]'
```

## Мини-шпаргалка

```javascript
JSON.stringify(value); // JS -> JSON string
JSON.parse(json);      // JSON string -> JS
```

| Можно в JSON | Нельзя в JSON |
| --- | --- |
| string | function |
| number | `undefined` |
| boolean | `Symbol` |
| null | комментарии |
| object | trailing comma |
| array | одинарные кавычки для строк |
