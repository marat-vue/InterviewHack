# Какие команды Redis нужно знать на собеседовании?

> [!NOTE]
> На собеседовании не нужно помнить все команды Redis. Важно знать ключевые группы команд, понимать структуры данных, complexity, TTL, atomicity и где каждая команда применяется.

## Key commands

| Команда | Зачем нужна |
|---|---|
| `EXISTS` | проверить наличие ключа |
| `TYPE` | узнать тип значения |
| `DEL` | удалить ключ |
| `UNLINK` | удалить большой ключ мягче |
| `EXPIRE` | задать TTL |
| `TTL` | посмотреть TTL |
| `PERSIST` | убрать TTL |
| `SCAN` | безопасный обход keyspace |

## String commands

| Команда | Зачем нужна |
|---|---|
| `GET` | прочитать строку |
| `SET` | записать строку |
| `SET ... EX` | записать с TTL |
| `SET ... NX` | записать только если нет ключа |
| `INCR` | атомарный increment |
| `DECR` | атомарный decrement |
| `MGET` | прочитать несколько keys |
| `MSET` | записать несколько keys |

## Hash commands

| Команда | Зачем нужна |
|---|---|
| `HSET` | записать field |
| `HGET` | прочитать field |
| `HGETALL` | прочитать весь hash, осторожно на больших |
| `HMGET` | прочитать несколько fields |
| `HINCRBY` | атомарный counter внутри hash |
| `HDEL` | удалить field |
| `HSCAN` | incremental обход hash |

## List commands

| Команда | Зачем нужна |
|---|---|
| `LPUSH` | добавить слева |
| `RPUSH` | добавить справа |
| `LPOP` | снять слева |
| `RPOP` | снять справа |
| `BLPOP` | blocking pop |
| `LRANGE` | получить range |
| `LTRIM` | ограничить длину |

## Set commands

| Команда | Зачем нужна |
|---|---|
| `SADD` | добавить unique member |
| `SREM` | удалить member |
| `SISMEMBER` | проверить membership |
| `SMEMBERS` | все members, осторожно на больших |
| `SCARD` | размер set |
| `SINTER` | пересечение |
| `SUNION` | объединение |
| `SSCAN` | incremental обход |

## Sorted set commands

| Команда | Зачем нужна |
|---|---|
| `ZADD` | добавить member со score |
| `ZRANGE` | получить range |
| `ZREVRANGE` | получить top по убыванию в старом стиле |
| `ZRANK` | rank member |
| `ZSCORE` | score member |
| `ZREM` | удалить member |
| `ZREMRANGEBYSCORE` | удалить по score |

## Stream commands

| Команда | Зачем нужна |
|---|---|
| `XADD` | добавить event |
| `XREAD` | читать stream |
| `XGROUP CREATE` | создать consumer group |
| `XREADGROUP` | читать через group |
| `XACK` | подтвердить обработку |
| `XPENDING` | посмотреть pending |
| `XAUTOCLAIM` | забрать stuck entries |
| `XTRIM` | ограничить stream |

## Pub/Sub commands

| Команда | Зачем нужна |
|---|---|
| `PUBLISH` | отправить сообщение |
| `SUBSCRIBE` | подписаться на channel |
| `UNSUBSCRIBE` | отписаться |
| `PSUBSCRIBE` | подписаться по pattern |

## Administrative commands

| Команда | Зачем нужна |
|---|---|
| `INFO` | диагностика server state |
| `CONFIG GET` | посмотреть config |
| `CLIENT LIST` | посмотреть connections |
| `SLOWLOG GET` | медленные команды |
| `MEMORY USAGE` | оценить память ключа |

## Мини-шпаргалка

- Для TTL: `SET EX`, `EXPIRE`, `TTL`.
- Для rate limit: `INCR` + `EXPIRE`.
- Для lock: `SET NX PX`.
- Для leaderboard: `ZADD`, `ZRANGE`, `ZSCORE`.
- Для reliable events: Streams.
- Для realtime broadcast: Pub/Sub.
- Для production scan: `SCAN`, не `KEYS`.
