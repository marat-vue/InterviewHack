# Как сделать самый простой radio button в HTML

> [!summary]
> Radio button создают через `<input type="radio">`. Радиокнопки с одинаковым `name` образуют группу, где пользователь может выбрать только один вариант.

## Главное

```html
<label>
  <input type="radio" name="delivery" value="pickup">
  Самовывоз
</label>

<label>
  <input type="radio" name="delivery" value="courier">
  Курьер
</label>
```

Обе радиокнопки имеют `name="delivery"`, поэтому выбрать можно только одну.

## Зачем нужен value

`value` - значение, которое отправится с формой.

```html
<input type="radio" name="plan" value="basic">
```

Если пользователь выберет этот вариант, форма отправит:

```text
plan=basic
```

## Вариант по умолчанию

```html
<label>
  <input type="radio" name="plan" value="basic" checked>
  Basic
</label>
```

`checked` отмечает radio button по умолчанию.

## Fieldset и legend

Для группы вариантов полезно использовать `fieldset` и `legend`.

```html
<fieldset>
  <legend>Способ доставки</legend>

  <label>
    <input type="radio" name="delivery" value="pickup">
    Самовывоз
  </label>

  <label>
    <input type="radio" name="delivery" value="courier">
    Курьер
  </label>
</fieldset>
```

Так группа становится понятнее для скринридеров.

## Мини-шпаргалка

- Radio button: `input type="radio"`.
- Одинаковый `name` объединяет варианты в группу.
- `value` отправляется на сервер.
- `checked` выбирает вариант по умолчанию.
- Для группы лучше использовать `fieldset` и `legend`.
