# Как браузер загружает изображение указанное в src

> [!summary]
> Когда браузер встречает `<img src="...">`, он определяет URL изображения, ставит ресурс в очередь загрузки, скачивает файл, декодирует его и отображает в рассчитанном месте страницы.

## Общая схема

```text
parse HTML
  -> find img src
  -> resolve URL
  -> request image
  -> download bytes
  -> decode image
  -> paint image
```

## Пример

```html
<img src="/images/hero.jpg" alt="Главный баннер">
```

Браузер превратит `/images/hero.jpg` в абсолютный URL относительно текущего сайта и отправит запрос за файлом.

## Загрузка и приоритет

Изображения в первом экране обычно важнее изображений ниже. Для второстепенных картинок можно использовать lazy loading.

```html
<img src="/gallery/item-1.jpg" alt="Фото товара" loading="lazy">
```

Для очень важного изображения иногда используют высокий приоритет.

```html
<img src="/hero.jpg" alt="Главный экран" fetchpriority="high">
```

## Если изображение не загрузилось

Если файл недоступен, браузер покажет область изображения и текст `alt`, если это возможно.

```html
<img src="/missing.jpg" alt="Схема работы формы">
```

Поэтому `alt` важен не только для скринридеров, но и для ситуации ошибки загрузки.

## Размеры

```html
<img src="/cover.jpg" alt="Обложка" width="800" height="450">
```

`width` и `height` помогают браузеру заранее выделить место и уменьшить скачки layout.

## Мини-шпаргалка

- `src` указывает URL изображения.
- Браузер загружает и декодирует файл.
- `loading="lazy"` откладывает загрузку.
- `fetchpriority="high"` можно использовать для важного изображения.
- `alt` нужен при ошибке загрузки и для доступности.
- `width` и `height` помогают стабильности layout.
