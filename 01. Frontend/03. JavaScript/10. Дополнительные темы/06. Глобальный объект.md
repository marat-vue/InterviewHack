# Глобальный объект

> [!NOTE]
> Глобальный объект - объект верхнего уровня, через который доступны глобальные значения окружения.

## Вопрос

Что такое глобальный объект и как к нему обратиться?

## Определение

Глобальный объект зависит от окружения. В браузере это обычно `window`, в Node.js - `global`. Универсальный способ обратиться к глобальному объекту - `globalThis`.

## Примеры

```javascript
console.log(globalThis);
```

В браузере:

```javascript
console.log(globalThis === window); // true
```

В Node.js:

```javascript
console.log(globalThis === global); // true
```

## Что хранится в глобальном объекте

- стандартные встроенные объекты: `Array`, `Promise`, `Map`;
- функции вроде `setTimeout`;
- браузерные API в браузере;
- глобальные переменные, объявленные через `var` в script-коде.

## var и let

```javascript
var a = 1;
let b = 2;

console.log(window.a); // 1 в браузерном script
console.log(window.b); // undefined
```

`let` и `const` не становятся свойствами `window`.

## Почему лучше globalThis

`globalThis` работает в разных окружениях: браузер, Node.js, worker. Это безопаснее, чем писать `window`, если код должен быть универсальным.

## Мини-шпаргалка

```javascript
globalThis; // универсальный глобальный объект
window;     // браузер
global;     // Node.js
```
