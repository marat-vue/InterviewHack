# Можно ли использовать Composition API вместе с Options API?

> [!NOTE]
> Да, Vue 3 позволяет смешивать Composition API и Options API в одном компоненте, но делать это стоит аккуратно: обычно лучше выбрать один стиль для компонента.

## Вопрос

Можно ли использовать Composition API вместе с Options API?

## Пример смешивания

```vue
<script>
import { ref } from "vue";

export default {
  setup() {
    const count = ref(0);
    return { count };
  },
  computed: {
    doubled() {
      return this.count * 2;
    },
  },
};
</script>

<template>
  <button @click="count++">{{ doubled }}</button>
</template>
```

Значения, возвращенные из `setup`, доступны в template и Options API через `this`.

## Важное ограничение

Внутри `setup` нельзя обращаться к `this`: экземпляр компонента еще не создан в привычном виде.

```typescript
setup() {
  // this.count; // нельзя
}
```

## Когда смешивание оправдано

Это полезно при постепенной миграции старого компонента, подключении composable к Options API или работе в проекте со смешанным стилем.

## Когда лучше не смешивать

Если компонент новый, обычно чище выбрать один подход. Смешивание может запутать, где находится источник состояния и как связана логика.

## Мини-шпаргалка

- Смешивать можно.
- В `setup` нет `this`.
- Возвращенное из `setup` доступно в template.
- Для нового кода чаще выбирают единый стиль.
