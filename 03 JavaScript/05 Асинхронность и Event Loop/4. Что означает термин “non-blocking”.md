# Что означает термин “non-blocking”

> [!summary] Коротко
> Non-blocking означает, что операция запускается, а программа не стоит на месте в ожидании результата.

## Вопрос

Что значит "неблокирующий код" в JavaScript?

## Определение

Неблокирующая операция не занимает основной поток ожиданием. JavaScript передает задачу среде выполнения, продолжает выполнять следующий код, а результат получает позже через callback, промис или событие.

Обычно термин используют для I/O: запросов к серверу, чтения файлов, таймеров, событий.

## Блокирующий пример

```javascript
alert('Пока окно открыто, страница не реагирует');

console.log('Выполнится после закрытия alert');
```

`alert()` блокирует поток: пользовательский интерфейс фактически ждет.

## Неблокирующий пример

```javascript
console.log('start');

setTimeout(() => {
  console.log('done');
}, 1000);

console.log('next');

// start
// next
// done
```

Код не ждет таймер, а идет дальше.

## Почему это важно

В браузере блокировка делает интерфейс неотзывчивым. В Node.js блокировка мешает серверу обрабатывать другие запросы. Поэтому долгие операции лучше выполнять асинхронно или выносить в отдельный поток.

## Типичные non-blocking операции

- `fetch()`;
- `setTimeout()`;
- события DOM;
- `fs.readFile()` в Node.js;
- WebSocket-сообщения;
- stream-операции.

## Мини-шпаргалка

```javascript
// blocking: код ждет
const data = readFileSync(path);

// non-blocking: результат придет позже
readFile(path, (error, data) => {});
```
