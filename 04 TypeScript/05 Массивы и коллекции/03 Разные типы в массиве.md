# Разные типы в массиве

> [!NOTE] Коротко
> Массив с элементами разных типов описывают через union: `(string | number)[]`. Каждый элемент может быть любым из перечисленных типов.

## Вопрос

Как объявить массив с элементами разных типов?

## Базовый вариант

```typescript
const values: Array<string | number> = ["id", 1, 2, "count"];
```

То же самое в короткой записи:

```typescript
const values: (string | number)[] = ["id", 1];
```

Скобки важны: `string | number[]` означает "строка или массив чисел", а не массив строк и чисел.

## Массив объектов разных форм

```typescript
type User = { role: "user"; name: string };
type Admin = { role: "admin"; permissions: string[] };

const people: Array<User | Admin> = [
  { role: "user", name: "Анна" },
  { role: "admin", permissions: ["users:read"] },
];
```

Для работы с конкретным вариантом нужен narrowing.

```typescript
for (const person of people) {
  if (person.role === "admin") {
    console.log(person.permissions);
  }
}
```

## Массив против кортежа

Массив не фиксирует порядок разных типов.

```typescript
const list: (string | number)[] = [1, "age", 30];
```

Кортеж фиксирует длину и типы по позициям.

```typescript
const tuple: [string, number] = ["age", 30];
```

## Мини-шпаргалка

- `(A | B)[]` - массив элементов типа `A` или `B`.
- Для объектов добавляй поле-дискриминатор.
- Для фиксированного порядка нужен tuple.
- Не забывай скобки вокруг union.
