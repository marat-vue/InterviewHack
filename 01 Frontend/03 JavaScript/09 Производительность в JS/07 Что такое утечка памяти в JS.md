# Что такое утечка памяти в JS?

> [!NOTE] Коротко
> Утечка памяти возникает, когда ненужные объекты остаются достижимыми по ссылкам, поэтому сборщик мусора не может их удалить.

## Вопрос

Что такое memory leak в JavaScript?

## Определение

JavaScript автоматически освобождает память через Garbage Collector. Но GC удаляет только объекты, до которых больше нельзя добраться из активного кода.

Если объект уже не нужен логике, но на него где-то осталась ссылка, память не освобождается. Это и есть утечка.

## Пример с глобальным массивом

```javascript
const cache = [];

function saveData(data) {
  cache.push(data);
}
```

Если данные бесконечно добавляются и не очищаются, память будет расти.

## Пример с обработчиком

```javascript
function mount() {
  const element = document.querySelector('.button');

  element.addEventListener('click', handleClick);
}
```

Если компонент удаляется, а обработчик и ссылки не очищаются, связанные объекты могут удерживаться в памяти.

## Частые причины

- глобальные переменные и кэши без очистки;
- забытые event listeners;
- таймеры и интервалы;
- замыкания, удерживающие большие объекты;
- detached DOM nodes;
- подписки в SPA без отписки.

## Как предотвращать

- удалять слушатели;
- очищать интервалы;
- ограничивать размер кэша;
- обнулять ненужные ссылки;
- профилировать память в DevTools.

## Мини-шпаргалка

```javascript
element.removeEventListener('click', handler);
clearInterval(intervalId);
cache.clear();
```
