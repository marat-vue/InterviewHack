# Type Coercion

> [!summary] Коротко
> Type coercion - это преобразование типов. В JavaScript оно часто происходит неявно: язык сам приводит значения к строке, числу или boolean, чтобы выполнить операцию.

## Вопрос

Что такое преобразование типов (type coercion)?

## Основная идея

Преобразование типов бывает явным и неявным.

Явное:

```javascript
Number("42");   // 42
String(42);     // "42"
Boolean("hi");  // true
```

Неявное:

```javascript
"42" * 2; // 84
"42" + 2; // "422"
```

Во втором примере JavaScript сам решает, какой тип нужен для операции.

## Приведение к строке

Оператор `+` работает как сложение или как конкатенация строк. Если один операнд строка, часто получается строка.

```javascript
"Hello, " + "Anna"; // "Hello, Anna"
"5" + 2;            // "52"
2 + "5";            // "25"
true + "!";         // "true!"
```

## Приведение к числу

Арифметические операторы `-`, `*`, `/`, `%` обычно приводят значения к числу.

```javascript
"10" - 2; // 8
"10" * 2; // 20
"10" / 2; // 5
```

Если число получить нельзя, результатом будет `NaN`.

```javascript
"abc" * 2; // NaN
```

Некоторые значения приводятся неочевидно:

```javascript
Number(null);      // 0
Number(undefined); // NaN
Number("");        // 0
Number(false);     // 0
Number(true);      // 1
```

## Приведение к boolean

В условиях JavaScript приводит значение к boolean.

```javascript
if ("hello") {
  console.log("строка truthy");
}

if ("") {
  console.log("не выполнится");
}
```

Falsy-значения:

```javascript
false;
0;
-0;
0n;
"";
null;
undefined;
NaN;
```

Все остальные значения - truthy, включая `[]` и `{}`.

## Приведение в сравнении

`==` делает неявное приведение типов:

```javascript
0 == false;        // true
"5" == 5;          // true
null == undefined; // true
```

`===` не делает:

```javascript
0 === false;        // false
"5" === 5;          // false
null === undefined; // false
```

## Мини-шпаргалка

| Контекст | Во что приводит |
| --- | --- |
| `+` со строкой | к строке |
| `-`, `*`, `/`, `%` | к числу |
| `if`, `while`, `!`, `&&`, `||` | к boolean |
| `==` | по специальным правилам |
| `===` | не приводит |

## Практический совет

Пишите преобразования явно, когда от типа зависит логика:

```javascript
const page = Number(searchParams.get("page") ?? 1);
const isVisible = Boolean(element);
```

Так код проще читать и отлаживать.
