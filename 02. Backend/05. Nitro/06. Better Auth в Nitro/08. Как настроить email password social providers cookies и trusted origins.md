# Как настроить email/password, social providers, cookies и trusted origins?

> [!NOTE]
> Better Auth настраивается в `betterAuth({ ... })`: включаются auth methods, social providers, session/cookie behavior, trusted origins и plugins. Для Nitro особенно важно согласовать `BETTER_AUTH_URL`, frontend origin, CORS и cookie settings.

## Email/password

```ts
export const auth = betterAuth({
  emailAndPassword: {
    enabled: true,
    autoSignIn: true,
  },
});
```

`autoSignIn: false` можно использовать, если после регистрации пользователь должен подтвердить email или пройти дополнительный flow.

## Password reset и email verification

Обычно нужно подключить отправку email:

```ts
export const auth = betterAuth({
  emailAndPassword: {
    enabled: true,
    sendResetPassword: async ({ user, url }) => {
      await emailService.sendPasswordReset(user.email, url);
    },
  },
  emailVerification: {
    sendVerificationEmail: async ({ user, url }) => {
      await emailService.sendVerification(user.email, url);
    },
  },
});
```

Точные options зависят от актуальной версии Better Auth, поэтому при настройке email flow сверяйся с документацией по Email & Password.

## Social providers

```ts
export const auth = betterAuth({
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
});
```

В provider dashboard нужно добавить callback URL, который соответствует Better Auth route.

## `BETTER_AUTH_URL`

Development:

```bash
BETTER_AUTH_URL="http://localhost:3000"
```

Production:

```bash
BETTER_AUTH_URL="https://app.example.com"
```

Если URL неверный, ломаются:

- cookies;
- OAuth callback;
- redirects;
- session flow.

## Trusted origins

Если frontend и backend на разных origins, настрой trusted origins и CORS.

Пример:

```ts
export const auth = betterAuth({
  trustedOrigins: [
    'https://app.example.com',
  ],
});
```

И Nitro CORS:

```ts
handleCors(event, {
  origin: ['https://app.example.com'],
  credentials: true,
});
```

## Cookies

Production cookies должны быть secure:

```txt
HttpOnly
Secure
SameSite=Lax/Strict/None по flow
```

Если frontend/backend на разных subdomains, нужно внимательно настроить:

- cookie domain;
- `SameSite=None`;
- `Secure=true`;
- CORS `credentials: true`;
- frontend fetch credentials.

## Client baseURL

Same-origin:

```ts
export const authClient = createAuthClient();
```

Different origin:

```ts
export const authClient = createAuthClient({
  baseURL: 'https://api.example.com',
});
```

Если path не `/api/auth`, укажи base path по документации Better Auth client.

## Мини-шпаргалка

- Email/password включается через `emailAndPassword.enabled`.
- Social providers задаются в `socialProviders`.
- `BETTER_AUTH_SECRET` должен быть случайным и приватным.
- `BETTER_AUTH_URL` должен совпадать с production origin.
- Cross-origin auth требует CORS + trusted origins + правильные cookies.
- Email verification/reset требуют email provider callback.
