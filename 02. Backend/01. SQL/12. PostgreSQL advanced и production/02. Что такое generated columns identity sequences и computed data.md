# Что такое generated columns, identity, sequences и computed data?

> [!NOTE]
> PostgreSQL умеет генерировать значения: identity columns для id, sequences для счетчиков и generated columns для вычисляемых данных. Это помогает держать часть инвариантов рядом с БД.

## Identity columns

Современный способ автоинкрементного id:

```sql
CREATE TABLE users (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email text NOT NULL UNIQUE
);
```

Варианты:

```sql
GENERATED ALWAYS AS IDENTITY
GENERATED BY DEFAULT AS IDENTITY
```

`ALWAYS` строже: БД сама генерирует значение. `BY DEFAULT` позволяет явно передать id, если нужно.

## Sequences

Sequence - объект, который генерирует числа.

```sql
CREATE SEQUENCE invoice_number_seq;

SELECT nextval('invoice_number_seq');
```

Sequences полезны для:

- invoice numbers;
- internal counters;
- custom numbering.

Важно: sequence values могут иметь gaps. Не обещай пользователям “без пропусков”, если используешь sequence.

## Generated columns

Generated column вычисляется из других колонок.

```sql
CREATE TABLE products (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  price numeric(12, 2) NOT NULL,
  tax numeric(12, 2) NOT NULL,
  total numeric(12, 2) GENERATED ALWAYS AS (price + tax) STORED
);
```

`STORED` значит, что значение хранится физически и обновляется при изменении зависимых колонок.

## Когда использовать generated columns?

Хорошо:

- normalized search fields;
- derived numeric values;
- computed full name;
- extracted JSONB fields для индекса;
- stable deterministic expressions.

Плохо:

- сложная бизнес-логика;
- выражения, зависящие от внешних таблиц;
- runtime context;
- часто меняющиеся правила.

## Пример с JSONB

```sql
CREATE TABLE events (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  payload jsonb NOT NULL,
  event_type text GENERATED ALWAYS AS (payload->>'type') STORED
);

CREATE INDEX events_event_type_idx ON events (event_type);
```

## Мини-шпаргалка

- Identity - современный авто id.
- Sequence может иметь gaps.
- Generated column хранит вычисляемое значение.
- Generated columns хороши для stable deterministic derived data.
- Сложную бизнес-логику лучше оставить приложению или отдельным процессам.
