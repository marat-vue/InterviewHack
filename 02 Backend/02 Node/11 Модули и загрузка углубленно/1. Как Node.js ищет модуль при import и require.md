# Как Node.js ищет модуль при import и require?

> [!summary]
> Node.js resolve-ит модуль по спецификатору импорта: встроенный модуль, относительный путь, абсолютный путь, package import или пакет из `node_modules`. Правила немного отличаются для CommonJS и ES Modules.

## Типы спецификаторов

```js
import fs from 'node:fs'; // встроенный модуль
import config from './config.js'; // относительный путь
import express from 'express'; // пакет из node_modules
```

## Встроенные модули

Встроенные модули лучше импортировать с префиксом `node:`.

```js
import path from 'node:path';
```

Так видно, что зависимость идет из Node.js, а не из npm.

## Относительные импорты

В ESM обычно нужно указывать расширение файла:

```js
import { sum } from './math.js';
```

CommonJS исторически умел пробовать варианты вроде `.js`, `.json`, `index.js`.

```js
const { sum } = require('./math');
```

## Пакеты

Если спецификатор не относительный и не встроенный, Node.js ищет пакет в `node_modules`, поднимаясь вверх по папкам проекта.

```txt
project/src/app.js
project/src/node_modules/pkg
project/node_modules/pkg
node_modules/pkg
```

## Мини-шпаргалка

- `node:fs` - встроенный модуль.
- `./file.js` - относительный путь.
- `express` - пакет.
- ESM строже относится к расширениям.
- `package.json` может менять точку входа через `main` и `exports`.
