# Подключение React Router и базовая маршрутизация

> [!summary]
> React Router подключается через пакет `react-router` или фреймворковую интеграцию. Для обычного React SPA часто используют `createBrowserRouter` и `RouterProvider`, а routes описывают массивом объектов.

## Установка

```bash
npm install react-router
```

В проектах, где используется `react-router-dom`, пакет может уже приходить через ecosystem setup. В современных версиях React Router основной пакет - `react-router`.

## Базовый router

```tsx
import { createBrowserRouter, RouterProvider } from 'react-router'

const router = createBrowserRouter([
  {
    path: '/',
    element: <HomePage />,
  },
  {
    path: '/about',
    element: <AboutPage />,
  },
  {
    path: '/users/:userId',
    element: <UserPage />,
  },
])

function Root() {
  return <RouterProvider router={router} />
}
```

## Link

```tsx
import { Link } from 'react-router'

function Header() {
  return (
    <nav>
      <Link to="/">Home</Link>
      <Link to="/about">About</Link>
    </nav>
  )
}
```

`Link` меняет route без полной перезагрузки страницы.

## NavLink

```tsx
import { NavLink } from 'react-router'

function MainNav() {
  return (
    <NavLink
      to="/settings"
      className={({ isActive }) => (isActive ? 'active' : undefined)}
    >
      Settings
    </NavLink>
  )
}
```

`NavLink` знает, активен ли текущий route.

## Dynamic params

Route:

```tsx
{
  path: '/users/:userId',
  element: <UserPage />,
}
```

Компонент:

```tsx
import { useParams } from 'react-router'

function UserPage() {
  const { userId } = useParams()

  return <h1>User {userId}</h1>
}
```

## Not Found

```tsx
const router = createBrowserRouter([
  { path: '/', element: <HomePage /> },
  { path: '*', element: <NotFoundPage /> },
])
```

`*` ловит все unmatched paths.

## Что отвечать на собеседовании?

В React Router routes описывают URL и соответствующий UI. Для SPA используют browser history, `Link` меняет маршрут без reload, `NavLink` помогает подсветить активный route, dynamic params задаются через `:paramName`, а fallback route можно описать через `*`.

## Мини-шпаргалка

- Установка: `npm install react-router`.
- Router: `createBrowserRouter`.
- Provider: `RouterProvider`.
- Ссылка: `Link`.
- Активная ссылка: `NavLink`.
- Dynamic path: `/users/:userId`.
