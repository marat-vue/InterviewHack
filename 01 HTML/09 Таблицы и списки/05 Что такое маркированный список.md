# Что такое маркированный список?

> [!NOTE]
> Маркированный список создается тегом `<ul>` и используется для набора пунктов, где порядок не имеет принципиального значения.

## Главное

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

`ul` означает unordered list. Каждый пункт создается через `li`.

## Когда использовать ul

- Список преимуществ.
- Меню.
- Набор тегов или категорий.
- Список характеристик.
- Перечень ссылок.

```html
<nav aria-label="Разделы сайта">
  <ul>
    <li><a href="/html">HTML</a></li>
    <li><a href="/css">CSS</a></li>
    <li><a href="/js">JavaScript</a></li>
  </ul>
</nav>
```

## ul или ol

```text
Порядок важен     -> ol
Порядок не важен  -> ul
```

Например, шаги установки - `ol`, а список технологий - `ul`.

## Стили маркеров

Внешний вид маркеров меняют через CSS.

```css
ul {
  list-style-type: square;
}
```

Не нужно выбирать `ol` или `ul` из-за внешнего вида маркера: выбирай по смыслу.

## Мини-шпаргалка

- `ul` - unordered list.
- `li` - пункт списка.
- Используется, когда порядок не важен.
- Навигационные меню часто делают через `ul`.
- Внешний вид маркеров настраивает CSS.
