# Что такое свойство и значение в CSS

> [!summary]
> **CSS-свойство** указывает, какую визуальную характеристику нужно изменить, а **значение** говорит, на что именно ее установить.

## Главное

```css
p {
  color: #111827;
  font-size: 16px;
  line-height: 1.5;
}
```

Здесь:

- `color`, `font-size`, `line-height` - свойства;
- `#111827`, `16px`, `1.5` - значения;
- `color: #111827;` - объявление;
- весь блок `p { ... }` - CSS-правило.

## Структура объявления

```css
property: value;
```

После свойства ставится двоеточие, после значения - точка с запятой.

## Примеры свойств

| Свойство | Что меняет |
| --- | --- |
| `color` | Цвет текста |
| `background-color` | Цвет фона |
| `font-size` | Размер шрифта |
| `margin` | Внешний отступ |
| `padding` | Внутренний отступ |
| `display` | Модель отображения |
| `position` | Позиционирование |

## Разные типы значений

```css
.card {
  width: 320px;
  color: rgb(17 24 39);
  display: flex;
  opacity: 0.8;
  transform: translateY(4px);
}
```

Значениями могут быть числа, цвета, ключевые слова, функции, строки, URL и переменные.

## Мини-шпаргалка

- Свойство отвечает на вопрос "что меняем?".
- Значение отвечает на вопрос "на что меняем?".
- Объявление записывается как `property: value;`.
- Несколько объявлений объединяются в CSS-правило.
- Ошибочное значение браузер обычно игнорирует.
