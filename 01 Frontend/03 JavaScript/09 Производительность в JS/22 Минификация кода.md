# Минификация кода

> [!NOTE] Коротко
> Минификация уменьшает размер JavaScript/CSS, удаляя лишние пробелы, комментарии и сокращая код без изменения поведения.

## Вопрос

Зачем нужна минификация кода?

## Определение

Минификация - этап сборки, который делает файлы меньше для передачи по сети. Минификатор удаляет пробелы, переносы, комментарии, может сокращать имена локальных переменных и упрощать выражения.

## До минификации

```javascript
function calculateTotal(price, count) {
  const total = price * count;

  return total;
}
```

## После минификации

```javascript
function calculateTotal(t,n){return t*n}
```

Код стал менее читаемым, но выполняет то же самое.

## Что дает минификация

- меньший размер файлов;
- быстрее загрузка;
- меньше трафика;
- лучше работа с gzip/brotli;
- меньше времени на передачу ресурсов.

## Что минификация не решает

Минификация не удаляет автоматически весь неиспользуемый код. Для этого нужны tree shaking и dead code elimination.

Также минификация не исправляет плохие алгоритмы и блокировки main thread.

## Source maps

Для отладки минифицированного кода используют source maps.

```text
app.min.js -> app.js via source map
```

## Мини-шпаргалка

```text
minification -> smaller files
tree shaking -> remove unused code
source map -> debug original code
```
