# Как создавать Zod schemas?

> [!NOTE]
> Zod schema описывает форму данных: строки, числа, boolean, objects, arrays, enums, optional fields и nested structures. Schema можно использовать для validation и получения TypeScript-типа.

## Object schema

```ts
import { z } from 'zod';

export const createUserSchema = z.object({
  email: z.email(),
  name: z.string().min(2).max(100),
  age: z.number().int().min(18).optional(),
});
```

Это базовый пример. Для уверенной работы нужно знать не только `z.object`, но и методы `optional`, `nullable`, `default`, `pick`, `omit`, `partial`, `extend`, `refine`, `superRefine`, `transform`, `coerce`, а также string/number validators. Подробный каталог методов: [[11. Какие методы есть у Zod schemas]].

## Type inference

```ts
export type CreateUserInput = z.infer<typeof createUserSchema>;
```

Теперь TypeScript-тип создается из validation schema.

## Arrays

```ts
const tagsSchema = z.array(z.string().min(1)).max(10);
```

## Enum

```ts
const roleSchema = z.enum(['user', 'admin']);
```

## Мини-шпаргалка

- `z.object` описывает объект.
- `z.string`, `z.number`, `z.boolean` - базовые типы.
- `optional()` делает поле необязательным.
- `z.array(schema)` описывает массив.
- `z.infer<typeof schema>` получает TS-тип.
- Хороший validator собирают по шагам: структура, ограничения, нормализация, cross-field rules, типы.
