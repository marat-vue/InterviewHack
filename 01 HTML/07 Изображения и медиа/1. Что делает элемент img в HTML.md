# Что делает элемент img в HTML

> [!summary]
> Элемент `<img>` вставляет изображение в HTML-документ. Он использует `src` для адреса файла и `alt` для текстового описания изображения.

## Главное

```html
<img
  src="/images/profile.jpg"
  alt="Фото пользователя Анны"
  width="320"
  height="240"
>
```

`img` - void-элемент: у него нет закрывающего тега и внутреннего содержимого.

## Важные атрибуты

| Атрибут | Назначение |
| --- | --- |
| `src` | Адрес изображения |
| `alt` | Текстовая альтернатива |
| `width` | Ширина изображения |
| `height` | Высота изображения |
| `loading` | Стратегия загрузки |
| `srcset` | Набор изображений для разных условий |
| `sizes` | Подсказка браузеру о размере изображения в layout |

## Alt

`alt` описывает смысл изображения.

```html
<img src="/chart.png" alt="График роста продаж за 2026 год">
```

Если изображение декоративное, можно оставить пустой `alt`.

```html
<img src="/decor.svg" alt="">
```

## Lazy loading

```html
<img src="/gallery-1.jpg" alt="Фото проекта" loading="lazy">
```

`loading="lazy"` откладывает загрузку изображения, пока оно не приблизится к видимой области.

## Мини-шпаргалка

- `img` вставляет изображение.
- `src` обязателен для адреса картинки.
- `alt` важен для доступности.
- `width` и `height` помогают избежать layout shift.
- `loading="lazy"` полезен для изображений ниже первого экрана.
- Для адаптивных изображений используют `srcset` и `sizes`.
