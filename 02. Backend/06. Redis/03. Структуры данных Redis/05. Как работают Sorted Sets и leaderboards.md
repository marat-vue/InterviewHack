# Как работают Sorted Sets и leaderboards?

> [!NOTE]
> Sorted Set хранит unique members со score. Это идеальная структура для leaderboard, ranking, priority queues, delayed jobs и time-based индексов.

## Что такое Sorted Set?

```redis
ZADD leaderboard 1500 user:1
ZADD leaderboard 1700 user:2
ZADD leaderboard 1200 user:3
```

Каждый member уникален, у каждого есть numeric score.

## Основные команды

| Команда | Что делает |
|---|---|
| `ZADD` | добавить или обновить score |
| `ZSCORE` | получить score member |
| `ZRANGE` | получить range |
| `ZRANK` | rank по возрастанию |
| `ZREVRANK` | rank по убыванию |
| `ZREM` | удалить member |
| `ZINCRBY` | увеличить score |
| `ZCOUNT` | количество members в score range |
| `ZREMRANGEBYSCORE` | удалить по score range |

## Как получить top-10?

```redis
ZRANGE leaderboard 0 9 REV WITHSCORES
```

Старый стиль:

```redis
ZREVRANGE leaderboard 0 9 WITHSCORES
```

## Как узнать место пользователя?

```redis
ZREVRANK leaderboard user:2
ZSCORE leaderboard user:2
```

Rank начинается с `0`, поэтому для UI обычно добавляют `+ 1`.

## Node.js пример leaderboard

```ts
await redis.zAdd('leaderboard', [
  {
    score: 1500,
    value: 'user:1',
  },
  {
    score: 1700,
    value: 'user:2',
  },
]);

const top = await redis.zRangeWithScores('leaderboard', 0, 9, {
  REV: true,
});
```

## Delayed jobs через Sorted Set

```redis
ZADD jobs:delayed 1786000000000 job:42
ZRANGEBYSCORE jobs:delayed -inf 1786000000000 LIMIT 0 100
ZREM jobs:delayed job:42
```

Score - timestamp, когда job можно выполнить.

## Мини-шпаргалка

- Sorted Set = unique member + score.
- Leaderboard: `ZADD`, `ZRANGE REV WITHSCORES`, `ZREVRANK`.
- Priority queue: score как priority.
- Delayed jobs: score как timestamp.
- Для очистки старых данных: `ZREMRANGEBYSCORE`.
