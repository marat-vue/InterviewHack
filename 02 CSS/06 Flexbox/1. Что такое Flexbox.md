# Что такое Flexbox

> [!summary]
> **Flexbox** - это CSS-модель layout для распределения элементов по одной оси: горизонтально или вертикально. Она удобна для строк, колонок, меню, тулбаров, карточек и выравнивания элементов.

## Главное

Flexbox включается на контейнере.

```css
.toolbar {
  display: flex;
  gap: 8px;
}
```

Дочерние элементы становятся flex items.

```html
<div class="toolbar">
  <button>Назад</button>
  <button>Сохранить</button>
</div>
```

## Почему "одномерный"

Flexbox хорошо управляет элементами вдоль одной главной оси.

```text
row:
  item -> item -> item

column:
  item
  item
  item
```

Если нужно одновременно управлять строками и колонками как сеткой, чаще подходит CSS Grid.

## Что умеет Flexbox

- Выравнивать элементы по горизонтали и вертикали.
- Распределять свободное пространство.
- Переносить элементы на новые строки.
- Менять порядок отображения.
- Растягивать или сжимать элементы.
- Делать одинаковые колонки без сложных расчетов.

## Пример карточек

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 240px;
}
```

Карточки будут переноситься и занимать доступное пространство.

## Мини-шпаргалка

- Flexbox включается через `display: flex`.
- Контейнер управляет flex items.
- Главные оси: main axis и cross axis.
- `justify-content` выравнивает по main axis.
- `align-items` выравнивает по cross axis.
- Для двумерных сеток часто лучше Grid.
