# Что такое e2e testing и когда нужен Playwright?

> [!summary]
> E2E testing проверяет приложение глазами пользователя: браузер, UI, routing, network, backend и данные работают вместе. Playwright - современный инструмент для e2e-тестов, который управляет Chromium, Firefox и WebKit и дает test runner, assertions, isolation, parallelization и debugging tools.

## Что проверяет e2e?

E2E test отвечает:

```text
Пользователь может пройти важный сценарий от начала до конца?
```

Примеры:

- регистрация;
- login;
- checkout;
- создание проекта;
- восстановление пароля;
- отправка формы;
- переход между страницами.

## Почему не все тестировать e2e?

E2E-тесты дают много уверенности, но они:

- медленнее unit/component tests;
- требуют окружения;
- сложнее в отладке;
- дороже в поддержке;
- могут быть flaky при плохой изоляции.

Поэтому e2e лучше оставлять для критичных flows.

## Почему Playwright?

Playwright умеет:

- запускать Chromium, Firefox и WebKit;
- делать auto-wait перед действиями;
- использовать locators;
- делать screenshots/videos/traces;
- мокать network;
- работать в CI;
- запускать тесты параллельно;
- эмулировать mobile devices.

## Первый пример

```ts
import { expect, test } from '@playwright/test';

test('user can open login page', async ({ page }) => {
  await page.goto('/login');

  await expect(page.getByRole('heading', { name: 'Вход' })).toBeVisible();
});
```

## Мини-шпаргалка

- E2E проверяет полный пользовательский путь.
- Playwright управляет реальными браузерами.
- E2E надо писать для критичных flows, а не для каждой кнопки.
- Locators и auto-wait делают тесты стабильнее.
- E2E не заменяет unit/component/integration tests.
