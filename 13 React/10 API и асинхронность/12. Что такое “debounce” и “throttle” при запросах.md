# Что такое “debounce” и “throttle” при запросах?

> [!summary]
> Debounce и throttle ограничивают частоту вызова функции. Debounce ждет паузу в событиях, а throttle разрешает вызов не чаще заданного интервала. Их используют, чтобы не отправлять запрос на каждый символ, скролл или resize.

## Debounce

Debounce откладывает выполнение до тех пор, пока события не прекратятся на заданное время.

```text
typing: r -> re -> rea -> reac -> react
debounce 300ms -> один запрос по "react"
```

Пример хука:

```jsx
function useDebouncedValue(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timerId = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(timerId)
  }, [value, delay])

  return debouncedValue
}
```

Использование:

```jsx
function SearchPage() {
  const [query, setQuery] = useState('')
  const debouncedQuery = useDebouncedValue(query, 300)

  useEffect(() => {
    if (!debouncedQuery) return

    searchProducts(debouncedQuery)
  }, [debouncedQuery])

  return <input value={query} onChange={(event) => setQuery(event.target.value)} />
}
```

## Throttle

Throttle разрешает выполнение не чаще одного раза за интервал.

```text
scroll events every 10ms
throttle 500ms -> обработчик максимум 2 раза в секунду
```

Упрощенный вариант:

```js
function throttle(callback, delay) {
  let lastCall = 0

  return (...args) => {
    const now = Date.now()

    if (now - lastCall >= delay) {
      lastCall = now
      callback(...args)
    }
  }
}
```

## Что выбрать?

| Сценарий | Что выбрать |
|---|---|
| Поиск при вводе | Debounce |
| Валидация после паузы | Debounce |
| Resize handler | Throttle |
| Scroll progress | Throttle |
| Infinite scroll | Throttle или IntersectionObserver |
| Save draft | Debounce |

## Важный нюанс с запросами

Debounce уменьшает количество запросов, но не отменяет уже начатые запросы. Для защиты от устаревших ответов все равно нужны:

- `AbortController`;
- race condition guard;
- query library;
- проверка актуальности query.

## Мини-шпаргалка

- Debounce ждет паузу.
- Throttle ограничивает частоту.
- Для поиска чаще используют debounce.
- Для scroll/resize чаще используют throttle.
- Эти техники не заменяют отмену запросов и обработку ошибок.
