# Как установить Prisma и настроить schema.prisma?

> [!NOTE]
> Подключение Prisma состоит из установки пакетов, инициализации Prisma, настройки datasource/generator, описания моделей, генерации Prisma Client и применения схемы через migrations или `db push`.

## Установка

```bash
npm i @prisma/client
npm i -D prisma
```

Инициализация:

```bash
npx prisma init
```

Обычно создается:

```txt
prisma/
  schema.prisma
.env
```

## Datasource

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

Provider зависит от БД:

| Provider | Когда использовать |
|---|---|
| `postgresql` | PostgreSQL |
| `mysql` | MySQL/MariaDB |
| `sqlite` | SQLite |
| `sqlserver` | Microsoft SQL Server |
| `mongodb` | MongoDB |
| `cockroachdb` | CockroachDB |

## Generator

Классический generator:

```prisma
generator client {
  provider = "prisma-client-js"
}
```

В новых Prisma docs также встречается generator `prisma-client` с явным `output`. В реальном проекте выбирай стиль, который соответствует версии Prisma и scaffold проекта.

```prisma
generator client {
  provider = "prisma-client"
  output   = "../server/generated/prisma"
}
```

Главная идея: generator создает typed client из моделей.

## DATABASE_URL

```bash
DATABASE_URL="postgresql://user:password@localhost:5432/app?schema=public"
```

Для SQLite:

```bash
DATABASE_URL="file:./dev.db"
```

## Минимальная модель

```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  name      String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

## Генерация client

```bash
npx prisma generate
```

После изменения `schema.prisma` нужно заново генерировать client. В `prisma migrate dev` генерация обычно запускается автоматически, но знать команду нужно.

## Применение схемы в development

С миграциями:

```bash
npx prisma migrate dev --name init
```

Быстро синхронизировать без migration history:

```bash
npx prisma db push
```

`db push` удобен для прототипа, но production workflow лучше строить на migrations.

## Проверка через Prisma Studio

```bash
npx prisma studio
```

Studio открывает UI для просмотра и редактирования данных.

## Package scripts

```json
{
  "scripts": {
    "db:generate": "prisma generate",
    "db:migrate": "prisma migrate dev",
    "db:deploy": "prisma migrate deploy",
    "db:studio": "prisma studio"
  }
}
```

## Мини-шпаргалка

- Runtime package: `@prisma/client`.
- Dev CLI: `prisma`.
- `schema.prisma` содержит datasource, generator и models.
- `DATABASE_URL` хранится в env.
- `prisma generate` создает Prisma Client.
- Development migrations: `prisma migrate dev`.
- Production migrations: `prisma migrate deploy`.
