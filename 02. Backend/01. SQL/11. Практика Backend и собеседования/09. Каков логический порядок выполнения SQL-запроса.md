# Каков логический порядок выполнения SQL-запроса?

> [!NOTE]
> SQL-запрос записывается начиная с `SELECT`, но логически обрабатывается в другом порядке: сначала источники данных, затем фильтрация, группировка, агрегаты, выбор выражений, сортировка и ограничение результата.

## Упрощенный порядок

```txt
FROM / JOIN
WHERE
GROUP BY
HAVING
SELECT
DISTINCT
ORDER BY
LIMIT / OFFSET
```

Это логическая модель, а физически оптимизатор может выполнять запрос иначе, если результат останется тем же.

## Почему это важно?

Alias из `SELECT` обычно недоступен в `WHERE`, потому что `WHERE` логически выполняется раньше.

```sql
SELECT total * 0.2 AS tax
FROM orders
WHERE tax > 100;
```

Так часто нельзя. Нужно повторить выражение или использовать подзапрос/CTE.

```sql
WITH calculated AS (
  SELECT total * 0.2 AS tax
  FROM orders
)
SELECT *
FROM calculated
WHERE tax > 100;
```

## Где доступны alias?

Во многих СУБД alias из `SELECT` доступен в `ORDER BY`, потому что сортировка логически идет после выбора выражений.

## Мини-шпаргалка

- Запись запроса и логическая обработка отличаются.
- `WHERE` идет до `SELECT`.
- `HAVING` идет после `GROUP BY`.
- `ORDER BY` идет ближе к концу.
- Физический план может отличаться из-за оптимизатора.
