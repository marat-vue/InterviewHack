# Что такое Redis Stack, JSON, Search, TimeSeries, Bloom и Vector sets?

> [!NOTE]
> Кроме классических структур Redis, современная экосистема Redis включает модули и возможности для JSON-документов, полнотекстового поиска, time series, probabilistic structures и vector search. Для собеседования достаточно понимать, зачем они нужны и когда не стоит тащить их в проект.

## RedisJSON

RedisJSON позволяет хранить JSON-документы и менять части документа без полной перезаписи строки.

Когда полезно:

- document cache;
- profiles/settings;
- nested object updates;
- быстрый read/write JSON рядом с search.

Пример идеи:

```redis
JSON.SET user:1 $ '{"email":"admin@example.com","profile":{"name":"Marat"}}'
JSON.GET user:1 $.profile.name
```

## Redis Search

Search добавляет indexing и search queries.

Когда полезно:

- full-text search;
- secondary indexes;
- filtering/sorting;
- поиск по JSON/hashes.

Для сложного search на больших продуктах часто сравнивают с Elasticsearch/OpenSearch/Meilisearch.

## Redis TimeSeries

TimeSeries предназначен для временных рядов:

- metrics;
- IoT;
- latency samples;
- counters over time.

Пример идеи:

```redis
TS.ADD metrics:latency * 42
TS.RANGE metrics:latency - +
```

## Bloom filters

Bloom filter отвечает “элемент точно отсутствует” или “возможно присутствует”.

Когда полезно:

- защититься от cache penetration;
- быстро проверять seen ids;
- approximate membership.

Минус: возможны false positives.

## Vector sets / vector search

Vector search используют для similarity search:

- semantic search;
- recommendations;
- embeddings;
- nearest neighbors.

Это уже не базовый Redis cache-сценарий, а отдельный search/AI use case.

## Нужно ли учить Redis Stack для backend interview?

Для Node.js fullstack собеседования чаще спрашивают:

- strings;
- hashes;
- lists;
- sets;
- sorted sets;
- streams;
- TTL;
- Pub/Sub;
- persistence;
- replication;
- cluster.

Redis Stack полезен как расширение, но не заменяет базу.

## Мини-шпаргалка

- RedisJSON - JSON-документы.
- Search - индексы и full-text.
- TimeSeries - временные ряды.
- Bloom - approximate membership.
- Vector search - similarity по embeddings.
- Сначала уверенно разберись с core Redis data types.
