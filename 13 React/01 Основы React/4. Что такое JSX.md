# Что такое JSX?

> [!summary]
> JSX - это синтаксическое расширение JavaScript, которое позволяет описывать UI похожей на HTML разметкой прямо внутри JS-кода. JSX не является HTML: под капотом он превращается в JavaScript-объекты React-элементов.

## Как выглядит JSX?

```jsx
function Profile({ user }) {
  return (
    <section className="profile">
      <h1>{user.name}</h1>
      <p>{user.role}</p>
    </section>
  )
}
```

В фигурных скобках можно вставлять JavaScript-выражения:

```jsx
<p>Счет: {count + 1}</p>
```

## Во что превращается JSX?

JSX можно представить как вызов `createElement`:

```jsx
const element = <h1 className="title">Привет</h1>
```

примерно соответствует:

```jsx
const element = React.createElement(
  'h1',
  { className: 'title' },
  'Привет'
)
```

Современные сборщики используют новый JSX transform, но идея остается той же: JSX превращается в JavaScript.

## Что можно писать внутри JSX?

Можно:

```jsx
<h1>{user.name}</h1>
```

```jsx
{isAdmin && <AdminPanel />}
```

```jsx
{items.map((item) => (
  <li key={item.id}>{item.title}</li>
))}
```

Нельзя писать statements напрямую:

```jsx
// так нельзя
<div>{if (isOpen) 'open'}</div>
```

В JSX нужны выражения, а не инструкции.

## Чем JSX отличается от HTML?

| HTML | JSX |
|---|---|
| `class` | `className` |
| `for` | `htmlFor` |
| `onclick` | `onClick` |
| атрибуты строками | можно передавать JS-значения |
| комментарии `<!-- -->` | комментарии `{/* ... */}` |

## Мини-шпаргалка

- JSX похож на HTML, но является JavaScript.
- В JSX используют `className`, а не `class`.
- Внутри `{}` пишут JavaScript-выражения.
- Списки обычно рендерят через `map`.
- JSX должен возвращать один корневой элемент или Fragment.
