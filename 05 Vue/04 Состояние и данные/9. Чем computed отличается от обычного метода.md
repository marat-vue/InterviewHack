# Чем computed отличается от обычного метода

> [!summary] Коротко
> `computed` кэширует результат и пересчитывается только при изменении зависимостей. Обычный метод выполняется каждый раз, когда его вызывают при рендере.

## Вопрос

Чем `computed` отличается от обычного метода?

## Computed

```vue
<script setup>
import { computed, ref } from "vue";

const items = ref([1, 2, 3]);
const total = computed(() => items.value.reduce((sum, item) => sum + item, 0));
</script>

<template>
  <p>{{ total }}</p>
  <p>{{ total }}</p>
</template>
```

Если `items` не изменились, `total` не будет пересчитан заново для каждого обращения.

## Method

```vue
<script setup>
const getTotal = () => items.value.reduce((sum, item) => sum + item, 0);
</script>

<template>
  <p>{{ getTotal() }}</p>
  <p>{{ getTotal() }}</p>
</template>
```

Метод будет вызываться при каждом рендере и каждом обращении в шаблоне.

## Когда использовать computed

Если значение зависит от реактивных данных и должно отображаться или переиспользоваться, выбирай `computed`.

## Когда использовать метод

Если нужна операция по событию, передача аргументов или действие без кэширования, подходит метод.

```vue
<button @click="save">Сохранить</button>
```

## Мини-шпаргалка

- `computed` кэшируется.
- Method выполняется при каждом вызове.
- `computed` хорош для производных данных.
- Method хорош для действий и обработчиков событий.
