# Метод класса VS функция в свойстве объекта

> [!NOTE] Коротко
> Метод класса хранится в прототипе, а функция, записанная в свойство объекта, хранится прямо в этом объекте.

## Вопрос

Чем метод класса отличается от функции в свойстве объекта?

## Метод класса

```javascript
class User {
  sayHi() {
    return 'Hi';
  }
}

const user = new User();

console.log(user.hasOwnProperty('sayHi')); // false
```

Метод `sayHi` лежит в `User.prototype`.

## Функция в свойстве объекта

```javascript
const user = {
  sayHi: function () {
    return 'Hi';
  },
};

console.log(user.hasOwnProperty('sayHi')); // true
```

Здесь функция лежит прямо в объекте `user`.

## Функция как поле экземпляра

```javascript
class Button {
  handleClick = () => {
    console.log(this);
  };
}

const button = new Button();

console.log(button.hasOwnProperty('handleClick')); // true
```

Поля класса создаются на каждом экземпляре.

## Сравнение

| Вариант | Где хранится | Особенность |
| --- | --- | --- |
| метод класса | в прототипе | общий для экземпляров |
| функция в объекте | в самом объекте | отдельное свойство |
| поле класса со стрелкой | в экземпляре | сохраняет `this` |

## Мини-шпаргалка

```javascript
class A {
  method() {}       // prototype
  field = () => {}; // own property
}
```
