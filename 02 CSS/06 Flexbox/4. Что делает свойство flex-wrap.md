# Что делает свойство flex-wrap

> [!summary]
> `flex-wrap` управляет переносом flex items на новые строки или колонки, если им не хватает места на main axis.

## Главное

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

Если карточки не помещаются в одну строку, они перенесутся на следующую.

## Значения

| Значение | Поведение |
| --- | --- |
| `nowrap` | Не переносить, значение по умолчанию |
| `wrap` | Переносить на новые линии |
| `wrap-reverse` | Переносить в обратном направлении |

## nowrap

```css
.toolbar {
  display: flex;
  flex-wrap: nowrap;
}
```

Элементы будут пытаться уместиться в одну линию. Они могут сжиматься или вызвать overflow.

## wrap

```css
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
```

Хорошо подходит для тегов, карточек, кнопок фильтров.

## Мини-шпаргалка

- `flex-wrap` управляет переносом flex items.
- По умолчанию стоит `nowrap`.
- `wrap` разрешает несколько flex-линий.
- `gap` задает расстояние между строками и колонками.
- Для многострочного выравнивания есть `align-content`.
