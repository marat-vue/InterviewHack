# Что такое кастомный хук?

> [!summary]
> Кастомный хук - это пользовательская функция, имя которой начинается с `use` и внутри которой можно вызывать другие хуки. Он нужен для переиспользования stateful-логики между компонентами без копирования кода и без HOC-оберток.

## Базовый пример

```jsx
function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue)

  function toggle() {
    setValue((value) => !value)
  }

  return [value, toggle]
}
```

Использование:

```jsx
function Sidebar() {
  const [isOpen, toggleOpen] = useToggle()

  return (
    <button onClick={toggleOpen}>
      {isOpen ? 'Закрыть' : 'Открыть'}
    </button>
  )
}
```

## Что переиспользует custom hook?

Custom hook переиспользует не UI, а логику:

- state;
- effects;
- refs;
- subscriptions;
- API-запросы;
- работу с browser API;
- form logic;
- derived values.

Он не обязан возвращать JSX.

## Почему имя должно начинаться с use?

По имени `useSomething` React tooling и ESLint понимают, что внутри могут быть хуки и к функции применяются правила хуков.

Плохо:

```jsx
function getOnlineStatus() {
  return useSyncExternalStore(subscribe, getSnapshot)
}
```

Лучше:

```jsx
function useOnlineStatus() {
  return useSyncExternalStore(subscribe, getSnapshot)
}
```

## Custom hook не делит state между компонентами

Если два компонента вызывают один custom hook, они получают независимое состояние, если внутри хука используется локальный `useState`.

```jsx
const a = useToggle()
const b = useToggle()
```

Это два разных состояния.

## Мини-шпаргалка

- Custom hook - функция с именем `use...`.
- Внутри можно вызывать другие хуки.
- Он переиспользует логику, а не разметку.
- Каждый вызов хука имеет свое состояние.
- Правила хуков применяются и к custom hooks.
