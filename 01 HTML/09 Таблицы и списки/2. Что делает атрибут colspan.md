# Что делает атрибут colspan

> [!summary]
> Атрибут `colspan` объединяет ячейку таблицы по горизонтали, позволяя ей занимать несколько столбцов.

## Главное

```html
<table>
  <tr>
    <th colspan="2">Контакты</th>
  </tr>
  <tr>
    <td>Email</td>
    <td>hello@example.com</td>
  </tr>
</table>
```

`colspan="2"` означает: ячейка занимает ширину двух столбцов.

## Где можно использовать

`colspan` применяют к `td` и `th`.

```html
<td colspan="3">Итого</td>
<th colspan="2">Период</th>
```

## Пример с итогом

```html
<table>
  <tr>
    <th>Товар</th>
    <th>Количество</th>
    <th>Цена</th>
  </tr>
  <tr>
    <td>Книга</td>
    <td>2</td>
    <td>1200 ₽</td>
  </tr>
  <tr>
    <td colspan="2">Итого</td>
    <td>1200 ₽</td>
  </tr>
</table>
```

Первая ячейка последней строки занимает два столбца.

## Важный нюанс

После объединения нужно следить за общим количеством столбцов в строке. Если структура не совпадает, таблица может стать трудной для чтения и поддержки.

## Мини-шпаргалка

- `colspan` объединяет столбцы.
- Значение показывает, сколько столбцов занимает ячейка.
- Работает на `td` и `th`.
- Часто используется для заголовков групп и итогов.
- Сложные объединения могут ухудшать доступность таблицы.
