# Чем жизненный цикл классового компонента отличается от функционального?

> [!summary]
> В классовых компонентах lifecycle описывается специальными методами: `componentDidMount`, `componentDidUpdate`, `componentWillUnmount`. В функциональных компонентах lifecycle обычно выражается через `useEffect`, `useLayoutEffect`, state, refs и cleanup.

## Классовый подход

```jsx
class ChatRoom extends Component {
  componentDidMount() {
    this.connection = createConnection(this.props.roomId)
    this.connection.connect()
  }

  componentDidUpdate(prevProps) {
    if (prevProps.roomId !== this.props.roomId) {
      this.connection.disconnect()
      this.connection = createConnection(this.props.roomId)
      this.connection.connect()
    }
  }

  componentWillUnmount() {
    this.connection.disconnect()
  }

  render() {
    return <h1>Комната {this.props.roomId}</h1>
  }
}
```

Логика одной подписки разбросана по трем методам.

## Функциональный подход

```jsx
function ChatRoom({ roomId }) {
  useEffect(() => {
    const connection = createConnection(roomId)
    connection.connect()

    return () => connection.disconnect()
  }, [roomId])

  return <h1>Комната {roomId}</h1>
}
```

Логика подключения и отключения находится рядом.

## Как сопоставить?

| Class lifecycle | Function component |
|---|---|
| `componentDidMount` | `useEffect(..., [])` или effect с dependencies |
| `componentDidUpdate` | `useEffect(..., [deps])` |
| `componentWillUnmount` | cleanup function |
| `shouldComponentUpdate` | `memo`, `useMemo`, архитектура props |
| `componentDidCatch` | Error Boundary |

Это не всегда точная замена один к одному, но помогает читать legacy-код.

## Важный нюанс

`useEffect` не является прямым "componentDidMount + componentDidUpdate + componentWillUnmount" для всего компонента. Лучше думать так:

```text
Каждый effect описывает отдельную синхронизацию с внешней системой.
```

## Мини-шпаргалка

- В классах lifecycle - методы класса.
- В функциях lifecycle выражается через hooks.
- Cleanup в effect похож на `componentWillUnmount`.
- `useEffect` лучше мыслить как синхронизацию, а не как lifecycle-method.
- Legacy-классы нужно уметь читать на собеседовании.
