# Какие файлы обычно находятся в корне Next.js проекта?

> [!summary]
> В корне Next.js проекта обычно лежат конфиги, package-файлы, TypeScript-настройки, ESLint, PostCSS/Tailwind, `next.config.ts`, папки `app` или `src/app`, `public` и документация проекта.

## Типичная структура

```text
my-next-app/
  app/
  public/
  next.config.ts
  package.json
  tsconfig.json
  eslint.config.mjs
  postcss.config.mjs
  next-env.d.ts
  README.md
```

Если используется `src`:

```text
my-next-app/
  src/
    app/
    shared/
    features/
  public/
  next.config.ts
```

## package.json

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "next lint"
  }
}
```

Главные scripts:

- `dev` - разработка;
- `build` - production build;
- `start` - запуск production server после build.

## next.config.ts

```ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'images.example.com',
      },
    ],
  },
}

export default nextConfig
```

Здесь настраивают images, redirects, headers, rewrites, experimental options и другое.

## next-env.d.ts

Этот файл генерируется Next.js и помогает TypeScript понимать типы Next.js. Обычно его не редактируют вручную.

## public

```text
public/
  favicon.ico
  logo.svg
  robots.txt
```

Файлы из `public` доступны от корня сайта.

## Что отвечать на собеседовании?

В корне Next.js проекта находятся конфиги и служебные файлы: `package.json`, `next.config.ts`, `tsconfig.json`, ESLint/PostCSS config, `next-env.d.ts`, `public` и папка приложения `app` или `src/app`. Бизнес-код можно держать в `src`.

## Частые ошибки

- Редактировать `next-env.d.ts` руками.
- Хранить секреты в публичных env-переменных.
- Путать `next start` и `next dev`.
- Класть исходники в корень без структуры.
- Забывать настроить external domains для `next/image`.

## Мини-шпаргалка

- `next.config.ts` - конфигурация Next.js.
- `package.json` - scripts и зависимости.
- `tsconfig.json` - TypeScript.
- `public` - статические файлы.
- `next-env.d.ts` - генерируется Next.js.
- `src` - опциональная папка исходников.
