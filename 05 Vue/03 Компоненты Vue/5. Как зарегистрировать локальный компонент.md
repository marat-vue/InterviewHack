# Как зарегистрировать локальный компонент

> [!summary] Коротко
> Локальный компонент подключают только в том компоненте, где он нужен. В `<script setup>` достаточно импортировать `.vue` файл.

## Вопрос

Как зарегистрировать локальный компонент?

## В Composition API через script setup

```vue
<script setup>
import UserCard from "./UserCard.vue";
</script>

<template>
  <UserCard />
</template>
```

Импортированный компонент автоматически доступен в template.

## В Options API

```vue
<script>
import UserCard from "./UserCard.vue";

export default {
  components: {
    UserCard,
  },
};
</script>

<template>
  <UserCard />
</template>
```

Здесь компонент нужно явно добавить в опцию `components`.

## Почему локальная регистрация хороша

Зависимости компонента видны прямо в файле. Это облегчает чтение, рефакторинг и удаление неиспользуемого кода.

## Когда использовать

Почти всегда по умолчанию. Глобальную регистрацию стоит оставлять для действительно общих базовых компонентов.

## Мини-шпаргалка

- В `<script setup>` достаточно `import`.
- В Options API нужна опция `components`.
- Локальная регистрация делает зависимости явными.
- Это предпочтительный вариант для большинства компонентов.
