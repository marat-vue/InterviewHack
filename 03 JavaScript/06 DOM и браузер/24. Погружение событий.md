# Погружение событий

> [!summary] Коротко
> Погружение - фаза события, на которой событие идет сверху вниз: от `window` и `document` к целевому элементу.

## Вопрос

Что такое capturing в DOM-событиях?

## Определение

DOM-событие проходит несколько фаз:

1. Capturing - погружение от верхних узлов к цели.
2. Target - событие дошло до целевого элемента.
3. Bubbling - всплытие от цели к родителям.

По умолчанию обработчики через `addEventListener()` чаще слушают фазу всплытия. Чтобы слушать фазу погружения, нужно включить `capture`.

## Пример

```javascript
parent.addEventListener(
  'click',
  () => {
    console.log('capture parent');
  },
  { capture: true }
);
```

Так обработчик родителя сработает на фазе погружения, до обработчика цели.

## Порядок фаз

```text
window -> document -> parent -> target -> parent -> document -> window
```

Первая часть - погружение, вторая - всплытие.

## Когда использовать

- редко, когда нужно перехватить событие до дочерних элементов;
- для сложной инфраструктуры событий;
- для аналитики или глобальных обработчиков с особым порядком.

В обычном UI-коде чаще достаточно всплытия.

## Мини-шпаргалка

```javascript
element.addEventListener('click', handler, { capture: true });
```
