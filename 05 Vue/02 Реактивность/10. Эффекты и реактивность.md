# Эффекты и реактивность

> [!summary] Коротко
> Эффект - функция, которая зависит от реактивных данных и должна запускаться снова при их изменении. Рендер компонента, `computed` и `watch` опираются на эту идею.

## Вопрос

Что такое эффекты в системе реактивности Vue?

## Простая модель

```text
reactive value changes -> dependent effect runs again
```

Во Vue эффект читает реактивные значения. Vue запоминает эти чтения и повторно запускает эффект при записи.

## Пример через watchEffect

```typescript
import { ref, watchEffect } from "vue";

const count = ref(0);

watchEffect(() => {
  console.log("count:", count.value);
});

count.value++;
```

`watchEffect` сам собирает зависимости: он видит, что внутри читается `count.value`.

## Рендер компонента как эффект

Шаблон компонента тоже можно представить как эффект. Он читает реактивные данные, а Vue перерисовывает компонент при их изменении.

```vue
<template>
  <p>{{ count }}</p>
</template>
```

## computed как ленивый эффект

`computed` пересчитывается только когда изменились зависимости и кто-то запросил его значение.

```typescript
const doubled = computed(() => count.value * 2);
```

## Мини-шпаргалка

- Эффект зависит от реактивных данных.
- При чтении Vue делает `track`.
- При записи Vue делает `trigger`.
- Render, `computed`, `watch`, `watchEffect` используют эту модель.
