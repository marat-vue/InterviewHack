# Что такое JOIN?

> [!NOTE]
> `JOIN` соединяет строки из нескольких таблиц по условию. Он нужен, когда данные нормализованы и разные части сущности хранятся в разных таблицах.

## Пример

```sql
SELECT
  users.email,
  orders.total
FROM users
JOIN orders ON orders.user_id = users.id;
```

Запрос берет пользователей и их заказы.

## Почему нужен ON?

`ON` описывает, как строки из таблиц связаны.

```sql
ON orders.user_id = users.id
```

Если забыть условие соединения, можно получить декартово произведение: каждая строка одной таблицы соединится с каждой строкой другой.

## JOIN и нормализация

В реляционной модели данные часто разбивают:

- пользователи в `users`;
- заказы в `orders`;
- товары в `products`;
- позиции заказа в `order_items`.

`JOIN` собирает нужную картину обратно.

## Мини-шпаргалка

- `JOIN` соединяет таблицы.
- `ON` задает условие связи.
- Чаще всего соединяют FK с PK.
- Неправильный join может создать дубли.
- Понимание связей важнее заучивания синтаксиса.
