# Как работают DISTINCT и удаление дублей?

> [!summary]
> `DISTINCT` удаляет повторяющиеся строки из результата запроса. Он сравнивает весь выбранный набор выражений, а не только одну колонку, если выбрано несколько столбцов.

## Простой DISTINCT

```sql
SELECT DISTINCT status
FROM orders;
```

Вернет уникальные статусы заказов.

## DISTINCT по нескольким колонкам

```sql
SELECT DISTINCT user_id, status
FROM orders;
```

Уникальность считается по паре `(user_id, status)`.

## DISTINCT не лечит плохой JOIN

Иногда `DISTINCT` добавляют, чтобы скрыть дубли после неправильного join.

```sql
SELECT DISTINCT u.id, u.email
FROM users u
JOIN orders o ON o.user_id = u.id;
```

Такой запрос может быть нормальным, если нужны пользователи с заказами. Но если дубли появились неожиданно, сначала нужно проверить связи и условие join.

## DISTINCT vs GROUP BY

```sql
SELECT DISTINCT status
FROM orders;
```

часто эквивалентно:

```sql
SELECT status
FROM orders
GROUP BY status;
```

Но `GROUP BY` нужен, когда есть агрегации.

## Мини-шпаргалка

- `DISTINCT` убирает дубли из результата.
- При нескольких колонках сравнивается вся строка результата.
- Не используй `DISTINCT` как маскировку неправильного join.
- Для агрегатов нужен `GROUP BY`.
- `DISTINCT` может требовать сортировки или hash-операции.
