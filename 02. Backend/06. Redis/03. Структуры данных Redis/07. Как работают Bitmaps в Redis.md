# Как работают Bitmaps в Redis?

> [!NOTE]
> Bitmap - это не отдельный тип, а операции над string как над последовательностью битов. Bitmaps полезны для компактного хранения булевых признаков по индексам: daily active users, flags, attendance, feature toggles.

## Когда использовать Bitmap?

Bitmap подходит, если:

- есть numeric id или индекс;
- нужно хранить true/false;
- нужно считать количество true;
- данных очень много;
- нужна компактность.

Пример:

```txt
active:2026-08-06 bit 123 = user 123 был активен
```

## Основные команды

```redis
SETBIT active:2026-08-06 123 1
GETBIT active:2026-08-06 123
BITCOUNT active:2026-08-06
```

`SETBIT` выставляет бит по offset.

## Daily active users

```redis
SETBIT dau:2026-08-06 1001 1
SETBIT dau:2026-08-06 1002 1
BITCOUNT dau:2026-08-06
```

Ответ `BITCOUNT` - количество активных пользователей, если offset соответствует user id.

## Операции между днями

Пользователи, активные в оба дня:

```redis
BITOP AND dau:both dau:2026-08-05 dau:2026-08-06
BITCOUNT dau:both
```

Пользователи, активные хотя бы в один день:

```redis
BITOP OR dau:any dau:2026-08-05 dau:2026-08-06
BITCOUNT dau:any
```

## Ограничения

Bitmaps неудобны, если:

- id не numeric;
- id очень разреженные и огромные;
- нужно хранить дополнительные данные;
- нужно перечислять пользователей часто;
- есть privacy/security требования к user id mapping.

## Мини-шпаргалка

- Bitmap хранится как string.
- `SETBIT` - выставить boolean flag.
- `GETBIT` - прочитать flag.
- `BITCOUNT` - посчитать включенные биты.
- `BITOP` - объединять/пересекать bitmaps.
- Хорошо для компактной аналитики boolean events.
