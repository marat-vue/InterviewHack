# Что делает useMemo()?

> [!summary]
> `useMemo` кэширует результат вычисления между рендерами. Он помогает не пересчитывать дорогие значения и сохранять стабильные ссылки на объекты/массивы, когда это нужно для оптимизации дочерних компонентов.

## Базовый синтаксис

```jsx
const value = useMemo(() => {
  return expensiveCalculation(input)
}, [input])
```

React выполнит функцию при первом render, сохранит результат и будет возвращать его снова, пока зависимости не изменятся.

## Пример с дорогим вычислением

```jsx
function ProductTable({ products, query }) {
  const visibleProducts = useMemo(() => {
    return products
      .filter((product) => product.title.includes(query))
      .sort((a, b) => a.price - b.price)
  }, [products, query])

  return <Table rows={visibleProducts} />
}
```

Без `useMemo` фильтрация и сортировка выполнялись бы при каждом render компонента, даже если изменился unrelated state вроде открытой модалки.

## Второй сценарий: стабильная ссылка

`React.memo` сравнивает props поверхностно. Новый массив или объект всегда считается новым значением.

```jsx
const Chart = memo(function Chart({ options }) {
  return <ExpensiveChart options={options} />
})

function Dashboard({ theme }) {
  const options = useMemo(() => {
    return {
      theme,
      animation: false,
    }
  }, [theme])

  return <Chart options={options} />
}
```

Если написать объект прямо в JSX, `Chart` будет получать новую ссылку при каждом render:

```jsx
<Chart options={{ theme, animation: false }} />
```

## Что useMemo не делает?

`useMemo` не гарантирует вечное хранение значения и не должен использоваться как механизм бизнес-логики.

Плохо:

```jsx
const user = useMemo(() => createUserOnce(), [])
```

Если нужно хранить состояние - используй `useState` или `useRef`. `useMemo` нужен для оптимизации вычислений, а не для хранения важных данных.

## Когда useMemo вреден?

Он добавляет собственную работу: React должен хранить значение и сравнивать зависимости через `Object.is`.

Не нужно:

```jsx
const fullName = useMemo(() => `${firstName} ${lastName}`, [firstName, lastName])
```

Проще:

```jsx
const fullName = `${firstName} ${lastName}`
```

## Типичные кейсы

- фильтрация больших списков;
- сортировка;
- группировка данных;
- подготовка данных для графика;
- создание стабильного объекта props;
- создание стабильного массива props;
- вычисление derived data, которое реально заметно в profiler.

## Мини-шпаргалка

- `useMemo` кэширует значение.
- Зависимости должны описывать все значения из render scope, которые используются внутри.
- Для простых вычислений он часто лишний.
- Для стабильных объектов полезен вместе с `memo`.
- Не используй `useMemo` как замену state.
