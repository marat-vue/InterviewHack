# Что значит "responsive accessibility"?

> [!NOTE]
> **Responsive accessibility** - это доступность интерфейса на разных размерах экрана, устройствах, ориентациях и способах ввода. Адаптивная верстка должна оставаться не только красивой, но и удобной для клавиатуры, скринридеров, touch-управления и масштабирования.

## Главное

Responsive accessibility находится на пересечении адаптивной верстки и доступности.

```text
responsive design
  -> layout adapts to screen

accessibility
  -> interface remains usable for different users

responsive accessibility
  -> adapted layout remains accessible
```

Недостаточно просто перестроить колонки в одну. Нужно проверить, что пользователь по-прежнему может прочитать контент, попасть в нужные элементы, понять порядок страницы и выполнить действие.

## Что может сломаться на мобильных

- Меню становится недоступным с клавиатуры.
- Порядок визуальных блоков отличается от DOM-порядка.
- Кнопки слишком маленькие для touch.
- Фокус уходит в скрытый элемент.
- Текст не масштабируется или обрезается.
- Горизонтальный скролл мешает чтению.
- Модальное окно не помещается на экран.

## DOM-порядок и визуальный порядок

CSS может визуально переставить блоки, но скринридер и клавиатура часто идут по DOM-порядку.

```html
<main>
  <section class="content">Контент</section>
  <aside class="sidebar">Фильтры</aside>
</main>
```

Если на мобильном фильтры визуально оказываются сверху, нужно убедиться, что порядок фокуса и чтения остается логичным.

## Размер touch-целей

Интерактивные элементы должны быть достаточно крупными и не располагаться слишком близко друг к другу.

```css
.icon-button {
  min-width: 44px;
  min-height: 44px;
}
```

Это помогает людям с моторными ограничениями и всем пользователям на телефоне.

## Масштабирование

Не стоит запрещать zoom через viewport.

```html
<!-- плохо для доступности -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
```

Пользователь должен иметь возможность увеличить страницу.

## Мини-шпаргалка

- Responsive accessibility = адаптивность + доступность.
- Проверяй не только layout, но и фокус, чтение, touch и масштабирование.
- DOM-порядок должен оставаться логичным.
- Touch-цели должны быть достаточно крупными.
- Нельзя ломать zoom без серьезной причины.
- Мобильное меню должно работать с клавиатуры и скринридером.
