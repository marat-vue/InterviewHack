# Что такое блокировки?

> [!summary]
> Блокировки защищают данные от конфликтующих параллельных операций. Они могут быть на уровне строк, таблиц или других объектов и помогают сохранять целостность при конкурентном доступе.

## Зачем нужны lock-и?

Если две транзакции одновременно меняют одну строку, база должна определить безопасный порядок.

```sql
UPDATE accounts
SET balance = balance - 100
WHERE id = 1;
```

Такая операция обычно берет блокировку на изменяемую строку.

## SELECT FOR UPDATE

```sql
BEGIN;

SELECT *
FROM accounts
WHERE id = 1
FOR UPDATE;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

COMMIT;
```

`FOR UPDATE` явно блокирует выбранные строки для последующего изменения.

## Проблемы

- долгие транзакции держат locks;
- locks могут задерживать другие запросы;
- разные порядки блокировок могут приводить к deadlock.

## Мини-шпаргалка

- Lock защищает данные при параллельных изменениях.
- `UPDATE` обычно блокирует изменяемые строки.
- `SELECT FOR UPDATE` явно берет row lock.
- Долгие транзакции опасны.
- Locks нужно анализировать при проблемах latency.
