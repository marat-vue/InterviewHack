# Как debug-ить e2e через trace, screenshots и video?

> [!summary]
> Playwright дает инструменты для отладки e2e: UI mode, headed mode, trace viewer, screenshots, video, debug mode и HTML report. Они помогают понять, на каком шаге тест упал и что видел браузер.

## UI mode

```bash
npx playwright test --ui
```

UI mode позволяет запускать отдельные тесты, смотреть шаги и быстрее разбираться с падениями.

## Headed mode

```bash
npx playwright test --headed
```

Тест запускается в видимом браузере. Это удобно, если хочешь глазами увидеть сценарий.

## Trace

В конфиге:

```ts
use: {
  trace: 'on-first-retry',
}
```

Trace показывает:

- actions;
- snapshots страницы;
- network;
- console;
- DOM;
- screenshots по шагам.

Открыть trace:

```bash
npx playwright show-trace trace.zip
```

## Screenshots и video

```ts
use: {
  screenshot: 'only-on-failure',
  video: 'retain-on-failure',
}
```

В CI это помогает понять проблему без локального воспроизведения.

## Мини-шпаргалка

- `--ui` - удобная интерактивная отладка.
- `--headed` - видимый браузер.
- Trace показывает историю теста.
- Screenshots/video полезны в CI.
- HTML report помогает смотреть результаты набора.
