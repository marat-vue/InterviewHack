# Что такое Slot во Vue.js?

> [!NOTE]
> Slot - место в дочернем компоненте, куда родитель может передать свой шаблон. Это способ сделать компонент гибким без жесткой привязки к конкретному контенту.

## Вопрос

Что такое `Slot` во Vue.js?

## Базовый пример

```vue
<!-- Card.vue -->
<template>
  <section class="card">
    <slot />
  </section>
</template>
```

```vue
<!-- Parent.vue -->
<template>
  <Card>
    <h2>Профиль</h2>
    <p>Информация о пользователе</p>
  </Card>
</template>
```

Контент между `<Card>` и `</Card>` попадет на место `<slot />`.

## Fallback-контент

Если родитель ничего не передал, можно показать значение по умолчанию.

```vue
<template>
  <button>
    <slot>Сохранить</slot>
  </button>
</template>
```

## Именованные слоты

```vue
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
</template>
```

```vue
<template>
  <Layout>
    <template #header>Заголовок</template>
    Контент страницы
  </Layout>
</template>
```

## Когда использовать

Слоты полезны для карточек, модальных окон, layout-компонентов, таблиц и wrapper-компонентов, где структура общая, а содержимое разное.

## Мини-шпаргалка

- Slot передает шаблон от родителя ребенку.
- `<slot />` - место вставки контента.
- Fallback показывается, если контент не передали.
- Именованные слоты разделяют зоны компонента.
