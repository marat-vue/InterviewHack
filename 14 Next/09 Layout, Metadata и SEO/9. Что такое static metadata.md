# Что такое static metadata?

> [!summary]
> Static metadata - это метаданные страницы или layout, которые описываются обычным экспортом `metadata`. Они подходят для страниц, где `title`, `description`, Open Graph и robots-правила известны заранее и не зависят от `params`, базы данных или API.

## Как задается static metadata?

В App Router статические метаданные задаются через экспорт `metadata` из `layout.tsx` или `page.tsx`:

```tsx
// app/about/page.tsx
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: 'О проекте',
  description: 'Кто мы, что делаем и зачем существует проект',
  openGraph: {
    title: 'О проекте',
    description: 'Короткое описание для соцсетей',
    url: 'https://example.com/about',
    images: ['/og/about.png'],
  },
}

export default function AboutPage() {
  return <main>О проекте</main>
}
```

Next.js сам превратит этот объект в теги внутри `<head>`.

## Когда использовать static metadata?

Static metadata подходят для страниц, где SEO-данные не нужно получать из внешнего источника:

- главная страница;
- о компании;
- контакты;
- цены;
- документация с фиксированными страницами;
- страница логина;
- лендинг;
- раздел, у которого общий SEO-шаблон задан в layout.

Например:

```tsx
// app/pricing/page.tsx
export const metadata = {
  title: 'Тарифы',
  description: 'Выберите подходящий тариф для команды',
}
```

## Что можно описать?

Чаще всего в `metadata` используют:

```tsx
export const metadata = {
  title: 'Название страницы',
  description: 'Описание страницы',
  keywords: ['Next.js', 'React', 'SEO'],
  alternates: {
    canonical: 'https://example.com/page',
  },
  openGraph: {
    title: 'Название для соцсетей',
    description: 'Описание для соцсетей',
    images: ['/og.png'],
  },
  twitter: {
    card: 'summary_large_image',
    title: 'Название для Twitter/X',
    images: ['/og.png'],
  },
  robots: {
    index: true,
    follow: true,
  },
}
```

## Static metadata в layout

В layout часто задают общий шаблон:

```tsx
// app/layout.tsx
export const metadata = {
  title: {
    template: '%s | Frontend Notes',
    default: 'Frontend Notes',
  },
  description: 'База знаний по frontend-разработке',
}
```

А страницы уточняют конкретный заголовок:

```tsx
// app/next/page.tsx
export const metadata = {
  title: 'Next.js',
  description: 'Вопросы и ответы по Next.js',
}
```

Итог:

```html
<title>Next.js | Frontend Notes</title>
```

## Чем static metadata отличается от dynamic metadata?

| Критерий | Static metadata | Dynamic metadata |
| --- | --- | --- |
| API | `export const metadata` | `export async function generateMetadata` |
| Данные | Заданы прямо в коде | Получаются из `params`, API, CMS, базы |
| Подходит для | Статичных страниц | Статей, товаров, профилей |
| Сложность | Минимальная | Нужно учитывать загрузку данных |
| Риск ошибок | Низкий | Выше: 404, кеш, задержки, fallback |

## Важные правила

- `metadata` работает только в Server Components.
- Нельзя экспортировать `metadata` из Client Component.
- Для одной страницы не стоит одновременно использовать `metadata` и `generateMetadata`.
- Static metadata не подходят, если title зависит от `slug`, id товара или данных из CMS.
- Для App Router обычно не нужен `next/head`.

## Что отвечать на собеседовании?

Static metadata - это статический объект `metadata`, который экспортируется из `page.tsx` или `layout.tsx` в App Router. Он используется для заранее известных SEO-данных: `title`, `description`, Open Graph, Twitter, robots и canonical. Для динамических страниц вместо него используют `generateMetadata`.

## Частые ошибки

- Делать одинаковый `title` на всех страницах.
- Писать слишком общий `description`.
- Использовать static metadata для страниц товаров или статей, где данные должны быть уникальными.
- Экспортировать `metadata` из компонента с `'use client'`.
- Забывать про `title.default`, если в layout используется `title.template`.
- Дублировать ручные `<meta>` вместо Metadata API.

## Мини-шпаргалка

- `metadata` - статический объект.
- Подходит для `/about`, `/contacts`, `/pricing`.
- Работает в `layout.tsx` и `page.tsx`.
- Может задавать `title`, `description`, `openGraph`, `twitter`, `robots`.
- Для динамических данных нужен `generateMetadata`.
- В App Router это основной способ описывать `<head>`.
