# Какие типы селекторов существуют в CSS?

> [!NOTE]
> В CSS есть селекторы по тегу, классу, id, атрибуту, псевдоклассу, псевдоэлементу, комбинации элементов и универсальный селектор.

## Основные типы

| Тип | Пример | Что выбирает |
| --- | --- | --- |
| Универсальный | `*` | Все элементы |
| По тегу | `button` | Все кнопки |
| По классу | `.button` | Элементы с классом |
| По id | `#app` | Элемент с конкретным id |
| По атрибуту | `[disabled]` | Элементы с атрибутом |
| Псевдокласс | `:hover` | Состояние или условие |
| Псевдоэлемент | `::before` | Виртуальная часть элемента |

## Комбинаторы

Комбинаторы описывают отношения между элементами.

```css
.card p {
  color: #374151;
}

.tabs > button {
  flex: 1;
}

h2 + p {
  margin-top: 0;
}
```

| Комбинатор | Смысл |
| --- | --- |
| `A B` | Потомок |
| `A > B` | Прямой ребенок |
| `A + B` | Следующий сосед |
| `A ~ B` | Все следующие соседи |

## Атрибутные селекторы

```css
input[type="email"] {
  border-color: #2563eb;
}

a[href^="https://"] {
  text-decoration-style: dotted;
}
```

Можно выбирать элементы по наличию или значению атрибутов.

## Группировка

```css
h1,
h2,
h3 {
  line-height: 1.2;
}
```

Одинаковые объявления можно применить сразу к нескольким селекторам.

## Мини-шпаргалка

- `*` выбирает все элементы.
- `.class` - самый частый селектор для UI.
- `#id` имеет высокую специфичность.
- `[attr]` выбирает по атрибуту.
- `:hover` и `:focus-visible` - псевдоклассы.
- `::before` и `::after` - псевдоэлементы.
- Комбинаторы описывают отношения в DOM.
