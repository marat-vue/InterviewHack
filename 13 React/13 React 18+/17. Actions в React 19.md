# Actions в React 19

> [!summary]
> Actions в React 19 - это модель для асинхронных мутаций: отправки форм, сохранения данных, обновления профиля, добавления комментариев. React умеет связывать action с pending-состоянием, optimistic UI, формами, transitions и Server Functions во фреймворках.

## Что такое Action?

Action - это функция, которая выполняет мутацию данных.

Например:

```jsx
async function updateName(formData) {
  const name = formData.get('name')
  await api.updateProfile({ name })
}
```

В React 19 такую функцию можно передавать в `<form action={...}>`:

```jsx
function ProfileForm() {
  return (
    <form action={updateName}>
      <input name="name" />
      <button type="submit">Save</button>
    </form>
  )
}
```

React понимает, что форма запускает асинхронное действие.

## Зачем Actions нужны?

До Actions разработчик часто писал много ручного кода:

```jsx
const [isPending, setIsPending] = useState(false)
const [error, setError] = useState(null)

async function handleSubmit(event) {
  event.preventDefault()
  setIsPending(true)
  setError(null)

  try {
    const formData = new FormData(event.currentTarget)
    await updateName(formData)
  } catch (error) {
    setError(error)
  } finally {
    setIsPending(false)
  }
}
```

Actions не убирают необходимость думать об ошибках и UX, но дают React стандартную модель для отправки, pending-состояния и интеграции с формами.

## useActionState

`useActionState` помогает хранить результат action:

```jsx
import { useActionState } from 'react'

async function updateName(previousState, formData) {
  const name = formData.get('name')

  if (!name) {
    return { error: 'Name is required' }
  }

  await api.updateProfile({ name })

  return { message: 'Profile updated' }
}

function ProfileForm() {
  const [state, formAction, isPending] = useActionState(updateName, {
    message: null,
    error: null,
  })

  return (
    <form action={formAction}>
      <input name="name" disabled={isPending} />
      <button disabled={isPending}>
        {isPending ? 'Saving...' : 'Save'}
      </button>

      {state.error && <p>{state.error}</p>}
      {state.message && <p>{state.message}</p>}
    </form>
  )
}
```

`useActionState` возвращает:

| Значение | Что означает |
|---|---|
| `state` | последнее состояние, возвращенное action |
| `formAction` | функция, которую передают в `form action` |
| `isPending` | выполняется ли action сейчас |

## useFormStatus

`useFormStatus` нужен дочерним компонентам формы:

```jsx
import { useFormStatus } from 'react-dom'

function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button disabled={pending}>
      {pending ? 'Saving...' : 'Save'}
    </button>
  )
}
```

Он особенно удобен для переиспользуемых submit-кнопок.

## useOptimistic

Actions хорошо сочетаются с optimistic UI:

```jsx
import { useOptimistic } from 'react'

function Comments({ comments, addComment }) {
  const [optimisticComments, addOptimisticComment] = useOptimistic(
    comments,
    (currentComments, text) => [
      ...currentComments,
      { id: crypto.randomUUID(), text, sending: true },
    ],
  )

  async function formAction(formData) {
    const text = formData.get('text')
    addOptimisticComment(text)
    await addComment(text)
  }

  return (
    <form action={formAction}>
      {optimisticComments.map((comment) => (
        <p key={comment.id}>{comment.text}</p>
      ))}
      <input name="text" />
      <button>Send</button>
    </form>
  )
}
```

Пользователь видит комментарий сразу, пока серверная операция еще выполняется.

## Client Actions и Server Functions

Action может быть клиентской функцией:

```jsx
async function saveOnClient(formData) {
  await fetch('/api/profile', {
    method: 'POST',
    body: formData,
  })
}
```

Во фреймворках с RSC action может быть Server Function:

```jsx
'use server'

export async function updateProfile(formData) {
  const name = formData.get('name')
  await db.user.update({ data: { name } })
}
```

Такую функцию можно использовать из формы при поддержке фреймворка.

## Что отвечать на собеседовании?

Actions - это React 19 модель для асинхронных мутаций. Они позволяют передавать функцию в `form action`, получать pending-состояние через `useActionState` или `useFormStatus`, строить optimistic UI через `useOptimistic` и интегрироваться с Server Functions во фреймворках.

## Частые ошибки

- Думать, что Actions заменяют всю работу с API.
- Путать `useActionState` и `useFormStatus`.
- Не обрабатывать ошибки в action.
- Использовать optimistic UI для критичных операций вроде оплаты без строгого подтверждения.
- Думать, что Server Functions работают без RSC/framework-интеграции.

## Мини-шпаргалка

- Action - функция для мутации данных.
- `<form action={action}>` может запускать action.
- `useActionState` хранит результат action.
- `useFormStatus` читает статус родительской формы.
- `useOptimistic` показывает быстрый optimistic UI.
- Server Functions требуют поддержку фреймворка.
