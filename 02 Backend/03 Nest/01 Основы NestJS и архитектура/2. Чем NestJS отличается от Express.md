# Чем NestJS отличается от Express?

> [!summary]
> Express - минималистичный HTTP-фреймворк, а NestJS - полноценный application framework с архитектурой, dependency injection, модулями, decorators, validation, guards, interceptors и testing utilities.

## Express

```ts
app.get('/users', async (req, res) => {
  const users = await usersService.findAll();
  res.json(users);
});
```

Express дает route handlers и middleware, но структуру приложения разработчик выбирает сам.

## NestJS

```ts
@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  findAll() {
    return this.usersService.findAll();
  }
}
```

NestJS сразу предлагает архитектурные правила.

## Сравнение

| Критерий | Express | NestJS |
|---|---|---|
| Архитектура | свободная | модульная |
| DI | вручную или библиотека | встроен |
| TypeScript | опционально | центральная часть |
| Validation | вручную | pipes + DTO |
| Масштабирование кода | зависит от команды | встроенные паттерны |

## Мини-шпаргалка

- Express проще и ниже уровнем.
- NestJS строже и структурнее.
- NestJS часто используют для крупных backend-приложений.
- NestJS может работать поверх Express.
- Понимание Express помогает понимать HTTP-слой NestJS.
