# Отмена отправки формы

> [!NOTE] Коротко
> Чтобы отменить стандартную отправку формы и перезагрузку страницы, вызови `event.preventDefault()` в обработчике `submit`.

## Вопрос

Как отменить стандартную отправку формы?

## Определение

По умолчанию форма при `submit` отправляет данные на сервер и может перезагрузить страницу. Если форма обрабатывается JavaScript-кодом, стандартное действие нужно отменить.

## Пример

```javascript
const form = document.querySelector('form');

form.addEventListener('submit', (event) => {
  event.preventDefault();

  console.log('Form submit canceled');
});
```

## Получение данных формы

```javascript
form.addEventListener('submit', (event) => {
  event.preventDefault();

  const formData = new FormData(form);
  const email = formData.get('email');

  console.log(email);
});
```

`FormData` удобно собирает значения полей формы.

## Асинхронная отправка

```javascript
form.addEventListener('submit', async (event) => {
  event.preventDefault();

  const formData = new FormData(form);

  await fetch('/api/login', {
    method: 'POST',
    body: formData,
  });
});
```

Так данные отправляются без полной перезагрузки страницы.

## Важный нюанс

`preventDefault()` нужно вызвать синхронно в начале обработчика, до ожидания `await`.

## Мини-шпаргалка

```javascript
form.addEventListener('submit', (event) => {
  event.preventDefault();
});
```
