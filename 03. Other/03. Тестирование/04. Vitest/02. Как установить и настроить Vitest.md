# Как установить и настроить Vitest?

> [!summary]
> Vitest устанавливают как dev dependency, добавляют npm script и при необходимости настраивают `test`-секцию в `vite.config.ts` или отдельный `vitest.config.ts`. Для тестов компонентов обычно добавляют DOM environment.

## Установка

```bash
npm install -D vitest
```

В `package.json`:

```json
{
  "scripts": {
    "test": "vitest",
    "test:run": "vitest run",
    "coverage": "vitest run --coverage"
  }
}
```

`vitest` запускает watch mode, а `vitest run` выполняет тесты один раз, что удобно для CI.

## Где хранить конфиг?

Vitest может читать `vite.config.ts`:

```ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: ['./src/test/setup.ts'],
  },
});
```

Можно вынести в `vitest.config.ts`, если тестовый конфиг сильно отличается:

```ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    environment: 'node',
  },
});
```

## DOM environment

Для Vue-компонентов нужен DOM-like environment:

```bash
npm install -D jsdom
```

```ts
test: {
  environment: 'jsdom',
}
```

## Setup file

`setup.ts` нужен для глобальной подготовки:

```ts
import { afterEach } from 'vitest';
import { cleanup } from '@testing-library/vue';

afterEach(() => {
  cleanup();
});
```

Для Vue Test Utils cleanup может быть не нужен так же, как в Testing Library, но setup-файл полезен для mocks, глобальных polyfills и общих настроек.

## Мини-шпаргалка

- Установка: `npm install -D vitest`.
- Watch: `vitest`.
- Один запуск: `vitest run`.
- Конфиг можно держать в `vite.config.ts` или `vitest.config.ts`.
- Для Vue UI-тестов часто нужен `environment: 'jsdom'`.
