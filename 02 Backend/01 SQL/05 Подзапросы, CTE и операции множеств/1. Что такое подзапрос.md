# Что такое подзапрос?

> [!summary]
> Подзапрос - это SQL-запрос внутри другого запроса. Он позволяет сначала получить промежуточный набор данных или значение, а затем использовать его во внешнем запросе.

## Подзапрос в WHERE

```sql
SELECT *
FROM users
WHERE id IN (
  SELECT user_id
  FROM orders
  WHERE status = 'paid'
);
```

Запрос возвращает пользователей, у которых есть оплаченные заказы.

## Подзапрос как значение

```sql
SELECT
  email,
  (SELECT COUNT(*) FROM orders WHERE orders.user_id = users.id) AS orders_count
FROM users;
```

Это correlated subquery: внутренний запрос зависит от строки внешнего запроса.

## Подзапрос в FROM

```sql
SELECT status, avg_total
FROM (
  SELECT status, AVG(total) AS avg_total
  FROM orders
  GROUP BY status
) AS stats;
```

Подзапрос в `FROM` должен иметь alias.

## Мини-шпаргалка

- Подзапрос - запрос внутри запроса.
- Может возвращать одно значение, список или таблицу.
- Correlated subquery зависит от внешней строки.
- Подзапрос в `FROM` требует alias.
- Часто CTE читается лучше, чем вложенный подзапрос.
