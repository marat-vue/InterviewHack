# Основные методы TanStack Query

> [!summary]
> В работе с TanStack Query чаще всего нужны `useQuery`, `useMutation`, `useQueryClient`, `invalidateQueries`, `setQueryData`, `prefetchQuery`, `ensureQueryData`, `cancelQueries`, `removeQueries` и `resetQueries`.

## Главные hooks

| Hook | Зачем нужен |
|---|---|
| `useQuery` | получить и кешировать данные |
| `useMutation` | выполнить POST/PUT/PATCH/DELETE |
| `useQueryClient` | получить доступ к `QueryClient` |
| `useInfiniteQuery` | бесконечная пагинация |
| `useSuspenseQuery` | Suspense-режим |

## useQuery

```tsx
const productsQuery = useQuery({
  queryKey: ['products', { categoryId, page }],
  queryFn: () => fetchProducts({ categoryId, page }),
})
```

Ключ должен включать параметры запроса. Если `categoryId` влияет на результат, он должен быть в `queryKey`.

## useMutation

```tsx
const createProductMutation = useMutation({
  mutationFn: createProduct,
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['products'] })
  },
})
```

Mutation не кешируется как query. Ее задача - выполнить изменение и обновить связанные queries.

## useQueryClient

```tsx
const queryClient = useQueryClient()
```

Через него доступны методы cache.

## invalidateQueries

```tsx
await queryClient.invalidateQueries({
  queryKey: ['products'],
})
```

Данные помечаются как stale, активные queries могут refetch в фоне.

## setQueryData

```tsx
queryClient.setQueryData<Product[]>(
  ['products'],
  (oldProducts = []) => [newProduct, ...oldProducts],
)
```

`setQueryData` полезен, когда ответ mutation уже содержит новые данные и не хочется ждать refetch.

## getQueryData

```tsx
const cachedUser = queryClient.getQueryData<User>(['user', userId])
```

Метод читает данные из cache синхронно. Если данных нет, вернет `undefined`.

## prefetchQuery

```tsx
await queryClient.prefetchQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
})
```

Используется для предварительной загрузки, например при hover на ссылку.

## ensureQueryData

```tsx
const user = await queryClient.ensureQueryData({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
})
```

Если данные есть в cache, вернет их. Если нет - загрузит.

## cancelQueries

```tsx
await queryClient.cancelQueries({ queryKey: ['todos'] })
```

Часто используется перед optimistic update, чтобы фоновый refetch не перезаписал optimistic state.

## removeQueries и resetQueries

```tsx
queryClient.removeQueries({ queryKey: ['drafts'] })

queryClient.resetQueries({ queryKey: ['profile'] })
```

`removeQueries` удаляет queries из cache. `resetQueries` сбрасывает к начальному состоянию и уведомляет подписчиков.

## Что отвечать на собеседовании?

Нужно знать не только `useQuery`, но и cache API: `invalidateQueries` для устаревания данных, `setQueryData` для ручного обновления, `prefetchQuery` для предварительной загрузки, `cancelQueries` для optimistic updates и `removeQueries/resetQueries` для управления cache.

## Мини-шпаргалка

- `useQuery` читает данные.
- `useMutation` меняет данные.
- `invalidateQueries` запускает обновление связанных данных.
- `setQueryData` вручную меняет cache.
- `prefetchQuery` загружает заранее.
- `cancelQueries` важен для optimistic updates.
