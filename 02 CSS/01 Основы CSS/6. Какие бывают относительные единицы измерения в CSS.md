# Какие бывают относительные единицы измерения в CSS

> [!summary]
> **Относительные единицы CSS** рассчитываются относительно другого значения: размера шрифта, контейнера, viewport или размера символов. Они помогают делать интерфейсы гибкими и адаптивными.

## Частые относительные единицы

| Единица | Относительно чего считается |
| --- | --- |
| `%` | Родительского размера или контекста свойства |
| `em` | Размер шрифта текущего элемента |
| `rem` | Размер шрифта корневого элемента `html` |
| `vw` | 1% ширины viewport |
| `vh` | 1% высоты viewport |
| `vmin` | 1% меньшей стороны viewport |
| `vmax` | 1% большей стороны viewport |
| `ch` | Примерная ширина символа `0` |

## rem

```css
html {
  font-size: 16px;
}

.title {
  font-size: 2rem; /* 32px */
}
```

`rem` удобно использовать для типографики и отступов, потому что он связан с базовым размером шрифта документа.

## em

```css
.button {
  font-size: 16px;
  padding: 0.5em 1em;
}
```

Отступы будут зависеть от размера шрифта самой кнопки.

## Проценты

```css
.sidebar {
  width: 30%;
}
```

Проценты часто считаются от размера родителя, но точный контекст зависит от свойства.

## Viewport units

```css
.hero {
  min-height: 100vh;
}
```

Viewport-единицы полезны для секций, зависящих от размера окна.

## Мини-шпаргалка

- `rem` зависит от `html`.
- `em` зависит от текущего размера шрифта.
- `%` зависит от контекста свойства.
- `vw` и `vh` зависят от viewport.
- `ch` удобен для ограничения ширины текста.
- Относительные единицы помогают адаптивности.
