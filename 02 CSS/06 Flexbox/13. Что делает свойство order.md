# Что делает свойство order

> [!summary]
> `order` меняет визуальный порядок flex items внутри flex-контейнера, не изменяя порядок элементов в HTML.

## Главное

```css
.item--first {
  order: -1;
}
```

Элемент с меньшим `order` визуально появится раньше.

## Значение по умолчанию

```css
.item {
  order: 0;
}
```

Все flex items по умолчанию имеют `order: 0` и отображаются в порядке DOM.

## Пример

```html
<div class="layout">
  <main class="content">Контент</main>
  <aside class="sidebar">Сайдбар</aside>
</div>
```

```css
.layout {
  display: flex;
}

.sidebar {
  order: -1;
}
```

Сайдбар визуально окажется перед контентом.

## Accessibility-нюанс

`order` меняет визуальный порядок, но не меняет DOM-порядок. Клавиатура и скринридеры могут идти по исходному HTML.

Если визуальный и логический порядок сильно расходятся, пользователю будет трудно ориентироваться.

## Мини-шпаргалка

- `order` меняет визуальный порядок flex items.
- Значение по умолчанию `0`.
- Меньшее значение идет раньше.
- DOM-порядок не меняется.
- Осторожно используй для важных сценариев навигации.
- Для логического порядка лучше менять HTML.
