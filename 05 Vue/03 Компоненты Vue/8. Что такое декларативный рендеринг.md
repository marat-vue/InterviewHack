# Что такое декларативный рендеринг

> [!summary] Коротко
> Декларативный рендеринг означает, что компонент описывает UI как результат состояния. Vue сам обновляет DOM, когда состояние меняется.

## Вопрос

Что такое декларативный рендеринг во Vue?

## Пример

```vue
<script setup>
import { ref } from "vue";

const message = ref("Привет");
</script>

<template>
  <h1>{{ message }}</h1>
</template>
```

Шаблон говорит: в `h1` должен отображаться `message`. Как именно обновить DOM, решает Vue.

## С условиями

```vue
<template>
  <p v-if="isLoading">Загрузка</p>
  <UserCard v-else :user="user" />
</template>
```

Компонент описывает возможные состояния интерфейса.

## Со списками

```vue
<template>
  <ul>
    <li v-for="todo in todos" :key="todo.id">
      {{ todo.title }}
    </li>
  </ul>
</template>
```

Разработчик описывает список, а Vue создает и обновляет элементы.

## Отличие от ручного DOM

Без Vue пришлось бы вручную создавать элементы, удалять их, менять текст и обработчики. В декларативном рендеринге источник правды - состояние.

## Мини-шпаргалка

- Декларативно = описать результат.
- State управляет отображением.
- Vue сам применяет изменения к DOM.
- `v-if`, `v-for`, `v-bind` - инструменты декларативного рендера.
