# В чем ключевая идея роутинга в Next.js?

> [!summary]
> Ключевая идея роутинга в Next.js - file-system routing: URL создается структурой файлов и папок. В App Router папки внутри `app` задают route segments, а специальные файлы вроде `page.tsx`, `layout.tsx` и `route.ts` определяют UI и поведение маршрута.

## Чем отличается от React Router?

В React Router routes часто описываются в коде:

```tsx
createBrowserRouter([
  { path: '/', element: <HomePage /> },
  { path: '/blog/:slug', element: <PostPage /> },
])
```

В Next.js route создается файловой структурой:

```text
app/
  page.tsx
  blog/
    [slug]/
      page.tsx
```

## Основные правила App Router

```text
app/page.tsx                  -> /
app/about/page.tsx            -> /about
app/blog/[slug]/page.tsx      -> /blog/:slug
app/dashboard/settings/page.tsx -> /dashboard/settings
```

`page.tsx` делает route публично доступным.

## Layout как часть роутинга

```text
app/
  dashboard/
    layout.tsx
    page.tsx
    settings/
      page.tsx
```

`dashboard/layout.tsx` применяется ко всем вложенным dashboard routes.

## Dynamic routes

```text
app/products/[id]/page.tsx
```

Компонент получает params:

```tsx
export default async function ProductPage({ params }: Props) {
  const { id } = await params
  return <h1>Product {id}</h1>
}
```

## Navigation

Для ссылок используют `next/link`:

```tsx
import Link from 'next/link'

export function Header() {
  return <Link href="/products">Products</Link>
}
```

Для программной навигации в Client Component используют `useRouter` из `next/navigation`.

## Что отвечать на собеседовании?

Next.js использует файловую маршрутизацию: папки и специальные файлы в `app` описывают URL, layout, loading, errors и endpoints. Это делает структуру проекта картой сайта. В App Router роутинг тесно связан с Server Components, layouts и data fetching.

## Частые ошибки

- Писать React Router config внутри Next.js без необходимости.
- Забывать, что папка без `page.tsx` не создает страницу.
- Путать `[slug]` и `(group)`.
- Использовать `next/router` в App Router вместо `next/navigation`.
- Делать navigation через обычный `<a>` для внутренних переходов.

## Мини-шпаргалка

- Next.js routing основан на файлах.
- `app/page.tsx` - `/`.
- `[id]` - dynamic segment.
- `(group)` - route group без URL.
- `layout.tsx` - общий UI для segment.
- `Link` - переход без полной перезагрузки.
