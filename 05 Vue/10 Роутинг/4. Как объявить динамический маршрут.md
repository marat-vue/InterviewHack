# Как объявить динамический маршрут

> [!summary] Коротко
> Динамический маршрут объявляют через параметр в пути: `/users/:id`. Значение параметра доступно в `route.params`.

## Вопрос

Как объявить динамический маршрут?

## Базовый пример

```typescript
const routes = [
  {
    path: "/users/:id",
    component: UserPage,
  },
];
```

Такой маршрут подойдет для `/users/1`, `/users/42`, `/users/admin`.

## Получение параметра

```vue
<script setup>
import { useRoute } from "vue-router";

const route = useRoute();
const userId = route.params.id;
</script>
```

`route.params.id` обычно имеет тип `string | string[]`.

## Через props

Часто удобнее передавать params в компонент как props.

```typescript
{
  path: "/users/:id",
  component: UserPage,
  props: true,
}
```

```vue
<script setup lang="ts">
defineProps<{ id: string }>();
</script>
```

## Несколько параметров

```typescript
{
  path: "/projects/:projectId/tasks/:taskId",
  component: TaskPage,
}
```

## Мини-шпаргалка

- Динамический сегмент пишется как `:id`.
- Params доступны в `route.params`.
- Params приходят как строки.
- `props: true` делает страницу проще тестировать.
