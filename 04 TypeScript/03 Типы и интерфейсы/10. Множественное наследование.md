# Множественное наследование

> [!summary] Коротко
> Интерфейс может наследоваться сразу от нескольких интерфейсов через `extends A, B`.

## Вопрос

Можно ли наследовать несколько интерфейсов?

## Короткий ответ

Да. TypeScript позволяет интерфейсу расширять несколько интерфейсов. Итоговый интерфейс объединяет их контракты.

## Пример

```typescript
interface WithId {
  id: number;
}

interface WithTimestamps {
  createdAt: Date;
  updatedAt: Date;
}

interface User extends WithId, WithTimestamps {
  name: string;
}
```

`User` должен иметь поля из всех трех интерфейсов.

## Использование

```typescript
const user: User = {
  id: 1,
  name: 'Ann',
  createdAt: new Date(),
  updatedAt: new Date(),
};
```

## Конфликты свойств

Если родительские интерфейсы объявляют одно и то же поле несовместимыми типами, TypeScript выдаст ошибку.

```typescript
interface A {
  id: number;
}

interface B {
  id: string;
}

interface C extends A, B {} // ошибка
```

## Альтернатива через type

```typescript
type User = WithId & WithTimestamps & {
  name: string;
};
```

Intersection делает похожую композицию для type aliases.

## Мини-шпаргалка

```typescript
interface C extends A, B {
  extra: string;
}
```
