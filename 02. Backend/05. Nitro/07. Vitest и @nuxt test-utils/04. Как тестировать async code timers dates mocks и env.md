# Как тестировать async code, timers, dates, mocks и env?

> [!NOTE]
> Backend Nitro часто зависит от async operations, времени, env-переменных и внешних клиентов. Vitest закрывает эти сценарии через `resolves/rejects`, fake timers, spies, module mocks и `vi.stubEnv`.

## Async success

```ts
it('loads user', async () => {
  await expect(userService.findById('1')).resolves.toMatchObject({
    id: '1',
  });
});
```

Или:

```ts
const user = await userService.findById('1');
expect(user.email).toBe('a@example.com');
```

## Async error

```ts
it('throws when user is missing', async () => {
  await expect(userService.findById('missing')).rejects.toThrow('User not found');
});
```

## Fake timers

```ts
import { afterEach, expect, it, vi } from 'vitest';

afterEach(() => {
  vi.useRealTimers();
});

it('expires token', () => {
  vi.useFakeTimers();
  vi.setSystemTime(new Date('2026-01-01T00:00:00Z'));

  const token = createToken({ ttlMs: 1000 });

  vi.advanceTimersByTime(1001);

  expect(isExpired(token)).toBe(true);
});
```

## Mock function

```ts
const sendEmail = vi.fn().mockResolvedValue(undefined);

await authService.requestPasswordReset({
  email: 'a@example.com',
  sendEmail,
});

expect(sendEmail).toHaveBeenCalledWith(
  expect.objectContaining({
    to: 'a@example.com',
  }),
);
```

## Spy

```ts
const spy = vi.spyOn(console, 'error').mockImplementation(() => {});

logError(new Error('boom'));

expect(spy).toHaveBeenCalled();

spy.mockRestore();
```

## Module mock

```ts
vi.mock('../server/utils/email', () => {
  return {
    emailService: {
      send: vi.fn().mockResolvedValue(undefined),
    },
  };
});
```

Module mocks лучше использовать, когда зависимость импортируется внутри тестируемого module.

## Env mock

```ts
import { afterEach, expect, it, vi } from 'vitest';

afterEach(() => {
  vi.unstubAllEnvs();
});

it('reads auth url', () => {
  vi.stubEnv('BETTER_AUTH_URL', 'https://app.example.com');

  expect(getAuthUrl()).toBe('https://app.example.com');
});
```

## Global mock

```ts
vi.stubGlobal('fetch', vi.fn().mockResolvedValue(
  new Response(JSON.stringify({ ok: true })),
));
```

После теста:

```ts
vi.unstubAllGlobals();
```

## Мини-шпаргалка

- Async success: `await expect(promise).resolves`.
- Async error: `await expect(promise).rejects`.
- Dates/timers: `vi.useFakeTimers`, `vi.setSystemTime`.
- Function mock: `vi.fn`.
- Object method spy: `vi.spyOn`.
- Module mock: `vi.mock`.
- Env: `vi.stubEnv` + `vi.unstubAllEnvs`.
