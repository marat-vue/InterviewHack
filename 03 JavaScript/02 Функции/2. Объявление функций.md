# Объявление функций

> [!summary] Коротко
> Функции в JavaScript можно объявлять через Function Declaration, Function Expression, стрелочные функции, методы объекта, методы класса и конструктор `Function`. На практике чаще всего используют первые три.

## Вопрос

Какие способы объявления функций существуют в JavaScript?

## Function Declaration

```javascript
function sum(a, b) {
  return a + b;
}
```

Такую функцию можно вызвать до объявления.

```javascript
sum(2, 3); // 5

function sum(a, b) {
  return a + b;
}
```

## Function Expression

Функция создается как выражение и записывается в переменную.

```javascript
const sum = function (a, b) {
  return a + b;
};
```

Вызвать до строки объявления нельзя, потому что переменная находится в TDZ.

```javascript
sum(2, 3); // ReferenceError

const sum = function (a, b) {
  return a + b;
};
```

## Named Function Expression

Function Expression может иметь имя.

```javascript
const factorial = function calc(n) {
  if (n <= 1) return 1;

  return n * calc(n - 1);
};
```

Имя `calc` доступно внутри самой функции. Это полезно для рекурсии и stack trace.

## Arrow Function

```javascript
const sum = (a, b) => a + b;
```

Стрелочные функции удобны для коротких callback и не имеют собственного `this`.

```javascript
const doubled = numbers.map((number) => number * 2);
```

## Метод объекта

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};
```

Такой синтаксис часто используют, когда функция является поведением объекта.

## Метод класса

```javascript
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}
```

Методы класса хранятся в прототипе.

## `new Function`

```javascript
const sum = new Function("a", "b", "return a + b");
```

Используется крайне редко. Похож на `eval`, сложнее для безопасности и оптимизации.

## Мини-шпаргалка

| Способ | Пример | Особенность |
| --- | --- | --- |
| Function Declaration | `function f() {}` | hoisting целиком |
| Function Expression | `const f = function () {}` | функция как значение |
| Named FE | `const f = function name() {}` | имя внутри функции |
| Arrow Function | `const f = () => {}` | нет собственного `this` |
| Method | `obj.method() {}` | удобно для объектов |
| Class Method | `class A { m() {} }` | метод в прототипе |
