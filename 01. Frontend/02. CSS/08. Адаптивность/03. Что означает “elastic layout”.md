# Что означает "elastic layout"?

> [!NOTE]
> **Elastic layout** - это макет, размеры которого зависят от размера текста, обычно через `em` или `rem`. Он лучше подстраивается под изменение шрифта и пользовательские настройки.

## Главное

В elastic layout элементы масштабируются вместе с типографикой.

```css
.card {
  max-width: 40rem;
  padding: 1.5rem;
}
```

Если базовый размер шрифта увеличится, карточка и ее отступы тоже станут больше.

## Отличие от fixed layout

```css
.fixed {
  width: 960px;
}

.elastic {
  max-width: 60rem;
}
```

Fixed layout привязан к пикселям, elastic - к размеру текста.

## Где полезно

- Текстовые страницы.
- Документация.
- Формы.
- Компоненты, которые должны хорошо масштабироваться.
- Интерфейсы с учетом accessibility-настроек пользователя.

## Связь с rem

```css
html {
  font-size: 16px;
}

.article {
  font-size: 1rem;
  line-height: 1.6;
  max-width: 65ch;
}
```

`rem` помогает строить размеры вокруг базовой типографики.

## Мини-шпаргалка

- Elastic layout масштабируется от размера текста.
- Часто использует `em`, `rem`, `ch`.
- Хорош для доступной типографики.
- Отличается от fixed layout на пикселях.
- Может сочетаться с fluid и responsive-подходом.
