# Что такое Server Actions в Next.js?

> [!summary]
> Server Actions в Next.js - серверные функции для мутаций данных, которые можно вызывать из форм и компонентов. В современной терминологии React/Next это Server Functions, помеченные директивой `'use server'`.

## Базовый пример

```ts
'use server'

import { revalidatePath } from 'next/cache'

export async function createPost(formData: FormData) {
  const title = String(formData.get('title'))

  await db.post.create({
    data: { title },
  })

  revalidatePath('/blog')
}
```

Форма:

```tsx
import { createPost } from './actions'

export function CreatePostForm() {
  return (
    <form action={createPost}>
      <input name="title" />
      <button>Create</button>
    </form>
  )
}
```

## Что можно делать в Server Action?

- читать `FormData`;
- валидировать данные;
- записывать в БД;
- читать cookies/headers;
- вызывать backend services;
- делать `redirect`;
- вызывать `revalidatePath`/`revalidateTag`.

## Где размещать?

Можно inline в Server Component:

```tsx
export default function Page() {
  async function createPost(formData: FormData) {
    'use server'
    await savePost(formData)
  }

  return <form action={createPost}>...</form>
}
```

Для импорта в Client Component чаще используют отдельный файл:

```ts
'use server'

export async function createPost(formData: FormData) {
  await savePost(formData)
}
```

## Что отвечать на собеседовании?

Server Actions - это серверные функции для мутаций, которые можно вызывать из UI без ручного создания API endpoint. Они выполняются на сервере, могут работать с БД и секретами, но требуют авторизации, валидации и обработки ошибок.

## Частые ошибки

- Считать Server Action приватной и не проверять права.
- Не валидировать `FormData`.
- Делать тяжелую бизнес-логику без транзакций.
- Забывать revalidation после изменения данных.
- Пытаться использовать Server Action как публичный REST API.

## Мини-шпаргалка

- Директива: `'use server'`.
- Основной сценарий - mutation.
- Хорошо работает с `<form action={...}>`.
- Можно делать `revalidatePath`.
- Можно делать `redirect`.
- Нужны auth и validation.
