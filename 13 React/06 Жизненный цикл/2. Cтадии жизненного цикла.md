# Какие стадии жизненного цикла есть у компонента?

> [!summary]
> У компонента можно выделить три крупные стадии: mount, update и unmount. Внутри современного React также важно понимать render phase, commit phase, запуск effects и cleanup.

## Классическая схема

| Стадия | Что происходит |
|---|---|
| Mount | компонент впервые появляется |
| Update | компонент получает новые props/state/context |
| Unmount | компонент удаляется |

Эта схема хорошо подходит для базового объяснения.

## Более современная схема

```text
Trigger -> Render -> Commit -> Effects
```

Trigger:

- начальный render;
- state update;
- parent render;
- context update.

Render:

- React вызывает компоненты;
- получает новое дерево React-элементов;
- не трогает DOM до commit.

Commit:

- React применяет изменения к DOM;
- обновляет refs;
- запускает layout effects.

Effects:

- обычные `useEffect` выполняются после paint;
- cleanup выполняется перед повторным setup и при unmount.

## Стадии в классовом компоненте

```jsx
class Page extends Component {
  componentDidMount() {}
  componentDidUpdate(prevProps, prevState) {}
  componentWillUnmount() {}

  render() {
    return <main />
  }
}
```

## Стадии в функциональном компоненте

```jsx
function Page({ id }) {
  useEffect(() => {
    const connection = connect(id)

    return () => connection.disconnect()
  }, [id])

  return <main />
}
```

Один effect может покрывать mount, update и unmount для конкретной внешней синхронизации.

## Мини-шпаргалка

- Mount - появление компонента.
- Update - повторный render из-за изменений.
- Unmount - удаление компонента.
- Render phase должна быть чистой.
- Effects и cleanup отвечают за внешний мир.
