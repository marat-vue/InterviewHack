# Что такое global module?

> [!summary]
> Global module - module с decorator `@Global()`, providers которого становятся доступными во всем приложении после одного импорта. Использовать его нужно осторожно, чтобы не скрывать зависимости.

## Пример

```ts
@Global()
@Module({
  providers: [ConfigService],
  exports: [ConfigService],
})
export class ConfigModule {}
```

Теперь `ConfigService` доступен в других modules без повторного импорта `ConfigModule`.

## Когда полезно?

- config;
- logger;
- metrics;
- shared infrastructure.

## Почему опасно?

Global modules делают зависимости менее явными. Разработчик может не понять, откуда пришел provider.

## Правило

Используй global modules только для действительно инфраструктурных зависимостей, которые нужны почти везде.

## Мини-шпаргалка

- `@Global()` делает exports module глобальными.
- Module все равно нужно импортировать хотя бы один раз.
- Не делай domain modules глобальными.
- Global удобно для config/logger.
- Слишком много global modules ухудшают прозрачность архитектуры.
