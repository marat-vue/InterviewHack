# Способы отладки в браузере

> [!summary] Коротко
> В браузере отлаживают код через Console, Sources, breakpoints, Network, Performance и инспектор DOM.

## Вопрос

Какие способы отладки существуют в браузере?

## Console

```javascript
console.log(value);
console.table(users);
console.error(error);
```

Консоль помогает быстро посмотреть значения, ошибки и предупреждения.

## Breakpoints

Вкладка Sources позволяет поставить breakpoint на строку кода. Когда выполнение дойдет до нее, браузер поставит код на паузу.

На паузе можно:

- смотреть значения переменных;
- выполнять код в консоли;
- идти пошагово;
- изучать call stack;
- проверять scope.

## Оператор debugger

```javascript
function save() {
  debugger;
  sendData();
}
```

Если DevTools открыты, выполнение остановится на строке `debugger`.

## Network

Network tab помогает смотреть:

- запросы;
- статусы ответов;
- headers;
- payload;
- response;
- время загрузки.

## Elements

В Elements можно проверять DOM, CSS, размеры элементов, классы, атрибуты и event listeners.

## Performance

Performance tab помогает найти долгие задачи, проблемы рендера, частые reflow/repaint и блокировки main thread.

## Мини-шпаргалка

```text
Console -> values
Sources -> breakpoints
Network -> requests
Elements -> DOM/CSS
Performance -> speed
```
