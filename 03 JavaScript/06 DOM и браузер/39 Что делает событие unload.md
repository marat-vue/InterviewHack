# Что делает событие unload?

> [!NOTE] Коротко
> `unload` срабатывает, когда страница уже покидается, но для современной логики его используют редко.

## Вопрос

Что делает событие `unload` и почему оно считается неудобным?

## Определение

`unload` возникает при выгрузке страницы: переходе, обновлении или закрытии вкладки. В этот момент документ уже уходит из активного состояния.

Раньше `unload` использовали для очистки и отправки данных, но сейчас это ненадежный вариант.

## Пример

```javascript
window.addEventListener('unload', () => {
  console.log('page is unloading');
});
```

## Почему не стоит полагаться на unload

- браузер может не дать завершить асинхронные операции;
- событие может мешать back-forward cache;
- пользователь уже покидает страницу;
- на мобильных устройствах событие может не сработать ожидаемо.

## Чем заменить

Для аналитики и коротких отправок лучше использовать `navigator.sendBeacon()`.

```javascript
window.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    navigator.sendBeacon('/analytics', JSON.stringify({ page: location.href }));
  }
});
```

`visibilitychange` часто надежнее для фиксации ухода пользователя со страницы.

## unload vs beforeunload

| Событие | Когда | Для чего |
| --- | --- | --- |
| `beforeunload` | перед уходом | предупредить о несохраненных данных |
| `unload` | при выгрузке | редко, legacy-сценарии |

## Мини-шпаргалка

```javascript
window.addEventListener('unload', handler); // использовать осторожно
```
