# Чем Next.js отличается от React в плане получения данных?

> [!summary]
> React сам по себе не задает серверную модель получения данных, а Next.js предоставляет серверную среду, App Router, Server Components, Route Handlers, Server Actions и кеширование. Поэтому данные можно получать до отправки HTML, а не только после загрузки JavaScript в браузере.

## React SPA подход

```tsx
function UsersPage() {
  const [users, setUsers] = useState<User[]>([])

  useEffect(() => {
    fetch('/api/users')
      .then((res) => res.json())
      .then(setUsers)
  }, [])

  return <UserList users={users} />
}
```

HTML сначала может быть пустым или содержать loader.

## Next.js App Router подход

```tsx
export default async function UsersPage() {
  const users = await getUsers()

  return <UserList users={users} />
}
```

Данные можно получить на сервере до отправки HTML.

## Что меняется?

| Тема | React SPA | Next.js |
|---|---|---|
| место выполнения | браузер | сервер и браузер |
| SEO-контент | часто после JS | может быть в HTML |
| secrets | нельзя хранить | можно на сервере |
| DB access | нужен backend | можно в Server Component/Action |
| cache | библиотека/ручной | встроенные механизмы Next |
| mutation | fetch/API | Server Actions или Route Handlers |

## Next.js не отменяет React Query

TanStack Query все еще полезен для client-side server state:

- dashboards;
- фильтры с мгновенным refetch;
- infinite scroll;
- realtime-like UI;
- сложные optimistic updates.

Но первый SEO-контент часто лучше грузить на сервере.

## Что отвечать на собеседовании?

React отвечает за UI, а Next.js добавляет серверную модель. В Next.js можно получать данные в Server Components, Route Handlers и Server Actions, кешировать их и отправлять HTML уже с контентом. В React SPA чаще приходится грузить данные на клиенте через effects или data libraries.

## Частые ошибки

- Думать, что Next.js запрещает client fetching.
- Думать, что React Query не нужен в Next.js.
- Делать лишний Route Handler для запроса из Server Component.
- Считать серверную загрузку автоматической безопасностью.
- Не валидировать данные внешнего API.

## Мини-шпаргалка

- React - UI library.
- Next.js - server-capable framework.
- Server Components могут `await` данные.
- Secrets остаются на сервере.
- Client fetching остается для интерактива.
- Для server state на клиенте полезен TanStack Query.
