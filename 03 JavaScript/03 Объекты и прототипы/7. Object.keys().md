# `Object.keys()`

> [!summary] Коротко
> `Object.keys(obj)` возвращает массив строковых ключей собственных перечисляемых свойств объекта.

## Вопрос

Что делает `Object.keys()`?

## Базовый пример

```javascript
const user = {
  name: "Anna",
  age: 25,
};

Object.keys(user); // ["name", "age"]
```

Результат всегда массив.

## Только собственные свойства

```javascript
const proto = { role: "user" };
const user = Object.create(proto);
user.name = "Anna";

Object.keys(user); // ["name"]
```

Свойство `role` находится в прототипе, поэтому не попадет в результат.

## Только enumerable

```javascript
const user = { name: "Anna" };

Object.defineProperty(user, "id", {
  value: 1,
  enumerable: false,
});

Object.keys(user); // ["name"]
```

Неперечисляемые свойства не возвращаются.

## Symbol-ключи не попадают

```javascript
const id = Symbol("id");
const user = {
  name: "Anna",
  [id]: 1,
};

Object.keys(user); // ["name"]
```

Для символов есть:

```javascript
Object.getOwnPropertySymbols(user);
```

## Частые задачи

Проверить, пустой ли объект:

```javascript
Object.keys(obj).length === 0;
```

Перебрать ключи:

```javascript
for (const key of Object.keys(user)) {
  console.log(key, user[key]);
}
```

## Мини-шпаргалка

| Метод | Возвращает |
| --- | --- |
| `Object.keys(obj)` | ключи |
| `Object.values(obj)` | значения |
| `Object.entries(obj)` | пары `[key, value]` |
| `Object.getOwnPropertyNames(obj)` | все собственные строковые ключи |
| `Object.getOwnPropertySymbols(obj)` | symbol-ключи |
