# Чем resolve отличается от reject

> [!summary] Коротко
> `resolve` завершает промис успешно, а `reject` завершает его с ошибкой.

## Вопрос

Чем `resolve()` отличается от `reject()` внутри `Promise`?

## Определение

`resolve(value)` переводит промис в состояние `fulfilled` и передает успешное значение дальше в `.then()` или `await`.

`reject(reason)` переводит промис в состояние `rejected` и передает причину ошибки в `.catch()` или `try...catch` вокруг `await`.

## Пример resolve

```javascript
const promise = new Promise((resolve) => {
  resolve('User loaded');
});

promise.then((result) => {
  console.log(result); // 'User loaded'
});
```

## Пример reject

```javascript
const promise = new Promise((resolve, reject) => {
  reject(new Error('Network error'));
});

promise.catch((error) => {
  console.error(error.message); // 'Network error'
});
```

## Состояние фиксируется один раз

```javascript
const promise = new Promise((resolve, reject) => {
  resolve('first');
  reject(new Error('second'));
});

promise.then(console.log); // 'first'
```

После первого `resolve` или `reject` состояние промиса уже нельзя изменить.

## resolve с другим промисом

```javascript
const inner = Promise.resolve('ok');
const outer = Promise.resolve(inner);

outer.then(console.log); // 'ok'
```

Если в `resolve` передать промис, внешний промис дождется его результата.

## Мини-шпаргалка

```javascript
resolve(value); // success -> then / await
reject(error);  // failure -> catch / try...catch
```
