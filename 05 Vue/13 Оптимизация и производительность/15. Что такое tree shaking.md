# Что такое tree shaking

> [!summary]
> **Tree shaking** - это удаление неиспользуемого JavaScript из итогового bundle. Сборщик анализирует импорты и экспорты модулей и оставляет только то, что реально используется.

## Главное

Tree shaking помогает уменьшить размер JavaScript, который браузер должен скачать, распарсить и выполнить.

```text
library exports:
  formatDate
  parseDate
  addDays

app imports:
  formatDate

bundle:
  formatDate
```

## Почему важны ES modules

Tree shaking хорошо работает со статическими импортами и экспортами.

```js
import { formatDate } from "./date";

export function formatDate(date) {}
export function parseDate(value) {}
```

Сборщик видит, какие функции импортируются, а какие нет.

## Что мешает tree shaking

- CommonJS-модули с динамическим `require`.
- Импорт всей библиотеки ради одной функции.
- Модули с сайд-эффектами при импорте.
- Динамические обращения к объектам экспорта.
- Неправильная настройка `sideEffects` в package.

```js
// хуже для размера bundle
import _ from "lodash";

// лучше
import debounce from "lodash/debounce";
```

## Пример во Vue

```js
import { createApp } from "vue";
import { createPinia } from "pinia";
import App from "./App.vue";

createApp(App)
  .use(createPinia())
  .mount("#app");
```

Современная экосистема Vue построена вокруг ES modules, поэтому сборщики вроде Vite могут хорошо удалять неиспользуемый код.

## Tree shaking и lazy loading

Tree shaking удаляет неиспользуемый код. Lazy loading откладывает загрузку используемого кода.

```text
tree shaking -> не попадет в bundle
lazy loading -> попадет в отдельный chunk
```

Это разные оптимизации, но они часто работают вместе.

## Как проверить

- Собрать проект в production-режиме.
- Посмотреть размер chunks.
- Использовать bundle analyzer.
- Проверить, не импортируется ли вся библиотека ради одной функции.

## Мини-шпаргалка

- Tree shaking удаляет неиспользуемые exports.
- Лучше всего работает с ES modules.
- Сайд-эффекты мешают удалению кода.
- Не импортируй всю большую библиотеку без необходимости.
- Tree shaking уменьшает bundle, а lazy loading делит его на chunks.
