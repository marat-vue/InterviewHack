# Как зарегистрировать глобальный компонент в Vue 3?

> [!NOTE] Коротко
> Глобальный компонент регистрируют на экземпляре приложения через `app.component(name, component)`. После этого его можно использовать в любом шаблоне приложения.

## Вопрос

Как зарегистрировать глобальный компонент в Vue 3?

## Базовый пример

```typescript
import { createApp } from "vue";
import App from "./App.vue";
import BaseButton from "./components/BaseButton.vue";

const app = createApp(App);

app.component("BaseButton", BaseButton);

app.mount("#app");
```

Теперь компонент доступен без локального импорта.

```vue
<template>
  <BaseButton>Сохранить</BaseButton>
</template>
```

## Когда это удобно

Глобальная регистрация подходит для маленьких базовых компонентов, которые используются почти везде: кнопки, иконки, поля ввода, layout wrappers.

## Минусы

Глобальные компоненты делают зависимости менее явными. Открывая файл, не всегда понятно, откуда пришел компонент. Еще глобальная регистрация может ухудшить tree shaking, если подключать слишком много компонентов.

## Именование

Для глобальных базовых компонентов часто используют префикс `Base`, `App` или `Ui`.

```typescript
app.component("BaseInput", BaseInput);
app.component("AppIcon", AppIcon);
```

## Мини-шпаргалка

- Регистрация: `app.component("Name", Component)`.
- Делается до `app.mount`.
- Компонент становится доступен во всем приложении.
- Используй глобально только то, что правда нужно часто.
