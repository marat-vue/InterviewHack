# Как работать со связями, nested writes и transactions?

> [!NOTE]
> Prisma позволяет читать связанные данные через `include`/`select`, фильтровать по связям через `some`, `every`, `none`, создавать связанные записи через nested writes и объединять операции в transactions.

## Чтение связей

```ts
await prisma.user.findUnique({
  where: { id },
  include: {
    posts: true,
  },
});
```

Ограничение полей relation:

```ts
await prisma.user.findUnique({
  where: { id },
  select: {
    id: true,
    email: true,
    posts: {
      select: {
        id: true,
        title: true,
      },
    },
  },
});
```

## Фильтрация по связям

Users, у которых есть опубликованные posts:

```ts
await prisma.user.findMany({
  where: {
    posts: {
      some: {
        published: true,
      },
    },
  },
});
```

Users, у которых нет posts:

```ts
await prisma.user.findMany({
  where: {
    posts: {
      none: {},
    },
  },
});
```

Users, у которых все posts published:

```ts
await prisma.user.findMany({
  where: {
    posts: {
      every: {
        published: true,
      },
    },
  },
});
```

## Nested create

```ts
await prisma.user.create({
  data: {
    email: 'anna@example.com',
    posts: {
      create: [
        { title: 'First post' },
        { title: 'Second post' },
      ],
    },
  },
});
```

Nested writes выполняются атомарно: если часть операции падает, вся операция откатывается.

## connect

```ts
await prisma.post.create({
  data: {
    title: 'Nitro guide',
    author: {
      connect: {
        id: userId,
      },
    },
  },
});
```

`connect` связывает новую запись с уже существующей.

## connectOrCreate

```ts
await prisma.post.create({
  data: {
    title: 'Prisma',
    tags: {
      connectOrCreate: {
        where: {
          name: 'orm',
        },
        create: {
          name: 'orm',
        },
      },
    },
  },
});
```

Полезно для tags, categories, external identities.

## Nested update/delete

```ts
await prisma.user.update({
  where: { id: userId },
  data: {
    posts: {
      updateMany: {
        where: {
          published: false,
        },
        data: {
          archived: true,
        },
      },
    },
  },
});
```

## Batch transaction

```ts
const [items, total] = await prisma.$transaction([
  prisma.post.findMany({ where, take, skip }),
  prisma.post.count({ where }),
]);
```

Хорошо для независимых запросов, которые нужно выполнить в одном transaction.

## Interactive transaction

```ts
await prisma.$transaction(async (tx) => {
  const order = await tx.order.create({
    data: {
      userId,
      total,
    },
  });

  await tx.orderItem.createMany({
    data: items.map((item) => ({
      orderId: order.id,
      productId: item.productId,
      quantity: item.quantity,
    })),
  });

  await tx.auditLog.create({
    data: {
      action: 'ORDER_CREATED',
      entityId: order.id,
    },
  });
});
```

Interactive transaction нужна, когда вторая операция зависит от результата первой.

## Ошибки с transactions

Частые ошибки:

- делать долгие external HTTP calls внутри transaction;
- держать transaction открытой слишком долго;
- использовать `prisma` вместо `tx` внутри transaction callback;
- не учитывать unique conflicts;
- забывать про isolation/concurrency.

## Мини-шпаргалка

- `include` возвращает связи.
- `some/every/none` фильтруют по to-many relation.
- `create/connect/connectOrCreate` работают в nested writes.
- Nested writes атомарны.
- `$transaction([])` - batch независимых операций.
- `$transaction(async tx => {})` - зависимые операции.
- Не делай внешние долгие calls внутри transaction.
