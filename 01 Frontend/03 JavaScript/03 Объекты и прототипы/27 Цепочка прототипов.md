# Цепочка прототипов

> [!NOTE]
> Цепочка прототипов - механизм поиска свойств: если свойства нет в объекте, JavaScript ищет его в прототипе, затем в прототипе прототипа и так до `null`.

## Вопрос

Как работает цепочка прототипов?

## Алгоритм поиска

При обращении:

```javascript
obj.property;
```

JavaScript:

1. ищет `property` в самом `obj`;
2. если не нашел, идет в `Object.getPrototypeOf(obj)`;
3. повторяет поиск выше по цепочке;
4. если дошел до `null`, возвращает `undefined`.

## Пример

```javascript
const animal = {
  eats: true,
};

const dog = Object.create(animal);
dog.name = "Rex";

dog.name; // "Rex" - собственное свойство
dog.eats; // true - из прототипа
```

## Проверка собственных свойств

```javascript
Object.hasOwn(dog, "name"); // true
Object.hasOwn(dog, "eats"); // false

"eats" in dog; // true
```

`in` видит свойства в прототипе, `Object.hasOwn` - только собственные.

## Конец цепочки

```javascript
Object.getPrototypeOf(Object.prototype); // null
```

Обычная цепочка:

```text
dog -> animal -> Object.prototype -> null
```

## Затенение свойства

Если свойство есть в самом объекте, прототипное свойство с тем же именем не используется.

```javascript
const proto = { role: "user" };
const user = Object.create(proto);

user.role = "admin";

user.role; // "admin"
```

Собственное свойство "затенило" прототипное.

## Мини-шпаргалка

| Операция | Что делает |
| --- | --- |
| `obj.prop` | ищет по цепочке |
| `"prop" in obj` | проверяет объект и прототипы |
| `Object.hasOwn(obj, "prop")` | только сам объект |
| `Object.getPrototypeOf(obj)` | следующий объект в цепочке |
| конец цепочки | `null` |
