# Как Vue оптимизирует Virtual DOM

> [!summary]
> Vue оптимизирует Virtual DOM не только во время выполнения, но и на этапе компиляции шаблонов. Компилятор заранее помечает динамические части, чтобы runtime не проверял лишнее.

## Главное

В Vue шаблон компилируется в render-функцию. На этом этапе Vue видит, какие части шаблона статичны, а какие зависят от реактивных данных.

```vue
<template>
  <section>
    <h1>Каталог</h1>
    <p>{{ productsCount }} товаров</p>
  </section>
</template>
```

В этом примере `h1` статичен, а текст внутри `p` динамический. Vue может не сравнивать `h1` при каждом обновлении.

## Основные оптимизации

| Оптимизация | Идея |
| --- | --- |
| Static hoisting | Статические VNode выносятся из render-функции и переиспользуются |
| Patch flags | Динамические узлы получают подсказки о том, что именно может измениться |
| Block tree | Vue группирует динамические узлы и быстрее находит места обновлений |
| Tree flattening | Runtime работает с плоским списком динамических потомков блока |
| Event handler caching | Обработчики событий могут переиспользоваться между рендерами |

## Static hoisting

Если часть шаблона не зависит от состояния, Vue может создать ее один раз.

```vue
<template>
  <article>
    <h2>Постоянный заголовок</h2>
    <p>{{ description }}</p>
  </article>
</template>
```

`h2` не нужно создавать заново на каждом рендере. Это снижает количество работы в JavaScript.

## Patch flags

Patch flag говорит runtime, что именно динамическое в узле.

```vue
<template>
  <p :class="statusClass">{{ message }}</p>
</template>
```

Для такого узла Vue понимает, что нужно проверять текст и класс, а не весь объект props.

## Block tree

Block tree помогает Vue пропускать большие статические участки и переходить сразу к динамическим узлам.

```vue
<template>
  <div>
    <Header />
    <main>
      <p>{{ user.name }}</p>
    </main>
    <Footer />
  </div>
</template>
```

Если меняется `user.name`, Vue не обязан глубоко обходить весь статический layout.

## Keyed diff

Для списков Vue использует `key`, чтобы понять, какие элементы были добавлены, удалены или перемещены.

```vue
<template>
  <TodoItem
    v-for="todo in todos"
    :key="todo.id"
    :todo="todo"
  />
</template>
```

Стабильный `key` помогает Vue переиспользовать правильные DOM-узлы и компоненты.

## Мини-шпаргалка

- Vue компилирует шаблоны в render-функции.
- Статические части можно переиспользовать.
- Patch flags указывают, что именно изменяется.
- Block tree помогает быстрее находить динамические узлы.
- Для списков обязательно использовать стабильный `key`.
