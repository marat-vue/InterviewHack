# Что делает элемент video. Как указать источник видео в HTML?

> [!NOTE]
> Элемент `<video>` встраивает видео на страницу. Источник можно указать через атрибут `src` или через вложенные элементы `<source>` для нескольких форматов.

## Простой пример

```html
<video controls src="/video/demo.mp4">
  Ваш браузер не поддерживает видео.
</video>
```

`controls` добавляет нативную панель управления.

## Несколько источников

```html
<video controls width="800" height="450" poster="/video/poster.jpg">
  <source src="/video/demo.webm" type="video/webm">
  <source src="/video/demo.mp4" type="video/mp4">
  Ваш браузер не поддерживает видео.
</video>
```

Браузер выберет первый поддерживаемый формат.

## Важные атрибуты

| Атрибут | Что делает |
| --- | --- |
| `controls` | Показывает управление |
| `poster` | Картинка до запуска видео |
| `width`, `height` | Размеры видео |
| `muted` | Отключает звук |
| `autoplay` | Пытается запустить автоматически |
| `loop` | Зацикливает видео |
| `preload` | Подсказывает стратегию загрузки |
| `playsinline` | Помогает воспроизводить inline на мобильных |

## Субтитры

```html
<video controls>
  <source src="/video/lesson.mp4" type="video/mp4">
  <track
    src="/video/subtitles-ru.vtt"
    kind="subtitles"
    srclang="ru"
    label="Русские субтитры"
    default
  >
</video>
```

`track` добавляет субтитры, captions или другие текстовые дорожки.

## Производительность

Видео может быть тяжелым ресурсом. Для больших видео полезны:

- постер;
- сжатие;
- потоковая передача;
- `preload="metadata"` или `preload="none"`;
- lazy loading через JavaScript для видео ниже первого экрана.

## Мини-шпаргалка

- `<video>` встраивает видео.
- Источник задают через `src` или `<source>`.
- `controls` добавляет управление.
- `poster` показывает превью.
- `track` добавляет субтитры.
- Видео нужно оптимизировать как тяжелый ресурс.
