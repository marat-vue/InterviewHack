# Function Declaration и Function Expression

> [!summary] Коротко
> Function Declaration объявляет функцию как отдельную декларацию и всплывает целиком. Function Expression создает функцию как значение и присваивает ее переменной.

## Вопрос

В чем разница между Function Declaration и Function Expression?

## Function Declaration

```javascript
function sayHi() {
  return "Hi";
}
```

Главная особенность: функцию можно вызвать до объявления.

```javascript
sayHi(); // "Hi"

function sayHi() {
  return "Hi";
}
```

Это работает из-за hoisting: декларация функции поднимается целиком.

## Function Expression

```javascript
const sayHi = function () {
  return "Hi";
};
```

Функция создается в момент выполнения строки с присваиванием.

```javascript
sayHi(); // ReferenceError

const sayHi = function () {
  return "Hi";
};
```

Здесь всплывает переменная `sayHi`, но не значение функции.

## Function Expression с `var`

```javascript
sayHi(); // TypeError: sayHi is not a function

var sayHi = function () {
  return "Hi";
};
```

Почему `TypeError`: переменная уже существует и равна `undefined`, но `undefined` нельзя вызвать.

## Именованное Function Expression

```javascript
const factorial = function calc(n) {
  if (n <= 1) return 1;

  return n * calc(n - 1);
};
```

Имя `calc` доступно внутри функции, но не снаружи.

```javascript
calc(5); // ReferenceError
```

## Когда что использовать

Function Declaration хорошо подходит для обычных именованных функций верхнего уровня.

```javascript
function validateUser(user) {
  return Boolean(user.email);
}
```

Function Expression удобно использовать, когда функция является значением:

```javascript
const validators = {
  email(value) {
    return value.includes("@");
  },
};
```

или callback:

```javascript
button.addEventListener("click", function () {
  console.log("click");
});
```

## Мини-шпаргалка

| Отличие | Function Declaration | Function Expression |
| --- | --- | --- |
| Синтаксис | `function f() {}` | `const f = function () {}` |
| Hoisting | всплывает целиком | зависит от переменной |
| Имя | обязательно | может быть анонимной |
| Использование | обычные функции | функции как значения |
| Вызов до объявления | можно | нельзя с `let/const` |
