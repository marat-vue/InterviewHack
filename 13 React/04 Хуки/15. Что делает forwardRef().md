# Что делает forwardRef?

> [!summary]
> `forwardRef` позволяет компоненту принять `ref` от родителя и передать его внутрь к DOM-элементу или другому компоненту. В React 19 `ref` можно передавать как обычный prop в новых сценариях, но `forwardRef` по-прежнему важно знать для legacy-кода и библиотек.

## Зачем нужен ref forwarding?

Обычный DOM ref:

```jsx
const inputRef = useRef(null)

return <input ref={inputRef} />
```

Но если input спрятан внутри своего компонента:

```jsx
function TextInput(props) {
  return <input {...props} />
}
```

родителю может понадобиться сфокусировать именно внутренний `input`.

## Пример с forwardRef

```jsx
import { forwardRef, useRef } from 'react'

const TextInput = forwardRef(function TextInput(props, ref) {
  return <input ref={ref} {...props} />
})

function Form() {
  const inputRef = useRef(null)

  return (
    <>
      <TextInput ref={inputRef} />
      <button onClick={() => inputRef.current?.focus()}>
        Фокус
      </button>
    </>
  )
}
```

`forwardRef` передает ref через компонентную границу.

## Когда это нужно?

- UI-kit компоненты;
- input/button wrappers;
- focus management;
- animation libraries;
- measurement;
- интеграция с form libraries;
- imperative API через `useImperativeHandle`.

## Важный нюанс React 19

В React 19 `ref` становится более обычным prop для компонентов, и потребность в `forwardRef` постепенно уменьшается. Но в существующем коде, библиотеках и проектах на React 18 `forwardRef` все еще встречается часто.

На собеседовании лучше сказать:

```text
forwardRef нужен, чтобы пробросить ref через компонент к внутреннему DOM-узлу. В React 19 подход с ref меняется, но forwardRef важно понимать для совместимости и legacy-кода.
```

## Мини-шпаргалка

- `forwardRef` пробрасывает ref внутрь компонента.
- Часто используется в UI-kit.
- Нужен для focus, scroll, measurements.
- В React 19 роль `forwardRef` уменьшается.
- Не пробрасывай ref без реальной причины.
