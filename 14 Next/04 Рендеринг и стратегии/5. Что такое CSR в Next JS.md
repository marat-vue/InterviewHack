# Что такое CSR в Next JS?

> [!summary]
> CSR в Next.js - рендеринг интерактивной части UI в браузере. В App Router CSR обычно появляется внутри Client Components, которые помечены директивой `'use client'` и используют state, effects, browser APIs или event handlers.

## Где появляется CSR?

```tsx
'use client'

import { useState } from 'react'

export function Counter() {
  const [count, setCount] = useState(0)

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

Этот компонент требует клиентский JavaScript.

## CSR не значит, что вся страница client-only

В Next.js можно смешивать:

```tsx
export default async function ProductPage() {
  const product = await getProduct()

  return (
    <>
      <h1>{product.title}</h1>
      <AddToCartButton productId={product.id} />
    </>
  )
}
```

`ProductPage` может быть Server Component, а `AddToCartButton` - Client Component.

## Когда CSR нужен?

- формы с локальным состоянием;
- dropdown;
- tabs;
- modals;
- drag and drop;
- browser APIs;
- event handlers;
- animations;
- client-only libraries.

## Когда CSR вреден?

CSR хуже, если весь важный контент грузится только после `useEffect`:

```tsx
'use client'

useEffect(() => {
  fetch('/api/products').then(...)
}, [])
```

Для SEO-важного контента лучше Server Components или SSR/SSG.

## Что отвечать на собеседовании?

CSR в Next.js нужен для интерактивности. В App Router его область задается Client Components. Хорошая практика - держать client boundary как можно ниже: статичный контент и data fetching оставлять на сервере, а на клиент переносить только интерактивные островки.

## Частые ошибки

- Ставить `'use client'` на весь layout.
- Загружать SEO-контент только в `useEffect`.
- Импортировать server-only код в Client Component.
- Делать всю страницу Client Component ради одной кнопки.
- Путать hydration и CSR.

## Мини-шпаргалка

- CSR выполняется в браузере.
- В App Router CSR = Client Components.
- `'use client'` задает client boundary.
- Нужен для state/effects/events.
- Не нужен для статичного контента.
- Client Components дороже по JS.
