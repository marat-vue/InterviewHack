# Как включить rate limiting в NestJS?

> [!summary]
> Rate limiting ограничивает количество запросов за период времени и помогает защищаться от brute force, spam и случайной перегрузки. В NestJS часто используют пакет `@nestjs/throttler`.

## Подключение

```ts
@Module({
  imports: [
    ThrottlerModule.forRoot([
      {
        ttl: 60_000,
        limit: 100,
      },
    ]),
  ],
})
export class AppModule {}
```

## Guard

```ts
@UseGuards(ThrottlerGuard)
@Controller('auth')
export class AuthController {}
```

Часто throttler guard подключают глобально через provider `APP_GUARD`.

## Route-specific limit

```ts
@Throttle({ default: { limit: 5, ttl: 60_000 } })
@Post('login')
login() {}
```

## Мини-шпаргалка

- Rate limiting ограничивает частоту запросов.
- Полезен для login endpoints.
- В NestJS есть `@nestjs/throttler`.
- Для нескольких инстансов нужно общее хранилище лимитов.
- Rate limiting не заменяет auth и validation.
