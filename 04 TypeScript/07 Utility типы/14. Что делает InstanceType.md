# Что делает InstanceType

> [!summary] Коротко
> `InstanceType<T>` достает тип экземпляра из типа конструктора `T`.

## Вопрос

Что делает `InstanceType`?

## Базовый пример

```typescript
class UserService {
  findUser(id: number) {
    return { id, name: "Анна" };
  }
}

type Service = InstanceType<typeof UserService>;
```

`Service` будет типом экземпляра, то есть объекта, который получается после `new UserService()`.

## Почему нужен `typeof`

```typescript
type ConstructorType = typeof UserService;
type Instance = InstanceType<ConstructorType>;
```

Класс в TypeScript имеет две стороны: тип экземпляра и тип конструктора.

## Практический пример

```typescript
function create<Ctor extends new (...args: any[]) => any>(
  Constructor: Ctor,
  ...args: ConstructorParameters<Ctor>
): InstanceType<Ctor> {
  return new Constructor(...args);
}
```

## Ограничение

`InstanceType` работает только с constructor type.

```typescript
// type Bad = InstanceType<() => string>; // ошибка
```

## Мини-шпаргалка

- `InstanceType<typeof Class>` достает тип экземпляра класса.
- Для параметров конструктора есть `ConstructorParameters`.
- Нужен `typeof`, чтобы обратиться к constructor-side класса.
- Часто встречается в factory и dependency injection.
