# Что делает блок finally

> [!summary] Коротко
> `finally` выполняется после `try` и `catch` независимо от того, была ошибка или нет.

## Вопрос

Для чего нужен блок `finally` в `try...catch...finally`?

## Определение

`finally` - блок для кода, который должен выполниться в любом случае: при успешном выполнении, при ошибке, после `catch`, а также перед выходом из функции через `return`.

Его используют для очистки ресурсов и восстановления состояния.

## Пример

```javascript
try {
  console.log('try');
} catch (error) {
  console.log('catch');
} finally {
  console.log('finally');
}
```

Если ошибки нет, выполнится `try`, затем `finally`.

## Пример с ошибкой

```javascript
try {
  throw new Error('Boom');
} catch (error) {
  console.log(error.message);
} finally {
  console.log('cleanup');
}
```

`finally` выполнится после обработки ошибки.

## Где полезен finally

```javascript
setLoading(true);

try {
  await saveData();
} catch (error) {
  showError(error);
} finally {
  setLoading(false);
}
```

Даже если запрос упадет, loader будет выключен.

## Мини-шпаргалка

```javascript
try {
  riskyCode();
} catch (error) {
  handleError(error);
} finally {
  cleanup();
}
```
