# Чем DOM отличается от HTML

> [!summary] Коротко
> HTML - исходная разметка, а DOM - живая объектная модель страницы, которую браузер построил из этой разметки.

## Вопрос

Почему HTML и DOM не всегда одно и то же?

## Определение

HTML - текстовый документ с тегами. DOM - структура объектов в памяти браузера. Браузер парсит HTML, исправляет некоторые ошибки разметки и создает DOM-дерево.

После загрузки страницы JavaScript может менять DOM, даже если исходный HTML-файл не изменился.

## Пример

HTML:

```html
<ul id="list">
  <li>HTML item</li>
</ul>
```

JavaScript:

```javascript
const list = document.querySelector('#list');
const item = document.createElement('li');

item.textContent = 'DOM item';
list.append(item);
```

В исходном HTML был один элемент, но в DOM стало два.

## Почему DOM может отличаться

- браузер исправил некорректную разметку;
- JavaScript добавил или удалил элементы;
- фреймворк перерендерил часть страницы;
- пользователь ввел данные в форму;
- браузер создал служебные состояния элементов.

## Сравнение

| HTML | DOM |
| --- | --- |
| текстовая разметка | объектная структура |
| хранится в файле или ответе сервера | живет в памяти браузера |
| статичен сам по себе | может меняться во время работы |
| описывает начальное состояние | отражает текущее состояние страницы |

## Мини-шпаргалка

```text
HTML -> browser parses -> DOM -> JavaScript changes DOM
```
