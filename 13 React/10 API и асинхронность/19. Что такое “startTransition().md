# Что такое startTransition()?

> [!summary]
> `startTransition` - это React API для пометки обновлений state как transition. Такие обновления считаются несрочными: React может выполнять их в фоне, прерывать и перезапускать, чтобы пользовательский ввод оставался отзывчивым.

## Импорт

```jsx
import { startTransition } from 'react'
```

`startTransition` можно использовать вне компонента, если у тебя есть доступ к setter.

```jsx
startTransition(() => {
  setPage('settings')
})
```

## Пример с поиском

```jsx
function SearchPage({ allProducts }) {
  const [query, setQuery] = useState('')
  const [products, setProducts] = useState(allProducts)

  function handleChange(event) {
    const nextQuery = event.target.value

    setQuery(nextQuery)

    startTransition(() => {
      setProducts(filterProducts(allProducts, nextQuery))
    })
  }

  return (
    <>
      <input value={query} onChange={handleChange} />
      <ProductsList products={products} />
    </>
  )
}
```

`setQuery` срочный: input должен обновиться сразу.

`setProducts` несрочный: список можно пересчитать в фоне.

## startTransition vs useTransition

| API | Что дает |
|---|---|
| `startTransition` | Помечает updates как transition |
| `useTransition` | Помечает updates и дает `isPending` |

Если нужен loader или disabled-state на время перехода, чаще используют `useTransition`.

## Ограничения

Transition не делает тяжелое вычисление "параллельным" в отдельном потоке. Если внутри callback ты синхронно считаешь огромный массив до `setState`, это вычисление все равно блокирует JavaScript thread.

Плохо:

```jsx
startTransition(() => {
  const result = veryHeavyCalculation()
  setResult(result)
})
```

Если вычисление реально тяжелое, подумай про:

- Web Worker;
- server-side filtering;
- virtualization;
- debounce;
- предварительную индексацию данных.

## Важное про async

`startTransition` вызывает переданную функцию сразу.

```jsx
startTransition(() => {
  setTab('reports')
})
```

State updates после `await` могут потребовать дополнительного `startTransition`, если их тоже нужно пометить как transition.

## Мини-шпаргалка

- `startTransition` помечает state updates как несрочные.
- Срочный ввод не помещают в transition.
- Transition render можно прервать.
- API не дает `isPending`; для этого нужен `useTransition`.
- Это про приоритет render, а не про отдельный поток.
