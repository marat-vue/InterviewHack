# Motion в проекте и вопросы на собеседовании

> [!summary]
> В реальном проекте Motion должен помогать UX: объяснять переходы, снижать резкость изменений, показывать связь элементов. Важно не анимировать все подряд, учитывать производительность, accessibility и server/client boundaries.

## Где анимация реально помогает?

Хорошие сценарии:

- открытие/закрытие modal;
- dropdown/menu;
- переход между tabs;
- добавление/удаление item в списке;
- skeleton-to-content;
- drag interaction;
- focus на важном изменении;
- shared element transition.

Плохие сценарии:

- анимация каждого блока dashboard;
- задержка критичных действий;
- слишком долгие page transitions;
- motion без учета reduced motion;
- анимации, мешающие чтению.

## Производительность

Лучше анимировать:

- `transform`;
- `opacity`.

Осторожнее с:

- `width`;
- `height`;
- `top`;
- `left`;
- box-shadow на больших элементах;
- filter blur.

Motion умеет layout animations, но это не значит, что любая layout-анимация бесплатна.

## Motion и React render

Motion может обновлять анимацию без постоянных React rerenders. Но если ты меняешь React state на каждый кадр, можно получить проблемы.

Плохой подход:

```tsx
onUpdate={(latest) => setX(latest.x)}
```

Если значение нужно только для анимации, лучше использовать Motion values.

## Частые вопросы

### Чем CSS transition отличается от Motion?

CSS transition хорош для простых hover/focus. Motion удобнее для React-driven states, mounting/unmounting, variants, gestures, layout animations и orchestration.

### Что такое variants?

Именованные состояния анимации, которые можно переиспользовать и передавать от parent к children.

### Зачем AnimatePresence?

Чтобы компонент успел проиграть exit animation перед удалением из React-дерева.

### Что важно для accessibility?

Учитывать `prefers-reduced-motion`, не делать анимацию единственным способом передачи смысла и не ломать keyboard navigation.

## Что отвечать на собеседовании?

Motion - инструмент декларативных анимаций для React. Важно знать `motion` components, variants, gestures, `AnimatePresence`, layout animations и reduced motion. Хороший разработчик объясняет не только "как анимировать", но и зачем эта анимация улучшает UX.

## Мини-шпаргалка

- Анимируй `transform` и `opacity`.
- CSS transition достаточно для простого hover.
- Motion силен в mount/unmount и layout transitions.
- `AnimatePresence` требует stable `key`.
- Reduced motion обязателен для accessibility.
- Анимация не должна блокировать задачу пользователя.
