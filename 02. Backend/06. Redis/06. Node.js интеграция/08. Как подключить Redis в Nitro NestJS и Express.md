# Как подключить Redis в Nitro, NestJS и Express?

> [!NOTE]
> Framework меняет место подключения и lifecycle, но Redis-паттерны остаются теми же: singleton client, env config, error listener, graceful shutdown и отдельное соединение для Pub/Sub.

## Общий client module

```ts
// src/redis.ts
import { createClient } from 'redis';

export const redis = createClient({
  url: process.env.REDIS_URL,
});

redis.on('error', (error) => {
  console.error('Redis error', error);
});

export async function connectRedis() {
  if (!redis.isOpen) {
    await redis.connect();
  }
}
```

## Express

```ts
await connectRedis();

app.get('/api/health/redis', async (_req, res) => {
  const pong = await redis.ping();
  res.json({
    redis: pong,
  });
});
```

## Nitro

```ts
// server/plugins/redis.ts
import { definePlugin } from 'nitro';
import { connectRedis } from '../utils/redis';

export default definePlugin(async () => {
  await connectRedis();
});
```

Route:

```ts
import { defineHandler } from 'nitro';
import { redis } from '../server/utils/redis';

export default defineHandler(async () => {
  return {
    redis: await redis.ping(),
  };
});
```

## NestJS

```ts
@Injectable()
export class RedisService implements OnModuleInit, OnModuleDestroy {
  readonly client = createClient({
    url: process.env.REDIS_URL,
  });

  async onModuleInit() {
    this.client.on('error', console.error);
    await this.client.connect();
  }

  async onModuleDestroy() {
    await this.client.quit();
  }
}
```

## Health checks

```ts
export async function redisHealth() {
  try {
    return await redis.ping();
  } catch {
    return 'DOWN';
  }
}
```

Не делай health check слишком тяжелым. `PING` обычно достаточно.

## Мини-шпаргалка

- Express: подключайся до `listen`.
- Nitro: удобно через plugin.
- NestJS: service + lifecycle hooks.
- Для Pub/Sub нужен duplicate client.
- Health endpoint должен быть дешевым.
