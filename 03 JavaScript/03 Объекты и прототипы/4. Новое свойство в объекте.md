# Новое свойство в объекте

> [!summary] Коротко
> Новое свойство добавляют через точку, квадратные скобки или сразу в объектном литерале. Скобки нужны для динамических и сложных ключей.

## Вопрос

Как добавить новое свойство в объект?

## Через точку

```javascript
const user = {};

user.name = "Anna";

console.log(user); // { name: "Anna" }
```

Точка подходит, если имя свойства известно заранее и является валидным идентификатором.

## Через квадратные скобки

```javascript
const user = {};
const key = "email";

user[key] = "anna@example.com";

console.log(user.email); // "anna@example.com"
```

Скобки нужны для динамических ключей.

## Сложные ключи

```javascript
const obj = {};

obj["user-name"] = "Anna";
obj["first name"] = "Anna";
```

Через точку так нельзя:

```javascript
obj.user-name; // ошибка смысла: JS прочитает как obj.user - name
```

## В литерале

```javascript
const name = "Anna";

const user = {
  name,
  age: 25,
};
```

Можно использовать вычисляемые свойства:

```javascript
const key = "role";

const user = {
  name: "Anna",
  [key]: "admin",
};
```

## Мини-шпаргалка

```javascript
obj.name = "Anna";       // обычный ключ
obj["name"] = "Anna";    // строковый ключ
obj[key] = value;        // динамический ключ
const obj = { [key]: value }; // вычисляемый ключ
```
