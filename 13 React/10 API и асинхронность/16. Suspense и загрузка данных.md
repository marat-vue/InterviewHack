# Suspense и загрузка данных

> [!summary]
> Suspense может управлять loading UI для загрузки данных, но только если источник данных умеет "suspend": интегрирован с React, фреймворком или кешем. Обычный `fetch` в `useEffect` сам по себе Suspense не активирует.

## Без Suspense

```jsx
function Profile() {
  const [user, setUser] = useState(null)
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    fetchUser()
      .then(setUser)
      .finally(() => setIsLoading(false))
  }, [])

  if (isLoading) return <ProfileSkeleton />

  return <ProfileView user={user} />
}
```

Компонент сам управляет loading.

## С Suspense-enabled источником

```jsx
function Profile() {
  const user = useUserSuspense()

  return <ProfileView user={user} />
}

function App() {
  return (
    <Suspense fallback={<ProfileSkeleton />}>
      <Profile />
    </Suspense>
  )
}
```

Компонент `Profile` рендерится так, будто данные уже готовы. Loading UI вынесен в Suspense boundary.

## React Query и Suspense

В TanStack Query есть отдельные Suspense API/режимы.

```jsx
function Profile({ userId }) {
  const { data } = useSuspenseQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
  })

  return <ProfileView user={data} />
}
```

```jsx
<ErrorBoundary fallback={<ErrorFallback />}>
  <Suspense fallback={<ProfileSkeleton />}>
    <Profile userId={userId} />
  </Suspense>
</ErrorBoundary>
```

Suspense покрывает loading, Error Boundary покрывает ошибку.

## Где Suspense особенно полезен?

- route-level data loading;
- streaming SSR;
- server frameworks;
- lazy components;
- независимые зоны загрузки;
- постепенное раскрытие страницы.

## Важные ограничения

- Не все библиотеки data fetching одинаково поддерживают Suspense.
- Для ошибок нужен Error Boundary.
- Слишком крупная Suspense boundary может скрыть всю страницу.
- Слишком мелкая boundary может создать хаотичный UX.
- Для старого кода на `useEffect` не надо механически переписывать все на Suspense.

## Мини-шпаргалка

- Suspense для данных требует Suspense-enabled источника.
- Обычный `fetch` в effect не включает Suspense.
- Loading UI задается через `fallback`.
- Error UI задается через Error Boundary.
- Boundaries нужно ставить вокруг смысловых частей UI.
