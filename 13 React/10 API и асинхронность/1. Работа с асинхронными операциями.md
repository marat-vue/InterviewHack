# Работа с асинхронными операциями

> [!summary]
> React сам по себе синхронно вычисляет UI из state и props, а асинхронные операции живут во внешнем мире: HTTP-запросы, таймеры, подписки, WebSocket, IndexedDB. Их результат обычно сохраняют в state, query cache или store, после чего React делает новый render.

## Какие async-операции встречаются в React?

- `fetch` к API;
- отправка формы;
- debounce/throttle;
- `setTimeout` и `setInterval`;
- WebSocket/SSE;
- чтение из IndexedDB;
- lazy loading компонентов;
- загрузка файлов;
- server state через TanStack Query/SWR.

## Базовый подход через useEffect

```jsx
function UserCard({ userId }) {
  const [user, setUser] = useState(null)
  const [isLoading, setIsLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    const controller = new AbortController()

    async function loadUser() {
      try {
        setIsLoading(true)
        setError(null)

        const response = await fetch(`/api/users/${userId}`, {
          signal: controller.signal,
        })

        if (!response.ok) {
          throw new Error('Failed to load user')
        }

        const data = await response.json()
        setUser(data)
      } catch (error) {
        if (error.name !== 'AbortError') {
          setError(error)
        }
      } finally {
        setIsLoading(false)
      }
    }

    loadUser()

    return () => controller.abort()
  }, [userId])

  if (isLoading) return <UserSkeleton />
  if (error) return <ErrorMessage error={error} />

  return <h2>{user.name}</h2>
}
```

## Почему запрос не делают прямо в render?

Render должен быть чистым:

```jsx
function UserCard() {
  fetch('/api/user') // плохо

  return <div />
}
```

React может вызывать render много раз, прерывать его или повторять в Strict Mode. Side effects в render приводят к повторным запросам, гонкам и непредсказуемому UI.

## Server state лучше отделять

Данные с сервера имеют собственные состояния:

```text
idle/loading/success/error/stale/refetching
```

Поэтому в продакшене часто используют TanStack Query, SWR или фреймворковые loaders.

```jsx
function UserCard({ userId }) {
  const { data, isLoading, error } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
  })

  if (isLoading) return <UserSkeleton />
  if (error) return <ErrorMessage error={error} />

  return <h2>{data.name}</h2>
}
```

## Мини-шпаргалка

- Async-операция обычно обновляет state или cache.
- Render должен оставаться чистым.
- `useEffect` подходит для синхронизации с внешним миром.
- Запросы нужно отменять или игнорировать при cleanup.
- Для server state в реальных проектах часто лучше query-библиотека.
