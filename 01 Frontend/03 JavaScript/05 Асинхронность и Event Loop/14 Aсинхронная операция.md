# Aсинхронная операция

> [!NOTE] Коротко
> Асинхронная операция стартует сейчас, завершается позже и не блокирует основной поток ожиданием результата.

## Вопрос

Что такое асинхронная операция в JavaScript?

## Определение

Асинхронная операция - это действие, результат которого будет доступен не сразу. JavaScript запускает такую операцию, продолжает выполнять код дальше, а результат обрабатывает позже.

Обычно завершение асинхронной операции приходит через callback, событие, промис или `await`.

## Пример с таймером

```javascript
console.log('before');

setTimeout(() => {
  console.log('inside timeout');
}, 1000);

console.log('after');

// before
// after
// inside timeout
```

Таймер запускается, но программа не ждет одну секунду на месте.

## Пример с fetch

```javascript
async function loadUser() {
  const response = await fetch('/api/user');
  const user = await response.json();

  return user;
}
```

Запрос к серверу выполняется асинхронно, а код после `await` продолжится, когда промис завершится.

## Типичные асинхронные операции

- сетевой запрос;
- таймер;
- чтение файла в Node.js;
- пользовательское событие;
- WebSocket-сообщение;
- работа Worker-потока.

## Мини-шпаргалка

```javascript
setTimeout(callback, delay);
fetch(url).then(callback);
const data = await promise;
```
