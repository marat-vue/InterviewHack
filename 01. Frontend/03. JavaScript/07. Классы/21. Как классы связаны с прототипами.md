# Как классы связаны с прототипами?

> [!NOTE]
> Классы в JavaScript используют прототипы: методы класса попадают в `ClassName.prototype`.

## Вопрос

Как `class` связан с прототипной моделью JavaScript?

## Определение

Класс в JavaScript - синтаксис поверх прототипов. Когда ты объявляешь метод внутри класса, этот метод сохраняется в прототипе класса, а экземпляры находят его через цепочку прототипов.

## Пример

```javascript
class User {
  sayHi() {
    return 'Hi';
  }
}

const user = new User();

console.log(User.prototype.sayHi); // function
console.log(user.sayHi === User.prototype.sayHi); // true
```

Метод `sayHi` не копируется в каждый объект.

## Цепочка прототипов

```javascript
console.log(Object.getPrototypeOf(user) === User.prototype); // true
```

Когда вызывается `user.sayHi()`, движок сначала ищет `sayHi` в самом объекте, затем в `User.prototype`.

## Наследование

```javascript
class Admin extends User {}

const admin = new Admin();

console.log(admin.sayHi()); // 'Hi'
```

`extends` связывает прототипы так, чтобы экземпляр `Admin` мог находить методы `User`.

## Важный вывод

`class` не отменяет прототипы. Он делает работу с ними понятнее: конструктор, методы, наследование и `super` записываются более компактно.

## Мини-шпаргалка

```javascript
class A {
  method() {}
}

A.prototype.method; // метод класса
```
