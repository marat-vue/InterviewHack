# Что такое CLS и как его улучшать?

> [!summary]
> CLS, Cumulative Layout Shift, измеряет неожиданные сдвиги layout. Пользователь страдает, когда текст, кнопки, изображения или реклама внезапно прыгают во время загрузки.

## Пример плохого CLS

```text
Пользователь собирается нажать "Купить"
Реклама загружается сверху
Кнопка сдвигается
Пользователь нажимает не туда
```

Это плохой UX и сигнал нестабильной страницы.

## Почему возникают сдвиги?

- У изображений нет размеров.
- Видео или iframe вставляются без reserved space.
- Реклама загружается в блок без высоты.
- Шрифты вызывают заметный reflow.
- Контент добавляется над уже видимым контентом.
- Skeleton и финальный layout имеют разные размеры.

## Как улучшать CLS?

```html
<img
  src="/product.webp"
  alt="Рюкзак для ноутбука"
  width="800"
  height="600"
>
```

Практики:

- задавать размеры изображений и видео;
- резервировать место под рекламу;
- использовать `aspect-ratio`;
- аккуратно подключать шрифты;
- не вставлять баннеры над контентом без действия пользователя;
- делать skeleton такого же размера, как финальный контент.

## Пример с aspect-ratio

```css
.product-image {
  aspect-ratio: 4 / 3;
  width: 100%;
  object-fit: cover;
}
```

## Мини-шпаргалка

- CLS - про неожиданные сдвиги.
- Размеры медиа нужно задавать заранее.
- Skeleton не должен менять layout при загрузке.
- Реклама и iframe требуют зарезервированного места.
- Визуальная стабильность важна для доверия.
