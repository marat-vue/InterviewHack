# Что делает элемент audio?

> [!NOTE]
> Элемент `<audio>` встраивает аудио на страницу. Он может показывать нативные элементы управления, использовать несколько источников и поддерживать fallback-текст.

## Главное

```html
<audio controls src="/audio/lesson.mp3">
  Ваш браузер не поддерживает аудио.
</audio>
```

Атрибут `controls` включает нативный интерфейс: воспроизведение, пауза, громкость и прогресс.

## Несколько источников

```html
<audio controls>
  <source src="/audio/lesson.webm" type="audio/webm">
  <source src="/audio/lesson.mp3" type="audio/mpeg">
  Ваш браузер не поддерживает аудио.
</audio>
```

Браузер выберет первый формат, который умеет воспроизводить.

## Частые атрибуты

| Атрибут | Назначение |
| --- | --- |
| `controls` | Показывает панель управления |
| `autoplay` | Пытается запустить автоматически |
| `loop` | Повторяет аудио |
| `muted` | Запускает без звука |
| `preload` | Подсказывает стратегию предварительной загрузки |
| `src` | Указывает файл |

## preload

```html
<audio controls preload="metadata" src="/podcast.mp3"></audio>
```

Значения:

- `none` - не загружать заранее;
- `metadata` - загрузить только метаданные;
- `auto` - браузер может загрузить файл заранее.

## Accessibility

Для важного аудио полезно дать текстовую альтернативу: расшифровку, описание или ссылку на текстовую версию.

```html
<p>
  <a href="/transcript.html">Открыть текстовую расшифровку</a>
</p>
```

## Мини-шпаргалка

- `<audio>` встраивает аудио.
- `controls` показывает управление.
- Через `<source>` можно дать несколько форматов.
- `preload` управляет предварительной загрузкой.
- Автовоспроизведение часто блокируется браузером.
- Для важного аудио нужна текстовая альтернатива.
