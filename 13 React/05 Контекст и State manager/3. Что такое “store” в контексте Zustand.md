# Что такое store в контексте Zustand?

> [!summary]
> Store в Zustand - это внешнее хранилище состояния и actions. В React-версии store обычно создается через `create` и возвращается как hook, который компоненты используют для чтения и обновления состояния.

## Из чего состоит store?

Store может содержать:

- данные;
- actions для изменения данных;
- derived helpers;
- async actions;
- reset actions;
- slices.

Пример:

```jsx
const useCartStore = create((set, get) => ({
  items: [],
  addItem: (product) =>
    set((state) => ({
      items: [...state.items, product],
    })),
  clearCart: () => set({ items: [] }),
  getTotal: () =>
    get().items.reduce((sum, item) => sum + item.price, 0),
}))
```

## Что делают set и get?

`set` обновляет store:

```jsx
set({ isOpen: true })
```

Или на основе предыдущего состояния:

```jsx
set((state) => ({ count: state.count + 1 }))
```

`get` читает текущее состояние внутри actions:

```jsx
const total = get().items.length
```

## Store hook

```jsx
const count = useCounterStore((state) => state.count)
```

Компонент подписывается на выбранное значение. Если selector вернет новое значение, компонент может перерендериться.

## Где хранить store?

Обычно store выносят в отдельный файл:

```text
src/shared/store/useCartStore.ts
src/features/cart/model/cart.store.ts
```

Структура зависит от архитектуры проекта. Главное - не превращать один store в свалку всего приложения.

## Мини-шпаргалка

- Store хранит state и actions.
- `create` создает Zustand store hook.
- `set` обновляет состояние.
- `get` читает текущее состояние внутри actions.
- Компоненты читают store через selectors.
