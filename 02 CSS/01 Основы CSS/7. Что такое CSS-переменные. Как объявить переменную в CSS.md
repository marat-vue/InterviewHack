# Что такое CSS-переменные. Как объявить переменную в CSS

> [!summary]
> **CSS-переменные** или custom properties - это именованные значения, которые можно объявить в CSS и переиспользовать через функцию `var()`.

## Главное

CSS-переменная начинается с двух дефисов.

```css
:root {
  --color-primary: #2563eb;
  --space-md: 16px;
}

.button {
  padding: var(--space-md);
  background: var(--color-primary);
}
```

`:root` часто используют для глобальных переменных.

## Локальные переменные

Переменную можно объявить внутри конкретного блока.

```css
.alert {
  --alert-color: #b91c1c;

  border-color: var(--alert-color);
  color: var(--alert-color);
}
```

Такая переменная доступна элементу и его потомкам.

## Fallback

`var()` может иметь запасное значение.

```css
.card {
  border-radius: var(--radius-md, 8px);
}
```

Если `--radius-md` не объявлена, будет использовано `8px`.

## Темизация

```css
:root {
  --page-bg: white;
  --text-color: #111827;
}

[data-theme="dark"] {
  --page-bg: #111827;
  --text-color: white;
}

body {
  background: var(--page-bg);
  color: var(--text-color);
}
```

CSS-переменные отлично подходят для тем, дизайн-токенов и переиспользуемых значений.

## Мини-шпаргалка

- CSS-переменная начинается с `--`.
- Читать значение нужно через `var(--name)`.
- `:root` используют для глобальных токенов.
- Переменные наследуются.
- В `var()` можно указать fallback.
- CSS-переменные полезны для темизации.
