## Что обязательно покрыто?

- Redis как in-memory data store, cache, broker-like инструмент и coordination layer.
- Команды ключей, TTL и безопасный обход keyspace через `SCAN`.
- Все основные структуры данных и когда выбирать каждую.
- Cache patterns: cache-aside, write-through, write-behind, refresh-ahead, negative cache.
- Atomicity: single-command atomicity, `MULTI`/`EXEC`, `WATCH`, Lua scripts.
- Pub/Sub и Streams, включая consumer groups, acknowledgements и pending entries.
- Node.js интеграция: подключение, reconnect, lifecycle, ошибки, production wrappers.
- Persistence: RDB, AOF, fsync, recovery и риски потери данных.
- Replication, Sentinel, Cluster, sharding и trade-offs.
- Security: ACL, key patterns, command categories, TLS, protected mode, secrets.
- Observability: `INFO`, `SLOWLOG`, latency, memory, hit ratio, eviction metrics.

## Как проверять актуальность?

1. Для синтаксиса команд сверяй конкретную команду в [Redis Commands](https://redis.io/docs/latest/commands/).
2. Для production-настроек проверяй раздел [Operate Redis](https://redis.io/docs/latest/operate/).
3. Для Node.js примеров сверяйся с [Redis Node.js Client Guide](https://redis.io/docs/latest/develop/clients/nodejs/), потому что API клиента развивается отдельно от сервера Redis.
4. Для Streams дополнительно проверяй команды `XADD`, `XREADGROUP`, `XACK`, `XPENDING`, `XAUTOCLAIM` и `XTRIM`.
