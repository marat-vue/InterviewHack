# Основные классы и возможности Tailwind

> [!summary]
> В Tailwind важно знать группы utilities: layout, flex/grid, spacing, sizing, typography, colors, borders, effects, transitions, responsive variants и state variants.

## Layout

```tsx
<section className="mx-auto max-w-5xl px-4">
  <div className="grid gap-4 md:grid-cols-3">
    <Card />
    <Card />
    <Card />
  </div>
</section>
```

Частые classes:

| Группа | Примеры |
|---|---|
| display | `block`, `inline-flex`, `grid`, `hidden` |
| position | `relative`, `absolute`, `fixed`, `sticky` |
| sizing | `w-full`, `h-screen`, `max-w-4xl`, `min-h-screen` |
| overflow | `overflow-hidden`, `overflow-auto` |

## Spacing

```tsx
<div className="space-y-4 p-6">
  <h2 className="mb-2">Title</h2>
  <p>Text</p>
</div>
```

Популярные:

- `p-4`, `px-6`, `py-2`;
- `m-4`, `mt-2`, `mb-8`;
- `gap-4`;
- `space-y-3`.

## Flex и Grid

```tsx
<div className="flex items-center justify-between gap-3">
  <span>Profile</span>
  <button>Logout</button>
</div>
```

```tsx
<div className="grid grid-cols-1 gap-4 md:grid-cols-2 xl:grid-cols-4">
  {items.map((item) => <Card key={item.id} item={item} />)}
</div>
```

## Typography

```tsx
<h1 className="text-3xl font-semibold tracking-normal text-zinc-950">
  Dashboard
</h1>
<p className="mt-2 text-sm leading-6 text-zinc-600">
  Account summary
</p>
```

Частые classes:

- `text-sm`, `text-lg`, `text-3xl`;
- `font-medium`, `font-semibold`, `font-bold`;
- `leading-6`;
- `text-zinc-600`;
- `text-center`.

## States

```tsx
<button className="rounded-md bg-blue-600 px-4 py-2 text-white hover:bg-blue-700 focus:outline-none focus:ring-2 focus:ring-blue-500 disabled:opacity-50">
  Save
</button>
```

Частые variants:

- `hover:`;
- `focus:`;
- `focus-visible:`;
- `active:`;
- `disabled:`;
- `group-hover:`;
- `peer-checked:`.

## Responsive

```tsx
<aside className="hidden w-64 border-r md:block">
  Sidebar
</aside>
```

Tailwind responsive classes mobile-first:

```tsx
className="grid grid-cols-1 md:grid-cols-2 xl:grid-cols-4"
```

База применяется на всех размерах, `md:` - начиная с breakpoint.

## Что отвечать на собеседовании?

Основная сила Tailwind - композиция utilities и variants. Нужно знать layout, spacing, typography, colors, flex/grid, responsive prefixes и state prefixes. Tailwind mobile-first: классы без prefix работают всегда, а `md:` и выше переопределяют их на больших экранах.

## Мини-шпаргалка

- `mx-auto max-w-5xl px-4` - контейнер.
- `flex items-center justify-between`.
- `grid gap-4 md:grid-cols-3`.
- `text-sm font-medium text-zinc-700`.
- `hover:bg-blue-700`.
- `disabled:opacity-50`.
