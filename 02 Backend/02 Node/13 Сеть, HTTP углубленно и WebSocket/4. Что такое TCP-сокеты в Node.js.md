# Что такое TCP-сокеты в Node.js?

> [!summary]
> TCP-сокет - двустороннее stream-соединение между клиентом и сервером. В Node.js с TCP работают через встроенный модуль `node:net`, который лежит ниже HTTP.

## TCP ниже HTTP

HTTP обычно работает поверх TCP. Если HTTP дает запросы и ответы, то TCP дает поток байтов.

```txt
HTTP message -> TCP stream -> network
```

## TCP-сервер

```js
import net from 'node:net';

const server = net.createServer((socket) => {
  socket.write('Привет\n');

  socket.on('data', (chunk) => {
    socket.write(`echo: ${chunk}`);
  });
});

server.listen(4000);
```

## TCP-клиент

```js
import net from 'node:net';

const socket = net.createConnection({ port: 4000 }, () => {
  socket.write('hello');
});

socket.on('data', (chunk) => {
  console.log(chunk.toString());
});
```

## Где это встречается?

- базы данных;
- брокеры сообщений;
- Redis protocol;
- внутренние протоколы;
- прокси;
- WebSocket upgrade начинается как HTTP, но дальше работает как постоянное соединение.

## Мини-шпаргалка

- `node:net` работает с TCP и IPC.
- TCP socket - duplex stream.
- TCP передает байты, а не готовые JSON-объекты.
- Нужно самому определять формат сообщений.
- HTTP находится уровнем выше TCP.
