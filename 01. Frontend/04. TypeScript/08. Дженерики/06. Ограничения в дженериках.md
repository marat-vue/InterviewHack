# Ограничения в дженериках

> [!NOTE]
> Ограничения в generics задают через `extends`: `T extends SomeType`. Это говорит TypeScript, что generic может быть не любым, а только подходящим под указанную форму.

## Вопрос

Что такое ограничения в дженериках?

## Зачем нужны ограничения

Без ограничения TypeScript почти ничего не знает о `T`.

```typescript
function getLength<T>(value: T): number {
  // return value.length; // ошибка
  return 0;
}
```

Чтобы использовать `.length`, нужно ограничить тип.

```typescript
function getLength<T extends { length: number }>(value: T): number {
  return value.length;
}

getLength("hello");
getLength([1, 2, 3]);
// getLength(10); // ошибка
```

## Ограничение ключами объекта

```typescript
function getProperty<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}
```

`K` может быть только ключом объекта `T`, поэтому результат получается точным.

## Ограничение union-ом

```typescript
type Id = string | number;

function normalizeId<T extends Id>(id: T): string {
  return String(id);
}
```

## Мини-шпаргалка

- `T extends X` ограничивает generic.
- Ограничение дает доступ к свойствам `X`.
- `K extends keyof T` - типичный способ безопасно брать поля.
- `extends` в generic не равно наследованию класса, это проверка совместимости.
