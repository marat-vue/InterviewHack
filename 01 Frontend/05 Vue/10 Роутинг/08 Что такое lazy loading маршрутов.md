# Что такое lazy loading маршрутов?

> [!NOTE] Коротко
> Lazy loading маршрутов означает, что компонент страницы загружается только при переходе на этот маршрут, а не попадает в начальный bundle.

## Вопрос

Что такое lazy loading маршрутов?

## Базовый пример

```typescript
const routes = [
  {
    path: "/settings",
    component: () => import("./pages/SettingsPage.vue"),
  },
];
```

Сборщик создаст отдельный chunk для `SettingsPage`.

## Зачем это нужно

Если приложение большое, пользователь не должен загружать код всех страниц при первом открытии. Lazy loading уменьшает начальную загрузку.

## С именованным маршрутом

```typescript
{
  path: "/users/:id",
  name: "user",
  component: () => import("./pages/UserPage.vue"),
}
```

Компонент загрузится при первом переходе на страницу пользователя.

## Loading state

Для обычных маршрутов загрузка chunk обычно быстрая. Если нужен сложный loading/error UI, его можно решать на уровне layout, Suspense или данных страницы.

## Мини-шпаргалка

- Lazy route: `component: () => import(...)`.
- Уменьшает начальный bundle.
- Особенно полезен для редких и тяжелых страниц.
- Хорошо сочетается с code splitting сборщика.
