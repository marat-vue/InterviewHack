# Что такое Vue Router

> [!summary] Коротко
> Vue Router - официальный роутер для Vue, который связывает URL приложения с компонентами страниц и позволяет строить SPA-навигацию без полной перезагрузки.

## Вопрос

Что такое Vue Router?

## Базовая настройка

```typescript
import { createRouter, createWebHistory } from "vue-router";

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: "/", component: HomePage },
    { path: "/users", component: UsersPage },
  ],
});
```

Роутер описывает, какой компонент показать для конкретного пути.

## Подключение

```typescript
import { createApp } from "vue";

createApp(App).use(router).mount("#app");
```

## Отображение страницы

```vue
<template>
  <RouterView />
</template>
```

`RouterView` показывает компонент текущего маршрута.

## Ссылки

```vue
<RouterLink to="/users">Пользователи</RouterLink>
```

`RouterLink` переключает маршрут без полной перезагрузки страницы.

## Мини-шпаргалка

- Vue Router управляет маршрутами SPA.
- `routes` связывает `path` и компонент.
- `RouterView` показывает текущую страницу.
- `RouterLink` нужен для навигации в шаблоне.
