# Пересечение типов

> [!NOTE]
> Intersection type `A & B` требует, чтобы значение одновременно соответствовало типу `A` и типу `B`.

## Вопрос

Что такое пересечение типов в TypeScript?

## Определение

Пересечение типов объединяет требования нескольких типов. Если написать `A & B`, итоговое значение должно иметь все свойства, которые нужны и `A`, и `B`.

## Пример

```typescript
type WithId = {
  id: number;
};

type WithName = {
  name: string;
};

type User = WithId & WithName;

const user: User = {
  id: 1,
  name: 'Ann',
};
```

`User` требует и `id`, и `name`.

## Пересечение с дополнительными полями

```typescript
type Admin = User & {
  permissions: string[];
};
```

Так удобно расширять объектные типы.

## Конфликт свойств

```typescript
type A = { id: number };
type B = { id: string };

type C = A & B;
```

Поле `id` в `C` станет невозможным типом `never`, потому что значение не может быть одновременно `number` и `string`.

## Intersection vs extends

```typescript
interface User extends WithId {
  name: string;
}

type User2 = WithId & {
  name: string;
};
```

Оба подхода могут описывать расширение объектной формы.

## Мини-шпаргалка

```typescript
type Combined = A & B;
```
