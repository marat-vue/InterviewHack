# Как работать с DOM в React?

> [!summary]
> В React обычно не нужно вручную менять DOM: интерфейс должен быть результатом props и state. Но иногда прямой доступ к DOM нужен для фокуса, измерений, управления медиа, canvas или интеграции со сторонними библиотеками. Для этого используют `ref`.

## Почему не стоит часто трогать DOM вручную?

Плохой подход:

```jsx
function Alert({ visible }) {
  if (visible) {
    document.querySelector('.alert').classList.add('show')
  }

  return <div className="alert">Готово</div>
}
```

Такой код:

- может выполняться во время render;
- ломает декларативную модель;
- конфликтует с React-обновлениями;
- сложнее тестируется;
- может падать при SSR.

## Декларативный вариант

```jsx
function Alert({ visible }) {
  return (
    <div className={visible ? 'alert show' : 'alert'}>
      Готово
    </div>
  )
}
```

Здесь DOM меняется через JSX и state/props.

## Когда нужен ref?

Пример с фокусом:

```jsx
import { useRef } from 'react'

function SearchForm() {
  const inputRef = useRef(null)

  function focusInput() {
    inputRef.current?.focus()
  }

  return (
    <>
      <input ref={inputRef} />
      <button onClick={focusInput}>Фокус</button>
    </>
  )
}
```

`ref.current` хранит DOM-элемент после commit.

## Для чего еще используют ref?

- `scrollIntoView`;
- измерение размеров через `getBoundingClientRect`;
- управление `video.play()`;
- canvas;
- интеграция с картами, графиками, редакторами;
- хранение mutable-значения, которое не должно вызывать render.

## Важное правило

Не читай и не меняй DOM в render:

```jsx
function Component() {
  // плохо
  const width = document.body.clientWidth

  return <div>{width}</div>
}
```

Для DOM-эффектов используй event handlers, `useEffect` или `useLayoutEffect`, если нужно измерение до отрисовки кадра.

## Мини-шпаргалка

- В React DOM обычно меняют декларативно через JSX.
- `ref` нужен для точечного доступа к DOM.
- `ref.current` доступен после commit.
- Не используй `querySelector` как основной способ управления UI.
- Для SSR нельзя полагаться на `window` и `document` во время render.
