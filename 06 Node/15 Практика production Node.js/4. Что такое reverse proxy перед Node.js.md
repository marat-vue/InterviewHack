# Что такое reverse proxy перед Node.js?

> [!summary]
> Reverse proxy принимает внешний трафик и передает его Node.js-приложению. Он может завершать TLS, отдавать статику, балансировать нагрузку, ограничивать запросы и скрывать внутреннюю структуру сервисов.

## Типичная схема

```txt
internet -> reverse proxy -> Node.js app
```

Примеры reverse proxy:

- Nginx;
- Caddy;
- Traefik;
- Envoy;
- cloud load balancer.

## Что делает reverse proxy?

| Возможность | Зачем нужна |
|---|---|
| TLS termination | сертификаты и HTTPS |
| Load balancing | несколько инстансов приложения |
| Static files | отдавать статику без Node.js |
| Rate limiting | защита от спама |
| Compression | сжатие ответов |
| Request size limit | защита от больших payload |

## Важные заголовки

Если приложение стоит за proxy, реальный IP и протокол часто приходят в заголовках:

```txt
X-Forwarded-For
X-Forwarded-Proto
Forwarded
```

Им нельзя доверять, если запрос пришел не от доверенного proxy.

## Мини-шпаргалка

- Reverse proxy стоит перед Node.js.
- Часто именно proxy завершает TLS.
- Proxy может балансировать несколько инстансов.
- Для WebSocket proxy должен поддерживать upgrade.
- Forwarded-заголовкам доверяют только от своего proxy.
