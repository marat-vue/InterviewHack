# Обращение к несуществующему индексу

> [!summary] Коротко
> Если обратиться к индексу массива, которого нет, JavaScript вернет `undefined`. Ошибки не будет, потому что массивы в JS работают как объекты со свойствами-индексами.

## Вопрос

Что произойдет при обращении к несуществующему индексу?

## Пример

```javascript
const arr = ["a", "b"];

arr[10]; // undefined
```

Такое чтение безопасно: JavaScript просто не нашел свойства `"10"`.

## Не путать с вложенным доступом

```javascript
const arr = ["a", "b"];

arr[10].length; // TypeError
```

`arr[10]` вернул `undefined`, а у `undefined` нельзя читать `.length`.

Безопаснее:

```javascript
arr[10]?.length; // undefined
```

## Индекс существует, но значение `undefined`

```javascript
const arr = [undefined];

arr[0]; // undefined
arr[5]; // undefined
```

Результат одинаковый, но смысл разный. Проверить наличие индекса можно через `in`.

```javascript
0 in arr; // true
5 in arr; // false
```

## Пустой слот

```javascript
const arr = [];
arr.length = 3;

arr[0];   // undefined
0 in arr; // false
```

Пустой слот при чтении тоже дает `undefined`, но элемента там нет.

## Мини-шпаргалка

| Код | Результат |
| --- | --- |
| `arr[100]` | `undefined` |
| `arr[100].x` | `TypeError` |
| `arr[100]?.x` | `undefined` |
| `index in arr` | проверяет наличие индекса |
| `arr.at(-1)` | последний элемент |
