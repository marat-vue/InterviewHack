# Как работают composables и utils auto imports?

> [!summary]
> Nuxt автоматически импортирует composables из `app/composables` и utilities из `app/utils`. Composables обычно содержат Vue-реактивность и начинаются с `use`, а utils лучше держать как обычные pure functions.

## Composable

```ts
// app/composables/useCart.ts
export function useCart() {
  const items = useState('cart:items', () => []);

  function addItem(item: CartItem) {
    items.value.push(item);
  }

  return {
    items,
    addItem,
  };
}
```

Использование без import:

```vue
<script setup lang="ts">
const { items, addItem } = useCart();
</script>
```

## Utility

```ts
// app/utils/formatPrice.ts
export function formatPrice(value: number) {
  return new Intl.NumberFormat('ru-RU', {
    style: 'currency',
    currency: 'RUB',
  }).format(value);
}
```

Использование:

```vue
<template>
  <span>{{ formatPrice(1200) }}</span>
</template>
```

## Composable или util?

| Нужно | Выбери |
|---|---|
| `ref`, `computed`, `useState`, lifecycle | composable |
| pure function без Vue context | util |
| доступ к Nuxt app context | composable |
| форматирование строки | util |

## Важное ограничение

Composables, которые используют Nuxt context, нужно вызывать в правильном месте:

- setup;
- plugin;
- middleware;
- другой composable.

Не вызывай их произвольно в обычном module scope.

## Мини-шпаргалка

- `app/composables` auto-imported.
- `app/utils` auto-imported.
- Composable обычно начинается с `use`.
- Utils лучше держать чистыми функциями.
- Nuxt context доступен не в любом месте.
