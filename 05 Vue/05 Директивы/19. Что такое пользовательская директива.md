# Что такое пользовательская директива

> [!summary] Коротко
> Пользовательская директива - собственная директива Vue для низкоуровневой работы с DOM, когда обычных props, компонентов и composables недостаточно.

## Вопрос

Что такое пользовательская директива?

## Базовый пример

```typescript
const vFocus = {
  mounted(element: HTMLElement) {
    element.focus();
  },
};
```

```vue
<script setup>
const vFocus = {
  mounted(element: HTMLElement) {
    element.focus();
  },
};
</script>

<template>
  <input v-focus />
</template>
```

В `<script setup>` локальная директива должна называться с префиксом `v`, например `vFocus`, а в шаблоне используется как `v-focus`.

## Глобальная регистрация

```typescript
app.directive("focus", {
  mounted(element) {
    element.focus();
  },
});
```

## Хуки директивы

```typescript
const vHighlight = {
  mounted(element: HTMLElement) {
    element.style.background = "yellow";
  },
  updated(element: HTMLElement, binding: { value: string }) {
    element.style.background = binding.value;
  },
};
```

## Когда использовать

Пользовательские директивы подходят для focus, click outside, интеграции с DOM-библиотекой, измерений, масок ввода. Если задача описывает UI-структуру, чаще лучше компонент.

## Мини-шпаргалка

- Custom directive нужна для прямой работы с DOM.
- Локальная директива в `<script setup>`: `const vName = ...`.
- В шаблоне используется kebab-case: `v-name`.
- Не заменяй директивами обычные компоненты и props.
