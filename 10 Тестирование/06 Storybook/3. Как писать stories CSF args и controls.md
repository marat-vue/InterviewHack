# Как писать stories, CSF, args и controls?

> [!summary]
> Storybook stories чаще пишут в формате CSF: default export описывает компонент, named exports описывают состояния. `args` задают входные данные story, а controls позволяют менять их прямо в интерфейсе Storybook.

## Что такое CSF?

CSF означает Component Story Format. Это обычный TypeScript/JavaScript-файл, где stories экспортируются как объекты.

```ts
import type { Meta, StoryObj } from '@storybook/vue3-vite';
import BaseButton from './BaseButton.vue';

const meta = {
  component: BaseButton,
  title: 'Components/BaseButton',
} satisfies Meta<typeof BaseButton>;

export default meta;

type Story = StoryObj<typeof meta>;
```

## Args

`args` - входные данные story:

```ts
export const Primary: Story = {
  args: {
    label: 'Сохранить',
    variant: 'primary',
    disabled: false,
  },
};
```

Они часто соответствуют props компонента.

## Несколько состояний

```ts
export const Disabled: Story = {
  args: {
    label: 'Недоступно',
    disabled: true,
  },
};

export const Loading: Story = {
  args: {
    label: 'Сохраняем...',
    loading: true,
  },
};
```

## Controls

Controls позволяют менять args из UI Storybook.

```ts
const meta = {
  component: BaseButton,
  argTypes: {
    variant: {
      control: 'select',
      options: ['primary', 'secondary', 'danger'],
    },
  },
} satisfies Meta<typeof BaseButton>;
```

## Хорошая story

Хорошая story показывает реальное состояние компонента:

- не абстрактный `foo`;
- понятный текст;
- реалистичные данные;
- важные edge cases;
- не слишком много логики внутри story.

## Мини-шпаргалка

- CSF - формат stories через exports.
- Default export описывает meta.
- Named exports описывают состояния.
- `args` задают props/inputs.
- `argTypes` настраивает controls.
- Story должна быть реалистичным примером использования.
