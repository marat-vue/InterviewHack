# Что такое SSR?

> [!summary]
> SSR, или Server-Side Rendering, - это подход, при котором React-дерево рендерится в HTML на сервере, а браузер получает уже готовую разметку. После загрузки JavaScript React выполняет hydration и делает страницу интерактивной.

## Что происходит при SSR?

```text
1. Браузер запрашивает URL
2. Сервер определяет route
3. Сервер загружает данные
4. Сервер рендерит React в HTML
5. Браузер получает и показывает HTML
6. Браузер загружает JavaScript
7. React выполняет hydration
8. Страница становится интерактивной
```

## Пример серверного рендера

```jsx
import { renderToString } from 'react-dom/server'

app.get('*', async (req, res) => {
  const appHtml = renderToString(<App url={req.url} />)

  res.send(`
    <!doctype html>
    <html>
      <head>
        <title>SSR app</title>
      </head>
      <body>
        <div id="root">${appHtml}</div>
        <script src="/client.js"></script>
      </body>
    </html>
  `)
})
```

На клиенте:

```jsx
import { hydrateRoot } from 'react-dom/client'

hydrateRoot(document.getElementById('root'), <App />)
```

## Чем SSR отличается от обычной SPA?

CSR SPA часто отдает почти пустой HTML:

```html
<div id="root"></div>
<script src="/bundle.js"></script>
```

Контент появится только после загрузки и выполнения JavaScript.

SSR сразу отдает HTML с контентом:

```html
<div id="root">
  <main>
    <h1>Product title</h1>
  </main>
</div>
```

## Зачем нужен SSR?

SSR полезен для:

- SEO;
- быстрого показа основного контента;
- Open Graph превью;
- публичных страниц;
- страниц товаров;
- новостей, блогов, документации;
- ситуаций, где пользователю важно увидеть content до полной интерактивности.

## Главный компромисс

SSR переносит часть работы с клиента на сервер.

Ты выигрываешь в первом показе контента и SEO, но платишь:

- серверной нагрузкой;
- сложностью hydration;
- требованиями к универсальному коду;
- риском hydration mismatch;
- более сложным кешированием.

## Мини-шпаргалка

- SSR рендерит HTML на сервере.
- Hydration делает этот HTML интерактивным.
- SSR помогает SEO и first contentful paint.
- SSR требует Node/server или фреймворк.
- Browser-only код нельзя выполнять во время серверного render.
