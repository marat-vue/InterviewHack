# Что такое очередь задач (task queue)

> [!summary] Коротко
> Task Queue - очередь макротасок, callbacks из которой ждут, пока освободится Call Stack и завершатся микротаски.

## Вопрос

Что попадает в очередь задач и когда выполняется?

## Определение

Task Queue, или очередь задач, хранит готовые к выполнению макротаски. Это callbacks таймеров, событий, некоторых I/O-операций и других задач среды выполнения.

Event Loop берет задачу из этой очереди только после того, как завершился текущий синхронный код и очищена очередь микротасок.

## Что относится к макротаскам

- `setTimeout`;
- `setInterval`;
- DOM-события: `click`, `input`, `scroll`;
- некоторые I/O-события;
- сообщения от `postMessage`.

## Пример

```javascript
console.log('A');

setTimeout(() => console.log('B'), 0);

Promise.resolve().then(() => console.log('C'));

console.log('D');

// A
// D
// C
// B
```

`setTimeout` попадает в очередь макротасок, поэтому выполняется после синхронного кода и микротаски промиса.

## Task Queue vs Microtask Queue

| Очередь | Примеры | Приоритет |
| --- | --- | --- |
| Microtask Queue | `Promise.then`, `queueMicrotask` | выше |
| Task Queue | `setTimeout`, события DOM | ниже |

После каждой макротаски JavaScript снова полностью очищает очередь микротасок.

## Мини-шпаргалка

```text
Call Stack empty -> run all microtasks -> run one task
```
