# Контекст функции

> [!NOTE] Коротко
> Контекст функции - это значение `this` во время вызова. В JavaScript `this` определяется не местом объявления функции, а способом ее вызова.

## Вопрос

Что такое контекст функции?

## Обычный вызов

```javascript
function showThis() {
  console.log(this);
}

showThis();
```

В strict mode `this` будет `undefined`. Без strict mode в браузере это может быть `window`.

## Вызов как метод

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};

user.sayHi(); // "Hi, Anna"
```

Когда функция вызывается через объект, `this` обычно указывает на объект слева от точки.

## Потеря контекста

```javascript
const sayHi = user.sayHi;

sayHi(); // this потерян
```

Функция была взята отдельно и вызвана без объекта.

Исправление через `bind`:

```javascript
const sayHi = user.sayHi.bind(user);

sayHi(); // "Hi, Anna"
```

## `call` и `apply`

Можно явно задать `this` при вызове.

```javascript
function sayHi() {
  return `Hi, ${this.name}`;
}

sayHi.call({ name: "Anna" }); // "Hi, Anna"
```

## Стрелочные функции

Стрелочная функция не имеет собственного `this`. Она берет его из внешней области.

```javascript
const user = {
  name: "Anna",
  sayHi: () => this.name,
};
```

Такой метод почти всегда ошибка, если нужен `this` объекта.

## Вызов через `new`

```javascript
function User(name) {
  this.name = name;
}

const user = new User("Anna");
```

При вызове через `new` создается новый объект, и `this` указывает на него.

## Мини-шпаргалка

| Вызов | `this` |
| --- | --- |
| `fn()` | `undefined` в strict mode |
| `obj.fn()` | `obj` |
| `fn.call(obj)` | `obj` |
| `fn.apply(obj)` | `obj` |
| `fn.bind(obj)` | закрепленный `obj` |
| `new Fn()` | новый объект |
| `() => {}` | внешний `this` |
