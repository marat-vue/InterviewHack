# Что такое hydration?

> [!summary]
> Hydration - процесс, при котором React подключает интерактивность к HTML, полученному с сервера. В Next.js гидратируются Client Components, а Server Components сами по себе не требуют отправки своего кода в браузер.

## Простая схема

```text
Server render -> HTML виден пользователю -> JS загружается -> React hydrates -> UI интерактивен
```

До hydration пользователь может видеть контент, но кнопка еще не обязательно работает.

## Пример

Server Component:

```tsx
export default async function ProductPage() {
  const product = await getProduct()

  return (
    <>
      <h1>{product.title}</h1>
      <AddToCartButton productId={product.id} />
    </>
  )
}
```

Client Component:

```tsx
'use client'

export function AddToCartButton({ productId }: { productId: string }) {
  return <button onClick={() => addToCart(productId)}>Add</button>
}
```

Гидратация нужна кнопке, потому что у нее есть `onClick`.

## Hydration mismatch

Mismatch возникает, когда первый клиентский render не совпадает с серверным HTML.

Плохой пример:

```tsx
function Clock() {
  return <p>{new Date().toLocaleTimeString()}</p>
}
```

Сервер и клиент могут получить разное время.

## Как избегать mismatch?

- не использовать `Date.now()` в render без стабилизации;
- не использовать `Math.random()` в render;
- browser APIs читать после mount;
- следить за locale/timezone;
- не делать разный HTML на сервере и первом клиенте.

## Что отвечать на собеседовании?

Hydration - подключение React к серверному HTML. В Next.js особенно важно помнить, что Server Components уменьшают объем клиентского JS, а Client Components гидратируются. Hydration mismatch появляется, если HTML сервера не совпал с первым render на клиенте.

## Частые ошибки

- Думать, что вся страница обязательно гидратируется целиком.
- Игнорировать hydration warnings.
- Генерировать случайные значения в render.
- Читать `localStorage` до mount.
- Путать hydration и server rendering.

## Мини-шпаргалка

- Hydration оживляет HTML.
- Нужна для Client Components.
- Server Components code не гидратируется как клиентский код.
- Mismatch = сервер и клиент отрендерили разное.
- Browser APIs читать осторожно.
