# Что такое fallback шрифт

> [!summary]
> **Fallback шрифт** - это запасной шрифт, который браузер использует, если основной шрифт недоступен, не загрузился или не содержит нужный символ.

## Главное

Шрифты в `font-family` указывают цепочкой.

```css
body {
  font-family: Inter, Arial, sans-serif;
}
```

Браузер сначала попробует `Inter`, затем `Arial`, затем любой доступный `sans-serif`.

## Зачем нужен fallback

- Основной webfont может не загрузиться.
- Пользователь может быть offline.
- Файл шрифта может быть заблокирован.
- В шрифте может не быть кириллицы или спецсимвола.
- Система пользователя может не иметь нужный локальный шрифт.

## Generic family

В конце font stack обычно ставят общее семейство.

```css
.code {
  font-family: "JetBrains Mono", Consolas, monospace;
}
```

`monospace` гарантирует, что браузер выберет моноширинный запасной шрифт.

## Хороший font stack

```css
.article {
  font-family: Georgia, "Times New Roman", serif;
}
```

Шрифты в цепочке должны быть похожи по характеру. Если основной шрифт геометрический sans-serif, запасной serif может заметно сломать визуальный ритм.

## Мини-шпаргалка

- Fallback - запасной шрифт.
- Шрифты перечисляют через запятую.
- Названия с пробелами пишут в кавычках.
- В конце указывают `sans-serif`, `serif` или `monospace`.
- Fallback помогает, если основной шрифт не загрузился.
