# Как фильтровать диапазоны через BETWEEN и операторы сравнения?

> [!NOTE]
> Диапазоны в SQL фильтруют через `BETWEEN`, `>`, `>=`, `<`, `<=`. Для дат и времени часто безопаснее использовать полуоткрытый интервал: `created_at >= start AND created_at < next_start`.

## BETWEEN

```sql
SELECT *
FROM orders
WHERE total BETWEEN 100 AND 500;
```

`BETWEEN` включает обе границы: это похоже на `total >= 100 AND total <= 500`.

## Операторы сравнения

```sql
SELECT *
FROM orders
WHERE total >= 100
  AND total < 500;
```

Такой вариант явно показывает, какая граница включена.

## Даты

Плохой подход для timestamp:

```sql
WHERE created_at BETWEEN DATE '2026-08-01' AND DATE '2026-08-31'
```

Если `created_at` содержит время, часть событий 31 августа после полуночи может не попасть в выборку в зависимости от приведения типов.

Лучше:

```sql
WHERE created_at >= TIMESTAMP '2026-08-01 00:00:00'
  AND created_at < TIMESTAMP '2026-09-01 00:00:00'
```

## Мини-шпаргалка

- `BETWEEN` включает обе границы.
- Для чисел `BETWEEN` часто читаем.
- Для timestamp обычно лучше полуоткрытый интервал.
- Не оборачивай индексируемую колонку в функцию без причины.
- Диапазонные условия хорошо работают с B-tree индексами.
