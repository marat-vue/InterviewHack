# Как писать where, orderBy, pagination, select и include?

> [!summary]
> Prisma-запросы собираются объектом: `where` фильтрует, `orderBy` сортирует, `skip/take` делают offset-пагинацию, `select` выбирает поля, а `include` подгружает связи.

## where

```ts
const users = await this.prisma.user.findMany({
  where: {
    email: { contains: 'example.com' },
    createdAt: { gte: new Date('2026-01-01') },
  },
});
```

## orderBy

```ts
const users = await this.prisma.user.findMany({
  orderBy: {
    createdAt: 'desc',
  },
});
```

## pagination

```ts
const page = 1;
const limit = 20;

const users = await this.prisma.user.findMany({
  skip: (page - 1) * limit,
  take: limit,
  orderBy: { createdAt: 'desc' },
});
```

## select

```ts
const users = await this.prisma.user.findMany({
  select: {
    id: true,
    email: true,
  },
});
```

## include

```ts
const users = await this.prisma.user.findMany({
  include: {
    posts: true,
  },
});
```

## select vs include

`select` выбирает конкретные поля, `include` добавляет relations. Не стоит бездумно `include`-ить большие связи.

## Мини-шпаргалка

- `where` фильтрует.
- `orderBy` сортирует.
- `skip/take` делают pagination.
- `select` уменьшает payload.
- `include` подгружает relations.
