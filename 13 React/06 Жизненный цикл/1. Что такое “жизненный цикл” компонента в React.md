# Что такое жизненный цикл компонента в React?

> [!summary]
> Жизненный цикл компонента - это этапы существования компонента в UI: создание, render, добавление в DOM, обновление, выполнение эффектов и удаление. В классовых компонентах это выражалось lifecycle methods, а в функциональных - через render, hooks и cleanup.

## Простая схема

```text
mount -> update -> unmount
```

Но в современном React полезнее мыслить точнее:

```text
trigger render -> render phase -> commit phase -> effects -> cleanup
```

## Mount

Mount - компонент впервые появляется в дереве.

```jsx
root.render(<App />)
```

React вызывает компонент, получает JSX, создает DOM-узлы и добавляет их на страницу.

## Update

Update - компонент обновляется из-за:

- изменения state;
- изменения props;
- изменения context;
- render родителя;
- изменения external store.

React снова вызывает компонент и сравнивает новый результат со старым.

## Unmount

Unmount - компонент удаляется из дерева.

В этот момент нужно очищать:

- subscriptions;
- timers;
- соединения;
- запросы;
- внешние ресурсы.

В функциональном компоненте это обычно cleanup в `useEffect`.

## Почему важно понимать lifecycle?

Это помогает объяснить:

- когда выполняется render;
- почему нельзя делать side effects в render;
- когда доступен DOM;
- когда запускаются effects;
- почему cleanup нужен;
- почему Strict Mode может вызывать код дважды в development.

## Мини-шпаргалка

- Lifecycle = mount, update, unmount.
- Render phase вычисляет UI.
- Commit phase применяет изменения к DOM.
- Effects синхронизируют компонент с внешним миром.
- Cleanup освобождает ресурсы.
