# Примитивные типы

> [!summary] Коротко
> Примитивные типы описывают простые значения: `string`, `number`, `boolean`, `bigint`, `symbol`, `null` и `undefined`.

## Вопрос

Какие примитивные типы есть в TypeScript?

## Определение

Примитивы - значения, которые не являются объектами. TypeScript использует примитивные типы JavaScript и позволяет явно указывать, какие значения допустимы.

## Основные примитивы

```typescript
const name: string = 'Ann';
const age: number = 25;
const isAdmin: boolean = false;
const id: bigint = 123n;
const token: symbol = Symbol('token');
const empty: null = null;
const missing: undefined = undefined;
```

## string

```typescript
let title: string = 'Frontend';
```

Для текста и строковых значений.

## number

```typescript
let price: number = 199.99;
```

В TypeScript тип `number` включает и целые числа, и дробные значения.

## boolean

```typescript
let isLoading: boolean = true;
```

Для значений `true` и `false`.

## null и undefined

```typescript
let value: string | null = null;
```

При `strictNullChecks` `null` и `undefined` не входят автоматически во все типы. Их нужно указывать явно.

## Примитивы vs объектные оболочки

```typescript
let name: string = 'Ann'; // правильно
let badName: String = new String('Ann'); // почти всегда не нужно
```

В типах обычно используют `string`, `number`, `boolean`, а не `String`, `Number`, `Boolean`.

## Мини-шпаргалка

```typescript
string;
number;
boolean;
bigint;
symbol;
null;
undefined;
```
