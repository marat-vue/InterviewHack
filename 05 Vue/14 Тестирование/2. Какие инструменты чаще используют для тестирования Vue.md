# Какие инструменты чаще используют для тестирования Vue

> [!summary]
> Во Vue чаще всего используют Vitest для unit-тестов, Vue Test Utils для монтирования компонентов, Testing Library для пользовательского подхода, Playwright или Cypress для E2E и MSW для моков API.

## Основные инструменты

| Инструмент | Для чего нужен |
| --- | --- |
| `Vitest` | Unit-тесты, интеграционные тесты, быстрый запуск в Vite-проектах |
| `Vue Test Utils` | Монтирование Vue-компонентов и работа с wrapper |
| `Testing Library` | Тестирование через пользовательские действия и доступные роли |
| `Playwright` | E2E-тесты в реальном браузере |
| `Cypress` | E2E и component testing |
| `MSW` | Мокирование сетевых запросов на уровне Service Worker |

## Vitest

Vitest часто выбирают для Vue-проектов на Vite, потому что он хорошо встраивается в эту экосистему.

```js
import { describe, expect, test } from "vitest";

describe("sum", () => {
  test("adds numbers", () => {
    expect(2 + 2).toBe(4);
  });
});
```

## Vue Test Utils

Vue Test Utils позволяет смонтировать компонент и проверить его поведение.

```js
import { mount } from "@vue/test-utils";
import CounterButton from "./CounterButton.vue";

test("increments counter", async () => {
  const wrapper = mount(CounterButton);

  await wrapper.get("button").trigger("click");

  expect(wrapper.text()).toContain("1");
});
```

## Testing Library

Testing Library заставляет писать тесты ближе к пользовательскому поведению.

```js
import { render, screen } from "@testing-library/vue";
import userEvent from "@testing-library/user-event";
import LoginForm from "./LoginForm.vue";

test("submits login form", async () => {
  render(LoginForm);

  await userEvent.type(screen.getByLabelText("Email"), "a@b.com");
  await userEvent.click(screen.getByRole("button", { name: "Войти" }));

  expect(screen.getByText("Готово")).toBeInTheDocument();
});
```

## Playwright

Playwright проверяет приложение как пользователь: открывает браузер, кликает, вводит текст, проверяет URL и элементы.

```js
import { expect, test } from "@playwright/test";

test("opens settings page", async ({ page }) => {
  await page.goto("/");
  await page.getByRole("link", { name: "Настройки" }).click();

  await expect(page).toHaveURL(/settings/);
});
```

## Как выбирать

- Логика и composables: `Vitest`.
- Компоненты Vue: `Vitest` + `Vue Test Utils`.
- UI как его видит пользователь: Testing Library.
- Реальные сценарии в браузере: Playwright или Cypress.
- API без настоящего backend: MSW.

## Мини-шпаргалка

- Vitest - базовый test runner для Vite/Vue.
- Vue Test Utils - низкоуровневое тестирование компонентов.
- Testing Library - тесты через пользовательское поведение.
- Playwright/Cypress - E2E.
- MSW помогает мокировать API реалистично.
