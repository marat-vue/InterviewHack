# Что делает селектор where()?

> [!NOTE]
> `:where()` группирует селекторы как `:is()`, но всегда имеет нулевую специфичность. Это удобно для базовых стилей, которые должно быть легко переопределять.

## Главное

```css
:where(h1, h2, h3) {
  line-height: 1.2;
}
```

Правило применится к заголовкам, но его будет легко перебить обычным классом.

## Почему нулевая специфичность полезна

```css
:where(.article h2) {
  margin-block-start: 2rem;
}

.article-title {
  margin-block-start: 0;
}
```

Класс легко переопределит базовое правило.

## Отличие от is()

```css
:is(.card, #featured) {
  padding: 16px;
}

:where(.card, #featured) {
  padding: 16px;
}
```

В `:is()` специфичность может стать высокой из-за `#featured`. В `:where()` она останется нулевой.

## Где использовать

- Reset/base styles.
- Стили типографики.
- Низкоприоритетные правила дизайн-системы.
- Группировка селекторов без роста специфичности.

## Мини-шпаргалка

- `:where()` группирует селекторы.
- Его специфичность всегда `0`.
- Хорош для базовых правил.
- Легко переопределяется классами.
- `:is()` похож, но учитывает специфичность аргументов.
