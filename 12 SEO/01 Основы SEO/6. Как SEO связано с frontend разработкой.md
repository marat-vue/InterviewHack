# Как SEO связано с frontend разработкой?

> [!summary]
> Frontend влияет на SEO через HTML, routing, rendering, meta tags, links, images, performance, accessibility, structured data и ошибки JavaScript. Для современных SPA/SSR/SSG приложений SEO - это часть инженерной архитектуры.

## Где frontend влияет на SEO?

Frontend отвечает за:

- `<title>`;
- meta description;
- canonical;
- headings;
- semantic HTML;
- links;
- image alt;
- structured data;
- lazy loading;
- hydration;
- client routing;
- status pages;
- Core Web Vitals.

## Пример плохого SPA SEO

```html
<div id="app"></div>
```

Контент появляется только после client JavaScript и API-запроса. Поисковик может обработать это хуже или позже.

## Пример лучше

SSR/SSG страница сразу отдает HTML:

```html
<main>
  <h1>Курс по Nuxt</h1>
  <p>Изучите SSR, SSG и SEO для Vue-приложений.</p>
  <a href="/nuxt/ssr">Что такое SSR</a>
</main>
```

## Типовые ошибки frontend-разработчика

- links сделаны через `div @click`;
- title одинаковый на всех страницах;
- canonical не меняется при dynamic routes;
- images без `alt`, `width`, `height`;
- важный контент грузится только после user action;
- 404 страница возвращает `200`;
- hydration errors игнорируются;
- filters генерируют тысячи индексируемых URL.

## Мини-шпаргалка

- SEO начинается с доступного HTML.
- Links должны быть настоящими `<a href>`.
- Meta должны быть уникальными для страниц.
- Performance и accessibility влияют на качество страницы.
- SSR/SSG часто помогают frontend SEO.
- JavaScript errors могут ломать indexing.
