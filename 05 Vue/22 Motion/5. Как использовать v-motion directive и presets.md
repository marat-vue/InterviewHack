# Как использовать v-motion directive и presets?

> [!summary]
> `v-motion` добавляет Motion-анимации к обычному HTML или SVG элементу без wrapper component. Directive удобна, когда не хочется менять тег на `<motion.div>`, но нужны `initial`, `animate`, gestures, layout или variants.

## Глобальное подключение

```typescript
import { MotionPlugin } from "motion-v";

app.use(MotionPlugin);
```

После этого `v-motion` доступна во всех компонентах.

## Базовый синтаксис через props

```vue
<template>
  <div
    v-motion
    :initial="{ opacity: 0, y: 24 }"
    :animate="{ opacity: 1, y: 0 }"
    :transition="{ duration: 0.35 }"
  >
    Fade in
  </div>
</template>
```

## Синтаксис через binding object

```vue
<template>
  <div
    v-motion="{
      initial: { opacity: 0, x: -30 },
      animate: { opacity: 1, x: 0 },
      transition: { duration: 0.4 },
    }"
  >
    Slide in
  </div>
</template>
```

## Props имеют приоритет

Если одновременно указать binding object и отдельный prop, prop победит:

```vue
<div
  v-motion="{ initial: { opacity: 0.5 } }"
  :initial="{ opacity: 0 }"
/>
```

Здесь итоговый `initial` будет `{ opacity: 0 }`.

## Presets

Можно зарегистрировать собственные directive-presets:

```typescript
app.use(MotionPlugin, {
  presets: {
    "fade-in": {
      initial: { opacity: 0 },
      animate: { opacity: 1 },
      transition: { duration: 0.3 },
    },
    "slide-up": {
      initial: { opacity: 0, y: 32 },
      animate: { opacity: 1, y: 0 },
      transition: { duration: 0.35 },
    },
  },
});
```

Использование:

```vue
<template>
  <section v-fade-in />
  <article v-slide-up />
</template>
```

## Когда выбрать v-motion?

`v-motion` хорош, если:

- нужно анимировать существующую разметку;
- не хочется менять component tree;
- нужен directive-style подход;
- нужно много простых enter effects.

`<motion.div>` часто удобнее, если ты активно используешь gestures, layout, `AnimatePresence` и variants.

## Мини-шпаргалка

- `v-motion` анимирует обычный element.
- Нужен `MotionPlugin` или локальный import `vMotion`.
- Можно передавать объект в directive.
- Можно передавать props рядом с directive.
- Props перекрывают binding object.
- Presets создают короткие directives вроде `v-fade-in`.
