# Как поставить цели и KPI для SEO?

> [!summary]
> SEO KPI должны связывать поисковую видимость с бизнес-результатом. Позиции важны, но сами по себе не показывают, приносит ли SEO пользу продукту.

## Какие цели бывают?

- Рост органического трафика.
- Рост заявок.
- Рост продаж.
- Рост регистраций.
- Снижение зависимости от paid channels.
- Рост видимости бренда.
- Улучшение индексации.
- Рост трафика на конкретные категории.

## Какие метрики смотреть?

| Метрика | Где смотреть |
|---|---|
| Clicks | Search Console |
| Impressions | Search Console |
| CTR | Search Console |
| Average position | Search Console |
| Organic sessions | GA4 |
| Conversions | GA4/CRM |
| Indexed pages | Search Console |
| Core Web Vitals | Search Console/CrUX |

## Почему позиции недостаточны?

Позиция может улучшиться, но бизнес не вырасти:

```text
Запрос дает много показов, но не приводит целевых пользователей.
```

Или наоборот:

```text
Низкочастотный коммерческий запрос дает мало трафика, но много заявок.
```

## Как формулировать KPI?

Плохо:

```text
Вывести сайт в топ.
```

Лучше:

```text
За 6 месяцев увеличить organic demo requests на 30% за счет страниц use cases, comparison pages и улучшения индексации product pages.
```

## Мини-шпаргалка

- KPI должны быть связаны с целью бизнеса.
- Позиции - диагностическая метрика, не финальная цель.
- Search Console показывает поисковую видимость.
- GA4 помогает смотреть поведение и конверсии.
- Для SEO важен горизонт недель и месяцев.
