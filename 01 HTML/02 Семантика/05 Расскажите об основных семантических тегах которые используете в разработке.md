> [!summary]
> Основные семантические теги HTML помогают описывать структуру страницы: шапку, навигацию, основное содержимое, разделы, статьи, дополнительный контент, подвал, формы и интерактивные элементы.

## Структурные теги

| Тег | Когда использовать |
| --- | --- |
| `<header>` | Шапка страницы или секции |
| `<nav>` | Блок навигационных ссылок |
| `<main>` | Главное содержимое страницы |
| `<section>` | Тематический раздел |
| `<article>` | Самостоятельный материал |
| `<aside>` | Дополнительный или боковой контент |
| `<footer>` | Подвал страницы или секции |

## Пример структуры страницы

```html
<body>
  <header>
    <nav aria-label="Основная навигация">
      <a href="/">Главная</a>
      <a href="/blog">Блог</a>
    </nav>
  </header>

  <main>
    <article>
      <h1>Как работает HTML</h1>
      <p>HTML описывает структуру документа.</p>
    </article>
  </main>

  <footer>
    <p>© 2026</p>
  </footer>
</body>
```

## Текстовые семантические теги

| Тег | Смысл |
| --- | --- |
| `<h1>`-`<h6>` | Заголовки разных уровней |
| `<p>` | Абзац |
| `<strong>` | Важность |
| `<em>` | Смысловое выделение |
| `<blockquote>` | Блочная цитата |
| `<code>` | Фрагмент кода |
| `<time>` | Дата или время |

## Интерактивные и формовые элементы

```html
<form>
  <label for="email">Email</label>
  <input id="email" type="email" name="email">
  <button type="submit">Подписаться</button>
</form>
```

`form`, `label`, `input` и `button` дают браузеру понятный контракт поведения.

## Как выбирать тег

Сначала спроси: "Что это такое по смыслу?"

- Это основное содержимое страницы? `main`.
- Это отдельная статья или карточка, которую можно читать отдельно? `article`.
- Это тематический блок с заголовком? `section`.
- Это действие? `button`.
- Это переход? `a`.

## Мини-шпаргалка

- `main` обычно один на странице.
- `nav` используют для навигационных ссылок.
- `section` желательно иметь с заголовком.
- `article` должен быть самостоятельной единицей контента.
- `button` - действие, `a` - переход.
- Тег выбирают по смыслу, а не по стилю.
