# Оператор spread

> [!summary] Коротко
> Spread `...` раскрывает массив, строку или другой iterable в отдельные элементы, а объект - в отдельные свойства. Часто используется для копирования и объединения.

## Вопрос

Для чего нужен оператор spread?

## Spread в массивах

Копия массива:

```javascript
const numbers = [1, 2, 3];
const copy = [...numbers];

copy.push(4);

console.log(numbers); // [1, 2, 3]
console.log(copy);    // [1, 2, 3, 4]
```

Объединение массивов:

```javascript
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b]; // [1, 2, 3, 4]
```

Вставка элементов:

```javascript
const result = [0, ...a, 99]; // [0, 1, 2, 99]
```

## Spread в вызове функции

```javascript
const numbers = [5, 10, 2];

Math.max(...numbers); // 10
```

Без spread пришлось бы передавать аргументы вручную.

## Spread со строкой

Строка является iterable:

```javascript
[..."hello"]; // ["h", "e", "l", "l", "o"]
```

## Spread в объектах

Копия объекта:

```javascript
const user = { name: "Anna", age: 25 };
const copy = { ...user };
```

Объединение объектов:

```javascript
const defaults = { theme: "light", pageSize: 20 };
const settings = { pageSize: 50 };

const result = { ...defaults, ...settings };
// { theme: "light", pageSize: 50 }
```

Если свойства повторяются, побеждает последнее.

## Поверхностная копия

Spread делает shallow copy.

```javascript
const user = {
  profile: {
    city: "Moscow",
  },
};

const copy = { ...user };

copy.profile.city = "Kazan";

console.log(user.profile.city); // "Kazan"
```

Вложенный объект остался общим.

## Spread vs rest

Синтаксис одинаковый, смысл разный.

Spread раскрывает:

```javascript
const copy = [...items];
```

Rest собирает:

```javascript
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
```

## Мини-шпаргалка

```javascript
[...arr];              // копия массива
[...a, ...b];          // объединение массивов
fn(...args);           // передача массива как аргументов
{ ...obj };            // копия объекта
{ ...a, ...b };        // объединение объектов
[..."abc"];            // ["a", "b", "c"]
```
