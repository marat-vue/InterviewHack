# Что означает тип void

> [!summary] Коротко
> `void` означает, что функция не возвращает полезное значение.

## Вопрос

Что означает тип `void` в TypeScript?

## Определение

`void` чаще всего используют как тип возвращаемого значения функции. Он говорит: функция может выполнить действие, но ее результат не нужно использовать.

На практике функция с `void` обычно ничего не возвращает или возвращает `undefined`.

## Пример

```typescript
function logMessage(message: string): void {
  console.log(message);
}
```

Функция выводит сообщение, но не возвращает полезный результат.

## void в callback

```typescript
button.addEventListener('click', (): void => {
  console.log('clicked');
});
```

Callback выполняет побочное действие и ничего полезного не возвращает.

## void vs undefined

```typescript
function doNothing(): undefined {
  return undefined;
}

function log(): void {
  console.log('log');
}
```

`undefined` означает конкретное значение. `void` означает, что возвращаемое значение не важно.

## Важный нюанс

Если функция типизирована как `void`, не стоит полагаться на ее возвращаемое значение.

```typescript
const result = logMessage('Hello');
// result имеет тип void
```

## Мини-шпаргалка

```typescript
function fn(): void {
  // no useful return value
}
```
