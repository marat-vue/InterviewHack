# Что делает модификатор .lazy

> [!summary] Коротко
> `.lazy` у `v-model` обновляет состояние не на каждом `input`, а на событии `change`. Обычно это значит: после потери фокуса или подтверждения значения.

## Вопрос

Что делает модификатор `.lazy`?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const email = ref("");
</script>

<template>
  <input v-model.lazy="email" />
  <p>{{ email }}</p>
</template>
```

Текст в `email` не будет обновляться на каждую клавишу.

## Без lazy

```vue
<input v-model="email" />
```

Обычный `v-model` на текстовом input обновляет состояние при вводе.

## Когда полезно

`.lazy` подходит, если обновление дорогое: запуск поиска, валидация, сохранение черновика, запрос на сервер.

## Важный нюанс

Для мгновенного отображения набранного текста `.lazy` не подходит. Пользователь может вводить текст, а state еще будет старым.

## Мини-шпаргалка

- `.lazy` меняет событие обновления на `change`.
- Уменьшает количество обновлений state.
- Полезен для дорогих реакций на ввод.
- Не подходит для live-preview.
