# Как тестировать events, trigger, emitted и v-model?

> [!summary]
> События тестируют через пользовательские действия: `trigger` вызывает DOM event, а `emitted` проверяет Vue events. `v-model` обычно проверяют через `update:modelValue` или изменение input.

## `trigger`

```ts
await wrapper.get('button').trigger('click');
```

`trigger` имитирует DOM-событие. После него обычно нужен `await`, потому что Vue обновляет DOM асинхронно.

## `emitted`

Компонент:

```vue
<button @click="$emit('save', { id: 1 })">
  Сохранить
</button>
```

Тест:

```ts
await wrapper.get('button').trigger('click');

expect(wrapper.emitted('save')).toEqual([
  [{ id: 1 }],
]);
```

## Проверка количества событий

```ts
expect(wrapper.emitted('save')).toHaveLength(1);
```

## `v-model`

Компонент может эмитить `update:modelValue`:

```ts
await wrapper.get('input').setValue('ann@example.com');

expect(wrapper.emitted('update:modelValue')).toEqual([
  ['ann@example.com'],
]);
```

Для нескольких моделей:

```ts
expect(wrapper.emitted('update:title')).toBeTruthy();
```

## Когда проверять emitted?

Проверяй emitted, если компонент должен сообщить родителю о действии:

- submit form;
- select option;
- close modal;
- change page;
- update model value.

## Мини-шпаргалка

- `trigger` вызывает DOM event.
- `setValue` удобен для input/select/textarea.
- `emitted()` возвращает события компонента.
- `v-model` проверяют через `update:modelValue`.
- События проверяют как контракт компонента с родителем.
