# Деление тяжелой задачи

> [!NOTE] Коротко
> Тяжелую задачу можно разбить на небольшие части, чтобы между ними Event Loop успевал обрабатывать UI и другие события.

## Вопрос

Как разбить тяжелые вычисления на части?

## Основная идея

Если обработать огромный массив одним синхронным циклом, main thread может зависнуть. Вместо этого можно выполнять работу порциями и отдавать управление браузеру между порциями.

## Пример chunking

```javascript
let index = 0;

function processChunk() {
  const end = Math.min(index + 1000, items.length);

  while (index < end) {
    process(items[index]);
    index++;
  }

  if (index < items.length) {
    setTimeout(processChunk, 0);
  }
}

processChunk();
```

После каждой порции браузер получает шанс обработать другие задачи.

## requestIdleCallback

```javascript
function processIdle(deadline) {
  while (deadline.timeRemaining() > 0 && tasks.length > 0) {
    process(tasks.shift());
  }

  if (tasks.length > 0) {
    requestIdleCallback(processIdle);
  }
}

requestIdleCallback(processIdle);
```

Подходит для некритичных фоновых задач.

## Web Worker

Если вычисления действительно тяжелые, лучше вынести их в worker.

```javascript
const worker = new Worker('worker.js');

worker.postMessage(data);
```

## Мини-шпаргалка

```text
small chunks -> setTimeout/requestIdleCallback
heavy CPU -> Web Worker
```
