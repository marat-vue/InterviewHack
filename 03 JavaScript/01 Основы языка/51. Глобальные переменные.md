# Глобальные переменные

> [!summary] Коротко
> Глобальные переменные доступны из любой части программы. Их стоит избегать, потому что они создают конфликты имен, усложняют отладку и делают код зависимым от скрытого общего состояния.

## Вопрос

Почему не стоит использовать глобальные переменные?

## Что такое глобальная переменная

Глобальная переменная объявлена во внешней области видимости.

```javascript
const appName = "Frontend Notes";

function printAppName() {
  console.log(appName);
}
```

В браузере глобальные свойства доступны через `window` или `globalThis`.

```javascript
var legacyValue = 1;

console.log(window.legacyValue); // 1
```

`let` и `const` в глобальной области не становятся свойствами `window`, но все равно остаются глобальными в своем скрипте/модуле.

## Почему это плохо

### Конфликты имен

```javascript
var user = "Anna";
var user = "Max";
```

Разные скрипты могут случайно использовать одно имя.

### Сложная отладка

```javascript
let config = { theme: "light" };

function updateTheme() {
  config.theme = "dark";
}
```

Если глобальное состояние можно изменить откуда угодно, сложно понять, кто его поменял.

### Скрытые зависимости

```javascript
function getApiUrl() {
  return config.apiUrl;
}
```

Функция зависит от `config`, но это не видно по ее параметрам.

## Что делать вместо этого

Передавать зависимости явно:

```javascript
function getApiUrl(config) {
  return config.apiUrl;
}
```

Использовать модули:

```javascript
// config.js
export const config = {
  apiUrl: "/api",
};
```

Ограничивать область видимости:

```javascript
function initApp() {
  const config = { apiUrl: "/api" };

  start(config);
}
```

## Когда глобальные значения допустимы

Иногда глобальные API являются нормой:

```javascript
window.location;
document;
console;
globalThis;
```

Но свои данные приложения лучше не складывать в глобальную область без необходимости.

## Мини-шпаргалка

| Проблема | Почему опасно |
| --- | --- |
| Конфликты имен | одно значение перезаписало другое |
| Сложная отладка | значение меняется из разных мест |
| Скрытые зависимости | функция зависит от внешнего состояния |
| Тестирование | тесты влияют друг на друга |
