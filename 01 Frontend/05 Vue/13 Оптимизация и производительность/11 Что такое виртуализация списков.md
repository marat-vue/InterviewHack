# Что такое виртуализация списков?

> [!NOTE]
> **Виртуализация списков** - это техника, при которой приложение рендерит только видимые элементы списка, а не весь массив данных целиком.

## Главное

Если в списке 50 000 элементов, пользователю одновременно видны только десятки строк. Виртуализация использует это: в DOM находятся только видимые элементы и небольшой буфер.

```text
all items:      50 000
visible items:      30
DOM nodes:          40-80
```

Визуально список кажется полным, но браузер работает с маленьким количеством элементов.

## Как это работает

1. Контейнер получает высоту, соответствующую всему списку.
2. По положению скролла вычисляется диапазон видимых элементов.
3. В DOM рендерятся только элементы из этого диапазона.
4. Рендеримые элементы сдвигаются через `transform` или отступ.

```text
scrollTop
  -> start index
  -> end index
  -> render only visible slice
```

## Упрощенный пример

```vue
<script setup>
import { computed, ref } from "vue";

const items = Array.from({ length: 10000 }, (_, index) => ({
  id: index,
  title: `Item ${index}`,
}));

const rowHeight = 40;
const viewportHeight = 400;
const scrollTop = ref(0);

const visibleItems = computed(() => {
  const start = Math.floor(scrollTop.value / rowHeight);
  const end = start + Math.ceil(viewportHeight / rowHeight) + 5;

  return items.slice(start, end);
});
</script>
```

На практике лучше использовать готовую библиотеку, потому что нужно учитывать динамические высоты, фокус, клавиатуру и доступность.

## Когда использовать

- Длинные списки.
- Большие таблицы.
- Ленты сообщений.
- Логи и события.
- Select/dropdown с тысячами вариантов.

## Когда не использовать

Для маленьких списков виртуализация лишняя. Она усложняет код, тестирование и UX: поиск по странице, фокус, sticky-элементы и динамическая высота строк требуют дополнительной работы.

## Мини-шпаргалка

- Виртуализация рендерит только видимый диапазон.
- Она резко снижает количество DOM-узлов.
- Особенно полезна для таблиц и длинных списков.
- Для продакшена лучше брать библиотеку.
- Не нужна для небольших списков.
