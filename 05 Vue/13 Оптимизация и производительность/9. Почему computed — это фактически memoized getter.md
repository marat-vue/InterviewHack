# Почему computed - это фактически memoized getter

> [!summary]
> `computed` во Vue похож на memoized getter: он вычисляет значение, запоминает результат и пересчитывает его только тогда, когда изменились реактивные зависимости.

## Главное

`computed` описывает производное значение. Оно не хранится как независимое состояние, а выводится из других реактивных данных.

```vue
<script setup>
import { computed, ref } from "vue";

const firstName = ref("Анна");
const lastName = ref("Иванова");

const fullName = computed(() => `${firstName.value} ${lastName.value}`);
</script>
```

`fullName` пересчитается только при изменении `firstName` или `lastName`.

## Почему это getter

К `computed` обращаются как к значению, но внутри оно вызывает функцию чтения.

```js
console.log(fullName.value);
```

Для Vue это означает: "дай мне актуальное значение, а если зависимости не менялись - верни кеш".

## Почему это memoized

```js
const expensiveTotal = computed(() => {
  console.log("calculate");
  return cart.value.reduce((sum, item) => sum + item.price, 0);
});
```

Если компонент обращается к `expensiveTotal.value` несколько раз подряд, Vue не будет каждый раз выполнять `reduce`. Он вернет сохраненный результат.

## Отличие от метода

```vue
<script setup>
const getTotal = () =>
  cart.value.reduce((sum, item) => sum + item.price, 0);
</script>

<template>
  <p>{{ getTotal() }}</p>
  <p>{{ getTotal() }}</p>
</template>
```

Метод вызывается при каждом обращении в шаблоне. `computed` при тех же зависимостях отдаст кешированное значение.

## Когда computed подходит

- Для фильтрации и сортировки данных.
- Для форматирования значений.
- Для вычисления derived state.
- Для проверки условий, зависящих от нескольких источников.
- Для подготовки данных перед передачей в дочерние компоненты.

## Мини-шпаргалка

- `computed` - производное значение.
- Он ведет себя как getter.
- Результат кешируется до изменения зависимостей.
- Для тяжелых вычислений `computed` лучше метода в шаблоне.
- Не стоит использовать `computed` для сайд-эффектов.
