# Что такое CHECK constraint?

> [!summary]
> `CHECK` constraint проверяет условие для значений строки. Он помогает запретить отрицательные цены, неправильные статусы, некорректные диапазоны и другие невозможные состояния.

## Пример

```sql
CREATE TABLE products (
  id bigint PRIMARY KEY,
  price numeric(10, 2) NOT NULL CHECK (price >= 0)
);
```

Цена не может быть отрицательной.

## Статус

```sql
CREATE TABLE orders (
  id bigint PRIMARY KEY,
  status text NOT NULL CHECK (status IN ('new', 'paid', 'cancelled'))
);
```

Так можно ограничить допустимые значения.

## Диапазон дат

```sql
CREATE TABLE bookings (
  id bigint PRIMARY KEY,
  starts_at timestamp NOT NULL,
  ends_at timestamp NOT NULL,
  CHECK (ends_at > starts_at)
);
```

## Мини-шпаргалка

- `CHECK` проверяет условие внутри строки.
- Хорош для диапазонов и ограниченных enum-like значений.
- Не заменяет foreign key для справочников.
- Может ссылаться на несколько колонок той же строки.
- Условия должны быть простыми и понятными.
