# Что такое Composition API

> [!summary] Коротко
> Composition API - способ писать Vue-компоненты через функции реактивности и `setup`. Он позволяет группировать связанную логику вместе и выносить ее в composable-функции.

## Вопрос

Что такое Composition API?

## Базовый пример

```vue
<script setup>
import { computed, ref } from "vue";

const count = ref(0);
const doubled = computed(() => count.value * 2);

function increment() {
  count.value++;
}
</script>

<template>
  <button @click="increment">{{ doubled }}</button>
</template>
```

Вместо секций `data`, `methods`, `computed` логика находится рядом.

## Главная идея

Composition API группирует код по смыслу: состояние, вычисления, watchers и lifecycle hooks одной фичи можно держать рядом или вынести в composable.

```typescript
export function useCounter() {
  const count = ref(0);
  const increment = () => count.value++;

  return { count, increment };
}
```

## Где используется

Composition API особенно удобен в больших компонентах, с TypeScript, при переиспользовании логики и при работе со сложной реактивностью.

## Мини-шпаргалка

- `setup` - место инициализации логики компонента.
- `<script setup>` - компактный синтаксис Vue 3.
- `ref`, `reactive`, `computed`, `watch` - основные инструменты.
- Composables помогают переиспользовать логику.
