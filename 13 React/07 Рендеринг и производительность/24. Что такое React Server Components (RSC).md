# Что такое React Server Components (RSC)?

> [!summary]
> React Server Components - это компоненты, которые выполняются на сервере и не отправляют свой JavaScript-код в браузер. Они помогают уменьшить client bundle, читать данные ближе к источнику и отделять интерактивный UI от серверной логики.

## Главное отличие

Server Component:

- выполняется на сервере;
- может читать файлы, базу данных, server-only API;
- не использует `useState`, `useEffect`, browser API и event handlers;
- не попадает как JS-код в client bundle.

Client Component:

- выполняется в браузере;
- может использовать state, effects и события;
- нужен для интерактива;
- помечается директивой `'use client'` в фреймворках, которые поддерживают RSC.

## Пример

```tsx
// app/products/page.tsx
import { db } from '@/db'
import ProductLikeButton from './ProductLikeButton'

export default async function ProductsPage() {
  const products = await db.product.findMany()

  return (
    <main>
      {products.map((product) => (
        <article key={product.id}>
          <h2>{product.title}</h2>
          <ProductLikeButton productId={product.id} />
        </article>
      ))}
    </main>
  )
}
```

```tsx
// app/products/ProductLikeButton.tsx
'use client'

import { useState } from 'react'

export default function ProductLikeButton({ productId }: { productId: string }) {
  const [liked, setLiked] = useState(false)

  return (
    <button onClick={() => setLiked((value) => !value)}>
      {liked ? 'Liked' : 'Like'} {productId}
    </button>
  )
}
```

Страница получает данные на сервере, а кнопка остается интерактивной на клиенте.

## RSC не то же самое, что SSR

SSR:

```text
Компоненты рендерятся на сервере в HTML -> затем JS гидрирует приложение на клиенте
```

RSC:

```text
Server Components выполняются на сервере -> их JS не отправляется в браузер
Client Components отправляются и гидрируются
```

SSR отвечает на вопрос "где был создан HTML". RSC отвечает на вопрос "какие компоненты вообще должны исполняться на клиенте".

## Что можно передавать из Server Component в Client Component?

Props должны быть сериализуемыми.

Хорошо:

```tsx
<ProductLikeButton productId={product.id} initialLiked={false} />
```

Плохо:

```tsx
<ProductLikeButton onLike={() => saveLike(product.id)} />
```

Функцию нельзя просто передать с сервера в клиент как обычный prop.

## Когда использовать Server Components?

Подходят для:

- страниц, которые показывают данные;
- чтения из базы данных;
- server-only секретов и API;
- markdown/content rendering;
- больших зависимостей, которые не нужны в браузере.

Client Components нужны для:

- кликов;
- форм;
- анимаций;
- browser API;
- local state;
- effects;
- интеграций с DOM-библиотеками.

## Мини-шпаргалка

- RSC выполняются на сервере.
- Их JavaScript не попадает в client bundle.
- Client Component нужен для интерактива.
- `'use client'` ставит границу клиентского дерева.
- SSR и RSC решают разные задачи, но часто работают вместе.
