# Как проектировать SEO-friendly URL?

> [!summary]
> SEO-friendly URL помогает пользователю и поисковику понять тему страницы. Хороший URL стабилен, читаем, короток, не содержит лишних параметров и отражает структуру сайта.

## Как выглядит хороший URL?

```text
https://example.com/blog/javascript-event-loop
https://example.com/catalog/laptops/macbook-pro-14
```

Он:

- читается человеком;
- описывает содержание;
- не содержит мусорных параметров;
- использует понятные слова;
- стабилен во времени.

## Как выглядит плохой URL?

```text
https://example.com/page?id=8912&ref=main&session=ab12
```

Такой URL сложнее читать, продвигать, запоминать и анализировать.

## Какие правила использовать?

- Используй lowercase.
- Разделяй слова дефисами.
- Не меняй URL без необходимости.
- Не добавляй дату, если контент не привязан к дате.
- Не делай слишком глубокую вложенность.
- Не добавляй служебные параметры в canonical URL.

## Что делать с кириллицей?

Кириллические URL допустимы, но часто превращаются в percent-encoding при копировании:

```text
/%D1%81%D1%82%D0%B0%D1%82%D1%8C%D1%8F
```

Для технических и международных проектов часто удобнее использовать латиницу:

```text
/blog/kak-rabotaet-seo
```

## URL и структура сайта

URL должен помогать понять место страницы:

```text
/docs/vue/router/navigation-guards
```

Но структура не должна быть чрезмерной:

```text
/frontend/frameworks/vue/plugins/router/v4/docs/navigation/guards/basic
```

## Мини-шпаргалка

- URL должен быть понятным и стабильным.
- Слова лучше разделять дефисами.
- Canonical URL не должен содержать лишних параметров.
- Не меняй URL без redirect-плана.
- Структура URL должна помогать, а не превращаться в лабиринт.
