# Можно ли margin задавать отрицательным?

> [!NOTE]
> Да, `margin` можно задавать отрицательным. Отрицательный margin сдвигает элемент или влияет на расстояние между элементами, но использовать его стоит осторожно.

## Главное

```css
.badge {
  margin-top: -8px;
}
```

Элемент может визуально подняться выше своего обычного положения.

## Где применяется

- Небольшие визуальные наложения.
- Компенсация отступов.
- Сдвиг декоративных элементов.
- Legacy-layout, где нельзя быстро изменить структуру.

```css
.avatar {
  margin-top: -24px;
}
```

## Почему опасно

Отрицательные margin могут:

- сделать layout менее предсказуемым;
- вызвать наложения элементов;
- ухудшить адаптивность;
- усложнить поддержку;
- неожиданно взаимодействовать со схлопыванием margin.

## Альтернативы

Для визуального сдвига часто лучше использовать `transform`.

```css
.badge {
  transform: translateY(-8px);
}
```

`transform` не меняет поток документа, а только визуально перемещает элемент.

## Мини-шпаргалка

- Отрицательный margin разрешен.
- Он влияет на layout и соседние элементы.
- Подходит для точечных случаев.
- Для визуального сдвига часто безопаснее `transform`.
- Сложные отрицательные margin лучше пересмотреть архитектурно.
