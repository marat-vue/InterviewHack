> [!summary]
> **Атрибут** - это дополнительная информация в открывающем теге элемента. Атрибуты настраивают поведение, значение, доступность, ссылки, классы и другие свойства элемента.

## Главное

Атрибут обычно состоит из имени и значения.

```html
<a href="/profile" class="link">Профиль</a>
```

Здесь:

- `href="/profile"` указывает адрес ссылки;
- `class="link"` задает CSS-класс;
- `Профиль` - содержимое элемента.

## Типичная форма записи

```html
<tag attribute="value">content</tag>
```

Значение атрибута лучше писать в кавычках, даже если браузер иногда допускает запись без них.

## Булевые атрибуты

Некоторые атрибуты работают самим фактом наличия.

```html
<button disabled>Отправить</button>
<input type="checkbox" checked>
```

`disabled` означает, что кнопка отключена. Не нужно писать `disabled="true"`.

## Глобальные атрибуты

Некоторые атрибуты можно использовать почти на любых HTML-элементах.

```html
<section id="profile" class="card" hidden>
  ...
</section>
```

Частые глобальные атрибуты:

- `id`;
- `class`;
- `title`;
- `hidden`;
- `data-*`;
- `aria-*`.

## Data-атрибуты

`data-*` позволяют хранить пользовательские данные в разметке.

```html
<button data-product-id="42">
  Добавить в корзину
</button>
```

JavaScript может прочитать значение через `dataset`.

```js
const button = document.querySelector("button");

console.log(button.dataset.productId); // "42"
```

## Мини-шпаргалка

- Атрибуты пишутся в открывающем теге.
- Они добавляют элементу настройки и данные.
- `href`, `src`, `alt`, `type`, `class`, `id` - частые атрибуты.
- Булев атрибут работает, если присутствует.
- `data-*` удобно использовать для пользовательских данных.
