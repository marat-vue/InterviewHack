# Что такое LCP и как его улучшать?

> [!summary]
> LCP, Largest Contentful Paint, измеряет время появления крупнейшего значимого элемента в видимой области. Часто это hero-изображение, большой заголовок, постер видео или крупный текстовый блок.

## Что может быть LCP-элементом?

- `img`;
- изображение в `picture`;
- poster у `video`;
- background image;
- крупный текстовый блок.

## Почему LCP бывает плохим?

Причины:

- медленный сервер;
- тяжелое изображение;
- изображение загружается поздно;
- render-blocking CSS;
- слишком много JavaScript;
- медленные шрифты;
- клиентский рендеринг вместо готового HTML.

## Как улучшать LCP?

Практики:

- оптимизировать серверный ответ;
- использовать SSR/SSG для важных страниц;
- сжимать LCP-изображение;
- отдавать WebP/AVIF;
- задать `width` и `height`;
- не ставить `loading="lazy"` на LCP-изображение;
- использовать preload/fetchpriority осторожно;
- уменьшить критический CSS и JS.

Пример:

```html
<img
  src="/hero.webp"
  alt="Панель аналитики SEO-проекта"
  width="1200"
  height="630"
  fetchpriority="high"
>
```

## Как диагностировать?

Смотри:

- PageSpeed Insights;
- Lighthouse;
- Chrome DevTools Performance;
- WebPageTest;
- реальные данные в Search Console.

## Мини-шпаргалка

- LCP - время появления главного контента.
- Частая причина плохого LCP - тяжелое hero-изображение.
- Не lazy-load LCP-картинку.
- SSR/SSG часто помогают контентным страницам.
- Оптимизируй не только файл, но и путь его загрузки.
