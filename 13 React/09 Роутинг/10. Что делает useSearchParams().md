# Что делает useSearchParams()?

> [!summary]
> `useSearchParams` читает и изменяет query-параметры URL. Это удобно для фильтров, сортировки, пагинации и любых настроек страницы, которые должны сохраняться в ссылке.

## Базовый пример

```jsx
import { useSearchParams } from 'react-router-dom'

function ProductsPage() {
  const [searchParams, setSearchParams] = useSearchParams()

  const page = searchParams.get('page') ?? '1'
  const sort = searchParams.get('sort') ?? 'popular'

  return (
    <>
      <p>Page: {page}</p>
      <button onClick={() => setSearchParams({ page: '2', sort })}>
        Go to page 2
      </button>
    </>
  )
}
```

URL станет:

```text
/products?page=2&sort=popular
```

## Что возвращает хук?

```jsx
const [searchParams, setSearchParams] = useSearchParams()
```

`searchParams` - объект `URLSearchParams`.

`setSearchParams` - функция, которая обновляет query string и запускает навигацию.

## Полезные методы URLSearchParams

```jsx
searchParams.get('page')
searchParams.has('sort')
searchParams.getAll('tag')
searchParams.toString()
```

Для нескольких значений:

```text
/products?tag=react&tag=router
```

```jsx
const tags = searchParams.getAll('tag')
```

## Обновление без потери старых параметров

Плохой вариант:

```jsx
setSearchParams({ page: '2' }) // sort и filters исчезнут
```

Лучше:

```jsx
setSearchParams((currentParams) => {
  const nextParams = new URLSearchParams(currentParams)
  nextParams.set('page', '2')
  return nextParams
})
```

## Когда query params лучше state?

Query params хороши, если состояние:

- должно переживать reload;
- должно шариться ссылкой;
- должно работать с Back/Forward;
- описывает фильтры, сортировку, страницу, вкладку.

## Мини-шпаргалка

- `useSearchParams` работает с частью URL после `?`.
- Значения в query string всегда строки.
- `setSearchParams` меняет URL без reload.
- Для нескольких значений используй `getAll`.
- Не затирай старые параметры случайно.
