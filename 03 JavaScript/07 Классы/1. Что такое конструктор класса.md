# Что такое конструктор класса

> [!summary] Коротко
> `constructor` - специальный метод класса, который вызывается при создании нового экземпляра через `new`.

## Вопрос

Что такое конструктор класса и какие задачи он решает?

## Определение

Конструктор класса - метод с именем `constructor`, который инициализирует новый объект. Он получает аргументы из вызова `new ClassName(...)` и обычно записывает начальные значения в свойства экземпляра.

## Пример

```javascript
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user = new User('Ann', 25);

console.log(user.name); // 'Ann'
console.log(user.age);  // 25
```

## Что происходит при new

1. Создается новый объект.
2. Его прототип связывается с `User.prototype`.
3. Вызывается `constructor`.
4. `this` внутри конструктора указывает на новый объект.
5. Новый объект становится результатом выражения `new User(...)`.

## Конструктор не обычный метод

```javascript
class User {
  constructor(name) {
    this.name = name;
  }
}
```

У класса может быть только один `constructor`. Если написать два, будет синтаксическая ошибка.

## Мини-шпаргалка

```javascript
class Name {
  constructor(value) {
    this.value = value;
  }
}
```
