# Как использовать reactive для формы

> [!summary] Коротко
> `reactive` удобно использовать для формы как одного объекта: все поля, ошибки и флаги можно хранить в связанной структуре.

## Вопрос

Как использовать `reactive` для формы?

## Базовый пример

```vue
<script setup>
import { reactive } from "vue";

const form = reactive({
  email: "",
  password: "",
  remember: false,
});
</script>

<template>
  <input v-model="form.email" />
  <input v-model="form.password" type="password" />
  <label>
    <input v-model="form.remember" type="checkbox" />
    Запомнить меня
  </label>
</template>
```

Все поля формы находятся в одном объекте.

## Ошибки формы

```typescript
const errors = reactive({
  email: "",
  password: "",
});

function validate() {
  errors.email = form.email.includes("@") ? "" : "Некорректный email";
  errors.password = form.password.length >= 6 ? "" : "Минимум 6 символов";
}
```

## Отправка

```typescript
async function submit() {
  validate();

  await login({
    email: form.email,
    password: form.password,
    remember: form.remember,
  });
}
```

В отличие от `ref`, у полей `reactive` не нужно писать `.value`.

## Осторожно с деструктуризацией

```typescript
const { email } = form; // потеря реактивной связи
```

Если нужно деструктурировать, используй `toRefs(form)`.

## Мини-шпаргалка

- `reactive` хорош для формы-объекта.
- Поля доступны без `.value`.
- Ошибки и флаги можно хранить рядом.
- Деструктуризация может сломать реактивность.
- Для отдельных независимых полей можно выбрать `ref`.
