# Что происходит в main.ts?

> [!summary]
> `main.ts` - entry point NestJS-приложения. В нем создают приложение через `NestFactory`, настраивают global pipes, filters, interceptors, CORS, Swagger и запускают HTTP-сервер.

## Базовый bootstrap

```ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  await app.listen(3000);
}

bootstrap();
```

`NestFactory.create(AppModule)` строит приложение из корневого модуля.

## Частые настройки

```ts
app.setGlobalPrefix('api');
app.enableCors();
app.useGlobalPipes(new ValidationPipe({ whitelist: true }));
```

Обычно в `main.ts` настраивают инфраструктурное поведение всего приложения.

## Чего избегать

Не стоит писать бизнес-логику в `main.ts`. Он должен быть bootstrap-файлом, а не местом для use cases.

## Мини-шпаргалка

- `main.ts` - entry point.
- `NestFactory.create` создает приложение.
- `app.listen` запускает сервер.
- Global pipes и CORS часто настраивают здесь.
- Бизнес-логика должна быть в services/use cases.
