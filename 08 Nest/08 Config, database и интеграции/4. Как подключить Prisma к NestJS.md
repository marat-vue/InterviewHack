# Как подключить Prisma к NestJS?

> [!summary]
> Prisma в NestJS обычно подключают через `PrismaService`, который расширяет `PrismaClient`, регистрируется как provider и внедряется в domain services.

## PrismaService

```ts
@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
  async onModuleInit() {
    await this.$connect();
  }
}
```

## Module

```ts
@Module({
  providers: [PrismaService],
  exports: [PrismaService],
})
export class PrismaModule {}
```

## Использование

```ts
@Injectable()
export class UsersService {
  constructor(private readonly prisma: PrismaService) {}

  findAll() {
    return this.prisma.user.findMany();
  }
}
```

## Shutdown

В production нужно корректно закрывать соединения при завершении приложения.

```ts
async onModuleDestroy() {
  await this.$disconnect();
}
```

## Мини-шпаргалка

- PrismaClient удобно обернуть в PrismaService.
- PrismaService регистрируют как provider.
- PrismaModule экспортирует PrismaService.
- Не создавай PrismaClient в каждом service.
- Закрывай соединение при shutdown.
