# Что такое серверные компоненты в Next.js?

> [!summary]
> Серверные компоненты в Next.js - React Server Components, которые выполняются на сервере и не отправляют свой код в браузер. В App Router все компоненты серверные по умолчанию, пока файл не помечен директивой `'use client'`.

## Главная идея

Server Component может делать серверную работу прямо во время render:

```tsx
export default async function ProductsPage() {
  const products = await db.product.findMany()

  return <ProductList products={products} />
}
```

Код `db.product.findMany()` не попадет в клиентский bundle.

## Что серверные компоненты умеют?

Можно:

- читать данные из БД;
- читать файлы;
- использовать server-only SDK;
- читать env secrets;
- делать `await`;
- импортировать тяжелые библиотеки, не нужные клиенту;
- передавать сериализуемые props в Client Components.

## Что нельзя?

Нельзя:

- использовать `useState`;
- использовать `useEffect`;
- использовать `useRef` для DOM;
- вешать `onClick`;
- читать `window`;
- читать `localStorage`;
- использовать browser-only библиотеки.

## Server Component с Client Component

```tsx
import { AddToCartButton } from './AddToCartButton'

export default async function ProductPage() {
  const product = await getProduct()

  return (
    <article>
      <h1>{product.title}</h1>
      <AddToCartButton productId={product.id} />
    </article>
  )
}
```

`ProductPage` остается серверным, а интерактивная кнопка может быть клиентской.

## Что отвечать на собеседовании?

Server Components выполняются на сервере, не отправляют свой код в браузер и подходят для data fetching, безопасного доступа к secrets и статичного UI. В Next.js App Router они используются по умолчанию, а Client Components нужны только для интерактивности.

## Частые ошибки

- Пытаться использовать `useState` в Server Component.
- Передавать функции как props в Client Component.
- Импортировать browser-only библиотеку на сервер.
- Ставить `'use client'` слишком высоко.
- Думать, что Server Component - это то же самое, что SSR.

## Мини-шпаргалка

- В App Router компоненты серверные по умолчанию.
- Код Server Component не едет в браузер.
- Можно читать БД и env secrets.
- Нельзя использовать event handlers.
- Client Components можно вкладывать внутрь Server Components.
- Props через границу должны быть сериализуемыми.
