# Как объявить состояние с помощью useState?

> [!summary]
> `useState` - React Hook для добавления state в функциональный компонент. Он возвращает пару: текущее значение состояния и setter-функцию, с помощью которой можно запланировать обновление.

## Базовый синтаксис

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
```

`useState(0)` задает начальное значение `0`.

Возвращается массив из двух элементов:

```jsx
const [state, setState] = useState(initialState)
```

## Как называть state?

Обычно используют пару:

```jsx
const [name, setName] = useState('')
const [isOpen, setIsOpen] = useState(false)
const [items, setItems] = useState([])
```

Так сразу понятно, какое значение обновляет setter.

## Где можно вызывать useState?

`useState` вызывают только:

- на верхнем уровне компонента;
- на верхнем уровне custom hook.

Нельзя:

```jsx
if (isAdmin) {
  const [permissions, setPermissions] = useState([])
}
```

Хуки должны вызываться в одинаковом порядке при каждом render.

## Начальное значение

Можно передать значение:

```jsx
const [query, setQuery] = useState('')
```

Или initializer function для дорогого вычисления:

```jsx
const [todos, setTodos] = useState(() => createInitialTodos())
```

Функция будет использована при инициализации состояния.

## Обновление состояния

Прямое значение:

```jsx
setName('Мария')
```

На основе предыдущего:

```jsx
setCount((count) => count + 1)
```

Для объектов:

```jsx
setUser((user) => ({
  ...user,
  name: 'Мария',
}))
```

## Мини-шпаргалка

- `useState` добавляет state в функциональный компонент.
- Возвращает `[value, setter]`.
- Setter планирует новый render.
- Хуки вызывают только на верхнем уровне.
- Для обновления от предыдущего значения используй updater function.
