# Геттеры и сеттеры в объекте

> [!summary] Коротко
> Getter вызывается при чтении свойства, setter - при присваивании. Они позволяют сделать свойство похожим на обычное поле, но с вычислением или контролем записи.

## Вопрос

Как задать геттер и сеттер в объекте?

## Getter

```javascript
const user = {
  firstName: "Anna",
  lastName: "Smith",

  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  },
};

user.fullName; // "Anna Smith"
```

`fullName` читается как свойство, хотя внутри работает функция.

## Setter

```javascript
const user = {
  firstName: "Anna",
  lastName: "Smith",

  set fullName(value) {
    const [firstName, lastName] = value.split(" ");

    this.firstName = firstName;
    this.lastName = lastName;
  },
};

user.fullName = "Max Payne";

console.log(user.firstName); // "Max"
console.log(user.lastName);  // "Payne"
```

Setter вызывается при присваивании.

## Getter и setter вместе

```javascript
const user = {
  firstName: "Anna",
  lastName: "Smith",

  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  },

  set fullName(value) {
    [this.firstName, this.lastName] = value.split(" ");
  },
};
```

## Через `Object.defineProperty`

```javascript
const user = {
  firstName: "Anna",
  lastName: "Smith",
};

Object.defineProperty(user, "fullName", {
  get() {
    return `${this.firstName} ${this.lastName}`;
  },
  set(value) {
    [this.firstName, this.lastName] = value.split(" ");
  },
});
```

## Подводные камни

Не называйте внутреннее поле так же, как setter, иначе будет рекурсия.

```javascript
const user = {
  set name(value) {
    this.name = value; // бесконечный вызов setter
  },
};
```

Используйте другое внутреннее имя:

```javascript
const user = {
  _name: "",

  set name(value) {
    this._name = value;
  },

  get name() {
    return this._name;
  },
};
```

## Мини-шпаргалка

| Синтаксис | Когда вызывается |
| --- | --- |
| `get prop() {}` | при чтении `obj.prop` |
| `set prop(value) {}` | при записи `obj.prop = value` |
| `Object.defineProperty` | для настройки descriptor |
| внутреннее поле `_prop` | чтобы избежать рекурсии |
