# Tailwind в компонентах темы responsive и dark mode

> [!summary]
> В React Tailwind лучше использовать через переиспользуемые компоненты, аккуратную композицию `className`, responsive variants и dark mode. Повторяющиеся паттерны стоит прятать в UI-компоненты, а не копировать длинные строки классов.

## Переиспользуемый компонент

```tsx
type ButtonProps = React.ComponentProps<'button'> & {
  variant?: 'primary' | 'ghost'
}

function Button({ variant = 'primary', className = '', ...props }: ButtonProps) {
  const base = 'inline-flex items-center justify-center rounded-md px-4 py-2 text-sm font-medium transition-colors disabled:opacity-50'
  const variants = {
    primary: 'bg-blue-600 text-white hover:bg-blue-700',
    ghost: 'bg-transparent text-zinc-700 hover:bg-zinc-100',
  }

  return (
    <button
      className={`${base} ${variants[variant]} ${className}`}
      {...props}
    />
  )
}
```

В больших проектах для классов часто используют `clsx`, `classnames`, `tailwind-merge` или `class-variance-authority`.

## Responsive пример

```tsx
function ProductLayout() {
  return (
    <div className="grid gap-6 lg:grid-cols-[280px_1fr]">
      <aside className="hidden lg:block">
        Filters
      </aside>

      <main className="grid gap-4 sm:grid-cols-2 xl:grid-cols-3">
        Products
      </main>
    </div>
  )
}
```

Tailwind mobile-first: сначала описывай mobile, потом добавляй `sm:`, `md:`, `lg:`.

## Dark mode

```tsx
<div className="bg-white text-zinc-950 dark:bg-zinc-950 dark:text-zinc-50">
  Content
</div>
```

Обычно тема переключается через class на `html`:

```ts
document.documentElement.classList.toggle('dark', theme === 'dark')
```

## group и peer

`group` позволяет менять дочерний элемент при hover родителя:

```tsx
<article className="group rounded-lg border p-4 hover:border-blue-500">
  <h2 className="text-zinc-900 group-hover:text-blue-600">
    Product
  </h2>
</article>
```

`peer` позволяет реагировать на состояние соседнего input:

```tsx
<input id="agree" type="checkbox" className="peer" />
<label htmlFor="agree" className="text-zinc-500 peer-checked:text-blue-600">
  I agree
</label>
```

## Что отвечать на собеседовании?

В React Tailwind используют через `className`, но для повторяющихся элементов создают компоненты с variants. Responsive делается mobile-first через prefixes, dark mode - через `dark:` variant, а сложные состояния можно строить через `group`, `peer`, `data-*` и условную композицию классов.

## Мини-шпаргалка

- Повторяющийся UI выноси в компонент.
- Mobile-first: база, потом `md:`, `lg:`.
- Dark mode: `dark:bg-zinc-950`.
- Parent state: `group-hover:`.
- Sibling state: `peer-checked:`.
- Для конфликтов классов помогает `tailwind-merge`.
