# `copyWithin()`

> [!summary] Коротко
> `copyWithin()` копирует часть массива в другую позицию внутри того же массива, не меняет длину и мутирует исходный массив.

## Вопрос

Что делает `copyWithin()`?

## Синтаксис

```javascript
arr.copyWithin(target, start, end);
```

- `target` - индекс, куда копировать;
- `start` - откуда начать копирование;
- `end` - где остановиться, не включая этот индекс.

## Пример

```javascript
const arr = [1, 2, 3, 4, 5];

arr.copyWithin(0, 3);

console.log(arr); // [4, 5, 3, 4, 5]
```

Элементы с индексов `3` и `4` скопировались в начало.

## С `end`

```javascript
const arr = [1, 2, 3, 4, 5];

arr.copyWithin(1, 3, 5);

console.log(arr); // [1, 4, 5, 4, 5]
```

Копируется диапазон `[start, end)`.

## Мутация и длина

```javascript
const arr = [1, 2, 3];
const result = arr.copyWithin(1, 0);

console.log(result === arr); // true
console.log(arr.length);     // 3
```

Метод возвращает тот же массив и не меняет длину.

## Отрицательные индексы

```javascript
const arr = [1, 2, 3, 4, 5];

arr.copyWithin(-2, 0, 2);

console.log(arr); // [1, 2, 3, 1, 2]
```

## Когда встречается

`copyWithin()` используется редко. Он полезен для низкоуровневых преобразований массива, буферов и ситуаций, где важно менять массив на месте без выделения новой памяти.

## Мини-шпаргалка

| Свойство | `copyWithin()` |
| --- | --- |
| мутирует массив | да |
| меняет длину | нет |
| возвращает | тот же массив |
| копирует | внутри массива |
| диапазон | `[start, end)` |
