# Функция-обертка

> [!NOTE] Коротко
> Функция-обертка вызывает другую функцию внутри себя и добавляет поведение вокруг вызова: логирование, проверку, обработку ошибок, кэширование или замер времени.

## Вопрос

Что такое функция-обертка?

## Базовая идея

```javascript
function wrapper() {
  console.log("До вызова");
  originalFunction();
  console.log("После вызова");
}
```

Обертка не обязательно меняет исходную функцию. Она добавляет дополнительный слой поведения.

## Пример с логированием

```javascript
function saveUser(user) {
  console.log("Сохраняем", user.name);
}

function saveUserWithLog(user) {
  console.log("Начало операции");
  saveUser(user);
  console.log("Конец операции");
}
```

## Обертка с `try...catch`

```javascript
function safeParse(json) {
  try {
    return JSON.parse(json);
  } catch (error) {
    return null;
  }
}
```

`safeParse` оборачивает опасный вызов `JSON.parse`.

## Обертка, сохраняющая аргументы

```javascript
function withLog(fn) {
  return function (...args) {
    console.log("args:", args);

    return fn(...args);
  };
}

const loggedSum = withLog((a, b) => a + b);

loggedSum(2, 3); // 5
```

Такая обертка уже похожа на декоратор.

## Зачем используют

- логирование;
- метрики;
- обработка ошибок;
- проверка прав;
- валидация аргументов;
- повторные попытки;
- кэширование.

## Мини-шпаргалка

```javascript
function wrapper(...args) {
  before();
  const result = fn(...args);
  after();
  return result;
}
```

| Идея | Пример |
| --- | --- |
| До вызова | логирование аргументов |
| После вызова | замер времени |
| Вместо ошибки | fallback |
| Вокруг вызова | `try...catch` |
