# Что означает реактивность состояния

> [!summary] Коротко
> Реактивность состояния означает, что Vue отслеживает зависимости от state и автоматически обновляет шаблон, computed и watchers при изменении данных.

## Вопрос

Что означает реактивность состояния?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

Когда `count` меняется, Vue обновляет текст кнопки.

## Реактивность не равна мутации DOM

Разработчик меняет данные, а Vue сам решает, как обновить DOM.

```typescript
count.value++;
```

Не нужно писать `button.textContent = ...`.

## Зависимости собираются при чтении

Если компонент читает значение в template или computed, Vue связывает этот компонент с данными.

```typescript
const fullName = computed(() => `${firstName.value} ${lastName.value}`);
```

`fullName` зависит от `firstName` и `lastName`.

## Мини-шпаргалка

- State реактивен, если Vue умеет отслеживать его изменения.
- `ref` и `reactive` создают реактивные значения.
- Template автоматически обновляется.
- `computed` и `watch` тоже зависят от реактивности.
