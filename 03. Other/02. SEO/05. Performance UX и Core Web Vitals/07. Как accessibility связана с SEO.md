# Как accessibility связана с SEO?

> [!summary]
> Accessibility и SEO пересекаются в семантике, доступности контента, навигации и качестве UX. Это разные дисциплины, но многие хорошие практики помогают и пользователям, и поисковым системам.

## Где они пересекаются?

- Семантический HTML.
- Понятные заголовки.
- Описательные ссылки.
- `alt` для значимых изображений.
- Доступные формы.
- Правильные кнопки и ссылки.
- Контраст и читаемость.
- Навигация с клавиатуры.

## Пример

Плохо:

```html
<div onclick="goToProduct()">Подробнее</div>
```

Лучше:

```html
<a href="/products/backpack">Рюкзак для ноутбука</a>
```

Так ссылка доступна пользователям, клавиатуре, скринридерам и поисковикам.

## Что accessibility не гарантирует?

Доступность сама по себе не гарантирует высокие позиции. Но плохая доступность часто совпадает с плохим UX и слабой HTML-структурой.

## Какие проверки полезны?

- Lighthouse Accessibility.
- Навигация Tab/Shift+Tab.
- Проверка alt.
- Проверка heading outline.
- Проверка контраста.
- Проверка форм и label.

## Мини-шпаргалка

- Accessibility и SEO объединяет понятный HTML.
- Настоящие ссылки лучше JS-кликов.
- `alt` нужен для смысла, а не для спама ключами.
- Заголовки помогают сканировать страницу.
- Улучшая доступность, часто улучшаешь качество страницы.
