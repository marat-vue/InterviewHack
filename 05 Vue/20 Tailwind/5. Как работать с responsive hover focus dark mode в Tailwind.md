# Как работать с responsive, hover, focus и dark mode в Tailwind?

> [!summary]
> Tailwind variants добавляют условия к utility classes: `md:`, `hover:`, `focus:`, `disabled:`, `dark:`. Это позволяет описывать адаптивность и состояния прямо в class attribute.

## Responsive

```vue
<div class="grid gap-4 md:grid-cols-2 xl:grid-cols-4">
  ...
</div>
```

Базовые classes работают mobile-first. `md:grid-cols-2` применится начиная с breakpoint `md`.

## Hover и focus

```vue
<button class="bg-blue-600 text-white hover:bg-blue-700 focus:outline-2 focus:outline-blue-500">
  Сохранить
</button>
```

States должны помогать UX:

- hover показывает интерактивность;
- focus важен для keyboard navigation;
- disabled показывает недоступность.

## Disabled

```vue
<button
  :disabled="isSaving"
  class="bg-blue-600 text-white disabled:cursor-not-allowed disabled:opacity-50"
>
  Сохранить
</button>
```

## Dark mode

```vue
<div class="bg-white text-slate-900 dark:bg-slate-950 dark:text-white">
  ...
</div>
```

Dark mode обычно завязан на class или data attribute на корневом элементе. Для управления состоянием можно использовать VueUse `useDark`.

## Сочетание variants

```vue
<button class="hover:bg-blue-700 md:hover:bg-blue-800 dark:hover:bg-blue-500">
  Button
</button>
```

Не злоупотребляй: если class list становится нечитаемым, вынеси часть в компонент.

## Мини-шпаргалка

- Tailwind mobile-first.
- `md:` и `xl:` применяются от breakpoint и выше.
- `hover:` описывает hover state.
- `focus:` важен для accessibility.
- `disabled:` помогает отображать disabled state.
- `dark:` применяет стили для dark mode.
