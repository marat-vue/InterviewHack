# Что такое mixins

> [!summary] Коротко
> Mixins - старый способ переиспользовать Options API логику между компонентами. Они смешивают `data`, `methods`, hooks и другие опции с компонентом, но могут делать зависимости неявными.

## Вопрос

Что такое `mixins`?

## Базовый пример

```javascript
const loadingMixin = {
  data() {
    return {
      isLoading: false,
    };
  },
  methods: {
    setLoading(value) {
      this.isLoading = value;
    },
  },
};

export default {
  mixins: [loadingMixin],
};
```

Компонент получает `isLoading` и `setLoading`.

## Проблемы mixins

- Непонятно, откуда пришло свойство или метод.
- Возможны конфликты имен.
- Сложнее типизировать.
- Труднее отслеживать зависимости.

## Современная альтернатива

В Vue 3 чаще используют composables.

```typescript
export function useLoading() {
  const isLoading = ref(false);
  const setLoading = (value: boolean) => {
    isLoading.value = value;
  };

  return { isLoading, setLoading };
}
```

Composable явно импортируется и возвращает нужные значения.

## Мини-шпаргалка

- Mixin смешивает опции с компонентом.
- Встречается в legacy Vue 2 коде.
- Может создавать скрытые зависимости.
- В новом Vue 3 коде чаще выбирают composables.
