# Изменение `length` вручную

> [!summary] Коротко
> `length` у массива можно менять вручную. Уменьшение `length` обрезает массив, увеличение создает пустые слоты.

## Вопрос

Что произойдет, если изменить `length` вручную?

## Уменьшение `length`

```javascript
const numbers = [1, 2, 3, 4, 5];

numbers.length = 3;

console.log(numbers); // [1, 2, 3]
```

Элементы с индексами `3` и выше удаляются.

## Увеличение `length`

```javascript
const numbers = [1, 2, 3];

numbers.length = 6;

console.log(numbers); // [1, 2, 3, empty × 3]
```

Появляются пустые слоты. Это не то же самое, что `undefined`.

## Пустые слоты

Некоторые методы пропускают empty slots.

```javascript
const arr = [1, 2];
arr.length = 4;

arr.forEach((item) => console.log(item));
// 1
// 2
```

Но чтение вернет `undefined`:

```javascript
arr[3]; // undefined
```

## Очистка массива

```javascript
const items = [1, 2, 3];

items.length = 0;

console.log(items); // []
```

Это мутирует исходный массив.

## Когда осторожно

Ручное изменение `length` может сделать массив разреженным и усложнить поведение методов. В обычном коде чаще используют методы вроде `slice`, `splice`, `push`, `pop`.

## Мини-шпаргалка

| Операция | Результат |
| --- | --- |
| `arr.length = меньше` | массив обрезается |
| `arr.length = больше` | появляются empty slots |
| `arr.length = 0` | массив очищается |
| чтение empty slot | `undefined` |
| `forEach` по empty slots | пропускает |
