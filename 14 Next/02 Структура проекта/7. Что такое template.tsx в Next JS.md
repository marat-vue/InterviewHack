# Что такое template.tsx в Next JS?

> [!summary]
> `template.tsx` похож на `layout.tsx`, но в отличие от layout создает новый экземпляр при навигации. Его используют, когда нужно сбросить состояние, заново запустить эффекты или анимации для дочернего сегмента.

## Чем template отличается от layout?

| Файл | Поведение |
|---|---|
| `layout.tsx` | сохраняется между переходами |
| `template.tsx` | перемонтируется при навигации |

Layout хорош для стабильной оболочки. Template хорош для reset.

## Пример

```tsx
export default function Template({ children }: { children: React.ReactNode }) {
  return <div className="page-transition">{children}</div>
}
```

Структура:

```text
app/
  dashboard/
    template.tsx
    settings/
      page.tsx
    billing/
      page.tsx
```

При переходе между дочерними routes template будет создаваться заново.

## Когда использовать template?

Подходит, если нужно:

- сбросить state формы;
- заново запустить animation;
- отправить page view analytics;
- сбросить scroll/локальный UI;
- пересоздать context provider для сегмента.

## Когда не использовать?

Не нужен для:

- обычного header/sidebar;
- persistent navigation;
- layout shell;
- providers, которые должны сохранять состояние;
- глобальных тем и auth wrappers.

## Layout плюс template

Можно использовать оба:

```text
app/
  dashboard/
    layout.tsx
    template.tsx
    page.tsx
```

Layout сохраняет dashboard shell, template сбрасывает содержимое страницы.

## Что отвечать на собеседовании?

`template.tsx` - специальный файл App Router, который похож на layout, но перемонтируется при навигации. Его выбирают, когда нужно сбросить состояние или заново выполнить эффекты для дочернего route. Для постоянной оболочки лучше `layout.tsx`.

## Частые ошибки

- Использовать template вместо layout для sidebar.
- Не понимать, почему state сбрасывается.
- Добавлять template без реальной причины.
- Класть глобальные providers в template.
- Путать reset поведения с revalidation данных.

## Мини-шпаргалка

- `layout.tsx` сохраняется.
- `template.tsx` перемонтируется.
- Template полезен для animations и reset.
- Providers с долгим state лучше держать в layout.
- Template принимает `children`.
