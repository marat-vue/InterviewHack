# Какие единицы измерения можно использовать для размера шрифта

> [!summary]
> Размер шрифта задают свойством `font-size`. Чаще всего используют `px`, `rem`, `em`, проценты и иногда viewport-единицы, но для доступной типографики обычно удобнее `rem`.

## Главное

```css
body {
  font-size: 1rem;
}

h1 {
  font-size: 2rem;
}
```

`rem` считается от размера шрифта корневого элемента `html`.

## Частые единицы

| Единица | Особенность |
| --- | --- |
| `px` | Фиксированный CSS-пиксель |
| `rem` | Относительно `html` |
| `em` | Относительно текущего элемента |
| `%` | Относительно родительского размера шрифта |
| `vw` | От ширины viewport |

## px

```css
.caption {
  font-size: 14px;
}
```

`px` понятен и точен, но хуже подстраивается под пользовательские настройки, если использовать его повсюду.

## rem

```css
.title {
  font-size: 1.5rem;
}
```

Если пользователь увеличит базовый размер шрифта, `rem`-типографика лучше подстроится.

## em

```css
.button {
  font-size: 1rem;
  padding: 0.5em 1em;
}
```

`em` удобно использовать для отступов, которые должны масштабироваться вместе с текстом элемента.

## Мини-шпаргалка

- `font-size` задает размер шрифта.
- `px` фиксированнее и проще.
- `rem` удобен для масштабируемой типографики.
- `em` зависит от текущего элемента.
- `%` зависит от родителя.
- Не стоит делать текст слишком мелким ради макета.
