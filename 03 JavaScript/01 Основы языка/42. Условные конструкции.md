# Условные конструкции

> [!summary] Коротко
> Условные конструкции позволяют выполнять разный код в зависимости от условия. Основные инструменты: `if...else`, `switch`, тернарный оператор, логические операторы и `??`.

## Вопрос

Расскажите про все способы работы с условными конструкциями, о которых вы знаете.

## `if...else`

Основной способ ветвления.

```javascript
if (age >= 18) {
  console.log("Можно зарегистрироваться");
} else {
  console.log("Нужен возраст 18+");
}
```

Условие приводится к boolean по правилам truthy/falsy.

## `else if`

Подходит, когда вариантов несколько.

```javascript
if (score >= 90) {
  grade = "A";
} else if (score >= 70) {
  grade = "B";
} else {
  grade = "C";
}
```

## `switch`

Удобен, когда одно значение сравнивается с несколькими вариантами.

```javascript
switch (role) {
  case "admin":
    access = "full";
    break;
  case "user":
    access = "limited";
    break;
  default:
    access = "none";
}
```

`switch` использует строгое сравнение, близкое к `===`.

## Тернарный оператор

Возвращает значение.

```javascript
const label = isLoading ? "Загрузка..." : "Отправить";
```

Хорош для короткого выбора, но не для сложной логики.

## Логические операторы

`&&` выполняет правую часть только если левая truthy.

```javascript
isVisible && renderModal();
```

`||` возвращает первое truthy-значение.

```javascript
const name = inputName || "Гость";
```

`??` возвращает fallback только для `null` и `undefined`.

```javascript
const page = currentPage ?? 1;
```

## Guard clause

Ранний выход часто делает код проще.

```javascript
function getDiscount(user) {
  if (!user) return 0;
  if (!user.isActive) return 0;

  return 10;
}
```

## Мини-шпаргалка

| Инструмент | Когда использовать |
| --- | --- |
| `if...else` | обычное ветвление |
| `else if` | несколько условий |
| `switch` | много вариантов одного значения |
| `?:` | короткий выбор значения |
| `&&` | выполнить/вернуть при truthy |
| `||` | fallback для falsy |
| `??` | fallback для `null`/`undefined` |
