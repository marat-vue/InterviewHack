# Что делает is()?

> [!NOTE]
> `:is()` группирует несколько селекторов внутри одного условия и помогает писать короче. Его специфичность равна специфичности самого сильного селектора внутри.

## Главное

```css
:is(h1, h2, h3) {
  line-height: 1.2;
}
```

Это короче, чем:

```css
h1,
h2,
h3 {
  line-height: 1.2;
}
```

## Упрощение длинных селекторов

```css
.article :is(h2, h3, h4) {
  margin-block-start: 2rem;
}
```

Правило применится к `h2`, `h3` и `h4` внутри `.article`.

## Специфичность

`:is()` берет специфичность самого специфичного селектора внутри.

```css
:is(.card, #featured) h2 {
  color: #2563eb;
}
```

Из-за `#featured` специфичность всего `:is()` станет выше.

## Отличие от where()

```css
:is(.card, .panel) h2 {
  margin: 0;
}

:where(.card, .panel) h2 {
  margin: 0;
}
```

`:is()` учитывает специфичность аргументов, а `:where()` всегда имеет нулевую специфичность.

## Мини-шпаргалка

- `:is()` сокращает группировку селекторов.
- Удобен для длинных вложенных правил.
- Специфичность равна самому сильному аргументу.
- Не путать с `:where()`.
- Помогает писать CSS компактнее.
