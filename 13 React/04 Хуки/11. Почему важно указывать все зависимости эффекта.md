# Почему важно указывать все зависимости эффекта?

> [!summary]
> Dependencies в `useEffect` описывают reactive values, которые effect использует: props, state и значения, созданные внутри компонента. Если зависимость пропустить, effect может работать со старым значением и создавать трудноуловимые баги.

## Пример пропущенной зависимости

```jsx
function UserPage({ userId }) {
  useEffect(() => {
    loadUser(userId)
  }, [])

  return <div>Профиль</div>
}
```

Если `userId` изменится, effect не запустится заново и загрузит не того пользователя.

Правильно:

```jsx
useEffect(() => {
  loadUser(userId)
}, [userId])
```

## Что считается зависимостью?

Обычно в dependencies указывают:

- props;
- state;
- переменные, объявленные в компоненте;
- функции, объявленные в компоненте;
- значения из custom hooks;
- memoized values, если effect их использует.

## Почему функции тоже зависимости?

```jsx
function Search({ query }) {
  function fetchResults() {
    return api.search(query)
  }

  useEffect(() => {
    fetchResults()
  }, [])
}
```

`fetchResults` использует `query`, значит effect зависит от результата текущего render.

Часто лучше перенести функцию внутрь effect:

```jsx
useEffect(() => {
  function fetchResults() {
    return api.search(query)
  }

  fetchResults()
}, [query])
```

## Что делать, если effect запускается слишком часто?

Не удаляй зависимости механически. Лучше:

- убрать лишний effect;
- вынести вычисление в render;
- перенести функцию внутрь effect;
- стабилизировать значение через `useMemo` или `useCallback`;
- разделить effect на несколько;
- пересмотреть структуру state.

## ESLint exhaustive-deps

Правило `react-hooks/exhaustive-deps` помогает находить пропущенные зависимости.

Если хочется отключить правило, сначала нужно понять, почему effect вообще устроен так сложно.

## Мини-шпаргалка

- Dependencies должны отражать все reactive values внутри effect.
- Пропущенная зависимость дает stale value.
- Не лечи частые запуски удалением dependency.
- Функции из компонента тоже могут быть зависимостями.
- ESLint для hooks - обязательный помощник.
