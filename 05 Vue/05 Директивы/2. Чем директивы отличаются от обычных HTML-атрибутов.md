# Чем директивы отличаются от обычных HTML-атрибутов

> [!summary] Коротко
> HTML-атрибуты задают статические свойства элемента, а директивы Vue подключают реактивное поведение: условия, циклы, события, привязку данных и двустороннее связывание.

## Вопрос

Чем директивы отличаются от обычных HTML-атрибутов?

## Обычный HTML-атрибут

HTML-атрибут просто описывает свойство элемента.

```html
<button disabled>Сохранить</button>
<a href="/profile">Профиль</a>
```

Значение задано прямо в разметке и само по себе не связано с состоянием Vue.

## Директива Vue

Директива может использовать реактивные данные и обновлять DOM при их изменении.

```vue
<script setup>
import { ref } from "vue";

const isSaving = ref(false);
const profileUrl = "/profile";
</script>

<template>
  <button :disabled="isSaving">Сохранить</button>
  <a :href="profileUrl">Профиль</a>
</template>
```

Если `isSaving` изменится, Vue обновит `disabled`.

## Главное отличие

Атрибут - статическое описание элемента. Директива - инструкция Vue, как связать элемент с состоянием, событием или условием.

## Примеры директив

```vue
<p v-if="isVisible">Виден</p>
<li v-for="todo in todos" :key="todo.id">{{ todo.title }}</li>
<button @click="save">Сохранить</button>
<input v-model="email" />
```

## Мини-шпаргалка

- HTML-атрибут работает как обычная разметка.
- Директива начинается с `v-` или сокращения `:`/`@`.
- Директива может читать реактивные данные.
- Vue обновляет DOM, когда данные директивы меняются.
