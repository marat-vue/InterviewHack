# Какие cookie, session, security и CORS utilities H3 нужно знать?

> [!NOTE]
> H3 содержит helpers для cookies, basic auth, sessions, CORS и path normalization. Для полноценной пользовательской auth-системы обычно подключают Better Auth, но базовые H3 utilities важно знать для middleware, sessions и security headers.

## Cookie utilities

| Метод | Зачем нужен |
|---|---|
| `getCookie(event, name)` | получить cookie по имени |
| `setCookie(event, name, value, options?)` | установить cookie |
| `deleteCookie(event, name, options?)` | удалить cookie |
| `parseCookies(event)` | получить объект всех cookies |
| `getChunkedCookie(event, name)` | прочитать cookie, разбитую на chunks |
| `setChunkedCookie(event, name, value, options?)` | установить большую cookie chunks |
| `deleteChunkedCookie(event, name, options?)` | удалить chunked cookie |
| `getValidatedCookies(event, validate, options?)` | прочитать и валидировать cookies |

Пример:

```ts
import { getCookie, setCookie } from 'h3';

export default defineHandler((event) => {
  const theme = getCookie(event, 'theme') || 'light';

  setCookie(event, 'theme', 'dark', {
    httpOnly: true,
    sameSite: 'lax',
    secure: true,
    path: '/',
  });

  return {
    previous: theme,
  };
});
```

## Как настраивать auth cookies?

Для session/auth cookies обычно нужны:

- `httpOnly: true` - JS в браузере не читает cookie;
- `secure: true` - отправлять только по HTTPS;
- `sameSite: 'lax'` или `'strict'` - защита от части CSRF-сценариев;
- `path: '/'` - область действия;
- разумный `maxAge`;
- аккуратный `domain`.

## Basic auth utilities

| Метод | Зачем нужен |
|---|---|
| `basicAuth(opts)` | создать middleware basic auth |
| `requireBasicAuth(event, opts)` | потребовать basic auth в текущем handler |

Пример:

```ts
import { requireBasicAuth } from 'h3';

export default defineHandler(async (event) => {
  await requireBasicAuth(event, {
    password: process.env.ADMIN_PASSWORD!,
  });

  return {
    secret: true,
  };
});
```

Basic auth подходит для internal/staging endpoints, но не заменяет нормальную user authentication.

## Session utilities

| Метод | Зачем нужен |
|---|---|
| `useSession(event, config)` | создать session manager |
| `getSession(event, config)` | получить session data |
| `updateSession(event, config, update?)` | обновить session |
| `clearSession(event, config)` | очистить session |
| `sealSession(event, config)` | зашифровать и подписать session |
| `unsealSession(event, config, sealed)` | расшифровать и проверить sealed session |

H3 sessions полезны для простых server-side sessions. Для сложного auth, OAuth, email/password, multi-session и plugins чаще выбирают Better Auth.

## CORS utilities

| Метод | Зачем нужен |
|---|---|
| `handleCors(event, options)` | обработать CORS и preflight |
| `appendCorsHeaders(event, options)` | добавить CORS response headers |
| `appendCorsPreflightHeaders(event, options)` | добавить preflight headers |
| `isCorsOriginAllowed(origin, options)` | проверить origin по CORS config |
| `isPreflightRequest(event)` | проверить, является ли запрос preflight |

Пример:

```ts
import { handleCors } from 'h3';

export default defineEventHandler((event) => {
  const cors = handleCors(event, {
    origin: ['https://app.example.com'],
    methods: ['GET', 'POST'],
    credentials: true,
  });

  if (cors !== false) {
    return cors;
  }
});
```

## Path security utilities

| Метод | Зачем нужен |
|---|---|
| `isCanonicalPath(path, opts?)` | проверить, что path уже canonical |
| `resolveDotSegments(path, opts?)` | нормализовать `.` и `..` segments без выхода выше root |

Полезно для protected files, custom static serving, proxy allowlists и любых операций, где path приходит от пользователя.

## Fingerprint utility

| Метод | Зачем нужен |
|---|---|
| `getRequestFingerprint(event, opts)` | получить fingerprint запроса |

Может использоваться для rate limit, logging, bot heuristics, но не должен быть единственным security factor.

## Мини-шпаргалка

- Cookies: `getCookie`, `setCookie`, `deleteCookie`, chunked cookie helpers.
- Basic auth: `basicAuth`, `requireBasicAuth`.
- Sessions: `useSession`, `getSession`, `updateSession`, `clearSession`.
- CORS: `handleCors`, `isPreflightRequest`, `appendCorsHeaders`.
- Path safety: `resolveDotSegments`, `isCanonicalPath`.
- Для полноценной auth чаще используй Better Auth.
