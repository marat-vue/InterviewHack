# Ошибки и их обработка

> [!NOTE] Коротко
> Ошибки в JavaScript обрабатывают через `try...catch`, выбрасывают через `throw`, а для асинхронного кода используют `try...catch` вместе с `async/await` или `.catch()` у промисов.

## Вопрос

Как отслеживать и обрабатывать ошибки в JavaScript?

## Зачем нужна обработка ошибок

Ошибка не всегда означает "программа сломалась навсегда". Иногда это ожидаемая ситуация:

- сервер недоступен;
- пользователь ввел некорректные данные;
- JSON оказался неправильным;
- нужного свойства нет;
- операция запрещена.

Задача обработки ошибок - не скрыть проблему, а управляемо на нее отреагировать.

## `try...catch`

```javascript
try {
  riskyOperation();
} catch (error) {
  console.error(error);
}
```

Если внутри `try` возникает ошибка, выполнение переходит в `catch`.

```javascript
try {
  JSON.parse("{bad json}");
} catch (error) {
  console.log("Не удалось распарсить JSON");
}
```

## `finally`

`finally` выполняется всегда: была ошибка или нет.

```javascript
try {
  openConnection();
  sendData();
} catch (error) {
  console.error(error);
} finally {
  closeConnection();
}
```

Его используют для очистки ресурсов, остановки загрузки, закрытия соединений.

## `throw`

`throw` выбрасывает ошибку вручную.

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error("Деление на ноль");
  }

  return a / b;
}
```

Лучше выбрасывать объект `Error`, а не строку:

```javascript
throw new Error("Что-то пошло не так");
```

## Типы ошибок

```javascript
new Error("Common error");
new TypeError("Wrong type");
new ReferenceError("Variable is not defined");
new SyntaxError("Invalid syntax");
new RangeError("Value out of range");
```

В реальном коде часто проверяют тип ошибки:

```javascript
try {
  run();
} catch (error) {
  if (error instanceof TypeError) {
    console.log("Ошибка типа");
  }
}
```

## Асинхронные ошибки

С `async/await`:

```javascript
async function loadUser() {
  try {
    const response = await fetch("/api/user");
    const user = await response.json();
    return user;
  } catch (error) {
    console.error("Не удалось загрузить пользователя", error);
    return null;
  }
}
```

С промисами:

```javascript
fetch("/api/user")
  .then((response) => response.json())
  .catch((error) => {
    console.error(error);
  });
```

## Важная ловушка

`try...catch` не поймает ошибку внутри асинхронного callback, если она произошла позже.

```javascript
try {
  setTimeout(() => {
    throw new Error("Boom");
  }, 1000);
} catch (error) {
  // не сработает
}
```

Ошибку нужно ловить внутри callback или использовать промисы.

## Практический пример

```javascript
function parseConfig(json) {
  try {
    return JSON.parse(json);
  } catch (error) {
    return {
      theme: "light",
      pageSize: 20,
    };
  }
}
```

Здесь ошибка парсинга не ломает приложение: функция возвращает настройки по умолчанию.

## Мини-шпаргалка

```javascript
try {
  risky();
} catch (error) {
  handle(error);
} finally {
  cleanup();
}

throw new Error("Message");
```

| Инструмент | Задача |
| --- | --- |
| `try` | код, который может упасть |
| `catch` | обработка ошибки |
| `finally` | действие в любом случае |
| `throw` | выбросить ошибку |
| `.catch()` | обработать ошибку промиса |
