# Как работают Vite plugins?

> [!summary]
> Vite plugins расширяют обработку проекта: Vue SFC, Tailwind CSS, Vuetify auto-imports, SVG loaders, PWA, compression, bundle analysis и другие возможности подключаются через `plugins` в `vite.config.ts`.

## Базовый vite.config.ts

```typescript
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

export default defineConfig({
  plugins: [vue()],
});
```

`@vitejs/plugin-vue` учит Vite обрабатывать `.vue` Single File Components.

## Несколько plugins

```typescript
import vue from "@vitejs/plugin-vue";
import tailwindcss from "@tailwindcss/vite";
import vuetify from "vite-plugin-vuetify";

export default defineConfig({
  plugins: [
    vue(),
    tailwindcss(),
    vuetify({ autoImport: true }),
  ],
});
```

Порядок plugins иногда важен, особенно если они обрабатывают одни и те же файлы или CSS.

## Что plugins могут делать?

- transform files;
- resolve imports;
- inject virtual modules;
- optimize dev server behavior;
- менять build output;
- подключать framework-specific HMR;
- генерировать assets.

## Частые plugins во Vue

| Plugin | Для чего |
|---|---|
| `@vitejs/plugin-vue` | Vue SFC |
| `@tailwindcss/vite` | Tailwind CSS v4 |
| `vite-plugin-vuetify` | Vuetify integration |
| `unplugin-auto-import` | auto-import APIs |
| `unplugin-vue-components` | auto-import components |
| `vite-plugin-pwa` | PWA |

## Мини-шпаргалка

- Plugins подключаются в `vite.config.ts`.
- Vue требует `@vitejs/plugin-vue`.
- Tailwind v4 имеет официальный Vite plugin.
- Vuetify часто использует `vite-plugin-vuetify`.
- Порядок plugins может иметь значение.
