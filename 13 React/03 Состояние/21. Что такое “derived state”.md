# Что такое derived state?

> [!summary]
> Derived state - это значение, которое можно вычислить из props или другого state. Его часто не нужно хранить отдельно, потому что дублирование состояния приводит к рассинхронизации и лишней сложности.

## Пример лишнего derived state

```jsx
function UserProfile({ firstName, lastName }) {
  const [fullName, setFullName] = useState(`${firstName} ${lastName}`)

  return <h1>{fullName}</h1>
}
```

Если `firstName` изменится, `fullName` может остаться старым.

Лучше:

```jsx
function UserProfile({ firstName, lastName }) {
  const fullName = `${firstName} ${lastName}`

  return <h1>{fullName}</h1>
}
```

## Когда не нужно хранить значение в state?

Не храни в state:

- отфильтрованный список, если есть исходный список и фильтр;
- `fullName`, если есть `firstName` и `lastName`;
- `isEmpty`, если есть `items.length`;
- `totalPrice`, если есть `cartItems`;
- выбранный объект, если можно хранить `selectedId`.

Пример:

```jsx
const visibleTodos = todos.filter((todo) => todo.status === status)
```

## Когда useMemo уместен?

Если вычисление дорогое:

```jsx
const visibleTodos = useMemo(() => {
  return todos.filter((todo) => todo.status === status)
}, [todos, status])
```

`useMemo` не делает значение state. Он просто мемоизирует вычисление между render.

## Когда derived state все-таки нужен?

Иногда локальная копия prop нужна:

- черновик формы;
- оптимистичное редактирование;
- animation state;
- состояние, которое намеренно отделяется от внешних данных.

Пример:

```jsx
function EditNameForm({ initialName }) {
  const [name, setName] = useState(initialName)
  return <input value={name} onChange={(event) => setName(event.target.value)} />
}
```

Здесь `name` - локальный черновик, а не автоматическая копия prop.

## Мини-шпаргалка

- Derived state можно вычислить из других данных.
- Не дублируй вычисляемые значения в state без причины.
- Для дорогих вычислений используй `useMemo`.
- Для выбранного элемента часто лучше хранить `selectedId`.
- Локальный draft формы - допустимый derived state-сценарий.
