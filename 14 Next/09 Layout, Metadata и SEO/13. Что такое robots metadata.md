# Что такое robots metadata?

> [!summary]
> Robots metadata - это настройки Metadata API, которые говорят поисковым роботам, можно ли индексировать конкретную страницу, переходить по ссылкам, показывать сниппет, кешировать страницу и индексировать изображения.

## Что такое robots meta tag?

В обычном HTML это выглядит так:

```html
<meta name="robots" content="noindex, nofollow" />
```

Этот тег относится к конкретной странице. Он говорит поисковику, как ее обрабатывать.

В Next.js App Router это задается через `metadata.robots`:

```tsx
import type { Metadata } from 'next'

export const metadata: Metadata = {
  robots: {
    index: false,
    follow: false,
  },
}
```

## Основные директивы

| Директива | Значение |
| --- | --- |
| `index` | Разрешить индексацию страницы |
| `noindex` | Запретить индексацию страницы |
| `follow` | Разрешить переход по ссылкам |
| `nofollow` | Запретить переход по ссылкам |
| `nosnippet` | Не показывать текстовый сниппет |
| `noarchive` | Не хранить кешированную копию |
| `noimageindex` | Не индексировать изображения на странице |
| `nocache` | Не показывать кешированную версию в некоторых поисковиках |

В Metadata API часть этих правил задается булевыми полями:

```tsx
export const metadata = {
  robots: {
    index: true,
    follow: true,
    nocache: false,
    noarchive: false,
    nosnippet: false,
    noimageindex: false,
  },
}
```

## Примеры

### Закрыть страницу логина

```tsx
export const metadata = {
  title: 'Вход',
  robots: {
    index: false,
    follow: false,
  },
}
```

Такую страницу не нужно показывать в поиске.

### Закрыть страницу фильтра

```tsx
export const metadata = {
  robots: {
    index: false,
    follow: true,
  },
}
```

Страницу не индексируем, но ссылки на товары можно обходить.

### Настроить Googlebot отдельно

```tsx
export const metadata = {
  robots: {
    index: true,
    follow: true,
    googleBot: {
      index: true,
      follow: true,
      'max-snippet': -1,
      'max-image-preview': 'large',
      'max-video-preview': -1,
    },
  },
}
```

Это дает более тонкий контроль для Google.

## Robots metadata и robots.txt

Это разные инструменты:

| Инструмент | Где работает | Для чего |
| --- | --- | --- |
| `robots.txt` | На уровне сайта | Говорит, какие URL можно обходить |
| `robots metadata` | На уровне страницы | Говорит, можно ли страницу индексировать |

Важный нюанс: если запретить обход страницы через `robots.txt`, бот может не увидеть meta `noindex`, потому что не зайдет на страницу. Для удаления страницы из индекса часто используют именно `noindex`, а не только запрет в `robots.txt`.

## Когда использовать noindex?

- login/register;
- личный кабинет;
- корзина;
- checkout;
- внутренний поиск;
- страницы с дублями;
- фильтры и сортировки;
- временные страницы;
- админские интерфейсы;
- страницы с пользовательскими приватными данными.

## Что отвечать на собеседовании?

Robots metadata в Next.js - это часть Metadata API для управления индексацией конкретной страницы. Через `metadata.robots` можно задать `index`, `follow`, `nocache`, `noarchive`, `nosnippet`, `noimageindex` и настройки для `googleBot`. Это не то же самое, что `robots.txt`: robots.txt управляет обходом URL, а robots metadata - индексацией уже загруженной страницы.

## Частые ошибки

- Путать `robots.txt` и meta robots.
- Ставить `noindex` на важные коммерческие страницы.
- Закрывать страницу через `robots.txt` и ожидать, что бот увидит `noindex`.
- Забывать закрывать login, cart, checkout и внутренний поиск.
- Использовать `nofollow` без понимания последствий.
- Не проверять итоговые meta-теги в HTML.

## Мини-шпаргалка

- `index: false` - не индексировать страницу.
- `follow: false` - не переходить по ссылкам.
- `robots.txt` управляет обходом.
- `robots metadata` управляет индексацией страницы.
- Для Google есть `googleBot`.
- Служебные страницы обычно закрывают от индексации.
