# Какие ограничения есть у серверных компонентов?

> [!summary]
> Серверные компоненты выполняются в серверной среде, поэтому не имеют доступа к интерактивности браузера: нельзя использовать state/effect hooks, event handlers, DOM APIs и browser-only библиотеки. Их props в Client Components должны быть сериализуемыми.

## Нельзя использовать интерактивность

Плохо:

```tsx
export default function ServerButton() {
  return <button onClick={() => alert('click')}>Click</button>
}
```

Server Component не может содержать `onClick`.

## Нельзя использовать client hooks

Плохо:

```tsx
export default function Counter() {
  const [count, setCount] = useState(0)

  return <button>{count}</button>
}
```

Для `useState`, `useEffect`, `useReducer`, DOM refs и похожих хуков нужен Client Component.

## Нельзя читать browser APIs

Плохо:

```tsx
export default function ThemeLabel() {
  const theme = localStorage.getItem('theme')

  return <p>{theme}</p>
}
```

На сервере нет `window`, `document`, `localStorage`, `navigator`.

## Нельзя передавать несериализуемые props

Плохо:

```tsx
<ClientWidget
  db={db}
  onSave={() => saveToDatabase()}
/>
```

Хорошо:

```tsx
<ClientWidget userId={user.id} initialName={user.name} />
```

Через server-to-client boundary передают данные, которые React может сериализовать.

## Можно передавать Client Components как children

```tsx
export default function Page() {
  return (
    <ServerShell>
      <ClientSearch />
    </ServerShell>
  )
}
```

Это нормальная композиция: серверная оболочка и клиентский интерактивный участок.

## Что отвечать на собеседовании?

Server Components не имеют браузерной интерактивности. В них нельзя использовать event handlers, state/effect hooks и browser APIs. Они хороши для data fetching и серверного HTML, но интерактивность нужно выносить в Client Components через `'use client'`.

## Частые ошибки

- Думать, что Server Component может иметь `onClick`.
- Читать `localStorage` на сервере.
- Передавать функции в Client Component.
- Импортировать client-only UI library в Server Component.
- Считать Server Components заменой авторизации.

## Мини-шпаргалка

- Нет `useState`.
- Нет `useEffect`.
- Нет `onClick`.
- Нет `window`.
- Props в Client Component должны быть сериализуемыми.
- Для интерактива нужен `'use client'`.
