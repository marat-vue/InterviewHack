# Как валидировать query params через Zod?

> [!summary]
> Query params приходят строками, поэтому в Zod для них часто используют coercion: `z.coerce.number()`, `z.coerce.boolean()` и transform. Это особенно важно для pagination, sorting и filtering.

## Query schema

```ts
export const findUsersQuerySchema = z.object({
  page: z.coerce.number().int().min(1).default(1),
  limit: z.coerce.number().int().min(1).max(100).default(20),
  search: z.string().trim().min(1).optional(),
  sort: z.enum(['createdAt', 'email']).default('createdAt'),
});
```

## Controller

```ts
@Get()
findAll(
  @Query(new ZodValidationPipe(findUsersQuerySchema))
  query: FindUsersQuery,
) {
  return this.usersService.findAll(query);
}
```

## Почему нужен coerce?

HTTP query:

```txt
?page=2&limit=20
```

Для NestJS это строки:

```ts
{ page: '2', limit: '20' }
```

`z.coerce.number()` превращает строку в число и валидирует результат.

## Мини-шпаргалка

- Query params приходят строками.
- `z.coerce.number()` удобен для page/limit.
- `default()` задает значение по умолчанию.
- Sorting поля проверяй enum/allowlist.
- Ограничивай `limit` сверху.
