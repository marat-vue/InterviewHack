# Как изучать Material UI

> [!summary]
> Material UI - React UI library с готовыми компонентами Material Design. Изучать ее нужно через компоненты, `sx`, theme, `ThemeProvider`, responsive system, overrides, forms, tables, dialogs и правила кастомизации.

## Что такое Material UI?

Material UI, или MUI, - библиотека готовых React-компонентов:

- `Button`;
- `TextField`;
- `Dialog`;
- `Select`;
- `Autocomplete`;
- `Table`;
- `Tabs`;
- `Drawer`;
- `Snackbar`;
- `Tooltip`.

Пример:

```tsx
import Button from '@mui/material/Button'

function SaveButton() {
  return <Button variant="contained">Save</Button>
}
```

## Когда MUI особенно полезен?

- Admin panels.
- CRM/ERP.
- Dashboards.
- Internal tools.
- Быстрый production UI.
- Проекты, где важны готовые accessible components.

## Когда MUI может быть плохим выбором?

- Нужен уникальный брендовый дизайн.
- Очень маленький лендинг.
- Команда хочет полностью custom CSS.
- Нельзя принимать bundle cost компонентной библиотеки.

## Что нужно знать по порядку?

1. Установка MUI и Emotion.
2. Базовые компоненты.
3. `sx` prop.
4. Layout: `Box`, `Stack`, `Grid`, `Container`.
5. Theme и `ThemeProvider`.
6. Palette, typography, spacing, breakpoints.
7. Component overrides.
8. Form components.
9. Dialog, Drawer, Snackbar.
10. Data-heavy UI и MUI X.

## Что отвечать на собеседовании?

MUI - production-ready React component library, реализующая Material Design. Она ускоряет разработку за счет готовых компонентов, темы, responsive system и встроенных accessibility-паттернов. Главные инструменты кастомизации - `sx`, `styled`, `ThemeProvider` и `components` overrides в theme.

## Мини-шпаргалка

- `Button`, `TextField`, `Dialog` - базовые компоненты.
- `Box`, `Stack`, `Grid` - layout.
- `sx` - быстрые стили на один компонент.
- `ThemeProvider` - глобальная тема.
- `createTheme` - настройка design tokens.
- `components` в theme - default props и overrides.
