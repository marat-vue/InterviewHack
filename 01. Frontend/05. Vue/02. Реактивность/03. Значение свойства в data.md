# Значение свойства в data

> [!NOTE]
> В Options API `data()` возвращает объект состояния компонента. Каждое свойство этого объекта становится реактивным и доступным в шаблоне через `this` или напрямую в template.

## Вопрос

Что означает значение свойства в `data`?

## Базовый пример

```vue
<script>
export default {
  data() {
    return {
      count: 0,
      userName: "Анна",
    };
  },
};
</script>

<template>
  <p>{{ userName }}</p>
  <button @click="count++">{{ count }}</button>
</template>
```

`count` и `userName` становятся состоянием компонента.

## Почему data - функция

В компонентах `data` должна быть функцией, чтобы каждый экземпляр компонента получил собственную копию состояния.

```javascript
export default {
  data() {
    return {
      isOpen: false,
    };
  },
};
```

Если бы объект был общим, несколько экземпляров могли бы случайно делить одно состояние.

## Начальные значения важны

Лучше объявлять свойства заранее, даже если данных еще нет.

```javascript
data() {
  return {
    user: null,
    isLoading: false,
  };
}
```

Так структура состояния понятнее и предсказуемее.

## Мини-шпаргалка

- `data()` возвращает начальное состояние.
- Поля `data` реактивны.
- В template поля доступны напрямую.
- В Options API внутри методов к ним обращаются через `this`.
- Для компонентов `data` должна быть функцией.
