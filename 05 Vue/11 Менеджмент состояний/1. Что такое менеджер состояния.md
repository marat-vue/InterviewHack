# Что такое менеджер состояния

> [!summary] Коротко
> Менеджер состояния - инструмент для хранения и изменения общего состояния приложения в одном понятном месте. Во Vue для этого чаще используют Pinia.

## Вопрос

Что такое менеджер состояния?

## Главная идея

Когда данные нужны многим компонентам, их неудобно передавать через цепочки props и events. State manager создает общий store.

```typescript
export const useUserStore = defineStore("user", {
  state: () => ({
    currentUser: null as User | null,
  }),
  actions: {
    setUser(user: User) {
      this.currentUser = user;
    },
  },
});
```

## Что хранит store

- State: общие данные.
- Getters: производные значения.
- Actions: операции изменения и async-логика.

```typescript
const userStore = useUserStore();
userStore.setUser(user);
```

## Зачем это нужно

Store помогает иметь единый источник правды для пользователя, корзины, прав доступа, настроек, справочников и данных, которые нужны разным экранам.

## Когда не нужен

Если состояние нужно одному компоненту, лучше оставить его локально через `ref`, `reactive` или `data`.

## Мини-шпаргалка

- State manager хранит общее состояние.
- Во Vue стандартный выбор - Pinia.
- Store дает state, getters и actions.
- Не выноси в store все подряд.
