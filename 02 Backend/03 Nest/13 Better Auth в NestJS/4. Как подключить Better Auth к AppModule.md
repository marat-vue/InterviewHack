# Как подключить Better Auth к AppModule?

> [!summary]
> В NestJS integration Better Auth подключают через `AuthModule.forRoot({ auth })`. Также нужно отключить встроенный body parser при создании Nest application, чтобы Better Auth мог обработать raw request body.

## Отключить body parser

```ts
// main.ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule, {
    bodyParser: false,
  });

  await app.listen(process.env.PORT ?? 3000);
}
```

Это требование Better Auth Nest integration.

## Импорт AuthModule

```ts
// app.module.ts
import { Module } from '@nestjs/common';
import { AuthModule } from '@thallesp/nestjs-better-auth';
import { auth } from './auth';

@Module({
  imports: [
    AuthModule.forRoot({ auth }),
  ],
})
export class AppModule {}
```

## Что создается?

Integration монтирует auth routes и добавляет guards/decorators для работы с session.

## Мини-шпаргалка

- Better Auth подключается через `AuthModule.forRoot`.
- Нужно передать `auth` instance.
- В `main.ts` отключают `bodyParser`.
- Auth routes обрабатываются Better Auth.
- Fastify support в integration помечен как beta, проверяй issues.
