# Что такое агрегатные функции?

> [!NOTE]
> Агрегатные функции считают одно значение по набору строк: количество, сумму, среднее, минимум или максимум. Они используются для отчетов, статистики и аналитических запросов.

## Частые агрегаты

| Функция | Что считает |
|---|---|
| `COUNT(*)` | количество строк |
| `SUM(amount)` | сумму |
| `AVG(amount)` | среднее |
| `MIN(created_at)` | минимум |
| `MAX(created_at)` | максимум |

## Пример

```sql
SELECT COUNT(*) AS users_count
FROM users;
```

## Агрегат по условию

```sql
SELECT COUNT(*) AS active_users
FROM users
WHERE is_active = true;
```

`WHERE` сначала фильтрует строки, затем агрегат считает результат.

## NULL и агрегаты

Большинство агрегатов игнорируют `NULL`.

```sql
SELECT AVG(rating)
FROM reviews;
```

Если часть `rating` равна `NULL`, они не участвуют в среднем.

## Мини-шпаргалка

- Агрегаты считают значение по набору строк.
- `COUNT(*)` считает строки.
- `COUNT(column)` считает не-NULL значения.
- `SUM`, `AVG`, `MIN`, `MAX` игнорируют `NULL`.
- Для агрегатов по группам нужен `GROUP BY`.
