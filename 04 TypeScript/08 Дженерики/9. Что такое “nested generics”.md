# Что такое nested generics

> [!summary] Коротко
> Nested generics - это вложенные generic-типы, например `Promise<ApiResponse<User[]>>`. Они описывают данные, которые завернуты в несколько типовых оболочек.

## Вопрос

Что такое `nested generics`?

## Базовый пример

```typescript
type ApiResponse<T> = {
  data: T;
  status: number;
};

type UsersResponse = Promise<ApiResponse<User[]>>;
```

Здесь `User[]` находится внутри `ApiResponse<T>`, а весь ответ находится внутри `Promise<T>`.

## Как читать вложенность

Читай изнутри наружу:

```typescript
Promise<ApiResponse<User[]>>
```

1. `User[]` - массив пользователей.
2. `ApiResponse<User[]>` - API-ответ с массивом пользователей.
3. `Promise<ApiResponse<User[]>>` - асинхронный API-ответ.

## Практический пример

```typescript
async function getUsers(): Promise<ApiResponse<User[]>> {
  const response = await fetch("/users");
  return response.json();
}
```

## Когда стоит упростить

Если тип становится слишком длинным, вынеси промежуточные части в отдельные aliases.

```typescript
type Users = User[];
type UsersApiResponse = ApiResponse<Users>;
type AsyncUsersApiResponse = Promise<UsersApiResponse>;
```

## Мини-шпаргалка

- Nested generics = generic внутри generic.
- Читать удобнее изнутри наружу.
- Длинные цепочки лучше разбивать на именованные типы.
- Часто встречается в `Promise`, `Array`, `Record`, `ApiResponse`.
