# then, catch, finally

> [!summary] Коротко
> `.then()` обрабатывает успех, `.catch()` обрабатывает ошибку, `.finally()` выполняется в любом случае.

## Вопрос

Что делают методы `.then()`, `.catch()` и `.finally()` у промиса?

## then()

`.then(onFulfilled)` вызывается, когда промис успешно завершился. Значение, переданное в `resolve`, попадает аргументом в callback.

```javascript
fetch('/api/user')
  .then((response) => response.json())
  .then((user) => {
    console.log(user.name);
  });
```

Каждый `.then()` возвращает новый промис, поэтому их можно объединять в цепочку.

## catch()

`.catch(onRejected)` вызывается, если промис был отклонен или если ошибка произошла в одном из предыдущих `.then()`.

```javascript
fetch('/api/user')
  .then((response) => response.json())
  .catch((error) => {
    console.error('Request failed:', error);
  });
```

## finally()

`.finally(callback)` выполняется и при успехе, и при ошибке. Он удобен для очистки состояния: убрать loader, закрыть соединение, освободить ресурс.

```javascript
setLoading(true);

fetch('/api/user')
  .then((response) => response.json())
  .catch(console.error)
  .finally(() => {
    setLoading(false);
  });
```

## Важное отличие finally

`finally()` обычно не получает результат промиса и не должен его менять. Он нужен для действия "после завершения".

```javascript
Promise.resolve(10)
  .finally(() => console.log('done'))
  .then((value) => console.log(value)); // 10
```

## Мини-шпаргалка

```javascript
promise
  .then(handleSuccess)
  .catch(handleError)
  .finally(cleanup);
```
