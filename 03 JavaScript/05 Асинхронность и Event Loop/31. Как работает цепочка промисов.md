# Как работает цепочка промисов

> [!summary] Коротко
> Цепочка промисов строится потому, что каждый `.then()`, `.catch()` и `.finally()` возвращает новый промис.

## Вопрос

Как данные и ошибки проходят через цепочку промисов?

## Определение

Цепочка промисов - последовательность обработчиков, где результат одного шага становится входом для следующего. Если внутри `.then()` вернуть значение, следующий `.then()` получит это значение. Если вернуть промис, цепочка дождется его завершения.

## Возврат обычного значения

```javascript
Promise.resolve(2)
  .then((value) => value * 2)
  .then((value) => value + 1)
  .then(console.log); // 5
```

## Возврат промиса

```javascript
fetch('/api/user')
  .then((response) => response.json())
  .then((user) => {
    return fetch(`/api/posts?userId=${user.id}`);
  })
  .then((response) => response.json())
  .then(console.log);
```

Если `.then()` возвращает промис, следующий шаг дождется его результата.

## Ошибки в цепочке

```javascript
Promise.resolve()
  .then(() => {
    throw new Error('Boom');
  })
  .then(() => {
    console.log('will not run');
  })
  .catch((error) => {
    console.error(error.message); // 'Boom'
  });
```

Ошибка пропускает обычные `.then()` до ближайшего `.catch()`.

## Восстановление после ошибки

```javascript
Promise.reject(new Error('No data'))
  .catch(() => {
    return [];
  })
  .then((items) => {
    console.log(items); // []
  });
```

Если `.catch()` возвращает значение, цепочка снова становится успешной.

## Мини-шпаргалка

```javascript
then returns value   -> next then gets value
then returns promise -> next then waits
throw / reject       -> nearest catch
catch returns value  -> chain recovers
```
