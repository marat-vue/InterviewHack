# Переменное число аргументов

> [!NOTE]
> Переменное число аргументов описывается rest-параметром: `...args`. В TypeScript ему задают тип массива или кортежа.

## Вопрос

Как задать тип для функции с переменным числом аргументов?

## Базовый вариант

```typescript
function sum(...numbers: number[]): number {
  return numbers.reduce((total, value) => total + value, 0);
}

sum(1, 2, 3);
```

Внутри функции `numbers` - обычный массив `number[]`.

## Фиксированные параметры плюс rest

Rest-параметр всегда идет последним.

```typescript
function log(prefix: string, ...messages: string[]): void {
  messages.forEach((message) => console.log(prefix, message));
}
```

## Несколько допустимых типов

```typescript
function joinValues(...values: Array<string | number>): string {
  return values.join(", ");
}
```

## Точный порядок через кортеж

Если аргументы должны идти в конкретном порядке, используй tuple.

```typescript
type EventArgs = [type: "click" | "submit", targetId: string, meta?: object];

function track(...args: EventArgs): void {
  const [type, targetId, meta] = args;
  console.log(type, targetId, meta);
}
```

## Generic rest

```typescript
function first<T>(...items: T[]): T | undefined {
  return items[0];
}
```

## Мини-шпаргалка

- `...args: T[]` - любое количество аргументов одного типа.
- Rest-параметр должен быть последним.
- Для точного порядка используй tuple: `...args: [string, number]`.
- Внутри функции rest-параметр является массивом.
