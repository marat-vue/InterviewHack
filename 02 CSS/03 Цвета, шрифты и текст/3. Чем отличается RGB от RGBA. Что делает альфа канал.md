# Чем отличается RGB от RGBA. Что делает альфа канал

> [!summary]
> `RGB` задает цвет через красный, зеленый и синий каналы, а `RGBA` добавляет четвертый канал - прозрачность. Альфа-канал управляет тем, насколько цвет непрозрачен.

## Главное

RGB описывает цвет тремя каналами:

```css
.text {
  color: rgb(37, 99, 235);
}
```

RGBA добавляет прозрачность:

```css
.overlay {
  background-color: rgba(0, 0, 0, 0.5);
}
```

`0.5` означает 50% непрозрачности.

## Современный синтаксис

В современном CSS можно писать RGB с пробелами и альфа-каналом через `/`.

```css
.overlay {
  background-color: rgb(0 0 0 / 0.5);
}
```

Это то же самое по смыслу, что `rgba(0, 0, 0, 0.5)`.

## Как работает альфа-канал

Альфа-канал принимает значение от `0` до `1` или в процентах.

```css
.example {
  background: rgb(37 99 235 / 1);    /* полностью непрозрачный */
  border-color: rgb(37 99 235 / 50%); /* наполовину прозрачный */
  box-shadow: 0 8px 24px rgb(0 0 0 / 0.2);
}
```

Значение `0` делает цвет полностью прозрачным, а `1` - полностью непрозрачным.

## RGB/RGBA и opacity

`rgba()` делает прозрачным только конкретный цвет.

```css
.card {
  background: rgb(255 255 255 / 0.8);
}
```

`opacity` делает прозрачным весь элемент вместе с текстом и дочерними элементами.

```css
.card {
  opacity: 0.8;
}
```

Для полупрозрачного фона чаще лучше использовать альфа-канал, а не `opacity`.

## Мини-шпаргалка

- `rgb()` задает цвет через red, green, blue.
- `rgba()` добавляет alpha.
- Alpha `0` - полностью прозрачно.
- Alpha `1` - полностью непрозрачно.
- Современная запись: `rgb(0 0 0 / 0.5)`.
- `opacity` влияет на весь элемент, а alpha - на конкретное CSS-значение.
