# Можно ли наследовать приватные свойства?

> [!NOTE] Коротко
> Приватные поля с `#` не доступны в дочерних классах напрямую, даже если объект является наследником.

## Вопрос

Наследуются ли приватные свойства класса?

## Короткий ответ

Приватное поле принадлежит классу, где оно объявлено. Дочерний класс не может обратиться к нему напрямую через `this.#field`, если это поле объявлено только в родителе.

## Пример

```javascript
class Parent {
  #secret = 'parent secret';
}

class Child extends Parent {
  showSecret() {
    return this.#secret; // SyntaxError
  }
}
```

`Child` не имеет доступа к `#secret`.

## Как дать доступ наследнику

Через публичный или защищенный по соглашению метод.

```javascript
class Parent {
  #secret = 'parent secret';

  getSecret() {
    return this.#secret;
  }
}

class Child extends Parent {
  showSecret() {
    return this.getSecret();
  }
}
```

Наследник вызывает публичный метод родителя.

## Можно объявить свое приватное поле

```javascript
class Child extends Parent {
  #secret = 'child secret';
}
```

Это отдельное приватное поле класса `Child`, а не переопределение поля родителя.

## Практический вывод

Если значение нужно использовать в наследниках, не делай его `#private`. Используй публичный метод или соглашение вроде `_value`, понимая, что `_` не дает реальной приватности.

## Мини-шпаргалка

```javascript
class Parent {
  #value = 1;
  getValue() {
    return this.#value;
  }
}
```
