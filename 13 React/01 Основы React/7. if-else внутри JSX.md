# Как писать if-else внутри JSX?

> [!summary]
> Внутри JSX можно использовать JavaScript-выражения, но нельзя напрямую писать `if` как statement. Поэтому условия обычно выносят до `return`, пишут через тернарный оператор, `&&` или отдельные функции/компоненты.

## Почему обычный if не работает внутри JSX?

Так нельзя:

```jsx
function Message({ isLoggedIn }) {
  return (
    <div>
      {if (isLoggedIn) {
        return <p>Добро пожаловать</p>
      }}
    </div>
  )
}
```

`if` - инструкция, а JSX внутри `{}` ожидает выражение.

## Вариант 1: вынести if до return

```jsx
function Message({ isLoggedIn }) {
  if (isLoggedIn) {
    return <p>Добро пожаловать</p>
  }

  return <p>Войдите в аккаунт</p>
}
```

Это самый читаемый вариант, если ветки сильно отличаются.

## Вариант 2: тернарный оператор

```jsx
function Message({ isLoggedIn }) {
  return (
    <p>
      {isLoggedIn ? 'Добро пожаловать' : 'Войдите в аккаунт'}
    </p>
  )
}
```

Подходит для короткого выбора между двумя вариантами.

## Вариант 3: логическое &&

```jsx
function AdminNotice({ isAdmin }) {
  return (
    <section>
      {isAdmin && <p>Доступна панель администратора</p>}
    </section>
  )
}
```

Подходит, когда нужно показать элемент только при условии.

Осторожно с числами:

```jsx
{items.length && <List items={items} />}
```

Если `items.length` равен `0`, React может отрендерить `0`. Лучше так:

```jsx
{items.length > 0 && <List items={items} />}
```

## Вариант 4: переменная

```jsx
function Profile({ user }) {
  let content

  if (user) {
    content = <UserCard user={user} />
  } else {
    content = <LoginButton />
  }

  return <main>{content}</main>
}
```

## Мини-шпаргалка

- В JSX внутри `{}` нужны выражения.
- Большие условия лучше выносить до `return`.
- Тернарный оператор хорош для коротких двух веток.
- `&&` хорош для условного показа.
- Избегай длинных вложенных тернарников.
