# Что такое props в компоненте?

> [!summary]
> Props, properties, - это входные данные React-компонента. Родитель передает props ребенку, а ребенок использует их для отображения UI или вызова переданных callback-функций. Props в React следует считать read-only.

## Простое определение

Props похожи на аргументы функции:

```jsx
function Welcome({ name }) {
  return <h1>Привет, {name}!</h1>
}

function App() {
  return <Welcome name="Анна" />
}
```

`App` передает prop `name`, а `Welcome` использует его внутри JSX.

## Что можно передавать через props?

Через props можно передать любое JavaScript-значение:

```jsx
<UserCard
  name="Анна"
  age={28}
  isOnline={true}
  roles={['admin', 'editor']}
  profile={{ city: 'Москва' }}
  onSelect={() => console.log('selected')}
/>
```

Важно: строки можно писать в кавычках, а JavaScript-значения - в `{}`.

## Props и однонаправленный поток данных

В React данные обычно текут сверху вниз:

```text
Parent -> props -> Child
```

Ребенок не должен менять props напрямую. Если ребенок хочет повлиять на родителя, родитель передает callback:

```jsx
function TodoItem({ todo, onToggle }) {
  return (
    <label>
      <input
        type="checkbox"
        checked={todo.done}
        onChange={() => onToggle(todo.id)}
      />
      {todo.title}
    </label>
  )
}
```

## Props в обычных DOM-элементах

В JSX props есть и у обычных тегов:

```jsx
<img
  className="avatar"
  src="/avatar.png"
  alt="Аватар пользователя"
  width={80}
  height={80}
/>
```

React DOM преобразует эти props в атрибуты или свойства DOM-элемента.

## Частые ошибки

- Мутировать объект из props.
- Передавать слишком много несвязанных props.
- Использовать props вместо state для внутренней интерактивности.
- Называть callback непонятно, например `handleClick`, когда лучше `onSelect`.
- Смешивать данные и UI-ответственность в одном компоненте.

## Мини-шпаргалка

- Props - входные данные компонента.
- Props передаются сверху вниз.
- Props считаются read-only.
- Через props можно передавать строки, числа, объекты, массивы, JSX и функции.
- Для связи ребенка с родителем передают callback-props.
