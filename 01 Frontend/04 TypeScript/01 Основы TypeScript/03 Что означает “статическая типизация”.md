# Что означает “статическая типизация”?

> [!NOTE] Коротко
> Статическая типизация означает, что типы проверяются до запуска программы, на этапе разработки или компиляции.

## Вопрос

Что значит статическая типизация в TypeScript?

## Определение

Статическая типизация - подход, при котором система типов анализирует код заранее. TypeScript проверяет, какие значения можно передавать в функции, какие свойства есть у объектов и какие операции допустимы.

Если типы не совпадают, TS сообщает об ошибке до выполнения кода.

## Пример

```typescript
function double(value: number): number {
  return value * 2;
}

double(10);
double('10'); // ошибка TypeScript
```

В JavaScript строка могла бы попасть в функцию во время выполнения. TypeScript предупреждает раньше.

## Статическая vs динамическая проверка

| Подход | Когда проверяется |
| --- | --- |
| Статическая типизация | до запуска |
| Динамическая типизация | во время выполнения |

JavaScript сам по себе динамически типизирован. TypeScript добавляет статический слой поверх него.

## Важный нюанс

Статическая типизация не гарантирует отсутствие всех ошибок. Например, данные от сервера могут не совпасть с ожидаемым типом, если их не проверить в runtime.

```typescript
const user = await response.json(); // TypeScript не знает реальную форму данных
```

## Мини-шпаргалка

```text
static typing = detect type errors before running code
```
