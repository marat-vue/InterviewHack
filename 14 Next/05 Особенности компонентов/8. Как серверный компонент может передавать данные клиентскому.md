# Как серверный компонент может передавать данные клиентскому?

> [!summary]
> Server Component передает данные Client Component через props. Эти props должны быть сериализуемыми: строки, числа, boolean, plain objects, arrays, null. Нельзя передавать DB clients, class instances, DOM nodes и обычные функции.

## Базовый пример

Server Component:

```tsx
import { LikeButton } from './LikeButton'

export default async function PostPage({ params }: Props) {
  const { id } = await params
  const post = await getPost(id)

  return (
    <article>
      <h1>{post.title}</h1>
      <LikeButton postId={post.id} initialLikes={post.likes} />
    </article>
  )
}
```

Client Component:

```tsx
'use client'

import { useState } from 'react'

export function LikeButton({
  postId,
  initialLikes,
}: {
  postId: string
  initialLikes: number
}) {
  const [likes, setLikes] = useState(initialLikes)

  return <button onClick={() => setLikes(likes + 1)}>{likes}</button>
}
```

## Что можно передавать?

Можно:

- `string`;
- `number`;
- `boolean`;
- `null`;
- arrays;
- plain objects;
- serializable data transfer objects.

## Что нельзя передавать?

Плохо:

```tsx
<ClientWidget db={db} />
<ClientWidget user={new User()} />
<ClientWidget onSave={() => save()} />
```

Такие значения не являются обычными сериализуемыми данными.

## Как передавать действия?

Для мутаций можно использовать Server Actions, но их правила отличаются от обычных функций:

```tsx
<form action={createPost}>
  <input name="title" />
  <button>Create</button>
</form>
```

Для Client Component Server Action обычно выносят в отдельный файл с `'use server'`.

## Что отвечать на собеседовании?

Server Component может подготовить данные на сервере и передать Client Component через props. На границе server-to-client данные должны быть сериализуемыми. Если нужна интерактивность, клиентский компонент получает initial data и дальше управляет локальным состоянием или вызывает Server Action.

## Частые ошибки

- Передавать функции вместо Server Actions.
- Передавать class instances.
- Передавать весь backend response без нормализации.
- Дублировать data fetching на клиенте.
- Мутировать initial props внутри клиента.

## Мини-шпаргалка

- Передача идет через props.
- Props должны быть сериализуемыми.
- Client Component может принять initial data.
- Server-only объекты не передают.
- Для мутаций есть Server Actions.
