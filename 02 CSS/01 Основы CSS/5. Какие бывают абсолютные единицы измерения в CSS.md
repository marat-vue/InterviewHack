# Какие бывают абсолютные единицы измерения в CSS

> [!summary]
> **Абсолютные единицы CSS** имеют фиксированный размер относительно физической или CSS-системы координат. В веб-интерфейсах чаще всего используют `px`, а остальные абсолютные единицы встречаются редко.

## Основные абсолютные единицы

| Единица | Название | Пример |
| --- | --- | --- |
| `px` | CSS pixel | `16px` |
| `cm` | сантиметр | `2cm` |
| `mm` | миллиметр | `10mm` |
| `Q` | четверть миллиметра | `40Q` |
| `in` | дюйм | `1in` |
| `pt` | пункт | `12pt` |
| `pc` | пика | `1pc` |

## CSS pixel

```css
.card {
  width: 320px;
  padding: 16px;
}
```

`px` - самая распространенная абсолютная единица в интерфейсах. В CSS это не всегда один физический пиксель экрана: браузер учитывает масштабирование и плотность пикселей.

## Печатные единицы

`cm`, `mm`, `in`, `pt`, `pc` чаще полезны в стилях для печати.

```css
@media print {
  @page {
    margin: 2cm;
  }
}
```

## Когда использовать px

- Границы.
- Иконки.
- Тонкие отступы в UI.
- Размеры, которые должны быть стабильными.
- Точные значения в дизайн-системе.

## Когда лучше относительные единицы

Для шрифтов, адаптивных размеров и расстояний часто удобнее `rem`, `em`, `%`, `vw`, `vh`.

## Мини-шпаргалка

- `px` - главная абсолютная единица в вебе.
- `cm`, `mm`, `in`, `pt`, `pc` чаще нужны для печати.
- Абсолютные единицы не адаптируются сами по себе.
- Для доступной типографики часто лучше `rem`.
- CSS pixel отличается от физического пикселя устройства.
