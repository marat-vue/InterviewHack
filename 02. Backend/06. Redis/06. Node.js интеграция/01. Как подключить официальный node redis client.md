# Как подключить официальный node-redis client?

> [!NOTE]
> Официальный Node.js клиент для Redis - пакет `redis`, часто его называют `node-redis`. Он поддерживает promises, auto-pipelining, Pub/Sub, transactions, Redis Stack commands и production-настройки подключения.

## Установка

```bash
npm install redis
```

или:

```bash
pnpm add redis
```

## Минимальное подключение

```ts
import { createClient } from 'redis';

const redis = createClient({
  url: process.env.REDIS_URL,
});

redis.on('error', (error) => {
  console.error('Redis client error', error);
});

await redis.connect();
```

## Базовые команды

```ts
await redis.set('hello', 'world');
const value = await redis.get('hello');

await redis.set('cache:user:1', JSON.stringify({
  id: '1',
}), {
  EX: 300,
});
```

## Как закрыть соединение?

```ts
await redis.quit();
```

`quit()` закрывает соединение аккуратно. Для аварийного закрытия у клиентов может быть отдельный destroy/disconnect API, но в обычном graceful shutdown лучше использовать корректное завершение.

## Как подключиться к TLS Redis?

Обычно через URL:

```bash
REDIS_URL="rediss://default:password@redis.example.com:6380"
```

```ts
const redis = createClient({
  url: process.env.REDIS_URL,
});
```

Managed Redis provider может требовать дополнительные TLS options.

## Как обрабатывать errors?

Обязательно подпишись на `error`:

```ts
redis.on('error', (error) => {
  logger.error({
    error,
  }, 'Redis error');
});
```

Без error listener Node.js process может упасть при connection error.

## Мини-шпаргалка

- Установка: `npm install redis`.
- Создание: `createClient({ url })`.
- Старт: `await client.connect()`.
- Errors: `client.on('error', ...)`.
- Завершение: `await client.quit()`.
- TLS часто задается через `rediss://`.
