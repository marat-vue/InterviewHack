# Можно ли не определять конструктор?

> [!NOTE]
> Да, если `constructor` не указан, JavaScript создает конструктор по умолчанию.

## Вопрос

Обязательно ли писать `constructor()` в классе?

## Определение

Конструктор нужен только тогда, когда при создании экземпляра нужно выполнить инициализацию: принять аргументы, записать свойства, подготовить состояние.

Если конструктор не нужен, его можно не писать.

## Пример без конструктора

```javascript
class Logger {
  log(message) {
    console.log(message);
  }
}

const logger = new Logger();

logger.log('Hello');
```

JavaScript создаст пустой конструктор автоматически.

## Конструктор по умолчанию

Для обычного класса он примерно такой:

```javascript
constructor() {}
```

Для класса-наследника он примерно такой:

```javascript
constructor(...args) {
  super(...args);
}
```

## Когда конструктор нужен

```javascript
class User {
  constructor(name) {
    this.name = name;
  }
}
```

Здесь конструктор нужен, чтобы сохранить имя пользователя в экземпляре.

## Мини-шпаргалка

```javascript
class Empty {} // constructor создается автоматически
```
