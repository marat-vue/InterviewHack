# Как работать с транзакциями Prisma?

> [!summary]
> Prisma поддерживает транзакции через `$transaction`. В NestJS транзакционную границу обычно держат в service/use case, а не в controller.

## Batch transaction

```ts
const [user, postsCount] = await this.prisma.$transaction([
  this.prisma.user.create({
    data: { email: 'anna@example.com' },
  }),
  this.prisma.post.count(),
]);
```

Подходит, когда операции независимы.

## Interactive transaction

```ts
const result = await this.prisma.$transaction(async (tx) => {
  const order = await tx.order.create({
    data: { userId, total },
  });

  await tx.orderItem.createMany({
    data: items.map((item) => ({
      orderId: order.id,
      productId: item.productId,
      quantity: item.quantity,
    })),
  });

  return order;
});
```

`tx` - transaction-scoped Prisma Client.

## Где использовать в NestJS?

```txt
OrdersController.create
  -> OrdersService.createOrder
    -> prisma.$transaction(...)
```

Controller не должен управлять транзакцией.

## Осторожно

Не вызывай долгие внешние API внутри транзакции: это держит database connection и locks дольше нужного.

## Мини-шпаргалка

- `$transaction([])` - batch transaction.
- `$transaction(async tx => ...)` - interactive transaction.
- Используй `tx`, а не обычный `this.prisma`, внутри transaction callback.
- Транзакция должна быть короткой.
- Для конфликтов нужна retry/idempotency стратегия.
