# Как задать цвет текста элемента?

> [!NOTE]
> Цвет текста в CSS задается свойством `color`. Оно наследуется дочерними элементами, поэтому часто достаточно задать базовый цвет на `body` или контейнере.

## Главное

```css
p {
  color: #111827;
}
```

Свойство `color` отвечает именно за цвет текста и некоторых зависимых вещей, например `currentColor`.

## Пример

```html
<p class="error">Заполните email</p>
```

```css
.error {
  color: #b91c1c;
}
```

## Наследование

```css
.article {
  color: #374151;
}
```

```html
<article class="article">
  <h2>Заголовок</h2>
  <p>Абзац унаследует цвет.</p>
</article>
```

`h2` и `p` получат цвет от `.article`, если у них не задан другой `color`.

## Ссылки

У ссылок браузер имеет дефолтный цвет. Его можно переопределить.

```css
a {
  color: #2563eb;
}

a:hover {
  color: #1d4ed8;
}
```

## Контраст

Цвет текста нужно подбирать вместе с фоном.

```css
.button {
  background: #2563eb;
  color: white;
}
```

Если контраст низкий, текст будет трудно читать.

## Мини-шпаргалка

- Цвет текста задается через `color`.
- `color` наследуется.
- Базовый цвет часто задают на `body`.
- Ссылки можно стилизовать отдельно.
- Цвет нужно проверять на контраст с фоном.
- Для повторяемых цветов удобно использовать CSS-переменные.
