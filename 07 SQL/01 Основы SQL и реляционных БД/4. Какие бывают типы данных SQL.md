# Какие бывают типы данных SQL?

> [!summary]
> Тип данных определяет, какие значения можно хранить в столбце и какие операции с ними доступны. Типы различаются между СУБД, но базовые группы похожи: числа, строки, даты, boolean, JSON и бинарные данные.

## Частые типы

| Группа | Примеры | Для чего |
|---|---|---|
| Целые числа | `integer`, `bigint` | id, счетчики |
| Дробные числа | `numeric`, `decimal`, `real` | деньги, измерения |
| Строки | `varchar`, `text` | имена, email, описания |
| Дата и время | `date`, `timestamp` | даты событий |
| Boolean | `boolean` | флаги |
| JSON | `json`, `jsonb` | гибкие структуры |

## Деньги

Для денег обычно не используют floating point.

```sql
price numeric(10, 2) NOT NULL
```

`numeric` хранит точное десятичное значение, что важно для финансовых расчетов.

## Дата и время

```sql
created_at timestamp NOT NULL DEFAULT now()
```

В backend-проектах часто важно договориться о timezone-стратегии: хранить UTC, отображать в timezone пользователя.

## Мини-шпаргалка

- Тип защищает данные и помогает оптимизатору.
- Для id часто используют `bigint` или UUID.
- Для денег лучше `numeric`, а не float.
- Для дат важно учитывать timezone.
- JSON удобен, но не должен заменять всю модель данных.
