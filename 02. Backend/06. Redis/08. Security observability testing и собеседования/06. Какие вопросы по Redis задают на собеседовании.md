## Мини-шпаргалка ответа

Хороший кандидат говорит:

> Redis - быстрый in-memory data store с богатыми структурами данных. Я использую его для cache, TTL state, counters, rate limits, Pub/Sub, Streams и leaderboards. В production думаю про key naming, TTL, memory, eviction, persistence, replication, ACL/TLS, monitoring и failure behavior.
