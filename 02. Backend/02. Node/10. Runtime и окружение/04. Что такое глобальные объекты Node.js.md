# Что такое глобальные объекты Node.js?

> [!NOTE]
> Глобальные объекты Node.js доступны без импорта. К ним относятся `globalThis`, `process`, `Buffer`, таймеры, `console`, `URL`, `fetch` и другие API, которые runtime предоставляет каждому модулю.

## globalThis

`globalThis` - стандартный способ обратиться к глобальному объекту в JavaScript.

```js
console.log(globalThis === global); // true в Node.js
```

В новом коде лучше думать через `globalThis`, а не завязываться на старое имя `global`.

## Частые глобальные API

| API | Зачем нужен |
|---|---|
| `process` | текущий процесс |
| `Buffer` | бинарные данные |
| `console` | вывод в консоль |
| `setTimeout` | таймер |
| `queueMicrotask` | microtask |
| `URL` | работа с URL |
| `fetch` | HTTP-запросы |

## Не все стоит делать глобальным

Можно добавить свое значение в глобальный объект:

```js
globalThis.appName = 'demo';
```

Но это почти всегда плохая идея для приложения: появляется скрытая зависимость, сложнее тестировать и понимать порядок инициализации.

## Глобальные, но модульные

Многие важные возможности лучше импортировать явно:

```js
import process from 'node:process';
import { Buffer } from 'node:buffer';
```

Так код становится понятнее и легче анализируется инструментами.

## Мини-шпаргалка

- Глобальные объекты доступны без импорта.
- `globalThis` - стандартное имя глобального объекта.
- `process` и `Buffer` - важные Node.js-глобалы.
- Не складывай состояние приложения в `globalThis`.
- Явный импорт встроенных модулей часто читабельнее.
