# Что такое рекурсивный CTE?

> [!summary]
> Рекурсивный CTE позволяет обходить иерархии и графоподобные структуры: категории, дерево комментариев, сотрудников и менеджеров. Он состоит из базовой части и рекурсивной части.

## Пример таблицы

```sql
CREATE TABLE categories (
  id bigint PRIMARY KEY,
  title text NOT NULL,
  parent_id bigint REFERENCES categories(id)
);
```

## Обход дерева

```sql
WITH RECURSIVE tree AS (
  SELECT id, title, parent_id, 1 AS level
  FROM categories
  WHERE parent_id IS NULL

  UNION ALL

  SELECT c.id, c.title, c.parent_id, tree.level + 1
  FROM categories c
  JOIN tree ON c.parent_id = tree.id
)
SELECT *
FROM tree
ORDER BY level, id;
```

## Как это работает?

Базовая часть выбирает корни. Рекурсивная часть снова и снова добавляет дочерние строки, пока новые строки не закончатся.

## Осторожно

Если данные содержат цикл, рекурсия может работать слишком долго. В production-запросах часто добавляют ограничение глубины.

## Мини-шпаргалка

- Рекурсивный CTE пишется через `WITH RECURSIVE`.
- Нужна базовая и рекурсивная часть.
- Частый кейс - деревья.
- `UNION ALL` обычно быстрее, чем `UNION`.
- Защищайся от циклов и бесконечной глубины.
