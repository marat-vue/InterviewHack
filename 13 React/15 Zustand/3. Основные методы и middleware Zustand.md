# Основные методы и middleware Zustand

> [!summary]
> В Zustand важно знать `create`, `set`, `get`, selectors, `subscribe`, а также middleware `persist`, `devtools`, `immer`, `subscribeWithSelector`. Эти инструменты покрывают большую часть рабочих сценариев.

## Основные API

| API | Зачем нужен |
|---|---|
| `create` | создать store-hook |
| `set` | обновить state |
| `get` | прочитать state внутри action |
| selector | подписаться на часть state |
| `subscribe` | подписаться вне React |
| `persist` | сохранить state в storage |
| `devtools` | подключить Redux DevTools |
| `immer` | писать immutable updates в mutable стиле |
| `subscribeWithSelector` | подписываться на конкретные срезы вне React |

## persist

```tsx
import { create } from 'zustand'
import { createJSONStorage, persist } from 'zustand/middleware'

type SettingsStore = {
  theme: 'light' | 'dark'
  setTheme: (theme: 'light' | 'dark') => void
}

export const useSettingsStore = create<SettingsStore>()(
  persist(
    (set) => ({
      theme: 'light',
      setTheme: (theme) => set({ theme }),
    }),
    {
      name: 'settings',
      storage: createJSONStorage(() => localStorage),
      partialize: (state) => ({ theme: state.theme }),
    },
  ),
)
```

`partialize` позволяет сохранять не весь store, а только нужную часть.

## devtools

```tsx
import { devtools } from 'zustand/middleware'

const useStore = create<Store>()(
  devtools(
    (set) => ({
      count: 0,
      increment: () =>
        set((state) => ({ count: state.count + 1 }), false, 'counter/increment'),
    }),
    { name: 'AppStore' },
  ),
)
```

Так actions видны в Redux DevTools.

## immer

```tsx
import { immer } from 'zustand/middleware/immer'

type TodoStore = {
  todos: { id: string; done: boolean }[]
  toggleTodo: (id: string) => void
}

const useTodoStore = create<TodoStore>()(
  immer((set) => ({
    todos: [],
    toggleTodo: (id) =>
      set((state) => {
        const todo = state.todos.find((item) => item.id === id)

        if (todo) {
          todo.done = !todo.done
        }
      }),
  })),
)
```

Immer удобен для вложенных структур, но не стоит использовать его как оправдание плохой формы state.

## subscribe

```tsx
const unsubscribe = useSettingsStore.subscribe((state) => {
  console.log('theme changed or another store field changed', state.theme)
})

unsubscribe()
```

`subscribe` полезен вне React: для логирования, синхронизации, интеграций.

## subscribeWithSelector

```tsx
import { subscribeWithSelector } from 'zustand/middleware'

const useStore = create(
  subscribeWithSelector((set) => ({
    theme: 'light',
    count: 0,
  })),
)

const unsubscribe = useStore.subscribe(
  (state) => state.theme,
  (theme, previousTheme) => {
    console.log(theme, previousTheme)
  },
)
```

Так можно реагировать только на конкретное поле.

## Что отвечать на собеседовании?

Основные API Zustand - `create`, `set`, `get`, selectors и `subscribe`. Для рабочих проектов важно знать middleware: `persist` для localStorage/AsyncStorage, `devtools` для Redux DevTools, `immer` для удобного immutable update и `subscribeWithSelector` для точных подписок.

## Мини-шпаргалка

- `persist` сохраняет store.
- `partialize` выбирает, что сохранять.
- `devtools` помогает дебажить actions.
- `immer` упрощает вложенные updates.
- `subscribeWithSelector` нужен для точных внешних подписок.
