# Как делать lazy loading routes?

> [!summary]
> Lazy loading routes разбивает приложение на chunks и загружает код страницы только при переходе на соответствующий маршрут. Это уменьшает initial bundle и ускоряет первый экран.

## Static import

```typescript
import AdminPage from "@/pages/AdminPage.vue";

{
  path: "/admin",
  component: AdminPage,
}
```

Так компонент попадет в initial bundle.

## Dynamic import

```typescript
{
  path: "/admin",
  component: () => import("@/pages/AdminPage.vue"),
}
```

Теперь page component загрузится отдельным chunk, когда пользователь перейдет на `/admin`.

## Где lazy loading особенно полезен?

- admin pages;
- settings;
- reports;
- rarely used pages;
- heavy charts;
- pages with big UI libraries.

## Loading UX

Lazy loading может добавить задержку при первом переходе. Для хорошего UX:

- держи chunks разумного размера;
- показывай skeleton/loading state для данных;
- prefetch важные routes, если это поддерживает инфраструктура;
- не дроби каждую мелочь без смысла.

## Мини-шпаргалка

- Lazy route = `component: () => import(...)`.
- Код страницы грузится при переходе.
- Initial bundle становится меньше.
- Не дроби приложение бессистемно.
- Тяжелые и редкие страницы - хорошие кандидаты.
