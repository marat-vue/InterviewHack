# Минимизация HTTP запросов

> [!NOTE]
> Чем меньше лишних запросов и чем лучше они организованы, тем быстрее страница получает нужные ресурсы и данные.

## Вопрос

Почему важно минимизировать количество HTTP-запросов?

## Основная идея

Каждый запрос имеет накладные расходы: DNS, соединение, TLS, заголовки, ожидание сервера, передача данных. Современный HTTP/2 и HTTP/3 лучше справляются с множеством запросов, но лишние запросы все равно ухудшают загрузку.

## Что можно оптимизировать

- удалить ненужные ресурсы;
- объединять запросы там, где это разумно;
- использовать кэширование;
- сжимать ответы;
- загружать данные по требованию;
- избегать waterfall-загрузки.

## Waterfall-проблема

```javascript
const user = await fetchUser();
const posts = await fetchPosts(user.id);
const comments = await fetchComments(posts[0].id);
```

Если запросы зависят друг от друга, последовательность неизбежна. Если не зависят, лучше запускать параллельно.

## Параллельная загрузка

```javascript
const [user, settings] = await Promise.all([
  fetchUser(),
  fetchSettings(),
]);
```

## Мини-шпаргалка

```text
remove unused -> cache -> compress -> parallelize -> lazy load
```
