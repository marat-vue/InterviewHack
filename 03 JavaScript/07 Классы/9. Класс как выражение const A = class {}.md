# Класс как выражение const A = class {}

> [!summary] Коротко
> Класс можно объявить как выражение и сохранить в переменную: `const A = class {}`.

## Вопрос

Можно ли использовать класс как выражение?

## Определение

Class expression - форма записи, где класс создается как значение и присваивается переменной, передается в функцию или возвращается из функции.

```javascript
const User = class {
  constructor(name) {
    this.name = name;
  }
};
```

После этого `User` можно использовать как обычный класс.

## Создание экземпляра

```javascript
const user = new User('Ann');

console.log(user.name); // 'Ann'
```

## Именованное class expression

```javascript
const User = class UserClass {
  getClassName() {
    return UserClass.name;
  }
};
```

Имя `UserClass` доступно внутри класса и полезно для отладки.

## Где встречается

- динамическое создание классов;
- фабрики классов;
- экспорт значения;
- передача класса как зависимости;
- тесты и моки.

## Class declaration vs class expression

```javascript
class A {}

const B = class {};
```

Оба варианта создают класс, но второй явно показывает, что класс используется как значение.

## Мини-шпаргалка

```javascript
const A = class {
  method() {}
};
```
