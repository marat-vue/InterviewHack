# Что происходит, когда в коде возникает ошибка?

> [!NOTE]
> Когда возникает ошибка, JavaScript прерывает обычный поток выполнения и ищет ближайший подходящий `catch`.

## Вопрос

Что делает движок JavaScript при ошибке?

## Порядок действий

1. Движок обнаруживает проблему.
2. Создается или выбрасывается объект ошибки.
3. Обычное выполнение кода прерывается.
4. Движок ищет ближайший `try...catch` выше по стеку вызовов.
5. Если `catch` найден, ошибка передается туда.
6. Если `catch` не найден, ошибка становится необработанной.

## Пример без обработки

```javascript
console.log('before');

throw new Error('Boom');

console.log('after'); // не выполнится
```

После `throw` выполнение текущего блока останавливается.

## Пример с обработкой

```javascript
try {
  console.log('before');
  throw new Error('Boom');
  console.log('after');
} catch (error) {
  console.log(error.message); // 'Boom'
}

console.log('continue');
```

`catch` перехватывает ошибку, и программа может продолжить работу.

## Ошибка поднимается по стеку

```javascript
function a() {
  b();
}

function b() {
  throw new Error('Failed');
}

try {
  a();
} catch (error) {
  console.log(error.message);
}
```

Если внутри `b` нет `catch`, ошибка поднимается к вызвавшей функции.

## Мини-шпаргалка

```text
error -> throw -> search catch -> handled or unhandled
```
