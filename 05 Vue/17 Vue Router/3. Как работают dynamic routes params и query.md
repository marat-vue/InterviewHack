# Как работают dynamic routes, params и query?

> [!summary]
> Dynamic routes позволяют описывать переменные части URL через `:param`. `params` являются частью path, а `query` находится после `?` и обычно используется для фильтров, поиска, пагинации и сортировки.

## Params

Route:

```typescript
{
  path: "/users/:id",
  name: "user-details",
  component: UserDetailsPage,
}
```

URL:

```txt
/users/42
```

Использование:

```typescript
const route = useRoute();
const userId = route.params.id;
```

`params` часто используют для identity ресурса: user id, product slug, article id.

## Query

URL:

```txt
/products?page=2&limit=20&search=phone
```

Использование:

```typescript
const route = useRoute();

const page = Number(route.query.page ?? 1);
const search = String(route.query.search ?? "");
```

Query подходит для состояния списка:

- page;
- limit;
- search;
- filters;
- sorting;
- tabs, если вкладка должна быть shareable URL state.

## Навигация с params

```typescript
router.push({
  name: "user-details",
  params: { id: user.id },
});
```

## Навигация с query

```typescript
router.push({
  name: "products",
  query: {
    page: 2,
    search: "phone",
  },
});
```

## Watch route changes

Если один и тот же компонент переиспользуется для разных params, `mounted` не вызовется заново. Следи за route:

```typescript
watch(
  () => route.params.id,
  async (id) => {
    await loadUser(String(id));
  },
  { immediate: true },
);
```

## Мини-шпаргалка

- `params` - часть path.
- `query` - часть после `?`.
- Params подходят для id/slug ресурса.
- Query подходит для фильтров и pagination.
- При изменении params компонент может переиспользоваться.
- Для загрузки данных по params используй `watch`.
