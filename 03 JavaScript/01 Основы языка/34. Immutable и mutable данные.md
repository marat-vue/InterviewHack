# Immutable и mutable данные

> [!summary] Коротко
> Mutable данные можно менять "на месте". Immutable данные нельзя изменить: вместо изменения создается новое значение. В JavaScript примитивы immutable, а объекты и массивы обычно mutable.

## Вопрос

Что такое immutable и mutable данные?

## Mutable

Mutable означает "изменяемый".

```javascript
const user = {
  name: "Anna",
};

user.name = "Max";

console.log(user); // { name: "Max" }
```

Объект остался тем же, но его содержимое изменилось.

Массивы тоже mutable:

```javascript
const numbers = [1, 2, 3];

numbers.push(4);

console.log(numbers); // [1, 2, 3, 4]
```

## Immutable

Immutable означает "неизменяемый".

Примитивы в JavaScript immutable:

```javascript
let text = "Hello";

text.toUpperCase(); // "HELLO"

console.log(text);  // "Hello"
```

Метод создал новую строку, но исходную не изменил.

```javascript
let count = 1;
count = count + 1;
```

Число `1` не изменилось. Переменная `count` теперь указывает на новое значение `2`.

## `const` не делает объект immutable

```javascript
const user = { name: "Anna" };

user.name = "Max"; // можно
user = {};         // нельзя
```

`const` защищает переменную от переназначения, но не замораживает объект.

## Почему иммутабельность полезна

Иммутабельный подход уменьшает неожиданные побочные эффекты.

Мутация:

```javascript
function addItem(items, item) {
  items.push(item);
  return items;
}
```

Иммутабельный вариант:

```javascript
function addItem(items, item) {
  return [...items, item];
}
```

Во втором варианте исходный массив не меняется.

## Пример с состоянием UI

```javascript
const state = {
  user: {
    name: "Anna",
  },
};

const nextState = {
  ...state,
  user: {
    ...state.user,
    name: "Max",
  },
};
```

Такой подход часто используют в React, Redux и других системах, где важно понимать, изменилось ли состояние.

## Как ограничить мутацию

`Object.freeze` запрещает менять верхний уровень объекта.

```javascript
const user = Object.freeze({
  name: "Anna",
});

user.name = "Max"; // не изменит объект, в strict mode может быть ошибка
```

Но это поверхностная заморозка:

```javascript
const state = Object.freeze({
  profile: { city: "Moscow" },
});

state.profile.city = "Kazan"; // вложенный объект все еще mutable
```

## Мини-шпаргалка

| Вид данных | Mutable? |
| --- | --- |
| `string`, `number`, `boolean` | нет |
| `null`, `undefined` | нет |
| `symbol`, `bigint` | нет |
| object | обычно да |
| array | да |
| function | объект, может иметь свойства |
