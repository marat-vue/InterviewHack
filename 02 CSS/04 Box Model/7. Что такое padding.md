# Что такое padding

> [!summary]
> `padding` - это внутренний отступ элемента: расстояние между content area и border. Он увеличивает внутреннее пространство блока.

## Главное

```css
.card {
  padding: 16px;
}
```

Текст внутри карточки отойдет от ее краев на `16px`.

## Запись по сторонам

```css
.box {
  padding-top: 8px;
  padding-right: 16px;
  padding-bottom: 8px;
  padding-left: 16px;
}
```

Сокращенная запись:

```css
.box {
  padding: 8px 16px;
}
```

Это означает: сверху/снизу `8px`, справа/слева `16px`.

## Padding и размер блока

При `content-box` padding увеличивает итоговый размер элемента.

```css
.box {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
}
```

При `border-box` padding входит в заданную ширину.

## Padding не бывает отрицательным

```css
.box {
  padding: -10px; /* невалидно */
}
```

Для сдвигов и наложений используют margin, transform или позиционирование.

## Мини-шпаргалка

- Padding - внутренний отступ.
- Находится между content и border.
- Может задаваться для каждой стороны.
- Не может быть отрицательным.
- При `content-box` увеличивает итоговый размер.
- При `border-box` входит в ширину элемента.
