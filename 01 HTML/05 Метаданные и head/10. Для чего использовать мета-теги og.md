# Для чего использовать мета-теги og

> [!summary]
> `og`-мета-теги используют, чтобы страница красиво и предсказуемо выглядела при отправке ссылки в соцсети, мессенджеры и сервисы предпросмотра.

## Главное

Когда пользователь отправляет ссылку, платформа пытается собрать preview-карточку. `og`-теги подсказывают, что именно показать.

```text
URL shared
  -> crawler reads HTML
  -> finds og-tags
  -> builds preview card
```

## Что можно контролировать

- Заголовок карточки.
- Описание.
- Изображение.
- Канонический URL.
- Тип страницы.
- Название сайта.

```html
<meta property="og:title" content="Курс по HTML">
<meta property="og:description" content="Практические заметки по HTML-разметке">
<meta property="og:image" content="https://example.com/og-image.jpg">
```

## Зачем это бизнесу и продукту

Хороший preview повышает доверие к ссылке и кликабельность. Это особенно важно для статей, лендингов, товаров, мероприятий и публичных страниц профиля.

## Изображение

`og:image` лучше задавать абсолютным URL.

```html
<meta property="og:image" content="https://example.com/assets/share.png">
```

Картинка должна быть доступна внешним сервисам без авторизации и блокировок.

## Отличие от обычных meta

```html
<meta name="description" content="Описание для поиска">
<meta property="og:description" content="Описание для карточки ссылки">
```

Обычный `description` ориентирован на поисковые системы, а `og:description` - на предпросмотр ссылки.

## Мини-шпаргалка

- `og`-теги нужны для preview ссылок.
- Они не заменяют `title` и `description`.
- `og:image` должен быть доступен по абсолютному URL.
- Для статей часто ставят `og:type="article"`.
- Для главной страницы часто ставят `og:type="website"`.
