# Как работают Hashes в Redis?

> [!NOTE]
> Hash в Redis - это map полей внутри одного ключа. Он удобен для объектов, где нужно читать и обновлять отдельные поля без перезаписи всего JSON.

## Когда использовать Hash?

Hash подходит для:

- user profile;
- session metadata;
- cart summary;
- feature flags object;
- counters by field;
- small object-like records.

Пример:

```redis
HSET user:1 email admin@example.com name Marat role admin
HGET user:1 email
HGETALL user:1
```

## Основные команды

| Команда | Что делает |
|---|---|
| `HSET key field value` | записывает field |
| `HGET key field` | читает field |
| `HMGET key f1 f2` | читает несколько fields |
| `HGETALL key` | читает весь hash |
| `HDEL key field` | удаляет field |
| `HEXISTS key field` | проверяет field |
| `HINCRBY key field n` | атомарно увеличивает number field |
| `HSCAN key cursor` | incremental обход fields |

## Node.js пример

```ts
await redis.hSet('user:1', {
  email: 'admin@example.com',
  name: 'Marat',
  role: 'admin',
});

const email = await redis.hGet('user:1', 'email');
const user = await redis.hGetAll('user:1');
```

## Как использовать Hash для counters?

```redis
HINCRBY metrics:api:2026-08-06 GET:/api/users 1
HINCRBY metrics:api:2026-08-06 POST:/api/users 1
EXPIRE metrics:api:2026-08-06 604800
```

Так можно хранить несколько counters в одном ключе.

## Когда `HGETALL` опасен?

`HGETALL` возвращает весь hash. Если hash огромный, команда может стать тяжелой.

Лучше:

```redis
HMGET user:1 email role
HSCAN huge:hash 0 COUNT 100
```

## Hash или JSON string?

| Задача | Лучше |
|---|---|
| Читать объект целиком | JSON string |
| Обновлять отдельные поля | Hash |
| Атомарно увеличивать field | Hash |
| Хранить сложную вложенность | RedisJSON или JSON string |
| Нужны schema/relations | SQL |

## Мини-шпаргалка

- Hash - object-like структура.
- `HSET`/`HGET` - поля.
- `HINCRBY` - counters внутри объекта.
- `HGETALL` осторожно на больших hash.
- Для больших hash используй `HSCAN`.
