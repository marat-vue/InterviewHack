# Объединение примитивов и объектов

> [!summary] Коротко
> Union может объединять и примитивы, и объекты: `string | number`, `User | Admin`, `string | { id: number }`. Правило одно: перед использованием уникальных свойств тип нужно сузить.

## Вопрос

Как объединять примитивы и объекты?

## Примитивы

```typescript
type Id = string | number;

function normalizeId(id: Id): string {
  return typeof id === "number" ? String(id) : id.trim();
}
```

## Объекты

```typescript
type User = { role: "user"; name: string };
type Admin = { role: "admin"; permissions: string[] };

type Person = User | Admin;

function getLabel(person: Person): string {
  if (person.role === "admin") {
    return person.permissions.join(", ");
  }

  return person.name;
}
```

## Примитив плюс объект

Иногда API принимает либо готовое значение, либо объект с настройками.

```typescript
type TimeoutConfig = number | { ms: number; retry: boolean };

function getTimeout(config: TimeoutConfig): number {
  if (typeof config === "number") {
    return config;
  }

  return config.ms;
}
```

## Что доступно без проверки

Без narrowing доступны только общие операции, безопасные для всех вариантов.

```typescript
function print(value: string | { toString(): string }) {
  console.log(value.toString());
}
```

## Мини-шпаргалка

- Примитивы сужают через `typeof`.
- Объекты часто сужают через дискриминатор или `in`.
- Не смешивай слишком много вариантов без необходимости.
- Хороший union легко проверить в коде.
