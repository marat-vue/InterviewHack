# Что делают хуки?

> [!summary]
> Хуки дают функциональным компонентам доступ к возможностям React: state, effects, refs, context, reducers, мемоизации, transition-обновлениям и пользовательским переиспользуемым сценариям.

## Основные группы хуков

| Хук | Что делает |
|---|---|
| `useState` | хранит локальное состояние |
| `useReducer` | хранит состояние через reducer |
| `useEffect` | запускает side effects после render |
| `useLayoutEffect` | запускает layout effect до отрисовки кадра |
| `useRef` | хранит mutable значение или DOM-ссылку |
| `useContext` | читает context |
| `useMemo` | мемоизирует вычисление |
| `useCallback` | мемоизирует функцию |
| `useTransition` | помечает обновления как transition |
| `useDeferredValue` | откладывает менее срочное значение |
| `useId` | генерирует стабильный id для accessibility |

## Хуки для состояния

```jsx
const [isOpen, setIsOpen] = useState(false)
```

```jsx
const [state, dispatch] = useReducer(reducer, initialState)
```

Используются, когда UI должен реагировать на изменяемые данные.

## Хуки для side effects

```jsx
useEffect(() => {
  document.title = 'Профиль'
}, [])
```

Effects нужны для синхронизации с внешними системами:

- DOM API;
- сеть;
- subscriptions;
- timers;
- analytics;
- browser storage.

## Хуки для производительности

```jsx
const filteredItems = useMemo(() => {
  return items.filter((item) => item.visible)
}, [items])
```

Но хуки производительности не нужно использовать механически. Сначала должна быть реальная причина.

## Custom hooks

Если логика повторяется, ее можно вынести:

```jsx
function useOnlineStatus() {
  const [isOnline, setIsOnline] = useState(navigator.onLine)
  // effects...
  return isOnline
}
```

Custom hook не возвращает UI, он возвращает данные и функции.

## Мини-шпаргалка

- Хуки подключают React-возможности к функциональному компоненту.
- `useState` и `useReducer` - про state.
- `useEffect` - про синхронизацию с внешним миром.
- `useRef` - mutable значение или DOM.
- Custom hooks переиспользуют логику, а не разметку.
