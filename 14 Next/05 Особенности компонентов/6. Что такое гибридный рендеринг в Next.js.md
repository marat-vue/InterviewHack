# Что такое гибридный рендеринг в Next.js?

> [!summary]
> Гибридный рендеринг в Next.js - возможность сочетать разные модели в одном приложении и даже на одной странице: Server Components, Client Components, static rendering, dynamic rendering, ISR, streaming и client-side interactivity.

## Простая идея

Одна страница может состоять из разных частей:

- заголовок и SEO-контент рендерятся на сервере;
- список товаров кешируется и обновляется через ISR;
- кнопка корзины работает на клиенте;
- рекомендации стримятся через Suspense;
- фильтры хранят состояние в URL или Client Component.

## Пример

```tsx
import { Suspense } from 'react'
import { AddToCartButton } from './AddToCartButton'
import { Recommendations } from './Recommendations'

export const revalidate = 3600

export default async function ProductPage({ params }: Props) {
  const { id } = await params
  const product = await getProduct(id)

  return (
    <main>
      <h1>{product.title}</h1>
      <p>{product.description}</p>

      <AddToCartButton productId={product.id} />

      <Suspense fallback={<p>Loading recommendations...</p>}>
        <Recommendations productId={product.id} />
      </Suspense>
    </main>
  )
}
```

Здесь есть static/ISR route, Server Components, Client Component и streaming boundary.

## Почему это важно?

Next.js не заставляет выбирать "все SSR" или "все CSR". Можно выбирать стратегию под конкретную часть интерфейса.

## Что отвечать на собеседовании?

Гибридный рендеринг - это сочетание server-rendered и client-rendered частей, а также разных стратегий кеширования и доставки UI. В App Router это достигается Server/Client Components, Suspense, streaming и настройками cache/revalidate.

## Частые ошибки

- Называть гибридным только SSR + CSR.
- Делать все Client Components и терять преимущества.
- Думать, что `revalidate` влияет на локальный UI-state.
- Путать streaming и lazy loading.
- Не отделять интерактивность от контента.

## Мини-шпаргалка

- Server Components - данные и HTML.
- Client Components - интерактивность.
- ISR - обновляемая статика.
- Suspense - границы ожидания.
- Streaming - доставка частями.
- Гибридность выбирается на уровне частей UI.
