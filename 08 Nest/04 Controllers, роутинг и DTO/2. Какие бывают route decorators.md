# Какие бывают route decorators?

> [!summary]
> Route decorators связывают метод controller с HTTP-методом и путем. В NestJS часто используют `@Get`, `@Post`, `@Put`, `@Patch`, `@Delete`, `@Options`, `@Head` и `@All`.

## Примеры

```ts
@Controller('users')
export class UsersController {
  @Get()
  findAll() {}

  @Get(':id')
  findOne() {}

  @Post()
  create() {}

  @Patch(':id')
  update() {}

  @Delete(':id')
  remove() {}
}
```

## REST-смысл

| Decorator | HTTP | Типичная задача |
|---|---|---|
| `@Get` | GET | чтение |
| `@Post` | POST | создание |
| `@Put` | PUT | полная замена |
| `@Patch` | PATCH | частичное обновление |
| `@Delete` | DELETE | удаление |

## Путь route

```ts
@Controller('orders')
@Get(':id/items')
```

Итоговый путь: `/orders/:id/items`.

## Мини-шпаргалка

- Route decorator задает HTTP-метод.
- `@Controller` задает общий prefix.
- `@Get(':id')` задает path param.
- REST-методы стоит использовать по смыслу.
- `@All()` ловит все HTTP-методы, но используется редко.
