# Микро vs Макро таски

> [!NOTE] Коротко
> Микротаски выполняются раньше макротасок и очищаются все сразу. Макротаски берутся по одной за цикл Event Loop.

## Вопрос

Чем микротаски отличаются от макротасок?

## Основное правило

После выполнения синхронного кода Event Loop:

1. полностью очищает очередь микротасок;
2. выполняет одну макротаску;
3. снова полностью очищает микротаски;
4. повторяет цикл.

## Микротаски

Микротаски нужны для быстрых продолжений, которые должны выполниться как можно раньше после текущего кода.

```javascript
Promise.resolve().then(() => console.log('microtask'));
queueMicrotask(() => console.log('another microtask'));
```

Примеры:

- `Promise.then`;
- `Promise.catch`;
- `Promise.finally`;
- `queueMicrotask`;
- `MutationObserver`.

## Макротаски

Макротаски представляют более крупные события среды выполнения.

```javascript
setTimeout(() => console.log('task'), 0);
```

Примеры:

- `setTimeout`;
- `setInterval`;
- DOM-события;
- I/O;
- `postMessage`.

## Наглядный пример

```javascript
console.log('sync 1');

setTimeout(() => console.log('timeout'), 0);

Promise.resolve().then(() => console.log('promise'));

console.log('sync 2');

// sync 1
// sync 2
// promise
// timeout
```

## Сравнение

| Критерий | Микротаски | Макротаски |
| --- | --- | --- |
| Приоритет | выше | ниже |
| Выполнение | все подряд | по одной |
| Примеры | промисы, `queueMicrotask` | таймеры, события |
| Риск | могут задержать рендер | могут ждать микротаски |

## Мини-шпаргалка

```text
sync -> all microtasks -> one macrotask -> all microtasks
```
