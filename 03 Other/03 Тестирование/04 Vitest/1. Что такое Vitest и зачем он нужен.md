# Что такое Vitest и зачем он нужен?

> [!summary]
> Vitest - современный test runner, построенный вокруг Vite. Он быстро запускает тесты, понимает Vite-конфиг, поддерживает TypeScript, mocks, snapshots, coverage, watch mode и хорошо подходит для Vue/Vite-проектов.

## Простое определение

Vitest - это инструмент, который:

- находит тестовые файлы;
- запускает тесты;
- предоставляет API `test`, `describe`, `expect`;
- умеет мокать зависимости через `vi`;
- считает coverage;
- работает в watch mode;
- интегрируется с Vite.

## Почему Vitest популярен во Vue?

Современные Vue-проекты часто собираются через Vite. Vitest использует ту же экосистему, поэтому:

- проще работать с aliases из `vite.config`;
- быстрее старт;
- TypeScript и ESM работают естественнее;
- удобно тестировать компоненты через Vue Test Utils;
- можно использовать jsdom/happy-dom/browser mode.

## Минимальный тест

```ts
import { expect, test } from 'vitest';

function sum(a: number, b: number) {
  return a + b;
}

test('adds numbers', () => {
  expect(sum(2, 3)).toBe(5);
});
```

## Что важно знать на собеседовании?

Vitest похож на Jest по API, но лучше подходит для Vite-проектов. Он читает Vite-конфиг, хорошо работает с ESM и современным frontend stack.

Важно уметь объяснить:

- чем runner отличается от assertion library;
- что такое test environment;
- как работают mocks;
- зачем нужны setup files;
- как включить coverage;
- чем Vitest отличается от Jest.

## Мини-шпаргалка

- Vitest - test runner для Vite-экосистемы.
- Основные API: `test`, `describe`, `expect`, `vi`.
- Файлы часто называют `*.test.ts` или `*.spec.ts`.
- Для Vue-компонентов Vitest используют вместе с Vue Test Utils.
- Для DOM нужен `jsdom`, `happy-dom` или browser mode.
