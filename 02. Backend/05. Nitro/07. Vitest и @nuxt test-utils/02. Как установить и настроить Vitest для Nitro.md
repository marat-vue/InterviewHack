# Как установить и настроить Vitest для Nitro?

> [!NOTE]
> Для standalone Nitro достаточно `vitest`. Для Nuxt/Nitro runtime дополнительно используют `@nuxt/test-utils`, `@vue/test-utils`, DOM environment и иногда Playwright.

## Установка для standalone Nitro

```bash
npm i -D vitest
```

Scripts:

```json
{
  "scripts": {
    "test": "vitest",
    "test:run": "vitest run",
    "test:coverage": "vitest run --coverage"
  }
}
```

## `vitest.config.ts`

```ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    environment: 'node',
    include: [
      'tests/**/*.test.ts',
      'server/**/*.test.ts',
    ],
    setupFiles: [
      './tests/setup.ts',
    ],
  },
});
```

## Environment

| Environment | Когда использовать |
|---|---|
| `node` | server code, Nitro services, Prisma |
| `happy-dom` | легкий DOM для components |
| `jsdom` | DOM-compatible component tests |
| browser mode | реальные browser APIs |

Для Nitro backend по умолчанию нужен `node`.

## Setup file

```ts
// tests/setup.ts
import { afterEach } from 'vitest';
import { vi } from 'vitest';

afterEach(() => {
  vi.clearAllMocks();
});
```

Setup file используют для:

- reset mocks;
- env setup;
- database cleanup;
- global test helpers;
- fake timers cleanup.

## Aliases

Если проект использует aliases:

```ts
import { defineConfig } from 'vitest/config';
import { fileURLToPath } from 'node:url';

export default defineConfig({
  resolve: {
    alias: {
      '~': fileURLToPath(new URL('./', import.meta.url)),
      '@': fileURLToPath(new URL('./', import.meta.url)),
    },
  },
});
```

В Vite/Nuxt проектах Vitest часто может переиспользовать Vite/Nuxt config.

## Coverage

Установка provider:

```bash
npm i -D @vitest/coverage-v8
```

Config:

```ts
export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'html'],
      include: ['server/**/*.ts'],
      exclude: ['server/**/*.test.ts'],
    },
  },
});
```

## Мини-шпаргалка

- Standalone Nitro tests: `vitest`.
- Server environment: `node`.
- `setupFiles` - общая подготовка.
- Coverage: `vitest run --coverage`.
- Для Nuxt runtime нужен `@nuxt/test-utils`.
- Prisma tests требуют отдельной database strategy.
