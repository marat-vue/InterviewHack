## Что отвечать на собеседовании?

Хороший ответ по Docker строится вокруг причин: Docker нужен для воспроизводимого окружения, image - неизменяемый шаблон, container - запущенный экземпляр, Dockerfile собирает image слоями, Compose связывает несколько services, networks дают DNS между контейнерами, volumes сохраняют state, а production требует маленьких images, non-root user и безопасной работы с secrets.

## Частые ошибки

- Учить только команды без понимания модели.
- Не уметь объяснить `localhost` внутри container.
- Не знать разницу между `RUN`, `CMD`, `ENTRYPOINT`.
- Забывать про `.dockerignore`.
- Не понимать named volumes.
- Считать Compose production orchestrator уровня Kubernetes.

## Мини-шпаргалка

- Image vs container - главный базис.
- Dockerfile layers/cache - частая тема.
- Ports: `host:container`.
- Compose service name = DNS.
- Volume нужен для state.
- Secrets не в image.
- Debug starts with `ps`, `logs`, `inspect`.
