# Неизменяемые поля

> [!NOTE]
> Неизменяемое поле задается модификатором `readonly`, который запрещает присваивать новое значение после инициализации.

## Вопрос

Как задать неизменяемые свойства в интерфейсе или типе?

## readonly в interface

```typescript
interface User {
  readonly id: number;
  name: string;
}

const user: User = {
  id: 1,
  name: 'Ann',
};

user.name = 'Bob';
user.id = 2; // ошибка TypeScript
```

`readonly` запрещает менять поле через присваивание.

## readonly в type

```typescript
type User = {
  readonly id: number;
  name: string;
};
```

Работает так же.

## Важный нюанс

`readonly` - проверка TypeScript на этапе компиляции. Она не делает объект полностью неизменяемым в runtime.

## Вложенные объекты

```typescript
type State = {
  readonly user: {
    name: string;
  };
};

const state: State = {
  user: { name: 'Ann' },
};

state.user.name = 'Bob'; // разрешено
```

`readonly` здесь защищает только свойство `user`, но не делает вложенный объект глубокозамороженным.

## Readonly utility type

```typescript
type ReadonlyUser = Readonly<User>;
```

`Readonly<T>` делает все верхнеуровневые поля типа `readonly`.

## Мини-шпаргалка

```typescript
type Entity = {
  readonly id: number;
};
```
