# Как передавать props, slots, attrs и global options?

> [!summary]
> В `mount` можно передавать `props`, `slots`, `attrs` и `global` options. Это позволяет смонтировать компонент в нужном состоянии и подключить плагины, stubs, mocks, provide/inject и глобальные компоненты.

## Props

```ts
const wrapper = mount(UserCard, {
  props: {
    user: {
      name: 'Ann',
      email: 'ann@example.com',
    },
  },
});

expect(wrapper.text()).toContain('Ann');
```

Props задают входные данные компонента.

## Slots

```ts
const wrapper = mount(AppLayout, {
  slots: {
    default: '<p>Контент страницы</p>',
    header: '<h1>Профиль</h1>',
  },
});

expect(wrapper.text()).toContain('Профиль');
```

Slots нужны для layout-компонентов, карточек, модалок и таблиц.

## Attrs

```ts
const wrapper = mount(BaseInput, {
  attrs: {
    id: 'email',
    name: 'email',
  },
});

expect(wrapper.get('input').attributes('name')).toBe('email');
```

## Global options

`global` используется для plugin-level настроек:

```ts
mount(Component, {
  global: {
    plugins: [pinia, router],
    stubs: {
      RouterLink: true,
    },
    provide: {
      apiClient,
    },
    mocks: {
      $t: (key: string) => key,
    },
  },
});
```

## Мини-шпаргалка

- `props` передают входные данные.
- `slots` проверяют вставляемый контент.
- `attrs` передают обычные HTML-атрибуты.
- `global.plugins` подключает Pinia, Router, Vuetify.
- `global.stubs` заменяет дочерние компоненты.
- `global.provide` помогает тестировать injection.
