# Что делает useInsertionEffect?

> [!summary]
> `useInsertionEffect` - специальный хук для авторов CSS-in-JS библиотек. Он позволяет вставить стили в DOM до layout effects, чтобы измерения layout уже учитывали нужные стили. В обычном приложении почти всегда нужен `useEffect` или `useLayoutEffect`, а не `useInsertionEffect`.

## Для чего он существует?

CSS-in-JS библиотекам иногда нужно вставить `<style>` до того, как другие компоненты начнут измерять layout:

```jsx
useInsertionEffect(() => {
  injectStyle(rule)
}, [rule])
```

Если стили вставить слишком поздно, `useLayoutEffect` другого компонента может измерить элемент без актуальных стилей.

## Когда обычному разработчику он не нужен?

Почти всегда.

Не используй `useInsertionEffect` для:

- API-запросов;
- подписок;
- таймеров;
- DOM-измерений;
- обновления состояния;
- analytics.

Официальная идея: это hook для библиотек, а не everyday app code.

## Важные ограничения

- Нельзя обновлять state внутри `useInsertionEffect`.
- Refs к этому моменту могут быть еще не прикреплены.
- Не нужно полагаться на конкретное состояние DOM.
- Effects не выполняются во время server rendering.

## Что использовать вместо него?

| Задача | Хук |
|---|---|
| API, подписка, analytics | `useEffect` |
| измерить DOM до paint | `useLayoutEffect` |
| mutable value или DOM ref | `useRef` |
| вставить CSS до layout effects в библиотеке | `useInsertionEffect` |

## Мини-шпаргалка

- `useInsertionEffect` нужен в основном CSS-in-JS библиотекам.
- Он выполняется до layout effects.
- Он не предназначен для обычных side effects.
- Внутри нельзя обновлять state.
- В приложениях почти всегда выбирают `useEffect` или `useLayoutEffect`.
