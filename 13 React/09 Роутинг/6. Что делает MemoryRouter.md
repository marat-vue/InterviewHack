# Что делает MemoryRouter?

> [!summary]
> `MemoryRouter` хранит историю навигации в памяти JavaScript, а не в адресной строке браузера. Он особенно полезен в тестах, Storybook и окружениях, где нет настоящего browser history.

## Базовый пример

```jsx
import { MemoryRouter, Route, Routes } from 'react-router-dom'

function AppForTest() {
  return (
    <MemoryRouter initialEntries={['/about']}>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
      </Routes>
    </MemoryRouter>
  )
}
```

Приложение стартует как будто пользователь находится на `/about`, но реальный URL браузера не меняется.

## Чем отличается от BrowserRouter?

`BrowserRouter` синхронизируется с адресной строкой.

`MemoryRouter` хранит массив entries внутри себя:

```text
['/', '/about', '/settings']
```

И текущий индекс:

```text
initialIndex = 1 -> текущий route '/about'
```

## Почему полезен в тестах?

В тестах часто нужно проверить компонент в конкретном маршруте.

```jsx
test('renders user page', () => {
  render(
    <MemoryRouter initialEntries={['/users/42']}>
      <Routes>
        <Route path="/users/:userId" element={<UserPage />} />
      </Routes>
    </MemoryRouter>,
  )

  expect(screen.getByText(/42/)).toBeInTheDocument()
})
```

Не нужно поднимать реальный сервер или менять URL тестового окружения.

## Тест перехода

```jsx
test('navigates to about page', async () => {
  render(
    <MemoryRouter initialEntries={['/']}>
      <Routes>
        <Route path="/" element={<Link to="/about">About</Link>} />
        <Route path="/about" element={<h1>About page</h1>} />
      </Routes>
    </MemoryRouter>,
  )

  await userEvent.click(screen.getByText('About'))

  expect(screen.getByRole('heading', { name: 'About page' })).toBeInTheDocument()
})
```

## Где еще используют?

- Storybook stories;
- unit/integration tests;
- React Native-like окружения;
- демо-компоненты;
- изолированные preview.

## Мини-шпаргалка

- `MemoryRouter` не меняет адресную строку.
- История хранится в памяти.
- `initialEntries` задает стартовые URL.
- `initialIndex` выбирает текущую позицию в истории.
- Это основной router для тестов компонентов с routing.
