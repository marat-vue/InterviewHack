# Что делает useSyncExternalStore?

> [!summary]
> `useSyncExternalStore` - хук для подписки React-компонента на внешний store, который живет вне React. Он нужен авторам state managers, интеграциям с browser APIs и библиотекам, которым важно корректно работать с concurrent rendering и SSR.

## Базовый синтаксис

```jsx
const snapshot = useSyncExternalStore(
  subscribe,
  getSnapshot,
  getServerSnapshot
)
```

Аргументы:

- `subscribe` - подписывает на изменения и возвращает unsubscribe;
- `getSnapshot` - возвращает текущий снимок данных;
- `getServerSnapshot` - snapshot для SSR, если нужен.

## Пример с browser API

```jsx
function subscribe(callback) {
  window.addEventListener('online', callback)
  window.addEventListener('offline', callback)

  return () => {
    window.removeEventListener('online', callback)
    window.removeEventListener('offline', callback)
  }
}

function getSnapshot() {
  return navigator.onLine
}

function useOnlineStatus() {
  return useSyncExternalStore(subscribe, getSnapshot)
}
```

Использование:

```jsx
function Status() {
  const isOnline = useOnlineStatus()
  return <p>{isOnline ? 'online' : 'offline'}</p>
}
```

## Почему не просто useEffect + useState?

Для простых случаев можно использовать `useEffect`. Но `useSyncExternalStore` создан для корректной подписки на внешние изменяемые источники в современной модели React.

Он особенно важен для:

- Redux-like stores;
- Zustand-like stores;
- browser APIs;
- libraries;
- SSR-compatible subscriptions.

## Важная ошибка

`getSnapshot` должен возвращать кешируемое значение. Если он каждый раз возвращает новый объект без реального изменения, React может постоянно ререндерить компонент.

Плохо:

```jsx
function getSnapshot() {
  return { online: navigator.onLine }
}
```

Лучше возвращать примитив или стабильный snapshot.

## Мини-шпаргалка

- `useSyncExternalStore` подписывает компонент на внешний store.
- Нужны `subscribe` и `getSnapshot`.
- Изменение snapshot вызывает render.
- Для SSR можно передать `getServerSnapshot`.
- Это чаще инструмент библиотек, чем everyday UI-кода.
