# Что такое HTTP headers?

> [!summary]
> HTTP headers - это metadata запроса или ответа. Через headers клиент и сервер договариваются о формате данных, auth, cookies, cache, CORS, security policy, compression и других правилах обмена.

## Как выглядит header?

```http
Content-Type: application/json
Authorization: Bearer access_token
Cache-Control: no-store
```

Header состоит из имени и значения. Имена headers нечувствительны к регистру, но на практике их пишут в привычном виде.

## Request headers

Request headers отправляет клиент:

```http
GET /api/users HTTP/1.1
Host: api.example.com
Accept: application/json
Authorization: Bearer token
Origin: https://app.example.com
```

Они объясняют серверу:

- кто отправил запрос;
- какой формат ответа нужен;
- есть ли credentials;
- откуда пришел cross-origin request;
- можно ли использовать compression.

## Response headers

Response headers отправляет сервер:

```http
HTTP/1.1 200 OK
Content-Type: application/json
Set-Cookie: sid=abc; HttpOnly; Secure; SameSite=Lax
Cache-Control: private, max-age=60
```

Они объясняют браузеру:

- какой формат body;
- нужно ли сохранить cookie;
- можно ли кешировать response;
- разрешен ли CORS;
- какие security policies применить.

## Headers и body

Headers не заменяют body. Headers описывают сообщение, body несет основные данные.

```http
POST /api/users
Content-Type: application/json

{
  "email": "anna@example.com"
}
```

`Content-Type` говорит, как читать body.

## Мини-шпаргалка

- Headers - metadata HTTP-сообщения.
- Request headers отправляет client.
- Response headers отправляет server.
- `Content-Type` описывает body.
- `Authorization`, `Cookie`, `Set-Cookie`, `Cache-Control`, `Origin` особенно важны для frontend.
