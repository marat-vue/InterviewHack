# По ссылке или по значению

> [!NOTE]
> Примитивы копируются по значению. Объекты копируются по ссылке: переменные могут указывать на один и тот же объект, поэтому изменение через одну переменную видно через другую.

## Вопрос

Что такое "значение по ссылке" и "по значению"?

## Примитивы копируются по значению

Примитивы:

```javascript
string;
number;
boolean;
null;
undefined;
symbol;
bigint;
```

При присваивании копируется само значение.

```javascript
let a = 5;
let b = a;

b = 10;

console.log(a); // 5
console.log(b); // 10
```

`a` и `b` независимы.

## Объекты копируются по ссылке

Объект хранится отдельно, а переменная содержит ссылку на него.

```javascript
const user = { name: "Anna" };
const admin = user;

admin.name = "Max";

console.log(user.name); // "Max"
```

`user` и `admin` указывают на один и тот же объект.

## Сравнение

Примитивы сравниваются по значению:

```javascript
10 === 10;       // true
"hi" === "hi";   // true
```

Объекты сравниваются по ссылке:

```javascript
{} === {};       // false
[] === [];       // false

const a = {};
const b = a;

a === b;         // true
```

Два одинаково выглядящих объекта - это два разных объекта.

## Передача в функцию

Примитив:

```javascript
function change(value) {
  value = 100;
}

let count = 1;
change(count);

console.log(count); // 1
```

Объект:

```javascript
function change(user) {
  user.name = "Max";
}

const user = { name: "Anna" };
change(user);

console.log(user.name); // "Max"
```

Функция получает копию ссылки, но эта ссылка ведет к тому же объекту.

## Как сделать копию объекта

Поверхностная копия:

```javascript
const user = { name: "Anna", age: 25 };
const copy = { ...user };

copy.name = "Max";

console.log(user.name); // "Anna"
```

Для вложенных объектов поверхностной копии недостаточно.

```javascript
const user = { profile: { city: "Moscow" } };
const copy = { ...user };

copy.profile.city = "Kazan";

console.log(user.profile.city); // "Kazan"
```

## Мини-шпаргалка

| Тип значения | Как копируется | Как сравнивается |
| --- | --- | --- |
| Примитив | по значению | по значению |
| Объект | копируется ссылка | по ссылке |
| Массив | копируется ссылка | по ссылке |
| Функция | копируется ссылка | по ссылке |
