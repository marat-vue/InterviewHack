# Как использовать Nuxt Scripts?

> [!summary]
> Nuxt Scripts помогает безопаснее и производительнее подключать third-party scripts: analytics, trackers, chat widgets, maps, ads. Он дает SSR-safe API, lazy triggers, type safety и контроль загрузки вместо хаотичных script tags.

## Зачем нужен Nuxt Scripts?

Third-party scripts могут:

- блокировать rendering;
- ухудшать LCP/INP;
- ставить cookies;
- ломать privacy;
- вызывать ошибки при SSR;
- грузиться раньше согласия пользователя.

Nuxt Scripts дает controlled loading.

## Установка

```bash
npx nuxi@latest module add scripts
```

Вручную:

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/scripts'],
});
```

## Пример useScript

```ts
const { proxy } = useScript('/tracker.js', {
  trigger: 'onNuxtReady',
  use() {
    return {
      trackEvent: window.trackEvent,
    };
  },
});

proxy.trackEvent('page_view');
```

Идея: код остается SSR-safe, а script грузится по выбранному trigger.

## Когда использовать?

- analytics;
- A/B testing;
- chat widgets;
- maps;
- payment widgets;
- video embeds;
- consent-dependent scripts.

## Что не стоит делать?

Не стоит бездумно добавлять scripts через `useHead`:

```ts
useHead({
  script: [{ src: 'https://tracker.example.com/script.js' }],
});
```

Так легко потерять контроль над загрузкой, SSR и privacy.

## Мини-шпаргалка

- Nuxt Scripts управляет third-party scripts.
- Полезен для performance, privacy и SSR safety.
- `useScript` дает controlled loading.
- Trigger определяет, когда грузить script.
- Third-party scripts всегда проверяй в Lighthouse/DevTools.
