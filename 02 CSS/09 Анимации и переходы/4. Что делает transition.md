# Что делает transition

> [!summary]
> `transition` задает плавный переход CSS-свойства от одного значения к другому при изменении состояния элемента.

## Главное

```css
.button {
  background: #2563eb;
  transition: background 200ms ease;
}

.button:hover {
  background: #1d4ed8;
}
```

Когда пользователь наведет курсор, фон изменится плавно за `200ms`.

## Состав transition

```css
.card {
  transition-property: transform;
  transition-duration: 200ms;
  transition-timing-function: ease;
  transition-delay: 0ms;
}
```

Сокращенная запись:

```css
.card {
  transition: transform 200ms ease;
}
```

## Несколько свойств

```css
.card {
  transition:
    transform 200ms ease,
    box-shadow 200ms ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgb(0 0 0 / 0.16);
}
```

## Что можно анимировать

Плавно переходят только свойства, у которых можно интерполировать значения: цвет, opacity, transform, размеры, отступы и другие числовые значения. `display` обычно не анимируется как обычное числовое свойство.

## Мини-шпаргалка

- `transition` работает при изменении CSS-свойства.
- Нужно начальное и конечное состояние.
- Сокращение: `property duration timing delay`.
- Можно перечислить несколько transitions через запятую.
- Для производительности чаще выбирают `transform` и `opacity`.
