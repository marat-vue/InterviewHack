# Когда промис считается “выполненным”?

> [!NOTE]
> Промис считается выполненным, когда он перешел из `pending` в `fulfilled` и получил успешное значение.

## Вопрос

Когда Promise считается выполненным и что значит `fulfilled`?

## Определение

Промис считается выполненным, когда для него вызван `resolve(value)` и итоговое состояние стало `fulfilled`.

После выполнения промис хранит значение, которое можно получить через `.then()` или `await`.

## Пример

```javascript
const promise = new Promise((resolve) => {
  setTimeout(() => {
    resolve('data loaded');
  }, 1000);
});

promise.then((value) => {
  console.log(value); // 'data loaded'
});
```

Через секунду промис перейдет в состояние `fulfilled`.

## Важное уточнение про resolve

Если вызвать `resolve()` с обычным значением, промис выполнится этим значением.

```javascript
Promise.resolve(10).then(console.log); // 10
```

Если вызвать `resolve()` с другим промисом, внешний промис примет его итоговое состояние.

```javascript
const inner = Promise.resolve('ok');
const outer = Promise.resolve(inner);

outer.then(console.log); // 'ok'
```

## Выполненный не значит settled?

`fulfilled` - успешное завершение. `settled` - любое завершение: `fulfilled` или `rejected`.

```text
pending -> fulfilled
pending -> rejected
```

Оба варианта делают промис settled, но только первый делает его fulfilled.

## Мини-шпаргалка

```javascript
resolve(value); // fulfilled
reject(reason); // rejected
```
