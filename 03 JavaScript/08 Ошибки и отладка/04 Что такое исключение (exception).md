# Что такое исключение (exception)?

> [!NOTE] Коротко
> Исключение - ошибка или значение, которое выбрасывается через `throw` и прерывает обычный поток выполнения.

## Вопрос

Что такое exception в JavaScript?

## Определение

Исключение - событие во время выполнения программы, когда нормальный ход кода прерывается. Исключение можно выбросить через `throw` и обработать через `try...catch`.

В JavaScript технически можно выбросить любое значение, но хорошая практика - выбрасывать объект `Error` или его наследника.

## Пример

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('Division by zero');
  }

  return a / b;
}
```

## Обработка исключения

```javascript
try {
  divide(10, 0);
} catch (error) {
  console.error(error.message); // 'Division by zero'
}
```

После обработки программа может продолжить работу.

## Исключение vs ошибка

| Термин | Смысл |
| --- | --- |
| Error | объект с информацией о проблеме |
| Exception | выброшенная проблема, которая прерывает поток |
| throw | оператор, который выбрасывает исключение |
| catch | блок, который ловит исключение |

## Мини-шпаргалка

```javascript
try {
  throw new Error('Problem');
} catch (error) {
  console.log(error.message);
}
```
