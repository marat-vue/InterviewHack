# Что такое ACID?

> [!summary]
> ACID - набор свойств транзакций: Atomicity, Consistency, Isolation, Durability. Эти свойства объясняют, почему база может безопасно выполнять сложные изменения данных.

## Atomicity

Транзакция выполняется целиком или не выполняется вообще.

```txt
списать деньги -> зачислить деньги
```

Нельзя оставить систему только со списанием.

## Consistency

Транзакция переводит базу из одного корректного состояния в другое, не нарушая constraints.

## Isolation

Параллельные транзакции не должны некорректно мешать друг другу. Степень изоляции зависит от уровня isolation.

## Durability

После `COMMIT` данные должны сохраниться даже при сбое, в рамках гарантий конкретной СУБД и настроек.

## Мини-шпаргалка

- A - атомарность.
- C - согласованность.
- I - изоляция.
- D - долговечность.
- ACID особенно важен для финансов, заказов и любых критичных данных.
