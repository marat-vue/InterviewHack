# Что такое роутинг (routing) в React-приложении?

> [!summary]
> Роутинг в React-приложении - это связь между URL и тем, какой экран или компонент должен быть показан. В SPA роутинг обычно работает на клиенте: страница не перезагружается, а React меняет отображаемый компонент.

## Зачем нужен роутинг?

Без роутинга приложение похоже на один экран. Роутинг дает:

- разные страницы;
- URL для конкретного состояния;
- навигацию назад/вперед;
- deep links;
- динамические страницы вроде `/users/42`;
- query-параметры для фильтров;
- вложенные layout.

## Базовый пример React Router

```jsx
import { BrowserRouter, Link, Route, Routes } from 'react-router-dom'

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/users/42">User</Link>
      </nav>

      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/users/:userId" element={<UserPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Routes>
    </BrowserRouter>
  )
}
```

## Что происходит при переходе?

```text
1. Пользователь нажимает <Link>
2. React Router меняет URL через History API
3. Routes выбирает подходящий Route
4. React рендерит нужный компонент
5. Полной перезагрузки страницы нет
```

## Динамические маршруты

```jsx
<Route path="/products/:slug" element={<ProductPage />} />
```

```jsx
function ProductPage() {
  const { slug } = useParams()

  return <h1>Product: {slug}</h1>
}
```

`slug` берется из URL.

## Роутинг - это не только компоненты

В современных версиях React Router есть несколько режимов использования. В простом SPA часто достаточно declarative routing через `BrowserRouter`, `Routes` и `Route`. В более сложных приложениях используют data routers, loaders, actions, redirects и framework mode.

## Мини-шпаргалка

- Роутинг связывает URL и UI.
- В SPA переходы обычно происходят без полной перезагрузки.
- `BrowserRouter` хранит историю в адресной строке.
- `Routes` выбирает подходящий `Route`.
- Динамические параметры читают через `useParams`.
