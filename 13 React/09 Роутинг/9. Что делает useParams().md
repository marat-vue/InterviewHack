# Что делает useParams()?

> [!summary]
> `useParams` возвращает динамические параметры текущего маршрута. Если route описан как `/users/:userId`, то на URL `/users/42` хук вернет объект с `userId`.

## Базовый пример

```jsx
import { Route, Routes, useParams } from 'react-router-dom'

function App() {
  return (
    <Routes>
      <Route path="/users/:userId" element={<UserPage />} />
    </Routes>
  )
}

function UserPage() {
  const { userId } = useParams()

  return <h1>User {userId}</h1>
}
```

URL:

```text
/users/42 -> { userId: "42" }
```

## Важные особенности

Все параметры приходят строками:

```jsx
const { productId } = useParams()
const numericProductId = Number(productId)
```

Имена берутся из route path:

```jsx
<Route path="/teams/:teamId/projects/:projectId" element={<ProjectPage />} />
```

```jsx
const { teamId, projectId } = useParams()
```

## Для чего используют?

- загрузка сущности по id;
- страницы деталей;
- slug страниц;
- вложенные ресурсы;
- tabs внутри сущности;
- route-based permissions.

Пример:

```jsx
function ProductPage() {
  const { slug } = useParams()
  const { data, isLoading } = useProductBySlug(slug)

  if (isLoading) return <ProductSkeleton />

  return <ProductDetails product={data} />
}
```

## Params vs query params

Route params описывают часть пути:

```text
/products/macbook-pro
```

Query params описывают настройки просмотра:

```text
/products?page=2&sort=price
```

Обычно `id` или `slug` кладут в params, а фильтры, сортировку и пагинацию - в query.

## Мини-шпаргалка

- `useParams` читает `:params` из route path.
- Значения всегда строки.
- Имена параметров задаются в маршруте.
- Для query string используй `useSearchParams`.
- Хук работает только внутри Router.
