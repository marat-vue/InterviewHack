# Как реализовать вложенный список

> [!summary]
> Вложенный список создается, когда один список помещается внутрь элемента `<li>` другого списка. Так показывают иерархию: меню, категории, оглавление или дерево разделов.

## Главное

Вложенный `ul` или `ol` должен находиться внутри `li`, а не рядом с ним.

```html
<ul>
  <li>
    Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
```

## Вложенный нумерованный список

```html
<ol>
  <li>
    Подготовить проект
    <ol>
      <li>Создать репозиторий</li>
      <li>Установить зависимости</li>
    </ol>
  </li>
  <li>Запустить приложение</li>
</ol>
```

Так удобно описывать шаги с подшагами.

## Частая ошибка

```html
<!-- неправильно -->
<ul>
  <li>Frontend</li>
  <ul>
    <li>HTML</li>
  </ul>
</ul>
```

Вложенный список должен быть частью пункта, к которому относится.

## Навигационное меню

```html
<nav aria-label="Каталог">
  <ul>
    <li>
      <a href="/catalog">Каталог</a>
      <ul>
        <li><a href="/catalog/laptops">Ноутбуки</a></li>
        <li><a href="/catalog/phones">Смартфоны</a></li>
      </ul>
    </li>
  </ul>
</nav>
```

## Мини-шпаргалка

- Вложенный список помещают внутрь `li`.
- Можно вкладывать `ul` в `ul`, `ol` в `ol` и смешивать их.
- Используется для иерархий и подшагов.
- Не делай слишком глубокую вложенность без необходимости.
- Для навигации оборачивай список в `nav`.
