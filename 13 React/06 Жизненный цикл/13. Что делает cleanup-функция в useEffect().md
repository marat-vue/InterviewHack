# Что делает cleanup-функция в useEffect?

> [!summary]
> Cleanup-функция в `useEffect` очищает то, что effect создал: подписку, таймер, соединение, observer или запрос. React вызывает cleanup перед следующим запуском effect с новыми зависимостями и при размонтировании компонента.

## Базовый пример

```jsx
useEffect(() => {
  const timerId = setInterval(() => {
    console.log('tick')
  }, 1000)

  return () => {
    clearInterval(timerId)
  }
}, [])
```

Effect создает timer, cleanup удаляет timer.

## Схема выполнения

```text
setup
dependencies changed
cleanup старого setup
setup нового effect
unmount
cleanup последнего setup
```

Cleanup должен зеркально отменять setup.

## Пример с WebSocket

```jsx
useEffect(() => {
  const socket = new WebSocket(url)

  socket.addEventListener('message', handleMessage)

  return () => {
    socket.removeEventListener('message', handleMessage)
    socket.close()
  }
}, [url])
```

При смене `url` старое соединение закроется до открытия нового.

## Strict Mode

В development Strict Mode React может выполнить:

```text
setup -> cleanup -> setup
```

Это проверяет, что cleanup действительно отменяет setup. Если код ломается, значит effect неустойчив к повторной инициализации.

## Мини-шпаргалка

- Cleanup возвращается из `useEffect`.
- Он выполняется перед новым setup и при unmount.
- Нужен для timers, subscriptions, sockets, observers.
- Cleanup должен зеркально отменять setup.
- Strict Mode помогает найти ошибки cleanup.
