# Как решить top N per group?

> [!summary]
> Top N per group - классическая задача: выбрать лучшие или последние N строк внутри каждой группы. Обычно ее решают через `ROW_NUMBER`, `RANK` или `DENSE_RANK`.

## Последний заказ каждого пользователя

```sql
WITH ranked_orders AS (
  SELECT
    *,
    ROW_NUMBER() OVER (
      PARTITION BY user_id
      ORDER BY created_at DESC, id DESC
    ) AS rn
  FROM orders
)
SELECT *
FROM ranked_orders
WHERE rn = 1;
```

## Топ-3 товара в каждой категории

```sql
WITH ranked_products AS (
  SELECT
    *,
    ROW_NUMBER() OVER (
      PARTITION BY category_id
      ORDER BY rating DESC, id
    ) AS rn
  FROM products
)
SELECT *
FROM ranked_products
WHERE rn <= 3;
```

## ROW_NUMBER или RANK?

Если нужно ровно 3 строки на группу, используй `ROW_NUMBER`. Если нужно включить всех, кто разделил место, используй `RANK` или `DENSE_RANK`.

## Мини-шпаргалка

- Top N per group часто решают через CTE.
- Внутри CTE добавляют `ROW_NUMBER`.
- Потом фильтруют `rn <= N`.
- Для стабильности сортировки добавляй уникальный tie-breaker.
- Это один из самых частых SQL-вопросов на собеседовании.
