## Хороший короткий ответ "что такое Nitro?"

Nitro - это server engine и full-stack server framework для TypeScript. Он дает file-based server routes, H3 handlers, middleware, route rules, cache, storage и deployment presets. В Nuxt он обслуживает `server/` директорию и production output, но может использоваться standalone.

## Мини-шпаргалка

- Объясняй Nitro через request lifecycle.
- H3 - HTTP слой Nitro.
- `event.context` - request-scoped context.
- Route rules - декларативное поведение routes.
- Cache/storage/deploy presets - сильные стороны Nitro.
- Prisma/Auth/Vitest - внешние инструменты вокруг Nitro.
