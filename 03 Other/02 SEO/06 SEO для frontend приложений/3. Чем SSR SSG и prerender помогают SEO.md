# Чем SSR, SSG и prerender помогают SEO?

> [!summary]
> SSR, SSG и prerender помогают отдавать поисковику и пользователю уже готовый HTML. Это снижает зависимость от клиентского JavaScript и улучшает предсказуемость индексации.

## Что такое SSR?

SSR, Server-Side Rendering, генерирует HTML на сервере при запросе:

```text
GET /product/123 -> сервер получает данные -> возвращает HTML страницы
```

Подходит для динамических страниц, где данные часто меняются.

## Что такое SSG?

SSG, Static Site Generation, генерирует HTML заранее во время build:

```text
npm run build -> /blog/vue-seo/index.html
```

Подходит для блогов, документации, лендингов и стабильного контента.

## Что такое prerender?

Prerender - предварительная генерация HTML для набора маршрутов SPA.

Подходит, если:

- маршрутов немного;
- данные стабильны;
- не хочется полностью переходить на SSR-фреймворк.

## Что выбрать?

| Сценарий | Подход |
|---|---|
| Блог | SSG |
| Документация | SSG |
| Каталог с частыми изменениями | SSR или ISR/SWR |
| Личный кабинет | CSR |
| Маркетинговые страницы | SSG или SSR |
| SPA с несколькими публичными страницами | prerender |

## Мини-шпаргалка

- SSR генерирует HTML на запрос.
- SSG генерирует HTML заранее.
- Prerender помогает SPA получить статический HTML.
- Для SEO-страниц полезно отдавать контент в HTML.
- Выбор режима зависит от данных, частоты обновлений и нагрузки.
