# Основные хуки и компоненты React Router

> [!summary]
> В повседневной работе с React Router чаще всего нужны `Link`, `NavLink`, `Outlet`, `Navigate`, `useNavigate`, `useParams`, `useLocation`, `useSearchParams`, `useLoaderData`, `useActionData` и `useNavigation`.

## Таблица основных API

| API | Зачем нужен |
|---|---|
| `Link` | переход без reload |
| `NavLink` | ссылка с состоянием active |
| `Outlet` | место для дочернего route |
| `Navigate` | declarative redirect |
| `useNavigate` | programmatic navigation |
| `useParams` | path params |
| `useLocation` | текущий location object |
| `useSearchParams` | query string |
| `useLoaderData` | данные loader |
| `useActionData` | результат action |
| `useNavigation` | pending navigation state |

## useNavigate

```tsx
import { useNavigate } from 'react-router'

function SaveButton() {
  const navigate = useNavigate()

  async function handleSave() {
    await save()
    navigate('/dashboard')
  }

  return <button onClick={handleSave}>Save</button>
}
```

Можно перейти назад:

```tsx
navigate(-1)
```

Для redirects внутри loaders/actions часто лучше использовать `redirect`.

## useLocation

```tsx
const location = useLocation()

console.log(location.pathname)
console.log(location.search)
console.log(location.state)
```

`location.state` подходит для временных UI-данных, но не должен быть единственным источником критичной информации.

## useSearchParams

```tsx
const [searchParams, setSearchParams] = useSearchParams()

const page = searchParams.get('page') ?? '1'

function goToNextPage() {
  setSearchParams((params) => {
    params.set('page', String(Number(page) + 1))
    return params
  })
}
```

Query params хорошо подходят для фильтров, сортировки, поиска и pagination.

## Outlet

```tsx
function DashboardLayout() {
  return (
    <>
      <DashboardSidebar />
      <main>
        <Outlet />
      </main>
    </>
  )
}
```

`Outlet` показывает дочерний route внутри layout.

## Navigate

```tsx
function ProtectedPage({ user }: { user: User | null }) {
  if (!user) {
    return <Navigate to="/login" replace />
  }

  return <Dashboard />
}
```

`replace` не добавляет текущий route в history stack.

## Что отвечать на собеседовании?

Основные hooks React Router позволяют читать URL и управлять навигацией: `useParams` для path params, `useSearchParams` для query params, `useLocation` для location object, `useNavigate` для программного перехода. `Outlet` нужен для nested routes, а `Navigate` - для declarative redirect.

## Мини-шпаргалка

- `useParams()` - `/users/:id`.
- `useSearchParams()` - `?page=2`.
- `useNavigate()` - перейти программно.
- `useLocation()` - текущий URL object.
- `Outlet` - дочерний route.
- `Navigate` - redirect компонентом.
