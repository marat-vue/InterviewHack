# Что такое Open Graph?

> [!summary]
> Open Graph - это набор meta-тегов, который управляет тем, как ссылка выглядит при отправке в соцсети и мессенджеры: заголовок, описание, картинка, URL и тип контента. В Next.js Open Graph обычно задают через поле `openGraph` в Metadata API.

## Зачем нужен Open Graph?

Когда пользователь отправляет ссылку в Telegram, Facebook, LinkedIn, Slack или другой сервис, платформа делает запрос к странице и читает meta-теги.

Без Open Graph сервис может сам выбрать:

- случайный заголовок;
- нерелевантное описание;
- первую попавшуюся картинку;
- неправильный URL.

С Open Graph ты явно говоришь:

```html
<meta property="og:title" content="Next.js для собеседований" />
<meta property="og:description" content="Краткий и понятный разбор Next.js" />
<meta property="og:image" content="https://example.com/og/next.png" />
<meta property="og:url" content="https://example.com/next" />
```

## Open Graph в Next.js

В App Router это описывается через `metadata`:

```tsx
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: 'Next.js',
  description: 'Вопросы и ответы по Next.js',
  openGraph: {
    title: 'Next.js',
    description: 'Вопросы и ответы по Next.js',
    url: 'https://example.com/next',
    siteName: 'Frontend Notes',
    images: [
      {
        url: 'https://example.com/og/next.png',
        width: 1200,
        height: 630,
        alt: 'Next.js notes preview',
      },
    ],
    locale: 'ru_RU',
    type: 'article',
  },
}
```

Next.js сам сгенерирует нужные `<meta property="og:*">`.

## Самые важные поля

| Поле | Зачем нужно |
| --- | --- |
| `openGraph.title` | Заголовок превью |
| `openGraph.description` | Описание под заголовком |
| `openGraph.images` | Картинка превью |
| `openGraph.url` | Канонический URL страницы |
| `openGraph.siteName` | Название сайта |
| `openGraph.type` | Тип контента: `website`, `article`, `profile` |
| `openGraph.locale` | Язык и регион |

## Картинка Open Graph

Самый популярный размер OG-картинки:

```text
1200 x 630
```

Важно:

- картинка должна быть доступна поисковым и социальным ботам;
- лучше использовать абсолютный URL;
- текст на картинке должен быть крупным;
- нельзя полагаться только на мелкие детали;
- для разных страниц лучше делать уникальные изображения.

## File-based Open Graph images

В App Router можно использовать файловую конвенцию:

```text
app/
  blog/
    [slug]/
      page.tsx
      opengraph-image.tsx
```

Например:

```tsx
// app/blog/[slug]/opengraph-image.tsx
import { ImageResponse } from 'next/og'

export const size = {
  width: 1200,
  height: 630,
}

export const contentType = 'image/png'

export default function Image({ params }: { params: { slug: string } }) {
  return new ImageResponse(
    (
      <div
        style={{
          fontSize: 72,
          background: 'white',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
        }}
      >
        {params.slug}
      </div>
    ),
  )
}
```

Это позволяет генерировать превью для каждой статьи или товара.

## Open Graph и SEO

Open Graph не заменяет обычные `title` и `description`. Его главная роль - не классическое ранжирование, а качество карточки при шеринге.

Но косвенно OG важен:

- повышает CTR из соцсетей;
- делает бренд узнаваемее;
- уменьшает риск неправильного превью;
- помогает пользователю понять, куда ведет ссылка.

## Что отвечать на собеседовании?

Open Graph - это протокол meta-тегов для управления превью ссылки в соцсетях и мессенджерах. В Next.js его задают через `metadata.openGraph` или файловые conventions вроде `opengraph-image`. Важно указывать title, description, image, url и type, особенно для статей, товаров и лендингов.

## Частые ошибки

- Не задавать `og:image`.
- Использовать относительный URL там, где сервис ожидает абсолютный.
- Делать одну OG-картинку для всех страниц.
- Забывать размеры изображения.
- Путать Open Graph с обычным SEO title.
- Не проверять превью после деплоя.

## Мини-шпаргалка

- OG управляет превью ссылки.
- Главные поля: `title`, `description`, `image`, `url`, `type`.
- В Next.js используется `metadata.openGraph`.
- Частый размер картинки - `1200x630`.
- Для динамических страниц можно использовать `generateMetadata`.
- Для генерации картинок есть `opengraph-image.tsx`.
