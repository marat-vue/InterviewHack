# Оператор label

> [!summary] Коротко
> Label - это метка для цикла или блока кода. Ее можно использовать с `break` и `continue`, чтобы управлять внешним циклом из вложенного.

## Вопрос

Что делает оператор `label`?

## Синтаксис

```javascript
labelName: statement;
```

Чаще всего метки ставят перед циклом.

```javascript
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) {
      break outer;
    }
  }
}
```

`break outer` завершит внешний цикл, а не только внутренний.

## Пример без label

```javascript
for (const row of matrix) {
  for (const cell of row) {
    if (cell === target) {
      break;
    }
  }
}
```

Здесь `break` выйдет только из внутреннего цикла.

## Пример с label

```javascript
let found = false;

search: for (const row of matrix) {
  for (const cell of row) {
    if (cell === target) {
      found = true;
      break search;
    }
  }
}
```

Так можно сразу остановить оба цикла.

## `continue` с label

```javascript
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (j === 1) {
      continue outer;
    }

    console.log(i, j);
  }
}
```

`continue outer` переходит к следующей итерации внешнего цикла.

## Практическое замечание

Labels используются редко. Часто код можно сделать понятнее через функцию и `return`.

```javascript
function includesMatrix(matrix, target) {
  for (const row of matrix) {
    for (const cell of row) {
      if (cell === target) return true;
    }
  }

  return false;
}
```

## Мини-шпаргалка

| Конструкция | Что делает |
| --- | --- |
| `label: for (...) {}` | помечает цикл |
| `break label` | выходит из помеченной конструкции |
| `continue label` | переходит к следующей итерации помеченного цикла |
| обычный `break` | выходит только из ближайшего цикла/switch |
