# Что такое однонаправленный поток данных

> [!summary] Коротко
> Однонаправленный поток данных означает, что данные движутся предсказуемо: состояние хранится в одном месте, передается вниз в UI, а изменения происходят через явные события или actions.

## Вопрос

Что такое однонаправленный поток данных в контексте state management?

## Базовая схема

```text
state -> view -> event/action -> state
```

Компонент читает состояние, пользователь выполняет действие, action меняет состояние, UI обновляется.

## В компонентах Vue

```vue
<Child :count="count" @increment="count++" />
```

Родитель передает `count` вниз через props, ребенок сообщает о событии наверх через `emit`.

## В store

```typescript
const cart = useCartStore();

cart.addItem(product);
```

Компоненты не должны менять данные хаотично в разных местах. Лучше иметь понятные actions, через которые происходят изменения.

## Почему это важно

Предсказуемый поток данных упрощает отладку: легче понять, кто владеет состоянием и где оно меняется.

## Мини-шпаргалка

- State является источником правды.
- View отображает state.
- Events/actions сообщают о намерении изменить state.
- Props вниз, events вверх.
- Store actions делают изменения заметными и понятными.
