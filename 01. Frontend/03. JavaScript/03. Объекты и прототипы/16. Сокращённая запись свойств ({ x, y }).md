# Сокращенная запись свойств

> [!NOTE]
> Сокращенная запись `{ x, y }` используется в объектном литерале, когда имя свойства совпадает с именем переменной.

## Вопрос

Что такое сокращенная запись свойств (`{ x, y }`)?

## Базовый пример

```javascript
const x = 10;
const y = 20;

const point = { x, y };

console.log(point); // { x: 10, y: 20 }
```

Это эквивалентно:

```javascript
const point = {
  x: x,
  y: y,
};
```

## Зачем нужно

Код становится короче, когда объект собирается из существующих переменных.

```javascript
function createUser(name, age) {
  return {
    name,
    age,
    active: true,
  };
}
```

## С методами

В объектном литерале есть сокращенный синтаксис методов.

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};
```

Это короче, чем:

```javascript
const user = {
  name: "Anna",
  sayHi: function () {
    return `Hi, ${this.name}`;
  },
};
```

## С вычисляемыми свойствами

```javascript
const key = "role";
const value = "admin";

const user = {
  [key]: value,
};
```

Если имя свойства не совпадает с переменной, shorthand не подходит.

## Мини-шпаргалка

```javascript
const obj = { x, y };
// то же, что { x: x, y: y }

const obj = {
  method() {},
};

const obj = {
  [key]: value,
};
```
