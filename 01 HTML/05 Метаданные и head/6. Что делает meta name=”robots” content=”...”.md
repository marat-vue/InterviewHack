# Что делает meta name="robots" content="..."

> [!summary]
> `<meta name="robots">` задает инструкции для поисковых роботов: можно ли индексировать страницу, переходить по ссылкам и показывать определенные фрагменты в выдаче.

## Главное

```html
<meta name="robots" content="noindex, nofollow">
```

Этот тег не управляет браузером пользователя. Он предназначен для поисковых роботов, которые уважают такие инструкции.

## Частые значения

| Значение | Смысл |
| --- | --- |
| `index` | Страницу можно индексировать |
| `noindex` | Страницу не нужно показывать в поиске |
| `follow` | Можно переходить по ссылкам на странице |
| `nofollow` | Не переходить по ссылкам или не передавать им сигнал |
| `noarchive` | Не показывать сохраненную копию |
| `nosnippet` | Не показывать текстовый сниппет |

## Примеры

Разрешить индексацию и переход по ссылкам:

```html
<meta name="robots" content="index, follow">
```

Запретить индексацию страницы:

```html
<meta name="robots" content="noindex">
```

Запретить индексацию и переход по ссылкам:

```html
<meta name="robots" content="noindex, nofollow">
```

## Когда использовать noindex

- Страницы админки.
- Технические страницы.
- Дубли контента.
- Черновики.
- Страницы поиска внутри сайта.
- Временные landing pages.

## Важный нюанс

Если страница заблокирована в `robots.txt`, робот может не зайти на нее и не увидеть meta robots. Для запрета индексации часто важно, чтобы робот мог прочитать страницу и увидеть `noindex`.

## Мини-шпаргалка

- `meta robots` живет в `head`.
- `noindex` запрещает индексацию.
- `nofollow` ограничивает переход по ссылкам.
- Тег не защищает приватные данные.
- Для приватных страниц нужна авторизация, а не только `noindex`.
- `robots.txt` и `meta robots` решают разные задачи.
