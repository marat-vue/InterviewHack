# Как изучать Motion

> [!summary]
> Motion for React - библиотека анимаций для React. Изучать ее нужно через `motion` components, props `initial`, `animate`, `exit`, transitions, variants, gestures, `AnimatePresence`, layout animations и scroll animations.

## Что такое Motion?

Motion - современная библиотека анимаций для React и веба. Раньше многие знали ее как Framer Motion; сейчас официальная документация живет на motion.dev.

Базовый пример:

```tsx
import { motion } from 'motion/react'

function Card() {
  return (
    <motion.div
      initial={{ opacity: 0, y: 12 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.25 }}
    >
      Content
    </motion.div>
  )
}
```

## Что нужно знать по порядку?

1. Установка.
2. `motion.div` и другие motion components.
3. `initial`, `animate`, `transition`.
4. Gestures: `whileHover`, `whileTap`, drag.
5. Variants.
6. `AnimatePresence` для exit animations.
7. Layout animations через `layout`.
8. Shared layout через `layoutId`.
9. Accessibility и reduced motion.
10. Когда анимация помогает UX, а когда мешает.

## Где Motion особенно полезен?

- модалки;
- dropdown;
- tabs;
- cards;
- onboarding;
- page transitions;
- drag interactions;
- animated lists;
- layout transitions;
- micro-interactions.

## Что отвечать на собеседовании?

Motion позволяет декларативно описывать анимации React-компонентов через `motion` components. Основные инструменты - `initial`, `animate`, `exit`, `transition`, variants, gestures, `AnimatePresence` и layout animations. Хорошая анимация должна улучшать понимание UI, а не просто украшать экран.

## Мини-шпаргалка

- `motion.div` - анимированный div.
- `initial` - стартовое состояние.
- `animate` - целевое состояние.
- `exit` - состояние при удалении.
- `transition` - длительность/тип движения.
- `AnimatePresence` - exit animations.
