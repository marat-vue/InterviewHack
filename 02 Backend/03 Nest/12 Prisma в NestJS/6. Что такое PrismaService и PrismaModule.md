# Что такое PrismaService и PrismaModule?

> [!summary]
> `PrismaService` - Nest provider, который инкапсулирует `PrismaClient`. `PrismaModule` регистрирует и экспортирует этот provider, чтобы другие modules могли безопасно использовать Prisma через DI.

## PrismaService

```ts
@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
  async onModuleInit() {
    await this.$connect();
  }
}
```

## PrismaModule

```ts
@Module({
  providers: [PrismaService],
  exports: [PrismaService],
})
export class PrismaModule {}
```

## Использование в feature module

```ts
@Module({
  imports: [PrismaModule],
  providers: [UsersService],
  controllers: [UsersController],
})
export class UsersModule {}
```

## Почему не создавать PrismaClient в каждом service?

```ts
// Плохо
const prisma = new PrismaClient();
```

Так можно создать много подключений и потерять контроль над lifecycle. В NestJS клиент должен быть provider.

## Мини-шпаргалка

- `PrismaService` оборачивает `PrismaClient`.
- `PrismaModule` экспортирует `PrismaService`.
- Feature modules импортируют `PrismaModule`.
- Не создавай `new PrismaClient()` в каждом service.
- При shutdown нужно закрывать connection.
