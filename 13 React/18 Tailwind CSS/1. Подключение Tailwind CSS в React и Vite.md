# Подключение Tailwind CSS в React и Vite

> [!summary]
> В современных Vite-проектах Tailwind CSS подключают через пакет `tailwindcss` и официальный Vite plugin `@tailwindcss/vite`, затем импортируют Tailwind в главный CSS-файл.

## Установка

```bash
npm install tailwindcss @tailwindcss/vite
```

## vite.config.ts

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

## CSS entry

```css
@import "tailwindcss";
```

Обычно это `src/index.css` или `src/main.css`.

## Подключение CSS в React

```tsx
import './index.css'

createRoot(document.getElementById('root')!).render(<App />)
```

## Первый компонент

```tsx
function App() {
  return (
    <main className="min-h-screen bg-zinc-950 p-8 text-zinc-50">
      <h1 className="text-3xl font-semibold">Hello Tailwind</h1>
      <p className="mt-2 text-zinc-300">
        Utility classes are compiled into production CSS.
      </p>
    </main>
  )
}
```

## Как Tailwind попадает в production?

Tailwind анализирует файлы проекта и генерирует CSS только для реально использованных классов. Поэтому production CSS обычно меньше, чем полный набор всех utilities.

## Что отвечать на собеседовании?

В Vite Tailwind подключается как plugin в `vite.config`, а в главный CSS добавляется `@import "tailwindcss"`. После этого utility-классы можно использовать в `className` React-компонентов.

## Мини-шпаргалка

- Установка: `tailwindcss @tailwindcss/vite`.
- Vite plugin: `tailwindcss()`.
- CSS: `@import "tailwindcss";`.
- В React: обычный `className`.
- Production CSS генерируется из используемых классов.
