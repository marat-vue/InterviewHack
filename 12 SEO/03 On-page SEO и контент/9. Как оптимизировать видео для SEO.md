# Как оптимизировать видео для SEO?

> [!summary]
> Video SEO помогает поисковикам обнаруживать и понимать видео на странице. Для этого нужны доступный HTML, понятные метаданные, превью, структурированные данные и страница, где видео является важной частью контента.

## Когда видео полезно для SEO?

Видео полезно, если оно реально помогает intent:

- показывает процесс;
- демонстрирует продукт;
- объясняет сложную тему;
- дает обзор;
- дополняет инструкцию.

Видео "для галочки" может только замедлить страницу.

## Что нужно добавить?

- Описательный заголовок.
- Текст рядом с видео.
- Превью.
- Транскрипт или краткое содержание.
- Structured data `VideoObject`.
- Доступный плеер.
- Быструю загрузку страницы.

## Пример разметки

```html
<video controls poster="/video/seo-audit-poster.jpg">
  <source src="/video/seo-audit.webm" type="video/webm">
  <source src="/video/seo-audit.mp4" type="video/mp4">
</video>
```

## Почему нужен текстовый контекст?

Поисковик лучше понимает страницу, если рядом с видео есть:

- краткое описание;
- основные тезисы;
- ответы на вопросы;
- ссылки на связанные материалы;
- дата и автор, если это важно.

## Мини-шпаргалка

- Видео должно помогать задаче пользователя.
- Добавляй превью, описание и транскрипт.
- Используй structured data `VideoObject`, если видео важно.
- Следи, чтобы видео не ломало LCP.
- Не прячь весь полезный контент только внутри видео.
