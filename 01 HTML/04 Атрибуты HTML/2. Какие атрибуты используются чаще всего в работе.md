# Какие атрибуты используются чаще всего в работе

> [!summary]
> В повседневной HTML-разработке чаще всего используют атрибуты для идентификации, стилизации, ссылок, медиа, форм, доступности и пользовательских данных.

## Частые атрибуты

| Атрибут | Где встречается | Зачем нужен |
| --- | --- | --- |
| `id` | почти везде | Уникальный идентификатор |
| `class` | почти везде | CSS-классы и состояние |
| `href` | `a`, `link` | Адрес ссылки или ресурса |
| `src` | `img`, `script`, `iframe` | Путь к внешнему ресурсу |
| `alt` | `img` | Текстовое описание изображения |
| `type` | `input`, `button`, `script` | Тип элемента или поведения |
| `name` | формы | Имя поля при отправке |
| `value` | формы | Значение поля |
| `disabled` | формы, кнопки | Отключение элемента |
| `aria-*` | интерактивные элементы | Дополнительная информация для доступности |
| `data-*` | почти везде | Пользовательские данные |

## Пример формы

```html
<form action="/subscribe" method="post">
  <label for="email">Email</label>
  <input
    id="email"
    name="email"
    type="email"
    autocomplete="email"
    required
  >

  <button type="submit">Подписаться</button>
</form>
```

Здесь каждый атрибут влияет на поведение формы.

## Пример изображения

```html
<img
  src="/team.jpg"
  alt="Команда проекта за рабочим столом"
  width="800"
  height="450"
>
```

`alt` важен для доступности, а `width` и `height` помогают браузеру заранее выделить место под изображение.

## Пример data-атрибута

```html
<button data-product-id="42" type="button">
  Купить
</button>
```

```js
const productId = button.dataset.productId;
```

## Мини-шпаргалка

- `id` должен быть уникальным.
- `class` используют для CSS и JS-хуков.
- `href` - адрес перехода.
- `src` - источник ресурса.
- `alt` нужен значимым изображениям.
- `aria-*` не заменяет правильный HTML, а дополняет его.
- `data-*` хранит пользовательские данные.
