# Как relative влияет на поток документа

> [!summary]
> `position: relative` не убирает элемент из потока документа. Элемент сохраняет свое исходное место, даже если визуально смещается через `top`, `right`, `bottom` или `left`.

## Главное

```css
.box {
  position: relative;
  top: 20px;
  left: 20px;
}
```

Элемент визуально сдвинется вниз и вправо, но соседние элементы будут вести себя так, будто он остался на прежнем месте.

## Пример

```html
<div class="item">Первый</div>
<div class="item item--shifted">Второй</div>
<div class="item">Третий</div>
```

```css
.item--shifted {
  position: relative;
  top: 16px;
}
```

Третий элемент не поднимется на место второго. В потоке место второго элемента сохранится.

## Relative как anchor

Чаще всего `relative` ставят на родителя, чтобы абсолютно позиционированный ребенок считался от него.

```css
.card {
  position: relative;
}

.card__badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

Сам `.card` остается в обычном потоке.

## Когда использовать

- Для небольшого визуального смещения.
- Для создания containing block для `absolute`.
- Для управления `z-index`.
- Для декоративных элементов внутри компонента.

## Мини-шпаргалка

- `relative` сохраняет место элемента в потоке.
- Смещения двигают элемент визуально.
- Соседи не пересчитывают layout по новому визуальному положению.
- Частый паттерн: `relative` на родителе, `absolute` на бейдже.
- `relative` позволяет использовать `z-index`.
