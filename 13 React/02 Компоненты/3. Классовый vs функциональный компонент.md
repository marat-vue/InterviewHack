# Чем классовый компонент отличается от функционального?

> [!summary]
> Функциональный компонент - современный основной способ писать React UI. Классовый компонент использует `class`, `this`, `state`, lifecycle methods и метод `render`. После появления хуков функциональные компоненты покрывают почти все обычные сценарии.

## Функциональный компонент

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
```

Особенности:

- проще синтаксис;
- state через хуки;
- эффекты через `useEffect`;
- логика переиспользуется через custom hooks;
- меньше работы с `this`.

## Классовый компонент

```jsx
import { Component } from 'react'

class Counter extends Component {
  state = {
    count: 0,
  }

  componentDidMount() {
    console.log('mounted')
  }

  render() {
    return (
      <button onClick={() => this.setState({ count: this.state.count + 1 })}>
        {this.state.count}
      </button>
    )
  }
}
```

Особенности:

- состояние хранится в `this.state`;
- обновление через `this.setState`;
- lifecycle methods: `componentDidMount`, `componentDidUpdate`, `componentWillUnmount`;
- нужен `render`;
- часто встречается в legacy-проектах.

## Сравнение

| Критерий | Функциональный | Классовый |
|---|---|---|
| State | `useState`, `useReducer` | `this.state` |
| Side effects | `useEffect` | lifecycle methods |
| Переиспользование логики | custom hooks | HOC/render props |
| `this` | не нужен | нужен |
| Новый код | предпочтительно | редко |

## Что важно на собеседовании?

Нужно уметь объяснить:

```text
Классы не исчезли из React, но современный стиль - функциональные компоненты с хуками. Хуки дали способ использовать state, effects и другую React-логику без классов. Legacy-код с классами нужно уметь читать, а Error Boundary часто все еще реализуют классовым компонентом.
```

## Мини-шпаргалка

- Новый React-код обычно пишут функциональными компонентами.
- Классовые компоненты используют `this`, `state` и lifecycle methods.
- Хуки заменили большинство сценариев классов.
- Custom hooks удобнее для переиспользования логики.
- Классы полезно знать для legacy и Error Boundary.
