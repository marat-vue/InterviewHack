# Что такое "main axis" (главная ось) и "cross axis" (перекрестная ось)

> [!summary]
> В Flexbox **main axis** - это основная ось раскладки flex items, а **cross axis** - перпендикулярная ей ось. Их направление зависит от `flex-direction`.

## Главное

По умолчанию:

```css
.row {
  display: flex;
  flex-direction: row;
}
```

```text
main axis:  left -> right
cross axis: top -> bottom
```

## flex-direction row

```css
.container {
  display: flex;
  flex-direction: row;
}
```

Элементы идут в строку. `justify-content` работает по горизонтали, `align-items` - по вертикали.

## flex-direction column

```css
.container {
  display: flex;
  flex-direction: column;
}
```

Теперь main axis вертикальная. `justify-content` управляет вертикальным распределением, а `align-items` - горизонтальным.

## Почему это важно

Многие путают `justify-content` с "горизонтальным выравниванием". На самом деле оно выравнивает по main axis.

```css
.stack {
  display: flex;
  flex-direction: column;
  justify-content: center;
}
```

Здесь `justify-content: center` центрирует по вертикали.

## Мини-шпаргалка

- Main axis - главная ось Flexbox.
- Cross axis - поперечная ось.
- `flex-direction` определяет направление main axis.
- `justify-content` работает по main axis.
- `align-items` работает по cross axis.
- При `column` привычная интуиция "justify = горизонтально" ломается.
