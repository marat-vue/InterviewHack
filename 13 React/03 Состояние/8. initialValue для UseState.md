# Что такое initialValue для useState?

> [!summary]
> `initialValue` в `useState` - это начальное значение состояния, которое React использует при первом создании компонента. При последующих render это значение не применяется заново, поэтому оно не должно восприниматься как "значение по умолчанию на каждый render".

## Базовый пример

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

`0` - начальное значение state. Оно используется только при первом монтировании конкретного экземпляра `Counter`.

## Можно ли передать объект или массив?

Да:

```jsx
const [user, setUser] = useState({
  name: '',
  email: '',
})

const [items, setItems] = useState([])
```

Но объекты и массивы в state нужно обновлять иммутабельно: создавать новое значение, а не мутировать старое.

## Lazy initialization

Если начальное значение вычисляется дорого, можно передать функцию:

```jsx
const [todos, setTodos] = useState(() => {
  return loadTodosFromLocalStorage()
})
```

Функция будет вызвана при инициализации state, а не на каждом render.

## Частая ошибка

```jsx
function Profile({ userId }) {
  const [form, setForm] = useState(createForm(userId))

  return <ProfileForm form={form} />
}
```

Если `userId` изменится, `createForm(userId)` не переинициализирует state автоматически. Начальное значение не синхронизируется с prop после первого render.

Если нужно сбросить state при смене пользователя, можно использовать `key`:

```jsx
<ProfileForm key={userId} userId={userId} />
```

## initialValue vs defaultValue

| Термин | Где используется |
|---|---|
| `initialValue` | начальное значение React state |
| `defaultValue` | начальное значение uncontrolled input |

Пример uncontrolled input:

```jsx
<input defaultValue="Анна" />
```

## Мини-шпаргалка

- `initialValue` используется при первом создании state.
- При повторных render он не применяется заново.
- Для дорогого начального вычисления передают функцию.
- Изменение props не переинициализирует state автоматически.
- Для сброса state иногда используют изменение `key`.
