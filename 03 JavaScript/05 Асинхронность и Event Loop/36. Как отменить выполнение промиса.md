# Как отменить выполнение промиса

> [!summary] Коротко
> Сам `Promise` отменить нельзя. Можно отменить операцию, которую он представляет, если эта операция поддерживает отмену.

## Вопрос

Можно ли отменить промис в JavaScript?

## Определение

Промис - это контейнер для будущего результата. У него нет встроенного метода `cancel()`. Если асинхронная операция уже запущена, промис сам по себе не умеет ее остановить.

Отменять нужно источник работы: запрос, таймер, stream, worker или другую операцию.

## Отмена fetch через AbortController

```javascript
const controller = new AbortController();

fetch('/api/data', {
  signal: controller.signal,
}).catch((error) => {
  if (error.name === 'AbortError') {
    console.log('Request was aborted');
  }
});

controller.abort();
```

`AbortController` сообщает операции, что ее нужно прервать.

## Отмена таймера

```javascript
const id = setTimeout(() => {
  console.log('done');
}, 1000);

clearTimeout(id);
```

Здесь отменяется не промис, а таймер.

## Promise.race не отменяет работу

```javascript
await Promise.race([
  fetch('/api/data'),
  timeout(1000),
]);
```

Если победил таймаут, сам `fetch` не обязательно остановится. Для реальной отмены нужен `AbortController`.

## Мини-шпаргалка

```javascript
// Нельзя:
promise.cancel();

// Можно, если операция поддерживает signal:
controller.abort();
```
