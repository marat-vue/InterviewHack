# Как использовать headings и semantic HTML?

> [!summary]
> Headings и semantic HTML помогают структурировать страницу для людей, скринридеров и поисковых систем. Это не магия ранжирования, а способ сделать смысл страницы яснее.

## Зачем нужны headings?

Заголовки создают структуру:

```html
<h1>SEO для Vue-приложений</h1>

<h2>Почему SPA бывают проблемными для SEO?</h2>
<h2>Как SSR помогает индексации?</h2>
<h2>Как настроить meta tags?</h2>
```

Пользователь может быстро просканировать страницу, а поисковик лучше понимает темы блоков.

## Сколько H1 должно быть?

На практике чаще используют один понятный `h1` на страницу:

```html
<h1>Core Web Vitals: LCP, INP и CLS</h1>
```

HTML допускает разные структуры, но для SEO и поддержки один главный заголовок обычно проще и предсказуемее.

## Что такое semantic HTML?

Semantic HTML - это использование тегов по смыслу:

```html
<main>
  <article>
    <h1>Как работает sitemap.xml</h1>
    <p>...</p>
  </article>
</main>

<nav aria-label="Основная навигация">
  ...
</nav>
```

Вместо бесконечных `div` лучше использовать:

- `header`;
- `nav`;
- `main`;
- `article`;
- `section`;
- `aside`;
- `footer`;
- `button`;
- `a`;
- `img`.

## Частые ошибки

- Использовать `h1` только ради размера шрифта.
- Пропускать уровни заголовков хаотично.
- Делать кнопку через `div`.
- Делать ссылку через `span` и JavaScript.
- Прятать важный текст в изображении.
- Загружать основной контент только после клика.

## Мини-шпаргалка

- Заголовки должны описывать структуру страницы.
- `h1` - главный смысл страницы.
- Semantic HTML улучшает доступность и понимание контента.
- CSS отвечает за внешний вид, HTML - за смысл.
- Хорошая семантика полезна и SEO, и accessibility.
