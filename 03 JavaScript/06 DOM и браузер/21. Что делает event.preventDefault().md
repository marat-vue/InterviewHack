# Что делает event.preventDefault()

> [!summary] Коротко
> `event.preventDefault()` отменяет стандартное действие браузера для события.

## Вопрос

Когда использовать `preventDefault()`?

## Определение

У многих событий есть действие по умолчанию. Например, клик по ссылке открывает URL, отправка формы перезагружает страницу, нажатие клавиши вводит символ.

`event.preventDefault()` говорит браузеру не выполнять это стандартное действие.

## Пример со ссылкой

```javascript
const link = document.querySelector('a');

link.addEventListener('click', (event) => {
  event.preventDefault();

  console.log('Navigation canceled');
});
```

Ссылка не перейдет по `href`.

## Пример с формой

```javascript
form.addEventListener('submit', (event) => {
  event.preventDefault();

  sendFormData();
});
```

Форма не отправится стандартным способом, и страница не перезагрузится.

## Проверка

```javascript
event.preventDefault();

console.log(event.defaultPrevented); // true
```

## Важный нюанс

Если обработчик добавлен с `{ passive: true }`, внутри него нельзя отменить стандартное действие.

```javascript
window.addEventListener('scroll', handler, { passive: true });
```

## Мини-шпаргалка

```javascript
event.preventDefault(); // отменить действие браузера
event.stopPropagation(); // остановить распространение
```
