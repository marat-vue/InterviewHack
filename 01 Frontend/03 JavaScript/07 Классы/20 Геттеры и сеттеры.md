# Геттеры и сеттеры

> [!NOTE]
> Геттеры и сеттеры позволяют работать с методами как со свойствами: читать через `obj.value` и записывать через `obj.value = ...`.

## Вопрос

Что такое `get` и `set` в классе?

## Определение

Геттер - метод, который вызывается при чтении свойства. Сеттер - метод, который вызывается при записи свойства.

Они позволяют добавить вычисление, проверку или нормализацию данных, сохранив удобный синтаксис свойства.

## Пример

```javascript
class User {
  #name = '';

  get name() {
    return this.#name;
  }

  set name(value) {
    this.#name = value.trim();
  }
}

const user = new User();

user.name = ' Ann ';

console.log(user.name); // 'Ann'
```

Хотя выглядит как работа со свойством, внутри вызываются методы `get name()` и `set name()`.

## Только getter

```javascript
class Circle {
  constructor(radius) {
    this.radius = radius;
  }

  get area() {
    return Math.PI * this.radius ** 2;
  }
}

const circle = new Circle(10);

console.log(circle.area);
```

`area` вычисляется при чтении.

## Когда использовать

- валидация перед записью;
- вычисляемые свойства;
- инкапсуляция приватных полей;
- сохранение удобного API объекта.

## Мини-шпаргалка

```javascript
class A {
  get value() {
    return this._value;
  }

  set value(nextValue) {
    this._value = nextValue;
  }
}
```
