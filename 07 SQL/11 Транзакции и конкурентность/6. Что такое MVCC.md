# Что такое MVCC?

> [!summary]
> MVCC, Multi-Version Concurrency Control, - подход, при котором база хранит несколько версий строк, чтобы читатели и писатели меньше блокировали друг друга. Читатели видят согласованный snapshot данных.

## Идея

Без MVCC чтение и запись чаще блокировали бы друг друга. MVCC позволяет транзакции читать версию данных, которая была актуальна для ее snapshot.

```txt
row v1 -> видна старой транзакции
row v2 -> создана новой транзакцией
```

## Что это дает?

- чтение не всегда блокирует запись;
- запись не всегда блокирует чтение;
- транзакции видят согласованную картину;
- повышается конкурентность.

## Цена

Старые версии строк нужно очищать. В PostgreSQL это связано с vacuum. В разных СУБД механика отличается.

## На собеседовании

Хороший ответ: MVCC позволяет транзакциям работать со snapshot-ами данных, уменьшая блокировки между чтением и записью, но требует управления версиями и очистки старых данных.

## Мини-шпаргалка

- MVCC хранит версии строк.
- Транзакция читает snapshot.
- Чтение и запись меньше блокируют друг друга.
- Старые версии нужно очищать.
- MVCC влияет на понимание isolation levels.
