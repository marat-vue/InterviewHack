# Иммутабельность в функциях

> [!summary] Коротко
> Иммутабельность в функциях означает: не изменять входные данные, а возвращать новое значение. Это делает функции предсказуемее и уменьшает side effects.

## Вопрос

Что такое иммутабельность в функциях?

## Мутация аргумента

```javascript
function addItem(items, item) {
  items.push(item);
  return items;
}

const numbers = [1, 2];
const result = addItem(numbers, 3);

console.log(numbers); // [1, 2, 3]
```

Функция изменила исходный массив.

## Иммутабельный вариант

```javascript
function addItem(items, item) {
  return [...items, item];
}

const numbers = [1, 2];
const result = addItem(numbers, 3);

console.log(numbers); // [1, 2]
console.log(result);  // [1, 2, 3]
```

Исходные данные остались прежними.

## Объекты

Мутация:

```javascript
function renameUser(user, name) {
  user.name = name;
  return user;
}
```

Иммутабельно:

```javascript
function renameUser(user, name) {
  return {
    ...user,
    name,
  };
}
```

## Вложенные объекты

Spread делает поверхностную копию.

```javascript
function updateCity(user, city) {
  return {
    ...user,
    address: {
      ...user.address,
      city,
    },
  };
}
```

Нужно копировать каждый изменяемый уровень.

## Почему это важно

Иммутабельность помогает:

- избегать неожиданных изменений;
- проще сравнивать старое и новое состояние;
- легче тестировать функции;
- удобнее работать с UI-состоянием;
- снижать связанность кода.

## Когда мутация допустима

Локальная мутация внутри функции может быть нормальной, если она не меняет входные данные.

```javascript
function getSortedCopy(items) {
  const copy = [...items];
  copy.sort();
  return copy;
}
```

## Мини-шпаргалка

| Операция | Мутирует | Иммутабельная альтернатива |
| --- | --- | --- |
| `arr.push(x)` | да | `[...arr, x]` |
| `arr.sort()` | да | `[...arr].sort()` или `toSorted()` |
| `obj.key = value` | да | `{ ...obj, key: value }` |
| `arr.splice()` | да | `toSpliced()` или копия |
