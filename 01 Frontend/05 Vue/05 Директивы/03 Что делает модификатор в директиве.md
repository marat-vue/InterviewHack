# Что делает модификатор в директиве?

> [!NOTE]
> Модификатор уточняет поведение директивы. Он пишется после точки: `@submit.prevent`, `v-model.trim`, `@click.stop`.

## Вопрос

Что делает модификатор в директиве?

## Базовая идея

Модификатор позволяет добавить частое поведение без ручного кода в обработчике.

```vue
<form @submit.prevent="submit">
  <button type="submit">Отправить</button>
</form>
```

`.prevent` вызывает `event.preventDefault()` автоматически.

## Модификаторы событий

```vue
<button @click.stop="open">Открыть</button>
<button @click.once="send">Отправить один раз</button>
<div @scroll.passive="onScroll" />
```

Они управляют поведением DOM-событий.

## Модификаторы v-model

```vue
<input v-model.trim="name" />
<input v-model.number="age" />
<input v-model.lazy="email" />
```

`.trim` убирает пробелы, `.number` приводит к числу, `.lazy` обновляет значение после `change`, а не после каждого `input`.

## Модификаторы клавиш

```vue
<input @keyup.enter="submit" />
<input @keyup.esc="close" />
```

Обработчик вызовется только для указанной клавиши.

## Мини-шпаргалка

- Модификатор пишется через точку.
- Он уточняет поведение директивы.
- Частые модификаторы: `.prevent`, `.stop`, `.once`, `.trim`, `.number`, `.lazy`.
- Модификаторы делают шаблон выразительнее и уменьшают ручной код.
