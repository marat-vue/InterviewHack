# Наличие свойства в объекте

> [!summary] Коротко
> Проверить наличие свойства можно через `in`, `Object.hasOwn()` или сравнение с `undefined`. Самый точный современный способ для собственных свойств - `Object.hasOwn(obj, key)`.

## Вопрос

Как определить наличие свойства в объекте?

## Оператор `in`

`in` проверяет наличие свойства в объекте или его прототипе.

```javascript
const user = { name: "Anna" };

"name" in user;     // true
"age" in user;      // false
"toString" in user; // true
```

`toString` найден в прототипе, поэтому результат `true`.

## `Object.hasOwn`

`Object.hasOwn(obj, key)` проверяет только собственные свойства объекта.

```javascript
const user = { name: "Anna" };

Object.hasOwn(user, "name");     // true
Object.hasOwn(user, "toString"); // false
```

Это хороший вариант по умолчанию, если вам не нужны свойства прототипа.

## `hasOwnProperty`

Старый способ:

```javascript
user.hasOwnProperty("name");
```

Но он может быть небезопасен, если объект переопределил `hasOwnProperty` или создан без прототипа.

Более надежный старый вариант:

```javascript
Object.prototype.hasOwnProperty.call(user, "name");
```

В современном коде проще:

```javascript
Object.hasOwn(user, "name");
```

## Проверка через `undefined`

```javascript
const user = { name: undefined };

user.name !== undefined; // false
"name" in user;          // true
```

Такой способ не подходит, если свойство может существовать со значением `undefined`.

## С optional chaining

Optional chaining нужен не для проверки ключа, а для безопасного чтения.

```javascript
const city = user.address?.city;
```

Он не отвечает на вопрос "есть ли свойство", а просто не дает коду упасть.

## Мини-шпаргалка

| Способ | Что проверяет |
| --- | --- |
| `"key" in obj` | собственные и унаследованные свойства |
| `Object.hasOwn(obj, "key")` | только собственные свойства |
| `obj.key !== undefined` | значение не `undefined` |
| `obj?.key` | безопасное чтение |
