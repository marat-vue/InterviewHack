# Как установить и настроить Jest?

> [!summary]
> Jest устанавливают как dev dependency, добавляют script `jest` и при необходимости создают `jest.config`. Для TypeScript используют Babel или `ts-jest`, а для DOM-тестов настраивают `testEnvironment: 'jsdom'`.

## Установка

```bash
npm install --save-dev jest
```

В `package.json`:

```json
{
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:coverage": "jest --coverage"
  }
}
```

## Создание конфига

```bash
npm init jest@latest
```

Пример `jest.config.ts`:

```ts
import type { Config } from 'jest';

const config: Config = {
  testEnvironment: 'node',
  collectCoverageFrom: ['src/**/*.{ts,js}'],
};

export default config;
```

## TypeScript

Варианты:

- Babel - транспилирует TypeScript, но не делает type checking;
- `ts-jest` - интеграция Jest с TypeScript compiler;
- отдельный `tsc --noEmit` в CI для проверки типов.

Для типов Jest:

```bash
npm install --save-dev @types/jest
```

или импортируй API из `@jest/globals`:

```ts
import { expect, test } from '@jest/globals';
```

## DOM environment

Для тестов, которым нужен `document`:

```ts
const config: Config = {
  testEnvironment: 'jsdom',
};
```

Для backend лучше:

```ts
testEnvironment: 'node';
```

## Мини-шпаргалка

- Установка: `npm install --save-dev jest`.
- Script: `"test": "jest"`.
- Конфиг можно создать через `npm init jest@latest`.
- Для TypeScript нужны Babel, `ts-jest` или отдельный build step.
- `testEnvironment: 'node'` для backend, `jsdom` для DOM.
