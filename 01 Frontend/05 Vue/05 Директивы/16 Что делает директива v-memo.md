# Что делает директива v-memo?

> [!NOTE] Коротко
> `v-memo` мемоизирует поддерево шаблона и пропускает его обновление, если указанные зависимости не изменились.

## Вопрос

Что делает директива `v-memo`?

## Базовый пример

```vue
<div v-memo="[user.id, user.updatedAt]">
  <UserCard :user="user" />
</div>
```

Vue будет обновлять этот блок только когда изменится `user.id` или `user.updatedAt`.

## В списках

`v-memo` может помочь в больших списках, где часть элементов редко меняется.

```vue
<UserRow
  v-for="user in users"
  :key="user.id"
  v-memo="[user.id, user.isSelected]"
  :user="user"
/>
```

Если зависимости не изменились, Vue может пропустить обновление строки.

## Когда использовать

`v-memo` - инструмент точечной оптимизации. Он нужен не для каждого компонента, а для тяжелых участков, где уже понятна причина лишних обновлений.

## Отличие от v-once

`v-once` фиксирует результат навсегда после первого рендера. `v-memo` обновляет блок, когда изменились зависимости из массива.

## Мини-шпаргалка

- `v-memo="[deps]"` пропускает обновление при неизменных deps.
- Полезен для больших списков и тяжелых поддеревьев.
- Требует аккуратного выбора зависимостей.
- Это оптимизация, а не обычный стиль написания шаблонов.
