# Какие хуки жизненного цикла доступны?

> [!NOTE] Коротко
> В Composition API lifecycle hooks доступны как функции `onMounted`, `onUpdated`, `onUnmounted` и другие. Их вызывают внутри `setup` или `<script setup>`.

## Вопрос

Какие хуки жизненного цикла доступны в Composition API?

## Основные хуки

```typescript
import {
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted,
} from "vue";
```

Они соответствуют этапам монтирования, обновления и размонтирования.

## Пример

```vue
<script setup>
import { onMounted, onUnmounted } from "vue";

function onResize() {
  console.log(window.innerWidth);
}

onMounted(() => {
  window.addEventListener("resize", onResize);
});

onUnmounted(() => {
  window.removeEventListener("resize", onResize);
});
</script>
```

## KeepAlive-хуки

```typescript
import { onActivated, onDeactivated } from "vue";
```

Они нужны для компонентов внутри `<KeepAlive>`.

## Debug hooks

```typescript
import { onRenderTracked, onRenderTriggered } from "vue";
```

Эти хуки помогают понять, какие реактивные зависимости участвуют в рендере.

## Мини-шпаргалка

- `onMounted` - компонент попал в DOM.
- `onUpdated` - DOM обновился.
- `onUnmounted` - компонент удален.
- `onActivated/onDeactivated` - для `<KeepAlive>`.
- Регистрируй hooks синхронно в `setup`.
