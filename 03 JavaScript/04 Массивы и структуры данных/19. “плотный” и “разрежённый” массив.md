# Плотный и разреженный массив

> [!summary] Коротко
> Плотный массив содержит элементы на всех индексах от `0` до `length - 1`. Разреженный массив имеет "дырки" (empty slots), где индекса формально нет.

## Вопрос

Что такое плотный и разреженный массив?

## Плотный массив

```javascript
const dense = [10, 20, 30];

0 in dense; // true
1 in dense; // true
2 in dense; // true
```

Все индексы от `0` до `length - 1` существуют.

## Разреженный массив

```javascript
const sparse = [10, , 30];

sparse.length; // 3
1 in sparse;   // false
sparse[1];     // undefined
```

На индексе `1` пустой слот, а не значение `undefined`.

## Как появляются дырки

Через пропуск в литерале:

```javascript
const arr = [1, , 3];
```

Через увеличение `length`:

```javascript
const arr = [1, 2];
arr.length = 5;
```

Через `delete`:

```javascript
const arr = [1, 2, 3];
delete arr[1];
```

## Поведение методов

Некоторые методы пропускают empty slots.

```javascript
const arr = [1, , 3];

arr.forEach((value) => console.log(value));
// 1
// 3
```

`map` тоже пропускает дырку и оставляет дырку в результате:

```javascript
const result = arr.map((value) => value * 2);

console.log(result); // [2, empty, 6]
```

## Как сделать плотнее

```javascript
const arr = [1, , 3];

const dense = arr.filter(() => true);

console.log(dense); // [1, 3]
```

Или заполнить значения:

```javascript
const filled = Array.from(arr, (value) => value ?? 0);
```

## Мини-шпаргалка

| Массив | Индексы |
| --- | --- |
| `[1, 2, 3]` | плотный |
| `[1, , 3]` | разреженный |
| `arr.length = 10` | создает empty slots |
| `delete arr[0]` | создает empty slot |
| `0 in arr` | проверяет наличие слота |
