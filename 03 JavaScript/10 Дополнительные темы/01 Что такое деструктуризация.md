# Что такое деструктуризация?

> [!NOTE] Коротко
> Деструктуризация - синтаксис, который позволяет удобно извлекать значения из массивов и объектов в переменные.

## Вопрос

Что такое деструктуризация в JavaScript?

## Определение

Деструктуризация позволяет "разобрать" массив или объект по структуре и сразу создать переменные для нужных значений. Это делает код короче и понятнее, особенно при работе с параметрами функций, ответами API и вложенными данными.

## Деструктуризация массива

```javascript
const numbers = [10, 20, 30];

const [first, second] = numbers;

console.log(first);  // 10
console.log(second); // 20
```

Значения берутся по позиции.

## Пропуск элементов

```javascript
const [first, , third] = ['a', 'b', 'c'];

console.log(first); // 'a'
console.log(third); // 'c'
```

Пустое место между запятыми пропускает элемент.

## Деструктуризация объекта

```javascript
const user = {
  name: 'Ann',
  age: 25,
};

const { name, age } = user;

console.log(name); // 'Ann'
console.log(age);  // 25
```

Значения берутся по имени свойства.

## Переименование

```javascript
const { name: userName } = user;

console.log(userName); // 'Ann'
```

## Значения по умолчанию

```javascript
const { role = 'reader' } = user;

console.log(role); // 'reader'
```

## В параметрах функции

```javascript
function renderUser({ name, age }) {
  console.log(`${name}: ${age}`);
}

renderUser({ name: 'Ann', age: 25 });
```

## Мини-шпаргалка

```javascript
const [a, b] = array;
const { id, name } = object;
const { name: userName = 'Guest' } = object;
```
