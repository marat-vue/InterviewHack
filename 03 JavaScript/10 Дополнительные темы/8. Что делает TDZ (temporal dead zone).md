# Что делает TDZ (temporal dead zone)

> [!summary] Коротко
> TDZ - период от начала области видимости до инициализации `let` или `const`, когда переменная уже существует, но доступ к ней запрещен.

## Вопрос

Что такое temporal dead zone?

## Определение

Переменные `let` и `const` создаются при входе в область видимости, но становятся доступными только после строки объявления. До этой строки они находятся в TDZ.

Попытка обратиться к переменной в TDZ приводит к `ReferenceError`.

## Пример

```javascript
console.log(value); // ReferenceError

let value = 10;
```

Переменная уже есть в лексическом окружении, но еще не инициализирована.

## TDZ в блоке

```javascript
const value = 'outer';

{
  console.log(value); // ReferenceError

  const value = 'inner';
}
```

Внутренний `const value` затеняет внешний `value` с начала блока, но доступен только после объявления.

## var ведет себя иначе

```javascript
console.log(count); // undefined

var count = 1;
```

`var` инициализируется значением `undefined`, поэтому TDZ для него нет в таком же смысле.

## Зачем это нужно

TDZ помогает ловить ошибки раннего доступа к переменным и делает поведение `let`/`const` более безопасным.

## Мини-шпаргалка

```javascript
// TDZ starts
console.log(x); // ReferenceError
let x = 1;      // TDZ ends
```
