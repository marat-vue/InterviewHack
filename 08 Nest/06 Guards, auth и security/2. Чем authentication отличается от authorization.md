# Чем authentication отличается от authorization?

> [!summary]
> Authentication отвечает на вопрос "кто пользователь?", а authorization - "что ему разрешено?". В NestJS authentication часто реализуют через Passport/JWT guard, а authorization - через roles или permissions guard.

## Authentication

Проверяем личность пользователя.

```txt
Authorization: Bearer <jwt>
```

Если токен валиден, request получает `user`.

## Authorization

Проверяем права пользователя.

```ts
@Roles('admin')
@UseGuards(JwtAuthGuard, RolesGuard)
@Delete(':id')
remove() {}
```

Пользователь может быть аутентифицирован, но не иметь права удалить ресурс.

## 401 vs 403

| Статус | Значение |
|---|---|
| 401 | пользователь не аутентифицирован |
| 403 | пользователь известен, но доступ запрещен |

## Мини-шпаргалка

- Authentication = кто ты.
- Authorization = что тебе можно.
- 401 - нет валидной личности.
- 403 - нет прав.
- В NestJS оба слоя часто оформляются guards.
