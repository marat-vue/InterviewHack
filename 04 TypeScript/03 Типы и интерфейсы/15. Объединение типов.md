# Объединение типов

> [!summary] Коротко
> Объединение типов, или union, описывает значение, которое может быть одним из нескольких типов. В TypeScript это записывается через `|`: `string | number`.

## Вопрос

Расскажите про объединение типов.

## Что такое union

Union читается как "или": значение подходит, если оно соответствует хотя бы одному варианту.

```typescript
let id: string | number;

id = "user-1";
id = 42;
```

Пока тип не сужен, TypeScript разрешает использовать только то, что безопасно для всех вариантов.

```typescript
function printId(id: string | number) {
  console.log(id.toString()); // есть и у string, и у number
  // id.toUpperCase(); // ошибка: у number нет такого метода
}
```

## Сужение типа

Чтобы работать с конкретным вариантом, нужно проверить значение.

```typescript
function normalizeId(id: string | number): string {
  if (typeof id === "number") {
    return id.toFixed(0);
  }

  return id.trim().toLowerCase();
}
```

## Union для состояний

Union особенно полезен для ограниченного набора строковых значений.

```typescript
type RequestStatus = "idle" | "loading" | "success" | "error";

let status: RequestStatus = "loading";
// status = "done"; // ошибка
```

## Union объектов

Для разных форм объектов лучше добавлять общее поле-дискриминатор.

```typescript
type Success = { status: "success"; data: string[] };
type ErrorResult = { status: "error"; message: string };
type Result = Success | ErrorResult;

function render(result: Result) {
  if (result.status === "success") {
    return result.data.join(", ");
  }

  return result.message;
}
```

## Мини-шпаргалка

- `A | B` - значение типа `A` или типа `B`.
- Для доступа к уникальным полям нужен narrowing.
- Literal union удобен для статусов, ролей, режимов и событий.
- Для union объектов добавляй дискриминатор: `type`, `kind`, `status`.
