# Последний элемент массива

> [!NOTE]
> Последний элемент можно получить через `arr[arr.length - 1]` или современным методом `arr.at(-1)`.

## Вопрос

Как получить последний элемент массива?

## Классический способ

```javascript
const arr = ["a", "b", "c"];

const last = arr[arr.length - 1];

console.log(last); // "c"
```

Работает везде и хорошо знаком большинству разработчиков.

## Современный способ `at`

```javascript
const arr = ["a", "b", "c"];

arr.at(-1); // "c"
```

`at()` поддерживает отрицательные индексы:

```javascript
arr.at(-2); // "b"
arr.at(0);  // "a"
```

## Пустой массив

```javascript
const arr = [];

arr[arr.length - 1]; // undefined
arr.at(-1);          // undefined
```

Оба способа вернут `undefined`.

## Не путать с `pop`

```javascript
const arr = ["a", "b", "c"];

arr.pop(); // "c"
```

`pop()` возвращает последний элемент, но также удаляет его из массива.

## Мини-шпаргалка

| Задача | Код |
| --- | --- |
| получить последний | `arr[arr.length - 1]` |
| получить последний современно | `arr.at(-1)` |
| получить предпоследний | `arr.at(-2)` |
| получить и удалить последний | `arr.pop()` |
