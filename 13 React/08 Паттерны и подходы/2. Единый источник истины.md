# Единый источник истины

> [!summary]
> Single Source of Truth означает, что каждое важное значение хранится в одном месте, а остальные части приложения получают его оттуда. Это защищает интерфейс от рассинхронизации и делает поток данных понятнее.

## Проблема дублирования

```jsx
function ProfilePage() {
  const [userName, setUserName] = useState('Ada')
  const [formName, setFormName] = useState('Ada')

  return (
    <>
      <h1>{userName}</h1>
      <input value={formName} onChange={(event) => setFormName(event.target.value)} />
    </>
  )
}
```

Теперь есть два имени пользователя. Если обновить одно и забыть обновить второе, UI станет противоречивым.

## Как сделать один источник правды?

```jsx
function ProfilePage() {
  const [name, setName] = useState('Ada')

  return (
    <>
      <h1>{name}</h1>
      <input value={name} onChange={(event) => setName(event.target.value)} />
    </>
  )
}
```

Данные хранятся один раз. Заголовок и input читают одно и то же значение.

## Controlled components как пример SSOT

```jsx
function EmailField() {
  const [email, setEmail] = useState('')

  return (
    <input
      value={email}
      onChange={(event) => setEmail(event.target.value)}
    />
  )
}
```

Источник истины для значения input - React state. DOM не живет отдельной жизнью.

## Где должен лежать источник истины?

Правило:

```text
Храни state в ближайшем общем родителе компонентов, которым эти данные нужны.
```

Если значение нужно только одному компоненту - state локальный.

Если значение нужно двум соседним компонентам - подними state в родителя.

Если значение нужно многим далеким частям приложения - можно использовать context или state manager.

## Не путать с "все в глобальный store"

Single Source of Truth не означает, что все данные должны лежать в одном глобальном объекте.

Хорошая архитектура может иметь много локальных источников истины:

- состояние формы внутри формы;
- открытие dropdown внутри dropdown;
- текущий пользователь в auth store;
- server data в query cache;
- выбранная вкладка внутри страницы.

Главное - не дублировать одну и ту же смысловую сущность в нескольких местах без необходимости.

## Мини-шпаргалка

- Одна сущность - один источник правды.
- Не копируй props в state без причины.
- Controlled input - классический пример SSOT.
- State должен лежать настолько низко, насколько возможно, и настолько высоко, насколько необходимо.
- Глобальный store не обязан быть единственным источником всех данных.
