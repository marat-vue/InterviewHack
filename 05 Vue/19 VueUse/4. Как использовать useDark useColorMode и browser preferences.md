# Как использовать useDark, useColorMode и browser preferences?

> [!summary]
> `useDark` и `useColorMode` помогают управлять темной темой и учитывать системные предпочтения пользователя. Они меняют DOM attribute/class и могут сохранять выбор в storage.

## useDark

```typescript
import { useDark, useToggle } from "@vueuse/core";

const isDark = useDark();
const toggleDark = useToggle(isDark);
```

```vue
<button @click="toggleDark()">
  {{ isDark ? "Light" : "Dark" }}
</button>
```

`useDark` управляет признаком темы, но не создает стили сам. CSS или UI framework должны реагировать на class/attribute.

## useColorMode

```typescript
const mode = useColorMode({
  modes: {
    dim: "dim",
    sepia: "sepia",
  },
});

mode.value = "dark";
```

`useColorMode` полезен, если кроме light/dark нужны дополнительные режимы.

## С Tailwind

```html
<html class="dark">
```

```vue
<div class="bg-white text-slate-900 dark:bg-slate-950 dark:text-white">
  ...
</div>
```

## С Vuetify

Если theme управляется Vuetify, можно синхронизировать VueUse state и Vuetify theme:

```typescript
const isDark = useDark();
const theme = useTheme();

watch(isDark, (value) => {
  theme.global.name.value = value ? "dark" : "light";
}, { immediate: true });
```

## Мини-шпаргалка

- `useDark` управляет dark/light состоянием.
- `useColorMode` подходит для нескольких color modes.
- VueUse не пишет всю тему за тебя.
- Tailwind реагирует на `dark:` variants.
- Vuetify theme можно синхронизировать через `useTheme`.
