# Readonly свойства

> [!summary] Коротко
> Свойство можно сделать только для чтения через `Object.defineProperty()` с `writable: false`. Для всего объекта используют `Object.freeze()`, но он работает только на верхнем уровне.

## Вопрос

Как сделать свойство только для чтения?

## Через `Object.defineProperty`

```javascript
const user = {};

Object.defineProperty(user, "id", {
  value: 1,
  writable: false,
  enumerable: true,
  configurable: false,
});

user.id = 2;

console.log(user.id); // 1
```

В strict mode попытка изменить `id` приведет к `TypeError`.

## Что означает `writable`

`writable: false` запрещает менять значение свойства через присваивание.

```javascript
obj.id = 2;
```

Но если значение - объект, его внутренности все еще могут быть mutable.

```javascript
const user = {};

Object.defineProperty(user, "profile", {
  value: { city: "Moscow" },
  writable: false,
});

user.profile.city = "Kazan"; // можно
```

Ссылка readonly, но объект внутри не заморожен.

## `configurable`

Если `configurable: false`, свойство нельзя удалить или переопределить.

```javascript
delete user.id; // false или TypeError в strict mode
```

## `Object.freeze`

```javascript
const user = Object.freeze({
  name: "Anna",
  age: 25,
});

user.name = "Max"; // не изменится
```

`freeze` делает все существующие свойства верхнего уровня readonly и запрещает добавлять/удалять свойства.

## TypeScript `readonly`

В TypeScript есть `readonly`, но это проверка на этапе компиляции.

```typescript
type User = {
  readonly id: number;
};
```

В runtime JavaScript это само по себе объект не защищает.

## Мини-шпаргалка

| Задача | Инструмент |
| --- | --- |
| одно readonly-свойство | `Object.defineProperty` + `writable: false` |
| запретить удаление | `configurable: false` |
| readonly верхнего уровня | `Object.freeze(obj)` |
| проверить заморозку | `Object.isFrozen(obj)` |
| TypeScript-only защита | `readonly` |
