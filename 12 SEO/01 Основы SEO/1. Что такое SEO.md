# Что такое SEO?

> [!summary]
> SEO, Search Engine Optimization, - это работа над сайтом и контентом, чтобы поисковые системы могли находить, понимать и показывать страницы пользователям по релевантным запросам. Хорошее SEO начинается с пользы для людей, а не с манипуляций алгоритмами.

## Простое определение

SEO отвечает на вопрос:

```text
Как сделать так, чтобы нужные страницы могли появляться в органическом поиске по нужным запросам?
```

Для этого нужно:

- сделать страницы доступными для crawling;
- разрешить indexing нужных страниц;
- объяснить смысл страницы через контент и HTML;
- улучшить UX и скорость;
- создать доверие к сайту и бренду;
- получать релевантные упоминания и ссылки;
- измерять результат.

## Что SEO не гарантирует?

SEO не гарантирует:

- первое место;
- быстрый рост за неделю;
- стабильные позиции навсегда;
- трафик без полезного контента;
- результат только от meta tags.

Поисковые системы учитывают много сигналов и постоянно меняются.

## Из чего состоит SEO?

| Направление | Что включает |
|---|---|
| Technical SEO | crawling, indexing, sitemap, redirects |
| On-page SEO | title, content, headings, internal links |
| Content SEO | search intent, quality, expertise |
| Performance SEO | Core Web Vitals, mobile UX |
| Structured data | Schema.org, rich results |
| Off-page SEO | links, mentions, reputation |
| Analytics | Search Console, GA4, audits |

## Для frontend-разработчика

Frontend-разработчик влияет на SEO через:

- rendering mode;
- HTML structure;
- meta tags;
- routing;
- status codes;
- canonical;
- images;
- performance;
- accessibility;
- structured data;
- hydration/JavaScript behavior.

## Мини-шпаргалка

- SEO = доступность + понятность + полезность + доверие + измерение.
- SEO делается для пользователей и поисковых систем одновременно.
- Meta tags важны, но это только часть работы.
- Frontend сильно влияет на technical SEO.
- Манипулятивные методы могут привести к санкциям или потере видимости.
