# Динамические ключи объекта

> [!NOTE] Коротко
> Динамические ключи описывают объекты, у которых заранее неизвестны имена всех свойств.

## Вопрос

Как описать объект с динамическими ключами?

## Определение

Иногда объект работает как словарь: ключи создаются динамически, а значения имеют общий тип. Для этого используют index signature или `Record`.

## Index signature

```typescript
type Scores = {
  [userId: string]: number;
};

const scores: Scores = {
  ann: 10,
  bob: 15,
};
```

Любой строковый ключ должен иметь значение типа `number`.

## Record

```typescript
type Scores = Record<string, number>;
```

`Record<K, V>` означает объект с ключами типа `K` и значениями типа `V`.

## Ограниченный набор ключей

```typescript
type Role = 'admin' | 'user';
type Permissions = Record<Role, boolean>;

const permissions: Permissions = {
  admin: true,
  user: false,
};
```

Теперь нужны все ключи из union `Role`.

## Смешивание известных и динамических полей

```typescript
type Dictionary = {
  title: string;
  [key: string]: string;
};
```

Важно: известные свойства должны быть совместимы с типом index signature.

## Мини-шпаргалка

```typescript
type Dict = Record<string, string>;

type CustomDict = {
  [key: string]: string;
};
```
