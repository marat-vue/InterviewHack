# Функция с точки зрения типов

> [!NOTE]
> В TypeScript функция - это значение с сигнатурой. Сигнатура описывает параметры, их типы и тип результата.

## Вопрос

Что такое функция в TypeScript с точки зрения типов?

## Сигнатура функции

Тип функции отвечает на два вопроса: что функция принимает и что возвращает.

```typescript
type Sum = (a: number, b: number) => number;

const sum: Sum = (a, b) => a + b;
```

Здесь `Sum` означает: функция принимает два числа и возвращает число.

## Функция как значение

Функцию можно передавать в другую функцию, хранить в объекте или возвращать.

```typescript
function repeat(count: number, action: () => void): void {
  for (let i = 0; i < count; i += 1) {
    action();
  }
}

repeat(3, () => console.log("tick"));
```

## Важные возвращаемые типы

```typescript
function log(message: string): void {
  console.log(message);
}

function fail(message: string): never {
  throw new Error(message);
}

async function loadUser(id: number): Promise<User> {
  return fetch(`/users/${id}`).then((response) => response.json());
}
```

`void` говорит, что результат не используется. `never` означает, что функция не завершится обычным возвратом. `Promise<T>` описывает асинхронный результат.

## Когда тип писать явно

Параметры почти всегда стоит типизировать явно. Возвращаемый тип часто выводится автоматически, но для публичных функций его полезно фиксировать.

## Мини-шпаргалка

- Тип функции = параметры + возвращаемое значение.
- `(a: number) => string` - сигнатура функции.
- Callback тоже имеет тип.
- Публичным функциям полезен явный return type.
