# Как тестировать forms, setValue и async updates?

> [!summary]
> Формы в Vue Test Utils проверяют через `setValue`, `trigger('submit')`, `emitted` и ожидание async updates. Важно проверять не только отправку, но и ошибки валидации, disabled state, loading и server error.

## `setValue`

```ts
await wrapper.get('input[name="email"]').setValue('ann@example.com');
```

`setValue` обновляет значение input и запускает связанные события.

## Submit формы

```ts
await wrapper.get('form').trigger('submit');

expect(wrapper.emitted('submit')).toEqual([
  [{ email: 'ann@example.com' }],
]);
```

Если в шаблоне `@submit.prevent`, тест все равно вызывает submit-событие.

## Validation error

```ts
await wrapper.get('input[name="email"]').setValue('wrong');
await wrapper.get('form').trigger('submit');

expect(wrapper.text()).toContain('Введите корректный email');
expect(wrapper.emitted('submit')).toBeUndefined();
```

## Async update

Иногда одного `await trigger` недостаточно, если внутри есть promise:

```ts
await wrapper.get('form').trigger('submit');
await flushPromises();

expect(wrapper.text()).toContain('Профиль сохранен');
```

## Double submit

```ts
await wrapper.get('form').trigger('submit');

expect(wrapper.get('button[type="submit"]').attributes('disabled')).toBeDefined();
```

Это защищает от повторных запросов.

## Мини-шпаргалка

- `setValue` меняет значение поля.
- `trigger('submit')` отправляет форму.
- Проверяй validation errors.
- Для promises используй `flushPromises`.
- Loading и disabled states важны для UX и надежности.
