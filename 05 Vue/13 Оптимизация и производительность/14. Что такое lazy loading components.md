# Что такое lazy loading components

> [!summary]
> **Lazy loading components** - это отложенная загрузка компонентов. Код компонента попадает в отдельный chunk и скачивается только тогда, когда компонент реально нужен.

## Главное

Если приложение сразу загружает весь JavaScript, первая загрузка становится тяжелее. Lazy loading помогает уменьшить стартовый bundle.

```text
initial bundle:
  App + Router + Main page

lazy chunk:
  AdminPanel
  ChartEditor
  LargeModal
```

## defineAsyncComponent

Во Vue компонент можно загрузить асинхронно.

```vue
<script setup>
import { defineAsyncComponent } from "vue";

const ChartEditor = defineAsyncComponent(() =>
  import("./ChartEditor.vue")
);
</script>

<template>
  <ChartEditor />
</template>
```

Сборщик вроде Vite создаст отдельный chunk для `ChartEditor`.

## Состояния загрузки и ошибки

```js
import { defineAsyncComponent } from "vue";

export const AdminPanel = defineAsyncComponent({
  loader: () => import("./AdminPanel.vue"),
  loadingComponent: () => import("./AdminPanelSkeleton.vue"),
  errorComponent: () => import("./AdminPanelError.vue"),
  delay: 200,
  timeout: 5000,
});
```

Так пользователь видит понятное состояние, если компонент грузится долго или chunk не загрузился.

## Lazy routes

Чаще всего lazy loading используют на уровне страниц.

```js
const routes = [
  {
    path: "/settings",
    component: () => import("./pages/SettingsPage.vue"),
  },
];
```

Пользователь скачает код страницы настроек только при переходе на `/settings`.

## Когда использовать

- Редко открываемые модальные окна.
- Админские разделы.
- Страницы маршрутов.
- Тяжелые редакторы.
- Графики, карты, rich text editor.

## Когда не стоит использовать

Не нужно лениво грузить маленький компонент, который виден сразу на главном экране. Слишком много мелких chunks может ухудшить загрузку из-за накладных расходов сети.

## Мини-шпаргалка

- Lazy loading уменьшает стартовый bundle.
- Во Vue используют `defineAsyncComponent` и динамический `import()`.
- Для страниц lazy loading обычно настраивают в router.
- Для тяжелых компонентов стоит добавить loading и error состояния.
- Не дроби приложение на слишком мелкие chunks без причины.
