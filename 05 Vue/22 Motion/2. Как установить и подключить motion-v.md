# Как установить и подключить motion-v?

> [!summary]
> Motion for Vue устанавливается пакетом `motion-v`. Для component API достаточно импортировать `motion` или `Motion` в компоненте. Для directive API `v-motion` можно подключить `MotionPlugin` глобально или импортировать directive локально.

## Установка

```bash
npm install motion-v
```

## Использование без глобальной настройки

```vue
<script setup lang="ts">
import { motion } from "motion-v";
</script>

<template>
  <motion.div :animate="{ opacity: 1, y: 0 }" />
</template>
```

Такой вариант хорош для старта: импортируешь только то, что используешь.

## Глобальная регистрация directive

Если хочешь использовать `v-motion` по всему приложению:

```typescript
// src/main.ts
import { createApp } from "vue";
import { MotionPlugin } from "motion-v";
import App from "./App.vue";

const app = createApp(App);

app.use(MotionPlugin);
app.mount("#app");
```

Теперь можно писать:

```vue
<template>
  <div v-motion :initial="{ opacity: 0 }" :animate="{ opacity: 1 }">
    Hello
  </div>
</template>
```

## Локальная регистрация v-motion

```vue
<script setup lang="ts">
import { vMotion } from "motion-v";
</script>

<template>
  <div v-motion :initial="{ opacity: 0 }" :animate="{ opacity: 1 }" />
</template>
```

В `<script setup>` импорт directive делает ее доступной в template.

## Auto-import компонентов

Motion поддерживает integration с `unplugin-vue-components`, но для `<motion />` component может понадобиться ручной import. На практике для учебного проекта проще явно импортировать:

```typescript
import { motion, AnimatePresence, Motion } from "motion-v";
```

## Мини-шпаргалка

- Установка: `npm install motion-v`.
- Component API: `import { motion } from "motion-v"`.
- Primitive API: `import { Motion } from "motion-v"`.
- Directive API: `v-motion`.
- Для глобального `v-motion` нужен `app.use(MotionPlugin)`.
- Начинай с локальных импортов, если не уверен в архитектуре.
