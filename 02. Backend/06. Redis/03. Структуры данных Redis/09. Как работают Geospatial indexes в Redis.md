# Как работают Geospatial indexes в Redis?

> [!NOTE]
> Geospatial команды Redis позволяют хранить координаты и искать объекты по расстоянию. Внутри они построены поверх sorted sets, но дают удобные geo-команды.

## Когда использовать Geo?

Geo подходит для:

- ближайших магазинов;
- курьеров рядом;
- гео-поиска точек;
- поиска объектов в радиусе;
- простого location-based matching.

Для сложной GIS-аналитики лучше специализированные инструменты или PostgreSQL + PostGIS.

## Как добавить координаты?

```redis
GEOADD stores 37.6173 55.7558 store:moscow
GEOADD stores 30.3351 59.9343 store:spb
```

Порядок: longitude, latitude, member.

## Как получить координаты?

```redis
GEOPOS stores store:moscow
```

## Как посчитать расстояние?

```redis
GEODIST stores store:moscow store:spb km
```

Единицы:

- `m`;
- `km`;
- `mi`;
- `ft`.

## Как найти рядом?

```redis
GEOSEARCH stores FROMLONLAT 37.62 55.75 BYRADIUS 10 km WITHDIST ASC COUNT 10
```

Это найдет до 10 stores в радиусе 10 км.

## Node.js пример

```ts
await redis.geoAdd('stores', {
  longitude: 37.6173,
  latitude: 55.7558,
  member: 'store:moscow',
});

const nearby = await redis.geoSearchWith(
  'stores',
  {
    longitude: 37.62,
    latitude: 55.75,
  },
  {
    radius: 10,
    unit: 'km',
  },
  ['WITHDIST'],
);
```

## Ограничения

Redis Geo не заменяет полноценный GIS:

- нет сложных polygon operations;
- нет spatial joins;
- точность и модель подходят для простых cases;
- нужно думать о privacy location data.

## Мини-шпаргалка

- `GEOADD` - добавить точку.
- `GEOPOS` - получить координаты.
- `GEODIST` - расстояние.
- `GEOSEARCH` - поиск рядом.
- Для сложного GIS выбирай PostGIS.
