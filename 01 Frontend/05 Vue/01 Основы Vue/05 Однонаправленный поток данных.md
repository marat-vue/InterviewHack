# Однонаправленный поток данных

> [!NOTE] Коротко
> Однонаправленный поток данных означает, что данные передаются сверху вниз: от родителя к дочерним компонентам через props. Обратно ребенок сообщает о событиях через emit.

## Вопрос

Что такое однонаправленный поток данных во Vue?

## Главная схема

Родитель владеет состоянием, передает его ребенку, а ребенок не меняет props напрямую.

```vue
<!-- Parent.vue -->
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <CounterButton :count="count" @increment="count++" />
</template>
```

```vue
<!-- CounterButton.vue -->
<script setup>
defineProps<{ count: number }>();
const emit = defineEmits<{ increment: [] }>();
</script>

<template>
  <button @click="emit('increment')">{{ count }}</button>
</template>
```

## Почему props нельзя мутировать

Props принадлежат родителю. Если ребенок начнет менять их напрямую, источник правды станет неясным.

```vue
<script setup>
const props = defineProps<{ count: number }>();

// props.count++; // ошибка и плохая архитектура
</script>
```

## Что делать вместо мутации props

Использовать событие, `v-model` для согласованного двустороннего API или локальную копию, если нужно редактирование внутри компонента.

## Мини-шпаргалка

- Данные вниз: props.
- События вверх: emit.
- Props readonly для ребенка.
- Источник состояния должен быть понятен.
