# Что такое INTERSECT и EXCEPT?

> [!summary]
> `INTERSECT` возвращает строки, которые есть в обоих результатах, а `EXCEPT` возвращает строки из первого результата, которых нет во втором. Это операции множеств.

## INTERSECT

```sql
SELECT user_id FROM orders
INTERSECT
SELECT user_id FROM reviews;
```

Вернет пользователей, у которых есть и заказы, и отзывы.

## EXCEPT

```sql
SELECT id FROM users
EXCEPT
SELECT user_id FROM orders;
```

Вернет пользователей без заказов.

## Альтернатива

Для anti join чаще используют `NOT EXISTS`, особенно когда нужно контролировать условия связи.

```sql
SELECT u.*
FROM users u
WHERE NOT EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
);
```

## Поддержка

Операции множеств есть не во всех диалектах одинаково. Например, в MySQL исторически с ними были отличия, поэтому в конкретной СУБД нужно проверять поддержку.

## Мини-шпаргалка

- `INTERSECT` - пересечение.
- `EXCEPT` - разность.
- Требуется одинаковое число колонок.
- Для anti join часто удобнее `NOT EXISTS`.
- Проверяй поддержку в своем SQL-диалекте.
