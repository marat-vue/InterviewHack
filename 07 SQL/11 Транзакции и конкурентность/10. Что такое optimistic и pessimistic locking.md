# Что такое optimistic и pessimistic locking?

> [!summary]
> Pessimistic locking заранее блокирует строку, чтобы другие транзакции не изменили ее одновременно. Optimistic locking не блокирует заранее, а проверяет при записи, что данные не изменились с момента чтения.

## Pessimistic locking

```sql
BEGIN;

SELECT *
FROM accounts
WHERE id = 1
FOR UPDATE;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

COMMIT;
```

Строка блокируется до конца транзакции.

## Optimistic locking

В таблице есть версия:

```sql
ALTER TABLE products
ADD COLUMN version integer NOT NULL DEFAULT 1;
```

Обновление:

```sql
UPDATE products
SET price = 120,
    version = version + 1
WHERE id = 1
  AND version = 5;
```

Если обновлено `0` строк, значит кто-то уже изменил запись.

## Когда что выбирать?

| Подход | Когда подходит |
|---|---|
| Pessimistic | высокая вероятность конфликта, критичная операция |
| Optimistic | конфликты редкие, важна высокая конкурентность |

## Мини-шпаргалка

- Pessimistic locking блокирует заранее.
- Optimistic locking проверяет версию при записи.
- `SELECT FOR UPDATE` - частый pessimistic-подход.
- `version`-колонка - частый optimistic-подход.
- Для optimistic locking нужен retry или понятная ошибка пользователю.
