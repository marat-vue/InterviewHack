# Что такое child_process?

> [!summary]
> `child_process` - встроенный модуль Node.js для запуска внешних процессов: shell-команд, других Node.js-скриптов, утилит ОС и отдельных программ.

## Зачем нужен child_process?

Node.js-процесс может запускать другие процессы, если нужно:

- вызвать системную команду;
- запустить сборщик;
- обработать файл внешней утилитой;
- вынести отдельную задачу за пределы основного процесса.

## exec

`exec` запускает команду в shell и возвращает весь вывод целиком.

```js
import { exec } from 'node:child_process';
import { promisify } from 'node:util';

const execAsync = promisify(exec);

const { stdout } = await execAsync('node --version');
console.log(stdout);
```

Подходит для простых команд с небольшим выводом.

## spawn

`spawn` запускает процесс и дает streams для stdin/stdout/stderr.

```js
import { spawn } from 'node:child_process';

const child = spawn('node', ['--version']);

child.stdout.on('data', (chunk) => {
  console.log(chunk.toString());
});
```

Подходит для долгих процессов и большого вывода.

## Важная безопасность

Никогда не склеивай shell-команду из пользовательского ввода.

```js
// Опасно
exec(`convert ${userFile}`);
```

Лучше передавать аргументы отдельно через `spawn`.

```js
spawn('convert', [userFile]);
```

## Мини-шпаргалка

- `child_process` запускает внешние процессы.
- `exec` удобен для коротких shell-команд.
- `spawn` лучше для больших данных и долгих процессов.
- Пользовательский ввод нельзя вставлять в shell-команду строкой.
- Для CPU-bound JavaScript-задач часто лучше `worker_threads`.
