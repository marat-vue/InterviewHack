# Как установить Storybook для Vue и Vite?

> [!summary]
> Для Vue 3 + Vite проектов Storybook устанавливают через `npm create storybook@latest`. Он добавляет `.storybook`, scripts для запуска и сборки, а framework обычно настраивается как `@storybook/vue3-vite`.

## Установка

```bash
npm create storybook@latest
```

Storybook анализирует проект и добавляет нужные зависимости.

После установки появляются scripts:

```json
{
  "scripts": {
    "storybook": "storybook dev -p 6006",
    "build-storybook": "storybook build"
  }
}
```

## Запуск

```bash
npm run storybook
```

Storybook обычно открывается на:

```text
http://localhost:6006
```

## Сборка

```bash
npm run build-storybook
```

Результат обычно попадает в `storybook-static`.

## Основные файлы

```text
.storybook/
  main.ts
  preview.ts
src/
  components/
    BaseButton.vue
    BaseButton.stories.ts
```

`main.ts` отвечает за framework, addons и поиск stories.

```ts
import type { StorybookConfig } from '@storybook/vue3-vite';

const config: StorybookConfig = {
  framework: '@storybook/vue3-vite',
  stories: ['../src/**/*.stories.@(js|jsx|ts|tsx|mdx)'],
  addons: ['@storybook/addon-docs'],
};

export default config;
```

## Подключение plugins Vue

В `preview.ts` можно настроить Vue app:

```ts
import { setup } from '@storybook/vue3-vite';
import { createPinia } from 'pinia';

setup((app) => {
  app.use(createPinia());
});
```

Так stories получают те же plugins, что и приложение.

## Мини-шпаргалка

- Установка: `npm create storybook@latest`.
- Запуск: `npm run storybook`.
- Сборка: `npm run build-storybook`.
- Vue/Vite framework: `@storybook/vue3-vite`.
- Глобальные plugins подключают в `.storybook/preview.ts`.
