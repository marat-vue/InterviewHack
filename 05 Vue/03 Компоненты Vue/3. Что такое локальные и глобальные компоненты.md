# Что такое локальные и глобальные компоненты

> [!summary] Коротко
> Локальный компонент доступен только там, где его импортировали или зарегистрировали. Глобальный компонент доступен во всем приложении после регистрации через `app.component`.

## Вопрос

Что такое локальные и глобальные компоненты?

## Локальный компонент

В `<script setup>` импортированный компонент автоматически доступен в шаблоне.

```vue
<script setup>
import UserCard from "./UserCard.vue";
</script>

<template>
  <UserCard />
</template>
```

Такой компонент доступен только в текущем файле.

## Глобальный компонент

Глобальный компонент регистрируют при создании приложения.

```typescript
import { createApp } from "vue";
import App from "./App.vue";
import BaseButton from "./components/BaseButton.vue";

const app = createApp(App);

app.component("BaseButton", BaseButton);
app.mount("#app");
```

После этого `<BaseButton />` можно использовать в любом компоненте.

## Что выбирать

Локальная регистрация лучше по умолчанию: зависимости явно видны, сборщик может лучше оптимизировать код. Глобальная регистрация удобна для базовых UI-компонентов: `BaseButton`, `BaseInput`, `AppIcon`.

## Мини-шпаргалка

- Локальный компонент импортируется в конкретный файл.
- Глобальный регистрируется через `app.component`.
- По умолчанию выбирай локальную регистрацию.
- Глобально удобно регистрировать часто используемые базовые компоненты.
