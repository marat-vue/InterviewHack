# Приватные свойства

> [!NOTE]
> Приватные свойства класса объявляются через `#` и доступны только внутри тела этого класса.

## Вопрос

Что такое приватное свойство класса?

## Определение

Приватное поле с `#` скрыто от внешнего кода. К нему нельзя обратиться через точку, квадратные скобки или наследника.

Такой механизм помогает защищать внутреннее состояние объекта от случайного изменения.

## Пример

```javascript
class Counter {
  #value = 0;

  increment() {
    this.#value++;
  }

  getValue() {
    return this.#value;
  }
}

const counter = new Counter();

counter.increment();

console.log(counter.getValue()); // 1
```

## Попытка доступа снаружи

```javascript
counter.#value; // SyntaxError
```

Приватные поля проверяются на уровне синтаксиса.

## Приватный метод

```javascript
class User {
  #formatName(name) {
    return name.trim().toLowerCase();
  }

  setName(name) {
    this.name = this.#formatName(name);
  }
}
```

Приватными могут быть не только поля, но и методы.

## Мини-шпаргалка

```javascript
class A {
  #secret = 123;

  getSecret() {
    return this.#secret;
  }
}
```
