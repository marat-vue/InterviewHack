# Что такое defineHandler, defineEventHandler и lazy handlers?

> [!NOTE]
> `defineHandler` и `defineEventHandler` описывают request handler. В Nitro v3 standalone-документации чаще встречается `defineHandler` из `nitro`; в Nuxt server routes часто используется `defineEventHandler`, совместимый с H3/Nitro-подходом.

## Что делает handler?

Handler принимает `event` и возвращает response-compatible значение.

```ts
export default defineHandler((event) => {
  return {
    path: event.path,
  };
});
```

Handler можно сравнить с controller action в других фреймворках.

## `defineHandler`

`defineHandler` нужен для:

- лучшего type inference;
- явного объявления handler;
- совместимости с Nitro v3 API;
- object syntax с meta/middleware в H3.

```ts
import { defineHandler } from 'nitro';

export default defineHandler(async (event) => {
  return {
    ok: true,
  };
});
```

## `defineEventHandler`

`defineEventHandler` часто встречается в Nuxt:

```ts
// server/api/me.get.ts
export default defineEventHandler(async (event) => {
  return {
    user: event.context.user,
  };
});
```

В Nuxt этот helper обычно auto-imported, поэтому import может отсутствовать.

## Можно ли экспортировать обычную функцию?

Да, handler может быть обычной функцией:

```ts
export default (event) => {
  return 'Hello';
};
```

Но явный helper обычно лучше:

- понятнее намерение;
- лучше типизация;
- проще читать в команде;
- меньше магии при переносе между Nuxt и standalone Nitro.

## Object syntax

H3 поддерживает object syntax, где можно указать middleware и meta:

```ts
import { defineHandler, basicAuth } from 'h3';

export default defineHandler({
  middleware: [
    basicAuth({ password: 'secret' }),
  ],
  meta: {
    tag: 'admin',
  },
  handler() {
    return {
      ok: true,
    };
  },
});
```

Object syntax полезен для route-scoped middleware и metadata.

## Lazy handlers

Lazy handler откладывает тяжелую инициализацию до первого запроса.

```ts
import { defineLazyEventHandler } from 'h3';

export default defineLazyEventHandler(async () => {
  const sdk = await createExpensiveSdk();

  return async () => {
    return sdk.getData();
  };
});
```

Lazy handlers полезны, когда:

- route вызывается редко;
- initialization дорогая;
- SDK нужно поднять один раз;
- хочется уменьшить cold start основного сервера.

## Какой helper использовать?

| Контекст | Что использовать |
|---|---|
| Standalone Nitro v3 | `defineHandler` |
| Nuxt `server/api` | `defineEventHandler` |
| Нужно отложить init | `defineLazyEventHandler` |
| Нужны route meta/middleware | object syntax |
| Простой demo handler | можно обычную функцию |

## Мини-шпаргалка

- Handler - функция `event -> response`.
- `defineHandler` - основной Nitro v3 стиль.
- `defineEventHandler` - привычный Nuxt/H3 стиль.
- Lazy handler выполняет setup один раз при первом обращении.
- Object syntax удобен для meta и route-scoped middleware.
