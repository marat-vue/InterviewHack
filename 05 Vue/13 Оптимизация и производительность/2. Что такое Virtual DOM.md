# Что такое Virtual DOM

> [!summary]
> **Virtual DOM** - это JavaScript-представление интерфейса. Vue строит дерево виртуальных узлов, сравнивает новое дерево со старым и точечно обновляет настоящий DOM.

## Главное

Работа с реальным DOM может быть дорогой, особенно если изменений много. Virtual DOM позволяет Vue сначала описать изменения в JavaScript, а затем применить к DOM только нужные операции.

```text
state changed
  -> render function creates new VNode tree
  -> Vue compares old tree and new tree
  -> Vue patches real DOM
```

## Что такое VNode

VNode - это обычный объект, который описывает будущий DOM-узел или компонент.

```js
const vnode = {
  type: "button",
  props: {
    class: "primary",
    disabled: false,
  },
  children: "Сохранить",
};
```

Примерно такой объект может соответствовать разметке:

```html
<button class="primary">Сохранить</button>
```

## Как это выглядит во Vue

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">
    Нажато: {{ count }}
  </button>
</template>
```

Когда `count` меняется, Vue не пересоздает всю страницу. Он понимает, что изменился текст внутри кнопки, и обновляет именно эту часть DOM.

## Зачем нужен Virtual DOM

- Дает декларативную модель: UI является результатом состояния.
- Позволяет Vue эффективно сравнивать старый и новый интерфейс.
- Упрощает работу с компонентами.
- Делает рендер предсказуемым.
- Позволяет компилятору Vue добавлять оптимизации.

## Virtual DOM не всегда самый быстрый

Virtual DOM - это универсальный механизм. Иногда прямые точечные обновления могли бы быть быстрее, но писать их вручную сложно и легко ошибиться. Vue сочетает Virtual DOM с компиляторными оптимизациями: статическим hoisting, patch flags и block tree.

## Мини-шпаргалка

- Virtual DOM - дерево JS-объектов, описывающее UI.
- VNode - один узел этого дерева.
- Vue сравнивает старый и новый VNode tree.
- Реальный DOM обновляется только там, где нужно.
- Vue 3 ускоряет Virtual DOM за счет информации, которую получает на этапе компиляции шаблона.
