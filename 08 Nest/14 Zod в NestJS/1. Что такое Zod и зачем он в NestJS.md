# Что такое Zod и зачем он в NestJS?

> [!summary]
> Zod - TypeScript-first библиотека для описания schemas и validation. В NestJS Zod можно использовать для DTO validation, query parsing, env validation и проверки данных от внешних API.

## Чем Zod отличается от class-validator?

`class-validator` работает через decorators на class.

```ts
export class CreateUserDto {
  @IsEmail()
  email: string;
}
```

Zod описывает schema как значение.

```ts
const createUserSchema = z.object({
  email: z.email(),
});
```

## Где Zod полезен?

- validation body/query/params;
- env validation;
- parsing внешних API responses;
- runtime validation без decorators;
- shared schemas между frontend и backend.

## Важная идея

TypeScript проверяет типы во время разработки, а Zod проверяет данные в runtime. Это особенно важно на границах системы.

## Мини-шпаргалка

- Zod описывает validation schemas.
- Schema можно использовать и для runtime validation, и для TypeScript type inference.
- `z.infer` получает TS-тип из schema.
- В NestJS нужен custom pipe или integration package.
- Zod удобен, когда хочется schemas как обычные значения.
