# Что такое Vitest и зачем он нужен для Nitro?

> [!NOTE]
> Vitest - test runner из Vite-экосистемы. Для Nitro он нужен, чтобы тестировать services, utils, validation schemas, Prisma repositories, auth helpers, route handlers и Nuxt/Nitro integration вместе с `@nuxt/test-utils`.

## Что делает Vitest?

Vitest:

- находит test files;
- запускает tests;
- предоставляет `test`, `it`, `describe`;
- предоставляет assertions через `expect`;
- дает mocks/spies через `vi`;
- поддерживает TypeScript и ESM;
- умеет watch mode;
- умеет coverage;
- умеет setup/teardown;
- интегрируется с Vite config.

## Почему Vitest подходит Nitro?

Nitro и Nuxt живут в современном TypeScript/Vite/ESM мире. Vitest хорошо подходит, потому что:

- понимает Vite aliases;
- быстро запускается;
- хорошо работает с TypeScript;
- похож на Jest по API;
- поддерживает mocks;
- удобно тестирует server utilities;
- используется в Nuxt testing docs.

## Что тестировать в Nitro через Vitest?

Хорошие цели:

- чистые функции;
- Zod schemas;
- services;
- repositories;
- Prisma query builders;
- auth guards;
- error mapping;
- utility functions;
- cache key builders;
- permission logic.

## Что не стоит тестировать только unit-тестами?

Только unit-тестов мало для:

- Better Auth full flow;
- Prisma migrations;
- cookies/session behavior;
- CORS;
- Nitro routeRules;
- WebSocket;
- deployment-specific behavior.

Для этого нужны integration/e2e tests.

## Минимальный тест

```ts
import { expect, test } from 'vitest';

function sum(a: number, b: number) {
  return a + b;
}

test('adds numbers', () => {
  expect(sum(2, 3)).toBe(5);
});
```

## Пример теста auth guard logic

```ts
import { describe, expect, it } from 'vitest';
import { canEditPost } from '../server/services/permissions';

describe('canEditPost', () => {
  it('allows owner', () => {
    expect(canEditPost({
      userId: 'u1',
      postAuthorId: 'u1',
      role: 'user',
    })).toBe(true);
  });

  it('allows admin', () => {
    expect(canEditPost({
      userId: 'u2',
      postAuthorId: 'u1',
      role: 'admin',
    })).toBe(true);
  });
});
```

## Мини-шпаргалка

- Vitest - test runner.
- `test/it` описывает test case.
- `describe` группирует tests.
- `expect` проверяет результат.
- `vi` отвечает за mocks, spies, timers.
- Для Nuxt runtime используй `@nuxt/test-utils`.
