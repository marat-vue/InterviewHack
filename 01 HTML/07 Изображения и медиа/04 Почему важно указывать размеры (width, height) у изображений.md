# Почему важно указывать размеры (width, height) у изображений?

> [!NOTE]
> Атрибуты `width` и `height` помогают браузеру заранее выделить место под изображение. Это уменьшает скачки layout и улучшает визуальную стабильность страницы.

## Главное

```html
<img
  src="/cover.jpg"
  alt="Обложка статьи"
  width="800"
  height="450"
>
```

Даже если изображение еще не загрузилось, браузер знает его соотношение сторон.

## Проблема без размеров

```text
HTML rendered
  -> text appears
  -> image downloads
  -> browser learns image size
  -> content jumps down
```

Такой скачок ухудшает `CLS` и раздражает пользователя.

## Размеры и CSS

HTML-атрибуты задают intrinsic size, а CSS может управлять отображением.

```css
img {
  max-width: 100%;
  height: auto;
}
```

Так изображение адаптируется по ширине контейнера, но сохраняет правильное соотношение сторон.

## Responsive пример

```html
<img
  src="/article-cover-800.webp"
  alt="Рабочий стол с ноутбуком"
  width="800"
  height="450"
>
```

```css
.article-cover {
  width: 100%;
  height: auto;
}
```

Можно добавить класс, но сами `width` и `height` все равно полезны для расчета пропорций.

## Мини-шпаргалка

- `width` и `height` помогают заранее занять место.
- Это снижает layout shift.
- CSS может масштабировать изображение.
- `height: auto` сохраняет пропорции.
- Для важных изображений размеры особенно полезны.
