# Как установить и настроить Swagger в NestJS?

> [!summary]
> Swagger в NestJS подключают через `@nestjs/swagger`: создают config через `DocumentBuilder`, генерируют document через `SwaggerModule.createDocument` и монтируют UI через `SwaggerModule.setup`.

## Установка

```bash
npm install @nestjs/swagger
```

## main.ts

```ts
const config = new DocumentBuilder()
  .setTitle('App API')
  .setDescription('API documentation')
  .setVersion('1.0')
  .addBearerAuth()
  .build();

const document = SwaggerModule.createDocument(app, config);
SwaggerModule.setup('docs', app, document);
```

Теперь документация доступна по `/docs`.

## С global prefix

Если есть:

```ts
app.setGlobalPrefix('api');
```

проверь, по какому пути должна быть доступна документация и endpoints в документе.

## Production

Для internal API Swagger UI часто закрывают auth, выключают в production или оставляют только за VPN/admin guard.

## Мини-шпаргалка

- Пакет: `@nestjs/swagger`.
- `DocumentBuilder` настраивает title/version/auth.
- `createDocument` генерирует OpenAPI document.
- `setup` монтирует Swagger UI.
- Swagger UI в production нельзя оставлять публичным бездумно.
