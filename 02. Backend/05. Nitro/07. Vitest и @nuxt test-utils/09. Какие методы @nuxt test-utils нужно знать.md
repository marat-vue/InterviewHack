# Какие методы @nuxt/test-utils нужно знать?

> [!NOTE]
> В `@nuxt/test-utils` чаще всего используют runtime helpers для component/runtime tests и e2e helpers для поднятия приложения и HTTP/browser checks. Главные методы: `mountSuspended`, `renderSuspended`, `mockNuxtImport`, `mockComponent`, `registerEndpoint`, `setup`, `$fetch`, `fetch`, `url`, `createPage`.

## Runtime helpers

| Метод | Зачем нужен |
|---|---|
| `mountSuspended(component, options?)` | смонтировать Vue/Nuxt component в Nuxt environment с поддержкой async setup/Suspense |
| `renderSuspended(component, options?)` | отрендерить component через Testing Library style |
| `mockNuxtImport(name, factory)` | замокать auto-imported Nuxt composable/helper |
| `mockComponent(name, factory)` | замокать Nuxt component |
| `registerEndpoint(path, handlerOrOptions)` | зарегистрировать mock endpoint для `$fetch`/runtime tests |

## `mountSuspended`

```ts
import { mountSuspended } from '@nuxt/test-utils/runtime';
import UserCard from '~/components/UserCard.vue';

const wrapper = await mountSuspended(UserCard, {
  props: {
    userId: 'u1',
  },
});

expect(wrapper.text()).toContain('Anna');
```

Под капотом использует Vue Test Utils `mount`, поэтому wrapper имеет familiar API: `find`, `text`, `html`, `emitted`.

## `renderSuspended`

```ts
import { renderSuspended } from '@nuxt/test-utils/runtime';
import { screen } from '@testing-library/vue';

await renderSuspended(UserCard);

expect(screen.getByText('Anna')).toBeTruthy();
```

Подходит, если команда предпочитает Testing Library подход: проверять UI как пользователь, а не internals component.

## `mockNuxtImport`

```ts
import { mockNuxtImport } from '@nuxt/test-utils/runtime';
import { vi } from 'vitest';

mockNuxtImport('useRoute', () => {
  return () => ({
    params: {
      id: 'u1',
    },
  });
});
```

Используется для `useRoute`, `useRuntimeConfig`, `useAsyncData`, custom auto imports.

## `mockComponent`

```ts
mockComponent('NuxtLink', {
  template: '<a><slot /></a>',
});
```

Полезно, если child component тяжелый или зависит от browser/runtime, который не нужен в текущем тесте.

## `registerEndpoint`

```ts
import { registerEndpoint, mountSuspended } from '@nuxt/test-utils/runtime';

registerEndpoint('/api/user', () => ({
  id: 'u1',
  name: 'Anna',
}));

const wrapper = await mountSuspended(UserProfile);

expect(wrapper.text()).toContain('Anna');
```

С method:

```ts
registerEndpoint('/api/users', {
  method: 'POST',
  handler: () => ({
    id: 'created',
  }),
});
```

## E2E helpers

| Метод | Зачем нужен |
|---|---|
| `setup(options?)` | поднять Nuxt test app |
| `$fetch(path, options?)` | сделать request к test app и сразу распарсить response |
| `fetch(path, options?)` | получить raw `Response` |
| `url(path?)` | получить полный URL test app |
| `createPage(path?)` | открыть Playwright page |
| `getBrowser()` | получить browser instance |

## Мини-шпаргалка

- Components: `mountSuspended` или `renderSuspended`.
- Auto imports: `mockNuxtImport`.
- Child components: `mockComponent`.
- Mock API in runtime tests: `registerEndpoint`.
- E2E app setup: `setup`.
- HTTP check: `$fetch`/`fetch`.
- Browser check: `createPage`.
