# Что делает toReversed()?

> [!NOTE] Коротко
> `toReversed()` возвращает новый массив с элементами в обратном порядке и не изменяет исходный массив.

## Вопрос

Чем `toReversed()` отличается от `reverse()` и когда его лучше использовать?

## Определение

`toReversed()` - немутирующий метод массива из ES2023. Он делает то же логическое действие, что и `reverse()`, но вместо изменения оригинала создает новую копию.

Это особенно удобно в React, Redux и любом коде, где важно не менять исходные данные.

## Пример

```javascript
const numbers = [1, 2, 3];

const reversed = numbers.toReversed();

console.log(reversed); // [3, 2, 1]
console.log(numbers);  // [1, 2, 3]
```

## Сравнение с reverse()

```javascript
const list = ['a', 'b', 'c'];

const result = list.reverse();

console.log(result); // ['c', 'b', 'a']
console.log(list);   // ['c', 'b', 'a'] - исходный массив изменился
```

`reverse()` мутирует массив, а `toReversed()` оставляет его нетронутым.

## Когда использовать

- когда нужно получить перевернутую копию;
- когда исходный массив должен остаться прежним;
- когда данные лежат в состоянии приложения;
- когда хочется писать более предсказуемый код без побочных эффектов.

## Мини-шпаргалка

```javascript
arr.reverse();    // меняет arr
arr.toReversed(); // возвращает новую копию
```
