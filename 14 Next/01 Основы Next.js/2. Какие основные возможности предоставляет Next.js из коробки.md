# Какие основные возможности предоставляет Next.js из коробки?

> [!summary]
> Next.js из коробки дает App Router, Server Components, несколько стратегий рендеринга, data fetching на сервере, кеширование, Server Actions, Route Handlers, Metadata API, оптимизацию изображений, шрифтов, скриптов и production build.

## 1. File-system routing

Маршруты создаются структурой папок:

```text
app/
  page.tsx
  about/
    page.tsx
  products/
    [id]/
      page.tsx
```

Результат:

- `/`;
- `/about`;
- `/products/:id`.

Не нужно вручную описывать `<Routes>`.

## 2. Layouts

`layout.tsx` задает общую оболочку для сегмента:

```tsx
export default function DashboardLayout({ children }: { children: React.ReactNode }) {
  return (
    <section>
      <Sidebar />
      {children}
    </section>
  )
}
```

Layout сохраняется между переходами внутри своего сегмента.

## 3. Server Components

В App Router компоненты серверные по умолчанию:

```tsx
export default async function ProductsPage() {
  const products = await db.product.findMany()

  return <ProductList products={products} />
}
```

Такой код выполняется на сервере и не отправляет сам компонент в клиентский JS bundle.

## 4. Client Components

Если нужна интерактивность, добавляют директиву:

```tsx
'use client'

import { useState } from 'react'

export function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

## 5. Rendering strategies

Next.js поддерживает:

- static rendering;
- dynamic rendering;
- streaming;
- ISR;
- client-side rendering внутри Client Components.

## 6. Route Handlers и Server Actions

Route Handler:

```ts
export async function GET() {
  return Response.json({ ok: true })
}
```

Server Action:

```ts
'use server'

export async function createPost(formData: FormData) {
  await db.post.create({ data: { title: String(formData.get('title')) } })
}
```

## 7. Metadata API

```tsx
export const metadata = {
  title: 'Products',
  description: 'Product catalog',
}
```

Metadata помогает SEO и social sharing.

## Что отвечать на собеседовании?

Next.js предоставляет не одну фичу, а набор production-возможностей: файловый роутинг, layouts, Server Components, Client Components, SSR/SSG/ISR/streaming, data fetching, cache, Route Handlers, Server Actions, Metadata API и оптимизацию assets.

## Частые ошибки

- Называть Next.js только SSR-фреймворком.
- Забывать про Server Components.
- Смешивать App Router и Pages Router API.
- Писать API там, где достаточно Server Action.
- Использовать Client Components для всего дерева.

## Мини-шпаргалка

- `app` - App Router.
- `page.tsx` - страница.
- `layout.tsx` - общая оболочка.
- `route.ts` - Route Handler.
- `metadata` и `generateMetadata` - SEO.
- `next/image`, `next/font` - оптимизация.
