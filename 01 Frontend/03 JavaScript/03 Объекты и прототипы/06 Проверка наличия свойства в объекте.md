# Проверка наличия свойства в объекте

> [!NOTE]
> Для проверки свойства используют `in`, `Object.hasOwn()` или сравнение значения с `undefined`. Самый точный современный способ для собственных свойств - `Object.hasOwn(obj, key)`.

## Вопрос

Как проверить, есть ли свойство в объекте?

## Оператор `in`

Проверяет свойство в объекте и его прототипе.

```javascript
const user = { name: "Anna" };

"name" in user;     // true
"age" in user;      // false
"toString" in user; // true
```

`toString` найден в прототипе.

## `Object.hasOwn`

Проверяет только собственные свойства.

```javascript
Object.hasOwn(user, "name");     // true
Object.hasOwn(user, "toString"); // false
```

Это хороший вариант по умолчанию.

## `hasOwnProperty`

Старый способ:

```javascript
user.hasOwnProperty("name");
```

Более безопасная форма:

```javascript
Object.prototype.hasOwnProperty.call(user, "name");
```

Она работает даже если объект переопределил `hasOwnProperty`.

## Проверка через `undefined`

```javascript
const user = { name: undefined };

user.name !== undefined; // false
"name" in user;          // true
```

Так можно проверить значение, но не факт наличия ключа.

## Мини-шпаргалка

| Способ | Проверяет |
| --- | --- |
| `"key" in obj` | собственные и унаследованные |
| `Object.hasOwn(obj, "key")` | только собственные |
| `obj.key !== undefined` | значение не `undefined` |
| `obj?.key` | безопасное чтение |
