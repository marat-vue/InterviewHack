# Базовый случай в рекурсии

> [!NOTE] Коротко
> Базовый случай - условие, при котором рекурсивная функция прекращает вызывать саму себя и возвращает готовый результат.

## Вопрос

Что такое базовый случай в рекурсии?

## Пример

```javascript
function factorial(n) {
  if (n === 0) return 1;

  return n * factorial(n - 1);
}
```

Базовый случай:

```javascript
if (n === 0) return 1;
```

Без него функция не остановится.

## Зачем он нужен

Рекурсия должна двигаться к завершению.

```javascript
factorial(3);
// 3 * factorial(2)
// 3 * 2 * factorial(1)
// 3 * 2 * 1 * factorial(0)
// 3 * 2 * 1 * 1
```

`factorial(0)` - точка остановки.

## Базовый случай для массива

```javascript
function sum(numbers) {
  if (numbers.length === 0) return 0;

  const [first, ...rest] = numbers;
  return first + sum(rest);
}

sum([1, 2, 3]); // 6
```

Базовый случай - пустой массив.

## Базовый случай для дерева

```javascript
function countNodes(node) {
  if (node === null) return 0;

  return 1 + countNodes(node.left) + countNodes(node.right);
}
```

Базовый случай - отсутствие узла.

## Частые ошибки

Базовый случай слишком узкий:

```javascript
function countDown(n) {
  if (n === 0) return;

  countDown(n - 1);
}

countDown(-1); // не остановится
```

Лучше:

```javascript
function countDown(n) {
  if (n <= 0) return;

  countDown(n - 1);
}
```

## Мини-шпаргалка

| Задача | Возможный базовый случай |
| --- | --- |
| факториал | `n === 0` |
| обратный отсчет | `n <= 0` |
| массив | `array.length === 0` |
| дерево | `node === null` |
| строка | `str.length === 0` |
