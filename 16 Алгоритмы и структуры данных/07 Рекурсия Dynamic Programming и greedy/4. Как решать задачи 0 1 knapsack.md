# Как решать задачи 0 1 knapsack?

> [!summary]
> 0/1 Knapsack - классический DP-паттерн выбора предметов: каждый предмет можно взять или не взять. State обычно зависит от индекса предмета и оставшейся вместимости.

## Формулировка

Есть предметы:

```text
weights[i], values[i]
```

Есть вместимость `capacity`.

Нужно получить максимальную ценность, взяв каждый предмет максимум один раз.

## State

```text
dp[i][w] = максимум ценности, используя первые i предметов и вместимость w
```

## Transition

Не берем предмет:

```text
dp[i][w] = dp[i - 1][w]
```

Берем предмет, если помещается:

```text
dp[i][w] = dp[i - 1][w - weight] + value
```

## Реализация

```ts
function knapsack(weights: number[], values: number[], capacity: number): number {
  const n = weights.length
  const dp = Array.from({ length: n + 1 }, () => new Array(capacity + 1).fill(0))

  for (let i = 1; i <= n; i++) {
    const weight = weights[i - 1]
    const value = values[i - 1]

    for (let w = 0; w <= capacity; w++) {
      dp[i][w] = dp[i - 1][w]

      if (weight <= w) {
        dp[i][w] = Math.max(dp[i][w], dp[i - 1][w - weight] + value)
      }
    }
  }

  return dp[n][capacity]
}
```

## Что отвечать на собеседовании?

0/1 knapsack решается DP, где состояние зависит от номера предмета и оставшейся вместимости. На каждом шаге есть выбор: взять предмет или не взять. Каждый предмет можно взять только один раз, поэтому при переходе смотрим на предыдущую строку `i - 1`.

## Частые ошибки

- Путать 0/1 knapsack и unbounded knapsack.
- Неправильно идти по capacity при 1D optimization.
- Забывать base row/column.
- Использовать greedy по value/weight, хотя это не всегда корректно.
- Ошибаться в индексах `i - 1`.

## Мини-шпаргалка

- Choice: take / skip.
- State: `i`, `capacity`.
- 2D DP: `O(n * W)`.
- Каждый предмет один раз.
- Base: нули.
- Greedy не гарантирует ответ.
