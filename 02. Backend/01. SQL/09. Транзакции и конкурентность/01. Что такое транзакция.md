# Что такое транзакция?

> [!NOTE]
> Транзакция - группа SQL-операций, которая выполняется как единое логическое действие. Если все успешно, изменения фиксируются через `COMMIT`; если что-то пошло не так, откатываются через `ROLLBACK`.

## Пример

```sql
BEGIN;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

UPDATE accounts
SET balance = balance + 100
WHERE id = 2;

COMMIT;
```

Денежный перевод должен выполниться целиком.

## Rollback

```sql
BEGIN;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

ROLLBACK;
```

Изменения внутри транзакции откатываются.

## Зачем нужны транзакции?

- сохранить целостность данных;
- объединить несколько операций;
- защититься от частичных изменений;
- управлять конкурентным доступом;
- сделать бизнес-действие атомарным.

## Мини-шпаргалка

- `BEGIN` начинает транзакцию.
- `COMMIT` фиксирует изменения.
- `ROLLBACK` откатывает изменения.
- Транзакции нужны для целостности.
- Не держи транзакции открытыми дольше нужного.
