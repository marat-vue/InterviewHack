# Как тестировать Vue через Vue Testing Library?

> [!summary]
> Vue Testing Library предоставляет `render` для Vue-компонентов и encourages тестировать DOM как пользователь. Она удобна для форм, доступности, интерактивных сценариев и компонентных тестов, где не нужен прямой доступ к Vue wrapper.

## Установка

```bash
npm install -D @testing-library/vue @testing-library/user-event @testing-library/jest-dom
```

В Vitest setup можно подключить matchers:

```ts
import '@testing-library/jest-dom/vitest';
```

## Пример компонента

```vue
<template>
  <form @submit.prevent="$emit('submit', email)">
    <label for="email">Email</label>
    <input id="email" v-model="email" />
    <button>Подписаться</button>
  </form>
</template>
```

## Тест

```ts
import { render, screen } from '@testing-library/vue';
import userEvent from '@testing-library/user-event';
import SubscribeForm from './SubscribeForm.vue';

test('submits email', async () => {
  const user = userEvent.setup();

  const { emitted } = render(SubscribeForm);

  await user.type(screen.getByLabelText('Email'), 'ann@example.com');
  await user.click(screen.getByRole('button', { name: 'Подписаться' }));

  expect(emitted().submit[0]).toEqual(['ann@example.com']);
});
```

## Plugins

```ts
render(Component, {
  global: {
    plugins: [pinia, router],
  },
});
```

Синтаксис похож на Vue Test Utils, потому что Vue Testing Library использует его под капотом.

## Когда выбрать Vue Testing Library?

Выбирай ее, если:

- хочешь тестировать как пользователь;
- важны roles/labels;
- тестируешь формы;
- хочешь меньше привязки к Vue internals;
- команде близок Testing Library-подход.

## Мини-шпаргалка

- `render` монтирует Vue-компонент.
- `screen` ищет элементы в DOM.
- `user-event` имитирует действия.
- `jest-dom` добавляет удобные DOM-matchers.
- Для emitted events можно использовать результат `render`.
