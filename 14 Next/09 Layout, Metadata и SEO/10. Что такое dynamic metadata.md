# Что такое dynamic metadata?

> [!summary]
> Dynamic metadata - это метаданные, которые генерируются на сервере через функцию `generateMetadata`. Они нужны, когда `title`, `description`, Open Graph или robots зависят от URL-параметров, query-параметров, CMS, базы данных или API.

## Как задается dynamic metadata?

Вместо объекта `metadata` экспортируется функция `generateMetadata`:

```tsx
// app/blog/[slug]/page.tsx
import type { Metadata } from 'next'

type Props = {
  params: Promise<{ slug: string }>
}

export async function generateMetadata({
  params,
}: Props): Promise<Metadata> {
  const { slug } = await params

  return {
    title: `Статья: ${slug}`,
    description: `Подробный разбор темы ${slug}`,
  }
}

export default async function BlogPostPage({ params }: Props) {
  const { slug } = await params
  return <article>{slug}</article>
}
```

В современных версиях Next.js `params` и `searchParams` в App Router могут передаваться как Promise, поэтому в примерах документации их часто ожидают через `await`.

## Пример с данными из базы или CMS

```tsx
// app/products/[id]/page.tsx
import type { Metadata } from 'next'
import { notFound } from 'next/navigation'
import { getProduct } from '@/lib/products'

type Props = {
  params: Promise<{ id: string }>
}

export async function generateMetadata({
  params,
}: Props): Promise<Metadata> {
  const { id } = await params
  const product = await getProduct(id)

  if (!product) {
    return {
      title: 'Товар не найден',
      robots: {
        index: false,
        follow: false,
      },
    }
  }

  return {
    title: product.name,
    description: product.shortDescription,
    openGraph: {
      title: product.name,
      description: product.shortDescription,
      images: [
        {
          url: product.coverUrl,
          width: 1200,
          height: 630,
        },
      ],
    },
  }
}

export default async function ProductPage({ params }: Props) {
  const { id } = await params
  const product = await getProduct(id)

  if (!product) {
    notFound()
  }

  return <main>{product.name}</main>
}
```

Так каждая страница товара получает уникальные SEO-данные.

## Можно ли переиспользовать запрос?

Да. Если `generateMetadata` и сама страница используют один и тот же `fetch`, Next.js может мемоизировать одинаковые запросы в рамках рендера.

```tsx
async function getPost(slug: string) {
  const res = await fetch(`https://api.example.com/posts/${slug}`, {
    next: { revalidate: 3600 },
  })

  if (!res.ok) return null
  return res.json()
}
```

```tsx
export async function generateMetadata({ params }: Props) {
  const { slug } = await params
  const post = await getPost(slug)

  return {
    title: post?.title ?? 'Статья не найдена',
  }
}

export default async function Page({ params }: Props) {
  const { slug } = await params
  const post = await getPost(slug)

  if (!post) notFound()
  return <article>{post.title}</article>
}
```

## Когда dynamic metadata обязательна?

Она нужна, если метаданные зависят от:

- `params`: `/blog/[slug]`, `/products/[id]`;
- `searchParams`: страницы поиска, фильтры, пагинация;
- данных из CMS;
- данных из базы;
- роли пользователя;
- языка страницы;
- наличия или отсутствия сущности.

## Нюанс производительности

`generateMetadata` выполняется на сервере. Если внутри нее медленный запрос, это может задержать формирование ответа. Поэтому:

- кешируй данные через `fetch` options;
- не делай лишние запросы;
- обрабатывай 404;
- не генерируй огромные описания;
- не тяни данные, которые не нужны для SEO;
- используй static metadata там, где она достаточна.

## Что отвечать на собеседовании?

Dynamic metadata в Next.js создается через `generateMetadata`. Эта функция выполняется на сервере и возвращает объект `Metadata`, когда SEO-данные зависят от URL, базы, CMS или API. Ее используют для статей, товаров, профилей и других динамических страниц, где у каждой сущности должен быть уникальный title, description и Open Graph.

## Частые ошибки

- Использовать dynamic metadata там, где хватило бы static metadata.
- Не обрабатывать ситуацию, когда сущность не найдена.
- Делать отдельный некешируемый запрос только для metadata.
- Забывать Open Graph image для страниц, которыми делятся в соцсетях.
- Пытаться использовать `generateMetadata` в Client Component.
- Считать, что metadata обновляются на клиенте как обычный React state.

## Мини-шпаргалка

- `generateMetadata` - функция для динамических SEO-данных.
- Работает на сервере.
- Может использовать `params` и `searchParams`.
- Подходит для `/blog/[slug]`, `/products/[id]`.
- Возвращает объект `Metadata`.
- Медленные запросы внутри metadata влияют на ответ страницы.
