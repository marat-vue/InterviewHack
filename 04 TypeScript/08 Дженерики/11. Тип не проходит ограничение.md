# Тип не проходит ограничение

> [!summary] Коротко
> Ошибка "тип не проходит ограничение" возникает, когда generic-аргумент не совместим с условием `extends`.

## Вопрос

Что значит, если тип не проходит ограничение?

## Базовый пример

```typescript
function getId<T extends { id: string }>(value: T): string {
  return value.id;
}

getId({ id: "1", name: "Анна" });
// getId({ name: "Анна" }); // ошибка
```

Второй объект не подходит, потому что у него нет обязательного поля `id`.

## Несовместимый тип поля

```typescript
getId({ id: 123 });
// ошибка: number не совместим со string
```

Ограничение требует именно `id: string`.

## Ограничение ключами

```typescript
function getProperty<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}

const user = { name: "Анна", age: 28 };

getProperty(user, "name");
// getProperty(user, "email"); // ошибка
```

`"email"` не проходит ограничение, потому что не входит в `keyof typeof user`.

## Как исправлять

Проверь, что передаваемый тип действительно имеет нужную форму. Иногда нужно расширить объект, иногда - ослабить ограничение, а иногда - выбрать другой generic.

## Мини-шпаргалка

- Ограничение задается через `extends`.
- Ошибка означает: переданный тип не совместим с требованием.
- Частые причины: нет поля, поле другого типа, ключ не входит в `keyof`.
- Не ослабляй ограничение, если оно защищает реальный контракт.
