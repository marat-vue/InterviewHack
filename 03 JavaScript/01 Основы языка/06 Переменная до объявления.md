# Переменная до объявления

> [!NOTE] Коротко
> `var` можно прочитать до строки объявления, но значение будет `undefined`. `let` и `const` тоже всплывают, но до объявления находятся в TDZ и дают `ReferenceError`.

## Вопрос

Что происходит, если использовать переменную до ее объявления? Назовите отличия между `var`, `let` и `const`.

## Почему так происходит

Перед выполнением кода JavaScript создает привязки для объявлений. Это называют hoisting - всплытием. Но разные способы объявления ведут себя по-разному.

## `var`

`var` всплывает и сразу получает значение `undefined`.

```javascript
console.log(count); // undefined

var count = 10;

console.log(count); // 10
```

Код можно представить так:

```javascript
var count;

console.log(count); // undefined

count = 10;
```

Важно: всплывает объявление, а не присваивание.

## `let`

`let` тоже всплывает, но до строки объявления переменная находится в temporal dead zone.

```javascript
console.log(count); // ReferenceError

let count = 10;
```

TDZ - это участок от начала области видимости до строки объявления.

```javascript
{
  // TDZ для value начинается здесь
  console.log(value); // ReferenceError
  let value = 1;
}
```

## `const`

`const` ведет себя как `let`, но требует сразу указать значение.

```javascript
console.log(apiUrl); // ReferenceError

const apiUrl = "/api";
```

Так нельзя:

```javascript
const token; // SyntaxError
token = "abc";
```

## Функции

Function Declaration можно вызвать до объявления:

```javascript
sayHi(); // "Hi"

function sayHi() {
  console.log("Hi");
}
```

Function Expression ведет себя как переменная:

```javascript
sayHi(); // ReferenceError

const sayHi = function () {
  console.log("Hi");
};
```

С `var` ошибка будет другой:

```javascript
sayHi(); // TypeError: sayHi is not a function

var sayHi = function () {};
```

Потому что `sayHi` уже существует, но пока равно `undefined`.

## Мини-шпаргалка

| Объявление | Можно обратиться до строки объявления? | Что будет |
| --- | --- | --- |
| `var x` | да | `undefined` |
| `let x` | нет | `ReferenceError` |
| `const x` | нет | `ReferenceError` |
| `function f() {}` | да | функция доступна |
| `const f = () => {}` | нет | `ReferenceError` |
