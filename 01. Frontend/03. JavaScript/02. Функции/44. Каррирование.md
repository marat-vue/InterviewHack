# Каррирование

> [!NOTE]
> Каррирование превращает функцию от нескольких аргументов в цепочку функций, каждая из которых принимает один аргумент: `f(a, b, c)` -> `f(a)(b)(c)`.

## Вопрос

Что такое каррирование (currying)?

## Базовый пример

Обычная функция:

```javascript
function sum(a, b, c) {
  return a + b + c;
}

sum(1, 2, 3); // 6
```

Каррированная:

```javascript
function curriedSum(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

curriedSum(1)(2)(3); // 6
```

## Стрелочный вариант

```javascript
const curriedSum = (a) => (b) => (c) => a + b + c;

curriedSum(1)(2)(3); // 6
```

## Зачем нужно

Каррирование позволяет создавать специализированные функции.

```javascript
const multiply = (a) => (b) => a * b;

const double = multiply(2);
const triple = multiply(3);

double(10); // 20
triple(10); // 30
```

Первая функция запоминает `a` через замыкание.

## Каррирование vs частичное применение

Каррирование всегда разбивает функцию на цепочку по одному аргументу:

```javascript
f(a, b, c) -> f(a)(b)(c)
```

Частичное применение просто фиксирует часть аргументов:

```javascript
f(a, b, c) -> g(b, c)
```

## Когда полезно

- настройка функций;
- функциональная композиция;
- переиспользование общих функций;
- создание предикатов для `filter`;
- обработчики с заранее заданными параметрами.

## Мини-шпаргалка

```javascript
const add = (a) => (b) => a + b;

const add10 = add(10);
add10(5); // 15
```

| Термин | Смысл |
| --- | --- |
| currying | `f(a)(b)(c)` |
| closure | запоминает предыдущие аргументы |
| partial application | фиксирует часть аргументов |
