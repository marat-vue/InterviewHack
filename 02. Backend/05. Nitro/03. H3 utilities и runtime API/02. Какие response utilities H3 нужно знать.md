# Какие response utilities H3 нужно знать?

> [!NOTE]
> Response utilities H3 помогают явно формировать ответ: HTML, streams, empty response, redirects, static assets, disposal callbacks и early hints. В простых API чаще всего хватает return object, но utilities нужны для нестандартных ответов.

## Основная идея

В Nitro можно просто вернуть object:

```ts
export default defineHandler(() => {
  return {
    ok: true,
  };
});
```

Но когда нужен особый response behavior, используются H3 helpers.

## Event stream

| Метод | Зачем нужен |
|---|---|
| `EventStream()` | создать event stream для streaming/SSE-like сценариев |
| `isEventStream(input)` | проверить, является ли значение event stream |

Используется для live updates, прогресса задач, streaming endpoints.

## HTML utilities

| Метод | Зачем нужен |
|---|---|
| `html(first)` | вернуть HTML response с безопасной вставкой значений |
| `raw(value)` | пометить строку как доверенный HTML |

Пример:

```ts
import { html } from 'h3';

export default defineHandler(() => {
  const title = 'Nitro';

  return html`<h1>${title}</h1>`;
});
```

`raw` используй только для HTML, который полностью контролируешь сам. Пользовательский input через `raw` - XSS риск.

## Stream utility

| Метод | Зачем нужен |
|---|---|
| `iterable(iterable)` | вернуть stream из sync/async iterable |

Пример:

```ts
import { iterable } from 'h3';

export default defineHandler(() => {
  return iterable(async function* () {
    yield 'step 1\n';
    yield 'step 2\n';
    return 'done\n';
  });
});
```

Важно: headers и status нужно выставить до первого chunk.

## Empty response

| Метод | Зачем нужен |
|---|---|
| `noContent(status?)` | вернуть пустой response |

Пример:

```ts
import { noContent } from 'h3';

export default defineHandler(async (event) => {
  await userService.remove(getRouterParam(event, 'id'));

  return noContent(204);
});
```

## Redirect utilities

| Метод | Зачем нужен |
|---|---|
| `redirect(location, status?, statusText?)` | отправить redirect |
| `redirectBack(event, options?)` | вернуть пользователя назад по same-origin referer или fallback |

Пример:

```ts
import { redirect } from 'h3';

export default defineHandler(() => {
  return redirect('/login');
});
```

Безопасность: redirect target из query/body нужно проверять по allowlist.

## Static assets

| Метод | Зачем нужен |
|---|---|
| `serveStatic(event, options)` | динамически отдавать static assets |

Обычно static assets лучше отдавать через Nitro assets/public assets, но `serveStatic` полезен для custom storage, generated files, protected downloads.

## Lifecycle callback

| Метод | Зачем нужен |
|---|---|
| `onDispose(event, cb)` | выполнить callback, когда event полностью завершен |

Пример:

```ts
import { onDispose } from 'h3';

export default defineHandler((event) => {
  const interval = setInterval(() => {}, 1000);

  onDispose(event, () => {
    clearInterval(interval);
  });

  return {
    ok: true,
  };
});
```

Полезно для cleanup, streaming и abort-aware интеграций.

## Sanitize utilities

| Метод | Зачем нужен |
|---|---|
| `sanitizeStatusCode(statusCode?, defaultStatusCode)` | проверить и нормализовать HTTP status code |
| `sanitizeStatusMessage(statusMessage)` | сделать status message безопасным для response |

Нужны редко, чаще внутри framework/library code.

## Early hints

| Метод | Зачем нужен |
|---|---|
| `writeEarlyHints(event, hints)` | отправить `103 Early Hints` или fallback headers |

Используют для performance optimization, например preload важных assets.

## Мини-шпаргалка

- JSON обычно возвращают простым object.
- `html` - HTML response.
- `raw` - только для доверенного HTML.
- `iterable` - streaming.
- `noContent` - 204/empty response.
- `redirect` и `redirectBack` - redirects.
- `onDispose` - cleanup после request.
- `serveStatic` - custom static serving.
