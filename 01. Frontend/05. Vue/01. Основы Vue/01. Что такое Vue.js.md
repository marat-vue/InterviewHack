# Что такое Vue.js?

> [!NOTE]
> Vue.js - прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. Он связывает данные приложения с DOM и автоматически обновляет страницу, когда состояние меняется.

## Вопрос

Что такое Vue.js?

## Главная идея

Vue помогает описывать интерфейс декларативно: ты описываешь, как UI должен выглядеть при конкретном состоянии, а Vue сам применяет изменения к DOM.

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">
    Нажато: {{ count }}
  </button>
</template>
```

Когда `count` меняется, Vue обновляет текст кнопки.

## Почему Vue называют прогрессивным

Vue можно использовать по-разному: подключить к небольшой части страницы, собрать полноценное SPA, писать компоненты через Single File Components или использовать экосистему с Vue Router и Pinia.

## Из чего состоит Vue-приложение

- Компоненты описывают куски интерфейса.
- Реактивность связывает состояние и UI.
- Директивы добавляют поведение в шаблон.
- Props и events связывают родителя и ребенка.
- Router и store помогают строить большие приложения.

## Мини-шпаргалка

- Vue = фреймворк для UI.
- Главная сила - реактивность и компоненты.
- Шаблон описывает HTML, связанный с данными.
- Vue 3 чаще пишут через Composition API и `<script setup>`.
