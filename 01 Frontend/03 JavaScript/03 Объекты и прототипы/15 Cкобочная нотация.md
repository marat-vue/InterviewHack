# Скобочная нотация

> [!NOTE] Коротко
> Скобочная нотация `obj[key]` позволяет обращаться к свойствам по строке, переменной, выражению или ключу, который нельзя записать через точку.

## Вопрос

Как обратиться к свойству через скобочную нотацию?

## Синтаксис

```javascript
obj["prop"];
obj[key];
```

Пример:

```javascript
const user = {
  name: "Anna",
};

user["name"]; // "Anna"
```

## Динамический ключ

```javascript
const key = "name";

user[key]; // "Anna"
```

Через точку так не получится:

```javascript
user.key; // ищет свойство "key", а не значение переменной key
```

## Сложные имена свойств

```javascript
const obj = {
  "user-name": "anna",
  "first name": "Anna",
};

obj["user-name"];  // "anna"
obj["first name"]; // "Anna"
```

Через точку такие свойства читать нельзя.

## Выражение внутри скобок

```javascript
const prefix = "user";
const obj = {
  userName: "Anna",
};

obj[prefix + "Name"]; // "Anna"
```

## Symbol-ключ

```javascript
const id = Symbol("id");
const user = {
  [id]: 123,
};

user[id]; // 123
```

## Мини-шпаргалка

| Запись | Что делает |
| --- | --- |
| `obj.name` | свойство `name` |
| `obj["name"]` | свойство `name` |
| `obj[key]` | свойство из переменной |
| `obj["first name"]` | сложный ключ |
| `obj[symbol]` | symbol-ключ |
