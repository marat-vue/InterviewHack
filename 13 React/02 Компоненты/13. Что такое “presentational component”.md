# Что такое presentational component?

> [!summary]
> Presentational component - это компонент, который в основном отвечает за отображение UI. Он получает данные через props, не знает, откуда они пришли, и обычно не содержит сложной бизнес-логики или запросов к API.

## Простое определение

Presentational component отвечает на вопрос:

```text
Как показать переданные данные?
```

Пример:

```jsx
function UserCard({ name, role, avatarUrl, onSelect }) {
  return (
    <article className="user-card">
      <img src={avatarUrl} alt="" />
      <h2>{name}</h2>
      <p>{role}</p>
      <button onClick={onSelect}>Открыть</button>
    </article>
  )
}
```

Компонент не знает, пришел пользователь из API, localStorage или моков.

## Почему это удобно?

- Легче переиспользовать.
- Легче тестировать.
- Легче показывать в Storybook.
- Меньше зависимости от инфраструктуры.
- UI не смешивается с получением данных.

## Может ли presentational component иметь state?

Да, если это локальное UI-состояние:

- открыт dropdown;
- активная вкладка;
- hover/focus-состояние, если оно нужно в JS;
- временное значение input.

Но если компонент начинает сам получать данные, решать бизнес-правила и знать про API, он становится менее presentational.

## Presentational vs dumb

Термин `dumb component` устаревший и не очень удачный. Лучше говорить `presentational` или `UI component`.

Так точнее: компонент не "глупый", он просто отвечает за отображение.

## Мини-шпаргалка

- Presentational component показывает данные.
- Данные приходят через props.
- Он не должен знать источник данных.
- Локальное UI-состояние допустимо.
- Такой компонент удобно тестировать и документировать.
