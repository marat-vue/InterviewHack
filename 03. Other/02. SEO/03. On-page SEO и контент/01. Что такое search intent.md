# Что такое search intent?

> [!summary]
> Search intent - это намерение пользователя за поисковым запросом. Страница может быть технически идеальной, но плохо ранжироваться, если не отвечает на то, зачем человек ввел запрос.

## Какие бывают типы intent?

| Тип | Что хочет пользователь | Пример запроса |
|---|---|---|
| Informational | узнать | `что такое SSR` |
| Navigational | попасть на сайт | `nuxt docs` |
| Commercial | сравнить перед покупкой | `лучшие CRM для малого бизнеса` |
| Transactional | купить или выполнить действие | `купить macbook pro 14` |
| Local | найти рядом | `ремонт ноутбуков рядом` |

## Как понять intent?

Нужно посмотреть:

- какие страницы уже ранжируются;
- какой формат результата преобладает;
- нужны ли инструкции, карточки товара, сравнения или каталог;
- есть ли локальный блок;
- есть ли видео, изображения, FAQ, reviews.

Пример:

```text
Запрос: "как настроить robots txt"
Ожидание: пошаговая инструкция, примеры, ошибки, проверка.
```

```text
Запрос: "robots txt генератор"
Ожидание: инструмент, а не статья.
```

## Почему intent важнее количества ключей?

Раньше часто пытались "набить" текст ключевыми словами. Сейчас важнее закрыть задачу пользователя.

Плохой подход:

```text
SEO аудит заказать SEO аудит цена SEO аудит Москва
```

Хороший подход:

```text
Страница объясняет, что входит в аудит, кому он нужен, сколько длится, какие артефакты клиент получит и какие проблемы обычно находятся.
```

## Мини-шпаргалка

- Search intent отвечает на вопрос "зачем пользователь это ищет?".
- Формат страницы должен соответствовать намерению.
- Один ключ может требовать статью, другой - товарную страницу.
- Нельзя заменить intent плотностью ключевых слов.
- Анализ выдачи помогает понять ожидания пользователя.
