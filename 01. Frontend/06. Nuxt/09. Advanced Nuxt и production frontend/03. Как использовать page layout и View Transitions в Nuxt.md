# Как использовать page, layout и View Transitions в Nuxt?

> [!NOTE]
> Nuxt умеет анимировать переходы между страницами и layout через Vue `<Transition>`, а также использовать browser View Transitions. Это полезно для polished UX, но может ломаться при неправильной структуре root elements и слишком тяжелых анимациях.

## Page transition

Глобальная настройка:

```ts
export default defineNuxtConfig({
  app: {
    pageTransition: {
      name: 'page',
      mode: 'out-in'
    }
  }
})
```

CSS:

```css
.page-enter-active,
.page-leave-active {
  transition: opacity 180ms ease, transform 180ms ease;
}

.page-enter-from,
.page-leave-to {
  opacity: 0;
  transform: translateY(4px);
}
```

`app.vue`:

```vue
<template>
  <NuxtPage />
</template>
```

## Transition для одной страницы

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'fade',
    mode: 'out-in'
  }
})
</script>

<template>
  <main>
    <h1>Каталог</h1>
  </main>
</template>
```

CSS classes должны совпадать с `name`:

```css
.fade-enter-active,
.fade-leave-active {
  transition: opacity 160ms ease;
}

.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
```

## Layout transition

```ts
export default defineNuxtConfig({
  app: {
    layoutTransition: {
      name: 'layout',
      mode: 'out-in'
    }
  }
})
```

`app.vue`:

```vue
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

Page:

```vue
<script setup lang="ts">
definePageMeta({
  layout: 'account'
})
</script>
```

## Главное ограничение: один root element

Плохо:

```vue
<template>
  <h1>Title</h1>
  <p>Text</p>
</template>
```

Хорошо:

```vue
<template>
  <main>
    <h1>Title</h1>
    <p>Text</p>
  </main>
</template>
```

Для transitions страница или layout должны иметь один root element. HTML comment тоже может считаться node и мешать.

## Отключение transitions

Для страницы:

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: false,
  layoutTransition: false
})
</script>
```

Глобально:

```ts
export default defineNuxtConfig({
  app: {
    pageTransition: false,
    layoutTransition: false
  }
})
```

## Dynamic transitions

Можно менять transition по направлению навигации:

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'slide-right',
    mode: 'out-in'
  },
  middleware(to, from) {
    if (
      typeof to.meta.pageTransition === 'object' &&
      typeof from.params.id === 'string' &&
      typeof to.params.id === 'string'
    ) {
      to.meta.pageTransition.name =
        Number(to.params.id) > Number(from.params.id)
          ? 'slide-left'
          : 'slide-right'
    }
  }
})
</script>
```

## JavaScript hooks

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'custom',
    mode: 'out-in',
    onBeforeEnter(el) {
      el.classList.add('is-entering')
    },
    onAfterEnter(el) {
      el.classList.remove('is-entering')
    }
  }
})
</script>
```

JS hooks нужны, когда CSS недостаточно: timeline, GSAP, focus management, metrics.

## View Transitions

Browser View Transitions могут дать более нативный переход между состояниями страницы. Их используют осторожно:

```ts
export default defineNuxtConfig({
  app: {
    viewTransition: true
  }
})
```

Проверяй поддержку браузеров и делай graceful fallback. Для обычных проектов часто достаточно Vue transitions.

## Что отвечать на собеседовании?

Nuxt page/layout transitions построены вокруг Vue `<Transition>`. Глобально они задаются в `nuxt.config.ts`, а для отдельной страницы переопределяются через `definePageMeta`. Страница должна иметь один root element. Для сложных сценариев можно использовать JS hooks или browser View Transitions, но анимации не должны ухудшать navigation performance.

## Частые ошибки

- Делать несколько root elements на странице.
- Задать `name: 'fade'`, но написать CSS classes для `.page-*`.
- Анимировать layout shift тяжелыми свойствами вроде `height`.
- Использовать View Transitions без fallback.
- Забыть отключить transition на страницах, где он мешает UX.
- Делать долгие transition, блокирующие навигацию.

## Мини-шпаргалка

- Global page: `app.pageTransition`.
- Global layout: `app.layoutTransition`.
- Per page: `definePageMeta`.
- CSS classes: `{name}-enter-active`.
- Root: один element.
- View Transitions: красиво, но проверяй поддержку.
