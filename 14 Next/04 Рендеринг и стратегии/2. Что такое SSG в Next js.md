# Что такое SSG в Next js?

> [!summary]
> SSG в Next.js - статическая генерация HTML заранее, обычно во время build. В App Router статический rendering часто выбирается автоматически, если route не зависит от request-specific данных и использует кешируемые данные.

## Как работает SSG?

1. Next.js выполняет route до запроса пользователя.
2. Создает HTML и RSC payload.
3. Сохраняет результат в build/cache.
4. Пользователь получает готовый контент очень быстро.

## Пример статической страницы

```tsx
export default function AboutPage() {
  return (
    <main>
      <h1>About us</h1>
      <p>Static marketing content.</p>
    </main>
  )
}
```

## Пример с данными

```tsx
export default async function BlogPage() {
  const posts = await fetch('https://api.example.com/posts', {
    cache: 'force-cache',
  }).then((res) => res.json())

  return <PostList posts={posts} />
}
```

Кешируемый `fetch` помогает сохранить статическую стратегию.

## Когда использовать SSG?

- маркетинговые страницы;
- документация;
- блог;
- changelog;
- справочники;
- публичные страницы без персонализации.

## Сильные стороны

- быстрый TTFB;
- хорошо кешируется CDN;
- меньше нагрузки на сервер;
- хороший SEO;
- простая инфраструктура.

## Ограничения

SSG плохо подходит, если:

- контент зависит от пользователя;
- нужны cookies/headers;
- данные должны быть свежими на каждый request;
- страниц слишком много и build становится огромным;
- нужны real-time изменения.

## Что отвечать на собеседовании?

SSG - это предварительная генерация страницы. В Next.js App Router route может быть статическим автоматически, если не использует динамические данные. SSG отлично подходит для публичного стабильного контента, но не для персонализированных страниц.

## Частые ошибки

- Использовать SSG для личного кабинета.
- Не думать о build time.
- Путать SSG и ISR.
- Считать, что static page вообще не может иметь Client Components.
- Забывать обновление контента.

## Мини-шпаргалка

- SSG = HTML заранее.
- Хорошо для SEO и CDN.
- Не подходит для request-specific данных.
- Dynamic routes генерируются через `generateStaticParams`.
- Для обновления после build есть ISR.
