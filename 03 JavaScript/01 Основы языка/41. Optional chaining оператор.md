# Optional chaining `?.`

> [!summary] Коротко
> Optional chaining позволяет безопасно читать свойства, вызывать методы и обращаться к элементам, если часть цепочки может быть `null` или `undefined`.

## Вопрос

Optional chaining оператор. Для чего нужен?

## Основная идея

Без `?.` код падает, если промежуточное значение отсутствует.

```javascript
const user = {};

user.address.city; // TypeError
```

С optional chaining выражение вернет `undefined`.

```javascript
user.address?.city; // undefined
```

## Чтение свойств

```javascript
const city = user?.profile?.address?.city;
```

Если `user`, `profile` или `address` равны `null`/`undefined`, результатом будет `undefined`.

## Вызов методов

```javascript
user.sayHi?.();
```

Метод вызовется только если `sayHi` существует.

## Доступ к элементам

```javascript
const firstItem = items?.[0];
```

Полезно, когда массив может отсутствовать.

## С `??`

Optional chaining часто используют вместе с nullish coalescing.

```javascript
const city = user?.address?.city ?? "Город не указан";
```

## Подводный камень

`?.` защищает только место, где стоит оператор.

```javascript
user?.address.city;
```

Если `user` отсутствует, ошибки не будет. Но если `user` есть, а `address` отсутствует, будет `TypeError`. Безопаснее:

```javascript
user?.address?.city;
```

## Мини-шпаргалка

```javascript
obj?.prop;       // безопасное чтение свойства
obj?.[key];      // безопасное чтение по ключу
fn?.();          // безопасный вызов функции
obj?.method?.(); // безопасный вызов метода
value ?? "x";    // значение по умолчанию для null/undefined
```
