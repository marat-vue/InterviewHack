# Как трансформировать response через interceptor?

> [!summary]
> Interceptor может изменить данные, которые вернул controller, до отправки клиенту. Это удобно для единого wrapper-формата, serialization, удаления лишних полей или добавления metadata.

## Пример wrapper

```ts
@Injectable()
export class ResponseInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler) {
    return next.handle().pipe(
      map((data) => ({
        data,
        timestamp: new Date().toISOString(),
      })),
    );
  }
}
```

## Глобальное применение

```ts
app.useGlobalInterceptors(new ResponseInterceptor());
```

## Осторожно

Не все responses удобно оборачивать:

- file download;
- stream;
- redirects;
- raw response через `@Res()`.

## ClassSerializerInterceptor

NestJS также предоставляет `ClassSerializerInterceptor`, который работает с `class-transformer` и помогает сериализовать class instances.

## Мини-шпаргалка

- Interceptor может менять response body.
- Использует RxJS `map`.
- Глобальный wrapper должен учитывать streams/files.
- `ClassSerializerInterceptor` помогает скрывать поля.
- `@Res()` может обходить стандартный flow.
