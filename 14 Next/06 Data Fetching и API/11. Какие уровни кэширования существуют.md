# Какие уровни кэширования существуют?

> [!summary]
> В Next.js App Router важно понимать несколько уровней: request memoization, Data Cache, Full Route Cache, Router Cache, Image Optimization Cache и внешние CDN/browser caches. Они решают разные задачи и инвалидируются по-разному.

## Request memoization

В рамках одного render pass одинаковые запросы могут не выполняться повторно.

```tsx
const userA = await getUser(id)
const userB = await getUser(id)
```

Это помогает избежать дублирования внутри одного render tree.

## Data Cache

Сохраняет результаты server `fetch`.

```tsx
await fetch(url, {
  next: { revalidate: 3600 },
})
```

Data Cache управляется через `cache`, `revalidate`, `tags`.

## Full Route Cache

Сохраняет результат статически отрендеренного route: HTML и RSC output.

Хорошо подходит для:

- SSG;
- ISR;
- публичных страниц;
- контента без request-specific данных.

## Router Cache

Клиентский cache в браузере для RSC payload при навигации. Он помогает быстрее возвращаться и переходить между routes.

`router.refresh()` может запросить актуальный route payload заново.

## Image Optimization Cache

`next/image` может кешировать оптимизированные версии изображений.

## Внешние cache layers

Кроме Next.js, могут быть:

- CDN;
- browser HTTP cache;
- reverse proxy;
- database cache;
- TanStack Query client cache.

## Что отвечать на собеседовании?

У Next.js несколько уровней кеширования. Data Cache хранит результаты `fetch`, Full Route Cache хранит статический route output, Router Cache работает на клиенте для навигации, request memoization убирает дубли в рамках render, а Image Cache хранит оптимизированные изображения.

## Частые ошибки

- Смешивать Data Cache и Router Cache.
- Думать, что `router.refresh()` очищает все серверные кеши.
- Не понимать, почему в dev и production cache ведет себя по-разному.
- Кешировать private data.
- Забывать external CDN/browser cache.

## Мини-шпаргалка

- Request memoization - один render pass.
- Data Cache - server fetch.
- Full Route Cache - static route output.
- Router Cache - client navigation.
- Image Cache - optimized images.
- CDN/browser cache - вне Next.js.
