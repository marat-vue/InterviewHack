# Что значат HttpOnly, Secure, SameSite, Path, Domain и Max-Age?

> [!summary]
> Cookie attributes управляют тем, кто может прочитать cookie, когда она отправляется, для каких путей и доменов действует, сколько живет и можно ли отправлять ее только по HTTPS.

## Пример Set-Cookie

```http
Set-Cookie: sid=abc; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=3600
```

## HttpOnly

`HttpOnly` запрещает JavaScript читать cookie через `document.cookie`.

```http
Set-Cookie: sid=abc; HttpOnly
```

Это снижает риск кражи session id или refresh token при XSS. Но `HttpOnly` не мешает браузеру автоматически отправлять cookie в requests.

## Secure

`Secure` означает, что cookie должна отправляться только по HTTPS.

```http
Set-Cookie: sid=abc; Secure
```

Для auth cookies в production `Secure` почти всегда обязателен.

## SameSite

`SameSite` управляет отправкой cookie в cross-site контексте.

| Значение | Смысл |
|---|---|
| `Strict` | cookie отправляется только в same-site переходах |
| `Lax` | баланс безопасности и удобства, подходит для многих session cookies |
| `None` | cookie можно отправлять cross-site, но нужен `Secure` |

`SameSite` помогает против CSRF, но не заменяет CSRF-токены для чувствительных действий.

## Path

```http
Set-Cookie: admin_sid=abc; Path=/admin
```

Cookie будет отправляться только для подходящих путей.

## Domain

```http
Set-Cookie: sid=abc; Domain=example.com
```

`Domain` определяет, для какого домена и поддоменов действует cookie. Если не указывать `Domain`, cookie обычно будет host-only.

## Max-Age и Expires

```http
Set-Cookie: sid=abc; Max-Age=3600
```

`Max-Age` задает время жизни в секундах. `Expires` задает конкретную дату истечения.

Session cookie без `Max-Age`/`Expires` обычно живет до закрытия browser session, но поведение может зависеть от браузера и восстановления вкладок.

## Мини-шпаргалка

- `HttpOnly` скрывает cookie от JavaScript.
- `Secure` разрешает отправку только по HTTPS.
- `SameSite` ограничивает cross-site отправку.
- `Path` ограничивает URL path.
- `Domain` ограничивает domain scope.
- `Max-Age` и `Expires` задают срок жизни.
