# Как спроектировать CRUD API на Nitro, Prisma и Better Auth?

> [!NOTE]
> Хороший CRUD API на Nitro строится слоями: route отвечает за HTTP, validation и auth; service отвечает за бизнес-логику; repository/Prisma отвечает за БД; Better Auth отвечает за session; Vitest проверяет правила и интеграции.

## Структура проекта

```txt
server/
  api/
    posts/
      index.get.ts
      index.post.ts
      [id].get.ts

  services/
    postService.ts
    permissionService.ts
  repositories/

  utils/
    auth.ts
    prisma.ts
    require-auth.ts
```

## Prisma schema

```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  name      String?
  posts     Post[]
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

model Post {
  id        String   @id @default(cuid())
  title     String
  content   String
  published Boolean  @default(false)
  authorId  String
  author    User     @relation(fields: [authorId], references: [id])
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([authorId, createdAt])
}
```

## Validation schemas

```ts
// server/schemas/post.ts
import { z } from 'zod';

export const createPostSchema = z.object({
  title: z.string().min(1).max(120),
  content: z.string().min(1),
  published: z.boolean().default(false),
});

export const updatePostSchema = createPostSchema.partial();

export const listPostsQuerySchema = z.object({
  page: z.coerce.number().int().positive().default(1),
  limit: z.coerce.number().int().min(1).max(100).default(20),
});
```

## Repository

```ts
// server/repositories/postRepository.ts
export const postRepository = {
  findMany({ skip, take }: { skip: number; take: number }) {
    return prisma.post.findMany({
      skip,
      take,
      orderBy: [
        { createdAt: 'desc' },
        { id: 'asc' },
      ],
      select: {
        id: true,
        title: true,
        published: true,
        createdAt: true,
      },
    });
  },

  findById(id: string) {
    return prisma.post.findUnique({
      where: { id },
    });
  },
};
```

## Service

```ts
// server/services/postService.ts
export const postService = {
  async create(userId: string, data: CreatePostInput) {
    return prisma.post.create({
      data: {
        ...data,
        authorId: userId,
      },
    });
  },

  async update(userId: string, postId: string, data: UpdatePostInput) {
    const post = await prisma.post.findUnique({
      where: { id: postId },
    });

    if (!post) {
      throw createError({ statusCode: 404, statusMessage: 'Post not found' });
    }

    if (post.authorId !== userId) {
      throw createError({ statusCode: 403, statusMessage: 'Forbidden' });
    }

    return prisma.post.update({
      where: { id: postId },
      data,
    });
  },
};
```

## Route

```ts
// server/api/posts/index.post.ts
export default defineEventHandler(async (event) => {
  const session = await requireAuth(event);
  const body = await readValidatedBody(event, createPostSchema);

  event.res.status = 201;

  return postService.create(session.user.id, body);
});
```

## Мини-шпаргалка

- Handler - HTTP/auth/validation.
- Service - business rules.
- Repository/Prisma - database access.
- Better Auth - session.
- Zod - runtime validation.
- Vitest - services/validation/guards.
- `@nuxt/test-utils` - Nuxt/Nitro API integration.
