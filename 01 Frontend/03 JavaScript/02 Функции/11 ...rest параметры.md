# Rest-параметры

> [!NOTE]
> Rest-параметр `...args` собирает оставшиеся аргументы функции в настоящий массив. Он должен быть последним параметром.

## Вопрос

Что такое rest-параметры и как они работают?

## Базовый пример

```javascript
function sum(...numbers) {
  return numbers.reduce((total, number) => total + number, 0);
}

sum(1, 2, 3); // 6
```

`numbers` - обычный массив.

## Rest собирает оставшиеся аргументы

```javascript
function createUser(name, ...roles) {
  return {
    name,
    roles,
  };
}

createUser("Anna", "admin", "editor");
// { name: "Anna", roles: ["admin", "editor"] }
```

Первый аргумент попал в `name`, остальные - в `roles`.

## Rest всегда последний

Так можно:

```javascript
function fn(first, ...rest) {}
```

Так нельзя:

```javascript
function fn(...rest, last) {}
// SyntaxError
```

Иначе JavaScript не поймет, какие аргументы должны попасть в `rest`, а какие в `last`.

## Rest vs `arguments`

```javascript
function oldStyle() {
  return Array.from(arguments).map((value) => value * 2);
}

function modernStyle(...args) {
  return args.map((value) => value * 2);
}
```

Rest-параметры обычно удобнее и понятнее.

## Rest в стрелочных функциях

```javascript
const sum = (...numbers) => {
  return numbers.reduce((total, number) => total + number, 0);
};
```

Это основной способ получить все аргументы в arrow function.

## Мини-шпаргалка

```javascript
function fn(...args) {}          // все аргументы
function fn(first, ...rest) {}   // первый отдельно, остальные массивом
const fn = (...args) => args;    // работает в arrow function
```

| Особенность | Rest |
| --- | --- |
| Синтаксис | `...name` |
| Тип | массив |
| Позиция | только последний параметр |
| Замена | часто заменяет `arguments` |
