# Как обойти двумерный массив?

> [!NOTE]
> Двумерный массив обычно обходят вложенными циклами: внешний цикл идет по строкам, внутренний - по элементам строки.

## Вопрос

Как перебрать все элементы матрицы?

## Классический обход с индексами

```javascript
const matrix = [
  [1, 2],
  [3, 4],
];

for (let row = 0; row < matrix.length; row++) {
  for (let col = 0; col < matrix[row].length; col++) {
    console.log(matrix[row][col]);
  }
}
```

Такой вариант нужен, когда важны координаты элемента: номер строки и номер столбца.

## Обход значений через for...of

```javascript
for (const row of matrix) {
  for (const value of row) {
    console.log(value);
  }
}
```

Этот способ короче и читается лучше, если индексы не нужны.

## Обход через forEach

```javascript
matrix.forEach((row, rowIndex) => {
  row.forEach((value, columnIndex) => {
    console.log(value, rowIndex, columnIndex);
  });
});
```

`forEach` удобен для простого выполнения действия над каждым элементом, но из него нельзя выйти через `break`.

## Пример: сумма всех чисел

```javascript
const sum = matrix.flat().reduce((total, number) => total + number, 0);

console.log(sum); // 10
```

Для глубокой вложенности вместо `flat()` можно использовать `flat(Infinity)`.

## Мини-шпаргалка

```javascript
for (const row of matrix) {
  for (const item of row) {
    // item - текущий элемент
  }
}
```
