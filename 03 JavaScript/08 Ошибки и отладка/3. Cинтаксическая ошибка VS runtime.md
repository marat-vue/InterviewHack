# Cинтаксическая ошибка VS runtime

> [!summary] Коротко
> Синтаксическая ошибка возникает при разборе кода, а runtime-ошибка возникает уже во время выполнения.

## Вопрос

Чем синтаксическая ошибка отличается от ошибки времени выполнения?

## Синтаксическая ошибка

Синтаксическая ошибка означает, что код написан с нарушением грамматики JavaScript. Движок не может корректно разобрать такой файл или скрипт.

```javascript
if (true {
  console.log('broken');
}
```

Здесь пропущена закрывающая скобка после `true`.

## Runtime-ошибка

Runtime-ошибка возникает во время выполнения кода, когда синтаксис корректный, но операция невозможна.

```javascript
const user = null;

console.log(user.name); // TypeError
```

Код синтаксически правильный, но у `null` нельзя прочитать свойство.

## Сравнение

| Критерий | Syntax error | Runtime error |
| --- | --- | --- |
| Когда возникает | при парсинге | во время выполнения |
| Код запускается | обычно нет | запускается до проблемного места |
| Пример | пропущенная скобка | обращение к `null.name` |
| Типичная ошибка | `SyntaxError` | `TypeError`, `ReferenceError` |

## Можно ли поймать try...catch

Runtime-ошибки внутри `try` можно поймать.

```javascript
try {
  JSON.parse('{ broken }');
} catch (error) {
  console.log(error.name); // 'SyntaxError'
}
```

Это `SyntaxError`, но она возникает во время выполнения `JSON.parse`, поэтому ловится.

## Мини-шпаргалка

```text
Syntax error: код не разобрался
Runtime error: код запустился, но сломался в процессе
```
