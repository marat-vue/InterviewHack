# Что делает “Control Props” паттерн?

> [!summary]
> Control Props - это паттерн для компонентов, которые могут работать в двух режимах: controlled и uncontrolled. Родитель может полностью управлять состоянием через props, но если props не переданы, компонент управляет состоянием сам.

## Зачем нужен паттерн?

Он позволяет сделать компонент гибким.

Простой сценарий:

```jsx
<Toggle defaultOn />
```

Сложный сценарий:

```jsx
<Toggle on={isEnabled} onChange={setIsEnabled} />
```

Один компонент подходит и для быстрого использования, и для строгого внешнего контроля.

## Реализация Toggle

```jsx
function Toggle({ on: controlledOn, defaultOn = false, onChange }) {
  const [uncontrolledOn, setUncontrolledOn] = useState(defaultOn)
  const isControlled = controlledOn !== undefined
  const on = isControlled ? controlledOn : uncontrolledOn

  function setOn(nextOn) {
    if (!isControlled) {
      setUncontrolledOn(nextOn)
    }

    onChange?.(nextOn)
  }

  return (
    <button onClick={() => setOn(!on)}>
      {on ? 'On' : 'Off'}
    </button>
  )
}
```

## Uncontrolled использование

```jsx
<Toggle defaultOn onChange={(value) => console.log(value)} />
```

Компонент хранит состояние внутри себя.

## Controlled использование

```jsx
function Settings() {
  const [notificationsEnabled, setNotificationsEnabled] = useState(false)

  return (
    <Toggle
      on={notificationsEnabled}
      onChange={setNotificationsEnabled}
    />
  )
}
```

Родитель хранит состояние и передает его компоненту.

## Как назвать props?

Для input-подобных компонентов часто используют:

```text
value
defaultValue
onChange
```

Для boolean-компонентов:

```text
open
defaultOpen
onOpenChange
```

или:

```text
checked
defaultChecked
onCheckedChange
```

Важно соблюдать пару `controlled value` + `change callback`.

## Важное правило

Компонент не должен менять режим во время жизни.

Плохо:

```jsx
<Toggle on={maybeValue} />
```

Если `maybeValue` сначала `undefined`, а потом `true`, компонент переключится из uncontrolled в controlled.

## Мини-шпаргалка

- Control Props дают controlled и uncontrolled режимы.
- Controlled: значение приходит через prop.
- Uncontrolled: значение хранится внутри.
- `defaultValue` задает только начальное состояние.
- Нельзя случайно менять режим во время жизни компонента.
