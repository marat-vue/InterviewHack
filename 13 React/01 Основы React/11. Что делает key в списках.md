# Что делает `key` в списках?

> [!summary]
> `key` помогает React понять, какой элемент списка соответствует какому элементу данных между render. Без стабильных ключей React может неправильно переиспользовать DOM и состояние компонентов при добавлении, удалении или сортировке элементов.

## Базовый пример

```jsx
function UserList({ users }) {
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  )
}
```

`key={user.id}` говорит React:

```text
Эта li относится именно к пользователю с таким id.
```

## Почему key нужен?

Представь список:

```text
1. Анна
2. Борис
3. Виктор
```

Если в начало добавили нового пользователя, React должен понять:

```text
Новый элемент добавился в начало, а старые элементы просто сдвинулись.
```

С хорошими ключами React сопоставляет элементы по id. Без ключей или с плохими ключами он может сопоставить их по позиции.

## Почему index - плохой key?

```jsx
{users.map((user, index) => (
  <UserCard key={index} user={user} />
))}
```

Индекс можно использовать только если список:

- статичный;
- не сортируется;
- не фильтруется;
- элементы не добавляются в середину или начало;
- у элементов нет локального состояния.

Если список изменяется, `index` может привести к багам.

## Пример бага

Есть список input:

```jsx
{tasks.map((task, index) => (
  <TaskInput key={index} task={task} />
))}
```

Пользователь ввел текст во второй input. Потом первый элемент удалили. React может переиспользовать состояние не для той задачи, потому что ключи по индексам сдвинулись.

## Каким должен быть хороший key?

Хороший key:

- уникален среди соседей;
- стабилен между render;
- основан на данных;
- не генерируется на лету через `Math.random()`;
- не меняется без причины.

Пример:

```jsx
<ProductCard key={product.slug} product={product} />
```

## Мини-шпаргалка

- `key` нужен React для сопоставления элементов списка.
- Key должен быть стабильным и уникальным среди соседей.
- `index` опасен для изменяемых списков.
- `Math.random()` как key ломает переиспользование.
- Хорошие keys уменьшают баги с состоянием и DOM.
