# Чем SVG отличается от растровых изображений?

> [!NOTE]
> SVG - это векторный формат, который описывает фигуры и линии, а растровые изображения состоят из пикселей. Поэтому SVG хорошо масштабируется, а растр лучше подходит для фотографий и сложных изображений.

## Главное отличие

```text
SVG:
  circle, path, line, text

Raster:
  pixels, pixels, pixels
```

SVG можно увеличить без потери четкости, потому что браузер заново рассчитывает фигуры. Растровое изображение при сильном увеличении может размываться.

## SVG

```html
<svg viewBox="0 0 24 24" width="24" height="24">
  <circle cx="12" cy="12" r="10" fill="tomato" />
</svg>
```

Подходит для:

- иконок;
- логотипов;
- схем;
- простых иллюстраций;
- UI-графики;
- графиков и диаграмм.

## Растровые изображения

```html
<img src="/photo.jpg" alt="Пейзаж с горами">
```

Подходят для:

- фотографий;
- сложных текстур;
- скриншотов;
- изображений с большим количеством деталей.

## Сравнение

| Критерий | SVG | Растр |
| --- | --- | --- |
| Основа | Фигуры и пути | Пиксели |
| Масштабирование | Без потери качества | Может размываться |
| Лучший сценарий | Иконки, логотипы, схемы | Фото, сложные изображения |
| Стилизация CSS | Часто возможна | Ограничена |
| DOM-доступ | Inline SVG доступен как элементы | Обычно один `img` |

## Важный нюанс

SVG не всегда легче растрового файла. Очень сложный SVG с тысячами путей может быть тяжелым и медленным. Формат выбирают под задачу.

## Мини-шпаргалка

- SVG - вектор, растр - пиксели.
- SVG хорош для иконок и логотипов.
- Растр хорош для фотографий.
- SVG масштабируется четко.
- Сложный SVG тоже может быть тяжелым.
- Для фото обычно лучше WebP, AVIF или JPEG.
