# Что такое platform adapter Express и Fastify?

> [!summary]
> Platform adapter - слой, через который NestJS подключается к конкретной HTTP-платформе. По умолчанию часто используют Express, но NestJS также поддерживает Fastify через адаптер.

## Зачем нужен adapter?

NestJS старается давать единый API для controllers, guards, pipes и interceptors, но реальные HTTP-запросы обрабатывает underlying platform.

```txt
Nest application
  -> platform adapter
    -> Express или Fastify
      -> Node.js HTTP server
```

## Express adapter

Express привычен, имеет огромную экосистему middleware и часто используется по умолчанию.

## Fastify adapter

Fastify выбирают, когда важны производительность и более строгий plugin-подход.

```ts
const app = await NestFactory.create<NestFastifyApplication>(
  AppModule,
  new FastifyAdapter(),
);
```

## Важный нюанс

Некоторые низкоуровневые API зависят от платформы. Если код напрямую использует `@Res()` или Express-specific objects, переход на Fastify станет сложнее.

## Мини-шпаргалка

- Adapter связывает NestJS с HTTP-платформой.
- Express - распространенный вариант.
- Fastify - альтернатива с фокусом на скорость.
- Чем меньше platform-specific кода, тем переносимее приложение.
- `@Res()` может привязать код к конкретной платформе.
