# Что возвращает функция data?

> [!NOTE]
> Функция `data()` возвращает объект начального состояния компонента. Vue делает свойства этого объекта реактивными и доступными в шаблоне и через `this`.

## Вопрос

Что возвращает функция `data`?

## Базовый пример

```vue
<script>
export default {
  data() {
    return {
      count: 0,
      name: "Анна",
      isLoading: false,
    };
  },
};
</script>

<template>
  <button @click="count++">{{ count }}</button>
  <p>{{ name }}</p>
</template>
```

Объект из `data()` становится локальным state компонента.

## Почему data - функция

Компонент может иметь несколько экземпляров. Каждый экземпляр должен получить свой объект состояния.

```javascript
export default {
  data() {
    return { isOpen: false };
  },
};
```

## Доступ через this

```javascript
export default {
  data() {
    return { count: 0 };
  },
  methods: {
    increment() {
      this.count++;
    },
  },
};
```

## Что хранить в data

В `data` кладут изменяемое состояние: поля формы, флаги, загруженные данные, выбранные элементы. Производные значения лучше делать через `computed`.

## Мини-шпаргалка

- `data()` возвращает объект.
- Поля объекта становятся реактивным state.
- В template поля доступны напрямую.
- В methods - через `this`.
- Для производных данных используй `computed`.
