# Что такое таблица, строка и столбец?

> [!summary]
> Таблица описывает набор однотипных данных, строка хранит одну запись, а столбец задает конкретный атрибут этой записи с именем, типом и ограничениями.

## Пример таблицы

```sql
CREATE TABLE products (
  id bigint PRIMARY KEY,
  title text NOT NULL,
  price numeric(10, 2) NOT NULL,
  in_stock boolean NOT NULL DEFAULT true
);
```

| Элемент | Пример | Что означает |
|---|---|---|
| Таблица | `products` | товары |
| Строка | один товар | конкретная запись |
| Столбец | `price` | цена товара |
| Тип | `numeric(10, 2)` | формат значения |
| Constraint | `NOT NULL` | правило |

## Строка как факт

```sql
INSERT INTO products (id, title, price)
VALUES (1, 'Keyboard', 99.90);
```

Эта команда добавляет одну строку в таблицу.

## Хорошие имена

Лучше выбирать имена, которые описывают бизнес-смысл.

```sql
-- Лучше
created_at timestamp

-- Хуже
date1 timestamp
```

## Мини-шпаргалка

- Таблица - набор записей одного типа.
- Строка - одна запись.
- Столбец - свойство записи.
- У столбца есть тип.
- Constraints защищают данные от некорректного состояния.
