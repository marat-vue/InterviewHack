# Что такое компонент во Vue.js?

> [!NOTE]
> Компонент во Vue - самостоятельная часть интерфейса со своим шаблоном, логикой, стилями, входными props и событиями.

## Вопрос

Что такое компонент во Vue.js?

## Базовая идея

Компонент помогает разбить интерфейс на понятные переиспользуемые блоки: кнопку, карточку пользователя, форму, layout, страницу.

```vue
<script setup>
defineProps<{
  name: string;
}>();
</script>

<template>
  <article class="user-card">
    <h2>{{ name }}</h2>
  </article>
</template>
```

Такой компонент можно использовать в другом компоненте.

```vue
<template>
  <UserCard name="Анна" />
</template>
```

## Single File Component

Чаще всего компонент Vue хранится в `.vue` файле и состоит из трех частей:

```vue
<script setup>
// логика
</script>

<template>
  <!-- разметка -->
</template>

<style scoped>
/* стили */
</style>
```

## Что входит в компонент

- Состояние и вычисляемые значения.
- Props от родителя.
- Events для связи с родителем.
- Шаблон отображения.
- Стили, часто scoped.

## Мини-шпаргалка

- Компонент = самостоятельный блок UI.
- `.vue` файл часто содержит `script`, `template`, `style`.
- Родитель передает данные через props.
- Ребенок сообщает о событиях через emit.
