# Как читать Google Search Console?

> [!summary]
> Google Search Console показывает, как сайт виден в Google Search: клики, показы, CTR, позиции, индексацию, Core Web Vitals, sitemap и проблемы. Это основной инструмент SEO-диагностики для владельца сайта.

## Что смотреть в Performance?

Основные показатели:

- clicks;
- impressions;
- average CTR;
- average position;
- queries;
- pages;
- countries;
- devices;
- search appearance;
- dates.

## Как анализировать запросы?

Пример:

```text
Много показов + низкий CTR -> проверить title/description и соответствие intent.
Позиции 8-20 -> страница близка к росту, можно улучшить контент и ссылки.
Падение кликов при стабильных позициях -> проверить сезонность и изменения SERP.
```

## Что смотреть в Indexing?

- Какие страницы проиндексированы.
- Какие исключены.
- Причины исключения.
- Sitemap.
- Ошибки `404`.
- Страницы с redirect.
- Страницы с `noindex`.
- Дубликаты без выбранного canonical.

## Что такое URL Inspection?

URL Inspection помогает проверить конкретную страницу:

- известна ли Google;
- можно ли ее индексировать;
- какой canonical выбран;
- когда был последний crawl;
- видит ли Google страницу после рендера;
- есть ли structured data.

## Мини-шпаргалка

- Performance показывает спрос и видимость.
- Indexing показывает, попадают ли страницы в индекс.
- URL Inspection нужен для конкретных URL.
- Анализируй pages и queries вместе.
- Search Console не показывает все данные, но дает главную SEO-картину.
