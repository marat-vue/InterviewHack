# `unshift()`

> [!NOTE] Коротко
> `unshift()` добавляет один или несколько элементов в начало массива, сдвигает существующие элементы вправо, мутирует массив и возвращает новую длину.

## Вопрос

Что делает `unshift()`?

## Пример

```javascript
const arr = [2, 3];

const length = arr.unshift(0, 1);

console.log(arr);    // [0, 1, 2, 3]
console.log(length); // 4
```

## Возвращает длину

Как и `push`, метод возвращает новую длину массива, а не сам массив.

```javascript
const result = arr.unshift("x");

typeof result; // "number"
```

## Производительность

`unshift()` может быть дороже, чем `push()`, потому что всем существующим элементам нужно изменить индексы.

Для частого добавления в начало больших коллекций стоит подумать о другой структуре данных.

## Без мутации

```javascript
const next = [newItem, ...arr];
```

Для нескольких элементов:

```javascript
const next = [...newItems, ...arr];
```

## Мини-шпаргалка

| Свойство | `unshift()` |
| --- | --- |
| добавляет | в начало |
| мутирует | да |
| возвращает | новую длину |
| сдвигает индексы | да |
| иммутабельная альтернатива | `[item, ...arr]` |
