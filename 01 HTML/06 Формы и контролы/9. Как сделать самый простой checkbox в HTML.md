# Как сделать самый простой checkbox в HTML

> [!summary]
> Checkbox создают через `<input type="checkbox">`. Он подходит для независимого выбора: согласие с условиями, включение настройки или выбор нескольких вариантов.

## Главное

```html
<label>
  <input type="checkbox" name="agreement" value="yes">
  Я согласен с условиями
</label>
```

Если чекбокс отмечен, форма отправит `agreement=yes`. Если не отмечен, поле обычно не отправляется.

## checked

```html
<label>
  <input type="checkbox" name="newsletter" checked>
  Получать рассылку
</label>
```

`checked` отмечает чекбокс по умолчанию.

## Несколько checkbox

Чекбоксы подходят, когда можно выбрать несколько вариантов.

```html
<fieldset>
  <legend>Навыки</legend>

  <label><input type="checkbox" name="skills" value="html"> HTML</label>
  <label><input type="checkbox" name="skills" value="css"> CSS</label>
  <label><input type="checkbox" name="skills" value="js"> JavaScript</label>
</fieldset>
```

При отправке выбранные значения уйдут под одним именем `skills`.

## Checkbox или radio

```text
Можно выбрать несколько вариантов -> checkbox
Можно выбрать только один вариант -> radio
```

Для согласия с условиями, переключателей настроек и множественного выбора нужен checkbox.

## Мини-шпаргалка

- Checkbox: `input type="checkbox"`.
- Подходит для независимого выбора.
- `checked` задает состояние по умолчанию.
- Если checkbox не выбран, он обычно не отправляется.
- Для группы добавляют `fieldset` и `legend`.
- Для единственного выбора из группы лучше radio.
