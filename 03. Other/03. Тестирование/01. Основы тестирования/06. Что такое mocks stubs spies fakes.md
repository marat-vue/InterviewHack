# Что такое mocks, stubs, spies и fakes?

> [!summary]
> Test doubles заменяют реальные зависимости в тестах. Stub возвращает заранее заданные данные, spy следит за вызовами, mock задает ожидания поведения, fake является рабочей упрощенной реализацией.

## Зачем нужны test doubles?

В тестах часто не хочется обращаться к настоящей базе, платежной системе, email-сервису или сетевому API.

Вместо этого зависимость заменяют контролируемым объектом:

```ts
const emailService = {
  sendWelcomeEmail: vi.fn(),
};
```

Так тест становится:

- быстрее;
- стабильнее;
- независимее от внешнего мира;
- проще для проверки ошибок.

## Stub

Stub просто возвращает нужное значение.

```ts
const userRepository = {
  findById: vi.fn().mockResolvedValue({ id: 1, name: 'Ann' }),
};
```

Используй stub, когда важно подготовить ответ зависимости.

## Spy

Spy следит, вызывалась ли функция, с какими аргументами и сколько раз.

```ts
const logger = {
  warn: vi.fn(),
};

service.handleInvalidToken();

expect(logger.warn).toHaveBeenCalledWith('Invalid token');
```

Используй spy, когда важно проверить взаимодействие.

## Mock

Mock часто объединяет stub и spy: он имитирует поведение и позволяет проверить вызовы.

```ts
const paymentGateway = {
  charge: vi.fn().mockResolvedValue({ status: 'paid' }),
};

await checkoutService.pay(order);

expect(paymentGateway.charge).toHaveBeenCalledWith({
  amount: 3000,
  currency: 'RUB',
});
```

## Fake

Fake - это упрощенная, но рабочая реализация.

```ts
class FakeUserRepository {
  private users = new Map<number, User>();

  async save(user: User) {
    this.users.set(user.id, user);
    return user;
  }

  async findById(id: number) {
    return this.users.get(id) ?? null;
  }
}
```

Fake полезен, когда моков становится слишком много, а тесту нужна более реалистичная зависимость.

## Мини-шпаргалка

- Stub возвращает подготовленные данные.
- Spy проверяет вызовы.
- Mock имитирует зависимость и часто проверяет взаимодействие.
- Fake - упрощенная рабочая реализация.
- Моки не должны скрывать реальные интеграционные проблемы.
