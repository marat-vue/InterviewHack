# Что такое WeakSet?

> [!NOTE] Коротко
> `WeakSet` - коллекция уникальных объектов со слабыми ссылками. Она не мешает сборщику мусора удалять объекты из памяти.

## Вопрос

Чем `WeakSet` отличается от обычного `Set`?

## Определение

`WeakSet` похож на `Set`, но хранит только объекты. Ссылки внутри `WeakSet` слабые: если объект больше нигде не используется, сборщик мусора может удалить его, а запись в `WeakSet` исчезнет автоматически.

## Пример

```javascript
const visited = new WeakSet();

let user = { name: 'Ann' };

visited.add(user);

console.log(visited.has(user)); // true

user = null; // объект может быть удален сборщиком мусора
```

Мы не можем вручную увидеть момент удаления: сборка мусора происходит автоматически и недетерминированно.

## Ограничения

```javascript
const weakSet = new WeakSet();

weakSet.add({ id: 1 }); // ok
// weakSet.add(1);      // TypeError
```

В `WeakSet` нельзя хранить примитивы: строки, числа, boolean, `null`, `undefined`.

## Почему WeakSet нельзя перебрать

У `WeakSet` нет `size`, `forEach`, `keys()` и `for...of`. Если бы коллекцию можно было перебрать, это конфликтовало бы с идеей слабых ссылок: объект может исчезнуть из памяти в любой момент.

## Когда использовать

- помечать объекты как уже обработанные;
- хранить временные флаги для объектов;
- избегать утечек памяти при работе с объектами, которые могут исчезать.

## Мини-шпаргалка

```javascript
const weakSet = new WeakSet();

weakSet.add(obj);
weakSet.has(obj);
weakSet.delete(obj);
```
