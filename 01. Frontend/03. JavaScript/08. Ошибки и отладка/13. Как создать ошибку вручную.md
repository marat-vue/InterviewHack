# Как создать ошибку вручную?

> [!NOTE]
> Ошибку вручную создают через `new Error(message)` и выбрасывают оператором `throw`.

## Вопрос

Как самостоятельно создать и выбросить ошибку?

## Базовый вариант

```javascript
const error = new Error('Invalid user id');

throw error;
```

Чаще это пишут в одну строку:

```javascript
throw new Error('Invalid user id');
```

## Пример в функции

```javascript
function getUser(id) {
  if (!id) {
    throw new Error('User id is required');
  }

  return { id };
}
```

Если аргумент не передан, функция явно сообщает о проблеме.

## Специализированные ошибки

```javascript
throw new TypeError('Expected string');
throw new RangeError('Age must be positive');
```

Встроенные типы помогают точнее описать проблему.

## Ошибка с причиной

```javascript
try {
  JSON.parse(text);
} catch (error) {
  throw new Error('Failed to parse config', {
    cause: error,
  });
}
```

`cause` связывает новую ошибку с исходной.

## Не стоит выбрасывать строки

```javascript
throw 'Bad value'; // плохая практика
```

У строки нет `name`, `message`, `stack` и нормального поведения объекта ошибки.

## Мини-шпаргалка

```javascript
throw new Error('Message');
throw new TypeError('Expected number');
```
