# Чистая функция

> [!NOTE] Коротко
> Чистая функция всегда возвращает один и тот же результат для одних и тех же аргументов и не имеет side effects.

## Вопрос

Что такое чистая функция?

## Два признака

### Детерминированность

Одинаковый ввод всегда дает одинаковый вывод.

```javascript
function sum(a, b) {
  return a + b;
}

sum(2, 3); // всегда 5
```

### Нет side effects

Функция не меняет внешний мир:

- не изменяет глобальные переменные;
- не мутирует аргументы;
- не пишет в DOM;
- не делает сетевые запросы;
- не пишет в консоль как часть вычисления;
- не зависит от времени или случайности.

## Нечистая функция

```javascript
let total = 0;

function add(value) {
  total += value;
  return total;
}
```

Функция зависит от внешнего `total` и меняет его.

## Чистый вариант

```javascript
function add(total, value) {
  return total + value;
}
```

Все данные приходят через аргументы, результат возвращается наружу.

## Мутация аргументов

Нечисто:

```javascript
function addItem(items, item) {
  items.push(item);
  return items;
}
```

Чисто:

```javascript
function addItem(items, item) {
  return [...items, item];
}
```

## Почему это полезно

Чистые функции проще:

- тестировать;
- переиспользовать;
- читать;
- кэшировать;
- отлаживать.

## Мини-шпаргалка

| Признак | Чистая функция |
| --- | --- |
| тот же ввод | тот же вывод |
| внешнее состояние | не меняет |
| аргументы | не мутирует |
| DOM/API/console | не использует как часть вычисления |
| тестирование | простое |
