# Что делает тип symbol

> [!summary] Коротко
> `symbol` описывает уникальные значения, которые часто используют как уникальные ключи свойств.

## Вопрос

Что такое тип `symbol` в TypeScript?

## Определение

`symbol` - примитивный тип JavaScript для создания уникальных идентификаторов. Даже два символа с одинаковым описанием не равны друг другу.

## Пример

```typescript
const first: symbol = Symbol('id');
const second: symbol = Symbol('id');

console.log(first === second); // false
```

Описание `'id'` нужно только для отладки.

## Symbol как ключ объекта

```typescript
const id = Symbol('id');

const user = {
  [id]: 123,
  name: 'Ann',
};

console.log(user[id]); // 123
```

Symbol-ключи помогают избежать конфликтов с обычными строковыми ключами.

## unique symbol

```typescript
const token: unique symbol = Symbol('token');
```

`unique symbol` описывает конкретный уникальный symbol и часто используется для специальных ключей в типах.

## Где встречается

- уникальные ключи объектов;
- метапрограммирование;
- well-known symbols, например `Symbol.iterator`;
- внутренние маркеры библиотек.

## Мини-шпаргалка

```typescript
const key: symbol = Symbol('key');
const value = object[key];
```
