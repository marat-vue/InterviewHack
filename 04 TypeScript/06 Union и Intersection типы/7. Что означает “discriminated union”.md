# Что означает discriminated union

> [!summary] Коротко
> Discriminated union - это union объектов, у которых есть общее поле с литеральным значением. По этому полю TypeScript понимает, какой вариант перед ним.

## Вопрос

Что означает `discriminated union`?

## Базовая схема

```typescript
type Loading = { status: "loading" };
type Success = { status: "success"; data: string[] };
type ErrorState = { status: "error"; message: string };

type RequestState = Loading | Success | ErrorState;
```

Поле `status` - дискриминатор. Его значение точно указывает на вариант.

## Использование в коде

```typescript
function render(state: RequestState): string {
  switch (state.status) {
    case "loading":
      return "Загрузка";
    case "success":
      return state.data.join(", ");
    case "error":
      return state.message;
  }
}
```

В каждой ветке TypeScript знает точную форму объекта.

## Почему это удобно

Такой подход хорошо описывает состояния UI, события, результаты API и команды.

```typescript
type FormEvent =
  | { type: "change"; field: string; value: string }
  | { type: "submit" }
  | { type: "reset" };
```

## Дискриминатор должен быть литералом

```typescript
type Good = { kind: "user"; name: string };
type Bad = { kind: string; name: string }; // слишком широко
```

## Мини-шпаргалка

- Общий ключ: `type`, `kind`, `status`.
- Значение ключа - literal type.
- `switch` по дискриминатору дает чистый narrowing.
- Отлично подходит для моделирования состояний.
