# Что такое TypeScript

> [!summary] Коротко
> TypeScript - надстройка над JavaScript, которая добавляет статическую проверку типов и помогает находить ошибки до запуска кода.

## Вопрос

Что такое TypeScript и зачем он нужен frontend-разработчику?

## Определение

TypeScript, TS, - язык программирования от Microsoft, который расширяет JavaScript системой типов. Любой корректный JavaScript-код в большинстве случаев является корректным TypeScript-кодом, но TS позволяет дополнительно описывать типы данных, параметры функций, структуры объектов и контракты модулей.

Браузер не выполняет TypeScript напрямую. TS-код компилируется в JavaScript.

## Пример

```typescript
function greet(name: string): string {
  return `Hello, ${name}`;
}

greet('Ann');
greet(123); // ошибка TypeScript
```

Ошибка обнаружится на этапе проверки типов, еще до запуска приложения.

## Что дает TypeScript

- автодополнение и подсказки в редакторе;
- раннее обнаружение ошибок;
- понятные контракты функций и объектов;
- безопасный рефакторинг;
- лучшую навигацию по коду;
- документацию прямо в типах.

## Что TypeScript не делает

TypeScript не заменяет JavaScript и не проверяет типы в runtime. После компиляции типы исчезают, а в браузере выполняется обычный JavaScript.

```typescript
const age: number = 25;
```

После компиляции:

```javascript
const age = 25;
```

## Мини-шпаргалка

```text
TypeScript = JavaScript + static types
TS code -> compiler -> JS code
```
