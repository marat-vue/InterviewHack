# Что делает параметр deep?

> [!NOTE] Коротко
> Параметр `deep` у `watch` включает глубокое наблюдение за вложенными изменениями объекта. Он нужен, когда важны изменения внутри объекта, а не только замена ссылки.

## Вопрос

Что делает параметр `deep`?

## Проблема

```typescript
const form = reactive({
  user: {
    name: "Анна",
  },
});

watch(
  () => form.user,
  () => {
    console.log("user changed");
  }
);

form.user.name = "Мария"; // watcher может не сработать для getter без deep
```

Watcher следит за результатом getter-а, а ссылка на `form.user` не изменилась.

## Решение

```typescript
watch(
  () => form.user,
  () => {
    console.log("nested change");
  },
  { deep: true }
);
```

Теперь Vue будет учитывать вложенные изменения.

## Когда не нужен

Если можно следить за конкретным полем, лучше сделать так.

```typescript
watch(
  () => form.user.name,
  (name) => {
    console.log(name);
  }
);
```

Это точнее и дешевле, чем глубокий watcher.

## Риск производительности

Deep-watch может быть дорогим для больших объектов, потому что Vue должен обходить вложенную структуру.

## Мини-шпаргалка

- `deep: true` включает глубокое наблюдение.
- Полезно для вложенных объектов.
- Может быть дорогим.
- Часто лучше следить за конкретным полем через getter.
