# Что такое $emit

> [!summary] Коротко
> `$emit` в Options API отправляет пользовательское событие из дочернего компонента родителю.

## Вопрос

Что такое `$emit` в Options API?

## Базовый пример

```vue
<script>
export default {
  emits: ["close"],
  methods: {
    close() {
      this.$emit("close");
    },
  },
};
</script>

<template>
  <button @click="close">Закрыть</button>
</template>
```

Родитель слушает событие так:

```vue
<BaseModal @close="isOpen = false" />
```

## Payload

```javascript
this.$emit("select", user.id);
```

```vue
<UserCard @select="selectedId = $event" />
```

## Для v-model

Во Vue 3 компонентный `v-model` обновляют событием `update:modelValue`.

```javascript
this.$emit("update:modelValue", newValue);
```

## Почему это важно

`$emit` сохраняет однонаправленный поток данных: ребенок не меняет состояние родителя напрямую, а сообщает о событии.

## Мини-шпаргалка

- `this.$emit("event")` отправляет событие.
- Второй аргумент и дальше - payload.
- Родитель слушает через `@event`.
- События лучше объявлять в `emits`.
