# Хуки жизненного цикла

> [!NOTE] Коротко
> Хуки жизненного цикла - функции, которые Vue вызывает на разных этапах жизни компонента: создание, монтирование, обновление и удаление.

## Вопрос

Что такое хуки жизненного цикла во Vue?

## Основные этапы

Компонент проходит несколько важных стадий:

- Создание экземпляра и подготовка реактивности.
- Монтирование в DOM.
- Обновление после изменения состояния.
- Размонтирование и очистка.

## Composition API

```vue
<script setup>
import { onMounted, onUnmounted } from "vue";

onMounted(() => {
  console.log("Компонент появился в DOM");
});

onUnmounted(() => {
  console.log("Компонент удален");
});
</script>
```

## Options API

```vue
<script>
export default {
  mounted() {
    console.log("Компонент появился в DOM");
  },
  unmounted() {
    console.log("Компонент удален");
  },
};
</script>
```

## Где полезны

`mounted` используют для работы с DOM, подключения сторонних библиотек или начальных запросов. `unmounted` - для очистки таймеров, подписок и обработчиков.

## Мини-шпаргалка

- `mounted/onMounted` - компонент уже в DOM.
- `updated/onUpdated` - DOM обновился после изменения state.
- `unmounted/onUnmounted` - компонент удален.
- В хуках удобно делать setup и cleanup side effects.
