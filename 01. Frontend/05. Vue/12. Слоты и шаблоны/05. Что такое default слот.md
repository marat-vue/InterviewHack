# Что такое default слот?

> [!NOTE]
> **Default слот** - это слот без имени. Он принимает основной контент, который родитель передает внутрь компонента между открывающим и закрывающим тегом.

## Главное

Default слот нужен, когда компонент задает оболочку, стили или поведение, а конкретное содержимое приходит снаружи.

```vue
<!-- BaseCard.vue -->
<template>
  <article class="card">
    <slot />
  </article>
</template>
```

```vue
<!-- Parent.vue -->
<template>
  <BaseCard>
    <h2>Профиль пользователя</h2>
    <p>Основная информация и настройки аккаунта.</p>
  </BaseCard>
</template>
```

Результат: `h2` и `p` окажутся на месте `<slot />` внутри `BaseCard`.

## Fallback-контент

Внутрь `<slot>` можно положить содержимое по умолчанию. Оно отобразится, если родитель ничего не передал.

```vue
<!-- EmptyState.vue -->
<template>
  <div class="empty">
    <slot>Пока здесь ничего нет</slot>
  </div>
</template>
```

```vue
<template>
  <EmptyState />

  <EmptyState>
    Список задач пуст
  </EmptyState>
</template>
```

В первом случае Vue покажет `Пока здесь ничего нет`, во втором - текст из родителя.

## Default слот и именованные слоты

Default слот отвечает за основной контент. Именованные слоты нужны для отдельных зон: `header`, `footer`, `actions`.

```vue
<!-- BaseModal.vue -->
<template>
  <section class="modal">
    <header>
      <slot name="title">Заголовок</slot>
    </header>

    <main>
      <slot />
    </main>

    <footer>
      <slot name="actions" />
    </footer>
  </section>
</template>
```

```vue
<BaseModal>
  <template #title>Удалить проект?</template>

  <p>Это действие нельзя отменить.</p>

  <template #actions>
    <button>Отмена</button>
    <button>Удалить</button>
  </template>
</BaseModal>
```

Здесь `<p>` попадает в default слот, а `title` и `actions` - в именованные слоты.

## Когда использовать

- Для карточек, панелей, модальных окон и layout-компонентов.
- Когда компоненту важно управлять внешней оболочкой, но не содержимым.
- Когда передаваемый контент сложнее обычной строки или одного значения.

## Мини-шпаргалка

- `<slot />` - место для основного контента.
- Default слот не имеет имени.
- Контент между тегами компонента попадает именно в default слот.
- Внутри `<slot>` можно указать fallback.
- Если нужны несколько зон, добавляют именованные слоты.
