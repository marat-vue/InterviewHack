# Деструктуризация с пропуском элементов

> [!summary] Коротко
> В деструктуризации массива лишняя запятая пропускает элемент на соответствующей позиции.

## Вопрос

Как использовать деструктуризацию, если нужны не все элементы массива?

## Определение

Деструктуризация массива позволяет достать значения по позициям. Если какое-то значение не нужно, его можно пропустить пустым местом между запятыми.

## Базовый пример

```javascript
const [first, , third] = ['a', 'b', 'c'];

console.log(first); // 'a'
console.log(third); // 'c'
```

Вторая позиция пропущена, поэтому переменная для `'b'` не создается.

## Несколько пропусков

```javascript
const [, , value] = [10, 20, 30];

console.log(value); // 30
```

Количество запятых помогает добраться до нужного индекса.

## Пропуск вместе с rest

```javascript
const [head, , ...tail] = [1, 2, 3, 4, 5];

console.log(head); // 1
console.log(tail); // [3, 4, 5]
```

Rest собирает все оставшиеся элементы после пропущенной позиции.

## Практический пример

```javascript
const coordinates = [55.75, 'Moscow', 37.61];
const [lat, , lng] = coordinates;

console.log(lat, lng); // 55.75 37.61
```

Так можно игнорировать промежуточное значение, если оно не нужно в текущем коде.

## Мини-шпаргалка

```javascript
const [a, , c] = arr;       // пропустить второй элемент
const [, second] = arr;     // пропустить первый
const [x, , ...rest] = arr; // пропуск + остаток
```
