# Для чего используется v-once?

> [!NOTE] Коротко
> `v-once` рендерит элемент или компонент только один раз. После первого рендера Vue пропускает его при последующих обновлениях.

## Вопрос

Для чего используется `v-once`?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const title = ref("Начальный заголовок");
</script>

<template>
  <h1 v-once>{{ title }}</h1>
  <button @click="title = 'Новый заголовок'">Изменить</button>
</template>
```

`h1` останется с первым значением, даже если `title` изменится.

## Когда использовать

`v-once` подходит для полностью статичных частей интерфейса, которые зависят от данных только при первом рендере.

## Почему осторожно

Если данные должны обновляться, `v-once` приведет к устаревшему UI. Поэтому директиву стоит применять только там, где статичность действительно намеренная.

## Отличие от обычного static content

Vue и так оптимизирует статичный HTML. `v-once` полезен именно когда шаблон выглядит динамическим, но его нужно зафиксировать после первого рендера.

## Мини-шпаргалка

- `v-once` рендерит один раз.
- Последующие изменения зависимостей игнорируются.
- Подходит для намеренно статичных блоков.
- Не используй для данных, которые должны обновляться.
