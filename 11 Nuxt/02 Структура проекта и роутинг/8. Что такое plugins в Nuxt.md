# Что такое plugins в Nuxt?

> [!summary]
> Plugins в Nuxt позволяют подключать код к Vue/Nuxt app при старте: библиотеки, provide/inject, analytics, API clients, директивы. Plugins лежат в `app/plugins` и могут иметь suffix `.client` или `.server`.

## Пример plugin

```ts
// app/plugins/api.ts
export default defineNuxtPlugin(() => {
  const config = useRuntimeConfig();

  const api = $fetch.create({
    baseURL: config.public.apiBase,
  });

  return {
    provide: {
      api,
    },
  };
});
```

Использование:

```ts
const { $api } = useNuxtApp();

const user = await $api('/users/me');
```

## Client-only plugin

```text
app/plugins/analytics.client.ts
```

Этот plugin выполнится только в browser.

## Server-only plugin

```text
app/plugins/logger.server.ts
```

Этот plugin выполнится только в SSR server context.

## Когда нужны plugins?

- подключить Vue plugin;
- создать API client;
- зарегистрировать directive;
- подключить analytics;
- добавить global helper;
- настроить стороннюю библиотеку.

## Когда plugin не нужен?

Если код можно выразить обычным composable, лучше начать с composable.

Plugins нужны для app-level initialization, а не для любой логики.

## Мини-шпаргалка

- Plugins лежат в `app/plugins`.
- Создаются через `defineNuxtPlugin`.
- `.client.ts` - только browser.
- `.server.ts` - только server.
- Через `provide` значения доступны как `$name` в `useNuxtApp()`.
