# Какие методы Prisma Client нужно знать?

> [!NOTE]
> Prisma Client генерирует методы для каждой модели. Нужно понимать не только названия, но и сценарии: unique lookup, списки, массовые операции, агрегаты, связи, nested writes, transactions и raw SQL.

## Методы чтения

| Метод | Когда использовать | Что возвращает |
|---|---|---|
| `findUnique` | найти одну запись по unique field или compound unique | объект или `null` |
| `findUniqueOrThrow` | unique lookup, отсутствие записи считается ошибкой | объект или exception |
| `findFirst` | найти первую запись по обычному filter | объект или `null` |
| `findFirstOrThrow` | `findFirst`, но отсутствие записи - exception | объект или exception |
| `findMany` | получить список записей | массив |

## Методы создания

| Метод | Когда использовать |
|---|---|
| `create` | создать одну запись |
| `createMany` | массово создать записи |
| `createManyAndReturn` | массово создать и вернуть созданные строки, если поддерживается connector |

Пример:

```ts
await prisma.user.createMany({
  data: [
    { email: 'a@example.com' },
    { email: 'b@example.com' },
  ],
  skipDuplicates: true,
});
```

## Методы обновления

| Метод | Когда использовать |
|---|---|
| `update` | обновить одну запись по unique field |
| `updateMany` | обновить все записи по filter |
| `updateManyAndReturn` | массово обновить и вернуть строки, если поддерживается connector |
| `upsert` | создать, если записи нет, иначе обновить |

Пример:

```ts
await prisma.user.upsert({
  where: {
    email: 'anna@example.com',
  },
  create: {
    email: 'anna@example.com',
    name: 'Anna',
  },
  update: {
    name: 'Anna',
  },
});
```

## Методы удаления

| Метод | Когда использовать |
|---|---|
| `delete` | удалить одну запись по unique field |
| `deleteMany` | удалить все записи по filter |

`deleteMany` полезен для cleanup:

```ts
await prisma.session.deleteMany({
  where: {
    expiresAt: {
      lt: new Date(),
    },
  },
});
```

## Агрегация

| Метод | Когда использовать |
|---|---|
| `count` | посчитать записи |
| `aggregate` | посчитать `_sum`, `_avg`, `_min`, `_max`, `_count` по выборке |
| `groupBy` | сгруппировать строки по полям и посчитать агрегаты |

Пример:

```ts
const stats = await prisma.order.aggregate({
  where: {
    status: 'PAID',
  },
  _sum: {
    total: true,
  },
  _avg: {
    total: true,
  },
});
```

## Relation methods через fluent API

Prisma может генерировать fluent API:

```ts
const posts = await prisma.user
  .findUnique({
    where: { id },
  })
  .posts();
```

Это удобно в некоторых GraphQL/N+1 сценариях, но для обычного REST API чаще используют `include`/`select`.

## Transactions

| Метод | Когда использовать |
|---|---|
| `$transaction([])` | batch transaction из независимых Prisma promises |
| `$transaction(async (tx) => {})` | interactive transaction для зависимых операций |

Пример:

```ts
await prisma.$transaction(async (tx) => {
  const order = await tx.order.create({
    data: {
      userId,
      total,
    },
  });

  await tx.auditLog.create({
    data: {
      action: 'ORDER_CREATED',
      entityId: order.id,
    },
  });
});
```

## Raw SQL

| Метод | Когда использовать |
|---|---|
| `$queryRaw` | SQL, который возвращает строки |
| `$executeRaw` | SQL command без строк результата |
| `$queryRawUnsafe` | raw SQL string, опасно без ручной защиты |
| `$executeRawUnsafe` | raw command string, опасно без ручной защиты |

Безопасный пример:

```ts
const rows = await prisma.$queryRaw`
  SELECT id, email
  FROM "User"
  WHERE email LIKE ${'%@example.com'}
`;
```

Не склеивай SQL строки с пользовательским input.

## Client lifecycle и extension methods

| Метод | Зачем нужен |
|---|---|
| `$connect` | явно подключиться к БД |
| `$disconnect` | закрыть соединения |
| `$on` | подписаться на events/logs |
| `$use` | middleware API в старых/совместимых сценариях |
| `$extends` | расширить Prisma Client |

## Как выбрать метод?

| Задача | Метод |
|---|---|
| Найти по id/email | `findUnique` |
| Найти последнюю запись | `findFirst` + `orderBy` |
| Получить страницу списка | `findMany` |
| Создать | `create` |
| Импортировать пачку | `createMany` |
| Обновить одну запись | `update` |
| Обновить пачку | `updateMany` |
| Idempotent create/update | `upsert` |
| Удалить одну запись | `delete` |
| Cleanup пачки | `deleteMany` |
| Pagination total | `count` |
| Сумма/среднее | `aggregate` |
| Статистика по группам | `groupBy` |
| Атомарный workflow | `$transaction` |
| Database-specific SQL | `$queryRaw`/`$executeRaw` |

## Мини-шпаргалка

- `findUnique` требует unique condition.
- `findFirst` лучше использовать с `orderBy`.
- `findMany` - главный метод списков.
- `createMany/updateMany/deleteMany` - массовые операции.
- `upsert` удобен для idempotency.
- `aggregate` считает по выборке, `groupBy` группирует.
- `$transaction` нужен для атомарности.
- Raw SQL используй параметризованно и точечно.
