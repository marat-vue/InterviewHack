# Пересечение примитивов

> [!NOTE] Коротко
> Пересечение несовместимых примитивов обычно дает `never`, потому что одно значение не может одновременно быть, например, `string` и `number`.

## Вопрос

Что происходит при пересечении примитивов?

## Несовместимые примитивы

```typescript
type Impossible = string & number;
// тип: never
```

Нет значения, которое одновременно является строкой и числом, поэтому результат - невозможный тип.

## Literal types

```typescript
type A = "admin" & "user";
// never

type B = "admin" & string;
// "admin"
```

Пересечение литерала с его широким типом оставляет литерал.

## Зачем это знать

Такие пересечения часто появляются не вручную, а как результат сложных generic, conditional types или конфликтующих объектных полей.

```typescript
type WithStringId = { id: string };
type WithNumberId = { id: number };

type Broken = WithStringId & WithNumberId;
// id: never
```

## Практический вывод

Intersection лучше использовать для совместимых объектных типов. Если пересекаются примитивы, почти всегда стоит проверить, не перепутан ли `&` с `|`.

## Мини-шпаргалка

- `string & number` = `never`.
- `"a" & string` = `"a"`.
- Конфликтующие поля объекта могут стать `never`.
- Для "строка или число" нужен `string | number`.
