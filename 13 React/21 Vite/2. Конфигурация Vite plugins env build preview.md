# Конфигурация Vite plugins env build preview

> [!summary]
> Vite настраивается через `vite.config.ts`. Самые частые настройки: plugins, server port, build options, aliases, env modes и preview server.

## defineConfig

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

`defineConfig` дает типизацию и автодополнение.

## Plugins

```ts
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

Plugins расширяют Vite: React, Tailwind, SVG loaders, PWA, анализ bundle и другие интеграции.

## server

```ts
export default defineConfig({
  server: {
    port: 5173,
    open: true,
  },
})
```

Частые настройки:

- `port`;
- `host`;
- `open`;
- `proxy`;
- `strictPort`.

## build

```ts
export default defineConfig({
  build: {
    outDir: 'dist',
    sourcemap: true,
  },
})
```

`vite build` создает production assets.

## preview

```ts
export default defineConfig({
  preview: {
    port: 4173,
  },
})
```

`vite preview` нужен для локальной проверки production build, но это не production server.

## Что отвечать на собеседовании?

Vite config описывает plugins, dev server, build и preview. Plugins - главный способ интеграции с React, Tailwind и другими инструментами. `vite build` делает production bundle, а `vite preview` локально показывает результат сборки.

## Мини-шпаргалка

- `defineConfig` - типизированный config.
- `plugins` - расширения Vite.
- `server.port` - dev port.
- `server.proxy` - API proxy.
- `build.outDir` - папка сборки.
- `preview` - локальная проверка build.
