# `Array.of()`

> [!NOTE] Коротко
> `Array.of()` создает массив из переданных аргументов. В отличие от `Array()`, один числовой аргумент становится элементом, а не длиной массива.

## Вопрос

Что делает `Array.of()`?

## Пример

```javascript
Array.of(1, 2, 3); // [1, 2, 3]
Array.of("a");     // ["a"]
Array.of();        // []
```

## Главное отличие от `Array()`

```javascript
Array.of(3); // [3]
Array(3);    // [empty × 3]
```

`Array(3)` создает массив длины 3 с пустыми слотами. `Array.of(3)` создает массив с одним элементом `3`.

## Несколько аргументов

```javascript
Array(1, 2, 3);    // [1, 2, 3]
Array.of(1, 2, 3); // [1, 2, 3]
```

Разница особенно важна при одном числовом аргументе.

## Когда использовать

`Array.of()` полезен, когда нужно гарантированно создать массив из значений, не боясь поведения конструктора `Array`.

```javascript
function wrap(value) {
  return Array.of(value);
}

wrap(3); // [3]
```

## Мини-шпаргалка

| Код | Результат |
| --- | --- |
| `Array.of(3)` | `[3]` |
| `Array(3)` | `[empty × 3]` |
| `Array.of(1, 2)` | `[1, 2]` |
| `Array.of()` | `[]` |
