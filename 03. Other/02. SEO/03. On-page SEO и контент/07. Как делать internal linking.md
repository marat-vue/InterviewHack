# Как делать internal linking?

> [!summary]
> Internal linking - это система внутренних ссылок между страницами сайта. Она помогает пользователям находить материалы, а поисковикам - обнаруживать URL, понимать структуру и распределять важность между страницами.

## Зачем нужны внутренние ссылки?

Внутренние ссылки:

- помогают crawling;
- показывают иерархию страниц;
- связывают близкие темы;
- передают сигналы важности;
- улучшают UX;
- уменьшают глубину важных страниц.

Пример:

```text
Главная -> Блог -> SEO -> JavaScript SEO
```

Если важная статья доступна только через поиск по сайту, робот может плохо ее находить.

## Что такое anchor text?

Anchor text - текст ссылки:

```html
<a href="/seo/javascript-seo">JavaScript SEO для SPA</a>
```

Хороший anchor text объясняет, куда ведет ссылка.

Плохо:

```html
<a href="/seo/javascript-seo">читать</a>
```

Лучше:

```html
<a href="/seo/javascript-seo">как работает JavaScript SEO</a>
```

## Где ставить внутренние ссылки?

- В навигации.
- В хлебных крошках.
- В тексте статьи.
- В блоках "похожие материалы".
- В карточках категорий.
- В footer, если ссылка действительно важна.

## Частые ошибки

- Важные страницы слишком глубоко.
- Все ссылки называются "подробнее".
- Ссылки создаются только JavaScript-кликом без `href`.
- Слишком много нерелевантных ссылок.
- Нет хлебных крошек в больших разделах.
- Новые материалы не связаны со старыми.

## Мини-шпаргалка

- Внутренние ссылки помогают и людям, и роботам.
- Anchor text должен быть описательным.
- Важные страницы должны быть доступны за несколько кликов.
- Ссылка должна быть настоящим `<a href="...">`.
- Перелинковка должна отражать смысловую структуру сайта.
