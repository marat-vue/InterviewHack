# Что такое асинхронный компонент?

> [!NOTE] Коротко
> Асинхронный компонент загружается не сразу вместе с основным бандлом, а по требованию. Во Vue его создают через `defineAsyncComponent`.

## Вопрос

Что такое асинхронный компонент?

## Базовый пример

```typescript
import { defineAsyncComponent } from "vue";

const UserModal = defineAsyncComponent(() => import("./UserModal.vue"));
```

Компонент попадет в отдельный chunk и загрузится, когда реально понадобится.

## Использование в шаблоне

```vue
<script setup>
import { defineAsyncComponent, ref } from "vue";

const isOpen = ref(false);
const UserModal = defineAsyncComponent(() => import("./UserModal.vue"));
</script>

<template>
  <button @click="isOpen = true">Открыть</button>
  <UserModal v-if="isOpen" />
</template>
```

## Loading и error состояния

```typescript
const UserModal = defineAsyncComponent({
  loader: () => import("./UserModal.vue"),
  loadingComponent: LoadingSpinner,
  errorComponent: ErrorBlock,
  delay: 200,
  timeout: 3000,
});
```

## Когда использовать

Асинхронные компоненты полезны для модальных окон, тяжелых виджетов, редакторов, графиков и редко посещаемых частей интерфейса.

## Мини-шпаргалка

- `defineAsyncComponent` загружает компонент лениво.
- Обычно внутри используется `import("./Component.vue")`.
- Помогает уменьшить начальный bundle.
- Можно задать loading, error, delay и timeout.
