# Какой тег используется для группировки навигационных ссылок

> [!summary]
> Для группировки основных навигационных ссылок используют тег `<nav>`. Он обозначает блок навигации по сайту, странице или разделу.

## Главное

```html
<nav aria-label="Основная навигация">
  <a href="/">Главная</a>
  <a href="/catalog">Каталог</a>
  <a href="/contacts">Контакты</a>
</nav>
```

`nav` помогает браузеру и assistive technologies понять, что внутри находится навигация.

## Когда использовать nav

- Главное меню сайта.
- Навигация по разделу.
- Breadcrumbs.
- Пагинация.
- Список ссылок внутри документации.

```html
<nav aria-label="Навигация по документации">
  <a href="/html">HTML</a>
  <a href="/css">CSS</a>
  <a href="/js">JavaScript</a>
</nav>
```

## Когда nav не нужен

Не каждый список ссылок обязан быть `nav`. Например, ссылки в тексте статьи или список источников обычно не являются главным навигационным блоком.

```html
<p>
  Подробнее см. в <a href="/docs">документации</a>.
</p>
```

## Несколько nav на странице

Если на странице несколько навигаций, стоит дать им понятные имена.

```html
<nav aria-label="Основная навигация">...</nav>
<nav aria-label="Хлебные крошки">...</nav>
<nav aria-label="Пагинация">...</nav>
```

## Мини-шпаргалка

- Навигационные ссылки группируют через `<nav>`.
- `nav` нужен для важных блоков навигации.
- Несколько `nav` лучше различать через `aria-label`.
- Breadcrumbs и пагинация тоже могут быть `nav`.
- Обычная ссылка в тексте не требует `nav`.
