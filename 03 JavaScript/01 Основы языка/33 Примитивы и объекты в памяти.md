# Примитивы и объекты в памяти

> [!NOTE] Коротко
> Примитивные значения ведут себя как самостоятельные значения. Объекты хранятся отдельно, а переменные содержат ссылки на них.

## Вопрос

Как копируются примитивы и объекты в памяти?

## Примитивы

Примитивы копируются по значению.

```javascript
let a = "hello";
let b = a;

b = "world";

console.log(a); // "hello"
console.log(b); // "world"
```

Изменение `b` не влияет на `a`, потому что у каждой переменной свое значение.

## Объекты

Объект может иметь несколько ссылок.

```javascript
const user = { name: "Anna" };
const sameUser = user;

sameUser.name = "Max";

console.log(user.name); // "Max"
```

Переменные разные, но объект один.

## Наглядная модель

```javascript
const user = { name: "Anna" };
const admin = user;
```

Упрощенно:

```text
user  ----\
          -> { name: "Anna" }
admin ----/
```

После изменения:

```javascript
admin.name = "Max";
```

Обе переменные продолжают смотреть на тот же объект:

```text
user  ----\
          -> { name: "Max" }
admin ----/
```

## Сравнение объектов

```javascript
const a = { id: 1 };
const b = { id: 1 };

a === b; // false
```

Объекты одинаковые по содержимому, но разные по ссылке.

```javascript
const c = a;

a === c; // true
```

## Поверхностная копия

```javascript
const user = {
  name: "Anna",
  city: "Moscow",
};

const copy = { ...user };

copy.name = "Max";

console.log(user.name); // "Anna"
```

Но вложенные объекты остаются общими:

```javascript
const user = {
  profile: {
    city: "Moscow",
  },
};

const copy = { ...user };
copy.profile.city = "Kazan";

console.log(user.profile.city); // "Kazan"
```

## Глубокая копия

Для простых данных можно использовать `structuredClone`:

```javascript
const user = {
  profile: {
    city: "Moscow",
  },
};

const copy = structuredClone(user);

copy.profile.city = "Kazan";

console.log(user.profile.city); // "Moscow"
```

## Мини-шпаргалка

| Действие | Примитив | Объект |
| --- | --- | --- |
| Присваивание | копирует значение | копирует ссылку |
| Сравнение `===` | сравнивает значение | сравнивает ссылку |
| Изменение копии | не влияет на оригинал | может влиять |
| `{ ...obj }` | не нужно | поверхностная копия |
