# Как работает prefetch в Next JS?

> [!summary]
> Prefetch в Next.js - фоновая предварительная загрузка ресурсов для будущего перехода. Обычно он включается через `<Link>` и помогает сделать navigation быстрее, особенно для статичных и часто посещаемых routes.

## Что такое prefetch?

Prefetch означает: "загрузи заранее то, что пользователь, вероятно, скоро откроет".

```tsx
<Link href="/dashboard">Dashboard</Link>
```

Когда ссылка появляется в viewport, Next.js может заранее подготовить ресурсы для перехода.

## Что может загружаться?

В App Router это может включать:

- JavaScript для Client Components;
- RSC payload;
- route assets;
- часть данных для маршрута в зависимости от стратегии кеширования.

## Как отключить?

```tsx
<Link href="/heavy-page" prefetch={false}>
  Heavy page
</Link>
```

Это полезно, если route тяжелый, редко открывается или ссылка массово повторяется в большом списке.

## Prefetch не должен заменять кеширование

Prefetch ускоряет переход, но не решает все:

- медленный backend все равно нужно оптимизировать;
- большие Client Components все равно увеличивают JS;
- динамические данные могут требовать свежей загрузки;
- protected routes должны проверять доступ на сервере.

## Когда prefetch особенно полезен?

- навигация в header/sidebar;
- карточки каталога;
- часто открываемые страницы;
- route с маленьким bundle;
- статические страницы.

## Что отвечать на собеседовании?

Prefetch - это предварительная загрузка ресурсов целевого route до клика пользователя. Next.js обычно делает ее через `Link`, когда ссылка появляется в viewport. Это ускоряет переходы, но не отменяет оптимизацию данных, кеширования и размера Client Components.

## Частые ошибки

- Отключать prefetch глобально без измерений.
- Prefetch-ить тысячи ссылок в большом списке.
- Думать, что prefetch гарантирует мгновенный переход.
- Не учитывать динамические routes и свежесть данных.
- Использовать prefetch как костыль для медленного API.

## Мини-шпаргалка

- Prefetch ускоряет будущую навигацию.
- Обычно работает через `Link`.
- Можно отключить `prefetch={false}`.
- Полезен для популярных routes.
- Не заменяет cache и backend optimization.
- Слишком много prefetch тоже может вредить.
