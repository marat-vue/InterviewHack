# Сортировка массива чисел

> [!NOTE] Коротко
> Для сортировки чисел нужен компаратор: `(a, b) => a - b` для возрастания и `(a, b) => b - a` для убывания. Без компаратора `sort()` сортирует как строки.

## Вопрос

Как отсортировать массив чисел по возрастанию?

## Возрастание

```javascript
const numbers = [10, 1, 3, 20];

numbers.sort((a, b) => a - b);

console.log(numbers); // [1, 3, 10, 20]
```

## Убывание

```javascript
numbers.sort((a, b) => b - a);
```

## Почему нужен компаратор

По умолчанию `sort()` приводит элементы к строкам.

```javascript
[10, 1, 3, 20].sort(); // [1, 10, 20, 3]
```

Строка `"10"` идет раньше `"3"`, поэтому результат для чисел выглядит странно.

## Без мутации

`sort()` мутирует массив.

```javascript
const sorted = [...numbers].sort((a, b) => a - b);
```

Или:

```javascript
const sorted = numbers.toSorted((a, b) => a - b);
```

## Как работает компаратор

```javascript
(a, b) => a - b;
```

- отрицательное число - `a` раньше `b`;
- положительное число - `b` раньше `a`;
- `0` - порядок не меняется.

## Мини-шпаргалка

| Задача | Код |
| --- | --- |
| по возрастанию | `arr.sort((a, b) => a - b)` |
| по убыванию | `arr.sort((a, b) => b - a)` |
| без мутации | `[...arr].sort(...)` |
| современно без мутации | `arr.toSorted(...)` |
