# Как экспортировать OpenAPI JSON?

> [!summary]
> OpenAPI document можно не только показывать через Swagger UI, но и экспортировать как JSON/YAML. Это полезно для SDK generation, contract tests, API gateways и schema diff в CI.

## Создать document

```ts
const document = SwaggerModule.createDocument(app, config);
```

## Отдать JSON endpoint

`SwaggerModule.setup('docs', app, document)` обычно уже дает доступ к UI и document, но конкретный путь зависит от настройки.

## Сохранить файл

```ts
import { writeFileSync } from 'node:fs';

writeFileSync('openapi.json', JSON.stringify(document, null, 2));
```

Такой код лучше запускать отдельным script, а не при каждом production startup.

## Зачем export?

- сгенерировать frontend client;
- проверить diff перед релизом;
- передать контракт внешним партнерам;
- использовать в API gateway;
- валидировать examples.

## Мини-шпаргалка

- OpenAPI document - обычный JS object.
- Его можно сохранить как JSON.
- Export лучше делать отдельной командой.
- Для SDK важны стабильные operationId и schema names.
- Diff OpenAPI помогает ловить breaking changes.
