# Функция-декоратор

> [!summary] Коротко
> Функция-декоратор принимает функцию и возвращает новую функцию с дополнительным поведением. Исходная функция при этом не меняется.

## Вопрос

Что такое функция-декоратор?

## Базовый пример

```javascript
function withLog(fn) {
  return function (...args) {
    console.log("Вызов с аргументами:", args);

    return fn(...args);
  };
}

function sum(a, b) {
  return a + b;
}

const loggedSum = withLog(sum);

loggedSum(2, 3); // 5
```

`withLog` - декоратор. Он добавляет логирование к `sum`.

## Сохранение `this`

Если декорируемая функция использует `this`, важно передать контекст.

```javascript
function withLog(fn) {
  return function (...args) {
    console.log("args:", args);

    return fn.apply(this, args);
  };
}
```

`apply(this, args)` сохраняет контекст вызова.

## Декоратор для замера времени

```javascript
function withTiming(fn) {
  return function (...args) {
    const start = performance.now();
    const result = fn.apply(this, args);
    const end = performance.now();

    console.log(`Время: ${end - start}ms`);

    return result;
  };
}
```

## Декоратор для кэширования

```javascript
function memoize(fn) {
  const cache = new Map();

  return function (arg) {
    if (cache.has(arg)) {
      return cache.get(arg);
    }

    const result = fn.call(this, arg);
    cache.set(arg, result);
    return result;
  };
}
```

Здесь используется замыкание: `cache` живет между вызовами.

## Декоратор vs обертка

Обертка - общий прием "вызвать функцию внутри другой функции".

Декоратор - более конкретный паттерн: функция принимает `fn` и возвращает улучшенную версию `fn`.

## Мини-шпаргалка

```javascript
function decorator(fn) {
  return function (...args) {
    // до вызова
    const result = fn.apply(this, args);
    // после вызова
    return result;
  };
}
```

| Декоратор | Что добавляет |
| --- | --- |
| `withLog` | логирование |
| `withTiming` | замер времени |
| `memoize` | кэширование |
| `withRetry` | повторные попытки |
| `withAuth` | проверку прав |
