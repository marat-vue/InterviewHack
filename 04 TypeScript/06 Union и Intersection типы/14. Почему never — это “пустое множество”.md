# Почему never - это пустое множество

> [!summary] Коротко
> `never` называют пустым множеством, потому что у этого типа нет ни одного возможного значения. Нельзя создать значение типа `never`.

## Вопрос

Почему `never` - это "пустое множество"?

## Типы как множества

Если тип - это множество допустимых значений, то:

```typescript
type A = "yes" | "no";
```

`A` содержит два значения. А `never` не содержит ни одного.

```typescript
let value: never;
// value = "anything"; // ошибка
```

## Откуда появляется `never`

`never` появляется там, где варианты невозможны.

```typescript
type Impossible = string & number;
// never
```

Или когда union полностью исчерпан проверками.

```typescript
type Status = "success" | "error";

function handle(status: Status) {
  if (status === "success") return;
  if (status === "error") return;

  const impossible: never = status;
}
```

## `never` в union исчезает

```typescript
type Result = string | never;
// string
```

Добавление пустого множества ничего не меняет.

## `never` в intersection

```typescript
type Result = string & never;
// never
```

Пересечение с пустым множеством всегда пустое.

## Мини-шпаргалка

- `never` не имеет значений.
- `T | never` превращается в `T`.
- `T & never` превращается в `never`.
- `never` помогает проверять невозможные ветки.
