# Что такое interceptor?

> [!summary]
> Interceptor оборачивает выполнение route handler и может выполнить код до и после handler, трансформировать response, логировать время, добавлять cache или обрабатывать stream через RxJS.

## Пример logging interceptor

```ts
@Injectable()
export class LoggingInterceptor implements NestInterceptor {
  intercept(context: ExecutionContext, next: CallHandler) {
    const startedAt = Date.now();

    return next.handle().pipe(
      tap(() => console.log(`Done in ${Date.now() - startedAt}ms`)),
    );
  }
}
```

## Применение

```ts
@UseInterceptors(LoggingInterceptor)
@Controller('users')
export class UsersController {}
```

## Что умеют interceptors?

- bind extra logic before/after method;
- transform result;
- transform exception stream;
- cache response;
- timeout;
- logging/tracing.

## Мини-шпаргалка

- Interceptor реализует `NestInterceptor`.
- `next.handle()` возвращает Observable.
- Interceptor оборачивает route handler.
- Подходит для cross-cutting concerns.
- Для validation используй pipe, не interceptor.
