# Что делает атрибут rowspan

> [!summary]
> Атрибут `rowspan` объединяет ячейку таблицы по вертикали, позволяя ей занимать несколько строк.

## Главное

```html
<table>
  <tr>
    <th rowspan="2">Контакт</th>
    <td>Email</td>
  </tr>
  <tr>
    <td>Телефон</td>
  </tr>
</table>
```

`rowspan="2"` означает: ячейка занимает две строки.

## Где можно использовать

`rowspan` применяют к `td` и `th`.

```html
<td rowspan="3">Москва</td>
<th rowspan="2">Период</th>
```

## Пример

```html
<table>
  <tr>
    <th>Город</th>
    <th>Офис</th>
  </tr>
  <tr>
    <td rowspan="2">Москва</td>
    <td>Центральный</td>
  </tr>
  <tr>
    <td>Северный</td>
  </tr>
</table>
```

Ячейка `Москва` относится к двум строкам офисов.

## Чем отличается от colspan

```text
colspan -> объединение по горизонтали
rowspan -> объединение по вертикали
```

Оба атрибута помогают моделировать сложные таблицы, но их избыток усложняет чтение.

## Мини-шпаргалка

- `rowspan` объединяет строки.
- Значение показывает, сколько строк занимает ячейка.
- Работает на `td` и `th`.
- Полезен для группировки строк.
- Сложные rowspan-таблицы нужно особенно проверять на доступность.
