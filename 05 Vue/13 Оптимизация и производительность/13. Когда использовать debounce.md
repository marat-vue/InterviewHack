# Когда использовать debounce

> [!summary]
> **Debounce** откладывает вызов функции до тех пор, пока события не перестанут происходить в течение заданного времени.

## Главное

Debounce нужен, когда важно выполнить действие после паузы, а не на каждое событие.

```text
events:   x x x x       x x
debounce: --------x       ---x
```

Классический пример - поисковая строка. Пользователь печатает быстро, а запрос к API отправляется только после короткой паузы.

## Где использовать

- поиск по мере ввода;
- автосохранение формы;
- проверка доступности username;
- фильтрация тяжелой таблицы;
- обновление URL query после ввода;
- обработка resize, если нужен только финальный размер.

## Пример

```js
function debounce(callback, delay) {
  let timerId;

  return (...args) => {
    clearTimeout(timerId);

    timerId = setTimeout(() => {
      callback(...args);
    }, delay);
  };
}
```

```vue
<script setup>
import { ref, watch } from "vue";

const query = ref("");

const search = debounce(async (value) => {
  await fetch(`/api/search?q=${encodeURIComponent(value)}`);
}, 400);

watch(query, (value) => {
  search(value);
});
</script>

<template>
  <input v-model="query" placeholder="Поиск" />
</template>
```

## Debounce или throttle

Debounce ждет паузу. Throttle выполняет функцию с ограниченной частотой.

```text
Пользователь печатает запрос -> debounce
Пользователь скроллит страницу -> throttle
```

## Важный нюанс

Если компонент уничтожается, а debounce еще ждет таймер, иногда нужно отменить отложенное действие. Готовые утилиты вроде `lodash/debounce` обычно дают метод `cancel`.

## Мини-шпаргалка

- Debounce откладывает выполнение до паузы.
- Подходит для ввода, поиска и автосохранения.
- Уменьшает количество запросов и тяжелых пересчетов.
- Не подходит, если нужно реагировать регулярно во время события.
- Для постоянного потока событий чаще используют throttle.
