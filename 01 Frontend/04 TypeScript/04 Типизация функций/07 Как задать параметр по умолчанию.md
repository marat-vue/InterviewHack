# Как задать параметр по умолчанию?

> [!NOTE]
> Параметр по умолчанию задается через `=` прямо в списке параметров: `page = 1`. Если аргумент не передали или передали `undefined`, будет использовано дефолтное значение.

## Вопрос

Как задать параметр по умолчанию?

## Базовый синтаксис

```typescript
function greet(name = "Гость"): string {
  return `Привет, ${name}`;
}

greet(); // "Привет, Гость"
greet("Анна"); // "Привет, Анна"
```

TypeScript сам выводит тип `name` как `string`.

## Явная типизация

Если нужно, тип можно указать явно.

```typescript
function createPage(title: string, pageSize: number = 20): void {
  console.log(title, pageSize);
}
```

## Зависимость от предыдущих параметров

Дефолтное значение может использовать параметры, объявленные раньше.

```typescript
function createSlug(title: string, slug = title.toLowerCase()): string {
  return slug.replaceAll(" ", "-");
}
```

## `?` против `=`

```typescript
function optional(name?: string) {}
function withDefault(name = "Гость") {}
```

`name?: string` внутри функции имеет тип `string | undefined`. `name = "Гость"` внутри функции имеет тип `string`.

## Мини-шпаргалка

- `param = value` - параметр по умолчанию.
- Тип часто выводится автоматически.
- Переданный `undefined` тоже включает дефолт.
- Дефолтный параметр обычно удобнее, чем `param?: T`, если нужен запасной вариант.
