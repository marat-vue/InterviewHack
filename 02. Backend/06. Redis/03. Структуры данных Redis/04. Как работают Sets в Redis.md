# Как работают Sets в Redis?

> [!NOTE]
> Set - неупорядоченная коллекция уникальных members. Sets удобны для membership checks, tags, online users, permissions и операций пересечения/объединения.

## Когда использовать Set?

Set подходит для:

- online user ids;
- unique visitors;
- tags;
- user permissions;
- blacklist/allowlist;
- groups membership;
- “лайкнул ли пользователь пост”.

## Основные команды

```redis
SADD post:42:likes user:1
SADD post:42:likes user:2
SISMEMBER post:42:likes user:1
SCARD post:42:likes
SREM post:42:likes user:1
```

## Как получить members?

```redis
SMEMBERS post:42:likes
```

На большом set это опасно. Лучше:

```redis
SSCAN post:42:likes 0 COUNT 100
```

## Операции множеств

Пересечение:

```redis
SINTER user:1:tags user:2:tags
```

Объединение:

```redis
SUNION team:backend team:frontend
```

Разность:

```redis
SDIFF all:users banned:users
```

## Пример permissions

```redis
SADD user:1:permissions posts:create posts:delete admin:panel
SISMEMBER user:1:permissions posts:create
```

Node.js:

```ts
export async function can(userId: string, permission: string) {
  return redis.sIsMember(`user:${userId}:permissions`, permission);
}
```

## Set или Sorted Set?

| Задача | Структура |
|---|---|
| Только membership | Set |
| Нужен score/rank/order | Sorted Set |
| Нужна unique collection | Set |
| Нужен top-N | Sorted Set |

## Мини-шпаргалка

- Set хранит unique members.
- `SISMEMBER` - быстрый membership check.
- `SCARD` - размер set.
- `SINTER`/`SUNION`/`SDIFF` - операции множеств.
- Для больших sets используй `SSCAN`.
