# Как задать значение props по умолчанию?

> [!summary]
> Значение prop по умолчанию используют, когда родитель не передал prop или передал `undefined`. В современных функциональных компонентах чаще всего применяют default value прямо при деструктуризации параметров.

## Базовый пример

```jsx
function Avatar({ size = 80, src, alt = 'Аватар пользователя' }) {
  return (
    <img
      src={src}
      alt={alt}
      width={size}
      height={size}
    />
  )
}
```

Использование:

```jsx
<Avatar src="/user.png" />
```

Если `size` не передан, будет использовано `80`.

## Важный нюанс про null

Default value сработает для `undefined`, но не для `null`:

```jsx
function Button({ variant = 'primary' }) {
  return <button className={`button ${variant}`}>Сохранить</button>
}

<Button />                // variant = 'primary'
<Button variant={undefined} /> // variant = 'primary'
<Button variant={null} />      // variant = null
```

Если `null` нужно тоже заменить, делай явную проверку:

```jsx
const normalizedVariant = variant ?? 'primary'
```

## Default props для вложенных объектов

Осторожно с деструктуризацией:

```jsx
function UserCard({ user = {} }) {
  return <p>{user.name ?? 'Без имени'}</p>
}
```

Но лучше не прятать плохие данные слишком глубоко. Если `user` обязателен, пусть TypeScript или проверка данных покажут проблему.

## Старый вариант defaultProps

В legacy-коде можно встретить:

```jsx
function Button({ variant, children }) {
  return <button className={`button ${variant}`}>{children}</button>
}

Button.defaultProps = {
  variant: 'primary',
}
```

Для функциональных компонентов чаще используют default parameters.

## Когда default value полезен?

- Размеры и визуальные варианты.
- Текст fallback.
- Значение boolean-флага.
- Пустые массивы для списков.
- Callback no-op, если обработчик необязателен.

Пример no-op:

```jsx
function Modal({ onClose = () => {} }) {
  return <button onClick={onClose}>Закрыть</button>
}
```

## Мини-шпаргалка

- Default props чаще задают при деструктуризации.
- Default value срабатывает для `undefined`, но не для `null`.
- Не скрывай обязательные данные слишком агрессивными fallback.
- Для legacy-кода можно встретить `defaultProps`.
- В TypeScript optional props и defaults должны быть согласованы.
