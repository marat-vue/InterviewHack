# Что такое Storybook и зачем он нужен?

> [!summary]
> Storybook - инструмент для разработки, документации и тестирования UI-компонентов в изоляции. Он позволяет смотреть состояния компонентов без запуска всего приложения и превращает UI в живую библиотеку примеров.

## Простое определение

Storybook запускает отдельную среду, где каждый компонент можно открыть как story.

Story показывает конкретное состояние:

- primary button;
- disabled button;
- loading card;
- empty table;
- error alert;
- modal with long content.

## Зачем это frontend-разработчику?

Storybook помогает:

- разрабатывать компоненты в изоляции;
- документировать props и states;
- обсуждать UI с командой;
- ловить визуальные регрессии;
- писать interaction tests;
- собирать дизайн-систему.

## Story как пример использования

```ts
import type { Meta, StoryObj } from '@storybook/vue3-vite';
import BaseButton from './BaseButton.vue';

const meta = {
  component: BaseButton,
} satisfies Meta<typeof BaseButton>;

export default meta;

type Story = StoryObj<typeof meta>;

export const Primary: Story = {
  args: {
    variant: 'primary',
    label: 'Сохранить',
  },
};
```

## Storybook - это тесты?

Storybook сам по себе не заменяет unit/component/e2e tests. Но stories становятся базой для:

- ручной проверки состояний;
- документации;
- interaction tests;
- accessibility checks;
- visual regression tests.

## Мини-шпаргалка

- Storybook показывает компоненты в изоляции.
- Story - конкретное состояние компонента.
- Args позволяют менять props из UI.
- Storybook полезен для дизайн-систем.
- Он дополняет тесты, а не заменяет их полностью.
