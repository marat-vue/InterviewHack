# Почему доступность важна в веб-разработке. Кого она затрагивает?

> [!NOTE]
> Доступность важна, потому что вебом пользуются люди с разными возможностями, устройствами и условиями. Accessible-интерфейс снижает барьеры, улучшает UX и часто делает продукт качественнее для всех.

## Главное

Недоступный интерфейс может полностью заблокировать действие: пользователь не сможет оформить заказ, отправить форму, прочитать ошибку или перейти по меню.

```text
bad accessibility
  -> user cannot complete task
  -> lost conversion
  -> legal/product risk
  -> worse UX for everyone
```

## Кого затрагивает доступность

| Группа | Примеры потребностей |
| --- | --- |
| Пользователи скринридеров | Семантика, alt, правильные label |
| Пользователи клавиатуры | Фокус, порядок табуляции, доступные кнопки |
| Люди с нарушениями зрения | Контраст, масштабирование, понятная структура |
| Люди с нарушениями слуха | Субтитры, текстовые альтернативы аудио |
| Люди с моторными ограничениями | Крупные цели клика, клавиатура, отсутствие ловушек фокуса |
| Временные ситуации | Яркое солнце, сломанная мышь, медленный интернет |

## Пример: форма

```html
<label for="email">Email</label>
<input id="email" name="email" type="email" required>
```

Такая форма удобнее всем: можно кликнуть по подписи, браузер понимает тип поля, скринридер озвучивает label.

## Доступность улучшает качество кода

Accessible-интерфейс обычно требует:

- понятной семантики;
- предсказуемого состояния;
- явных ошибок;
- нормальной работы с клавиатуры;
- аккуратной структуры компонентов.

Это делает код устойчивее и понятнее.

## Важно

Доступность не сводится к ARIA. Часто лучший первый шаг - использовать правильные HTML-элементы: `button`, `a`, `label`, `fieldset`, `main`, `nav`.

## Мини-шпаргалка

- Доступность влияет на реальную возможность пользоваться продуктом.
- Она нужна не только незрячим пользователям.
- Клавиатура, контраст, семантика и формы - базовые части a11y.
- Хорошая доступность часто улучшает UX для всех.
- ARIA дополняет HTML, но не заменяет его.
