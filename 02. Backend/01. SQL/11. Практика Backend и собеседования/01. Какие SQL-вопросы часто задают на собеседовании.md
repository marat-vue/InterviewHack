# Какие SQL-вопросы часто задают на собеседовании?

> [!NOTE]
> На собеседованиях по SQL чаще всего проверяют не знание редких функций, а уверенность в базовых механиках: `JOIN`, `GROUP BY`, `NULL`, подзапросы, оконные функции, индексы и транзакции.

## Частые вопросы

| Тема | Вопрос |
|---|---|
| JOIN | Чем `INNER JOIN` отличается от `LEFT JOIN`? |
| NULL | Почему `= NULL` не работает? |
| GROUP BY | Чем `WHERE` отличается от `HAVING`? |
| Aggregates | Чем `COUNT(*)` отличается от `COUNT(column)`? |
| Subqueries | Когда использовать `EXISTS`? |
| Windows | Как выбрать последнюю запись в каждой группе? |
| Indexes | Почему индекс не всегда используется? |
| Transactions | Что такое isolation levels? |

## Как отвечать

Хороший ответ обычно содержит:

- определение;
- маленький пример;
- подводный камень;
- практический сценарий.

## Мини-шпаргалка

- Не заучивай только синтаксис.
- Умей объяснить порядок обработки запроса.
- Всегда упоминай `NULL`, если вопрос про сравнения или `COUNT`.
- Для производительности говори про `EXPLAIN`.
- Для транзакций говори про ACID и isolation.
