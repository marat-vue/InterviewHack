# Что такое `children`?

> [!summary]
> `children` - специальный prop, через который компонент получает JSX, вложенный между открывающим и закрывающим тегом. Он позволяет создавать гибкие компоненты-обертки: layout, card, modal, button, provider.

## Базовый пример

```jsx
function Card({ children }) {
  return <section className="card">{children}</section>
}

function App() {
  return (
    <Card>
      <h2>Профиль</h2>
      <p>Информация о пользователе</p>
    </Card>
  )
}
```

Все, что находится внутри `<Card>...</Card>`, попадет в prop `children`.

## Что может быть children?

`children` может быть:

- строкой;
- числом;
- JSX-элементом;
- массивом элементов;
- `null`;
- результатом условия;
- другим компонентом.

Пример:

```jsx
<Button>
  <IconSave />
  Сохранить
</Button>
```

## Когда использовать children?

Используй `children`, когда компонент не должен знать заранее, какой контент будет внутри:

- `Card`;
- `Modal`;
- `Layout`;
- `Tabs`;
- `Button`;
- `Tooltip`;
- `Provider`.

## children vs обычный prop

Обычный prop:

```jsx
<Page title="Настройки" />
```

`children`:

```jsx
<Page>
  <SettingsForm />
</Page>
```

Если передается основной вложенный контент, `children` обычно читабельнее.

## Частая ошибка

Не стоит делать компонент слишком магическим:

```jsx
function Card({ children }) {
  return <div>{children[0]} {children[3]}</div>
}
```

Если компонент зависит от конкретного порядка детей, лучше явно передать props или сделать compound components.

## Мини-шпаргалка

- `children` - содержимое между тегами компонента.
- Он нужен для компонентов-оберток.
- Через children можно передавать JSX.
- Основной контент часто удобнее передавать как children, а настройки - как props.
- Не делай хрупкую логику, завязанную на индекс children.
