# Что такое позиционирование элементов в CSS?

> [!NOTE]
> **Позиционирование в CSS** - это набор механизмов, которые управляют расположением элемента на странице: обычным потоком, `position`, смещениями, слоями и контекстами позиционирования.

## Главное

По умолчанию элементы располагаются в нормальном потоке документа.

```css
.box {
  position: static;
}
```

`position: static` - значение по умолчанию. Свойства `top`, `right`, `bottom`, `left` на него не влияют.

## Основные значения position

| Значение | Поведение |
| --- | --- |
| `static` | Обычный поток |
| `relative` | Остается в потоке, но может визуально смещаться |
| `absolute` | Выпадает из потока, позиционируется относительно containing block |
| `fixed` | Фиксируется относительно viewport |
| `sticky` | Ведет себя как relative, пока не "прилипнет" при скролле |

## Смещения

```css
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

`top`, `right`, `bottom`, `left` работают для позиционированных элементов, то есть не для `static`.

## z-index

```css
.modal {
  position: fixed;
  z-index: 1000;
}
```

`z-index` управляет наложением слоев, но работает внутри правил stacking context.

## Мини-шпаргалка

- По умолчанию элементы находятся в normal flow.
- `position: relative` сохраняет место в потоке.
- `absolute` выпадает из потока.
- `fixed` привязан к viewport.
- `sticky` зависит от скролла и границ родителя.
- `z-index` управляет слоями, но не всегда так просто, как кажется.
