# Как класс реализует интерфейс

> [!summary] Коротко
> Класс реализует интерфейс через `implements`. TypeScript проверяет, что у класса есть все поля и методы, описанные в интерфейсе.

## Вопрос

Как класс реализует интерфейс?

## Базовый пример

```typescript
interface Printable {
  print(): void;
}

class Invoice implements Printable {
  print(): void {
    console.log("Invoice");
  }
}
```

Если убрать `print`, класс перестанет соответствовать интерфейсу.

## Интерфейс с полями

```typescript
interface HasId {
  id: string;
}

class User implements HasId {
  constructor(public id: string, public name: string) {}
}
```

Класс может иметь больше полей, чем требует интерфейс.

## Несколько интерфейсов

```typescript
interface Serializable {
  toJSON(): string;
}

class Report implements Printable, Serializable {
  print(): void {}

  toJSON(): string {
    return "{}";
  }
}
```

## Важный нюанс

`implements` проверяет только instance-side класса. Статические методы и конструктор так напрямую не проверяются.

## Мини-шпаргалка

- `class A implements B` - класс обязан соответствовать интерфейсу.
- Все обязательные поля и методы должны быть реализованы.
- Можно реализовать несколько интерфейсов.
- `implements` не добавляет код, только проверяет типы.
