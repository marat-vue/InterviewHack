# Как работает рекурсия?

> [!summary]
> Рекурсия - подход, где функция вызывает саму себя для решения меньшей версии задачи. Чтобы рекурсия была корректной, нужны base case, recursive case и движение к завершению.

## Пример

```ts
function factorial(n: number): number {
  if (n <= 1) return 1
  return n * factorial(n - 1)
}
```

Здесь:

- base case: `n <= 1`;
- recursive case: `n * factorial(n - 1)`;
- progress: `n` уменьшается.

## Ментальная модель

```text
factorial(4)
4 * factorial(3)
4 * 3 * factorial(2)
4 * 3 * 2 * factorial(1)
4 * 3 * 2 * 1
```

## Где нужна рекурсия?

- деревья;
- DFS;
- backtracking;
- divide and conquer;
- dynamic programming top-down;
- парсинг вложенных структур.

## Что отвечать на собеседовании?

Рекурсия решает задачу через меньшие подзадачи. Для корректности нужны base case, recursive transition и гарантия, что мы приближаемся к base case. В JS нужно учитывать call stack: глубина рекурсии добавляет memory и может вызвать stack overflow.

## Частые ошибки

- Нет base case.
- Base case недостижим.
- Не уменьшается задача.
- Не учитывать return value.
- Не считать memory call stack.

## Мини-шпаргалка

- Base case.
- Recursive case.
- Progress.
- Stack memory.
- Деревья любят рекурсию.
- Большая глубина опасна в JS.
