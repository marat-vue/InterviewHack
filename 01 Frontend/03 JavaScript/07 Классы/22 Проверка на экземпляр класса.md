# Проверка на экземпляр класса

> [!NOTE]
> Проверить, создан ли объект определенным классом, можно через оператор `instanceof`.

## Вопрос

Как проверить, что объект является экземпляром класса?

## instanceof

`object instanceof ClassName` проверяет, есть ли `ClassName.prototype` в цепочке прототипов объекта.

```javascript
class User {}

const user = new User();

console.log(user instanceof User); // true
console.log(user instanceof Object); // true
```

## Наследование

```javascript
class Animal {}
class Dog extends Animal {}

const dog = new Dog();

console.log(dog instanceof Dog);    // true
console.log(dog instanceof Animal); // true
```

Экземпляр дочернего класса также считается экземпляром родительского.

## Когда instanceof может удивить

`instanceof` зависит от цепочки прототипов. Если объект пришел из другого iframe или realm, проверка встроенных классов может вести себя неожиданно.

Для массивов лучше использовать:

```javascript
Array.isArray(value);
```

## Проверка конструктора

```javascript
console.log(user.constructor === User); // true
```

Такую проверку используют реже, потому что `constructor` можно изменить или затереть.

## Мини-шпаргалка

```javascript
value instanceof ClassName;
object instanceof ParentClass;
Array.isArray(value); // лучше для массивов
```
