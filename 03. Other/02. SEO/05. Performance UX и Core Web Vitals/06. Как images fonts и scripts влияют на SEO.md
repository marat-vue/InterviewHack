# Как images, fonts и scripts влияют на SEO?

> [!summary]
> Изображения, шрифты и скрипты влияют на скорость загрузки, рендеринг, стабильность интерфейса и доступность контента. Для SEO это важно, потому что пользователь и поисковый робот должны быстро получить полезную страницу.

## Изображения

Изображения могут ухудшать:

- LCP;
- вес страницы;
- CLS;
- mobile UX.

Практики:

- отдавать нужный размер;
- использовать WebP/AVIF;
- задавать `width` и `height`;
- lazy-load только неважные изображения ниже первого экрана;
- оптимизировать hero отдельно.

## Шрифты

Шрифты могут вызывать:

- задержку текста;
- layout shift;
- лишние network requests.

Пример:

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-display: swap;
}
```

`font-display: swap` помогает быстрее показать текст.

## Скрипты

Скрипты могут ухудшать:

- INP;
- TTI;
- hydration;
- работу main thread;
- рендеринг первого экрана.

Практики:

- удалять ненужные библиотеки;
- делить bundle;
- грузить сторонние скрипты позже;
- использовать `defer` и `async` осознанно;
- измерять влияние аналитики, виджетов и чатов.

## Мини-шпаргалка

- Медиа и JS часто сильнее всего портят performance.
- Главное изображение требует отдельной оптимизации.
- Шрифты должны не блокировать чтение.
- Сторонние скрипты нужно ограничивать.
- Оптимизируй по данным, а не по ощущениям.
