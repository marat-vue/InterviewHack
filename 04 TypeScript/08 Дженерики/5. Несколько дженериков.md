# Несколько дженериков

> [!summary] Коротко
> Функция или тип может иметь несколько generic-параметров: `<T, U, R>`. Это нужно, когда разные части данных имеют разные, но связанные типы.

## Вопрос

Как использовать несколько дженериков?

## Базовый пример

```typescript
function pair<T, U>(first: T, second: U): [T, U] {
  return [first, second];
}

const result = pair("age", 30);
// [string, number]
```

`T` отвечает за первый аргумент, `U` - за второй.

## Преобразование массива

```typescript
function mapItems<T, R>(items: T[], mapper: (item: T) => R): R[] {
  return items.map(mapper);
}

const lengths = mapItems(["a", "hello"], (word) => word.length);
// number[]
```

## Связанные generic-параметры

Один generic может зависеть от другого.

```typescript
function getValue<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}

const name = getValue({ name: "Анна", age: 28 }, "name");
// string
```

## Хорошие имена

`T`, `U`, `K`, `V`, `R` - нормальны для коротких утилит. В бизнес-коде иногда читаемее `TUser`, `TResponse`, `TError`.

## Мини-шпаргалка

- Несколько generics пишутся через запятую: `<T, U>`.
- Каждый параметр типа должен иметь смысл.
- `K extends keyof T` - частый паттерн для ключей объекта.
- Не добавляй generic, если обычный тип проще.
