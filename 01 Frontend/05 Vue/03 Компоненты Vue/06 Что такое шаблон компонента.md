# Что такое шаблон компонента?

> [!NOTE] Коротко
> Шаблон компонента - HTML-подобная разметка внутри `<template>`, которая описывает, какой UI должен быть отрисован на основе состояния, props и computed-значений.

## Вопрос

Что такое шаблон компонента?

## Базовый пример

```vue
<script setup>
defineProps<{ title: string }>();
</script>

<template>
  <article>
    <h2>{{ title }}</h2>
  </article>
</template>
```

Шаблон выглядит как HTML, но понимает Vue-синтаксис: интерполяции, директивы, компоненты и события.

## Что можно использовать в шаблоне

```vue
<template>
  <p>{{ user.name }}</p>
  <button :disabled="isSaving" @click="save">Сохранить</button>
  <UserCard v-for="user in users" :key="user.id" :user="user" />
</template>
```

Здесь есть интерполяция, `v-bind`, `v-on`, `v-for`, `key` и дочерний компонент.

## Шаблон компилируется

Vue компилирует template в render-функцию. Поэтому шаблон - не просто строка HTML, а декларативное описание UI.

## Ограничение

В шаблоне лучше держать простые выражения. Сложную логику выносят в `computed` или методы.

```vue
<template>
  <p>{{ fullName }}</p>
</template>
```

## Мини-шпаргалка

- Template описывает UI компонента.
- Поддерживает интерполяции `{{ }}`.
- Директивы добавляют реактивное поведение.
- Сложную логику лучше выносить из шаблона.
