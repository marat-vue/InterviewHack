# Какие псевдоклассы вы знаете?

> [!NOTE]
> Псевдоклассы CSS можно группировать по назначению: состояния пользователя, состояния форм, структурные селекторы, ссылки, логические условия и пользовательские предпочтения.

## Состояния пользователя

```css
a:hover {
  color: #1d4ed8;
}

button:active {
  transform: translateY(1px);
}

:focus-visible {
  outline: 3px solid #2563eb;
}
```

Частые: `:hover`, `:active`, `:focus`, `:focus-visible`, `:focus-within`.

## Состояния форм

```css
input:disabled {
  opacity: 0.5;
}

input:checked {
  accent-color: #2563eb;
}

input:invalid {
  border-color: #b91c1c;
}
```

Частые: `:checked`, `:disabled`, `:enabled`, `:required`, `:optional`, `:valid`, `:invalid`.

## Структурные

```css
li:first-child {
  margin-top: 0;
}

li:nth-child(odd) {
  background: #f9fafb;
}
```

Частые: `:first-child`, `:last-child`, `:nth-child()`, `:nth-of-type()`, `:only-child`, `:empty`.

## Логические

```css
:is(h1, h2, h3) {
  line-height: 1.2;
}

.card:not(.is-featured) {
  opacity: 0.9;
}
```

Частые: `:not()`, `:is()`, `:where()`, `:has()`.

## Мини-шпаргалка

- `:hover` - наведение.
- `:focus-visible` - видимый фокус клавиатуры.
- `:checked` - отмеченный checkbox/radio.
- `:invalid` - невалидное поле.
- `:nth-child()` - выбор по порядку.
- `:has()` - выбор элемента по наличию потомка или условия.
