# Что такое index signature в интерфейсе

> [!summary] Коротко
> Index signature описывает тип значений для свойств, имена которых заранее неизвестны.

## Вопрос

Что означает запись `[key: string]: valueType`?

## Определение

Index signature позволяет сказать: у объекта могут быть любые ключи определенного типа, и значения по этим ключам должны иметь указанный тип.

## Пример

```typescript
interface Translations {
  [key: string]: string;
}

const messages: Translations = {
  hello: 'Привет',
  bye: 'Пока',
};
```

Любой строковый ключ должен иметь строковое значение.

## Числовой индекс

```typescript
interface NumberList {
  [index: number]: string;
}

const list: NumberList = {
  0: 'first',
  1: 'second',
};
```

## Известные свойства

```typescript
interface Config {
  mode: string;
  [key: string]: string;
}
```

Все строковые свойства должны быть совместимы со значением index signature.

## Частая ошибка

```typescript
interface Config {
  mode: string;
  timeout: number; // ошибка, если есть [key: string]: string
  [key: string]: string;
}
```

`timeout` тоже строковый ключ, значит его значение должно быть `string`.

## Record как альтернатива

```typescript
type Translations = Record<string, string>;
```

Для простых словарей `Record` часто короче.

## Мини-шпаргалка

```typescript
interface Dict {
  [key: string]: number;
}
```
