# Декларативность в React

> [!summary]
> Декларативность в React означает, что разработчик описывает желаемое состояние интерфейса, а React сам приводит DOM к этому состоянию. Мы пишем "что должно быть на экране", а не подробную инструкцию "как вручную поменять каждый DOM-узел".

## Императивный подход

В императивном коде ты сам управляешь шагами:

```js
const button = document.querySelector('#save')
const message = document.querySelector('#message')

button.disabled = true
message.textContent = 'Saving...'

saveUser().then(() => {
  button.disabled = false
  message.textContent = 'Saved'
})
```

Такой код быстро становится сложным: нужно помнить, где и когда поменять DOM, классы, тексты, disabled-состояния и обработчики.

## Декларативный подход

В React состояние становится источником правды, а UI выражается как функция от состояния.

```jsx
function SaveButton() {
  const [status, setStatus] = useState('idle')

  const isSaving = status === 'saving'

  return (
    <>
      <button disabled={isSaving} onClick={() => setStatus('saving')}>
        Save
      </button>
      <p>{isSaving ? 'Saving...' : 'Ready'}</p>
    </>
  )
}
```

Ты не говоришь React: "найди кнопку, поставь disabled, найди параграф, поменяй текст". Ты описываешь UI для каждого состояния.

## Почему это удобно?

Декларативность дает:

- предсказуемость;
- меньше ручной работы с DOM;
- проще читать состояния экрана;
- проще тестировать;
- проще переиспользовать компоненты;
- меньше рассинхронизации между данными и UI.

## Как отвечать на собеседовании?

Хороший ответ:

```text
React декларативен, потому что я описываю UI как результат текущего state и props.
Когда state меняется, React заново вычисляет дерево компонентов и сам решает,
какие изменения нужно применить к DOM.
```

## Мини-шпаргалка

- Императивно: "как пошагово поменять DOM".
- Декларативно: "что должно быть показано при таких данных".
- React-компонент похож на функцию от `props` и `state`.
- Декларативность хорошо сочетается с чистым render.
- DOM-операции остаются внутри React, а не размазываются по коду.
