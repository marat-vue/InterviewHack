# Как проводить keyword research?

> [!summary]
> Keyword research - это поиск и группировка запросов, по которым аудитория ищет продукт, знания или решение проблемы. Его цель - не собрать максимум слов, а понять спрос, намерения и структуру будущих страниц.

## С чего начать?

Начни не с инструмента, а с тем:

```text
Продукт: онлайн-школа frontend
Темы: JavaScript, Vue, TypeScript, собеседования, проекты, тестирование
```

Потом расширяй темы в запросы:

```text
vue router guards
как работает event loop
typescript generics простыми словами
вопросы по javascript на собеседовании
```

## Как группировать ключи?

Запросы нужно кластеризовать по intent и странице.

Пример:

| Запрос | Intent | Страница |
|---|---|---|
| `что такое vite` | informational | статья |
| `vite настройка vue` | informational/practical | гайд |
| `vite react шаблон` | transactional/practical | шаблон или документация |

## Какие метрики смотреть?

- Частотность.
- Конкурентность.
- Сложность ранжирования.
- Текущие позиции.
- Потенциал конверсии.
- Сезонность.
- SERP features.

Но метрики не должны заменять здравый смысл: низкочастотный запрос может приводить очень ценных пользователей.

## Как выбрать приоритет?

Оцени:

```text
Приоритет = спрос + бизнес-ценность + реалистичность + соответствие экспертизе
```

Если тема важна для продукта и ты можешь раскрыть ее лучше конкурентов, она может быть приоритетной даже при средней частотности.

## Мини-шпаргалка

- Keyword research начинается с понимания аудитории.
- Ключи группируют по intent, а не просто по похожим словам.
- Один кластер обычно соответствует одной странице.
- Важны не только частотность, но и бизнес-ценность.
- Хороший keyword research превращается в карту контента.
