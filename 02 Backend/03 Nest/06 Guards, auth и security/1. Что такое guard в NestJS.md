# Что такое guard в NestJS?

> [!summary]
> Guard решает, будет ли request обработан route handler. Обычно guards используют для authentication, authorization, roles, permissions и feature access.

## Пример guard

```ts
@Injectable()
export class AuthGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();

    return Boolean(request.headers.authorization);
  }
}
```

## Применение

```ts
@UseGuards(AuthGuard)
@Get('profile')
getProfile() {
  return {};
}
```

## Где guard в lifecycle?

Guard выполняется после middleware и до pipes/controller handler. Если guard вернет `false` или выбросит exception, handler не выполнится.

## Мини-шпаргалка

- Guard решает, пускать request дальше или нет.
- Интерфейс: `CanActivate`.
- Метод: `canActivate`.
- Используется через `@UseGuards`.
- Authentication и authorization часто реализуются guards.
