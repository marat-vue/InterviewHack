# Как ограничить generic-тип ключами другого типа

> [!summary] Коротко
> Чтобы generic-параметр был только ключом другого типа, используют связку `K extends keyof T`.

## Вопрос

Как ограничить generic-тип ключами другого типа?

## Базовый пример

```typescript
function getProperty<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}

const user = {
  id: 1,
  name: "Анна",
  email: "anna@example.com",
};

const name = getProperty(user, "name");
// string
```

`K` может быть только одним из ключей `T`.

## Ошибка при неверном ключе

```typescript
// getProperty(user, "age"); // ошибка
```

TypeScript знает, что `"age"` нет среди `"id" | "name" | "email"`.

## Возвращаемый тип зависит от ключа

```typescript
const id = getProperty(user, "id");
// number

const email = getProperty(user, "email");
// string
```

Это возможно благодаря `T[K]` - indexed access type.

## Практический helper

```typescript
function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
  return items.map((item) => item[key]);
}
```

## Мини-шпаргалка

- `keyof T` получает union ключей типа `T`.
- `K extends keyof T` ограничивает `K` этими ключами.
- `T[K]` достает тип значения по ключу.
- Паттерн полезен для helpers над объектами.
