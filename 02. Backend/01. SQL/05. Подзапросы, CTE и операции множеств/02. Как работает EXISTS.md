# Как работает EXISTS?

> [!NOTE]
> `EXISTS` проверяет, возвращает ли подзапрос хотя бы одну строку. Он часто используется для проверки наличия связанных записей и может быть лучше, чем `JOIN`, если не нужно выводить данные из связанной таблицы.

## Пример

```sql
SELECT *
FROM users u
WHERE EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
);
```

Запрос возвращает пользователей, у которых есть хотя бы один заказ.

## NOT EXISTS

```sql
SELECT *
FROM users u
WHERE NOT EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
);
```

Так можно найти пользователей без заказов.

## Почему SELECT 1?

Внутри `EXISTS` важен не список колонок, а факт наличия строки. Поэтому часто пишут `SELECT 1`.

## EXISTS vs JOIN

`JOIN` размножает строки при one-to-many. `EXISTS` просто проверяет существование.

## Мини-шпаргалка

- `EXISTS` проверяет наличие строки.
- `NOT EXISTS` проверяет отсутствие.
- Внутри часто пишут `SELECT 1`.
- Хорош для semi join и anti join.
- Помогает избежать дублей от `JOIN`.
