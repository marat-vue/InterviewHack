# Что такое хук в React?

> [!summary]
> Хук - это специальная функция React, которая позволяет функциональному компоненту использовать state, effects, refs, context, reducer и другие возможности React. Хуки начинаются с `use` и вызываются только на верхнем уровне компонента или custom hook.

## Простое определение

Хук дает компоненту доступ к React-возможности:

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

`useState` - хук для состояния.

## Почему хуки называются hooks?

Идея: компонент "подключается" к внутренним механизмам React.

Примеры:

- `useState` - подключает state;
- `useEffect` - подключает effects;
- `useRef` - хранит mutable ref;
- `useContext` - читает context;
- `useReducer` - подключает reducer state;
- `useMemo` - мемоизирует вычисление;
- `useCallback` - мемоизирует функцию.

## Как отличить хук?

Хук:

- начинается с `use`;
- вызывается в React-компоненте или custom hook;
- должен вызываться в одинаковом порядке;
- не вызывается внутри условий, циклов и вложенных функций;
- может использовать другие хуки, если это custom hook.

## Что такое custom hook?

Custom hook - твоя функция, которая использует встроенные хуки:

```jsx
function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue)

  function toggle() {
    setValue((value) => !value)
  }

  return [value, toggle]
}
```

Использование:

```jsx
const [isOpen, toggleOpen] = useToggle()
```

## Мини-шпаргалка

- Хук - функция для подключения React-возможностей.
- Название хука начинается с `use`.
- Хуки вызывают только на верхнем уровне.
- Хуки нельзя вызывать в условиях и циклах.
- Custom hooks позволяют переиспользовать логику.
