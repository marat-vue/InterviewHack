> [!summary]
> Семантический HTML помогает поисковым системам лучше понять структуру страницы: где основной контент, какие заголовки важны, что является навигацией, статьей, изображением или ссылкой.

## Главное

Семантика сама по себе не является волшебной кнопкой для высоких позиций. Но она помогает поисковому роботу корректно интерпретировать страницу и снижает риск неправильного понимания контента.

```html
<main>
  <article>
    <h1>Как выбрать велосипед</h1>
    <p>Подробное руководство для новичков.</p>
  </article>
</main>
```

Такой код понятнее, чем набор одинаковых `div`.

## Что особенно важно

- Один понятный `h1` для основной темы страницы.
- Логичная иерархия `h2`-`h6`.
- Основной контент внутри `<main>`.
- Навигация внутри `<nav>`.
- Самостоятельные материалы внутри `<article>`.
- Понятные тексты ссылок.
- Описательные `alt` у значимых изображений.

## Пример хорошей структуры

```html
<body>
  <header>
    <nav aria-label="Основная навигация">...</nav>
  </header>

  <main>
    <h1>Каталог ноутбуков</h1>

    <section>
      <h2>Игровые ноутбуки</h2>
      ...
    </section>
  </main>
</body>
```

Поисковику проще понять, что является навигацией, что главным содержимым, а что подразделом каталога.

## Ссылки и SEO

Текст ссылки должен объяснять, куда она ведет.

```html
<!-- хуже -->
<a href="/delivery">Подробнее</a>

<!-- лучше -->
<a href="/delivery">Условия доставки</a>
```

Понятный anchor text полезен и пользователям, и поисковым системам.

## Изображения

```html
<img
  src="/bike.jpg"
  alt="Горный велосипед с алюминиевой рамой"
>
```

`alt` помогает понять содержимое изображения, если оно не загрузилось или пользователь работает со скринридером.

## Мини-шпаргалка

- Семантика помогает поисковику понять страницу.
- Заголовки должны образовывать логичную структуру.
- `<main>`, `<nav>`, `<article>`, `<section>` дают контекст.
- Текст ссылок должен быть конкретным.
- `alt` важен для значимых изображений.
- Семантика помогает SEO косвенно, через понятность и качество структуры.
