# Что такое e2e test в NestJS?

> [!summary]
> E2E test проверяет приложение ближе к реальному HTTP-сценарию: поднимает Nest application, отправляет requests через supertest и проверяет полный путь через routing, pipes, guards, interceptors и controllers.

## Пример

```ts
describe('Users e2e', () => {
  let app: INestApplication;

  beforeEach(async () => {
    const moduleRef = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleRef.createNestApplication();
    app.useGlobalPipes(new ValidationPipe({ whitelist: true }));
    await app.init();
  });

  afterEach(async () => {
    await app.close();
  });

  it('/users (GET)', () => {
    return request(app.getHttpServer())
      .get('/users')
      .expect(200);
  });
});
```

## Что проверять e2e?

- routing;
- validation;
- auth;
- error format;
- serialization;
- integration с test database.

## Мини-шпаргалка

- E2E поднимает Nest application.
- Supertest отправляет HTTP requests.
- `app.init()` запускает приложение для теста.
- `app.close()` освобождает ресурсы.
- E2E дороже unit-тестов, но проверяет полный flow.
