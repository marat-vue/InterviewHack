# Зачем нужно сужение типов?

> [!NOTE]
> Сужение типов нужно, чтобы безопасно работать с union, `unknown` и данными из внешних источников. После проверки TypeScript разрешает использовать свойства конкретного варианта.

## Вопрос

Зачем нужно сужение типов?

## Проблема без сужения

```typescript
function print(value: string | number) {
  // value.toUpperCase(); // ошибка
}
```

У `number` нет `toUpperCase`, поэтому TypeScript не разрешает вызвать метод без проверки.

## Решение

```typescript
function print(value: string | number) {
  if (typeof value === "string") {
    console.log(value.toUpperCase());
  } else {
    console.log(value.toFixed(2));
  }
}
```

Теперь каждая ветка работает со своим точным типом.

## Для unknown

```typescript
function parse(value: unknown): string {
  if (typeof value === "string") {
    return value.trim();
  }

  return "";
}
```

`unknown` вынуждает сначала проверить данные, и это делает код безопаснее.

## Для UI-состояний

```typescript
type State =
  | { status: "loading" }
  | { status: "success"; data: string[] }
  | { status: "error"; message: string };

function render(state: State) {
  if (state.status === "success") {
    return state.data.join(", ");
  }
}
```

## Мини-шпаргалка

- Сужение защищает от обращения к несуществующим свойствам.
- Особенно важно для union и `unknown`.
- Проверки превращают широкий тип в конкретный.
- Хорошее моделирование типов упрощает narrowing.
