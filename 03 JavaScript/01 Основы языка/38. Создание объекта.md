# Создание объекта

> [!summary] Коротко
> Чаще всего объекты создают через литерал `{}`. Также есть `new Object()`, функции-конструкторы, классы, `Object.create()` и фабричные функции.

## Вопрос

Какие способы создания объекта вы знаете?

## Литерал объекта

Самый частый и удобный способ.

```javascript
const user = {
  name: "Anna",
  age: 25,
};
```

Подходит для обычных данных и конфигураций.

## `new Object()`

```javascript
const user = new Object();

user.name = "Anna";
```

Работает, но используется редко. Литерал `{}` короче и привычнее.

## Функция-конструктор

```javascript
function User(name) {
  this.name = name;
}

const user = new User("Anna");
```

Такой стиль часто встречается в старом коде.

Методы обычно кладут в прототип:

```javascript
User.prototype.sayHi = function () {
  return `Hi, ${this.name}`;
};
```

## Класс

```javascript
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}

const user = new User("Anna");
```

Класс - современный синтаксис для создания объектов с общим поведением.

## `Object.create`

Создает объект с указанным прототипом.

```javascript
const userProto = {
  sayHi() {
    return `Hi, ${this.name}`;
  },
};

const user = Object.create(userProto);
user.name = "Anna";

user.sayHi(); // "Hi, Anna"
```

Можно создать объект без прототипа:

```javascript
const dictionary = Object.create(null);
```

Такой объект не наследует `toString`, `constructor` и другие свойства.

## Фабричная функция

Функция просто возвращает объект.

```javascript
function createUser(name) {
  return {
    name,
    sayHi() {
      return `Hi, ${name}`;
    },
  };
}

const user = createUser("Anna");
```

Не требует `new`.

## Мини-шпаргалка

| Способ | Пример | Когда использовать |
| --- | --- | --- |
| Литерал | `{ name: "Anna" }` | почти всегда для простых объектов |
| `new Object()` | `new Object()` | редко |
| Конструктор | `new User()` | legacy и прототипы |
| Класс | `new User()` | модели с поведением |
| `Object.create()` | `Object.create(proto)` | контроль прототипа |
| Фабрика | `createUser()` | объект без `new` |
