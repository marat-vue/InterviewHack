# Подключение Material UI и базовые компоненты

> [!summary]
> Material UI подключается через `@mui/material` и Emotion packages. После установки можно импортировать компоненты из `@mui/material` и использовать их как обычные React-компоненты.

## Установка

```bash
npm install @mui/material @emotion/react @emotion/styled
```

Для иконок:

```bash
npm install @mui/icons-material
```

## Первый компонент

```tsx
import Button from '@mui/material/Button'

function App() {
  return (
    <Button variant="contained" color="primary">
      Save
    </Button>
  )
}
```

## Варианты Button

```tsx
<Button variant="text">Text</Button>
<Button variant="outlined">Outlined</Button>
<Button variant="contained">Contained</Button>
```

Частые props:

- `variant`;
- `color`;
- `size`;
- `disabled`;
- `startIcon`;
- `endIcon`;
- `onClick`.

## TextField

```tsx
import TextField from '@mui/material/TextField'

function LoginForm() {
  return (
    <TextField
      label="Email"
      type="email"
      name="email"
      required
      fullWidth
    />
  )
}
```

`TextField` объединяет label, input, helper text и error state.

## Layout компоненты

```tsx
import Box from '@mui/material/Box'
import Stack from '@mui/material/Stack'
import Container from '@mui/material/Container'

function Page() {
  return (
    <Container maxWidth="lg">
      <Stack spacing={2}>
        <Box>Header</Box>
        <Box>Main</Box>
      </Stack>
    </Container>
  )
}
```

## Dialog

```tsx
import Dialog from '@mui/material/Dialog'
import DialogTitle from '@mui/material/DialogTitle'
import DialogContent from '@mui/material/DialogContent'

function ConfirmDialog({ open, onClose }: Props) {
  return (
    <Dialog open={open} onClose={onClose}>
      <DialogTitle>Delete item?</DialogTitle>
      <DialogContent>This action cannot be undone.</DialogContent>
    </Dialog>
  )
}
```

## Что отвечать на собеседовании?

MUI подключается через `@mui/material` и Emotion. Компоненты импортируются по имени и управляются props. Для layout часто используют `Box`, `Stack`, `Grid`, `Container`; для форм - `TextField`, `Select`, `Checkbox`; для overlay - `Dialog`, `Drawer`, `Menu`, `Snackbar`.

## Мини-шпаргалка

- Установка: `@mui/material @emotion/react @emotion/styled`.
- Icons: `@mui/icons-material`.
- Button variants: `text`, `outlined`, `contained`.
- TextField props: `label`, `error`, `helperText`, `fullWidth`.
- Layout: `Box`, `Stack`, `Container`.
