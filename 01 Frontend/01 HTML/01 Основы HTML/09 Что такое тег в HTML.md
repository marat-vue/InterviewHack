# Что такое тег в HTML?

> [!NOTE]
> **Тег** - это синтаксическая конструкция HTML, с помощью которой создаются элементы. Теги обычно записываются в угловых скобках: `<p>`, `<a>`, `<img>`, `<button>`.

## Главное

Тег - это то, что написано в HTML-коде. Элемент - это то, что получается в документе после обработки браузером.

```html
<p>Привет</p>
```

Здесь:

- `<p>` - открывающий тег;
- `</p>` - закрывающий тег;
- `<p>Привет</p>` - HTML-элемент;
- `Привет` - содержимое элемента.

## Парные теги

Большинство тегов имеют начало и конец.

```html
<h1>Заголовок</h1>
<p>Абзац текста</p>
<button type="button">Открыть</button>
```

Закрывающий тег показывает, где заканчивается содержимое элемента.

## Void-элементы

Некоторые элементы не имеют содержимого и закрывающего тега.

```html
<img src="/photo.jpg" alt="Фото профиля">
<input type="email" name="email">
<br>
<hr>
```

Их называют void elements. В HTML им не нужен закрывающий тег.

## Вложенность тегов

Теги должны закрываться в правильном порядке.

```html
<!-- правильно -->
<p>Текст <strong>важный</strong></p>

<!-- неправильно -->
<p>Текст <strong>важный</p></strong>
```

Неправильная вложенность может привести к неожиданному DOM.

## Мини-шпаргалка

- Тег записывается в угловых скобках.
- Элемент состоит из тегов, содержимого и атрибутов.
- Парные теги имеют открытие и закрытие.
- Void-элементы не имеют содержимого.
- Вложенность должна быть корректной.
