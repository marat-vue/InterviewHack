# `yield` в генераторах

> [!summary] Коротко
> `yield` отдает значение из генератора наружу и ставит выполнение на паузу. Следующий вызов `.next()` продолжает выполнение сразу после этого `yield`.

## Вопрос

Как работает `yield`?

## Базовый пример

```javascript
function* gen() {
  yield 1;
  yield 2;
}

const iterator = gen();

iterator.next(); // { value: 1, done: false }
iterator.next(); // { value: 2, done: false }
iterator.next(); // { value: undefined, done: true }
```

Каждый `yield` - точка остановки.

## Что возвращает `.next()`

`.next()` возвращает объект:

```javascript
{
  value: any,
  done: boolean
}
```

- `value` - значение, отданное через `yield` или `return`;
- `done` - завершен ли генератор.

## `yield` ставит функцию на паузу

```javascript
function* demo() {
  console.log("A");
  yield 1;
  console.log("B");
  yield 2;
  console.log("C");
}

const g = demo();

g.next(); // печатает "A"
g.next(); // печатает "B"
g.next(); // печатает "C"
```

## Передача значения внутрь генератора

Значение, переданное в `.next(value)`, становится результатом предыдущего `yield`.

```javascript
function* askName() {
  const name = yield "Как тебя зовут?";
  return `Привет, ${name}`;
}

const g = askName();

g.next();        // { value: "Как тебя зовут?", done: false }
g.next("Anna");  // { value: "Привет, Anna", done: true }
```

Первый `.next()` запускает генератор. Его аргумент обычно игнорируется, потому что еще нет предыдущего `yield`.

## `return` и `yield`

```javascript
function* gen() {
  yield 1;
  return 2;
  yield 3;
}

const g = gen();

g.next(); // { value: 1, done: false }
g.next(); // { value: 2, done: true }
g.next(); // { value: undefined, done: true }
```

После `return` генератор завершен.

## `yield*`

```javascript
function* gen() {
  yield 1;
  yield* [2, 3];
  yield 4;
}

[...gen()]; // [1, 2, 3, 4]
```

`yield*` передает управление другому iterable.

## Мини-шпаргалка

| Конструкция | Что делает |
| --- | --- |
| `yield value` | отдает `value` и ставит паузу |
| `.next()` | продолжает до следующего `yield` |
| `.next(value)` | передает значение в прошлый `yield` |
| `return value` | завершает генератор |
| `yield* iterable` | делегирует значения |
