# Что делает position absolute

> [!summary]
> `position: absolute` убирает элемент из нормального потока документа и позиционирует его относительно ближайшего позиционированного предка или другого containing block.

## Главное

```css
.tooltip {
  position: absolute;
  top: 100%;
  left: 0;
}
```

Элемент больше не занимает место в обычном потоке, поэтому соседние элементы ведут себя так, будто его нет.

## Относительно чего позиционируется

Абсолютный элемент ищет ближайшего предка, у которого `position` не `static`.

```css
.card {
  position: relative;
}

.card__badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

```html
<article class="card">
  <span class="card__badge">New</span>
  <h2>Товар</h2>
</article>
```

Бейдж привязан к карточке, потому что у карточки есть `position: relative`.

## Если позиционированного предка нет

Если подходящего предка нет, элемент позиционируется относительно начального containing block, обычно близкого к viewport/document.

Именно поэтому для tooltip, badge и dropdown часто явно ставят `position: relative` на контейнер.

## Смещения

```css
.modal-close {
  position: absolute;
  top: 12px;
  right: 12px;
}
```

`top`, `right`, `bottom`, `left` задают расстояние от соответствующих сторон containing block.

## Мини-шпаргалка

- `absolute` убирает элемент из потока.
- Соседи не учитывают его размер.
- Позиционируется относительно ближайшего позиционированного предка.
- Родителю часто ставят `position: relative`.
- Полезен для бейджей, подсказок, декоративных слоев и кнопок закрытия.
