# Что такое exception filter?

> [!summary]
> Exception filter перехватывает exceptions и управляет форматом ответа об ошибке. NestJS уже имеет встроенный exceptions layer, но custom filters нужны для единого формата ошибок, логирования и mapping domain errors.

## Пример filter

```ts
@Catch(HttpException)
export class HttpExceptionFilter implements ExceptionFilter {
  catch(exception: HttpException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const status = exception.getStatus();

    response.status(status).json({
      statusCode: status,
      message: exception.message,
    });
  }
}
```

## Где применять?

```ts
@UseFilters(HttpExceptionFilter)
@Controller('users')
export class UsersController {}
```

Или глобально:

```ts
app.useGlobalFilters(new HttpExceptionFilter());
```

## Мини-шпаргалка

- Filter управляет error response.
- Built-in exceptions layer уже есть.
- Custom filter нужен для единого формата.
- `ArgumentsHost` дает доступ к context.
- Для microservices filters имеют отличия.
