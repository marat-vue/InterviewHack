# Возвращаемое значение генератора

> [!NOTE]
> Вызов `function*` не выполняет тело функции сразу. Он возвращает объект-генератор: итератор, который можно продвигать через `.next()`.

## Вопрос

Что возвращает вызов генератора?

## Базовый пример

```javascript
function* gen() {
  yield 1;
  yield 2;
}

const iterator = gen();
```

`iterator` - не число и не массив. Это объект-генератор.

```javascript
iterator.next(); // { value: 1, done: false }
iterator.next(); // { value: 2, done: false }
iterator.next(); // { value: undefined, done: true }
```

## Что возвращает `.next()`

Каждый вызов `.next()` возвращает объект:

```javascript
{
  value: any,
  done: boolean
}
```

- `value` - значение из ближайшего `yield` или `return`;
- `done` - завершился ли генератор.

## Генератор одновременно iterator и iterable

```javascript
const iterator = gen();

typeof iterator.next; // "function"
```

И его можно перебирать:

```javascript
for (const value of gen()) {
  console.log(value);
}
```

Можно собрать значения в массив:

```javascript
[...gen()]; // [1, 2]
```

## `return` в генераторе

```javascript
function* gen() {
  yield 1;
  return 2;
}

const iterator = gen();

iterator.next(); // { value: 1, done: false }
iterator.next(); // { value: 2, done: true }
```

Значение `return` видно при ручном вызове `.next()`, но не попадает в `for...of`.

```javascript
[...gen()]; // [1]
```

## Повторное использование

Один объект-генератор нельзя "перезапустить".

```javascript
const iterator = gen();

[...iterator]; // [1]
[...iterator]; // []
```

Чтобы пройти заново, нужно вызвать генераторную функцию еще раз.

```javascript
[...gen()]; // [1]
[...gen()]; // [1]
```

## Мини-шпаргалка

| Выражение | Что возвращает |
| --- | --- |
| `gen()` | объект-генератор |
| `iterator.next()` | `{ value, done }` |
| `yield value` | `value` наружу и пауза |
| `return value` | завершение генератора |
| `[...gen()]` | массив значений `yield` |
