# Что делает not-found.tsx в Next JS?

> [!summary]
> `not-found.tsx` задает UI для 404-состояния в App Router. Он может быть глобальным для всего приложения или локальным для конкретного сегмента, а вызвать его можно через функцию `notFound()` из `next/navigation`.

## Где создать not-found.tsx?

Глобальный 404:

```text
app/
  not-found.tsx
```

Локальный 404 для blog:

```text
app/
  blog/
    [slug]/
      page.tsx
      not-found.tsx
```

## Пример not-found.tsx

```tsx
import Link from 'next/link'

export default function NotFound() {
  return (
    <main>
      <h1>Страница не найдена</h1>
      <Link href="/">Вернуться на главную</Link>
    </main>
  )
}
```

## Как вызвать notFound()

```tsx
import { notFound } from 'next/navigation'

export default async function PostPage({ params }: Props) {
  const { slug } = await params
  const post = await getPost(slug)

  if (!post) {
    notFound()
  }

  return <Article post={post} />
}
```

`notFound()` прерывает render текущего route segment и показывает ближайший `not-found.tsx`.

## Когда использовать?

- товара нет в базе;
- статья удалена;
- user profile не публичен;
- slug не существует;
- API вернул 404 для ресурса.

## not-found vs error

| Сценарий | Что использовать |
|---|---|
| ресурс не найден | `notFound()` + `not-found.tsx` |
| неожиданная ошибка | `throw error` + `error.tsx` |
| глобальная фатальная ошибка | `global-error.tsx` |

404 - это ожидаемое состояние, а не обязательно ошибка приложения.

## Что отвечать на собеседовании?

`not-found.tsx` описывает UI для 404 в App Router. Его можно разместить глобально или внутри сегмента. Функция `notFound()` из `next/navigation` останавливает render и показывает ближайший `not-found.tsx`.

## Частые ошибки

- Использовать `error.tsx` для обычного 404.
- Возвращать пустой UI при отсутствии ресурса.
- Не делать ссылку назад или на главную.
- Путать unmatched route и ресурс, не найденный в БД.
- Забывать локальный `not-found.tsx` для важных разделов.

## Мини-шпаргалка

- Файл: `not-found.tsx`.
- Вызов: `notFound()`.
- Импорт: `next/navigation`.
- Ближайший `not-found.tsx` выигрывает.
- 404 лучше отделять от unexpected errors.
