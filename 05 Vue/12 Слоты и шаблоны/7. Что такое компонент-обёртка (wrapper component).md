# Что такое компонент-обертка (wrapper component)

> [!summary]
> **Компонент-обертка** - это компонент, который оборачивает другой контент или компонент, добавляя общую разметку, стили, поведение, валидацию или интеграцию с библиотекой.

## Главное

Wrapper component позволяет один раз описать повторяющуюся оболочку и использовать ее в разных местах приложения.

```vue
<!-- BasePanel.vue -->
<template>
  <section class="panel">
    <slot />
  </section>
</template>
```

```vue
<BasePanel>
  <h2>Заказы</h2>
  <p>Здесь отображается список последних заказов.</p>
</BasePanel>
```

`BasePanel` не знает, какой контент ему передадут. Его задача - дать единый внешний вид и структуру.

## Для чего используются компоненты-обертки

- Единые UI-оболочки: карточки, панели, секции, модальные окна.
- Обертки над нативными элементами: инпуты, кнопки, формы.
- Обертки над сторонними библиотеками.
- Добавление логики: обработка ошибок, доступность, загрузка, ограничения доступа.
- Сокрытие деталей реализации от остального приложения.

## Пример: обертка над input

```vue
<!-- BaseInput.vue -->
<script setup>
defineProps({
  label: {
    type: String,
    required: true,
  },
});

const model = defineModel();
</script>

<template>
  <label class="field">
    <span class="field__label">{{ label }}</span>
    <input v-model="model" class="field__control" />
  </label>
</template>
```

```vue
<script setup>
import { ref } from "vue";
import BaseInput from "./BaseInput.vue";

const email = ref("");
</script>

<template>
  <BaseInput v-model="email" label="Email" />
</template>
```

Родителю не нужно каждый раз писать `label`, классы и `v-model`-связку вручную.

## Пример: проброс атрибутов

Иногда wrapper должен передавать атрибуты внутрь конкретного элемента.

```vue
<!-- SearchInput.vue -->
<script setup>
defineOptions({
  inheritAttrs: false,
});

defineProps({
  label: String,
});
</script>

<template>
  <label class="search">
    <span>{{ label }}</span>
    <input v-bind="$attrs" type="search" />
  </label>
</template>
```

```vue
<SearchInput
  label="Поиск"
  placeholder="Введите название"
  autocomplete="off"
/>
```

`placeholder` и `autocomplete` попадут на `<input>`, а не на корневой `<label>`.

## Когда быть осторожнее

Слишком толстая обертка может скрыть важные возможности базового компонента. Хорошая обертка упрощает частый сценарий, но не превращается в универсальный комбайн на десятки пропсов.

## Мини-шпаргалка

- Wrapper component добавляет оболочку вокруг контента или другого компонента.
- Для гибкого контента обычно используются слоты.
- Для проброса HTML-атрибутов используют `$attrs`.
- Хорошая обертка уменьшает повторение и делает UI единообразным.
- Плохая обертка прячет слишком много деталей и становится сложнее исходного компонента.
