# Что такое microservice в NestJS?

> [!summary]
> Microservice в NestJS - приложение или часть приложения, которая общается не через обычный HTTP controller, а через transport layer: TCP, Redis, NATS, MQTT, Kafka, gRPC или RabbitMQ.

## MessagePattern

```ts
@Controller()
export class MathController {
  @MessagePattern({ cmd: 'sum' })
  sum(data: number[]) {
    return data.reduce((a, b) => a + b, 0);
  }
}
```

## ClientProxy

```ts
const result$ = this.client.send<number>({ cmd: 'sum' }, [1, 2, 3]);
```

`send()` возвращает Observable, поэтому его нужно subscribe или преобразовать в Promise.

## Когда нужны microservices?

- независимое масштабирование;
- разные bounded contexts;
- асинхронная интеграция;
- изоляция команд;
- интеграция через broker.

## Мини-шпаргалка

- Nest microservices используют message patterns.
- Transport выбирается под задачу.
- `send` обычно request-response.
- `emit` обычно event-based.
- Distributed systems требуют timeout и retries.
