# Как правильно сортировать в JavaScript?

> [!summary]
> В JavaScript `Array.prototype.sort()` мутирует массив и без comparator сортирует элементы как строки. Для чисел почти всегда нужен comparator `(a, b) => a - b`, а если нельзя мутировать input, используют копию или `toSorted()`.

## Главная ловушка

```ts
const nums = [10, 2, 1]
nums.sort()

console.log(nums) // [1, 10, 2]
```

Без comparator элементы приводятся к строкам и сравниваются лексикографически.

## Сортировка чисел

```ts
nums.sort((a, b) => a - b)
```

По убыванию:

```ts
nums.sort((a, b) => b - a)
```

## Сортировка объектов

```ts
type User = {
  name: string
  age: number
}

users.sort((a, b) => a.age - b.age)
```

По строкам:

```ts
users.sort((a, b) => a.name.localeCompare(b.name))
```

## Не мутировать input

```ts
const sorted = [...nums].sort((a, b) => a - b)
```

Или современный вариант:

```ts
const sorted = nums.toSorted((a, b) => a - b)
```

## Comparator contract

Comparator возвращает:

- отрицательное число, если `a` раньше `b`;
- положительное число, если `a` позже `b`;
- `0`, если порядок равен.

```ts
function compareNumbers(a: number, b: number): number {
  return a - b
}
```

## Что отвечать на собеседовании?

В JS `sort()` сортирует in-place и без comparator сравнивает строки. Для чисел нужен `(a, b) => a - b`, для строк часто `localeCompare`, для объектов comparator по нужному полю. Если нельзя менять исходный массив, нужно сделать копию или использовать `toSorted`.

## Частые ошибки

- Сортировать числа через `sort()` без comparator.
- Забывать, что `sort()` мутирует массив.
- Возвращать boolean из comparator.
- Не учитывать `localeCompare` для строк.
- Считать сложность `sort` строго заданной спецификацией.

## Мини-шпаргалка

- `sort()` мутирует.
- Числа: `(a, b) => a - b`.
- Desc: `(a, b) => b - a`.
- Strings: `localeCompare`.
- No mutation: `[...arr].sort()` или `toSorted`.
- Comparator возвращает number, не boolean.
