# Что такое custom provider?

> [!summary]
> Custom provider позволяет зарегистрировать зависимость не просто по классу, а через token, value, factory или existing provider. Это нужно для конфигов, clients, mocks и разных реализаций интерфейса.

## useValue

```ts
const mockUsersRepository = {
  findAll: jest.fn(),
};

@Module({
  providers: [
    {
      provide: 'USERS_REPOSITORY',
      useValue: mockUsersRepository,
    },
  ],
})
export class UsersModule {}
```

## useClass

```ts
{
  provide: PaymentClient,
  useClass: StripePaymentClient,
}
```

## useFactory

```ts
{
  provide: 'API_CLIENT',
  useFactory: (config: ConfigService) => {
    return new ApiClient(config.get('API_URL'));
  },
  inject: [ConfigService],
}
```

## Мини-шпаргалка

- Custom provider регистрируется через `provide`.
- Token может быть class, string или symbol.
- `useValue` удобен для mocks и constants.
- `useClass` подменяет реализацию.
- `useFactory` создает provider через функцию и inject.
