# Что такое Nuxt Security?

> [!summary]
> Nuxt Security - модуль, который помогает настроить security headers и middleware по практикам OWASP: CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy и другие защитные механизмы.

## Зачем нужен security module?

Web security включает много headers:

- Content-Security-Policy;
- Strict-Transport-Security;
- X-Frame-Options;
- X-Content-Type-Options;
- Referrer-Policy;
- Permissions-Policy.

Настроить их вручную можно, но легко ошибиться.

## Установка

```bash
npx nuxi@latest module add security
```

Или:

```ts
export default defineNuxtConfig({
  modules: ['nuxt-security'],
});
```

## Что важно понимать?

Модуль не делает приложение автоматически полностью безопасным.

Он помогает с инфраструктурными заголовками, но разработчик все равно должен правильно делать:

- auth;
- authorization;
- CSRF protection;
- XSS protection через escaping/sanitization;
- secure cookies;
- input validation;
- dependency updates.

## CSP и third-party scripts

CSP может конфликтовать с analytics, maps, payment widgets. Поэтому настройку security headers нужно тестировать вместе с Nuxt Scripts и реальными integrations.

## Мини-шпаргалка

- Nuxt Security помогает настроить security headers.
- Работает через headers и middleware.
- Не заменяет auth и validation.
- CSP требует аккуратной настройки.
- Security headers нужно проверять в production-like окружении.
