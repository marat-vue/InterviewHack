# Что такое graceful shutdown в NestJS?

> [!summary]
> Graceful shutdown - корректное завершение NestJS-приложения: перестать принимать запросы, закрыть database connections, queues, background workers и другие ресурсы перед выходом процесса.

## Включение shutdown hooks

```ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableShutdownHooks();

  await app.listen(3000);
}
```

## Закрытие ресурса

```ts
@Injectable()
export class QueueService implements OnApplicationShutdown {
  async onApplicationShutdown(signal?: string) {
    await this.queue.close();
  }
}
```

## Что закрывать?

- database pool;
- Prisma/TypeORM connection;
- Redis;
- queues;
- message consumers;
- telemetry exporters;
- file handles.

## Мини-шпаргалка

- Shutdown hooks нужно включить явно.
- `OnApplicationShutdown` вызывается при завершении.
- Ресурсы нужно закрывать корректно.
- Не держи process открытым случайными timers.
- Kubernetes/PM2/systemd ожидают корректного завершения.
