# Что такое "reset CSS"?

> [!NOTE]
> **Reset CSS** - это набор правил, который сбрасывает или унифицирует браузерные стили по умолчанию, чтобы верстка начиналась с более предсказуемой базы.

## Зачем нужен reset

Разные браузеры имеют свои дефолтные стили для заголовков, списков, кнопок, форм и отступов.

```css
h1,
p,
ul {
  margin: 0;
}
```

Reset уменьшает влияние этих дефолтов.

## Пример простого reset

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

body {
  margin: 0;
}

img {
  max-width: 100%;
  display: block;
}
```

Такой reset не уничтожает все стили, а делает базовое поведение удобнее.

## Жесткий reset

Некоторые reset-файлы почти полностью обнуляют стили.

```css
* {
  margin: 0;
  padding: 0;
}
```

Это может быть удобно, но иногда приходится заново восстанавливать полезные браузерные стили.

## Reset или normalize

```text
reset     -> сбросить дефолты
normalize -> привести дефолты к консистентному виду
```

Reset чаще агрессивнее, normalize мягче.

## Мини-шпаргалка

- Reset CSS сбрасывает браузерные стили.
- Он делает стартовую базу предсказуемее.
- Слишком жесткий reset может удалить полезные стили.
- Часто сбрасывают `box-sizing`, `body margin`, стили изображений.
- Reset отличается от normalize.css.
