# Как индексировать JSONB, full-text search и trigram поиск?

> [!NOTE]
> Поиск в PostgreSQL бывает разным: JSONB containment, full-text search по лингвистическим правилам и trigram поиск по подстроке/похожести. Для каждого нужен свой индекс.

## JSONB containment

```sql
CREATE TABLE events (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  payload jsonb NOT NULL
);

CREATE INDEX events_payload_gin_idx
ON events USING gin (payload);

SELECT *
FROM events
WHERE payload @> '{"type": "user.created"}';
```

GIN индекс помогает операторам JSONB вроде containment.

## Expression index по JSONB field

```sql
CREATE INDEX events_type_idx
ON events ((payload->>'type'));

SELECT *
FROM events
WHERE payload->>'type' = 'user.created';
```

Expression index хорош, если часто фильтруешь по конкретному полю.

## Full-text search

```sql
CREATE TABLE articles (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  title text NOT NULL,
  body text NOT NULL,
  search_vector tsvector GENERATED ALWAYS AS (
    to_tsvector('english', title || ' ' || body)
  ) STORED
);

CREATE INDEX articles_search_idx
ON articles USING gin (search_vector);

SELECT *
FROM articles
WHERE search_vector @@ plainto_tsquery('english', 'node streams');
```

FTS понимает language configuration, tokenization, ranking и stop words.

## Trigram search

```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;

CREATE INDEX articles_title_trgm_idx
ON articles USING gin (title gin_trgm_ops);

SELECT *
FROM articles
WHERE title ILIKE '%nod%';
```

Trigram полезен для substring/fuzzy search, где FTS не подходит.

## Что выбрать?

| Задача | Решение |
|---|---|
| Найти JSONB payload по структуре | GIN JSONB |
| Часто фильтровать по одному JSONB field | expression index |
| Поиск слов с ranking | full-text search |
| `ILIKE '%abc%'` | trigram |
| Большой search product | отдельный search engine или carefully tuned PostgreSQL |

## Мини-шпаргалка

- JSONB `@>` -> GIN.
- JSONB field equality -> expression index.
- FTS -> `tsvector` + GIN.
- Substring search -> `pg_trgm`.
- Не один индекс для всех видов поиска.
