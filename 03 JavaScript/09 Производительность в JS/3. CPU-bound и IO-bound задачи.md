# CPU-bound и IO-bound задачи

> [!summary] Коротко
> CPU-bound задачи ограничены вычислениями процессора, а IO-bound задачи ограничены ожиданием ввода-вывода: сети, диска, базы данных.

## Вопрос

Чем CPU-bound задачи отличаются от I/O-bound?

## CPU-bound

CPU-bound задача тратит основное время на вычисления.

```javascript
function calculate(numbers) {
  return numbers
    .filter((number) => number > 0)
    .map((number) => number ** 2)
    .reduce((sum, number) => sum + number, 0);
}
```

Если данных очень много, такая работа может занять main thread.

## IO-bound

IO-bound задача тратит основное время на ожидание внешней операции.

```javascript
const response = await fetch('/api/users');
const users = await response.json();
```

Здесь JavaScript в основном ждет сеть.

## Сравнение

| Тип | Ограничение | Примеры | Как оптимизировать |
| --- | --- | --- | --- |
| CPU-bound | процессор | вычисления, парсинг, сортировка | алгоритмы, workers, chunking |
| IO-bound | ввод-вывод | сеть, файлы, база | кэш, параллельные запросы, batching |

## Почему важно различать

CPU-bound задачу не исправить простым `await`: вычисления все равно будут выполняться в main thread. IO-bound задачу часто можно ускорить параллельным запуском или уменьшением числа запросов.

## Мини-шпаргалка

```text
CPU-bound -> "много считаем"
IO-bound  -> "много ждем"
```
