# Что такое модификаторы событий?

> [!NOTE] Коротко
> Модификаторы событий меняют поведение обработчика `v-on`: предотвращают стандартное действие, останавливают всплытие, вызывают обработчик один раз или фильтруют событие.

## Вопрос

Что такое модификаторы событий?

## prevent

```vue
<form @submit.prevent="submit">
  <button type="submit">Сохранить</button>
</form>
```

`.prevent` вызывает `event.preventDefault()`.

## stop

```vue
<div @click="close">
  <button @click.stop="save">Сохранить</button>
</div>
```

`.stop` вызывает `event.stopPropagation()` и не дает событию всплыть к родителю.

## once

```vue
<button @click.once="send">Отправить один раз</button>
```

Обработчик сработает только один раз.

## capture, passive, self

```vue
<div @click.capture="handle" />
<div @scroll.passive="onScroll" />
<div @click.self="close" />
```

Эти модификаторы соответствуют частым настройкам DOM-событий.

## Мини-шпаргалка

- `.prevent` отменяет стандартное действие.
- `.stop` останавливает всплытие.
- `.once` вызывает обработчик один раз.
- `.self` реагирует только на сам элемент.
- Модификаторы делают шаблон короче и понятнее.
