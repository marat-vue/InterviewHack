# Что должен возвращать компонент?

> [!summary]
> React-компонент должен возвращать то, что React может отрендерить: JSX, строку, число, `null`, массив элементов, Fragment или портал. Чаще всего компонент возвращает JSX, а если ничего не нужно показывать - `null`.

## Самый частый вариант

```jsx
function Title() {
  return <h1>React</h1>
}
```

JSX описывает React-элемент, который затем попадет в дерево UI.

## Можно вернуть Fragment

```jsx
function Header() {
  return (
    <>
      <h1>Профиль</h1>
      <p>Настройки аккаунта</p>
    </>
  )
}
```

Fragment нужен, если элементов несколько, но лишний DOM-контейнер не нужен.

## Можно вернуть null

```jsx
function AdminPanel({ isAdmin }) {
  if (!isAdmin) {
    return null
  }

  return <section>Панель администратора</section>
}
```

`null` означает: компонент ничего не отображает.

## Можно вернуть массив

```jsx
function Tags({ tags }) {
  return tags.map((tag) => (
    <span key={tag}>{tag}</span>
  ))
}
```

Если возвращаешь массив элементов, нужны `key`.

## Что нельзя возвращать?

Нельзя вернуть обычный объект как child:

```jsx
function Broken() {
  return { title: 'React' }
}
```

React не знает, как показать такой объект в DOM.

Но можно вывести свойство объекта:

```jsx
function ArticleTitle({ article }) {
  return <h1>{article.title}</h1>
}
```

## Что важно про чистоту компонента?

Компонент должен возвращать UI, а не выполнять побочные действия во время render.

Плохо:

```jsx
function Page() {
  localStorage.setItem('visited', 'true')
  return <main>...</main>
}
```

Побочные действия нужно выносить в event handlers или effects.

## Мини-шпаргалка

- Обычно компонент возвращает JSX.
- Несколько элементов группируют через Fragment.
- `null` означает "ничего не показывать".
- Массив элементов требует keys.
- Обычные объекты нельзя рендерить как children.
- Render должен быть чистым.
