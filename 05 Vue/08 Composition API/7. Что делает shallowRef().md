# Что делает shallowRef()

> [!summary] Коротко
> `shallowRef()` делает реактивной только замену `.value`, но не делает глубоко реактивным содержимое объекта.

## Вопрос

Что делает `shallowRef()`?

## Отличие от ref

```typescript
import { ref, shallowRef } from "vue";

const deep = ref({ count: 0 });
const shallow = shallowRef({ count: 0 });

deep.value.count++; // глубокое изменение отслеживается
shallow.value.count++; // замена .value не произошла
```

Для `shallowRef` реактивна именно замена объекта.

```typescript
shallow.value = { count: 1 }; // это отследится
```

## Когда использовать

`shallowRef` полезен для больших объектов, данных внешних библиотек, экземпляров классов, canvas/editor/chart-инстансов, где Vue не должен делать глубокую реактивность.

```typescript
const chart = shallowRef<Chart | null>(null);
```

## Принудительное уведомление

Если нужно сообщить Vue о внутреннем изменении, можно использовать `triggerRef`.

```typescript
import { triggerRef } from "vue";

shallow.value.count++;
triggerRef(shallow);
```

## Мини-шпаргалка

- `shallowRef` отслеживает только `.value`.
- Вложенные поля не становятся реактивными.
- Хорош для внешних инстансов и больших объектов.
- Для ручного уведомления есть `triggerRef`.
