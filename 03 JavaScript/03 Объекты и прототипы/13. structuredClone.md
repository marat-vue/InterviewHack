# `structuredClone()`

> [!summary] Коротко
> `structuredClone(value)` создает глубокую копию значения по алгоритму structured clone. Вложенные объекты копируются заново, а не остаются общими ссылками.

## Вопрос

Что делает `structuredClone()`?

## Базовый пример

```javascript
const user = {
  name: "Anna",
  address: {
    city: "Moscow",
  },
};

const copy = structuredClone(user);

copy.address.city = "Kazan";

console.log(user.address.city); // "Moscow"
```

Вложенный объект `address` тоже скопирован.

## Чем отличается от spread

```javascript
const shallow = { ...user };
```

Spread копирует только верхний уровень.

```javascript
shallow.address === user.address; // true
```

`structuredClone` создает новую вложенную структуру.

```javascript
copy.address === user.address; // false
```

## Что умеет копировать

`structuredClone` поддерживает многие встроенные типы:

```javascript
structuredClone(new Date());
structuredClone(new Map());
structuredClone(new Set());
structuredClone(new ArrayBuffer(8));
```

Также умеет копировать циклические ссылки.

```javascript
const obj = {};
obj.self = obj;

const copy = structuredClone(obj);

copy.self === copy; // true
```

## Что не копирует

Функции нельзя клонировать.

```javascript
structuredClone({
  fn() {},
});
// DataCloneError
```

Также могут быть ограничения для DOM-узлов и некоторых специальных объектов.

## Сравнение с JSON

```javascript
JSON.parse(JSON.stringify(obj));
```

JSON-подход теряет часть данных:

- `undefined`;
- функции;
- `Symbol`;
- `Date` превращается в строку;
- `Map` и `Set` теряют структуру;
- циклические ссылки ломают сериализацию.

## Мини-шпаргалка

| Способ | Копия | Ограничения |
| --- | --- | --- |
| `{ ...obj }` | поверхностная | вложенные ссылки общие |
| `Object.assign({}, obj)` | поверхностная | вложенные ссылки общие |
| `structuredClone(obj)` | глубокая | не копирует функции |
| JSON parse/stringify | глубокая с потерями | теряет специальные типы |
