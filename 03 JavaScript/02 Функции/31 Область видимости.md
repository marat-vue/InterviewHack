# Область видимости функции

> [!NOTE] Коротко
> Область видимости функции - это набор переменных, доступных внутри функции. Каждый вызов функции создает свое отдельное лексическое окружение.

## Вопрос

Что такое область видимости функции?

## Локальные переменные

Переменные, объявленные внутри функции, не видны снаружи.

```javascript
function createMessage() {
  const message = "Hello";
  return message;
}

console.log(message); // ReferenceError
```

## Внешние переменные

Функция может читать переменные из внешней области.

```javascript
const prefix = "User";

function formatName(name) {
  return `${prefix}: ${name}`;
}
```

Это называется лексическая область видимости.

## Каждый вызов создает свое окружение

```javascript
function createCounter() {
  let count = 0;

  return function () {
    count++;
    return count;
  };
}

const a = createCounter();
const b = createCounter();

a(); // 1
a(); // 2
b(); // 1
```

У `a` и `b` разные окружения.

## Параметры тоже локальные

```javascript
function greet(name) {
  return `Hi, ${name}`;
}

console.log(name); // ReferenceError
```

Параметр `name` доступен только внутри функции.

## `var` внутри функции

`var` ограничен функцией.

```javascript
function demo() {
  if (true) {
    var value = 10;
  }

  console.log(value); // 10
}
```

`let` и `const` ограничены блоком.

```javascript
function demo() {
  if (true) {
    const value = 10;
  }

  console.log(value); // ReferenceError
}
```

## Мини-шпаргалка

| Где объявлено | Где доступно |
| --- | --- |
| параметр функции | внутри функции |
| `const/let` внутри функции | внутри блока/функции |
| `var` внутри функции | внутри функции |
| внешняя переменная | внутри вложенных функций |
| переменная внутри функции | снаружи недоступна |
