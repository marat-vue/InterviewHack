# Имеет ли значение порядок атрибутов

> [!summary]
> В большинстве случаев порядок HTML-атрибутов не влияет на поведение элемента. Атрибуты читаются по имени, а не по позиции, но единый порядок улучшает читаемость кода.

## Главное

Эти две записи для браузера эквивалентны:

```html
<input type="email" id="email" name="email">
<input name="email" id="email" type="email">
```

Браузер смотрит на имена атрибутов: `type`, `id`, `name`.

## Почему порядок все равно важен для команды

Единый порядок делает код легче читать и ревьюить.

```html
<button
  id="save-button"
  class="button button--primary"
  type="submit"
  disabled
>
  Сохранить
</button>
```

Команда может договориться о стиле: сначала `id`, затем `class`, затем специфичные атрибуты, затем `aria-*` и `data-*`.

## Исключения и нюансы

Если один и тот же атрибут указан несколько раз, HTML становится некорректным, а результат может быть неожиданным.

```html
<!-- не делай так -->
<input type="text" type="email">
```

Нужно указывать один атрибут один раз.

## Порядок классов

Порядок классов внутри `class` может быть важен для читаемости, но не определяет CSS-специфичность.

```html
<button class="button button--primary is-loading">
  Отправить
</button>
```

В CSS решают порядок правил, специфичность и cascade, а не позиция класса в HTML.

## Мини-шпаргалка

- Порядок атрибутов обычно не влияет на браузер.
- Повторять один атрибут нельзя.
- Единый порядок полезен для читаемости.
- Порядок классов в `class` не задает CSS-приоритет.
- Форматтеры помогают поддерживать стиль.
