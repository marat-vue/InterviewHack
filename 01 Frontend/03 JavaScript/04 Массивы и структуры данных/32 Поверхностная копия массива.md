# Поверхностная копия массива

> [!NOTE] Коротко
> Поверхностная копия создает новый массив верхнего уровня, но вложенные объекты и массивы остаются общими ссылками.

## Вопрос

Как сделать поверхностную копию массива?

## Основные способы

Через spread:

```javascript
const copy = [...arr];
```

Через `slice`:

```javascript
const copy = arr.slice();
```

Через `Array.from`:

```javascript
const copy = Array.from(arr);
```

Через `concat`:

```javascript
const copy = [].concat(arr);
```

## Пример

```javascript
const original = [1, 2, 3];
const copy = [...original];

copy.push(4);

console.log(original); // [1, 2, 3]
console.log(copy);     // [1, 2, 3, 4]
```

Верхний уровень независим.

## Вложенные объекты

```javascript
const original = [{ name: "Anna" }];
const copy = [...original];

copy[0].name = "Max";

console.log(original[0].name); // "Max"
```

Объект внутри остался общим.

## Глубокая копия

Если нужно скопировать вложенные структуры:

```javascript
const copy = structuredClone(original);
```

Но `structuredClone` не копирует функции и имеет свои ограничения.

## Мини-шпаргалка

| Способ | Тип копии |
| --- | --- |
| `[...arr]` | shallow |
| `arr.slice()` | shallow |
| `Array.from(arr)` | shallow |
| `[].concat(arr)` | shallow |
| `structuredClone(arr)` | deep |
