# Что такое тестирование в разработке?

> [!summary]
> Тестирование - это проверка, что код ведет себя ожидаемо в важных сценариях. Оно не доказывает отсутствие всех багов, но снижает риск поломок, помогает безопасно менять код и делает требования более явными.

## Простое определение

Тест - это автоматизированный или ручной сценарий, который сравнивает ожидаемое поведение программы с фактическим.

В разработке тесты нужны не только для поиска ошибок. Они помогают:

- зафиксировать требования;
- быстрее рефакторить код;
- ловить регрессии;
- документировать поведение системы;
- давать команде уверенность перед релизом.

## Что значит "поведение"?

Поведение - это то, что видит пользователь или другая часть системы.

Например, для функции скидки важно не то, какие переменные внутри нее используются, а что она возвращает правильную цену:

```ts
function applyDiscount(price: number, percent: number) {
  return price - price * (percent / 100);
}

expect(applyDiscount(1000, 10)).toBe(900);
```

Для компонента важно не имя внутреннего метода, а то, что пользователь видит результат:

```ts
await wrapper.find('button').trigger('click');

expect(wrapper.text()).toContain('Товар добавлен');
```

## Что тестирование не гарантирует?

Тесты не гарантируют, что багов нет. Они проверяют только те сценарии, которые ты описал.

Плохой тест может быть зеленым, но бесполезным:

```ts
expect(true).toBe(true);
```

Хороший тест проверяет важный риск:

```ts
expect(calculateTotal([{ price: 100 }, { price: 50 }])).toBe(150);
```

## Что обычно спрашивают на собеседовании?

Частый вопрос: "Зачем нужны тесты, если есть QA?"

Хороший ответ: QA проверяет продукт шире, включая UX, edge cases и ручные сценарии. Автотесты быстрее проверяют повторяемые технические сценарии и ловят регрессии при каждом изменении кода. Это разные уровни защиты качества.

## Мини-шпаргалка

- Тест сравнивает expected result и actual result.
- Тесты уменьшают риск, но не доказывают отсутствие багов.
- Хороший тест проверяет поведение, а не детали реализации.
- Автотесты особенно полезны для регрессий и рефакторинга.
- Чем критичнее сценарий, тем важнее покрыть его тестами.
