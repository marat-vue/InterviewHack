# Оператор `&&`

> [!summary] Коротко
> `&&` - логическое И. Он возвращает первое falsy-значение или последнее значение, если все операнды truthy. Также использует short-circuit: правая часть может не выполниться.

## Вопрос

Что делает оператор `&&`?

## Boolean-логика

Если оба значения истинные, результат истинный.

```javascript
true && true;   // true
true && false;  // false
false && true;  // false
false && false; // false
```

## Как работает в JavaScript

`&&` возвращает не обязательно `true` или `false`. Он возвращает одно из исходных значений.

```javascript
"hello" && 123; // 123
0 && "hello";   // 0
null && "x";    // null
"a" && "b";     // "b"
```

Правило:

- если первое значение falsy, возвращается оно;
- если первое значение truthy, вычисляется и возвращается второе;
- если цепочка длинная, возвращается первое falsy или последнее truthy.

```javascript
"a" && 1 && "done"; // "done"
"a" && 0 && "done"; // 0
```

## Short-circuit

Правая часть не вычисляется, если левая уже falsy.

```javascript
function log() {
  console.log("Вызов");
}

false && log(); // log не вызовется
true && log();  // log вызовется
```

Это называют short-circuit evaluation.

## Частый паттерн

```javascript
user && user.name;
```

Если `user` falsy, доступ к `user.name` не произойдет. Но в современном коде для вложенных свойств чаще используют optional chaining:

```javascript
user?.name;
```

## Условный рендеринг

В UI-коде часто пишут:

```javascript
isVisible && renderModal();
```

Важно помнить: если левая часть не boolean, она может попасть в результат.

```javascript
const count = 0;

count && "Есть элементы"; // 0
```

В React это может случайно отрендерить `0`.

## Мини-шпаргалка

| Выражение | Результат |
| --- | --- |
| `true && "x"` | `"x"` |
| `false && "x"` | `false` |
| `"a" && "b"` | `"b"` |
| `0 && "b"` | `0` |
| `null && fn()` | `null`, `fn` не вызовется |
