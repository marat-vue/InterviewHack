# Где хранится состояние в Options API

> [!summary] Коротко
> В Options API локальное состояние компонента хранится в функции `data()`. Она возвращает объект, свойства которого становятся реактивными.

## Вопрос

Где хранится состояние в Options API?

## Базовый пример

```vue
<script>
export default {
  data() {
    return {
      count: 0,
      name: "Анна",
    };
  },
};
</script>

<template>
  <button @click="count++">{{ count }}</button>
  <p>{{ name }}</p>
</template>
```

`count` и `name` - локальное состояние компонента.

## Доступ через this

В методах Options API поля `data` доступны через `this`.

```javascript
export default {
  data() {
    return { count: 0 };
  },
  methods: {
    increment() {
      this.count++;
    },
  },
};
```

## Почему data должна быть функцией

У каждого экземпляра компонента должна быть своя копия состояния. Поэтому `data` возвращает новый объект.

## Где не хранить state

Не стоит хранить изменяемое состояние в module-level переменных рядом с компонентом, если оно должно быть отдельным для каждого экземпляра.

## Мини-шпаргалка

- Options API state хранится в `data()`.
- `data()` возвращает объект.
- Поля объекта становятся реактивными.
- В методах обращение идет через `this`.
- Каждый экземпляр получает свою копию state.
