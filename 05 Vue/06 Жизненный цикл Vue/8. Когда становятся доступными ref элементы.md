# Когда становятся доступными ref элементы

> [!summary] Коротко
> Template ref на DOM-элемент становится доступен после монтирования компонента, то есть в `mounted` или `onMounted`. До этого значение обычно `null`.

## Вопрос

Когда становятся доступными `ref` элементы?

## Базовый пример

```vue
<script setup>
import { onMounted, ref } from "vue";

const inputRef = ref<HTMLInputElement | null>(null);

onMounted(() => {
  inputRef.value?.focus();
});
</script>

<template>
  <input ref="inputRef" />
</template>
```

До `onMounted` DOM-элемент еще не гарантированно существует.

## После условного рендера

Если элемент находится под `v-if`, он станет доступен только когда условие истинно и Vue обновит DOM.

```vue
<script setup>
import { nextTick, ref } from "vue";

const isOpen = ref(false);
const inputRef = ref<HTMLInputElement | null>(null);

async function open() {
  isOpen.value = true;
  await nextTick();
  inputRef.value?.focus();
}
</script>
```

`nextTick` нужен, чтобы дождаться обновления DOM.

## Component ref

`ref` может указывать не только на DOM, но и на экземпляр компонента. В `<script setup>` дочерний компонент должен явно открыть методы через `defineExpose`.

## Мини-шпаргалка

- Template ref обычно `null` до mount.
- Для первого доступа используй `onMounted`.
- После `v-if` часто нужен `nextTick`.
- Для component ref в `<script setup>` нужен `defineExpose`.
