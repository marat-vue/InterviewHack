# Что такое дерево компонентов?

> [!NOTE] Коротко
> Дерево компонентов - иерархия Vue-компонентов в приложении: родительские компоненты содержат дочерние, а данные и события связывают уровни дерева.

## Вопрос

Что такое дерево компонентов?

## Простая схема

```text
App
  -> AppLayout
    -> Header
    -> Sidebar
    -> RouterView
      -> UserPage
        -> UserCard
```

Каждый узел - компонент. Вместе они образуют структуру интерфейса.

## Передача данных

Данные обычно идут сверху вниз через props.

```vue
<UserCard :user="selectedUser" />
```

События идут снизу вверх через emit.

```vue
<UserCard @select="selectedUser = $event" />
```

## Почему дерево важно

Оно помогает понимать ответственность компонентов: где хранить состояние, кому передавать props, где обрабатывать события.

## Когда дерево становится сложным

Если приходится пробрасывать props через много уровней, стоит подумать о `provide/inject`, Pinia или перестройке компонентов.

## Мини-шпаргалка

- Дерево компонентов показывает вложенность UI.
- Родитель передает props ребенку.
- Ребенок отправляет события родителю.
- Слишком глубокий prop drilling может быть сигналом для store или provide/inject.
