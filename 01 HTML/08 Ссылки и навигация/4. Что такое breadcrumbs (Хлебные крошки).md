# Что такое breadcrumbs (Хлебные крошки)

> [!summary]
> **Breadcrumbs**, или хлебные крошки, - это навигационная цепочка, которая показывает путь от главной страницы до текущего раздела или страницы.

## Главное

Хлебные крошки помогают пользователю понять, где он находится, и быстро вернуться на уровень выше.

```html
<nav aria-label="Хлебные крошки">
  <ol>
    <li><a href="/">Главная</a></li>
    <li><a href="/catalog">Каталог</a></li>
    <li aria-current="page">Ноутбуки</li>
  </ol>
</nav>
```

## Почему это nav

Breadcrumbs - это навигация, поэтому их оборачивают в `<nav>`. Атрибут `aria-label` объясняет тип навигации, если на странице есть несколько `nav`.

## aria-current

Текущую страницу помечают:

```html
<li aria-current="page">Ноутбуки</li>
```

Это помогает assistive technologies понять, какой пункт является текущим.

## Когда использовать

- Интернет-магазины.
- Документация.
- Блоги с категориями.
- Сложные панели управления.
- Сайты с глубокой иерархией разделов.

## Когда не обязательно

Если сайт состоит из одной-двух простых страниц без вложенной структуры, breadcrumbs могут быть лишними.

## Мини-шпаргалка

- Breadcrumbs показывают путь до текущей страницы.
- Обычно используют `nav` + `ol`.
- Текущий пункт помечают `aria-current="page"`.
- Полезны для сайтов с глубокой структурой.
- Не заменяют основное меню.
