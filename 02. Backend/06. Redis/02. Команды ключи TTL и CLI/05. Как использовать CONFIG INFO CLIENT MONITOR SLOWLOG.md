# Как использовать CONFIG, INFO, CLIENT, MONITOR и SLOWLOG?

> [!NOTE]
> Эти команды нужны для диагностики Redis. Их важно знать, но некоторые из них опасны в production, особенно `MONITOR`, потому что он показывает поток всех команд и создает overhead.

## Как использовать INFO?

```redis
INFO
INFO memory
INFO clients
INFO stats
INFO replication
INFO persistence
INFO commandstats
```

Что смотреть:

| Раздел | Что дает |
|---|---|
| `memory` | used memory, fragmentation, maxmemory |
| `clients` | connected clients, blocked clients |
| `stats` | total commands, hits/misses, evicted keys |
| `replication` | role, replicas, offsets |
| `persistence` | RDB/AOF status |
| `commandstats` | статистика команд |

## Как посмотреть config?

```redis
CONFIG GET maxmemory
CONFIG GET maxmemory-policy
CONFIG GET appendonly
```

Изменить runtime config:

```redis
CONFIG SET maxmemory 512mb
CONFIG SET maxmemory-policy allkeys-lru
```

Runtime change может не сохраниться после restart, если не обновить `redis.conf` или managed provider config.

## Как посмотреть клиентов?

```redis
CLIENT LIST
```

Полезно, когда нужно найти:

- слишком много connections;
- idle clients;
- blocked clients;
- client names;
- source IP.

Задать имя клиента:

```redis
CLIENT SETNAME api-worker-1
```

В Node.js имя можно задавать через client options, если клиент поддерживает настройку.

## Что такое SLOWLOG?

`SLOWLOG` хранит команды, которые выполнялись дольше порога.

```redis
SLOWLOG GET 10
SLOWLOG LEN
SLOWLOG RESET
```

Настройки:

```redis
CONFIG GET slowlog-log-slower-than
CONFIG GET slowlog-max-len
```

SLOWLOG помогает найти:

- большие `HGETALL`;
- тяжелые Lua scripts;
- `KEYS`;
- команды по big keys.

## Когда использовать MONITOR?

```redis
MONITOR
```

`MONITOR` показывает все команды, которые Redis получает. Это мощный debug-инструмент, но в production может создать overhead и раскрыть sensitive data.

Используй `MONITOR` только:

- локально;
- кратковременно;
- в изолированной среде;
- если понимаешь security impact.

## Мини-шпаргалка

- `INFO memory` - память.
- `INFO stats` - общая статистика.
- `CLIENT LIST` - connections.
- `SLOWLOG GET` - медленные команды.
- `CONFIG GET` - посмотреть настройку.
- `CONFIG SET` - изменить runtime настройку.
- `MONITOR` - мощно, но опасно.
