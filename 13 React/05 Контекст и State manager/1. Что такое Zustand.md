# Что такое Zustand?

> [!summary]
> Zustand - минималистичная библиотека управления состоянием для React. Она создает store, который можно читать через hook, обновлять через actions и подписывать компоненты только на нужные части состояния.

## Простое определение

Zustand отвечает на вопрос:

```text
Как хранить общее клиентское состояние без большого boilerplate?
```

Пример store:

```jsx
import { create } from 'zustand'

const useCounterStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}))
```

Использование:

```jsx
function Counter() {
  const count = useCounterStore((state) => state.count)
  const increment = useCounterStore((state) => state.increment)

  return <button onClick={increment}>{count}</button>
}
```

## Чем Zustand отличается от Context?

Context передает значение по дереву. Zustand хранит состояние во внешнем store, а компоненты подписываются на выбранные slices.

Это удобно, когда:

- состояние нужно в разных местах;
- хочется selectors;
- не хочется Provider для каждого store;
- нужны actions рядом со state;
- важны точечные подписки.

## Что хранить в Zustand?

Хорошие кандидаты:

- UI state, общий для разных частей приложения;
- настройки интерфейса;
- корзина;
- фильтры;
- состояние модальных окон;
- client-side cache, если он не заменяет TanStack Query;
- данные, которыми владеет клиент.

Server state лучше часто хранить в TanStack Query/SWR, потому что там есть кеш, refetch, stale time и invalidation.

## Мини-шпаргалка

- Zustand - легкий state manager на основе store hook.
- Store создается через `create`.
- Компоненты читают state через selector.
- Actions обычно лежат внутри store.
- Не смешивай client state и server state без причины.
