# Удаление свойства в объекте

> [!NOTE] Коротко
> Свойство объекта удаляют оператором `delete`. Он убирает ключ из объекта, а не просто присваивает `undefined`.

## Вопрос

Как удалить свойство из объекта?

## Через `delete`

```javascript
const user = {
  name: "Anna",
  age: 25,
};

delete user.age;

console.log(user); // { name: "Anna" }
```

## Удаление vs `undefined`

```javascript
const user = { name: "Anna" };

user.name = undefined;

"name" in user; // true
```

Ключ остался.

```javascript
delete user.name;

"name" in user; // false
```

Теперь ключа нет.

## Динамический ключ

```javascript
const key = "age";

delete user[key];
```

## Что возвращает `delete`

```javascript
delete user.missing; // true
```

`true` может означать, что свойство удалено или его и так не было.

Если свойство нельзя удалить, результат может быть `false`, а в strict mode - ошибка.

```javascript
const obj = {};

Object.defineProperty(obj, "id", {
  value: 1,
  configurable: false,
});

delete obj.id; // false или TypeError в strict mode
```

## Иммутабельное удаление

Если нельзя менять исходный объект, используйте rest-деструктуризацию.

```javascript
const user = { name: "Anna", age: 25 };
const { age, ...userWithoutAge } = user;

console.log(userWithoutAge); // { name: "Anna" }
```

## Мини-шпаргалка

| Действие | Код |
| --- | --- |
| удалить обычный ключ | `delete obj.key` |
| удалить динамический ключ | `delete obj[key]` |
| оставить ключ пустым | `obj.key = undefined` |
| удалить без мутации | `const { key, ...rest } = obj` |
