# Как задать цвет заднего фона у элемента

> [!summary]
> Цвет фона элемента задается свойством `background-color`. Также можно использовать сокращенное свойство `background`, если нужно одновременно настроить цвет, изображение, позицию или другие параметры фона.

## Главное

```css
.card {
  background-color: #ffffff;
}
```

`background-color` окрашивает фон области элемента: контент, padding и border-box в зависимости от сопутствующих свойств.

## Пример с HTML

```html
<article class="notification">
  Настройки сохранены
</article>
```

```css
.notification {
  padding: 16px;
  background-color: #ecfdf5;
  color: #065f46;
}
```

Важно подбирать цвет текста вместе с цветом фона, чтобы контраст был достаточным.

## background-color и background

```css
.hero {
  background-color: #111827;
}
```

Если нужно только задать цвет, `background-color` читабельнее.

```css
.hero {
  background: #111827 url("/hero.jpg") center / cover no-repeat;
}
```

`background` удобен, когда нужно задать несколько фоновых параметров сразу.

## Прозрачный фон

```css
.ghost-button {
  background-color: transparent;
}
```

`transparent` позволяет показать фон родительского элемента.

## Фон через переменные

```css
:root {
  --surface-color: #ffffff;
  --surface-muted: #f3f4f6;
}

.panel {
  background-color: var(--surface-color);
}
```

Так проще поддерживать темы и дизайн-токены.

## Мини-шпаргалка

- Цвет фона задается через `background-color`.
- `background` - сокращение для нескольких фоновых свойств.
- `transparent` делает фон прозрачным.
- Цвет текста и фона нужно проверять на контраст.
- Для дизайн-систем удобно использовать CSS-переменные.
