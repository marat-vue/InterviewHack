# Как оптимизировать performance Nuxt приложения?

> [!summary]
> Performance Nuxt-приложения складывается из rendering mode, route rules, data fetching, image/font optimization, script loading, bundle size, caching, hydration и server response time. Оптимизация начинается с измерений, а не с случайных модулей.

## Что измерять?

- LCP;
- INP;
- CLS;
- TTFB;
- bundle size;
- server response time;
- hydration cost;
- image weight;
- third-party script impact.

## Основные рычаги Nuxt

| Проблема | Инструмент |
|---|---|
| тяжелые images | Nuxt Image |
| медленные fonts | Nuxt Fonts |
| third-party scripts | Nuxt Scripts |
| дорогой page render | routeRules, caching |
| тяжелые widgets | lazy components/hydration |
| client bundle | code splitting, auto imports |
| SEO pages | SSR/SSG/ISR |

## Route-level optimization

```ts
export default defineNuxtConfig({
  routeRules: {
    '/': { prerender: true },
    '/blog/**': { isr: 3600 },
    '/products/**': { swr: 300 },
    '/admin/**': { ssr: false },
  },
});
```

## Scripts

Не загружай analytics до того, как он реально нужен или разрешен consent.

## Мини-шпаргалка

- Сначала измеряй, потом оптимизируй.
- RouteRules - мощный per-route рычаг.
- Images и fonts часто влияют на LCP/CLS.
- Third-party scripts часто портят INP.
- Hydration cost важен для интерактивности.
