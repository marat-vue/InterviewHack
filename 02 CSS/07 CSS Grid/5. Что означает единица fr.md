# Что означает единица fr

> [!summary]
> `fr` - это гибкая единица CSS Grid, которая означает долю доступного свободного пространства внутри grid-контейнера.

## Главное

```css
.layout {
  display: grid;
  grid-template-columns: 1fr 2fr;
}
```

Свободное пространство распределится в пропорции `1:2`: вторая колонка будет в два раза шире первой.

## fr после фиксированных размеров

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
}
```

Сначала браузер выделит `240px`, затем оставшееся место отдаст колонке `1fr`.

## Несколько равных колонок

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

Три колонки получат равные доли свободного пространства.

## fr не проценты

`fr` распределяет доступное пространство после учета fixed-треков, `gap`, min/max и содержимого.

```css
.grid {
  grid-template-columns: 200px 1fr 1fr;
  gap: 24px;
}
```

Сначала учитываются `200px` и `gap`, потом остаток делится между `fr`.

## Мини-шпаргалка

- `fr` означает fraction, долю пространства.
- `1fr 1fr` - две равные колонки.
- `1fr 2fr` - пропорция 1 к 2.
- Fixed-размеры и `gap` учитываются до распределения `fr`.
- `fr` особенно полезен для адаптивных Grid-layout.
