# Как настраивать styling, CSS, preprocessors, modules и Tailwind в Nuxt?

> [!NOTE]
> Nuxt поддерживает обычный CSS, scoped styles, CSS modules, preprocessors, PostCSS, Tailwind и UI libraries. Главный выбор: что должно быть глобальным, что локальным для компонента, а что лучше вынести в design system.

## Global CSS

Глобальные стили подключают в `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  css: ['~/assets/css/main.css']
})
```

`app/assets/css/main.css`:

```css
:root {
  --page-bg: #f8fafc;
  --text-main: #0f172a;
}

body {
  background: var(--page-bg);
  color: var(--text-main);
}
```

Глобально стоит держать:

- reset/base styles;
- CSS variables;
- typography defaults;
- layout primitives;
- imports UI library.

Не стоит держать глобально случайные стили конкретной карточки или страницы.

## Scoped CSS

```vue
<template>
  <article class="product">
    <h2>{{ title }}</h2>
  </article>
</template>

<style scoped>
.product {
  padding: 16px;
  border: 1px solid #e2e8f0;
}
</style>
```

`scoped` ограничивает selector текущим компонентом. Это удобно для локальных styles, но не замена design system.

## CSS Modules

```vue
<template>
  <button :class="$style.button">
    Купить
  </button>
</template>

<style module>
.button {
  border-radius: 8px;
  padding: 10px 14px;
}
</style>
```

CSS modules полезны, когда нужен локальный class name без коллизий и без Vue scoped attributes.

## Sass/SCSS

Установка:

```bash
pnpm add -D sass
```

Компонент:

```vue
<style scoped lang="scss">
.card {
  padding: 16px;

  &__title {
    font-weight: 700;
  }
}
</style>
```

Глобальные SCSS variables можно подключать через Vite CSS preprocessor options:

```ts
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorOptions: {
        scss: {
          additionalData: '@use "~/assets/scss/tokens.scss" as *;'
        }
      }
    }
  }
})
```

## PostCSS

Nuxt использует Vite и поддерживает PostCSS. Пример настройки:

```ts
export default defineNuxtConfig({
  postcss: {
    plugins: {
      autoprefixer: {}
    }
  }
})
```

PostCSS нужен для:

- autoprefixer;
- nesting plugin;
- Tailwind;
- custom CSS transforms.

## Tailwind

Установка через Nuxt module:

```bash
npx nuxi module add tailwindcss
```

`nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/tailwindcss']
})
```

Использование:

```vue
<template>
  <button class="rounded-md bg-teal-700 px-4 py-2 text-white">
    Сохранить
  </button>
</template>
```

Tailwind полезен, если команда принимает utility-first workflow. Если проект уже на Vuetify/Nuxt UI/custom CSS, не нужно смешивать все сразу без причины.

## UI libraries

Популярные варианты:

- Nuxt UI;
- Vuetify;
- Tailwind + headless components;
- собственная design system.

Правило: выбери один основной UI foundation. Смешивание нескольких UI систем быстро ломает визуальную консистентность.

## Где хранить design tokens?

Пример:

```text
app/assets/css/tokens.css
app/assets/css/base.css
app/assets/css/layout.css
app/assets/css/main.css
```

`main.css`:

```css
@import './tokens.css';
@import './base.css';
@import './layout.css';
```

## Что отвечать на собеседовании?

В Nuxt стили можно писать на нескольких уровнях: global CSS подключается через `css` в `nuxt.config.ts`, локальные стили пишутся через `<style scoped>`, CSS modules дают локальные class names, preprocessors подключаются как dev-зависимости, а Tailwind обычно ставится как Nuxt module. Важно не превращать global CSS в свалку и заранее выбрать UI foundation проекта.

## Частые ошибки

- Все стили писать глобально.
- Смешивать Tailwind, Vuetify и custom CSS без правил.
- Использовать scoped CSS для design tokens.
- Подключать огромный CSS framework ради двух компонентов.
- Забывать про critical rendering path и размер CSS.
- Делать стили зависимыми от случайной DOM-структуры стороннего компонента.

## Мини-шпаргалка

- Global CSS: `css` в `nuxt.config.ts`.
- Local CSS: `<style scoped>`.
- CSS Modules: `<style module>`.
- SCSS: `pnpm add -D sass`.
- PostCSS: `postcss` config.
- Tailwind: module, если utility-first подходит проекту.
