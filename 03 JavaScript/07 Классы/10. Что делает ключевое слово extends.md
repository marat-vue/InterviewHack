# Что делает ключевое слово extends

> [!summary] Коротко
> `extends` создает класс-наследник, который получает методы и поведение родительского класса.

## Вопрос

Что делает `extends` в классе?

## Определение

`extends` устанавливает наследование между классами. Дочерний класс получает доступ к методам родителя через цепочку прототипов и может добавлять или переопределять поведение.

## Пример

```javascript
class Animal {
  speak() {
    return 'sound';
  }
}

class Dog extends Animal {
  bark() {
    return 'woof';
  }
}

const dog = new Dog();

console.log(dog.speak()); // 'sound'
console.log(dog.bark());  // 'woof'
```

`Dog` наследует метод `speak()` от `Animal`.

## Переопределение метода

```javascript
class Dog extends Animal {
  speak() {
    return 'woof';
  }
}
```

Если дочерний класс объявляет метод с тем же именем, он переопределяет родительский.

## extends и super

```javascript
class Dog extends Animal {
  speak() {
    return super.speak() + ' and woof';
  }
}
```

`super.method()` вызывает метод родительского класса.

## Мини-шпаргалка

```javascript
class Child extends Parent {
  method() {
    return super.method();
  }
}
```
