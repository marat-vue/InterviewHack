# Как использовать decorators, parameters и globals?

> [!summary]
> Decorators оборачивают story в общий контекст, parameters настраивают поведение Storybook и addons, globals задают глобальные переключатели вроде темы, locale или viewport. Эти механизмы помогают показывать компонент в реалистичной среде.

## Decorators

Decorator оборачивает story:

```ts
export default {
  component: UserCard,
  decorators: [
    (story) => ({
      components: { story },
      template: '<div style="max-width: 360px"><story /></div>',
    }),
  ],
};
```

Использование:

- layout wrapper;
- theme provider;
- router;
- store;
- i18n;
- padding/background.

## Global decorator

В `.storybook/preview.ts`:

```ts
import type { Preview } from '@storybook/vue3-vite';

const preview: Preview = {
  decorators: [
    (story) => ({
      components: { story },
      template: '<main class="storybook-shell"><story /></main>',
    }),
  ],
};

export default preview;
```

## Parameters

Parameters настраивают story или addon:

```ts
export const Mobile: Story = {
  parameters: {
    viewport: {
      defaultViewport: 'mobile1',
    },
  },
};
```

Или:

```ts
parameters: {
  layout: 'centered',
}
```

## Globals

Globals используют для глобальных значений:

```ts
const preview: Preview = {
  globalTypes: {
    theme: {
      toolbar: {
        items: ['light', 'dark'],
      },
    },
  },
};
```

## Мини-шпаргалка

- Decorator оборачивает story.
- Parameters настраивают story/addons.
- Globals задают глобальные переключатели.
- Общие plugins лучше подключать в `preview.ts`.
- Story должна быть близка к реальному UI-контексту.
