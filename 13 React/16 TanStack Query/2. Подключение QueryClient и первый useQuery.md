# Подключение QueryClient и первый useQuery

> [!summary]
> Для работы TanStack Query создают `QueryClient`, оборачивают приложение в `QueryClientProvider`, а данные читают через `useQuery({ queryKey, queryFn })`.

## Установка

```bash
npm install @tanstack/react-query
```

Опционально Devtools:

```bash
npm install @tanstack/react-query-devtools
```

## QueryClientProvider

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { ReactQueryDevtools } from '@tanstack/react-query-devtools'

const queryClient = new QueryClient()

createRoot(document.getElementById('root')!).render(
  <QueryClientProvider client={queryClient}>
    <App />
    <ReactQueryDevtools initialIsOpen={false} />
  </QueryClientProvider>,
)
```

`queryClient` лучше создавать вне компонента, чтобы он не пересоздавался на каждый render.

## Первый useQuery

```tsx
import { useQuery } from '@tanstack/react-query'

type User = {
  id: string
  name: string
}

async function fetchUsers(): Promise<User[]> {
  const response = await fetch('/api/users')

  if (!response.ok) {
    throw new Error('Failed to load users')
  }

  return response.json()
}

function UsersPage() {
  const query = useQuery({
    queryKey: ['users'],
    queryFn: fetchUsers,
  })

  if (query.isPending) return <p>Loading...</p>
  if (query.isError) return <p>{query.error.message}</p>

  return (
    <ul>
      {query.data.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  )
}
```

## queryKey

`queryKey` - адрес данных в кеше.

```tsx
useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
})
```

Если меняется `userId`, меняется и ключ, значит TanStack Query понимает, что это другие данные.

## enabled

Если запрос нельзя делать сразу:

```tsx
const userQuery = useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
  enabled: userId !== null,
})
```

`enabled` часто нужен для dependent queries.

## select

`select` преобразует данные запроса:

```tsx
const userNamesQuery = useQuery({
  queryKey: ['users'],
  queryFn: fetchUsers,
  select: (users) => users.map((user) => user.name),
})
```

Это не меняет исходный cache value, а меняет данные для конкретного подписчика.

## staleTime и gcTime

```tsx
useQuery({
  queryKey: ['users'],
  queryFn: fetchUsers,
  staleTime: 60_000,
  gcTime: 5 * 60_000,
})
```

| Опция | Что означает |
|---|---|
| `staleTime` | сколько данные считаются свежими |
| `gcTime` | сколько неактивный cache хранится до удаления |

## Что отвечать на собеседовании?

Для подключения TanStack Query создают `QueryClient`, передают его в `QueryClientProvider`, а запросы описывают через `useQuery`. Главные поля `useQuery` - `queryKey` и `queryFn`; ключ должен включать все параметры, влияющие на данные.

## Мини-шпаргалка

- Provider: `QueryClientProvider`.
- Query: `useQuery({ queryKey, queryFn })`.
- `queryKey` должен быть стабильным и полным.
- `enabled` отключает запрос до выполнения условия.
- `select` преобразует данные для компонента.
- `staleTime` управляет свежестью.
