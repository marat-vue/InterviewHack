# Shadow DOM vs DOM

> [!summary] Коротко
> Обычный DOM описывает страницу целиком, а Shadow DOM создает изолированное дерево внутри конкретного элемента.

## Вопрос

Чем Shadow DOM отличается от обычного DOM?

## Обычный DOM

Обычный DOM - дерево документа, построенное из HTML страницы. Через него JavaScript находит элементы, меняет текст, классы, атрибуты и структуру страницы.

```javascript
document.querySelector('button');
```

Такой поиск работает по основному дереву документа.

## Shadow DOM

Shadow DOM прикрепляется к элементу-хосту и создает отдельное дерево внутри него.

```javascript
const host = document.querySelector('#app');
const shadow = host.attachShadow({ mode: 'open' });

shadow.innerHTML = '<button>Shadow button</button>';
```

Элемент внутри Shadow DOM не находится обычным `document.querySelector('button')`.

## Сравнение

| Критерий | DOM | Shadow DOM |
| --- | --- | --- |
| Где находится | основное дерево документа | внутри host-элемента |
| Изоляция стилей | нет | есть |
| Поиск через document | да | нет для внутренних элементов |
| Использование | страница | компоненты, виджеты |
| Безопасность | не защита | тоже не защита |

## Пример поиска

```javascript
const shadowButton = host.shadowRoot.querySelector('button');
```

Для поиска внутри открытого Shadow DOM нужно обращаться к `shadowRoot`.

## Когда использовать Shadow DOM

- Web Components;
- независимые UI-виджеты;
- защита стилей компонента от конфликтов;
- изоляция внутренней структуры.

## Мини-шпаргалка

```javascript
const shadow = host.attachShadow({ mode: 'open' });
shadow.querySelector('.inside');
```
