# Как подписаться на поле в Zustand?

> [!summary]
> Чтобы подписаться на конкретное поле Zustand store, нужно передать selector в store hook. Тогда компонент будет зависеть только от выбранной части состояния, а не от всего store.

## Подписка на одно поле

```jsx
const count = useCounterStore((state) => state.count)
```

Компонент обновится, когда изменится `count`.

## Подписка на action

```jsx
const increment = useCounterStore((state) => state.increment)
```

Actions обычно стабильны, если они объявлены при создании store.

## Подписка на несколько полей

Вариант 1: несколько selectors:

```jsx
const count = useCounterStore((state) => state.count)
const status = useCounterStore((state) => state.status)
```

Вариант 2: объект и shallow:

```jsx
import { useShallow } from 'zustand/react/shallow'

const { count, status } = useCounterStore(
  useShallow((state) => ({
    count: state.count,
    status: state.status,
  }))
)
```

Без shallow новый объект может считаться новым значением при каждом изменении store.

## Подписка вне React

```jsx
const unsubscribe = useCounterStore.subscribe((state) => {
  console.log(state.count)
})

unsubscribe()
```

Такой подход полезен для интеграций, но в компонентах обычно лучше использовать hook.

## Частые ошибки

- Читать весь store в каждом компоненте.
- Возвращать новый объект из selector без shallow.
- Хранить server state в Zustand без стратегии кеширования.
- Делать один огромный store для всех feature.
- Забывать unsubscribe при ручной подписке.

## Мини-шпаргалка

- Подписка на поле делается через selector.
- `useStore((state) => state.field)` - базовый паттерн.
- Несколько полей можно читать отдельными selectors.
- Для object selector используй shallow при необходимости.
- Ручная `subscribe` требует `unsubscribe`.
