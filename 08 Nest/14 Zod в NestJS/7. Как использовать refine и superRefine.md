# Как использовать refine и superRefine?

> [!summary]
> `refine` и `superRefine` позволяют описывать custom validation, которой нет среди стандартных методов Zod. `refine` подходит для одного условия, `superRefine` - для нескольких issues и cross-field validation.

## refine

```ts
const passwordSchema = z.string().min(8).refine(
  (value) => /[A-Z]/.test(value),
  { error: 'Password must contain uppercase letter' },
);
```

Refinement function не должна бросать exception. Она должна вернуть truthy/falsy value.

## superRefine

```ts
const registerSchema = z.object({
  password: z.string().min(8),
  confirmPassword: z.string(),
}).superRefine((data, ctx) => {
  if (data.password !== data.confirmPassword) {
    ctx.addIssue({
      code: 'custom',
      path: ['confirmPassword'],
      message: 'Passwords do not match',
    });
  }
});
```

## Когда использовать?

- сравнение двух полей;
- проверка диапазонов;
- сложные password rules;
- условно обязательные поля;
- custom business validation на границе API.

## Мини-шпаргалка

- `refine` добавляет custom условие.
- `superRefine` может добавить несколько issues.
- Не бросай exceptions внутри refine.
- Для async checks нужен async parse.
- Database uniqueness лучше проверять в service, не в schema.
