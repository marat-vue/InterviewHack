# Что такое data атрибуты

> [!summary] Коротко
> `data-*` атрибуты позволяют хранить пользовательские данные прямо на HTML-элементе.

## Вопрос

Для чего нужны `data-*` атрибуты и как работать с ними через JavaScript?

## Определение

`data-*` - специальные HTML-атрибуты для хранения дополнительных данных, которые не имеют отдельного стандартного атрибута.

В JavaScript они доступны через свойство `dataset`.

## Пример HTML

```html
<button data-user-id="42" data-action="delete">
  Delete
</button>
```

## Чтение через dataset

```javascript
const button = document.querySelector('button');

console.log(button.dataset.userId); // '42'
console.log(button.dataset.action); // 'delete'
```

Название `data-user-id` превращается в `dataset.userId`.

## Запись

```javascript
button.dataset.state = 'loading';
button.dataset.userId = '100';
```

В HTML это станет:

```html
<button data-user-id="100" data-action="delete" data-state="loading">
  Delete
</button>
```

## Важные нюансы

- значения в `dataset` всегда строки;
- не стоит хранить большие объекты;
- не нужно класть туда секретные данные;
- удобно использовать для делегирования событий.

## Пример с делегированием

```javascript
list.addEventListener('click', (event) => {
  const button = event.target.closest('[data-action]');

  if (!button) return;

  console.log(button.dataset.action);
});
```

## Мини-шпаргалка

```javascript
element.dataset.id;
element.dataset.userId = '42';
element.dataset.state = 'active';
```
