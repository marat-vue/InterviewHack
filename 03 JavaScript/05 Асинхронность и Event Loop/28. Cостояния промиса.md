# Cостояния промиса

> [!summary] Коротко
> У Promise есть три состояния: `pending`, `fulfilled` и `rejected`. Из ожидания он один раз переходит либо в успех, либо в ошибку.

## Вопрос

Какие состояния есть у промиса?

## Состояния

| Состояние | Что означает |
| --- | --- |
| `pending` | промис еще ожидает результат |
| `fulfilled` | промис успешно завершился |
| `rejected` | промис завершился с ошибкой |

Промис создается в состоянии `pending`. Затем он может перейти только в одно из двух финальных состояний: `fulfilled` или `rejected`.

## Пример fulfilled

```javascript
const success = new Promise((resolve) => {
  resolve('ok');
});

success.then(console.log); // 'ok'
```

## Пример rejected

```javascript
const failed = new Promise((resolve, reject) => {
  reject(new Error('fail'));
});

failed.catch((error) => {
  console.error(error.message); // 'fail'
});
```

## Состояние меняется только один раз

```javascript
const promise = new Promise((resolve, reject) => {
  resolve('first');
  reject(new Error('second'));
  resolve('third');
});

promise.then(console.log); // 'first'
```

Первый вызов `resolve` или `reject` фиксирует итог. Остальные попытки изменить состояние игнорируются.

## Settled

`settled` - это не отдельное состояние, а общее название для `fulfilled` и `rejected`.

```text
pending -> fulfilled
pending -> rejected
```

## Мини-шпаргалка

```javascript
pending   // ожидание
fulfilled // успех
rejected  // ошибка
settled   // fulfilled или rejected
```
