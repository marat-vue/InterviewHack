# Как подключить Zustand и создать store?

> [!summary]
> Zustand подключается через пакет `zustand`, а store создается функцией `create`. В TypeScript чаще используют форму `create<Store>()((set, get) => ({ ... }))`, чтобы типизировать state и actions.

## Установка

```bash
npm install zustand
```

или:

```bash
pnpm add zustand
```

## Базовый store

```tsx
import { create } from 'zustand'

type CounterStore = {
  count: number
  increment: () => void
  decrement: () => void
  reset: () => void
}

export const useCounterStore = create<CounterStore>()((set) => ({
  count: 0,

  increment: () => {
    set((state) => ({ count: state.count + 1 }))
  },

  decrement: () => {
    set((state) => ({ count: state.count - 1 }))
  },

  reset: () => {
    set({ count: 0 })
  },
}))
```

## Использование в компоненте

```tsx
function Counter() {
  const count = useCounterStore((state) => state.count)
  const increment = useCounterStore((state) => state.increment)
  const decrement = useCounterStore((state) => state.decrement)

  return (
    <>
      <button onClick={decrement}>-</button>
      <span>{count}</span>
      <button onClick={increment}>+</button>
    </>
  )
}
```

## set и get

`set` обновляет store:

```tsx
set({ count: 0 })
set((state) => ({ count: state.count + 1 }))
```

`get` читает текущее состояние внутри action:

```tsx
type CartStore = {
  items: string[]
  addItem: (id: string) => void
  hasItem: (id: string) => boolean
}

const useCartStore = create<CartStore>()((set, get) => ({
  items: [],

  addItem: (id) => {
    if (get().hasItem(id)) {
      return
    }

    set((state) => ({ items: [...state.items, id] }))
  },

  hasItem: (id) => {
    return get().items.includes(id)
  },
}))
```

## Почему нужен selector?

Плохо:

```tsx
const store = useCounterStore()
```

Компонент подпишется на весь store и будет ререндериться при любом изменении.

Лучше:

```tsx
const count = useCounterStore((state) => state.count)
```

Компонент обновится только когда изменится выбранное значение.

## Что отвечать на собеседовании?

Zustand store создается через `create`. Внутри store описывают state и actions, для обновления используют `set`, для чтения текущего значения внутри actions - `get`. В компонентах важно читать state через selectors, чтобы не подписываться на весь store.

## Мини-шпаргалка

- Установка: `npm install zustand`.
- Store: `create<Store>()((set, get) => ({ ... }))`.
- `set({ field })` - обновить state.
- `get()` - прочитать state внутри action.
- Selector: `useStore((state) => state.field)`.
