# Как создать собственный тип ошибки?

> [!NOTE]
> Собственную ошибку создают через класс, который наследуется от `Error`, вызывает `super(message)` и задает `name`.

## Вопрос

Как создать пользовательский тип ошибки в JavaScript?

## Определение

Собственный класс ошибки полезен, когда нужно отличать разные проблемы друг от друга: ошибки валидации, авторизации, сетевые ошибки, бизнес-ошибки.

Такой класс обычно наследуется от `Error`.

## Пример

```javascript
class ValidationError extends Error {
  constructor(message, field) {
    super(message);

    this.name = 'ValidationError';
    this.field = field;
  }
}

throw new ValidationError('Email is invalid', 'email');
```

`super(message)` создает базовую ошибку и заполняет `message` и `stack`.

## Обработка конкретного типа

```javascript
try {
  validateUser(user);
} catch (error) {
  if (error instanceof ValidationError) {
    console.log(error.field);
  } else {
    throw error;
  }
}
```

Если ошибка не того типа, ее часто пробрасывают дальше.

## Поле cause

```javascript
class AppError extends Error {
  constructor(message, options) {
    super(message, options);
    this.name = 'AppError';
  }
}

throw new AppError('Request failed', {
  cause: originalError,
});
```

`cause` помогает сохранить исходную причину ошибки.

## Мини-шпаргалка

```javascript
class MyError extends Error {
  constructor(message) {
    super(message);
    this.name = 'MyError';
  }
}
```
