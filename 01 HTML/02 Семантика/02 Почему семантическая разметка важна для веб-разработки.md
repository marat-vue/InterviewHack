# Почему семантическая разметка важна для веб-разработки?

> [!NOTE]
> Семантическая разметка делает страницу понятной для браузеров, поисковых систем, скринридеров и других разработчиков. Она улучшает доступность, SEO, поддержку и предсказуемость интерфейса.

## Главное

Семантический HTML дает структуре страницы смысл. Это важно даже если визуально страницу можно сверстать только на `div`.

```html
<!-- хуже -->
<div class="menu">...</div>
<div class="content">...</div>

<!-- лучше -->
<nav>...</nav>
<main>...</main>
```

Во втором варианте назначение блоков понятно без чтения CSS-классов.

## Польза для доступности

Скринридеры и другие assistive technologies используют семантику, чтобы помогать пользователю перемещаться по странице.

```html
<main>
  <h1>Личный кабинет</h1>
  <section aria-labelledby="orders-title">
    <h2 id="orders-title">Последние заказы</h2>
  </section>
</main>
```

Пользователь может быстро перейти к основному содержимому или просмотреть заголовки.

## Польза для SEO

Поисковые системы анализируют структуру страницы: заголовки, основной контент, ссылки, изображения, статьи. Семантика помогает им лучше понять, что является важным содержимым.

## Польза для команды

Семантическая разметка легче читается.

```html
<article class="post-card">
  <h2>Как работает HTML</h2>
  <p>Короткое описание статьи.</p>
</article>
```

Из кода сразу видно, что это самостоятельная карточка статьи.

## Польза для браузера

Некоторые элементы имеют встроенное поведение:

- `<button>` фокусируется и нажимается с клавиатуры;
- `<label>` связывается с полем формы;
- `<details>` раскрывается без JavaScript;
- `<input type="email">` включает проверку email.

## Мини-шпаргалка

- Семантика помогает доступности.
- Поисковики лучше понимают структуру страницы.
- Код становится понятнее для команды.
- Нативные элементы дают готовое поведение.
- Сначала выбирают правильный HTML, потом стилизуют CSS.
