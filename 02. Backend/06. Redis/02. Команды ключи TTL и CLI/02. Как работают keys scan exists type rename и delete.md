# Как работают KEYS, SCAN, EXISTS, TYPE, RENAME и delete?

> [!NOTE]
> Команды управления ключами нужны для диагностики и обслуживания Redis. Главный принцип: команды, которые обходят много ключей, нельзя бездумно выполнять в production.

## Как проверить существование ключа?

```redis
EXISTS user:1
```

Можно проверить несколько:

```redis
EXISTS user:1 user:2 user:3
```

Ответ - количество существующих ключей.

## Как узнать тип ключа?

```redis
TYPE cart:user:1
```

Это полезно при ошибке `WRONGTYPE`, когда код ожидает hash, а по ключу лежит string.

## Почему `KEYS` опасен?

```redis
KEYS *
KEYS session:*
```

`KEYS` проходит по всему keyspace. На маленькой локальной базе нормально, на production может заблокировать Redis.

Используй `KEYS` только:

- локально;
- в debug на маленькой базе;
- в одноразовом maintenance окне, если понимаешь риск.

## Как работает `SCAN`?

```redis
SCAN 0 MATCH session:* COUNT 100
```

Ответ содержит:

```txt
cursor
keys
```

Повторяй с новым cursor, пока cursor не станет `0`.

Node.js пример:

```ts
let cursor = 0;

do {
  const result = await redis.scan(cursor, {
    MATCH: 'session:*',
    COUNT: 100,
  });

  cursor = result.cursor;

  for (const key of result.keys) {
    console.log(key);
  }
} while (cursor !== 0);
```

## Как удалить ключ?

```redis
DEL session:abc
```

Для больших ключей лучше:

```redis
UNLINK huge:key
```

`DEL` удаляет синхронно. `UNLINK` отвязывает ключ и освобождает память асинхроннее, что снижает риск latency spike.

## Как переименовать ключ?

```redis
RENAME old:key new:key
```

Если `new:key` уже существует, он будет перезаписан.

Без перезаписи:

```redis
RENAMENX old:key new:key
```

## Как атомарно создать ключ только если его нет?

```redis
SET lock:job:42 token NX EX 30
```

`NX` - set only if key does not exist.

## Мини-шпаргалка

- `EXISTS` - есть ли ключ.
- `TYPE` - тип значения.
- `KEYS` - опасен на больших базах.
- `SCAN` - incremental обход.
- `DEL` - удалить.
- `UNLINK` - лучше для больших ключей.
- `RENAME` перезаписывает target, `RENAMENX` нет.
