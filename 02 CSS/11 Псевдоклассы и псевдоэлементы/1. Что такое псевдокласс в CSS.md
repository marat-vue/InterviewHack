# Что такое псевдокласс в CSS

> [!summary]
> **Псевдокласс** - это часть CSS-селектора, которая выбирает элемент по состоянию, положению в дереве, пользовательскому действию или логическому условию.

## Главное

Псевдокласс пишется через одно двоеточие.

```css
a:hover {
  text-decoration: underline;
}
```

Правило применится к ссылке только в состоянии наведения.

## Примеры состояний

```css
button:disabled {
  opacity: 0.5;
}

input:checked {
  accent-color: #2563eb;
}

:focus-visible {
  outline: 3px solid #2563eb;
}
```

## Структурные псевдоклассы

```css
li:first-child {
  font-weight: 700;
}

li:nth-child(2n) {
  background: #f3f4f6;
}
```

Они выбирают элементы по положению среди соседей.

## Логические псевдоклассы

```css
.card:not(.is-active) {
  opacity: 0.7;
}

.field:has(input:invalid) {
  color: #b91c1c;
}
```

Современные псевдоклассы позволяют описывать условия без лишних JS-классов.

## Мини-шпаргалка

- Псевдокласс начинается с `:`.
- Он выбирает состояние, позицию или условие.
- Частые: `:hover`, `:focus-visible`, `:disabled`, `:checked`.
- Структурные: `:first-child`, `:nth-child()`.
- Современные: `:is()`, `:where()`, `:has()`.
