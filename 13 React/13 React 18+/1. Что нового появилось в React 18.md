# Что нового появилось в React 18?

> [!summary]
> React 18 принес concurrent renderer, automatic batching, новый root API, transitions, новые хуки и streaming SSR с поддержкой Suspense. Главная идея версии - сделать UI отзывчивее и дать React возможность планировать render по приоритетам.

## Новый root API

Старый способ:

```jsx
import ReactDOM from 'react-dom'

ReactDOM.render(<App />, document.getElementById('root'))
```

Новый способ:

```jsx
import { createRoot } from 'react-dom/client'

const root = createRoot(document.getElementById('root'))
root.render(<App />)
```

`createRoot` включает новые возможности React 18 для корня приложения.

## Automatic batching

React 18 группирует несколько state updates в один render не только в React event handlers, но и в Promise, `setTimeout` и других callback.

```jsx
setTimeout(() => {
  setCount((count) => count + 1)
  setFlag((flag) => !flag)
  // React 18: один render
}, 1000)
```

## Transitions

Transitions позволяют отличать срочные updates от несрочных.

```jsx
const [isPending, startTransition] = useTransition()

function handleChange(event) {
  const value = event.target.value

  setInputValue(value)

  startTransition(() => {
    setSearchQuery(value)
  })
}
```

Input обновляется сразу, а тяжелый список может обновляться в фоне.

## Suspense и streaming SSR

React 18 улучшил серверный render:

- `renderToPipeableStream` для Node.js streams;
- `renderToReadableStream` для Web Streams;
- Suspense boundaries могут стримиться частями;
- shell можно отправлять раньше, чем готовы все данные.

## Новые хуки

- `useId` - стабильные ID для accessibility и SSR;
- `useTransition` - non-blocking updates с `isPending`;
- `useDeferredValue` - отложенная версия значения;
- `useSyncExternalStore` - безопасная подписка на external stores;
- `useInsertionEffect` - вставка CSS до layout effects для CSS-in-JS.

## Concurrent rendering

Concurrent rendering - внутренняя возможность React готовить render, прерывать его, продолжать позже и отдавать приоритет более важной работе.

Важно: это не значит, что JavaScript стал многопоточным. React просто лучше планирует работу в одном main thread.

## Мини-шпаргалка

- React 18 начинается с `createRoot`.
- Automatic batching уменьшает лишние render.
- Transitions улучшают отзывчивость UI.
- Streaming SSR работает вместе с Suspense.
- Новые хуки нужны для concurrency, SSR и библиотек.
