# Что такое компонент в React?

> [!summary]
> Компонент в React - это переиспользуемая часть интерфейса, которая получает входные данные через props, может иметь свое состояние и возвращает React-элементы. Компоненты позволяют собирать приложение из маленьких понятных блоков.

## Простое определение

Компонент - это функция, которая описывает кусок UI:

```jsx
function UserCard({ user }) {
  return (
    <article className="user-card">
      <h2>{user.name}</h2>
      <p>{user.role}</p>
    </article>
  )
}
```

Использование:

```jsx
<UserCard user={{ name: 'Анна', role: 'Frontend Developer' }} />
```

## Почему компоненты важны?

Они помогают:

- делить интерфейс на части;
- переиспользовать код;
- изолировать ответственность;
- тестировать UI по частям;
- строить дизайн-системы;
- думать о приложении как о дереве.

## Компонент как часть дерева

```jsx
function App() {
  return (
    <Layout>
      <Header />
      <UserList />
      <Footer />
    </Layout>
  )
}
```

React-приложение - это дерево компонентов, где родитель передает данные детям.

## Что должно быть внутри компонента?

Внутри компонента обычно есть:

- получение props;
- вычисление данных для отображения;
- обработчики событий;
- JSX;
- хуки, если нужно состояние или эффекты.

Важно: render-логика должна быть чистой. Компонент не должен во время render делать запросы, менять DOM или мутировать внешние данные.

## Хороший компонент

Хороший компонент:

- имеет понятное имя;
- решает одну задачу;
- получает данные через props;
- не знает лишнего о внешнем мире;
- легко переиспользуется;
- не содержит случайной бизнес-логики вперемешку с layout.

## Мини-шпаргалка

- Компонент - строительный блок React UI.
- Обычно компонент - функция, возвращающая JSX.
- Props - входные данные компонента.
- State - внутренняя память компонента.
- Приложение React - дерево компонентов.
