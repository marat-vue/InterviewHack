# AnimatePresence layout animations и scroll

> [!summary]
> Для production-анимаций в Motion важно знать `AnimatePresence` для exit animations, `layout` для анимации изменения размеров/позиции, `layoutId` для shared element transitions и scroll/in-view сценарии.

## AnimatePresence

React удаляет компонент сразу, поэтому exit animation не успевает проиграться. `AnimatePresence` решает эту задачу.

```tsx
import { AnimatePresence, motion } from 'motion/react'

function Modal({ open, onClose }: Props) {
  return (
    <AnimatePresence>
      {open && (
        <motion.div
          key="modal"
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
          exit={{ opacity: 0 }}
        >
          <button onClick={onClose}>Close</button>
        </motion.div>
      )}
    </AnimatePresence>
  )
}
```

Важно: элемент внутри `AnimatePresence` должен иметь стабильный `key`.

## Layout animations

```tsx
<motion.div layout>
  {expanded ? <FullCard /> : <CompactCard />}
</motion.div>
```

`layout` анимирует изменение размера и позиции, когда layout меняется.

## Shared layout через layoutId

```tsx
function Tabs({ activeTab }: Props) {
  return (
    <div>
      {tabs.map((tab) => (
        <button key={tab.id}>
          {tab.label}
          {activeTab === tab.id && (
            <motion.div layoutId="active-tab-indicator" />
          )}
        </button>
      ))}
    </div>
  )
}
```

`layoutId` помогает создать эффект общего элемента между разными местами UI.

## whileInView

```tsx
<motion.section
  initial={{ opacity: 0, y: 24 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, amount: 0.3 }}
>
  Content
</motion.section>
```

Полезно для лендингов и длинных страниц, но в app UI не стоит анимировать все подряд.

## Reduced motion

Пользователь может предпочитать меньше анимаций. Это важно для доступности.

```tsx
import { useReducedMotion } from 'motion/react'

function Panel() {
  const shouldReduceMotion = useReducedMotion()

  return (
    <motion.div
      animate={{ opacity: 1, y: shouldReduceMotion ? 0 : 16 }}
    />
  )
}
```

## Что отвечать на собеседовании?

`AnimatePresence` нужен для анимации удаления компонентов через `exit`. `layout` автоматически анимирует изменения размеров и позиции, `layoutId` создает shared element transitions, а `whileInView` запускает анимации при появлении в viewport. Для доступности важно учитывать reduced motion.

## Мини-шпаргалка

- `AnimatePresence` - exit animations.
- `exit` работает внутри `AnimatePresence`.
- `layout` - анимация layout changes.
- `layoutId` - shared element transition.
- `whileInView` - animation on viewport enter.
- `useReducedMotion` - accessibility.
