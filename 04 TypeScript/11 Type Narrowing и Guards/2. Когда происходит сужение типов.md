# Когда происходит сужение типов

> [!summary] Коротко
> Сужение типов происходит после проверок, которые TypeScript умеет анализировать: `typeof`, `instanceof`, `in`, сравнение литералов, truthy-check и пользовательские type guards.

## Вопрос

Когда происходит сужение типов?

## Через `typeof`

```typescript
function handle(value: string | number) {
  if (typeof value === "number") {
    value.toFixed(2);
  }
}
```

## Через `instanceof`

```typescript
function format(value: string | Date) {
  if (value instanceof Date) {
    return value.toISOString();
  }

  return value;
}
```

## Через `in`

```typescript
type Success = { data: string[] };
type Failure = { error: string };

function render(result: Success | Failure) {
  if ("data" in result) {
    return result.data.join(", ");
  }

  return result.error;
}
```

## Через сравнение литералов

```typescript
type State =
  | { status: "loading" }
  | { status: "success"; data: string[] };

function render(state: State) {
  if (state.status === "success") {
    return state.data;
  }
}
```

## Через ранний выход

```typescript
function getLength(value: string | null): number {
  if (value === null) return 0;

  return value.length;
}
```

## Мини-шпаргалка

- `typeof` - примитивы.
- `instanceof` - классы и встроенные объекты.
- `in` - наличие поля в объекте.
- Сравнение литералов - discriminated union.
- `return` и `throw` тоже помогают сужать тип.
