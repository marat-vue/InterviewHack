# Как объявить двумерный массив чисел

> [!summary] Коротко
> Двумерный массив чисел типизируется как `number[][]` или `Array<Array<number>>`. Это массив, внутри которого лежат массивы чисел.

## Вопрос

Как объявить двумерный массив чисел?

## Базовый синтаксис

```typescript
const matrix: number[][] = [
  [1, 2, 3],
  [4, 5, 6],
];
```

Полная generic-запись:

```typescript
const grid: Array<Array<number>> = [
  [0, 1],
  [1, 0],
];
```

## Создание матрицы

```typescript
const rows = 3;
const columns = 4;

const matrix: number[][] = Array.from({ length: rows }, () =>
  Array.from({ length: columns }, () => 0)
);
```

Лучше использовать `Array.from`, чтобы каждая строка была отдельным массивом.

## Частая ошибка с `fill`

```typescript
const matrix = Array(3).fill(Array(4).fill(0));

matrix[0][0] = 1;
console.log(matrix[1][0]); // тоже 1: строки ссылаются на один массив
```

## Readonly-вариант

```typescript
const matrix: readonly (readonly number[])[] = [
  [1, 2],
  [3, 4],
];
```

## Мини-шпаргалка

- `number[]` - одномерный массив чисел.
- `number[][]` - двумерный массив.
- `number[][][]` - трехмерный массив.
- Для создания матрицы безопаснее `Array.from`.
