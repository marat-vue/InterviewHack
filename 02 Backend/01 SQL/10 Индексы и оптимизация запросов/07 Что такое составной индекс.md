# Что такое составной индекс?

> [!NOTE]
> Составной индекс строится по нескольким колонкам. Он полезен для запросов, которые фильтруют и сортируют данные по устойчивой комбинации полей.

## Пример

```sql
CREATE INDEX idx_orders_user_created
ON orders(user_id, created_at DESC);
```

Запрос:

```sql
SELECT *
FROM orders
WHERE user_id = 42
ORDER BY created_at DESC
LIMIT 10;
```

Такой индекс хорошо подходит под условие и сортировку.

## Порядок колонок важен

Индекс `(user_id, created_at)` хорошо помогает запросам по `user_id`, но не обязательно помогает запросу только по `created_at`.

```sql
-- Хорошо
WHERE user_id = 42

-- Не всегда хорошо
WHERE created_at >= DATE '2026-01-01'
```

## Правило левого префикса

Многие B-tree индексы эффективно используют левую часть индекса: `(a, b, c)` помогает по `a`, по `a,b`, по `a,b,c`, но не всегда по одному `b`.

## Мини-шпаргалка

- Составной индекс содержит несколько колонок.
- Порядок колонок критичен.
- Смотри на реальные `WHERE` и `ORDER BY`.
- Не создавай все комбинации полей.
- Проверяй эффект через `EXPLAIN`.
