# Что такое тип (type) в TypeScript

> [!summary] Коротко
> `type` создает псевдоним для типа, чтобы переиспользовать его в коде и давать сложным типам понятные имена.

## Вопрос

Что делает ключевое слово `type` в TypeScript?

## Определение

`type` alias - имя для любого типа: примитива, объекта, union, intersection, функции, кортежа или сложной композиции.

Он не создает JavaScript-код и существует только на этапе проверки типов.

## Тип объекта

```typescript
type User = {
  id: number;
  name: string;
};

const user: User = {
  id: 1,
  name: 'Ann',
};
```

## Union type

```typescript
type Status = 'idle' | 'loading' | 'success' | 'error';

let status: Status = 'idle';
```

## Тип функции

```typescript
type Formatter = (value: number) => string;

const formatPrice: Formatter = (value) => `$${value}`;
```

## Когда использовать type

- union и intersection;
- литеральные типы;
- типы функций;
- mapped/conditional types;
- сложные композиции типов.

## Важный нюанс

`type` нельзя объявить повторно с тем же именем в одной области видимости. В отличие от `interface`, он не поддерживает declaration merging.

## Мини-шпаргалка

```typescript
type Name = string;
type User = { id: number; name: string };
type Status = 'idle' | 'done';
```
