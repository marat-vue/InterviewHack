# Проверка на массив

> [!summary] Коротко
> Надежный способ проверить массив - `Array.isArray(value)`. `typeof` не подходит, потому что для массива возвращает `"object"`.

## Вопрос

Как проверить, что значение - это массив?

## Правильный способ

```javascript
Array.isArray(value);
```

Примеры:

```javascript
Array.isArray([1, 2, 3]); // true
Array.isArray([]);        // true
Array.isArray({});        // false
Array.isArray("text");    // false
```

## Почему не `typeof`

```javascript
typeof []; // "object"
typeof {}; // "object"
```

Массив - разновидность объекта, поэтому `typeof` не различает их.

## Почему осторожно с `instanceof`

```javascript
[] instanceof Array; // true
```

Обычно работает, но может ошибаться с массивами из другого iframe/window.

`Array.isArray` надежнее.

## Практический пример

```javascript
function normalizeToArray(value) {
  return Array.isArray(value) ? value : [value];
}

normalizeToArray("a"); // ["a"]
normalizeToArray(["a", "b"]); // ["a", "b"]
```

## Мини-шпаргалка

| Проверка | Результат |
| --- | --- |
| `Array.isArray([])` | `true` |
| `Array.isArray({})` | `false` |
| `typeof []` | `"object"` |
| `[] instanceof Array` | менее надежно |
