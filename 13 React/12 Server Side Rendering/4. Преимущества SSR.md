# Преимущества SSR

> [!summary]
> SSR дает готовый HTML уже в первом ответе сервера. Это улучшает видимость контента для пользователей, поисковых систем и социальных preview, а также позволяет подготовить данные до запуска клиентского JavaScript.

## Быстрый показ контента

При CSR пользователь может сначала получить пустой root:

```html
<div id="root"></div>
```

При SSR он получает содержимое:

```html
<main>
  <h1>Running shoes</h1>
  <p>Lightweight shoes for daily training.</p>
</main>
```

Даже если JavaScript еще не загрузился, основной content уже виден.

## SEO

Поисковый бот получает HTML с текстом, заголовками и ссылками сразу.

Это особенно важно для:

- товарных страниц;
- статей;
- документации;
- новостей;
- публичных профилей.

## Meta и Open Graph

SSR позволяет сформировать теги под конкретную страницу:

```html
<title>Running shoes - Store</title>
<meta name="description" content="Lightweight shoes for daily training">
<meta property="og:title" content="Running shoes">
<meta property="og:image" content="https://example.com/shoes.jpg">
```

Социальные сети и мессенджеры видят эти теги при первом запросе.

## Данные доступны до render

Сервер может:

- прочитать cookies;
- проверить сессию;
- определить язык;
- получить данные из API;
- собрать initial state;
- выбрать правильный layout.

```jsx
const user = await getUserFromCookie(request.headers.cookie)
const html = renderToString(<App user={user} />)
```

## Progressive enhancement

Если JavaScript грузится медленно, SSR-страница может все равно показать базовый content. После hydration React добавит интерактивность.

## Мини-шпаргалка

- SSR улучшает первый показ осмысленного content.
- SEO и social preview обычно лучше, чем в чистом CSR.
- Сервер может подготовить данные заранее.
- Пользователь видит HTML до hydration.
- Для максимальной пользы SSR нужно сочетать с кешированием и хорошим data loading.
