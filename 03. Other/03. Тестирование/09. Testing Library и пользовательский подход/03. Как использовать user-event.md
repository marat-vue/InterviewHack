# Как использовать user-event?

> [!summary]
> `user-event` имитирует пользовательские действия реалистичнее, чем простой dispatch event: click, type, clear, tab, keyboard, selectOptions, upload. Его используют вместе с Testing Library, чтобы тестировать поведение интерфейса через действия человека.

## Зачем нужен `user-event`?

`fireEvent` просто вызывает событие. `user-event` пытается воспроизвести цепочку событий, которая происходит в браузере при реальном действии пользователя.

Например, ввод текста - это не одно событие, а набор keyboard/input events.

## Setup

```ts
import userEvent from '@testing-library/user-event';

test('submits login form', async () => {
  const user = userEvent.setup();

  render(LoginForm);

  await user.type(screen.getByLabelText('Email'), 'ann@example.com');
  await user.type(screen.getByLabelText('Password'), 'secret123');
  await user.click(screen.getByRole('button', { name: 'Войти' }));

  expect(await screen.findByText('Добро пожаловать')).toBeInTheDocument();
});
```

## Частые методы

```ts
await user.click(button);
await user.type(input, 'hello');
await user.clear(input);
await user.tab();
await user.keyboard('{Escape}');
await user.selectOptions(select, 'admin');
await user.upload(fileInput, file);
```

## Почему почти всегда нужен `await`?

Действия пользователя могут быть асинхронными: фокус, input events, promises, Vue updates. Поэтому `user-event` обычно используют через `await`.

## Когда нужен `fireEvent`?

`fireEvent` оставляют для низкоуровневых случаев:

- кастомное событие;
- событие, которое сложно выразить как действие пользователя;
- точная проверка обработчика.

Но для обычного UI лучше `user-event`.

## Мини-шпаргалка

- `userEvent.setup()` создает user instance.
- `user.type` вводит текст.
- `user.click` кликает как пользователь.
- `user.tab` проверяет keyboard navigation.
- Почти все действия лучше await-ить.
- `fireEvent` используй для низкоуровневых случаев.
