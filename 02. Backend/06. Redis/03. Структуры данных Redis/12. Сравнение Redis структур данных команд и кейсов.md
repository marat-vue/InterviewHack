# Сравнение Redis структур данных, команд и кейсов

> [!NOTE]
> Эта шпаргалка помогает быстро вспомнить, какая структура данных Redis подходит под конкретную backend-задачу.

## Общая таблица

| Структура | Что хранит | Частые команды | Типовые кейсы |
|---|---|---|---|
| String | bytes/string/number/JSON | `GET`, `SET`, `INCR` | cache, counters, locks |
| Hash | object fields | `HSET`, `HGET`, `HINCRBY` | profile, session metadata |
| List | ordered sequence | `LPUSH`, `RPOP`, `BLPOP` | queue, recent events |
| Set | unique members | `SADD`, `SISMEMBER`, `SINTER` | permissions, online users |
| Sorted Set | members with score | `ZADD`, `ZRANGE`, `ZREVRANK` | leaderboard, priority |
| Stream | append-only events | `XADD`, `XREADGROUP`, `XACK` | event log, worker queue |
| Bitmap | bits inside string | `SETBIT`, `BITCOUNT` | DAU flags |
| HyperLogLog | approximate unique count | `PFADD`, `PFCOUNT` | unique visitors |
| Geo | coordinates | `GEOADD`, `GEOSEARCH` | nearby stores |

## Какие структуры имеют unique members?

- Set;
- Sorted Set;
- HyperLogLog приблизительно считает unique, но не хранит список members для чтения.

## Какие структуры подходят для counters?

- String: `INCR`;
- Hash: `HINCRBY`;
- Sorted Set: `ZINCRBY`.

## Какие структуры подходят для очередей?

- List: простая очередь;
- Stream: надежнее, есть consumer groups и pending entries;
- Sorted Set: delayed jobs по timestamp score.

## Какие структуры требуют trimming?

Требуют явного контроля роста:

- Lists;
- Streams;
- Sorted Sets для time-based данных;
- Sets с growing membership;
- Hashes с большим числом fields.

Примеры:

```redis
LTRIM activity:user:1 0 99
XTRIM events MAXLEN ~ 100000
ZREMRANGEBYSCORE jobs:done -inf 1786000000000
```

## Что лучше для cache?

Для большинства cache:

```redis
SET cache:key value EX 300
```

Для cache объекта с частичными updates:

```redis
HSET cache:user:1 email admin@example.com role admin
EXPIRE cache:user:1 300
```

## Мини-шпаргалка

- String - default для cache.
- Hash - object fields.
- List - простая очередь.
- Set - unique membership.
- Sorted Set - score/rank/time.
- Stream - durable events.
- Bitmap/HLL - компактная аналитика.
- Geo - координаты.
