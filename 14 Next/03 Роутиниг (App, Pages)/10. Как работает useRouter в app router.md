# Как работает useRouter в app router?

> [!summary]
> `useRouter` в App Router - клиентский hook из `next/navigation` для программной навигации. Он работает только в Client Components и дает методы `push`, `replace`, `refresh`, `prefetch`, `back` и `forward`.

## Импорт

```tsx
'use client'

import { useRouter } from 'next/navigation'
```

Важно: в App Router нельзя импортировать `useRouter` из `next/router`. Это Pages Router API.

## Базовый пример

```tsx
'use client'

import { useRouter } from 'next/navigation'

export function SaveButton() {
  const router = useRouter()

  async function handleSave() {
    await saveDraft()
    router.push('/dashboard')
  }

  return <button onClick={handleSave}>Save</button>
}
```

## Основные методы

| Метод | Что делает |
|---|---|
| `router.push(url)` | перейти и добавить запись в history |
| `router.replace(url)` | перейти без новой history entry |
| `router.refresh()` | обновить текущий route и RSC payload |
| `router.prefetch(url)` | заранее загрузить route |
| `router.back()` | назад по истории |
| `router.forward()` | вперед по истории |

## push vs replace

```tsx
router.push('/profile')
router.replace('/login')
```

`push` подходит для обычного перехода. `replace` полезен после login/logout redirect, чтобы пользователь не возвращался на промежуточную страницу.

## refresh

```tsx
router.refresh()
```

`refresh` заново запрашивает данные текущего route на сервере и обновляет Server Components без полной перезагрузки документа.

## Когда лучше Link?

Для обычной навигации лучше `Link`:

```tsx
<Link href="/settings">Settings</Link>
```

`useRouter` нужен, когда переход является результатом действия: сохранение формы, успешная оплата, закрытие wizard.

## Что отвечать на собеседовании?

`useRouter` в App Router импортируется из `next/navigation`, работает только в Client Components и нужен для программной навигации. Для обычных ссылок используют `Link`, а `useRouter` применяют после действий пользователя или async операций.

## Частые ошибки

- Импортировать из `next/router`.
- Использовать hook в Server Component.
- Делать все ссылки через `router.push`.
- Передавать непроверенный URL в `router.push`.
- Путать `refresh` с полной перезагрузкой страницы.

## Мини-шпаргалка

- App Router import: `next/navigation`.
- Только Client Component.
- `push` добавляет history entry.
- `replace` заменяет current entry.
- `refresh` обновляет current route data.
- Для ссылок используй `Link`.
