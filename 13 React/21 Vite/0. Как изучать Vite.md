# Как изучать Vite

> [!summary]
> Vite нужно изучать как современный frontend build tool: dev server, HMR, plugins, env variables, build, preview, proxy, aliases и production optimization. В React-проектах Vite часто заменяет старые сборочные setups.

## Что такое Vite?

Vite - инструмент разработки и сборки frontend-приложений.

Он дает:

- быстрый dev server;
- Hot Module Replacement;
- поддержку React через plugin;
- работу с TypeScript;
- обработку CSS/assets;
- env variables;
- production build;
- plugin ecosystem.

## Почему Vite быстрый в dev?

В dev-режиме Vite не пытается заранее собрать весь проект в один bundle. Он использует native ES modules в браузере и отдает модули по запросу.

Это особенно заметно на больших проектах: старт dev server и обновления обычно быстрее, чем у старых bundler-first инструментов.

## Что нужно знать по порядку?

1. Создание React-проекта.
2. `npm run dev`.
3. `vite.config.ts`.
4. Plugins.
5. Path aliases.
6. Env variables.
7. Proxy для API.
8. Static assets.
9. `vite build`.
10. `vite preview`.

## Что отвечать на собеседовании?

Vite - современный build tool и dev server. В dev он использует native ESM и быстрый HMR, а для production делает оптимизированную сборку. Его настраивают через `vite.config.ts`, расширяют plugins, env читают через `import.meta.env`, а production проверяют через `vite preview`.

## Мини-шпаргалка

- `npm create vite@latest` - создать проект.
- `npm run dev` - dev server.
- `vite.config.ts` - конфигурация.
- `plugins` - React, Tailwind и другие интеграции.
- `import.meta.env` - env variables.
- `vite build` - production build.
