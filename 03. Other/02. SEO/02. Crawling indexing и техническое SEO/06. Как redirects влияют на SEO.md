# Как redirects влияют на SEO?

> [!summary]
> Redirect сообщает браузеру и поисковику, что URL должен вести в другое место. Для SEO редиректы особенно важны при переездах, изменении URL, удалении дублей и миграциях.

## Какие редиректы важны?

| Код | Смысл | SEO-сценарий |
|---|---|---|
| `301` | постоянный редирект | URL переехал навсегда |
| `302` | временный редирект | временная акция, A/B, гео-переход |
| `307` | временный, сохраняет метод | временный redirect для HTTP/1.1 |
| `308` | постоянный, сохраняет метод | современный аналог постоянного redirect |

## Пример 301

```http
HTTP/1.1 301 Moved Permanently
Location: https://example.com/new-page
```

Используй его, когда старая страница окончательно заменена новой.

## Что такое redirect chain?

Redirect chain - цепочка из нескольких переходов:

```text
/old -> /older -> /newer -> /new
```

Лучше сделать сразу:

```text
/old -> /new
```

Цепочки замедляют загрузку, усложняют crawling и повышают риск ошибок.

## Что такое redirect loop?

Redirect loop - бесконечный цикл:

```text
/a -> /b -> /a
```

Для пользователя это ошибка, для поисковика - невозможность получить страницу.

## Когда не нужен redirect?

Если страница удалена и замены нет, лучше вернуть:

```http
404 Not Found
```

или:

```http
410 Gone
```

Не стоит редиректить все удаленные страницы на главную. Это плохой UX и слабый сигнал релевантности.

## Мини-шпаргалка

- `301` и `308` - постоянный переезд.
- `302` и `307` - временный переезд.
- Избегай цепочек и циклов.
- Старые URL при миграции должны вести на максимально релевантные новые URL.
- Не редиректи все подряд на главную.
