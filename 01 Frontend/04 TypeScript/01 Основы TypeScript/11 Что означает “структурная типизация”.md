# Что означает “структурная типизация”?

> [!NOTE]
> Структурная типизация означает, что совместимость типов определяется их формой, а не названием.

## Вопрос

Что такое structural typing в TypeScript?

## Определение

TypeScript сравнивает типы по структуре: какие свойства и методы есть у значения. Если объект имеет нужную форму, он подходит, даже если не был явно объявлен как конкретный тип.

## Пример

```typescript
type User = {
  name: string;
};

function greet(user: User) {
  console.log(user.name);
}

const person = {
  name: 'Ann',
  age: 25,
};

greet(person); // ok
```

`person` подходит, потому что у него есть обязательное свойство `name`.

## Сравнение с номинальной типизацией

В номинальной типизации важно имя типа или явное наследование. В TypeScript чаще важна структура.

```text
TypeScript: "есть нужные поля?" -> подходит
Nominal style: "объявлен именно этим типом?" -> подходит
```

## Excess property check

```typescript
greet({ name: 'Ann', age: 25 }); // может быть ошибка для object literal
```

Для объектных литералов TypeScript выполняет дополнительную проверку лишних свойств. Это помогает ловить опечатки.

## Почему это удобно

- меньше лишней иерархии классов;
- проще описывать plain objects;
- удобно типизировать данные API;
- хорошо сочетается с JavaScript-стилем.

## Мини-шпаргалка

```typescript
type HasName = { name: string };

const value = { name: 'Ann', id: 1 };
// value совместим с HasName
```
