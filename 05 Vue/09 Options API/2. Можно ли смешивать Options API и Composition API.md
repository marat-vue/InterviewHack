# Можно ли смешивать Options API и Composition API

> [!summary] Коротко
> Да, смешивать Options API и Composition API можно, но лучше делать это осознанно: для миграции, подключения composable или постепенного рефакторинга.

## Вопрос

Можно ли смешивать Options API и Composition API?

## Пример

```vue
<script>
import { ref } from "vue";

export default {
  setup() {
    const count = ref(0);
    return { count };
  },
  computed: {
    doubled() {
      return this.count * 2;
    },
  },
};
</script>
```

Все, что возвращено из `setup`, доступно в шаблоне и через `this` в Options API.

## Важное правило

Внутри `setup` нет доступа к `this`.

```javascript
setup() {
  // this.count; // ошибка
}
```

`setup` выполняется раньше, чем Options API полностью подготовит экземпляр.

## Когда смешивание полезно

- Постепенная миграция Vue 2/Options-компонента.
- Нужно подключить composable в старый компонент.
- Команда переводит проект на Composition API поэтапно.

## Когда лучше выбрать один стиль

Для нового компонента обычно чище писать все либо в Composition API, либо в Options API. Так проще читать и поддерживать код.

## Мини-шпаргалка

- Смешивать можно.
- В `setup` нельзя использовать `this`.
- Возвращенное из `setup` видно в template.
- Смешивание удобно для миграции, но не как стиль по умолчанию.
