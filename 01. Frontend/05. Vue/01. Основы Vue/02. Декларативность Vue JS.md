# Декларативность Vue JS

> [!NOTE]
> Декларативность означает, что ты описываешь желаемое состояние интерфейса, а не пошаговые DOM-операции. Vue сам решает, какие изменения нужно применить.

## Вопрос

Что означает декларативность во Vue?

## Императивный подход

В чистом DOM-коде нужно вручную найти элемент и изменить его.

```javascript
const button = document.querySelector("button");
const counter = document.querySelector(".counter");

let count = 0;

button.addEventListener("click", () => {
  count += 1;
  counter.textContent = String(count);
});
```

## Декларативный подход Vue

Во Vue ты связываешь шаблон с состоянием.

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

Vue сам обновит DOM после изменения `count`.

## Почему это удобно

Код становится ближе к описанию UI: если `count` равен `3`, на кнопке должно быть `3`. Не нужно вручную синхронизировать каждое место в DOM.

## Где видно декларативность

```vue
<template>
  <p v-if="isLoading">Загрузка</p>
  <UserCard v-else :user="user" />
</template>
```

Ты описываешь правила отображения, а не команды "создай элемент", "удали элемент", "замени текст".

## Мини-шпаргалка

- Декларативно = описываем "что должно быть".
- Императивно = описываем "как пошагово изменить DOM".
- Vue синхронизирует DOM с состоянием.
- Директивы `v-if`, `v-for`, `v-bind` делают шаблон декларативным.
