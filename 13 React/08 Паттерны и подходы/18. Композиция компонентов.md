# Композиция компонентов

> [!summary]
> Композиция компонентов - это сборка сложного UI из простых компонентов через props, `children` и специальные слоты. В React композиция обычно предпочтительнее наследования.

## Простая композиция через children

```jsx
function Card({ children }) {
  return <section className="card">{children}</section>
}
```

Использование:

```jsx
<Card>
  <h2>Profile</h2>
  <p>User settings</p>
</Card>
```

Компонент `Card` отвечает за рамку и layout, а родитель решает, какой контент положить внутрь.

## Композиция через props

```jsx
function PageLayout({ header, sidebar, children }) {
  return (
    <div className="layout">
      <header>{header}</header>
      <aside>{sidebar}</aside>
      <main>{children}</main>
    </div>
  )
}
```

Использование:

```jsx
<PageLayout
  header={<Header />}
  sidebar={<Navigation />}
>
  <Dashboard />
</PageLayout>
```

Это похоже на Slot Pattern.

## Композиция поведения

Компоненты можно комбинировать не только визуально, но и по поведению.

```jsx
function ProtectedPage({ children }) {
  const user = useCurrentUser()

  if (!user) {
    return <Navigate to="/login" />
  }

  return children
}
```

Использование:

```jsx
<ProtectedPage>
  <SettingsPage />
</ProtectedPage>
```

## Почему не наследование?

В React редко нужно создавать компонент через наследование:

```jsx
class PrimaryButton extends Button {}
```

Вместо этого обычно используют props и composition:

```jsx
<Button variant="primary">Save</Button>
```

Композиция проще, гибче и лучше подходит для JSX.

## Типичные паттерны композиции

- `children`;
- named slots;
- compound components;
- render props;
- layout components;
- provider composition;
- wrapper components.

## Мини-шпаргалка

- Композиция = компонент собирается из других компонентов.
- `children` - основной способ вложения JSX.
- Props могут быть React nodes.
- Композиция обычно лучше наследования.
- Многие React-паттерны являются вариантами композиции.
