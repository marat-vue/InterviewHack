# Что делает innerHTML

> [!summary] Коротко
> `innerHTML` читает или заменяет HTML-разметку внутри элемента.

## Вопрос

Что делает свойство `innerHTML` и почему с ним нужно быть осторожным?

## Определение

`element.innerHTML` возвращает HTML-содержимое элемента в виде строки. Если присвоить ему новую строку, браузер распарсит ее как HTML и заменит содержимое элемента.

## Чтение HTML

```html
<div class="card">
  <strong>Hello</strong>
</div>
```

```javascript
const card = document.querySelector('.card');

console.log(card.innerHTML); // "\n  <strong>Hello</strong>\n"
```

## Запись HTML

```javascript
const container = document.querySelector('.container');

container.innerHTML = '<p>Saved</p>';
```

Старое содержимое `container` будет полностью заменено.

## Отличие от textContent

```javascript
element.innerHTML = '<strong>Hello</strong>'; // создаст тег strong
element.textContent = '<strong>Hello</strong>'; // покажет текст как есть
```

Если нужно вставить обычный текст, безопаснее использовать `textContent`.

## Важный риск

Если вставить в `innerHTML` строку от пользователя, можно получить XSS-уязвимость.

```javascript
container.innerHTML = userInput; // опасно
```

## Мини-шпаргалка

```javascript
element.innerHTML;        // прочитать HTML
element.innerHTML = html; // заменить HTML внутри
element.textContent = text; // безопаснее для текста
```
