# Как работает minmax()?

> [!NOTE]
> `minmax()` в CSS Grid задает минимальный и максимальный размер grid-трека. Это помогает создавать гибкие колонки и строки, которые не становятся слишком маленькими или слишком большими.

## Главное

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}
```

Каждая колонка будет минимум `240px`, а максимум - `1fr`.

## Синтаксис

```css
minmax(min, max)
```

Пример:

```css
grid-template-columns: minmax(200px, 400px) 1fr;
```

Первая колонка не станет меньше `200px` и больше `400px`.

## Почему это полезно

Без `minmax()` адаптивные колонки могут стать слишком узкими.

```css
.grid {
  grid-template-columns: repeat(4, 1fr);
}
```

На маленьком контейнере четыре колонки могут быть неудобными. `minmax()` позволяет браузеру переносить или менять количество колонок в связке с `auto-fit`.

## minmax(0, 1fr)

```css
.layout {
  grid-template-columns: minmax(0, 1fr) 320px;
}
```

`minmax(0, 1fr)` часто помогает колонке корректно сжиматься, если внутри длинный контент.

## Мини-шпаргалка

- `minmax(min, max)` задает диапазон размера.
- Часто используется в Grid.
- `minmax(240px, 1fr)` удобно для карточек.
- `auto-fit` + `minmax()` делает адаптивную сетку без media query.
- `minmax(0, 1fr)` помогает избежать переполнения.
