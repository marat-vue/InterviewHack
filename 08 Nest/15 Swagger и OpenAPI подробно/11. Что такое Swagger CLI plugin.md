# Что такое Swagger CLI plugin?

> [!summary]
> Swagger CLI plugin для NestJS может автоматически добавлять часть metadata для DTO, чтобы меньше писать `@ApiProperty` вручную. Это снижает boilerplate, но не отменяет необходимость проверять итоговую OpenAPI-схему.

## Зачем нужен plugin?

Без plugin часто приходится писать:

```ts
@ApiProperty()
email: string;
```

Plugin может автоматически вывести metadata по TypeScript AST и class-validator decorators.

## Где настраивать?

Обычно plugin подключают в Nest CLI/TypeScript build configuration проекта. Конкретная настройка зависит от build tool и версии Nest CLI.

## Что важно проверить?

- optional fields;
- arrays;
- enums;
- nested DTO;
- generics;
- examples;
- descriptions;
- circular dependencies.

## Мини-шпаргалка

- CLI plugin уменьшает ручные `@ApiProperty`.
- Он не заменяет осмысленные descriptions/examples.
- Generics все равно часто требуют ручной schema.
- После включения проверь generated OpenAPI.
- Команда должна договориться: decorators вручную или plugin.
