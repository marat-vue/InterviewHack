# Что такое components и auto imports?

> [!summary]
> Nuxt автоматически импортирует компоненты из `app/components`. Это значит, что компонент можно использовать в template без ручного `import`, а Nuxt сам разберется с регистрацией, code splitting и типизацией.

## Пример

```text
app/components/AppHeader.vue
app/components/product/ProductCard.vue
```

Использование:

```vue
<template>
  <AppHeader />
  <ProductCard />
</template>
```

Импорты писать не нужно.

## Имена компонентов

Nuxt строит имя по пути файла.

```text
app/components/base/Button.vue -> <BaseButton />
app/components/product/Card.vue -> <ProductCard />
```

Это помогает избегать конфликтов имен.

## Lazy components

Nuxt поддерживает lazy import через prefix `Lazy`:

```vue
<template>
  <LazyHeavyChart v-if="showChart" />
</template>
```

Компонент будет загружен только когда понадобится.

## Когда auto-imports вредят?

Auto-imports удобны, но новичок может потерять понимание зависимостей.

Полезная привычка:

- знать, из какой папки приходит компонент;
- не создавать слишком похожие имена;
- не складывать все в одну папку `components`;
- держать структуру по доменам или UI-слоям.

## Мини-шпаргалка

- Компоненты из `app/components` auto-imported.
- `<LazyComponentName />` загружает компонент лениво.
- Имя компонента строится по пути файла.
- Auto-imports уменьшают boilerplate.
- Структуру components надо держать понятной.
