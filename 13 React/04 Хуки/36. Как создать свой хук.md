# Как создать свой хук?

> [!summary]
> Чтобы создать свой хук, нужно вынести повторяющуюся React-логику в функцию с именем `useSomething`, вызвать внутри нужные хуки и вернуть удобный API: значения, функции или объект.

## Шаг 1: найти повторяющуюся логику

Например, несколько компонентов хотят знать, online пользователь или offline.

Без custom hook:

```jsx
function Status() {
  const [isOnline, setIsOnline] = useState(navigator.onLine)

  useEffect(() => {
    function updateStatus() {
      setIsOnline(navigator.onLine)
    }

    window.addEventListener('online', updateStatus)
    window.addEventListener('offline', updateStatus)

    return () => {
      window.removeEventListener('online', updateStatus)
      window.removeEventListener('offline', updateStatus)
    }
  }, [])

  return <p>{isOnline ? 'online' : 'offline'}</p>
}
```

## Шаг 2: вынести хук

```jsx
function useOnlineStatus() {
  const [isOnline, setIsOnline] = useState(navigator.onLine)

  useEffect(() => {
    function updateStatus() {
      setIsOnline(navigator.onLine)
    }

    window.addEventListener('online', updateStatus)
    window.addEventListener('offline', updateStatus)

    return () => {
      window.removeEventListener('online', updateStatus)
      window.removeEventListener('offline', updateStatus)
    }
  }, [])

  return isOnline
}
```

## Шаг 3: использовать в компоненте

```jsx
function Status() {
  const isOnline = useOnlineStatus()

  return <p>{isOnline ? 'online' : 'offline'}</p>
}
```

Компонент стал проще: он отвечает за UI, а hook - за логику.

## Что возвращать из custom hook?

Варианты:

```jsx
return value
```

```jsx
return [value, setValue]
```

```jsx
return { value, setValue, reset }
```

Объект удобнее, если возвращаемых значений много или порядок неочевиден.

## Мини-шпаргалка

- Назови функцию с `use`.
- Вынеси повторяющуюся React-логику.
- Соблюдай правила хуков.
- Верни минимальный удобный API.
- Компонент должен стать проще после выноса.
