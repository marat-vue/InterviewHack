# Чем COUNT звездочка отличается от COUNT column?

> [!summary]
> `COUNT(*)` считает все строки группы, а `COUNT(column)` считает только строки, где указанный столбец не равен `NULL`.

## COUNT(*)

```sql
SELECT COUNT(*)
FROM users;
```

Считает количество строк.

## COUNT(column)

```sql
SELECT COUNT(deleted_at)
FROM users;
```

Считает только пользователей, у которых `deleted_at IS NOT NULL`.

## Пример

| id | email | deleted_at |
|---|---|---|
| 1 | a@test.com | `NULL` |
| 2 | b@test.com | `2026-01-01` |

```sql
SELECT
  COUNT(*) AS all_rows,
  COUNT(deleted_at) AS deleted_rows
FROM users;
```

Результат:

| all_rows | deleted_rows |
|---|---|
| 2 | 1 |

## Частая ошибка

Если нужно количество заказов, обычно нужен `COUNT(*)`. Если нужно количество заполненных email, нужен `COUNT(email)`.

## Мини-шпаргалка

- `COUNT(*)` считает строки.
- `COUNT(column)` считает не-NULL значения.
- `COUNT(DISTINCT column)` считает уникальные не-NULL значения.
- Для `LEFT JOIN` разница особенно важна.
- На собеседовании обязательно упомяни `NULL`.
