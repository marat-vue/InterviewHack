# Что такое payload extraction?

> [!summary]
> Nuxt payload хранит данные, полученные во время SSR/prerender, чтобы клиент не запрашивал их повторно при hydration. Payload extraction управляет тем, как эти данные доставляются для prerendered и cached routes.

## Что такое Nuxt payload?

Когда страница делает:

```ts
const { data } = await useFetch('/api/products');
```

Nuxt может:

1. получить данные на сервере;
2. положить их в payload;
3. отправить payload клиенту;
4. использовать эти данные при hydration без повторного запроса.

## Зачем это нужно?

Без payload browser мог бы повторить тот же запрос после hydration.

Это плохо:

- лишний network;
- медленнее загрузка;
- возможные разные данные server/client;
- риск hydration mismatch.

## `_payload.json`

Для prerendered/cached routes Nuxt может выносить данные в отдельный payload file.

При client-side navigation Nuxt может загрузить payload destination route и переиспользовать данные.

## Что должен понимать разработчик?

Если используешь SSR-friendly composables:

- `useFetch`;
- `useAsyncData`;
- `useLazyFetch`;
- `useLazyAsyncData`;

Nuxt умеет управлять payload.

Если используешь `$fetch` прямо в component setup без `useAsyncData`, можно получить double fetch.

## Мини-шпаргалка

- Payload переносит SSR data на client.
- Это предотвращает повторный fetch при hydration.
- `useFetch` и `useAsyncData` работают с payload.
- `$fetch` сам по себе payload не создает.
- Payload особенно важен для prerendered/cached routes.
