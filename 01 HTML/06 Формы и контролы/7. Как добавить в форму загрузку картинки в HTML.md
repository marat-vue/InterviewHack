# Как добавить в форму загрузку картинки в HTML

> [!summary]
> Для загрузки картинки в HTML используют `<input type="file">`. Если файл отправляется обычной HTML-формой, у формы должен быть `method="post"` и `enctype="multipart/form-data"`.

## Главное

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <label for="avatar">Фото профиля</label>
  <input id="avatar" name="avatar" type="file" accept="image/*">

  <button type="submit">Загрузить</button>
</form>
```

`accept="image/*"` подсказывает браузеру, что нужны изображения.

## Почему нужен enctype

Файлы нельзя отправить как обычные текстовые поля. Для этого используется `multipart/form-data`.

```html
enctype="multipart/form-data"
```

Без него сервер может не получить файл корректно.

## Ограничение типов файлов

```html
<input type="file" accept=".png,.jpg,.jpeg,image/webp">
```

`accept` помогает пользователю выбрать подходящий файл, но не является защитой. Сервер все равно должен проверить тип и размер файла.

## Несколько файлов

```html
<input type="file" name="photos" accept="image/*" multiple>
```

`multiple` позволяет выбрать несколько изображений.

## Получение файла в JavaScript

```js
const input = document.querySelector('input[type="file"]');

input.addEventListener("change", () => {
  const file = input.files[0];
  console.log(file.name, file.type, file.size);
});
```

## Мини-шпаргалка

- Для файла используют `input type="file"`.
- Для картинки добавляют `accept="image/*"`.
- Для обычной отправки формы нужен `enctype="multipart/form-data"`.
- `multiple` разрешает несколько файлов.
- Клиентские ограничения не заменяют серверную проверку.
