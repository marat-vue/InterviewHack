# Из каких фаз состоит Event Loop

> [!summary]
> Event Loop в Node.js проходит через несколько фаз: timers, pending callbacks, poll, check, close callbacks. Между фазами также выполняются очереди microtasks и `process.nextTick`.

## Главное

Упрощенно event loop можно представить так:

```text
timers
  -> pending callbacks
  -> poll
  -> check
  -> close callbacks
```

На практике порядок может зависеть от версии Node.js, платформы и того, где именно был запланирован callback.

## Timers

Фаза timers обрабатывает callbacks от `setTimeout` и `setInterval`, когда их время наступило.

```js
setTimeout(() => {
  console.log("timer");
}, 100);
```

## Poll

Poll связан с I/O: чтение файлов, сетевые события, ответы сокетов.

```js
import { readFile } from "node:fs";

readFile("file.txt", () => {
  console.log("file read");
});
```

## Check

Фаза check обрабатывает `setImmediate`.

```js
setImmediate(() => {
  console.log("immediate");
});
```

## Close callbacks

Здесь обрабатываются события закрытия, например `socket.on("close")`.

## Microtasks

Promises и microtasks выполняются между макрозадачами. `process.nextTick` имеет отдельную очередь Node.js и может выполняться раньше обычных promise callbacks.

## Мини-шпаргалка

- Timers: `setTimeout`, `setInterval`.
- Poll: I/O callbacks.
- Check: `setImmediate`.
- Close callbacks: закрытие ресурсов.
- Promises - microtasks.
- `process.nextTick` не стоит использовать без необходимости, чтобы не зациклить event loop.
