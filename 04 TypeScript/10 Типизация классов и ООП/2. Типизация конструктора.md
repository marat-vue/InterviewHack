# Типизация конструктора

> [!summary] Коротко
> Конструктор типизируется так же, как функция: параметры получают типы, а возвращаемый тип не указывается, потому что `constructor` всегда создает экземпляр класса.

## Вопрос

Как типизировать конструктор класса?

## Базовый пример

```typescript
class User {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}
```

## Параметры-свойства

TypeScript позволяет объявить и заполнить поле прямо в параметрах конструктора.

```typescript
class User {
  constructor(
    public name: string,
    private age: number,
    readonly id: string
  ) {}
}
```

`public name` создает поле `name` и присваивает ему аргумент.

## Опциональные и дефолтные параметры

```typescript
class Pagination {
  constructor(
    public page = 1,
    public pageSize = 20
  ) {}
}
```

Типы `page` и `pageSize` выводятся как `number`.

## Тип конструктора

Если нужно передавать класс как значение, описывают constructor signature.

```typescript
type UserConstructor = new (name: string, age: number) => User;
```

## Мини-шпаргалка

- У параметров конструктора пишутся обычные типы.
- Return type у `constructor` не пишется.
- `public/private/readonly` в параметре сразу создает поле.
- Для типа конструктора используют `new (...args) => Instance`.
