# Для чего нужен React DevTools?

> [!summary]
> React DevTools - это инструмент для отладки React-приложений. Он позволяет смотреть дерево компонентов, props, state, hooks, context, причины render и производительность через Profiler.

## Что можно увидеть в Components?

Во вкладке Components можно:

- изучить дерево компонентов;
- выбрать компонент на странице;
- посмотреть props;
- посмотреть state и hooks;
- увидеть context;
- временно изменить props/state для проверки;
- найти компонент по имени.

Это помогает понять:

```text
Какие данные реально пришли в компонент?
Почему UI выглядит именно так?
Где находится нужный компонент в дереве?
```

## Что делает Profiler?

Profiler показывает, как приложение рендерится:

- какие компоненты рендерились;
- сколько времени занял render;
- почему компонент мог обновиться;
- какие части дерева дорогие;
- как изменилась производительность после оптимизации.

## Когда DevTools особенно полезен?

- Компонент получает не те props.
- State меняется неожиданно.
- Context обновляет слишком много компонентов.
- Список перерисовывается при каждом вводе.
- `memo` не помогает.
- Нужно найти тяжелый компонент.
- Нужно проверить, не сбрасывается ли state из-за key.

## Пример диагностики

Проблема:

```text
При вводе в поиск тормозит вся страница.
```

Что проверить:

- какой state обновляется на каждый символ;
- какие компоненты рендерятся после ввода;
- есть ли тяжелые вычисления;
- передаются ли новые object/function props;
- можно ли изолировать state ближе к input.

## Мини-шпаргалка

- Components показывает дерево, props, state, hooks и context.
- Profiler помогает искать дорогие render.
- DevTools нужен не только для багов, но и для оптимизации.
- Перед `memo` полезно понять реальную причину render.
- В production поведение может отличаться от development, особенно со Strict Mode.
