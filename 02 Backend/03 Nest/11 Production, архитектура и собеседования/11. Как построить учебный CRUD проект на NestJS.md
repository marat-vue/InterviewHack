# Как построить учебный CRUD проект на NestJS?

> [!summary]
> Учебный CRUD-проект лучше строить маленькими слоями: сначала users resource без базы, затем validation, затем database layer, auth, Swagger, tests и production-настройки. Так NestJS перестает быть набором decorators и становится понятной системой.

## Шаг 1. Создать проект

```bash
nest new nest-learning
```

## Шаг 2. Создать users resource

```bash
nest g resource users
```

Начни с in-memory массива, чтобы понять controller/service/DTO без базы.

## Шаг 3. Добавить validation

В `main.ts`:

```ts
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    transform: true,
  }),
);
```

В `CreateUserDto` добавь `@IsEmail`, `@IsString`, `@MinLength`.

## Шаг 4. Подключить database layer

Выбери Prisma или TypeORM. Для первого проекта Prisma часто проще как type-safe client, TypeORM полезен для изучения decorators/entities.

## Шаг 5. Добавить auth

Сделай:

- `AuthModule`;
- login endpoint;
- JWT strategy;
- `JwtAuthGuard`;
- `@CurrentUser()`.

## Шаг 6. Добавить Swagger и tests

Документируй DTO и проверь хотя бы:

- unit test для service;
- e2e test для `POST /users`;
- e2e test для validation error.

## Мини-шпаргалка

- Учись слоями, не подключай все сразу.
- Первый CRUD можно начать без базы.
- Потом добавь validation.
- Потом database и auth.
- Swagger и e2e tests закрепляют понимание.
