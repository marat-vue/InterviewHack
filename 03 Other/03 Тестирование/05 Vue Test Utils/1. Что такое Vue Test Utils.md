# Что такое Vue Test Utils?

> [!summary]
> Vue Test Utils - официальная библиотека для тестирования Vue-компонентов. Она монтирует компонент, возвращает `wrapper` и позволяет проверять rendered output, props, slots, events, forms, plugins и пользовательские действия.

## Простое определение

Vue Test Utils отвечает за Vue-часть теста:

- создать экземпляр компонента;
- передать props, slots, attrs;
- подключить plugins;
- найти элементы в DOM;
- вызвать события;
- проверить emitted events;
- дождаться обновлений Vue.

Vitest или Jest при этом отвечают за запуск тестов и assertions.

## Минимальный пример

```ts
import { mount } from '@vue/test-utils';
import { expect, test } from 'vitest';
import CounterButton from './CounterButton.vue';

test('increments counter after click', async () => {
  const wrapper = mount(CounterButton);

  await wrapper.get('button').trigger('click');

  expect(wrapper.text()).toContain('1');
});
```

## Что такое wrapper?

`wrapper` - объект вокруг смонтированного компонента.

Через него можно:

```ts
wrapper.text();
wrapper.html();
wrapper.find('button');
wrapper.get('[data-testid="save"]');
wrapper.props();
wrapper.emitted();
wrapper.vm;
```

`wrapper.vm` дает доступ к экземпляру компонента, но лучше использовать его редко. Обычно надежнее проверять то, что видит пользователь.

## Когда использовать Vue Test Utils?

Используй VTU, когда нужно проверить:

- компонент;
- props;
- slots;
- events;
- `v-model`;
- conditional rendering;
- router/store/plugins;
- composables внутри компонента.

## Мини-шпаргалка

- Vue Test Utils - официальная библиотека для Vue component tests.
- `mount` создает компонент.
- `wrapper` дает методы для поиска и взаимодействия.
- Vitest/Jest запускают тесты, VTU работает с Vue.
- Проверяй поведение компонента, а не внутренности.
