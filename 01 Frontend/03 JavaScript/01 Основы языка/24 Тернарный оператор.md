# Тернарный оператор

> [!NOTE] Коротко
> Тернарный оператор `condition ? a : b` - короткая форма выбора значения. В отличие от `if...else`, это выражение: оно возвращает результат.

## Вопрос

Что такое тернарный оператор `условие ? истина : ложь`?

## Синтаксис

```javascript
condition ? valueIfTrue : valueIfFalse;
```

Если условие truthy, возвращается первая ветка. Если falsy - вторая.

```javascript
const age = 20;
const status = age >= 18 ? "adult" : "minor";

console.log(status); // "adult"
```

## Отличие от `if...else`

`if...else` - инструкция. Она выполняет блок кода.

```javascript
let status;

if (age >= 18) {
  status = "adult";
} else {
  status = "minor";
}
```

Тернарный оператор - выражение. Его удобно использовать там, где нужно получить значение.

```javascript
const status = age >= 18 ? "adult" : "minor";
```

## Хороший пример использования

```javascript
function getButtonText(isLoading) {
  return isLoading ? "Загрузка..." : "Отправить";
}
```

В UI-коде это частый паттерн:

```javascript
const className = isActive ? "tab tab_active" : "tab";
```

## Когда лучше не использовать

Если логика сложная, `if...else` читается лучше.

```javascript
const message =
  score > 90
    ? "Отлично"
    : score > 70
      ? "Хорошо"
      : score > 50
        ? "Нормально"
        : "Повтори тему";
```

Такой код формально работает, но его сложнее читать. Лучше вынести в функцию:

```javascript
function getScoreMessage(score) {
  if (score > 90) return "Отлично";
  if (score > 70) return "Хорошо";
  if (score > 50) return "Нормально";
  return "Повтори тему";
}
```

## Важная деталь

Условие приводится к boolean по правилам truthy/falsy.

```javascript
const name = "";
const label = name ? name : "Без имени";

console.log(label); // "Без имени"
```

Если пустая строка является допустимым значением, нужно выбирать другой оператор, например `??`.

## Мини-шпаргалка

```javascript
const result = condition ? valueA : valueB;
const text = isLoading ? "Загрузка..." : "Готово";
const price = discount ? oldPrice - discount : oldPrice;
```
