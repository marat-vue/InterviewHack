# Что такое window frame?

> [!summary]
> Window frame определяет, какие строки внутри partition участвуют в расчете оконной функции относительно текущей строки. Frame особенно важен для накопительных сумм и скользящих средних.

## Пример накопительной суммы

```sql
SELECT
  created_at,
  total,
  SUM(total) OVER (
    ORDER BY created_at
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
  ) AS running_total
FROM orders;
```

Frame включает все строки от начала до текущей.

## Скользящее окно

```sql
SELECT
  day,
  revenue,
  AVG(revenue) OVER (
    ORDER BY day
    ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
  ) AS avg_7_days
FROM daily_revenue;
```

Считает среднее за текущий день и 6 предыдущих строк.

## ROWS vs RANGE

`ROWS` работает с физическим количеством строк. `RANGE` работает с диапазоном значений сортировки и может включать строки с одинаковым значением `ORDER BY`.

## Мини-шпаргалка

- Frame задает границы расчета внутри окна.
- `CURRENT ROW` - текущая строка.
- `UNBOUNDED PRECEDING` - от начала окна.
- `ROWS` проще и предсказуемее для собеседований.
- Для running total frame нужно понимать явно.
