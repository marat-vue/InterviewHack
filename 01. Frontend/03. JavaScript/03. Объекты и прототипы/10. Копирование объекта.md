# Копирование объекта

> [!NOTE]
> Объект нельзя скопировать простым `=`: так копируется ссылка. Для поверхностной копии используют spread или `Object.assign`, для глубокой - `structuredClone` или специальные решения.

## Вопрос

Как клонировать объект?

## Присваивание не копирует объект

```javascript
const user = { name: "Anna" };
const copy = user;

copy.name = "Max";

console.log(user.name); // "Max"
```

Обе переменные указывают на один объект.

## Поверхностная копия через spread

```javascript
const user = { name: "Anna", age: 25 };
const copy = { ...user };

copy.name = "Max";

console.log(user.name); // "Anna"
```

Верхний уровень скопирован.

## Поверхностная копия через `Object.assign`

```javascript
const copy = Object.assign({}, user);
```

Это похоже на `{ ...user }`.

## Проблема вложенных объектов

```javascript
const user = {
  name: "Anna",
  address: {
    city: "Moscow",
  },
};

const copy = { ...user };
copy.address.city = "Kazan";

console.log(user.address.city); // "Kazan"
```

Вложенный объект остался общим.

## Глубокая копия

```javascript
const copy = structuredClone(user);

copy.address.city = "Kazan";

console.log(user.address.city); // "Moscow"
```

`structuredClone` копирует вложенные структуры, но не поддерживает функции.

## JSON-подход

```javascript
const copy = JSON.parse(JSON.stringify(obj));
```

Этот способ ограничен: теряет `undefined`, функции, `Symbol`, `Date`, `Map`, `Set` и не работает с циклическими ссылками.

## Мини-шпаргалка

| Способ | Тип копии | Комментарий |
| --- | --- | --- |
| `copy = obj` | нет копии | только ссылка |
| `{ ...obj }` | shallow | удобно |
| `Object.assign({}, obj)` | shallow | старый вариант |
| `structuredClone(obj)` | deep | современный вариант |
| JSON parse/stringify | deep с потерями | осторожно |
