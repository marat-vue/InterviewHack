# Что делает useRef?

> [!summary]
> `useRef` возвращает стабильный объект с полем `current`. В нем можно хранить mutable-значение между render без запуска нового render или получить доступ к DOM-элементу через prop `ref`.

## Базовый синтаксис

```jsx
const ref = useRef(initialValue)
```

React вернет объект:

```js
{
  current: initialValue
}
```

Этот объект сохраняется между render.

## useRef для хранения значения

```jsx
function Stopwatch() {
  const intervalRef = useRef(null)

  function start() {
    intervalRef.current = setInterval(() => {
      console.log('tick')
    }, 1000)
  }

  function stop() {
    clearInterval(intervalRef.current)
  }

  return (
    <>
      <button onClick={start}>Старт</button>
      <button onClick={stop}>Стоп</button>
    </>
  )
}
```

Изменение `intervalRef.current` не вызывает render.

## useRef для DOM

```jsx
function SearchInput() {
  const inputRef = useRef(null)

  function focusInput() {
    inputRef.current?.focus()
  }

  return (
    <>
      <input ref={inputRef} />
      <button onClick={focusInput}>Фокус</button>
    </>
  )
}
```

После commit React положит DOM-узел в `inputRef.current`.

## useRef vs useState

| Критерий | useRef | useState |
|---|---|---|
| Изменение вызывает render | нет | да |
| Подходит для UI-данных | обычно нет | да |
| Хранит значение между render | да | да |
| Используется для DOM | да | нет |

Если значение должно отображаться на экране, используй state.

## Чего избегать?

Не читай и не меняй `ref.current` во время render, кроме безопасной инициализации. Render должен быть чистым и предсказуемым.

## Мини-шпаргалка

- `useRef` возвращает стабильный объект `{ current }`.
- Изменение `current` не вызывает render.
- Ref подходит для DOM, timers, ids, mutable values.
- Для данных UI нужен state.
- Не превращай ref в обход React-модели состояния.
