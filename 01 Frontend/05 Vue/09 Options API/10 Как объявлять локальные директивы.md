# Как объявлять локальные директивы?

> [!NOTE] Коротко
> В Options API локальные директивы объявляют в опции `directives`. Такая директива доступна только внутри текущего компонента.

## Вопрос

Как объявлять локальные директивы?

## Базовый пример

```vue
<script>
export default {
  directives: {
    focus: {
      mounted(element) {
        element.focus();
      },
    },
  },
};
</script>

<template>
  <input v-focus />
</template>
```

Ключ `focus` превращается в директиву `v-focus`.

## Хуки директивы

```javascript
directives: {
  highlight: {
    mounted(element, binding) {
      element.style.background = binding.value;
    },
    updated(element, binding) {
      element.style.background = binding.value;
    },
  },
}
```

`binding.value` содержит значение, переданное в директиву.

## Когда использовать

Локальные директивы полезны для прямой работы с DOM: focus, mask, click outside, измерения, интеграции с маленькими DOM-поведениями.

## Когда лучше компонент

Если нужно описать структуру UI, props или состояние, чаще подходит компонент, а не директива.

## Мини-шпаргалка

- Локальные директивы объявляются в `directives`.
- Используются как `v-name`.
- Доступны только в текущем компоненте.
- Подходят для низкоуровневого DOM-поведения.
