# Рекурсия

> [!NOTE]
> Рекурсия - прием, когда функция вызывает саму себя для решения меньшей версии той же задачи. Нужны базовый случай и рекурсивный шаг.

## Вопрос

Что такое рекурсия? Из чего она состоит? Как избежать бесконечной рекурсии?

## Базовый пример

```javascript
function factorial(n) {
  if (n === 0) return 1;

  return n * factorial(n - 1);
}

factorial(5); // 120
```

`factorial(5)` зависит от `factorial(4)`, тот от `factorial(3)` и так далее.

## Две обязательные части

### Базовый случай

Условие остановки.

```javascript
if (n === 0) return 1;
```

### Рекурсивный шаг

Вызов самой функции с более простой задачей.

```javascript
return n * factorial(n - 1);
```

## Что будет без базового случая

```javascript
function loop() {
  return loop();
}

loop(); // RangeError: Maximum call stack size exceeded
```

Каждый вызов добавляет новый frame в call stack. Если остановки нет, стек переполняется.

## Пример с деревом

Рекурсия хорошо подходит для вложенных структур.

```javascript
function countNodes(node) {
  if (!node) return 0;

  return 1 + node.children.reduce((sum, child) => {
    return sum + countNodes(child);
  }, 0);
}
```

## Когда лучше цикл

Если задача простая линейная, цикл часто понятнее и безопаснее для больших данных.

```javascript
function sum(numbers) {
  let total = 0;

  for (const number of numbers) {
    total += number;
  }

  return total;
}
```

## Мини-шпаргалка

| Часть | Зачем нужна |
| --- | --- |
| базовый случай | останавливает рекурсию |
| рекурсивный шаг | уменьшает задачу |
| call stack | хранит вложенные вызовы |
| переполнение стека | слишком глубокая рекурсия |
