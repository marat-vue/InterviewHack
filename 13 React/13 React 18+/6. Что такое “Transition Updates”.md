# Что такое “Transition Updates”?

> [!summary]
> Transition Updates - это обновления state, которые React считает несрочными. Они позволяют сохранить отзывчивость UI: срочные действия вроде ввода текста выполняются сразу, а тяжелые обновления списка, вкладки или страницы могут быть отложены и прерваны.

## Срочные и несрочные updates

Срочные:

- ввод в input;
- click;
- focus;
- hover;
- typing feedback.

Несрочные:

- фильтрация большого списка;
- переключение тяжелой вкладки;
- обновление графика;
- навигация с Suspense;
- пересчет сложной визуализации.

## Пример

```jsx
function Search({ allItems }) {
  const [query, setQuery] = useState('')
  const [items, setItems] = useState(allItems)
  const [isPending, startTransition] = useTransition()

  function handleChange(event) {
    const value = event.target.value

    setQuery(value)

    startTransition(() => {
      setItems(filterItems(allItems, value))
    })
  }

  return (
    <>
      <input value={query} onChange={handleChange} />
      {isPending && <span>Updating...</span>}
      <ItemsList items={items} />
    </>
  )
}
```

Input обновляется мгновенно. Список обновляется как transition.

## Почему transition можно прервать?

Если пользователь продолжает печатать, React может не завершать старый render списка. Он выбросит устаревшую работу и начнет render для нового значения.

Это возможно потому, что concurrent renderer умеет планировать render, а commit остается атомарным.

## Что нельзя помещать в transition?

Controlled input value:

```jsx
startTransition(() => {
  setQuery(event.target.value) // плохо
})
```

Пользовательский ввод должен быть срочным.

## Transition не делает тяжелый JS параллельным

Если ты выполняешь огромную синхронную функцию до `setState`, main thread все равно будет заблокирован:

```jsx
startTransition(() => {
  const result = veryHeavyCalculation()
  setResult(result)
})
```

Для реально тяжелых расчетов нужны Web Worker, сервер, виртуализация или оптимизация алгоритма.

## Мини-шпаргалка

- Transition updates имеют меньший приоритет.
- Они помогают UI оставаться отзывчивым.
- `useTransition` дает `isPending`.
- `startTransition` без хука не дает pending state.
- Transition - про приоритет render, а не про отдельный поток.
