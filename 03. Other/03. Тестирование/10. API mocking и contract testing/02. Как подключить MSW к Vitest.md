# Как подключить MSW к Vitest?

> [!summary]
> В Vitest MSW обычно подключают через Node server из `msw/node`: создают handlers, поднимают server в setup-файле, очищают handlers после каждого теста и закрывают server после набора.

## Установка

```bash
npm install -D msw
```

## Handlers

```ts
// src/test/mocks/handlers.ts
import { http, HttpResponse } from 'msw';

export const handlers = [
  http.get('/api/users/:id', ({ params }) => {
    return HttpResponse.json({
      id: Number(params.id),
      name: 'Ann',
    });
  }),
];
```

## Server

```ts
// src/test/mocks/server.ts
import { setupServer } from 'msw/node';
import { handlers } from './handlers';

export const server = setupServer(...handlers);
```

## Setup file

```ts
// src/test/setup.ts
import { afterAll, afterEach, beforeAll } from 'vitest';
import { server } from './mocks/server';

beforeAll(() => {
  server.listen({ onUnhandledRequest: 'error' });
});

afterEach(() => {
  server.resetHandlers();
});

afterAll(() => {
  server.close();
});
```

`onUnhandledRequest: 'error'` полезен: если компонент делает неожиданный запрос, тест сразу покажет проблему.

## Vitest config

```ts
export default defineConfig({
  test: {
    environment: 'jsdom',
    setupFiles: ['./src/test/setup.ts'],
  },
});
```

## Мини-шпаргалка

- Установи `msw`.
- Handlers описывают тестовые ответы.
- `setupServer` используется в Node/Vitest tests.
- `server.resetHandlers()` очищает overrides после теста.
- `onUnhandledRequest: 'error'` помогает ловить неожиданные запросы.
