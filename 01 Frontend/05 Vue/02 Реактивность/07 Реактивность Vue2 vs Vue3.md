# Реактивность Vue2 vs Vue3

> [!NOTE] Коротко
> Во Vue 2 реактивность построена на `Object.defineProperty`, а во Vue 3 - на `Proxy`. Из-за этого Vue 3 лучше отслеживает добавление свойств, работу с массивами, `Map`, `Set` и вложенными структурами.

## Вопрос

Чем отличается реактивность Vue 2 и Vue 3?

## Vue 2: Object.defineProperty

Vue 2 превращал поля объекта в getter/setter при создании компонента.

```javascript
data() {
  return {
    user: {
      name: "Анна",
    },
  };
}
```

Поля, объявленные заранее, становились реактивными. Но добавление нового свойства в уже созданный объект могло быть проблемой.

```javascript
this.user.age = 28; // во Vue 2 могло не отслеживаться как ожидается
```

Для таких случаев использовали `Vue.set`.

## Vue 3: Proxy

Vue 3 оборачивает объект в `Proxy`, который перехватывает чтение, запись, удаление и другие операции.

```typescript
import { reactive } from "vue";

const user = reactive({ name: "Анна" });

user.age = 28; // Vue 3 умеет отследить добавление поля
```

## Что улучшилось

- Добавление и удаление свойств объектов отслеживается естественнее.
- Массивы работают предсказуемее.
- Поддерживаются реактивные `Map`, `Set`, `WeakMap`, `WeakSet`.
- Реактивность вынесена в отдельный пакет и лучше сочетается с Composition API.

## Важный нюанс

`Proxy` не поддерживается очень старыми браузерами. Поэтому Vue 3 не ориентирован на Internet Explorer.

## Мини-шпаргалка

- Vue 2: `Object.defineProperty`.
- Vue 3: `Proxy`.
- Vue 3 лучше отслеживает динамические изменения объектов.
- В Vue 3 появились `ref`, `reactive`, `computed`, `watch` как функции Composition API.
