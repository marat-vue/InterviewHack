# Что делает аргумент в директиве?

> [!NOTE] Коротко
> Аргумент директивы указывает, к чему именно применяется директива: событие, атрибут, prop или слот. Он пишется после двоеточия: `v-bind:href`, `v-on:click`.

## Вопрос

Что делает аргумент в директиве?

## Базовый пример

```vue
<a v-bind:href="url">Профиль</a>
<button v-on:click="save">Сохранить</button>
```

В `v-bind:href` аргумент `href` говорит, какой атрибут нужно связать. В `v-on:click` аргумент `click` говорит, какое событие слушать.

## Сокращения

```vue
<a :href="url">Профиль</a>
<button @click="save">Сохранить</button>
```

`:` заменяет `v-bind:`, а `@` заменяет `v-on:`.

## Динамический аргумент

Аргумент может быть выражением в квадратных скобках.

```vue
<script setup>
const attributeName = "href";
const eventName = "click";
</script>

<template>
  <a :[attributeName]="url">Ссылка</a>
  <button @[eventName]="save">Сохранить</button>
</template>
```

Так можно динамически выбирать атрибут или событие.

## Аргумент в слотах

```vue
<template #header>
  Заголовок
</template>
```

`header` - имя слота, то есть аргумент `v-slot`.

## Мини-шпаргалка

- Аргумент уточняет цель директивы.
- `v-bind:href` связывает `href`.
- `v-on:click` слушает `click`.
- Динамический аргумент пишут как `:[name]` или `@[eventName]`.
- Для слотов аргумент задает имя слота.
