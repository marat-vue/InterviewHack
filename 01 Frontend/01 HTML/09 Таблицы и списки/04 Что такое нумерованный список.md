# Что такое нумерованный список?

> [!NOTE]
> Нумерованный список создается тегом `<ol>` и используется, когда порядок элементов имеет значение: шаги инструкции, рейтинг, последовательность действий или этапы процесса.

## Главное

```html
<ol>
  <li>Открыть терминал</li>
  <li>Установить зависимости</li>
  <li>Запустить проект</li>
</ol>
```

`ol` означает ordered list, а каждый пункт списка создается через `li`.

## Когда использовать ol

- Пошаговая инструкция.
- Рецепт.
- Рейтинг.
- Последовательность этапов.
- Правила с порядком выполнения.

## Атрибут start

```html
<ol start="4">
  <li>Проверить результат</li>
  <li>Отправить pull request</li>
</ol>
```

Список начнется с номера 4.

## Атрибут reversed

```html
<ol reversed>
  <li>Финал</li>
  <li>Полуфинал</li>
  <li>Четвертьфинал</li>
</ol>
```

Нумерация пойдет в обратном порядке.

## Мини-шпаргалка

- `ol` - ordered list.
- `li` - пункт списка.
- Используется, когда порядок важен.
- `start` задает начальный номер.
- `reversed` включает обратную нумерацию.
- Для обычного набора пунктов без порядка лучше `ul`.
