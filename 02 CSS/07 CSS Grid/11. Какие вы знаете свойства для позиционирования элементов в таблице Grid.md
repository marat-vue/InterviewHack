# Какие вы знаете свойства для позиционирования элементов в таблице Grid

> [!summary]
> В CSS Grid элементы позиционируют через `grid-column`, `grid-row`, `grid-area` и их longhand-свойства: `grid-column-start`, `grid-column-end`, `grid-row-start`, `grid-row-end`.

## Главное

```css
.item {
  grid-column: 1 / 3;
  grid-row: 2 / 4;
}
```

Элемент займет колонки от линии 1 до 3 и строки от линии 2 до 4.

## Основные свойства

| Свойство | Что задает |
| --- | --- |
| `grid-column-start` | Начальная линия колонки |
| `grid-column-end` | Конечная линия колонки |
| `grid-row-start` | Начальная линия строки |
| `grid-row-end` | Конечная линия строки |
| `grid-column` | Сокращение start / end для колонок |
| `grid-row` | Сокращение start / end для строк |
| `grid-area` | Область или shorthand для row/column |

## Span

```css
.card--wide {
  grid-column: span 2;
}
```

Элемент займет две колонки от своей текущей позиции.

## Именованные areas

```css
.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main";
}

.sidebar {
  grid-area: sidebar;
}
```

Это удобно для layout страницы.

## Auto-placement

Если не задавать позицию, Grid сам размещает items по порядку DOM.

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

## Мини-шпаргалка

- `grid-column` управляет колонками.
- `grid-row` управляет строками.
- `grid-area` может ссылаться на именованную область.
- `span 2` растягивает item на два трека.
- Без явного позиционирования работает auto-placement.
- Для читаемого page-layout удобны named areas.
