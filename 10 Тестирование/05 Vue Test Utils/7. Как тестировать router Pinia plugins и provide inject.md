# Как тестировать router, Pinia, plugins и provide/inject?

> [!summary]
> Зависимости Vue-приложения подключают через `global` options в `mount`. Router, Pinia, Vuetify, i18n и provide/inject можно подключить реально или заменить mocks/stubs, в зависимости от цели теста.

## Router

Для настоящего router:

```ts
const router = createRouter({
  history: createMemoryHistory(),
  routes: [
    { path: '/', component: HomePage },
    { path: '/profile/:id', component: ProfilePage },
  ],
});

await router.push('/profile/1');
await router.isReady();

const wrapper = mount(ProfileLink, {
  global: {
    plugins: [router],
  },
});
```

Для простой проверки navigation можно mock:

```ts
const push = vi.fn();

mount(Component, {
  global: {
    mocks: {
      $router: { push },
    },
  },
});
```

## Pinia

```ts
const pinia = createPinia();
setActivePinia(pinia);

const wrapper = mount(CartButton, {
  global: {
    plugins: [pinia],
  },
});
```

Для component tests также часто используют `@pinia/testing`.

## provide/inject

```ts
const apiClient = {
  getUser: vi.fn().mockResolvedValue({ id: 1, name: 'Ann' }),
};

mount(UserProfile, {
  global: {
    provide: {
      apiClient,
    },
  },
});
```

## UI plugins

Для Vuetify или i18n:

```ts
mount(Component, {
  global: {
    plugins: [vuetify, i18n],
  },
});
```

Если plugin тяжелый, иногда лучше stub/mock.

## Мини-шпаргалка

- `global.plugins` подключает реальные plugins.
- Router можно подключить через `createMemoryHistory`.
- Pinia можно тестировать через `createPinia` или testing pinia.
- `global.provide` задает injectable зависимости.
- Выбирай real dependency или mock по цели теста.
