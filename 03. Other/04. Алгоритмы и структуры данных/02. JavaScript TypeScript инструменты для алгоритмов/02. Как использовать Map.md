# Как использовать Map?

> [!summary]
> `Map` - структура ключ-значение. В алгоритмах ее используют для частот, индексов, кеша, adjacency list, memoization и быстрого поиска по ключу.

## Базовый API

```ts
const count = new Map<string, number>()

count.set('a', 1)
count.set('a', (count.get('a') ?? 0) + 1)

console.log(count.has('a'))
console.log(count.get('a'))
console.log(count.delete('a'))
console.log(count.size)
```

## Частотный словарь

```ts
function frequency(words: string[]): Map<string, number> {
  const map = new Map<string, number>()

  for (const word of words) {
    map.set(word, (map.get(word) ?? 0) + 1)
  }

  return map
}
```

## Two Sum

```ts
function twoSum(nums: number[], target: number): [number, number] | null {
  const indexByValue = new Map<number, number>()

  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i]

    if (indexByValue.has(need)) {
      return [indexByValue.get(need)!, i]
    }

    indexByValue.set(nums[i], i)
  }

  return null
}
```

Time `O(n)`, space `O(n)`.

## Почему Map, а не обычный object?

`Map` удобнее, когда:

- ключи не только строки;
- нужен стабильный `size`;
- важна итерация по entries;
- нужно избежать конфликтов с prototype keys;
- ключами могут быть объекты.

## Что отвечать на собеседовании?

`Map` хранит пары ключ-значение и подходит для быстрого доступа по ключу. В алгоритмах я использую `Map` для frequency counter, хранения индексов, memoization, adjacency list и кешей. В отличие от object, `Map` поддерживает ключи любых типов и имеет удобные методы `set`, `get`, `has`, `delete`, `size`.

## Частые ошибки

- Использовать `map.get(key) || 0`, если значение может быть `0`, `false` или пустой строкой.
- Забывать, что объектные ключи сравниваются по ссылке.
- Использовать object там, где ключ не строка.
- Не обновлять значение через `set`.
- Путать `Map.prototype.map` - такого метода нет.

## Мини-шпаргалка

- `set` - записать.
- `get` - получить.
- `has` - проверить.
- `delete` - удалить.
- `size` - размер.
- Частоты: `(map.get(x) ?? 0) + 1`.
