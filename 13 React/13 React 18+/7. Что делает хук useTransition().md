# Что делает хук useTransition()?

> [!summary]
> `useTransition` создает transition updates и дает флаг `isPending`. С его помощью можно пометить часть обновлений как несрочные и показать UI-индикатор, пока React готовит новый экран или тяжелое поддерево.

## Синтаксис

```jsx
const [isPending, startTransition] = useTransition()
```

`startTransition` помечает state updates внутри callback.

`isPending` становится `true`, пока transition не завершился.

## Пример с вкладками

```jsx
function Tabs() {
  const [tab, setTab] = useState('home')
  const [isPending, startTransition] = useTransition()

  function selectTab(nextTab) {
    startTransition(() => {
      setTab(nextTab)
    })
  }

  return (
    <>
      <nav>
        <button onClick={() => selectTab('home')}>Home</button>
        <button onClick={() => selectTab('reports')}>Reports</button>
      </nav>

      {isPending && <SmallLoader />}
      <TabContent tab={tab} />
    </>
  )
}
```

Если `Reports` тяжелый, React может оставить интерфейс отзывчивым.

## Пример с input

```jsx
function Search({ allItems }) {
  const [query, setQuery] = useState('')
  const [filteredQuery, setFilteredQuery] = useState('')
  const [isPending, startTransition] = useTransition()

  function handleChange(event) {
    const value = event.target.value

    setQuery(value)

    startTransition(() => {
      setFilteredQuery(value)
    })
  }

  return (
    <>
      <input value={query} onChange={handleChange} />
      {isPending && <span>Updating results...</span>}
      <SearchResults query={filteredQuery} items={allItems} />
    </>
  )
}
```

## Ограничения

- не используй transition для controlled input value;
- transition не ускоряет тяжелые синхронные вычисления сами по себе;
- `isPending` не заменяет сетевой loading во всех случаях;
- updates после `await` могут потребовать дополнительного `startTransition`.

## useTransition vs useDeferredValue

`useTransition` удобен, когда ты управляешь setter.

`useDeferredValue` удобен, когда значение уже пришло сверху и нужно отложить его использование.

## Мини-шпаргалка

- `useTransition` возвращает `[isPending, startTransition]`.
- Срочные updates оставляют обычными.
- Несрочные updates оборачивают в `startTransition`.
- `isPending` помогает показать тонкий loading.
- Это инструмент UX для отзывчивости.
