# Что такое batching в React?

> [!summary]
> Batching - это группировка нескольких обновлений state в один render. Вместо того чтобы перерисовывать компонент после каждого `setState`, React собирает обновления и применяет их вместе.

## Простой пример

```jsx
function Form() {
  const [name, setName] = useState('')
  const [isDirty, setIsDirty] = useState(false)
  const [error, setError] = useState(null)

  function handleChange(event) {
    setName(event.target.value)
    setIsDirty(true)
    setError(null)
  }
}
```

React не делает три отдельных render. Он группирует обновления и выполняет один render после завершения обработчика.

## Почему это важно?

Batching дает:

- меньше render;
- меньше reconciliation;
- более консистентный UI;
- меньше промежуточных состояний на экране;
- лучшую основу для concurrent rendering.

## React 18 и automatic batching

До React 18 batching стабильно работал в React event handlers. В React 18 с `createRoot` batching стал автоматическим и для других асинхронных источников.

```jsx
setTimeout(() => {
  setCount((count) => count + 1)
  setFlag(true)
  // React 18+: один render
}, 1000)
```

То же относится к Promise callbacks:

```jsx
fetchUser().then((user) => {
  setUser(user)
  setIsLoading(false)
  // React 18+: один render
})
```

## Batching не делает state мгновенным

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  function handleClick() {
    setCount(count + 1)
    setCount(count + 1)
    setCount(count + 1)
  }
}
```

Все три вызова используют один и тот же `count` из текущего render. Итог будет `+1`, а не `+3`.

Правильно:

```jsx
setCount((count) => count + 1)
setCount((count) => count + 1)
setCount((count) => count + 1)
```

Теперь React последовательно применит updater-функции, и итог будет `+3`.

## Как принудительно сбросить batching?

Редко, но можно использовать `flushSync`:

```jsx
import { flushSync } from 'react-dom'

flushSync(() => {
  setIsOpen(true)
})

dialogRef.current.focus()
```

Это нужно для интеграции с браузерными API или сторонними библиотеками, которым нужен обновленный DOM прямо сейчас.

## Мини-шпаргалка

- Batching группирует несколько updates в один render.
- React 18 расширил automatic batching.
- `setState` все равно не меняет значение прямо в текущем render.
- Для последовательных обновлений используй functional update.
- `flushSync` - редкий escape hatch.
