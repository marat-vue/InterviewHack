# Что такое @nuxt/test-utils и зачем он нужен?

> [!NOTE]
> `@nuxt/test-utils` - официальные utilities для тестирования Nuxt-приложений. Для Nitro он важен, потому что Nuxt server routes, plugins, auto imports, runtime config и composables требуют настоящего Nuxt runtime, а обычный Vitest не всегда поднимает его сам.

## Что тестирует @nuxt/test-utils?

Он помогает тестировать:

- Nuxt components;
- pages;
- composables с Nuxt auto imports;
- plugins;
- server API routes;
- `$fetch`;
- runtime config;
- route behavior;
- e2e flows через browser/page;
- modules.

## Чем отличается от Vitest?

Vitest - test runner.

`@nuxt/test-utils` - набор Nuxt-specific helpers поверх test runner/runtime.

```txt
Vitest
  -> запускает tests

@nuxt/test-utils
  -> поднимает Nuxt environment
  -> дает mountSuspended/renderSuspended
  -> дает setup/$fetch/createPage
  -> умеет mockNuxtImport/registerEndpoint
```

## Когда нужен @nuxt/test-utils?

Нужен, если тестируемый код использует:

- `useRuntimeConfig`;
- `useNuxtApp`;
- `useRoute`;
- `useRouter`;
- auto-imported composables;
- Nuxt plugins;
- `server/api`;
- Suspense/async setup;
- page routing.

## Когда не нужен?

Не нужен для:

- чистых functions;
- plain services;
- Prisma repositories без Nuxt runtime;
- Zod schemas;
- permission logic.

Для этого достаточно Vitest.

## Unit/runtime/e2e entrypoints

Часто используются imports:

```ts
import { mountSuspended } from '@nuxt/test-utils/runtime';
```

```ts
import { setup, $fetch } from '@nuxt/test-utils/e2e';
```

```ts
import { defineVitestConfig } from '@nuxt/test-utils/config';
```

## Мини-шпаргалка

- Vitest запускает tests.
- `@nuxt/test-utils` поднимает Nuxt runtime.
- `runtime` helpers нужны для component/runtime tests.
- `e2e` helpers нужны для app-level tests.
- `config` helpers помогают настроить Vitest под Nuxt.
- Для чистой backend logic используй обычный Vitest.
