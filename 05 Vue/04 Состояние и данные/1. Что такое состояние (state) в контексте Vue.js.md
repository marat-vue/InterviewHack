# Что такое состояние (state) в контексте Vue.js

> [!summary] Коротко
> State во Vue - данные, от которых зависит интерфейс компонента или приложения. Когда state меняется, Vue обновляет связанные части UI.

## Вопрос

Что такое состояние в контексте Vue.js?

## Простая идея

Состояние отвечает на вопрос: "что сейчас происходит в интерфейсе?"

```vue
<script setup>
import { ref } from "vue";

const isOpen = ref(false);
const count = ref(0);
</script>

<template>
  <button @click="isOpen = !isOpen">Переключить</button>
  <p v-if="isOpen">Открыто</p>
  <button @click="count++">{{ count }}</button>
</template>
```

`isOpen` и `count` - state компонента.

## Что может быть состоянием

- Значение поля формы.
- Флаг загрузки.
- Список данных из API.
- Текущий выбранный элемент.
- Информация о пользователе.
- Настройки интерфейса.

## Local и global state

Локальное состояние нужно одному компоненту или небольшой ветке. Глобальное состояние нужно многим независимым частям приложения.

## State и производные данные

Не все нужно хранить в state. Если значение можно вычислить из уже существующих данных, лучше использовать `computed`.

```typescript
const price = ref(100);
const count = ref(2);
const total = computed(() => price.value * count.value);
```

## Мини-шпаргалка

- State - данные, влияющие на UI.
- Изменение state запускает обновление зависимого интерфейса.
- Локальный state хранится рядом с компонентом.
- Глобальный state выносят в store, например Pinia.
- Производные значения лучше делать через `computed`.
