# Чем параллелизм отличается от конкурентности в Node.js?

> [!NOTE]
> Конкурентность означает умение вести несколько задач одновременно по времени, переключаясь между ними. Параллелизм означает реальное выполнение нескольких задач в один момент на разных ядрах или потоках.

## Конкурентность

Node.js конкурентно обрабатывает много I/O-задач.

```js
const [user, posts] = await Promise.all([
  fetchUser(),
  fetchPosts(),
]);
```

Обе операции ожидают I/O, а event loop может обрабатывать другие события.

## Параллелизм

Параллелизм нужен, когда несколько задач реально выполняются одновременно.

```txt
CPU core 1 -> worker A
CPU core 2 -> worker B
CPU core 3 -> worker C
```

В Node.js параллелизм достигается через:

- `worker_threads`;
- `child_process`;
- `cluster`;
- несколько контейнеров или инстансов приложения.

## Почему Promise.all не всегда параллелизм?

```js
await Promise.all([
  heavyCpuTask(),
  heavyCpuTask(),
]);
```

Если `heavyCpuTask` синхронно грузит CPU, первый вызов может заблокировать поток еще до создания второго результата.

## Мини-шпаргалка

- Конкурентность - много задач в работе.
- Параллелизм - реальное одновременное выполнение.
- Node.js силен в конкурентном I/O.
- CPU-bound задачи требуют workers или процессов.
- `Promise.all` не превращает синхронный CPU-код в параллельный.
