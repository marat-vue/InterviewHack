# Что значит “неблокирующий код”?

> [!NOTE] Коротко
> Неблокирующий код не удерживает основной поток в ожидании долгой операции и позволяет приложению оставаться отзывчивым.

## Вопрос

Что означает non-blocking code с точки зрения производительности?

## Определение

Неблокирующий код запускает долгую операцию и не заставляет main thread ждать ее завершения на месте. Результат приходит позже через callback, Promise, `async/await`, событие или сообщение worker-а.

## Пример блокировки

```javascript
const start = Date.now();

while (Date.now() - start < 3000) {
  // main thread занят
}

console.log('done');
```

Пока цикл работает, интерфейс не реагирует.

## Неблокирующий пример

```javascript
console.log('before');

setTimeout(() => {
  console.log('later');
}, 1000);

console.log('after');
```

Код не ждет таймер и продолжает выполнение.

## Важный нюанс

`async/await` делает ожидание удобным, но не превращает тяжелые вычисления в неблокирующие.

```javascript
async function run() {
  heavySynchronousTask(); // все равно блокирует
}
```

Для тяжелых CPU-задач нужны оптимизация алгоритма, дробление работы или Web Worker.

## Мини-шпаргалка

```text
non-blocking I/O -> await/fetch/callback
heavy CPU work -> split or move to Worker
```
