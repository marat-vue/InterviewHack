# Почему Next.js хорошо подходит для SEO?

> [!summary]
> Next.js хорошо подходит для SEO, потому что может отдавать поисковикам готовый HTML, управлять metadata через Metadata API, быстро загружать страницы, оптимизировать изображения и строить sitemap/robots как часть приложения.

## Готовый HTML

В обычной SPA поисковик может сначала увидеть почти пустой HTML:

```html
<div id="root"></div>
```

Next.js может отдать HTML с контентом:

```html
<h1>Купить iPhone 15</h1>
<p>Цена, описание, характеристики...</p>
```

Это помогает crawling и indexing.

## Metadata API

Статические metadata:

```tsx
export const metadata = {
  title: 'Products',
  description: 'Product catalog',
}
```

Динамические metadata:

```tsx
export async function generateMetadata({ params }: Props) {
  const { slug } = await params
  const product = await getProduct(slug)

  return {
    title: product.title,
    description: product.description,
  }
}
```

## Open Graph

Next.js позволяет задавать social preview:

```tsx
export const metadata = {
  openGraph: {
    title: 'Product catalog',
    description: 'Best products',
    images: ['/og.png'],
  },
}
```

## Performance и Core Web Vitals

SEO зависит не только от текста. Next.js помогает производительности через:

- `next/image`;
- `next/font`;
- code splitting по routes;
- prefetch links;
- Server Components;
- streaming;
- кеширование.

## Sitemap и robots

В App Router можно создавать специальные файлы:

```text
app/
  sitemap.ts
  robots.ts
```

Они помогают поисковым системам понимать, какие страницы сканировать.

## Что отвечать на собеседовании?

Next.js полезен для SEO, потому что отдает контент в HTML, поддерживает SSR/SSG/ISR, дает Metadata API для title/description/Open Graph, помогает с performance через Image/Font optimization и позволяет программно создавать sitemap и robots.

## Частые ошибки

- Думать, что Next.js автоматически делает SEO хорошим.
- Делать пустые metadata на всех страницах.
- Закрывать важный контент client-only загрузкой.
- Не настраивать canonical, robots, sitemap.
- Игнорировать Core Web Vitals.

## Мини-шпаргалка

- SSR/SSG дают HTML с контентом.
- `metadata` - статические meta tags.
- `generateMetadata` - динамические meta tags.
- Open Graph нужен для social preview.
- `sitemap.ts` и `robots.ts` помогают индексации.
- Performance влияет на SEO.
