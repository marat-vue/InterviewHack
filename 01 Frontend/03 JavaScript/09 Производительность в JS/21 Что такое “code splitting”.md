# Что такое “code splitting”?

> [!NOTE] Коротко
> Code splitting делит большой JavaScript-бандл на несколько частей, чтобы загружать только нужный код.

## Вопрос

Зачем нужен code splitting?

## Определение

Code splitting - техника сборки, при которой приложение разбивается на отдельные chunks. Вместо одного большого файла браузер получает минимальный код для текущего экрана, а остальное загружает позже.

Это уменьшает начальный JavaScript и ускоряет старт приложения.

## Пример с динамическим импортом

```javascript
button.addEventListener('click', async () => {
  const { openEditor } = await import('./editor.js');

  openEditor();
});
```

`editor.js` попадет в отдельный chunk и загрузится только при необходимости.

## Где применяется

- роуты приложения;
- тяжелые компоненты;
- админ-панели;
- редакторы;
- графики;
- редко используемые библиотеки.

## Плюсы и минусы

| Плюсы | Минусы |
| --- | --- |
| меньше начальный бандл | больше логики загрузки |
| быстрее первый экран | возможна задержка при открытии chunk |
| лучше кэширование | нужно обрабатывать loading/error |

## Code splitting vs lazy loading

Code splitting - разбиение кода на части. Lazy loading - стратегия загрузки этих частей тогда, когда они нужны.

## Мини-шпаргалка

```javascript
const module = await import('./feature.js');
```
