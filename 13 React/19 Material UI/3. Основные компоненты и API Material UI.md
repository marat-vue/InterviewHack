# Основные компоненты и API Material UI

> [!summary]
> Для работы с MUI нужно знать layout-компоненты, form controls, navigation, feedback и overlay-компоненты. У большинства компонентов есть props `variant`, `color`, `size`, `disabled`, `sx`, а сложные компоненты управляются controlled state.

## Layout

| Компонент | Зачем нужен |
|---|---|
| `Box` | универсальный контейнер с `sx` |
| `Stack` | вертикальные/горизонтальные группы |
| `Grid` | grid layout |
| `Container` | ограничение ширины страницы |
| `Paper` | поверхность с elevation |
| `Divider` | разделитель |

```tsx
<Stack direction="row" spacing={2} alignItems="center">
  <Avatar />
  <Box>
    <Typography fontWeight={600}>Ada</Typography>
    <Typography color="text.secondary">Frontend developer</Typography>
  </Box>
</Stack>
```

## Forms

| Компонент | Зачем нужен |
|---|---|
| `TextField` | input с label/error/helper |
| `Select` | select |
| `Checkbox` | checkbox |
| `RadioGroup` | radio buttons |
| `Switch` | toggle |
| `Autocomplete` | searchable select |
| `FormControl` | wrapper для сложных controls |

```tsx
<TextField
  label="Email"
  value={email}
  onChange={(event) => setEmail(event.target.value)}
  error={Boolean(error)}
  helperText={error}
  fullWidth
/>
```

## Feedback

| Компонент | Зачем нужен |
|---|---|
| `Alert` | inline message |
| `Snackbar` | toast-like message |
| `CircularProgress` | loader |
| `Skeleton` | placeholder |
| `Tooltip` | подсказка |

```tsx
<Snackbar open={open} autoHideDuration={3000} onClose={handleClose}>
  <Alert severity="success">Saved</Alert>
</Snackbar>
```

## Navigation

| Компонент | Зачем нужен |
|---|---|
| `Tabs` | вкладки |
| `Breadcrumbs` | путь страницы |
| `Drawer` | боковая панель |
| `Menu` | dropdown |
| `BottomNavigation` | mobile navigation |

## Overlay

```tsx
<Dialog open={open} onClose={onClose}>
  <DialogTitle>Confirm action</DialogTitle>
  <DialogContent>
    <DialogContentText>
      This action cannot be undone.
    </DialogContentText>
  </DialogContent>
  <DialogActions>
    <Button onClick={onClose}>Cancel</Button>
    <Button color="error" onClick={onConfirm}>Delete</Button>
  </DialogActions>
</Dialog>
```

## Что отвечать на собеседовании?

MUI разделяет компоненты на layout, inputs, navigation, feedback, surfaces и overlay. Большинство компонентов controlled через props, поддерживают `sx`, theme tokens и accessibility-паттерны. Для форм важно понимать `TextField`, `FormControl`, `error`, `helperText`, controlled value и связь с form libraries.

## Мини-шпаргалка

- Layout: `Box`, `Stack`, `Grid`, `Container`.
- Forms: `TextField`, `Select`, `Checkbox`, `Autocomplete`.
- Feedback: `Alert`, `Snackbar`, `Skeleton`.
- Overlay: `Dialog`, `Drawer`, `Menu`.
- Styling: `sx`.
- Theme: `ThemeProvider`.
