# Что такое cleanup в useEffect?

> [!summary]
> Cleanup в `useEffect` - это функция очистки, которую effect может вернуть. React вызывает ее перед повторным запуском effect с новыми зависимостями и при размонтировании компонента. Cleanup нужен для подписок, таймеров, соединений и отмены работы.

## Базовый пример

```jsx
useEffect(() => {
  const timerId = setInterval(() => {
    console.log('tick')
  }, 1000)

  return () => {
    clearInterval(timerId)
  }
}, [])
```

Без `clearInterval` таймер продолжит работать после удаления компонента.

## Когда cleanup выполняется?

React вызывает cleanup:

- перед новым запуском effect, если dependencies изменились;
- при размонтировании компонента;
- в development Strict Mode может вызвать cleanup дополнительный раз для проверки.

Схема:

```text
setup(roomId=1)
dependencies изменились
cleanup(roomId=1)
setup(roomId=2)
unmount
cleanup(roomId=2)
```

## Пример с подпиской

```jsx
useEffect(() => {
  function handleResize() {
    setWidth(window.innerWidth)
  }

  window.addEventListener('resize', handleResize)

  return () => {
    window.removeEventListener('resize', handleResize)
  }
}, [])
```

Подписался - отпишись. Это главное правило.

## Пример с AbortController

```jsx
useEffect(() => {
  const controller = new AbortController()

  fetch(`/api/users/${userId}`, {
    signal: controller.signal,
  })

  return () => {
    controller.abort()
  }
}, [userId])
```

Так можно отменить устаревший запрос при смене `userId`.

## Мини-шпаргалка

- Cleanup - функция, которую возвращает effect.
- Он нужен для отмены подписок, таймеров и соединений.
- Cleanup выполняется перед новым setup и при unmount.
- В Strict Mode dev cleanup помогает найти ошибки.
- Если effect что-то "открывает", cleanup должен это "закрыть".
