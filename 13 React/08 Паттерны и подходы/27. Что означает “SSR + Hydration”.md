# Что означает “SSR + Hydration”?

> [!summary]
> SSR + Hydration - это схема, при которой сервер сначала отправляет готовый HTML, а затем React в браузере "оживляет" этот HTML: подключает обработчики событий, state и интерактивность.

## Что делает SSR?

SSR, или Server-Side Rendering, создает HTML на сервере.

```text
Browser -> request page
Server -> renders React to HTML
Browser -> paints ready content
```

Пользователь быстрее видит контент, а поисковые системы получают не пустой `div`, а готовую разметку.

## Что делает hydration?

Hydration подключает React к HTML, который уже есть в DOM.

```jsx
import { hydrateRoot } from 'react-dom/client'

hydrateRoot(document.getElementById('root'), <App />)
```

React не создает страницу с нуля, а сопоставляет существующий HTML с деревом компонентов и подключает интерактивность.

## Схема работы

```text
1. Браузер запрашивает страницу
2. Сервер рендерит React-компоненты в HTML
3. Браузер показывает HTML
4. Браузер загружает JavaScript bundle
5. React выполняет hydration
6. Кнопки, формы и state начинают работать
```

## Почему это полезно?

SSR + Hydration улучшает:

- first paint;
- SEO;
- отображение контента на слабых устройствах;
- perceived performance;
- социальные preview и crawlers.

## Hydration mismatch

Hydration требует, чтобы HTML от сервера совпадал с первым render на клиенте.

Плохо:

```jsx
function Time() {
  return <p>{new Date().toLocaleTimeString()}</p>
}
```

Сервер и клиент могут получить разное время. React увидит несовпадение.

Лучше:

```jsx
function Time() {
  const [time, setTime] = useState(null)

  useEffect(() => {
    setTime(new Date().toLocaleTimeString())
  }, [])

  return <p>{time ?? 'Loading time...'}</p>
}
```

## SSR + Hydration vs RSC

SSR отвечает за начальный HTML.

RSC отвечает за то, какие компоненты выполняются только на сервере и не попадают в client bundle.

Они могут использоваться вместе в современных фреймворках.

## Мини-шпаргалка

- SSR дает готовый HTML.
- Hydration подключает React к уже существующему HTML.
- `hydrateRoot` используется вместо `createRoot`.
- Первый клиентский render должен совпасть с серверным HTML.
- Hydration делает страницу интерактивной.
