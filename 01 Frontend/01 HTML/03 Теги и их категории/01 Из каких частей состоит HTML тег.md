# Из каких частей состоит HTML тег?

> [!NOTE]
> HTML-тег - это часть синтаксиса разметки, которая сообщает браузеру, какой элемент нужно создать. Обычно элемент состоит из открывающего тега, атрибутов, содержимого и закрывающего тега.

## Главное

```html
<a href="/profile" class="link">Профиль</a>
```

В этом примере:

- `<a ...>` - открывающий тег;
- `href="/profile"` и `class="link"` - атрибуты;
- `Профиль` - содержимое элемента;
- `</a>` - закрывающий тег;
- весь фрагмент - HTML-элемент.

## Открывающий тег

Открывающий тег указывает тип элемента.

```html
<p>
<button>
<section>
```

Именно имя тега задает базовый смысл: абзац, кнопка, раздел, ссылка, изображение.

## Атрибуты

Атрибуты добавляют элементу настройки и данные.

```html
<img src="/avatar.png" alt="Фото пользователя">
```

`src` указывает путь к изображению, а `alt` описывает его смысл.

## Содержимое

Содержимым может быть текст или другие элементы.

```html
<button type="button">
  <span>Сохранить</span>
</button>
```

Вложенность формирует дерево элементов.

## Закрывающий тег

Закрывающий тег показывает, где элемент заканчивается.

```html
<strong>Важно</strong>
```

Некоторые элементы закрывающего тега не имеют: например, `img`, `input`, `br`, `hr`.

## Мини-шпаргалка

- Тег пишется в угловых скобках.
- Открывающий тег может содержать атрибуты.
- Закрывающий тег начинается с `/`.
- Элемент = тег + атрибуты + содержимое.
- Не все элементы имеют закрывающий тег.
