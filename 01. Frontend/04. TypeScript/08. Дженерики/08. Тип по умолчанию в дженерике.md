# Тип по умолчанию в дженерике

> [!NOTE]
> Generic-параметру можно задать тип по умолчанию: `<T = string>`. Он используется, если TypeScript не смог вывести тип и пользователь не указал его явно.

## Вопрос

Как задать тип по умолчанию в дженерике?

## Базовый синтаксис

```typescript
type ApiResponse<T = unknown> = {
  data: T;
  error: string | null;
};

type DefaultResponse = ApiResponse;
// data: unknown

type UserResponse = ApiResponse<User>;
// data: User
```

## В функциях

```typescript
function createList<T = string>(): T[] {
  return [];
}

const strings = createList(); // string[]
const numbers = createList<number>(); // number[]
```

## С несколькими generic-параметрами

Параметры с дефолтом обычно ставят правее обязательных.

```typescript
type Result<TData, TError = Error> =
  | { ok: true; data: TData }
  | { ok: false; error: TError };

type UserResult = Result<User>;
```

## С ограничением

```typescript
type Store<T extends object = Record<string, unknown>> = {
  state: T;
};
```

Дефолтный тип тоже должен проходить ограничение.

## Мини-шпаргалка

- `<T = Default>` задает тип по умолчанию.
- Дефолт используется, когда тип не указан и не выведен.
- Можно сочетать с `extends`.
- Удобно для API, где есть самый частый сценарий.
