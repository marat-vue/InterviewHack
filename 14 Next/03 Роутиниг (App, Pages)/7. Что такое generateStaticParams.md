# Что такое generateStaticParams?

> [!summary]
> `generateStaticParams` - функция App Router для статической генерации dynamic routes. Она возвращает список `params`, по которым Next.js заранее создаст страницы во время build.

## Зачем нужна generateStaticParams?

Есть dynamic route:

```text
app/blog/[slug]/page.tsx
```

Но Next.js не знает заранее, какие `slug` существуют. `generateStaticParams` сообщает это фреймворку.

```tsx
export async function generateStaticParams() {
  const posts = await getPosts()

  return posts.map((post) => ({
    slug: post.slug,
  }))
}
```

## Полный пример

```tsx
type Props = {
  params: Promise<{ slug: string }>
}

export async function generateStaticParams() {
  const posts = await getPosts()

  return posts.map((post) => ({
    slug: post.slug,
  }))
}

export default async function PostPage({ params }: Props) {
  const { slug } = await params
  const post = await getPost(slug)

  return <Article post={post} />
}
```

## Что возвращать?

Для route `app/products/[id]/page.tsx`:

```ts
return [{ id: '1' }, { id: '2' }]
```

Для route `app/shops/[shopId]/products/[productId]/page.tsx`:

```ts
return [
  { shopId: 'a', productId: '1' },
  { shopId: 'a', productId: '2' },
]
```

## generateStaticParams и ISR

`generateStaticParams` хорошо сочетается с revalidation:

```tsx
export const revalidate = 3600
```

Так страницы можно сгенерировать заранее и периодически обновлять.

## Что отвечать на собеседовании?

`generateStaticParams` используется в dynamic routes App Router, чтобы заранее сгенерировать страницы для известных параметров. Это аналог идеи `getStaticPaths` из Pages Router, но для App Router. Функция выполняется на сервере и возвращает массив объектов params.

## Частые ошибки

- Путать `generateStaticParams` с `generateMetadata`.
- Возвращать неправильные имена params.
- Использовать ее для request-specific страниц.
- Генерировать слишком много страниц без оценки build time.
- Забывать обработку неизвестного slug через `notFound()`.

## Мини-шпаргалка

- Нужна для dynamic SSG.
- Возвращает массив params.
- `[slug]` -> `{ slug: '...' }`.
- Выполняется на сервере.
- Похожа на `getStaticPaths` из Pages Router.
- Хорошо сочетается с ISR.
