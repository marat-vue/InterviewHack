# Как изучать React Router

> [!summary]
> React Router нужно изучать как систему синхронизации UI с URL: routes, links, params, search params, nested routes, layouts, redirects, data loaders, actions и navigation state.

## Что такое React Router?

React Router - библиотека маршрутизации для React. Она позволяет показывать разные экраны приложения в зависимости от URL без полной перезагрузки страницы.

```tsx
import { createBrowserRouter, RouterProvider } from 'react-router'

const router = createBrowserRouter([
  {
    path: '/',
    element: <HomePage />,
  },
  {
    path: '/users/:userId',
    element: <UserPage />,
  },
])

createRoot(document.getElementById('root')!).render(
  <RouterProvider router={router} />,
)
```

## Что нужно знать по порядку?

1. Что такое route.
2. `BrowserRouter` и `createBrowserRouter`.
3. `Link` и `NavLink`.
4. Dynamic params: `/users/:userId`.
5. Query params через `useSearchParams`.
6. Programmatic navigation через `useNavigate`.
7. Nested routes и `Outlet`.
8. Layout routes.
9. Loaders и actions.
10. Redirects и error boundaries.
11. Protected routes.

## Почему URL важен?

URL - часть состояния приложения.

Хороший URL:

```text
/products?category=books&page=2&sort=price
```

Пользователь может:

- обновить страницу;
- отправить ссылку;
- вернуться назад;
- открыть в новой вкладке;
- попасть на нужное состояние через bookmark.

## Что отвечать на собеседовании?

React Router синхронизирует React UI с URL. Он дает declarative navigation через `Link`, programmatic navigation через `useNavigate`, dynamic params через `useParams`, query params через `useSearchParams`, вложенную маршрутизацию через `Outlet` и data APIs через loaders/actions.

## Мини-шпаргалка

- `Route` описывает соответствие URL и UI.
- `Link` меняет URL без перезагрузки.
- `useParams` читает path params.
- `useSearchParams` читает query string.
- `Outlet` рендерит дочерний route.
- Loaders загружают данные до render route.
