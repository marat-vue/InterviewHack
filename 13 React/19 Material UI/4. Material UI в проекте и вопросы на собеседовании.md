# Material UI в проекте и вопросы на собеседовании

> [!summary]
> В production MUI важно использовать через тему, единые wrapper-компоненты и понятные правила кастомизации. Главные риски - хаотичный `sx`, тяжелые overrides, конфликт с другими styling-подходами и непонимание controlled-компонентов.

## Как организовать MUI в проекте?

Пример:

```text
src/
  app/
    theme.ts
  shared/
    ui/
      AppButton.tsx
      AppTextField.tsx
      AppDialog.tsx
```

`theme.ts`:

```tsx
export const theme = createTheme({
  palette: {
    primary: { main: '#2563eb' },
  },
  components: {
    MuiButton: {
      defaultProps: { disableElevation: true },
    },
  },
})
```

## Wrapper-компоненты

Если в проекте есть свой стандарт кнопки, лучше сделать wrapper:

```tsx
type AppButtonProps = React.ComponentProps<typeof Button>

export function AppButton(props: AppButtonProps) {
  return <Button variant="contained" disableElevation {...props} />
}
```

Так проще менять дизайн централизованно.

## MUI и Tailwind

MUI и Tailwind можно смешивать, но нужны правила:

- MUI для сложных компонентов;
- Tailwind для custom layout;
- не стилизовать один и тот же элемент двумя системами хаотично;
- theme MUI и design tokens Tailwind должны не конфликтовать.

## Частые вопросы

### Что такое sx?

`sx` - prop для стилизации MUI-компонентов с доступом к theme values.

### Чем `sx` отличается от `style`?

`style` - inline styles без theme, pseudo selectors и responsive system. `sx` понимает theme, breakpoints и nested selectors.

### Как глобально изменить Button?

Через `createTheme({ components: { MuiButton: { defaultProps, styleOverrides } } })`.

### Когда использовать MUI X?

Для продвинутых компонентов: Data Grid, Date Pickers, Charts, Tree View. Часть возможностей может быть платной.

## Частые ошибки

- Писать огромный `sx` на каждом компоненте.
- Не использовать theme и копировать цвета руками.
- Смешивать MUI/Tailwind без правил.
- Игнорировать bundle size.
- Делать uncontrolled/controlled forms случайно.
- Ломать accessibility при кастомизации.

## Что отвечать на собеседовании?

В production MUI используют как UI platform: theme задает общие tokens, wrapper-компоненты фиксируют продуктовые варианты, `sx` решает локальные кейсы, а overrides применяют для глобального поведения. Важно понимать controlled props и не превращать `sx` в хаотичный CSS.

## Мини-шпаргалка

- Theme - центр design tokens.
- Wrapper components - продуктовые variants.
- `sx` - локальные стили.
- `components` overrides - глобальная настройка.
- MUI X - сложные data components.
- Accessibility нельзя ломать кастомизацией.
