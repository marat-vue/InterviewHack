# Как работает SELECT?

> [!NOTE]
> `SELECT` читает данные из одной или нескольких таблиц и возвращает результирующий набор строк. В запросе можно выбирать столбцы, вычислять выражения, фильтровать, сортировать и ограничивать результат.

## Минимальный запрос

```sql
SELECT id, email
FROM users;
```

`SELECT` задает, какие выражения вывести, а `FROM` - откуда брать строки.

## SELECT с выражением

```sql
SELECT
  id,
  first_name || ' ' || last_name AS full_name
FROM users;
```

`AS` задает alias для результата.

## Порядок логической обработки

Упрощенно SQL-запрос обрабатывается не в том порядке, в котором написан.

```txt
FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY -> LIMIT
```

Это объясняет, почему alias из `SELECT` не всегда доступен в `WHERE`.

## SELECT *

```sql
SELECT *
FROM users;
```

`*` удобно для быстрых проверок, но в production-коде лучше явно перечислять столбцы: так меньше лишних данных и меньше случайных поломок при изменении схемы.

## Мини-шпаргалка

- `SELECT` возвращает результирующий набор.
- `FROM` задает источник данных.
- `AS` задает alias.
- Логический порядок отличается от порядка записи.
- В приложениях лучше избегать `SELECT *`.
