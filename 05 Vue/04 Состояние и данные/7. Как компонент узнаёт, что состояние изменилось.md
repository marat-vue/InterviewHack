# Как компонент узнает, что состояние изменилось

> [!summary] Коротко
> Компонент узнает об изменении состояния через систему реактивности Vue: при рендере Vue собирает зависимости, а при изменении этих данных планирует обновление компонента.

## Вопрос

Как компонент узнает, что состояние изменилось?

## Сбор зависимостей

Когда компонент рендерится, он читает реактивные значения.

```vue
<template>
  <p>{{ user.name }}</p>
</template>
```

Vue запоминает: render этого компонента зависит от `user.name`.

## Уведомление об изменении

Когда значение меняется, Vue запускает связанные эффекты.

```typescript
user.name = "Мария";
```

После этого компонент будет перерендерен.

## Упрощенная схема

```text
render reads state -> Vue tracks dependency -> state changes -> Vue triggers update
```

## Обновление планируется

Vue группирует изменения и обновляет DOM асинхронно, чтобы не делать лишнюю работу.

```typescript
import { nextTick } from "vue";

state.count++;
await nextTick();
```

После `nextTick` DOM уже отражает изменения.

## Мини-шпаргалка

- Компонент читает state во время рендера.
- Vue запоминает прочитанные зависимости.
- Изменение зависимости запускает обновление.
- DOM обновляется после batched flush.
