# Что такое DTO?

> [!summary]
> DTO, Data Transfer Object, - объект, который описывает форму данных между клиентом и сервером. В NestJS DTO обычно делают TypeScript-классами, чтобы использовать validation decorators и Swagger metadata.

## Пример DTO

```ts
export class CreateUserDto {
  @IsEmail()
  email: string;

  @IsString()
  @MinLength(2)
  name: string;
}
```

Controller:

```ts
@Post()
create(@Body() dto: CreateUserDto) {
  return this.usersService.create(dto);
}
```

## Почему класс, а не interface?

TypeScript interfaces исчезают в runtime. ValidationPipe и decorators работают с runtime metadata, поэтому DTO обычно делают class.

## DTO не entity

DTO описывает вход/выход API, а entity описывает модель хранения или доменную сущность. Их не стоит смешивать бездумно.

## Мини-шпаргалка

- DTO описывает контракт передачи данных.
- В NestJS DTO чаще class.
- DTO работает с validation decorators.
- Interface не подходит для runtime validation.
- DTO и database entity - разные ответственности.
