# Как добавить Schema.org structured data?

> [!summary]
> Schema.org structured data помогает поисковикам понимать сущности страницы: статью, товар, организацию, хлебные крошки, FAQ. В Nuxt это можно делать через Nuxt Schema.org из Nuxt SEO stack.

## Что такое structured data?

Structured data - машинно-читаемое описание страницы.

Например, страница товара может сообщить:

- product name;
- image;
- price;
- availability;
- brand;
- reviews.

Это не гарантирует rich results, но помогает поисковикам лучше понять контент.

## Через Nuxt SEO

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/seo'],
  site: {
    url: 'https://example.com',
    name: 'Example Store',
  },
});
```

## Пример useSchemaOrg

```ts
useSchemaOrg([
  defineWebPage({
    name: 'Каталог товаров',
  }),
  defineOrganization({
    name: 'Example Store',
    logo: '/logo.png',
  }),
]);
```

## Какие nodes часто нужны?

- WebSite;
- WebPage;
- Organization;
- Article;
- Product;
- BreadcrumbList;
- FAQPage;
- Person;

## Ошибки

Плохо:

- structured data не соответствует видимому контенту;
- цена в schema отличается от цены на странице;
- FAQ schema есть, а FAQ на странице нет;
- нет `site.url`;
- дублируются conflicting nodes.

## Мини-шпаргалка

- Schema.org помогает поисковикам понимать страницу.
- Structured data должны соответствовать видимому контенту.
- Nuxt SEO включает Schema.org module.
- Для сайта нужны WebSite/WebPage/Organization.
- Для ecommerce важны Product/BreadcrumbList.
