# Что делает директива use client?

> [!summary]
> Директива `'use client'` объявляет client boundary. Файл с этой директивой и его клиентский граф импортов попадают в JavaScript bundle браузера, поэтому внутри можно использовать hooks, события и browser APIs.

## Как выглядит?

```tsx
'use client'

import { useState } from 'react'

export function Counter() {
  const [count, setCount] = useState(0)

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

Директива должна быть первой инструкцией файла, до импортов.

## Что меняется?

Без директивы компонент в App Router считается Server Component.

С директивой:

- компонент может использовать `useState`, `useEffect`;
- можно добавлять `onClick`, `onChange`;
- можно читать browser APIs после mount;
- код компонента отправляется в браузер;
- компонент гидратируется.

## Важный эффект на imports

Если файл помечен `'use client'`, его imports становятся частью client graph.

Плохо:

```tsx
'use client'

import { db } from '@/shared/db'
```

Server-only модуль нельзя импортировать в Client Component.

## Где ставить директиву?

Лучше ставить как можно ниже:

```tsx
// page.tsx - Server Component
export default async function Page() {
  const product = await getProduct()

  return (
    <>
      <ProductInfo product={product} />
      <BuyButton productId={product.id} />
    </>
  )
}
```

```tsx
// BuyButton.tsx
'use client'

export function BuyButton({ productId }: { productId: string }) {
  return <button onClick={() => addToCart(productId)}>Buy</button>
}
```

## Что отвечать на собеседовании?

`'use client'` задает границу между Server и Client Components. Она нужна только в файлах, где требуется интерактивность, hooks или browser APIs. Чем выше поставить директиву, тем больше кода попадет в client bundle.

## Частые ошибки

- Ставить `'use client'` во всех файлах.
- Импортировать server-only код в client graph.
- Думать, что children автоматически становятся client code.
- Передавать функции как props из Server Component.
- Забывать, что директива влияет на bundle size.

## Мини-шпаргалка

- Пишется в начале файла.
- Нужна для hooks/events/browser APIs.
- Создает client boundary.
- Увеличивает client bundle.
- Держи boundary ниже.
- Server-only imports запрещены.
