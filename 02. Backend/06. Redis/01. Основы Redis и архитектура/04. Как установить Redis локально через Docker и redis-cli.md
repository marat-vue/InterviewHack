# Как установить Redis локально через Docker и redis-cli?

> [!NOTE]
> Для подготовки и локальной разработки удобнее всего запускать Redis в Docker. Так можно быстро поднять чистый instance, подключиться через `redis-cli`, проверить команды и не загрязнять систему.

## Как запустить Redis в Docker?

```bash
docker run --name interviewhack-redis -p 6379:6379 -d redis:latest
```

Проверить:

```bash
docker ps
```

Подключиться:

```bash
docker exec -it interviewhack-redis redis-cli
```

Проверить связь:

```redis
PING
```

Ответ:

```txt
PONG
```

## Как запустить Redis с persistence volume?

```bash
docker volume create redis-data

docker run --name interviewhack-redis \
  -p 6379:6379 \
  -v redis-data:/data \
  -d redis:latest \
  redis-server --appendonly yes
```

`--appendonly yes` включает AOF. Для учебного проекта это полезно, чтобы увидеть, что данные переживают restart.

## Как подключиться с паролем?

```bash
docker run --name interviewhack-redis-secure \
  -p 6379:6379 \
  -d redis:latest \
  redis-server --requirepass local_password
```

CLI:

```bash
docker exec -it interviewhack-redis-secure redis-cli -a local_password
```

Команда `-a` удобна локально, но в shared terminal может попасть в shell history. В production используй secrets и защищенную сеть.

## Как проверить Redis через redis-cli?

```redis
SET hello world
GET hello
DEL hello
EXISTS hello
```

С TTL:

```redis
SET token:1 abc EX 60
TTL token:1
GET token:1
```

## Как подключиться из Node.js?

```bash
npm install redis
```

```ts
import { createClient } from 'redis';

const client = createClient({
  url: 'redis://localhost:6379',
});

client.on('error', (error) => {
  console.error('Redis error', error);
});

await client.connect();

await client.set('hello', 'world');
console.log(await client.get('hello'));

await client.quit();
```

## Как остановить и удалить контейнер?

```bash
docker stop interviewhack-redis
docker rm interviewhack-redis
```

Если был volume:

```bash
docker volume rm redis-data
```

Удаляй volume только если данные точно не нужны.

## Мини-шпаргалка

- Локально проще всего запускать Redis через Docker.
- `redis-cli` нужен для ручной диагностики.
- `PING` проверяет связь.
- `SET`/`GET` проверяют запись и чтение.
- Для persistence используй volume и AOF/RDB config.
- Для Node.js начинай с пакета `redis`.
