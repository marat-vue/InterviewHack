# `Function.prototype.apply`

> [!summary] Коротко
> `apply()` сразу вызывает функцию и явно задает `this`, а аргументы передает массивом или массивоподобным объектом.

## Вопрос

Что делает `Function.prototype.apply`?

## Синтаксис

```javascript
fn.apply(thisArg, argsArray);
```

Пример:

```javascript
function introduce(role, city) {
  return `${this.name}, ${role}, ${city}`;
}

const user = { name: "Anna" };

introduce.apply(user, ["developer", "Moscow"]);
// "Anna, developer, Moscow"
```

## Отличие от `call`

```javascript
fn.call(obj, arg1, arg2);
fn.apply(obj, [arg1, arg2]);
```

`call` принимает аргументы списком, `apply` - массивом.

## Частый старый пример

До spread часто писали:

```javascript
const numbers = [5, 10, 2];

Math.max.apply(null, numbers); // 10
```

Сейчас чаще пишут:

```javascript
Math.max(...numbers); // 10
```

## С `arguments`

`apply` умеет принимать массивоподобные объекты.

```javascript
function max() {
  return Math.max.apply(null, arguments);
}

max(1, 5, 3); // 5
```

В современном коде проще rest:

```javascript
function max(...numbers) {
  return Math.max(...numbers);
}
```

## Мини-шпаргалка

| Метод | Аргументы | Вызывает сразу |
| --- | --- | --- |
| `call` | списком | да |
| `apply` | массивом/array-like | да |
| `bind` | списком для предустановки | нет |
