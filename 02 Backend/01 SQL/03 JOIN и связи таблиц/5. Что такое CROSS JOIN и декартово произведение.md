# Что такое CROSS JOIN и декартово произведение?

> [!summary]
> `CROSS JOIN` соединяет каждую строку одной таблицы с каждой строкой другой таблицы. Результат называется декартовым произведением и может очень быстро стать огромным.

## Пример

```sql
SELECT c.color, s.size
FROM colors c
CROSS JOIN sizes s;
```

Если есть 3 цвета и 4 размера, результат будет 12 строк.

## Когда это полезно?

`CROSS JOIN` полезен, когда нужно создать все комбинации:

- размер x цвет;
- дата x магазин;
- пользователь x эксперимент;
- календарная сетка;
- тестовые данные.

## Опасность

```sql
SELECT *
FROM users, orders;
```

Старый синтаксис через запятую без `WHERE` тоже создает декартово произведение. Если в `users` миллион строк и в `orders` миллион строк, результат теоретически будет огромным.

## Мини-шпаргалка

- `CROSS JOIN` создает все комбинации строк.
- Количество строк = `A * B`.
- Иногда нужен для генерации сеток и комбинаций.
- Случайный cross join - частая ошибка.
- Всегда проверяй условия соединения.
