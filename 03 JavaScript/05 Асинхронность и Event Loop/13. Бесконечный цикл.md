# Бесконечный цикл

> [!summary] Коротко
> Бесконечный синхронный цикл не освобождает Call Stack, поэтому Event Loop не может выполнить таймеры, промисы, события и рендер.

## Вопрос

Что произойдет, если в функции есть бесконечный цикл?

## Определение

Бесконечный цикл - это цикл, условие которого никогда не становится ложным. Если такой цикл выполняется в основном потоке, JavaScript не может перейти к следующим задачам.

В браузере это обычно приводит к зависанию вкладки. В Node.js процесс перестает нормально обслуживать другие задачи.

## Пример

```javascript
setTimeout(() => {
  console.log('timer');
}, 0);

while (true) {
  // бесконечная синхронная работа
}
```

`timer` не выведется, потому что стек вызовов никогда не станет пустым.

## Что именно блокируется

- callbacks таймеров;
- обработчики событий;
- выполнение промисовых микротасок;
- рендер страницы;
- взаимодействие пользователя с интерфейсом.

## Как избежать проблемы

Если работы очень много, ее можно дробить на части.

```javascript
let index = 0;

function processChunk() {
  const end = Math.min(index + 1000, items.length);

  while (index < end) {
    process(items[index]);
    index++;
  }

  if (index < items.length) {
    setTimeout(processChunk, 0);
  }
}

processChunk();
```

Так основной поток получает паузы между частями работы.

## Мини-шпаргалка

```javascript
while (true) {} // блокирует Event Loop

setTimeout(nextChunk, 0); // дает Event Loop шанс продолжить
```
