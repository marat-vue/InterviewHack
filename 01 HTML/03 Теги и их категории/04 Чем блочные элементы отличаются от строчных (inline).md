# Чем блочные элементы отличаются от строчных (inline)

> [!summary]
> Блочные элементы обычно занимают всю доступную ширину и начинаются с новой строки, а строчные элементы располагаются внутри строки и занимают ширину своего содержимого.

## Главное

Исторически элементы часто делили на block и inline. Сейчас в CSS точнее говорить о значении свойства `display`, но базовое различие все еще полезно.

```html
<p>Абзац занимает отдельную строку.</p>
<span>А span</span> <span>может идти рядом.</span>
```

## Блочные элементы

Блочный элемент ведет себя как отдельный прямоугольный блок.

```html
<div>Контейнер</div>
<p>Абзац</p>
<section>Раздел</section>
```

Обычно он:

- начинается с новой строки;
- занимает всю доступную ширину;
- может содержать другие блочные и строчные элементы;
- хорошо подходит для layout-структуры.

## Строчные элементы

Строчный элемент живет внутри текстового потока.

```html
<p>
  Это <strong>важный</strong> фрагмент текста.
</p>
```

Обычно он:

- не начинает новую строку;
- занимает ширину содержимого;
- используется внутри текста;
- не предназначен для крупных layout-блоков.

## CSS может изменить поведение

HTML-семантика и CSS-отображение - разные вещи.

```css
a {
  display: block;
}
```

Ссылка остается ссылкой по смыслу, но визуально может вести себя как блок.

## Inline-block

`inline-block` сочетает поведение строки и блока.

```css
.badge {
  display: inline-block;
  padding: 4px 8px;
}
```

Элемент остается в строке, но может иметь размеры и отступы как блок.

## Мини-шпаргалка

- Block обычно занимает строку целиком.
- Inline находится внутри текстового потока.
- CSS-свойство `display` может изменить визуальное поведение.
- Семантику тега не выбирают по дефолтному display.
- Для layout обычно используют блочные контейнеры.
