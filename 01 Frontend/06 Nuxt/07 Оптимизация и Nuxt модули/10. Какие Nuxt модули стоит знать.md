# Какие Nuxt модули стоит знать?

> [!summary]
> Для работы и собеседований полезно знать не только core Nuxt, но и популярные production-модули: Image, Icon, Fonts, Scripts, SEO, Sitemap, Robots, Schema.org, OG Image, DevTools, Security, Content, UI, i18n.

## Core production modules

| Модуль | Зачем |
|---|---|
| `@nuxt/image` | оптимизация изображений |
| `@nuxt/icon` | иконки через Iconify |
| `@nuxt/fonts` | оптимизация шрифтов |
| `@nuxt/scripts` | third-party scripts |
| `@nuxtjs/seo` | SEO stack |
| `@nuxtjs/sitemap` | sitemap.xml |
| Nuxt Robots | robots.txt |
| Nuxt Schema.org | structured data |
| Nuxt OG Image | social images |

## DX и качество

| Модуль | Зачем |
|---|---|
| Nuxt DevTools | анализ приложения |
| Nuxt Security | security headers |
| Nuxt Test Utils | тестирование Nuxt |

## Product modules

| Модуль | Когда нужен |
|---|---|
| Nuxt Content | docs/blog/content |
| Nuxt UI | UI system |
| Nuxt i18n | мультиязычность |
| Pinia Nuxt | сложное состояние |
| Tailwind/Vuetify modules | UI styling |

## Как отвечать на собеседовании?

Хороший ответ не просто перечисляет modules, а объясняет:

- какую проблему закрывает module;
- влияет ли он на SSR;
- влияет ли он на bundle;
- нужен ли он на server/client;
- как его проверить в production.

## Мини-шпаргалка

- Image, Fonts, Scripts - performance.
- SEO, Sitemap, Robots, Schema.org, OG Image - technical SEO.
- Icon - удобные иконки без ручных SVG bundles.
- DevTools - DX и анализ.
- Security - headers/middleware, но не замена secure architecture.
