# Что такое diffing algorithm?

> [!summary]
> Diffing algorithm - это часть reconciliation: React сравнивает старое и новое дерево элементов и определяет, какие изменения нужно применить. На практике важны тип элемента, позиция и `key` в списках.

## Простая схема

```text
old tree
new tree
diff
DOM operations
```

React не сравнивает все возможные варианты идеально, потому что это было бы слишком дорого. Он использует эвристики, которые хорошо работают для UI.

## Правило типа элемента

Если тип изменился:

```jsx
{isHeading ? <h1>React</h1> : <p>React</p>}
```

React считает, что это другой элемент, и заменяет узел.

Если тип тот же:

```jsx
<button disabled={isDisabled}>Сохранить</button>
```

React обновляет props/attributes.

## Компоненты

```jsx
{isAdmin ? <AdminPanel /> : <UserPanel />}
```

`AdminPanel` и `UserPanel` - разные component types. При переключении старый компонент размонтируется, новый монтируется.

## Списки и key

```jsx
{users.map((user) => (
  <UserRow key={user.id} user={user} />
))}
```

`key` помогает diffing algorithm сопоставить старые и новые элементы списка.

Без нормальных keys React может ошибочно переиспользовать состояние элементов по позиции.

## Мини-шпаргалка

- Diffing сравнивает старое и новое дерево.
- Разный тип элемента обычно означает замену.
- Одинаковый тип позволяет обновить props.
- `key` помогает сравнивать списки.
- Плохие keys дают баги с state и input.
