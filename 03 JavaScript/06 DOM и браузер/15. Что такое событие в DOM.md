# Что такое событие в DOM

> [!summary] Коротко
> Событие в DOM - сигнал браузера о том, что что-то произошло: клик, ввод текста, отправка формы, загрузка страницы.

## Вопрос

Что такое DOM-событие и как JavaScript на него реагирует?

## Определение

Событие - объект, который описывает произошедшее действие в браузере. Например, пользователь нажал кнопку, ввел символ, прокрутил страницу или отправил форму.

JavaScript может подписаться на событие с помощью обработчика и выполнить код в нужный момент.

## Пример

```javascript
const button = document.querySelector('button');

button.addEventListener('click', (event) => {
  console.log('Button clicked');
  console.log(event.type); // 'click'
});
```

`event` содержит информацию о событии: тип, цель, координаты, клавиши и другие данные.

## Популярные события

| Событие | Когда возникает |
| --- | --- |
| `click` | клик мышью или активация кнопки |
| `input` | изменение значения поля |
| `submit` | отправка формы |
| `keydown` | нажатие клавиши |
| `scroll` | прокрутка |
| `load` | загрузка ресурса |

## Объект события

```javascript
document.addEventListener('click', (event) => {
  console.log(event.target);
  console.log(event.currentTarget);
  console.log(event.defaultPrevented);
});
```

Объект события передается в обработчик автоматически.

## Мини-шпаргалка

```javascript
element.addEventListener('eventName', (event) => {
  // reaction
});
```
