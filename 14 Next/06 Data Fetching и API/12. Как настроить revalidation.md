# Как настроить revalidation?

> [!summary]
> Revalidation в Next.js обновляет кешированные данные или routes. Основные инструменты App Router: `next.revalidate` в `fetch`, `export const revalidate`, `revalidatePath` и `revalidateTag`.

## Revalidate конкретный fetch

```tsx
const posts = await fetch('https://api.example.com/posts', {
  next: { revalidate: 60 },
}).then((res) => res.json())
```

Запрос будет считаться свежим 60 секунд.

## Revalidate route segment

```tsx
export const revalidate = 3600

export default async function BlogPage() {
  const posts = await getPosts()
  return <PostList posts={posts} />
}
```

Route может обновляться по заданному интервалу.

## On-demand revalidate path

```ts
'use server'

import { revalidatePath } from 'next/cache'

export async function createPost(formData: FormData) {
  await db.post.create({
    data: { title: String(formData.get('title')) },
  })

  revalidatePath('/blog')
}
```

## On-demand revalidate tag

Сначала тегируем fetch:

```tsx
await fetch('https://api.example.com/posts', {
  next: { tags: ['posts'] },
})
```

Потом инвалидируем:

```ts
import { revalidateTag } from 'next/cache'

revalidateTag('posts')
```

## Path vs Tag

| Инструмент | Когда использовать |
|---|---|
| `revalidatePath` | обновить конкретный URL/route |
| `revalidateTag` | обновить все данные с тегом |
| `next.revalidate` | обновлять по времени |
| `cache: 'no-store'` | вообще не кешировать |

## Что отвечать на собеседовании?

Revalidation - это обновление кеша. В Next.js можно настроить time-based revalidation через `next.revalidate` или `export const revalidate`, а on-demand revalidation через `revalidatePath` и `revalidateTag`, часто после Server Action.

## Частые ошибки

- Путать `revalidatePath` с `router.refresh`.
- Не добавлять tags к fetch.
- Использовать `no-store`, когда достаточно revalidate.
- Считать, что revalidation мгновенно обновит уже открытую вкладку.
- Не инвалидировать кеш после mutation.

## Мини-шпаргалка

- `next: { revalidate: 60 }`.
- `export const revalidate = 3600`.
- `revalidatePath('/blog')`.
- `revalidateTag('posts')`.
- Tags нужно назначить заранее.
- `no-store` отключает кеш.
