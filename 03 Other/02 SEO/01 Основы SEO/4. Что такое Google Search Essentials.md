# Что такое Google Search Essentials?

> [!summary]
> Google Search Essentials - базовые требования, spam policies и best practices для появления в Google Search. Они описывают технический минимум, запрещенные манипуляции и принципы создания полезного сайта.

## Из чего состоят Search Essentials?

Упрощенно:

1. **Technical requirements** - Google должен иметь возможность получить и обработать страницу.
2. **Spam policies** - сайт не должен использовать манипулятивные практики.
3. **Best practices** - рекомендации по полезному контенту и хорошему пользовательскому опыту.

## Technical requirements

Минимум:

- Googlebot не заблокирован;
- страница возвращает успешный HTTP status;
- контент доступен Google;
- страница не закрыта от indexing, если она должна быть в поиске.

## Spam policies

Нельзя строить SEO на:

- cloaking;
- doorway pages;
- hacked content;
- hidden text;
- keyword stuffing;
- link spam;
- scaled content abuse;
- scraped content;
- site reputation abuse.

## Best practices

Google рекомендует:

- создавать helpful content;
- делать страницы для людей;
- использовать понятные titles и links;
- помогать поисковику находить страницы;
- делать сайт удобным и доступным.

## Почему это важно?

Если сайт нарушает spam policies, он может потерять видимость или быть исключен из результатов.

Если сайт не выполняет technical requirements, его страницы могут вообще не попасть в индекс.

## Мини-шпаргалка

- Search Essentials - база для работы с Google Search.
- Technical requirements отвечают за доступность.
- Spam policies запрещают манипуляции.
- Best practices направлены на пользователей.
- SEO-стратегия не должна нарушать Search Essentials.
