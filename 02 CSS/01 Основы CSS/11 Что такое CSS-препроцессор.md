# Что такое CSS-препроцессор?

> [!NOTE]
> **CSS-препроцессор** - это инструмент, который расширяет CSS дополнительным синтаксисом и компилирует его в обычный CSS, понятный браузеру.

## Главное

Браузер не исполняет Sass или Less напрямую. Сначала код проходит сборку.

```text
SCSS / Less / Stylus
  -> preprocessor
  -> CSS
  -> browser
```

## Пример SCSS

```scss
$primary: #2563eb;

.button {
  background: $primary;

  &:hover {
    background: darken($primary, 8%);
  }
}
```

После компиляции получится обычный CSS.

## Что дают препроцессоры

- Переменные.
- Вложенность.
- Миксины.
- Функции.
- Разделение файлов.
- Удобные операции с цветами и размерами.

## Что изменилось с современным CSS

Многие возможности, ради которых раньше брали препроцессор, появились в CSS: custom properties, nesting, `color-mix()`, cascade layers. Поэтому препроцессор уже не всегда обязателен.

## Когда полезен

- В проекте уже есть SCSS-архитектура.
- Нужны миксины и функции.
- Есть большая legacy-стилевая база.
- Команда привыкла к препроцессорным инструментам.

## Мини-шпаргалка

- Препроцессор расширяет CSS и компилируется в CSS.
- Популярный пример - Sass/SCSS.
- Браузер понимает только итоговый CSS.
- Препроцессоры дают переменные, миксины, функции, вложенность.
- Современный CSS частично закрывает эти задачи без препроцессора.
