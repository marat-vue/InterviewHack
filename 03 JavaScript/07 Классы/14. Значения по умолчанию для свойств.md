# Значения по умолчанию для свойств

> [!summary] Коротко
> Значения по умолчанию в классе можно задавать в конструкторе, через параметры по умолчанию или через поля класса.

## Вопрос

Как задать значения свойств по умолчанию в классе?

## Вариант 1: в constructor

```javascript
class User {
  constructor(name) {
    this.name = name || 'Guest';
  }
}
```

Минус такого варианта: `||` заменит не только `undefined`, но и пустую строку.

## Вариант 2: параметры по умолчанию

```javascript
class User {
  constructor(name = 'Guest', role = 'reader') {
    this.name = name;
    this.role = role;
  }
}

const user = new User();

console.log(user.name); // 'Guest'
```

Параметры по умолчанию срабатывают, когда аргумент равен `undefined`.

## Вариант 3: nullish coalescing

```javascript
class User {
  constructor(name) {
    this.name = name ?? 'Guest';
  }
}
```

`??` подставляет значение по умолчанию только для `null` и `undefined`.

## Вариант 4: поля класса

```javascript
class Counter {
  value = 0;
  step = 1;
}

const counter = new Counter();

console.log(counter.value); // 0
```

Поля класса удобны для простых начальных значений.

## Мини-шпаргалка

```javascript
constructor(name = 'Guest') {
  this.name = name;
}

class A {
  count = 0;
}
```
