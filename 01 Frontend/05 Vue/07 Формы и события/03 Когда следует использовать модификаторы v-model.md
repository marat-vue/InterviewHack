# Когда следует использовать модификаторы v-model?

> [!NOTE]
> Модификаторы `v-model` используют, когда нужно изменить стандартную обработку ввода: обновлять позже, обрезать пробелы или приводить значение к числу.

## Вопрос

Когда следует использовать модификаторы `v-model`?

## .lazy

Используй `.lazy`, если не нужно обновлять state на каждый ввод символа.

```vue
<input v-model.lazy="email" />
```

Значение обновится на `change`, а не на каждый `input`.

## .trim

Используй `.trim` для текстовых полей, где пробелы по краям обычно не важны.

```vue
<input v-model.trim="username" />
```

Это полезно для логина, email, имени пользователя.

## .number

Используй `.number`, когда ожидаешь число из input.

```vue
<input v-model.number="age" type="number" />
```

Без модификатора значение input часто приходит строкой.

## Комбинации

```vue
<input v-model.lazy.trim="title" />
```

Комбинируй модификаторы, когда это отражает правила конкретного поля.

## Когда не использовать

Если нужна сложная нормализация, лучше сделать явный обработчик или computed setter, чтобы логика была прозрачнее.

## Мини-шпаргалка

- `.lazy` - обновлять по `change`.
- `.trim` - убрать пробелы по краям.
- `.number` - привести к числу.
- Простые правила можно писать модификаторами.
- Сложную обработку лучше вынести в код.
