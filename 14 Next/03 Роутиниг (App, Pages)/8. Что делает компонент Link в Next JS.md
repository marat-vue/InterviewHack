# Что делает компонент Link в Next JS?

> [!summary]
> `Link` из `next/link` нужен для внутренней навигации без полной перезагрузки страницы. Он расширяет обычный `<a>`, поддерживает client-side navigation и может prefetch целевой route.

## Базовый пример

```tsx
import Link from 'next/link'

export function Header() {
  return (
    <nav>
      <Link href="/">Главная</Link>
      <Link href="/blog">Блог</Link>
    </nav>
  )
}
```

Для внутренних переходов `Link` лучше обычного `<a>`.

## Link vs a

| Вариант | Что происходит |
|---|---|
| `<Link href="/about">` | client-side navigation |
| `<a href="/about">` | браузер может полностью перезагрузить документ |

Для внешних ссылок обычный `<a>` нормален:

```tsx
<a href="https://nextjs.org" target="_blank" rel="noreferrer">
  Next.js
</a>
```

## Dynamic href

```tsx
<Link href={`/blog/${post.slug}`}>
  {post.title}
</Link>
```

Можно передавать объект:

```tsx
<Link
  href={{
    pathname: '/products',
    query: { page: '2' },
  }}
>
  Products
</Link>
```

## replace и scroll

```tsx
<Link href="/login" replace>
  Login
</Link>
```

`replace` заменяет текущую запись history.

```tsx
<Link href="/products" scroll={false}>
  Keep scroll
</Link>
```

`scroll={false}` отключает автоматический scroll behavior.

## Что отвечать на собеседовании?

`Link` - компонент Next.js для внутренних переходов. Он делает client-side navigation, интегрируется с App Router, поддерживает prefetch, `replace`, `scroll` и позволяет переходить по динамическим href. Для внешних ссылок можно использовать обычный `<a>`.

## Частые ошибки

- Использовать `<a>` для внутренних переходов.
- Использовать `router.push` там, где достаточно `Link`.
- Ставить `prefetch={false}` без причины.
- Забывать доступный текст ссылки.
- Делать ссылку кнопкой для действия, которое не является навигацией.

## Мини-шпаргалка

- Импорт: `next/link`.
- `href` обязателен.
- Internal navigation: `Link`.
- External link: обычный `<a>`.
- `replace` не добавляет history entry.
- `scroll={false}` сохраняет scroll.
