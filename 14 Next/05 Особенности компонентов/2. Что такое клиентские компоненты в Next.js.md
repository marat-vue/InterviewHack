# Что такое клиентские компоненты в Next.js?

> [!summary]
> Клиентские компоненты в Next.js - компоненты, чей JavaScript отправляется в браузер и гидратируется. Они нужны для интерактивности: state, effects, event handlers, browser APIs, формы, модалки, dropdown, animation и client-only библиотеки.

## Как обозначить Client Component?

```tsx
'use client'

import { useState } from 'react'

export function Counter() {
  const [count, setCount] = useState(0)

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

Директива должна быть в начале файла.

## Что умеют Client Components?

Можно использовать:

- `useState`;
- `useEffect`;
- `useReducer`;
- `useRef`;
- event handlers;
- browser APIs;
- Zustand;
- Motion;
- MUI interactive components;
- любые client-side libraries.

## Граница client boundary

Если файл помечен `'use client'`, все его imports становятся частью client graph, если они используются этим компонентом.

Поэтому лучше:

```tsx
// хорошо: маленький client island
<ServerProductInfo />
<AddToCartButton />
```

чем:

```tsx
// хуже: вся страница client-side
'use client'
export default function ProductPage() { ... }
```

## Props из Server Component

Server Component может передать данные:

```tsx
<AddToCartButton productId={product.id} initialCount={product.likes} />
```

Props должны быть сериализуемыми. Нельзя передавать обычные функции, class instances, connection objects.

## Что отвечать на собеседовании?

Client Component в Next.js - компонент, который выполняется в браузере и нужен для интерактивности. Он задается директивой `'use client'`. Чем выше поставить эту директиву, тем больше кода попадет в client bundle, поэтому client boundary держат как можно ниже.

## Частые ошибки

- Помечать весь `layout.tsx` как client ради одного dropdown.
- Передавать несериализуемые props.
- Импортировать server-only модуль в Client Component.
- Загружать SEO-контент только внутри Client Component.
- Думать, что Client Component не может быть предварительно отрендерен в HTML.

## Мини-шпаргалка

- `'use client'` в начале файла.
- Нужен для hooks и events.
- Код отправляется в браузер.
- Boundary держи ниже.
- Props должны быть сериализуемыми.
- Для data fetching по возможности используй Server Components.
