# Что такое SQL?

> [!summary]
> SQL, Structured Query Language, - декларативный язык для работы с реляционными базами данных. Через SQL описывают, какие данные нужны, какие таблицы изменить и какие правила должна соблюдать схема.

## Главное определение

SQL отвечает не на вопрос "как пройти по массиву", а на вопрос "какой результат нужен".

```sql
SELECT name, email
FROM users
WHERE is_active = true
ORDER BY created_at DESC;
```

В этом запросе мы не описываем алгоритм обхода строк. Мы описываем набор данных, который хотим получить.

## Основные группы команд

| Группа | Для чего | Примеры |
|---|---|---|
| DQL | запрос данных | `SELECT` |
| DML | изменение данных | `INSERT`, `UPDATE`, `DELETE` |
| DDL | изменение схемы | `CREATE`, `ALTER`, `DROP` |
| TCL | транзакции | `BEGIN`, `COMMIT`, `ROLLBACK` |
| DCL | доступы | `GRANT`, `REVOKE` |

## SQL и диалекты

Есть общий стандарт SQL, но реальные СУБД имеют диалекты: PostgreSQL, MySQL, SQLite, SQL Server, Oracle. База языка общая, но функции, типы, JSON, индексы и синтаксис могут отличаться.

## Мини-шпаргалка

- SQL - язык работы с реляционными данными.
- Он декларативный: описываешь результат, а не алгоритм.
- `SELECT` читает данные.
- `INSERT`, `UPDATE`, `DELETE` изменяют данные.
- Разные СУБД имеют диалектные отличия.
