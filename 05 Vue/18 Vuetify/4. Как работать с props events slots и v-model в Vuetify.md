# Как работать с props, events, slots и v-model в Vuetify?

> [!summary]
> Vuetify-компоненты остаются Vue-компонентами: props настраивают внешний вид и поведение, events сообщают о действиях, slots дают кастомизацию, а `v-model` связывает состояние с компонентом.

## Props

```vue
<v-btn
  color="primary"
  variant="flat"
  :loading="isSaving"
  :disabled="isSaving"
>
  Сохранить
</v-btn>
```

Props управляют компонентом. Для Vuetify особенно часто встречаются:

- `color`;
- `variant`;
- `density`;
- `disabled`;
- `loading`;
- `items`;
- `rules`;
- `label`.

## Events

```vue
<v-btn @click="save">
  Сохранить
</v-btn>
```

У сложных компонентов могут быть events обновления:

```vue
<v-select
  :model-value="role"
  @update:model-value="role = $event"
/>
```

## v-model

```vue
<v-dialog v-model="isDialogOpen">
  ...
</v-dialog>
```

`v-model` часто управляет:

- input value;
- dialog open state;
- selected tab;
- selected table rows;
- navigation drawer open state.

## Slots

```vue
<v-data-table :items="users">
  <template #item.role="{ item }">
    <v-chip :color="item.role === 'admin' ? 'error' : 'primary'">
      {{ item.role }}
    </v-chip>
  </template>
</v-data-table>
```

Slots позволяют заменить часть внутренней разметки компонента, не переписывая весь компонент.

## Мини-шпаргалка

- Props настраивают компонент.
- Events сообщают о действиях.
- `v-model` связывает state и component value.
- Slots кастомизируют внутренние части компонента.
- Сложные Vuetify components почти всегда нужно изучать через props/events/slots таблицы.
