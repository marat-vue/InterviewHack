# Что происходит при монтировании компонента?

> [!summary]
> Монтирование - это первое появление компонента в React-дереве и DOM. React вызывает компонент, получает JSX, создает DOM-узлы, добавляет их на страницу, устанавливает refs и запускает эффекты в нужном порядке.

## Последовательность

```text
1. Trigger initial render
2. React вызывает компонент
3. Компонент возвращает JSX
4. React создает DOM-узлы
5. React commit-ит DOM
6. React устанавливает refs
7. React запускает layout effects
8. Browser paint
9. React запускает passive effects, useEffect
```

## Пример

```jsx
function Profile() {
  useEffect(() => {
    console.log('component mounted')
  }, [])

  return <h1>Профиль</h1>
}
```

Effect с `[]` обычно запускается после первого commit.

## Что нельзя делать во время mount render?

Во время render нельзя:

- делать side effects;
- менять DOM;
- запускать timers;
- отправлять analytics;
- мутировать внешние данные;
- делать непредсказуемые операции.

Render должен быть чистым:

```jsx
function Profile({ user }) {
  return <h1>{user.name}</h1>
}
```

## Strict Mode

В development Strict Mode React может дополнительно вызывать render/effects, чтобы найти ошибки чистоты и cleanup. Это не production-поведение, но код должен быть устойчив к таким проверкам.

## Мини-шпаргалка

- Mount - первое появление компонента.
- React сначала вызывает render, потом commit.
- DOM доступен после commit.
- `useLayoutEffect` запускается до paint.
- `useEffect` запускается после paint.
