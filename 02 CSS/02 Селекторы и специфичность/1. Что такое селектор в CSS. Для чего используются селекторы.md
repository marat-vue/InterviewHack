# Что такое селектор в CSS. Для чего используются селекторы

> [!summary]
> **CSS-селектор** - это часть CSS-правила, которая выбирает HTML-элементы, к которым нужно применить стили.

## Главное

```css
.button {
  background: #2563eb;
  color: white;
}
```

Здесь `.button` - селектор. Он выбирает все элементы с классом `button`.

## Структура правила

```css
selector {
  property: value;
}
```

Селектор отвечает на вопрос: "К каким элементам применить эти объявления?"

## Примеры селекторов

```css
p {
  line-height: 1.5;
}

.card {
  padding: 16px;
}

#app {
  min-height: 100vh;
}

input[required] {
  border-color: #2563eb;
}
```

## Для чего используются селекторы

- Стилизовать элементы по тегу.
- Применять стили по классу.
- Находить элементы с атрибутами.
- Описывать состояния: `:hover`, `:focus-visible`.
- Стилизовать вложенные элементы.
- Создавать псевдоэлементы.

## Хорошая практика

В компонентах обычно удобнее опираться на классы, а не на слишком длинные цепочки тегов.

```css
.product-card__title {
  font-size: 1.25rem;
}
```

Такой селектор проще переиспользовать и переопределять.

## Мини-шпаргалка

- Селектор выбирает элементы.
- После селектора идет блок объявлений.
- Самые частые селекторы: тег, класс, id, атрибут, псевдокласс.
- Слишком сложные селекторы трудно поддерживать.
- Классы часто лучший выбор для UI-компонентов.
