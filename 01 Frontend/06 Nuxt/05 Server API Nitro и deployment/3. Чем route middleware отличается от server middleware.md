# Чем route middleware отличается от server middleware?

> [!summary]
> Route middleware работает на уровне Nuxt navigation между страницами, а server middleware работает на уровне Nitro HTTP request. Это разные механизмы для разных задач.

## Route middleware

Лежит в:

```text
app/middleware/
```

Используется для:

- redirects между страницами;
- auth guards;
- permissions;
- feature flags;
- логики перед navigation.

Пример:

```ts
export default defineNuxtRouteMiddleware(() => {
  const user = useState('user');

  if (!user.value) {
    return navigateTo('/login');
  }
});
```

## Server middleware

Лежит в:

```text
server/middleware/
```

Работает на каждый HTTP request до route handler.

Пример:

```ts
// server/middleware/logger.ts
export default defineEventHandler((event) => {
  console.log(event.method, event.path);
});
```

## Что выбрать?

| Задача | Middleware |
|---|---|
| redirect `/dashboard` -> `/login` | route middleware |
| логировать все HTTP requests | server middleware |
| проверить permission страницы | route middleware |
| добавить server request context | server middleware |
| проверить API token | server middleware или API handler |

## Мини-шпаргалка

- Route middleware - Nuxt page navigation.
- Server middleware - Nitro HTTP request.
- `app/middleware` не равно `server/middleware`.
- Route middleware может использовать `navigateTo`.
- Server middleware работает до API/server routes.
