# Синхронный VS асинхронный код

> [!NOTE]
> Синхронный код выполняется по порядку и блокирует следующий шаг, а асинхронный запускает долгую операцию и получает результат позже.

## Вопрос

Чем синхронный код отличается от асинхронного?

## Синхронный код

Синхронный код выполняется строго сверху вниз. Следующая строка не начнет выполняться, пока текущая не завершится.

```javascript
console.log(1);
console.log(2);
console.log(3);

// 1
// 2
// 3
```

Такой код прост для понимания, но тяжелая операция может заблокировать поток.

## Асинхронный код

Асинхронный код позволяет запустить операцию, результат которой появится позже, и продолжить выполнение программы.

```javascript
console.log(1);

setTimeout(() => {
  console.log(2);
}, 0);

console.log(3);

// 1
// 3
// 2
```

Callback таймера выполнится после завершения текущего синхронного кода.

## Сравнение

| Критерий | Синхронный код | Асинхронный код |
| --- | --- | --- |
| Порядок | строго сверху вниз | результат приходит позже |
| Ожидание | блокирует следующий шаг | не блокирует основной поток |
| Примеры | вычисления, обычные функции | `fetch`, таймеры, события |
| Ошибки | `try...catch` | `.catch()` или `try...catch` с `await` |

## Практический пример с запросом

```javascript
async function loadPosts() {
  const response = await fetch('/api/posts');
  const posts = await response.json();

  return posts;
}
```

`await` делает запись похожей на синхронную, но под капотом это все равно асинхронная работа с промисом.

## Мини-шпаргалка

```javascript
// sync
const result = calculate();

// async
const data = await fetchData();
```
