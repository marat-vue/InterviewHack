# Какие ошибки чаще всего делают в SEO?

> [!summary]
> Частые SEO-ошибки возникают из-за механического подхода: думают только о ключах, забывают об индексации, ломают URL при релизах, игнорируют mobile/performance и не измеряют результат.

## Технические ошибки

- Важные страницы закрыты `noindex`.
- robots.txt блокирует нужные ресурсы.
- Sitemap содержит мусор.
- Canonical ведет на неправильный URL.
- Редизайн поменял URL без redirect map.
- SPA отдает пустой HTML.
- 404 страница возвращает `200`.
- Слишком много redirect chains.

## Контентные ошибки

- Страница не закрывает intent.
- Title одинаковые.
- Description дублируются.
- H1 отсутствует или не отражает тему.
- Текст написан ради ключей.
- Нет примеров и конкретики.
- Старый контент не обновляется.
- Несколько страниц конкурируют за один запрос.

## Promotion-ошибки

- Покупка ссылок без оценки риска.
- Массовые шаблонные публикации.
- Накрутка отзывов.
- Doorway pages.
- Игнорирование бренда и репутации.

## Аналитические ошибки

- Смотреть только позиции.
- Не связывать SEO с конверсиями.
- Не фиксировать даты изменений.
- Делать много правок сразу и не понимать эффект.
- Игнорировать Search Console.

## Мини-шпаргалка

- SEO часто ломается техническими мелочами.
- Meta tags важны, но не равны SEO.
- Плохой intent нельзя исправить ключами.
- Миграции требуют redirect-плана.
- Без аналитики SEO превращается в догадки.
