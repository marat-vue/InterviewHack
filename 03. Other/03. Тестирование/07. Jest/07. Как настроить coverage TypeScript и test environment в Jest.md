# Как настроить coverage, TypeScript и test environment в Jest?

> [!summary]
> В Jest coverage включается через `--coverage` или `collectCoverage`. TypeScript требует Babel, `ts-jest` или отдельного type-checking шага. `testEnvironment` выбирают по задаче: `node` для backend, `jsdom` для DOM.

## Coverage

Запуск:

```bash
npm test -- --coverage
```

Конфиг:

```ts
const config = {
  collectCoverage: true,
  collectCoverageFrom: [
    'src/**/*.{ts,js}',
    '!src/main.ts',
  ],
  coverageReporters: ['text', 'html'],
};
```

## Thresholds

```ts
coverageThreshold: {
  global: {
    branches: 70,
    functions: 80,
    lines: 80,
    statements: 80,
  },
}
```

Пороги полезны, но не должны заставлять писать бессмысленные тесты.

## TypeScript через `ts-jest`

```bash
npm install --save-dev ts-jest typescript
```

```ts
const config = {
  preset: 'ts-jest',
  testEnvironment: 'node',
};
```

## TypeScript через Babel

Babel быстрее транспилирует, но не проверяет типы. Поэтому в CI часто добавляют:

```bash
npm run typecheck
npm test
```

## Test environment

```ts
testEnvironment: 'node';
```

Для backend, services, repositories.

```ts
testEnvironment: 'jsdom';
```

Для DOM, компонентов и browser-like APIs.

## Мини-шпаргалка

- Coverage включается через `--coverage`.
- `collectCoverageFrom` задает файлы для анализа.
- `coverageThreshold` задает минимальные пороги.
- TypeScript можно подключить через Babel или `ts-jest`.
- `node` для backend, `jsdom` для UI.
