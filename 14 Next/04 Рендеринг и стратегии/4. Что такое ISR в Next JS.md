# Что такое ISR в Next JS?

> [!summary]
> ISR в Next.js - стратегия, при которой route или данные остаются статическими, но могут обновляться после build через `revalidate`, `revalidatePath` или `revalidateTag`.

## Зачем нужен ISR?

SSG быстрый, но данные могут устаревать. SSR свежий, но дороже. ISR дает компромисс:

```text
static speed + periodic/on-demand update
```

## Time-based revalidation

```tsx
export const revalidate = 3600

export default async function BlogPage() {
  const posts = await getPosts()

  return <PostList posts={posts} />
}
```

Route может обновляться не чаще, чем раз в час.

## fetch revalidation

```tsx
const products = await fetch('https://api.example.com/products', {
  next: { revalidate: 600 },
}).then((res) => res.json())
```

Здесь конкретный fetch кешируется и обновляется по времени.

## On-demand revalidation

```ts
'use server'

import { revalidatePath } from 'next/cache'

export async function updatePost(formData: FormData) {
  await savePost(formData)
  revalidatePath('/blog')
}
```

Через tags:

```tsx
await fetch('https://api.example.com/posts', {
  next: { tags: ['posts'] },
})
```

```ts
revalidateTag('posts')
```

## Когда использовать ISR?

- блог с CMS;
- каталог товаров;
- новости;
- документация;
- публичные профили;
- landing pages, обновляемые редакторами.

## Что отвечать на собеседовании?

ISR позволяет статически отдавать страницу, но обновлять ее после build. В App Router это делается через `revalidate`, `next: { revalidate }`, `revalidatePath` и `revalidateTag`. ISR подходит для данных, которые должны обновляться, но не требуют свежести на каждый request.

## Частые ошибки

- Использовать ISR для real-time данных.
- Ставить очень маленький revalidate.
- Не понимать, что пользователи могут увидеть старую версию.
- Путать `revalidatePath` и `router.refresh`.
- Не тегировать fetch, который потом нужно инвалидировать.

## Мини-шпаргалка

- ISR = static + regeneration.
- `export const revalidate = 3600`.
- `fetch(..., { next: { revalidate } })`.
- `revalidatePath('/path')`.
- `revalidateTag('tag')`.
- Не для real-time.
