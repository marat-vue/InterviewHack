# Как расширить Error своими свойствами

> [!summary] Коротко
> Чтобы добавить свои свойства к ошибке, создай класс `extends Error`, вызови `super(message)` и запиши дополнительные поля.

## Вопрос

Как добавить к ошибке свои данные: `code`, `status`, `details`?

## Базовый шаблон

```javascript
class HttpError extends Error {
  constructor(message, status, details) {
    super(message);

    this.name = 'HttpError';
    this.status = status;
    this.details = details;
  }
}
```

`super(message)` нужен, чтобы корректно инициализировать базовый `Error`.

## Использование

```javascript
throw new HttpError('Request failed', 404, {
  url: '/api/user',
});
```

## Обработка

```javascript
try {
  await loadUser();
} catch (error) {
  if (error instanceof HttpError) {
    console.log(error.status);
    console.log(error.details);
  }
}
```

## Поле cause

```javascript
class AppError extends Error {
  constructor(message, options = {}) {
    super(message, { cause: options.cause });

    this.name = 'AppError';
    this.code = options.code;
  }
}
```

`cause` удобно использовать, когда одна ошибка оборачивает другую.

## Практические советы

- всегда задавай понятный `name`;
- не теряй исходную ошибку, используй `cause`;
- добавляй только полезные поля;
- проверяй тип через `instanceof`.

## Мини-шпаргалка

```javascript
class MyError extends Error {
  constructor(message, code) {
    super(message);
    this.name = 'MyError';
    this.code = code;
  }
}
```
