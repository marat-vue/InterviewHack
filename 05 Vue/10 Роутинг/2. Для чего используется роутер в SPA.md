# Для чего используется роутер в SPA

> [!summary] Коротко
> Роутер в SPA нужен, чтобы разные URL показывали разные экраны приложения без полной перезагрузки страницы.

## Вопрос

Для чего используется роутер в SPA?

## Проблема без роутера

SPA - это одно приложение в браузере. Но пользователю все равно нужны разные страницы: главная, профиль, настройки, карточка товара.

```text
/ -> HomePage
/profile -> ProfilePage
/users/42 -> UserPage
```

Роутер сопоставляет эти URL с компонентами.

## Что дает роутер

- Навигацию между страницами.
- Динамические маршруты.
- Query-параметры.
- History API браузера.
- Guards для проверки доступа.
- Lazy loading страниц.

## Пример

```vue
<template>
  <nav>
    <RouterLink to="/">Главная</RouterLink>
    <RouterLink to="/profile">Профиль</RouterLink>
  </nav>

  <RouterView />
</template>
```

## Почему это важно для UX

Пользователь может обновить страницу, скопировать ссылку, вернуться назад через browser back и попасть на тот же экран.

## Мини-шпаргалка

- SPA роутер связывает URL и экран.
- Навигация происходит без полной перезагрузки.
- URL остается полноценной частью приложения.
- Роутер помогает с доступами и lazy loading.
