# extends в generic-параметрах

> [!summary] Коротко
> `extends` в generic-параметре задает ограничение: `T extends SomeType`. Это значит, что `T` может быть только типом, совместимым с `SomeType`.

## Вопрос

Что делает `extends` в generic-параметрах?

## Проблема без ограничения

```typescript
function getId<T>(value: T) {
  // return value.id; // ошибка: TypeScript не знает, что id существует
}
```

Для произвольного `T` поле `id` не гарантировано.

## Ограничение формы

```typescript
function getId<T extends { id: string }>(value: T): string {
  return value.id;
}

getId({ id: "1", name: "Анна" });
// getId({ name: "Анна" }); // ошибка
```

Теперь TypeScript знает, что у `T` точно есть `id`.

## Ограничение union-ом

```typescript
type PrimitiveId = string | number;

function normalizeId<T extends PrimitiveId>(id: T): string {
  return String(id);
}
```

## Связанные generic-параметры

```typescript
function getProperty<T, K extends keyof T>(object: T, key: K): T[K] {
  return object[key];
}
```

`K` ограничен ключами `T`, поэтому нельзя запросить несуществующее поле.

## Мини-шпаргалка

- `T extends X` ограничивает допустимые типы для `T`.
- После ограничения можно использовать свойства `X`.
- `extends` в generic - проверка совместимости, не наследование runtime-кода.
- Частый паттерн: `K extends keyof T`.
