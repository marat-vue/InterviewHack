> [!summary]
> Элемент `<html>` - корневой элемент HTML-документа. Внутри него находятся `<head>` со служебной информацией и `<body>` с видимым содержимым страницы.

## Главное

`<html>` оборачивает весь документ.

```html
<!doctype html>
<html lang="ru">
  <head>
    <title>Главная</title>
  </head>
  <body>
    <h1>Добро пожаловать</h1>
  </body>
</html>
```

## Что находится внутри

| Элемент | Что содержит |
| --- | --- |
| `<head>` | Метаданные, `title`, подключение CSS, иконки, служебные теги |
| `<body>` | Видимый контент: текст, формы, изображения, навигацию, интерфейс |

## Атрибут lang

У `<html>` почти всегда стоит указывать язык документа.

```html
<html lang="ru">
```

Это помогает:

- скринридерам правильно произносить текст;
- браузеру выбирать правила перевода и проверки;
- поисковым системам понимать язык страницы.

## Атрибут dir

Если язык читается справа налево, можно указать направление текста.

```html
<html lang="ar" dir="rtl">
```

Для русского и английского обычно используется направление по умолчанию слева направо.

## Частая ошибка

Не стоит помещать видимый контент в `<head>`.

```html
<!-- неправильно -->
<head>
  <h1>Заголовок страницы</h1>
</head>
```

Видимый контент должен находиться в `<body>`.

## Мини-шпаргалка

- `<html>` - корень HTML-документа.
- Внутри обычно два основных элемента: `<head>` и `<body>`.
- `lang` важно указывать для доступности и SEO.
- `<head>` не предназначен для видимого контента.
- `<body>` содержит интерфейс страницы.
