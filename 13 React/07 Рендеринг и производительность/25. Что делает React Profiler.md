# Что делает React Profiler?

> [!summary]
> React Profiler помогает измерять производительность render в React-приложении. Он показывает, какие компоненты рендерились, сколько времени заняли и какие обновления стоит оптимизировать.

## Два способа профилирования

Интерактивно:

- вкладка Profiler в React DevTools;
- запись пользовательского сценария;
- анализ commit, flamegraph и ranked view.

Программно:

```jsx
import { Profiler } from 'react'

function onRender(id, phase, actualDuration, baseDuration, startTime, commitTime) {
  console.log({
    id,
    phase,
    actualDuration,
    baseDuration,
    startTime,
    commitTime,
  })
}

export function App() {
  return (
    <Profiler id="Products" onRender={onRender}>
      <ProductsPage />
    </Profiler>
  )
}
```

## Что означает phase?

`phase` показывает тип render:

- `mount` - компонентная область отрендерилась впервые;
- `update` - область обновилась из-за state/props/context/store changes;
- `nested-update` - обновление произошло во время commit phase.

## actualDuration и baseDuration

`actualDuration` - сколько времени занял текущий render с учетом мемоизации.

`baseDuration` - примерная стоимость render всего поддерева без мемоизации.

Если `actualDuration` сильно меньше `baseDuration`, оптимизация уже помогает.

## Как использовать Profiler на практике?

```text
1. Открыть React DevTools Profiler
2. Нажать Record
3. Выполнить реальный сценарий: ввод, фильтр, переход, открытие модалки
4. Остановить запись
5. Найти самый дорогой commit
6. Посмотреть, какие компоненты рендерились и почему
7. Исправить конкретное место
8. Повторить замер
```

## Что можно найти?

- тяжелый список без virtualization;
- компонент рендерится из-за нового callback;
- provider пересоздает `value`;
- дорогая сортировка выполняется на каждый render;
- слишком широкий global state;
- лишние render после изменения context.

## Важное правило

Не оптимизируй по ощущениям. React-приложение может казаться "сложным", но тормозить будет один конкретный список, график или provider.

## Мини-шпаргалка

- Profiler показывает стоимость render и commit.
- React DevTools удобнее для ручного анализа.
- `<Profiler>` полезен для программных замеров.
- Сначала измеряй, потом добавляй `memo`/`useMemo`/`useCallback`.
- Проверяй результат повторным профилированием.
