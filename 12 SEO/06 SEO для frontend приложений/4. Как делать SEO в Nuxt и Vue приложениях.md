# Как делать SEO в Nuxt и Vue-приложениях?

> [!summary]
> В Vue SEO зависит от выбранного режима рендеринга и настройки маршрутов. В Nuxt многое удобнее: SSR/SSG, meta tags, server routes, sitemap и SEO-модули уже хорошо ложатся на архитектуру приложения.

## Что важно для Vue SPA?

Для чистого Vue SPA нужно:

- менять title и meta на каждом route;
- использовать настоящие ссылки;
- настроить fallback на сервере;
- корректно отдавать страницу `404`;
- добавить prerender для публичных SEO-страниц или перейти на SSR/SSG;
- проверить rendered HTML.

## Что важно для Nuxt?

Nuxt удобен для SEO, потому что поддерживает:

- SSR;
- SSG/prerender;
- route rules;
- `useHead`;
- `useSeoMeta`;
- server routes;
- modules для sitemap, robots, schema.org;
- генерацию статических страниц.

## Пример useSeoMeta

```ts
useSeoMeta({
  title: 'SEO для Nuxt-приложений',
  description: 'Как настроить SSR, meta tags, sitemap, robots и structured data в Nuxt.',
  ogTitle: 'SEO для Nuxt-приложений',
  ogDescription: 'Практический разбор SEO в Nuxt.',
})
```

## Пример route rules

```ts
export default defineNuxtConfig({
  routeRules: {
    '/blog/**': { prerender: true },
    '/account/**': { ssr: false },
  },
})
```

Так публичные статьи можно prerender, а личный кабинет оставить клиентским.

## Мини-шпаргалка

- Vue SPA требует особого внимания к rendered HTML.
- Nuxt дает SSR/SSG и удобные SEO API.
- Для каждой страницы нужны свои title и description.
- Публичные страницы лучше делать SSR/SSG/prerender.
- Личный кабинет обычно не требует индексации.
