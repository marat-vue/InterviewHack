# Что делает свойство line-height?

> [!NOTE]
> `line-height` задает высоту строки текста. Оно влияет на расстояние между строками, читаемость абзацев и вертикальный ритм интерфейса.

## Главное

```css
p {
  font-size: 16px;
  line-height: 1.5;
}
```

Если `font-size` равен `16px`, то высота строки будет примерно `24px`.

## Почему лучше число без единицы

```css
body {
  line-height: 1.5;
}
```

Безразмерное значение наследуется как множитель. Это обычно безопаснее, потому что дочерние элементы с другим `font-size` получат пропорциональную высоту строки.

## Плохо читаемый текст

```css
.article {
  font-size: 16px;
  line-height: 1;
}
```

Строки будут слишком близко друг к другу, особенно в длинном тексте.

## Где разные значения

- Интерфейсные подписи: `1.2`-`1.4`.
- Обычный текст: `1.5`-`1.7`.
- Крупные заголовки: часто меньше, например `1.1`.

```css
h1 {
  line-height: 1.1;
}

.article p {
  line-height: 1.6;
}
```

## Мини-шпаргалка

- `line-height` задает высоту строки.
- Влияет на читаемость.
- Часто используют значение без единицы.
- Для длинного текста обычно нужно больше воздуха.
- Для крупных заголовков line-height может быть меньше.
