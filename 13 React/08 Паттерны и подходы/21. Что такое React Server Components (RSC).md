# Что такое React Server Components (RSC)?

> [!summary]
> React Server Components - это модель компонентов, в которой часть React-дерева выполняется на сервере и не отправляет свой JavaScript в браузер. RSC помогает уменьшить client bundle, читать данные на сервере и строить приложения, где интерактивность подключается только там, где она нужна.

## Server Component

Server Component выполняется на сервере.

Он может:

- читать данные из базы;
- обращаться к файловой системе;
- использовать server-only секреты;
- быть `async`;
- импортировать тяжелые server-only зависимости;
- возвращать JSX.

Пример:

```tsx
// app/products/page.tsx
import { db } from '@/db'
import { ProductCard } from '@/entities/product'

export default async function ProductsPage() {
  const products = await db.product.findMany()

  return (
    <main>
      {products.map((product) => (
        <ProductCard key={product.id} product={product} />
      ))}
    </main>
  )
}
```

## Client Component

Client Component нужен для интерактивности.

Он может:

- использовать `useState`;
- использовать `useEffect`;
- обрабатывать события;
- обращаться к browser API;
- управлять focus, animations, DOM libraries.

```tsx
// app/products/LikeButton.tsx
'use client'

import { useState } from 'react'

export function LikeButton({ productId }: { productId: string }) {
  const [liked, setLiked] = useState(false)

  return (
    <button onClick={() => setLiked((value) => !value)}>
      {liked ? 'Liked' : 'Like'} {productId}
    </button>
  )
}
```

## Граница 'use client'

Директива `'use client'` помечает файл как входную точку клиентского дерева.

```tsx
'use client'

export function SearchBox() {
  const [query, setQuery] = useState('')

  return <input value={query} onChange={(event) => setQuery(event.target.value)} />
}
```

Все компоненты, импортированные в этот client entry, становятся частью client bundle.

## Что нельзя делать в Server Component?

Нельзя:

- использовать `useState`;
- использовать `useEffect`;
- вешать `onClick`;
- обращаться к `window` или `document`;
- передавать обычные функции в Client Component как props.

Плохо:

```tsx
export default function Page() {
  return <LikeButton onLike={() => console.log('like')} />
}
```

Props из Server Component в Client Component должны быть сериализуемыми.

Хорошо:

```tsx
<LikeButton productId={product.id} initialLiked={product.liked} />
```

## RSC vs SSR

SSR:

```text
React рендерит HTML на сервере, затем клиентский JS гидрирует страницу.
```

RSC:

```text
Часть компонентов выполняется только на сервере и не отправляет JS в браузер.
```

Они могут работать вместе. Например, Next.js App Router использует Server Components и умеет делать SSR/streaming/hydration для клиентских частей.

## Мини-шпаргалка

- RSC выполняются на сервере.
- Server Components не используют state/effects/events.
- Client Components нужны для интерактива.
- Props через server-client границу должны быть сериализуемыми.
- RSC уменьшает client bundle и приближает data fetching к серверу.
