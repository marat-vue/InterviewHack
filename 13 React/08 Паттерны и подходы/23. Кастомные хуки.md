# Кастомные хуки

> [!summary]
> Кастомный хук - это JavaScript-функция, имя которой начинается с `use` и которая может вызывать другие хуки. Он нужен, чтобы переиспользовать stateful logic между компонентами без изменения компонентной иерархии.

## Базовое правило

```jsx
function useSomething() {
  // здесь можно вызывать useState, useEffect, useMemo и другие хуки
}
```

Название должно начинаться с `use`, чтобы React tooling и eslint-plugin-react-hooks понимали, что это хук.

## Пример: useToggle

```jsx
function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue)

  const toggle = useCallback(() => {
    setValue((currentValue) => !currentValue)
  }, [])

  return { value, setValue, toggle }
}
```

Использование:

```jsx
function Sidebar() {
  const sidebar = useToggle()

  return (
    <>
      <button onClick={sidebar.toggle}>Toggle</button>
      {sidebar.value && <aside>Menu</aside>}
    </>
  )
}
```

## Пример: useLocalStorage

```jsx
function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const savedValue = localStorage.getItem(key)

    return savedValue ? JSON.parse(savedValue) : initialValue
  })

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value))
  }, [key, value])

  return [value, setValue]
}
```

Такой хук инкапсулирует синхронизацию React state с внешней системой.

## Каждый вызов хука независим

```jsx
function FirstCounter() {
  const counter = useCounter()
}

function SecondCounter() {
  const counter = useCounter()
}
```

Оба компонента переиспользуют одну и ту же логику, но не разделяют один и тот же state. Если нужно разделить именно состояние, его поднимают выше или используют context/store.

## Правила хуков сохраняются

Кастомный хук нельзя вызывать:

```jsx
if (enabled) {
  useFeature() // плохо
}
```

Правильно:

```jsx
function useFeature(enabled) {
  useEffect(() => {
    if (!enabled) return

    startFeature()
  }, [enabled])
}
```

Хук вызывается всегда, а условие находится внутри.

## Что возвращать из хука?

Варианты:

```jsx
return value
return [value, setValue]
return { value, setValue, reset }
```

Для двух значений, похожих на `useState`, удобен tuple. Для большего количества значений объект обычно читается лучше.

## Мини-шпаргалка

- Кастомный хук начинается с `use`.
- Он переиспользует логику, а не JSX.
- Каждый вызов хука имеет независимый state.
- Rules of Hooks работают и внутри custom hooks.
- Если нужно разделить общее состояние, одного custom hook недостаточно.
