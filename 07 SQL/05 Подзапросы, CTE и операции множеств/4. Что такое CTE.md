# Что такое CTE?

> [!summary]
> CTE, Common Table Expression, - именованный временный результат внутри одного SQL-запроса. Он задается через `WITH` и помогает разбивать сложный запрос на понятные шаги.

## Пример

```sql
WITH paid_orders AS (
  SELECT *
  FROM orders
  WHERE status = 'paid'
)
SELECT user_id, COUNT(*) AS paid_count
FROM paid_orders
GROUP BY user_id;
```

`paid_orders` существует только внутри этого запроса.

## Зачем CTE?

- улучшить читаемость;
- переиспользовать промежуточный результат;
- отделить шаги аналитического запроса;
- написать рекурсивный запрос;
- упростить debug.

## Несколько CTE

```sql
WITH paid_orders AS (
  SELECT * FROM orders WHERE status = 'paid'
),
user_stats AS (
  SELECT user_id, COUNT(*) AS count
  FROM paid_orders
  GROUP BY user_id
)
SELECT *
FROM user_stats
WHERE count >= 3;
```

## Мини-шпаргалка

- CTE задается через `WITH`.
- Это временное имя результата внутри запроса.
- Делает сложные запросы читаемее.
- Может быть рекурсивным.
- Производительность CTE зависит от СУБД и версии.
