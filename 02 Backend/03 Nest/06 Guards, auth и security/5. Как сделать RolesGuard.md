# Как сделать RolesGuard?

> [!summary]
> RolesGuard проверяет, имеет ли текущий пользователь одну из ролей, требуемых route handler. Обычно роли задают custom decorator, а guard читает metadata через Reflector.

## Roles decorator

```ts
export const Roles = (...roles: string[]) => SetMetadata('roles', roles);
```

## Guard

```ts
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.getAllAndOverride<string[]>('roles', [
      context.getHandler(),
      context.getClass(),
    ]);

    if (!roles) return true;

    const request = context.switchToHttp().getRequest();
    return roles.includes(request.user.role);
  }
}
```

## Использование

```ts
@Roles('admin')
@UseGuards(JwtAuthGuard, RolesGuard)
@Delete(':id')
remove() {}
```

## Мини-шпаргалка

- Roles хранятся в metadata.
- `Reflector` читает metadata.
- RolesGuard должен запускаться после auth guard.
- 401 и 403 не одно и то же.
- Для сложных прав лучше permissions/policies, а не только roles.
