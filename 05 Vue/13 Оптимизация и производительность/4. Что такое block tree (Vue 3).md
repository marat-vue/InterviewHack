# Что такое block tree (Vue 3)

> [!summary]
> **Block tree** в Vue 3 - это внутренняя структура, которая группирует динамические узлы шаблона. Благодаря ей Vue быстрее обновляет интерфейс и пропускает статические части дерева.

## Зачем это нужно

В обычном Virtual DOM runtime должен обходить дерево и сравнивать узлы. Vue 3 получает больше информации от компилятора: он заранее знает, какие узлы могут изменяться.

```vue
<template>
  <section>
    <h1>Профиль</h1>
    <p>{{ user.name }}</p>
    <small>Статический текст</small>
  </section>
</template>
```

Здесь `h1` и `small` статичны, а `p` зависит от `user.name`. Block tree помогает Vue перейти к динамическому узлу без лишней проверки всей статической разметки.

## Как мыслить о block tree

Упрощенно:

```text
template
  -> compiler detects dynamic nodes
  -> dynamic nodes are collected into a block
  -> runtime patches only dynamic children of the block
```

Это не публичный API, а внутренняя оптимизация. Разработчик обычно не управляет block tree напрямую.

## Пример с несколькими динамическими местами

```vue
<template>
  <article>
    <h2>{{ title }}</h2>
    <p class="description">{{ description }}</p>
    <button :disabled="isSaving">
      {{ isSaving ? "Сохраняем..." : "Сохранить" }}
    </button>
  </article>
</template>
```

Vue может рассматривать динамические части как список:

```text
dynamic children:
  - h2 text
  - button disabled
  - button text
```

Статический класс `description` не требует такой же тщательной проверки при каждом обновлении.

## Что может нарушить оптимизацию

Некоторые конструкции делают дерево менее предсказуемым:

- нестабильные `key` в списках;
- слишком сложные условия внутри больших шаблонов;
- тяжелые вычисления прямо в шаблоне;
- компоненты, которые получают слишком много изменяющихся props;
- частые изменения больших массивов без виртуализации.

## Практический вывод

Разработчику не нужно вручную создавать blocks. Важно писать предсказуемые шаблоны: стабильные `key`, вынесенные вычисления, аккуратные компоненты, разумные списки.

## Мини-шпаргалка

- Block tree - внутренняя оптимизация Vue 3.
- Компилятор собирает динамические узлы в блоки.
- Runtime быстрее находит, что нужно обновить.
- Статическая разметка проверяется меньше.
- Это связано с patch flags и компиляцией шаблонов.
