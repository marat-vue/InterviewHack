# Какие state manager'ы используются в экосистеме Vue

> [!summary] Коротко
> В современной экосистеме Vue основной выбор для state management - Pinia. В legacy-проектах часто встречается Vuex, а для простых случаев хватает локального state, composables или provide/inject.

## Вопрос

Какие state manager'ы используются в экосистеме Vue?

## Pinia

Pinia - официальный и рекомендуемый state manager для Vue 3.

```typescript
export const useUserStore = defineStore("user", {
  state: () => ({
    user: null as User | null,
  }),
  actions: {
    setUser(user: User) {
      this.user = user;
    },
  },
});
```

Она проще Vuex, хорошо типизируется и удобно работает с Composition API.

## Vuex

Vuex был основным решением во Vue 2 и ранней экосистеме Vue.

```text
state -> getters -> mutations -> actions
```

В новых проектах его обычно не выбирают без причины, но в старых кодовых базах он встречается часто.

## Composables

Для небольшой переиспользуемой логики часто хватает composable.

```typescript
export function useTheme() {
  const theme = ref("dark");
  return { theme };
}
```

## provide/inject

Подходит для локального контекста в дереве компонентов: тема layout-а, форма, таблица, UI-библиотека.

## Мини-шпаргалка

- Pinia - основной современный выбор.
- Vuex - часто в legacy Vue 2/Vue 3 проектах.
- Composables подходят для простой общей логики.
- provide/inject хорош для локального контекста.
- Store нужен не всегда.
