# Роутинг и навигация

> [!NOTE] Коротко
> Роутинг во Vue обычно реализуют через Vue Router. Он сопоставляет URL с компонентами страниц и позволяет строить SPA-навигацию без полной перезагрузки страницы.

## Вопрос

Что такое роутинг и навигация во Vue?

## Базовая идея

В SPA разные URL показывают разные компоненты.

```typescript
import { createRouter, createWebHistory } from "vue-router";

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: "/", component: HomePage },
    { path: "/profile", component: ProfilePage },
  ],
});
```

Компонент текущего маршрута отображается через `RouterView`.

```vue
<template>
  <RouterLink to="/">Главная</RouterLink>
  <RouterLink to="/profile">Профиль</RouterLink>

  <RouterView />
</template>
```

## Навигация

Для ссылок используют `RouterLink`, а для переходов из кода - `router.push`.

```typescript
import { useRouter } from "vue-router";

const router = useRouter();

function goToProfile() {
  router.push("/profile");
}
```

## Динамические маршруты

```typescript
{ path: "/users/:id", component: UserPage }
```

Такой маршрут подходит для страниц конкретных сущностей.

## Мини-шпаргалка

- Vue Router связывает URL и компонент страницы.
- `RouterView` показывает текущую страницу.
- `RouterLink` делает SPA-ссылку.
- `router.push()` выполняет программную навигацию.
