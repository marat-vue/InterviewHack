# Почему скорость важна для SEO?

> [!summary]
> Скорость важна для SEO, потому что влияет на пользовательский опыт, Core Web Vitals, индексацию, поведение пользователей и конверсию. Быстрая страница не заменяет хороший контент, но помогает ему быть доступным, удобным и конкурентным.

## Скорость - это часть качества страницы

Поисковику важно не только понять, что написано на странице, но и насколько удобно пользователю эту страницу открыть.

Если две страницы похожи по качеству контента, то быстрее и стабильнее работающая страница получает преимущество:

- пользователь быстрее видит ответ;
- меньше вероятность возврата в выдачу;
- выше шанс дочитать материал;
- выше конверсия;
- меньше раздражения от сдвигов и задержек.

## Core Web Vitals и page experience

Google использует Core Web Vitals как часть сигналов page experience:

- LCP - быстро ли появился главный контент;
- INP - быстро ли страница реагирует;
- CLS - не прыгает ли интерфейс.

Это не магическая кнопка выхода в топ. Контент, интент и авторитетность все еще важнее. Но плохая скорость может мешать странице раскрыть свой потенциал.

## Скорость влияет на поведение пользователей

Медленный сайт часто получает:

- больше отказов;
- меньше просмотров страниц;
- меньше времени на сайте;
- меньше заявок и покупок;
- меньше возвратов пользователей.

Например, если карточка товара открывается 5 секунд, пользователь может вернуться в выдачу и выбрать конкурента.

## Скорость влияет на crawl budget

Поисковые роботы ограничены временем и ресурсами. Если сайт отвечает медленно, робот может обойти меньше страниц за один визит.

Это особенно важно для:

- интернет-магазинов;
- каталогов;
- больших блогов;
- маркетплейсов;
- сайтов с частыми обновлениями.

Быстрый серверный ответ и понятная структура помогают новым страницам быстрее попадать в индекс.

## Почему Next.js часто помогает SEO

Next.js может улучшить SEO-производительность за счет:

- SSR/SSG/ISR;
- Server Components;
- готового HTML на первом ответе;
- Metadata API;
- `next/image`;
- `next/font`;
- кэширования;
- streaming rendering;
- автоматического code splitting.

Но сам Next.js не гарантирует хороший SEO. Можно сделать медленный Next-проект, если отправить слишком много Client Components, тяжелых библиотек и некешируемых запросов.

## Практический чеклист

- Проверить LCP на мобильных.
- Оптимизировать главное изображение.
- Уменьшить клиентский JS.
- Не грузить основной контент только через `useEffect`.
- Настроить metadata.
- Проверить sitemap и robots.
- Убрать layout shifts.
- Кешировать данные там, где это безопасно.
- Проверить Search Console и PageSpeed Insights.

## Что отвечать на собеседовании?

Скорость важна для SEO, потому что она влияет на page experience, Core Web Vitals, поведение пользователей и эффективность индексации. Быстрая страница быстрее показывает контент, лучше реагирует на действия и меньше раздражает пользователя. Но скорость не заменяет релевантный контент: она усиливает хороший контент, а не исправляет плохой.

## Частые ошибки

- Думать, что хороший Lighthouse score автоматически даст топ выдачи.
- Оптимизировать только desktop.
- Игнорировать реальные field-данные.
- Считать SSR достаточным для SEO без нормальных metadata.
- Забывать про изображения как главный источник плохого LCP.
- Закрывать глаза на тяжелые Client Components.

## Мини-шпаргалка

- Скорость влияет на UX и SEO.
- Core Web Vitals - часть page experience.
- Контент важнее, но скорость усиливает результат.
- Медленный сайт хуже обходится роботами.
- Next.js помогает, но не спасает от плохой архитектуры.
- Главные враги: тяжелый JS, плохой LCP, CLS, медленный TTFB.
