# Объект в JavaScript

> [!NOTE] Коротко
> Объект - ссылочный тип данных, который хранит набор свойств в формате `ключ -> значение`. Значением может быть что угодно: примитив, массив, другой объект или функция.

## Вопрос

Что такое объект в JavaScript?

## Основная идея

Объект группирует связанные данные.

```javascript
const user = {
  name: "Anna",
  age: 25,
  isAdmin: false,
};
```

Здесь:

- `name`, `age`, `isAdmin` - ключи;
- `"Anna"`, `25`, `false` - значения.

## Ключи и значения

Ключи объекта обычно являются строками или `Symbol`.

```javascript
const id = Symbol("id");

const user = {
  name: "Anna",
  [id]: 123,
};
```

Значением может быть любой тип:

```javascript
const user = {
  name: "Anna",
  address: {
    city: "Moscow",
  },
  roles: ["admin", "editor"],
  sayHi() {
    return `Hi, ${this.name}`;
  },
};
```

## Доступ к свойствам

Через точку:

```javascript
user.name; // "Anna"
```

Через квадратные скобки:

```javascript
user["name"]; // "Anna"
```

Скобки нужны для динамических ключей:

```javascript
const key = "name";

user[key]; // "Anna"
```

## Объекты передаются по ссылке

```javascript
const user = { name: "Anna" };
const copy = user;

copy.name = "Max";

console.log(user.name); // "Max"
```

`copy` не является независимой копией. Это вторая ссылка на тот же объект.

## Мини-шпаргалка

```javascript
const obj = {};
obj.name = "Anna";
obj["age"] = 25;
delete obj.age;
"name" in obj;
Object.keys(obj);
```

| Особенность | Объект |
| --- | --- |
| тип | ссылочный |
| ключи | string или Symbol |
| значения | любые |
| доступ | точка или скобки |
| сравнение | по ссылке |
