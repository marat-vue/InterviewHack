# Как получить query-параметры из URL?

> [!summary]
> Query-параметры - это часть URL после `?`. В React Router их удобнее читать через `useSearchParams`, но можно также использовать `useLocation` и стандартный `URLSearchParams`.

## Что такое query-параметры?

```text
https://example.com/products?page=2&sort=price&tag=react
```

Здесь:

```text
page = "2"
sort = "price"
tag = "react"
```

## Способ 1: useSearchParams

```jsx
import { useSearchParams } from 'react-router-dom'

function ProductsPage() {
  const [params] = useSearchParams()

  const page = params.get('page') ?? '1'
  const sort = params.get('sort') ?? 'popular'

  return <p>{page} / {sort}</p>
}
```

Это основной способ внутри React Router.

## Способ 2: useLocation

```jsx
import { useLocation } from 'react-router-dom'

function ProductsPage() {
  const location = useLocation()
  const params = new URLSearchParams(location.search)

  return <p>{params.get('page')}</p>
}
```

Этот способ полезен, если нужен полный `location` или нужно сделать свою обертку.

## Способ 3: чистый браузерный API

```js
const params = new URLSearchParams(window.location.search)
const page = params.get('page')
```

Подходит вне React-компонентов, но в React Router компонентах лучше не завязываться напрямую на `window.location`.

## Преобразование типов

Query params всегда строки.

```jsx
const page = Number(params.get('page') ?? 1)
const showArchived = params.get('archived') === 'true'
```

Для массивов часто используют повторяющиеся параметры:

```text
?tag=react&tag=router
```

```jsx
const tags = params.getAll('tag')
```

## Мини-шпаргалка

- Query string начинается после `?`.
- В React Router основной инструмент - `useSearchParams`.
- `URLSearchParams` дает методы `get`, `has`, `getAll`, `set`, `delete`.
- Все значения надо явно приводить к нужному типу.
- Query params хорошо подходят для фильтров и пагинации.
