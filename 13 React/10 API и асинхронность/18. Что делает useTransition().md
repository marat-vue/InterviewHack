# Что делает useTransition()?

> [!summary]
> `useTransition` позволяет пометить часть обновлений state как transition, то есть несрочную работу. React может выполнить ее в фоне, не блокируя срочные обновления вроде ввода текста, кликов и фокуса.

## Синтаксис

```jsx
const [isPending, startTransition] = useTransition()
```

`isPending` показывает, что transition еще выполняется.

`startTransition` помечает state updates внутри callback как несрочные.

## Пример с тяжелым списком

```jsx
function SearchPage({ allItems }) {
  const [query, setQuery] = useState('')
  const [filteredItems, setFilteredItems] = useState(allItems)
  const [isPending, startTransition] = useTransition()

  function handleChange(event) {
    const nextQuery = event.target.value

    setQuery(nextQuery)

    startTransition(() => {
      setFilteredItems(filterItems(allItems, nextQuery))
    })
  }

  return (
    <>
      <input value={query} onChange={handleChange} />
      {isPending && <SmallLoader />}
      <ItemsList items={filteredItems} />
    </>
  )
}
```

Input обновляется срочно, список - как transition.

## Что нельзя делать?

Не стоит оборачивать controlled input value в transition:

```jsx
startTransition(() => {
  setQuery(event.target.value) // плохо для controlled input
})
```

Поле ввода должно обновляться сразу.

## useTransition и async actions

В React transitions могут использоваться с async actions, но важно помнить: state updates после `await` может потребоваться снова обернуть в `startTransition`, если они должны быть transition.

```jsx
startTransition(async () => {
  const data = await saveForm(values)

  startTransition(() => {
    setResult(data)
  })
})
```

## Где применять?

- переключение вкладок с тяжелым UI;
- route transitions;
- фильтрация больших списков;
- обновление графиков;
- Suspense-enabled навигация;
- не срочные визуальные пересчеты.

## Мини-шпаргалка

- `useTransition` возвращает `[isPending, startTransition]`.
- Transition updates имеют меньший приоритет.
- Срочные updates не должны попадать в transition.
- Transition render может быть прерван.
- Для pending UI используй `isPending`.
