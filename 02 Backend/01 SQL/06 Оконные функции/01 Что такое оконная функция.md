# Что такое оконная функция?

> [!NOTE]
> Оконная функция считает значение по набору строк, связанных с текущей строкой, но не схлопывает строки в одну, как `GROUP BY`. Поэтому она удобна для рейтингов, накопительных сумм и аналитики.

## Пример

```sql
SELECT
  user_id,
  total,
  SUM(total) OVER (PARTITION BY user_id) AS user_total
FROM orders;
```

Каждый заказ остается отдельной строкой, но рядом появляется сумма заказов пользователя.

## Отличие от GROUP BY

```sql
SELECT user_id, SUM(total)
FROM orders
GROUP BY user_id;
```

`GROUP BY` вернет одну строку на пользователя. Оконная функция сохранит все строки заказов.

## Синтаксис OVER

```sql
function() OVER (
  PARTITION BY ...
  ORDER BY ...
)
```

`PARTITION BY` делит строки на окна, `ORDER BY` задает порядок внутри окна.

## Мини-шпаргалка

- Оконная функция не уменьшает количество строк.
- `OVER` задает окно.
- `PARTITION BY` делит данные на группы окна.
- `ORDER BY` задает порядок внутри окна.
- Частые функции: `ROW_NUMBER`, `RANK`, `SUM`, `LAG`, `LEAD`.
