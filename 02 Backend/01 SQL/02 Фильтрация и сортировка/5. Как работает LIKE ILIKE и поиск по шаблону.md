# Как работает LIKE, ILIKE и поиск по шаблону?

> [!summary]
> `LIKE` ищет строки по шаблону, где `%` означает любую последовательность символов, а `_` - один символ. В PostgreSQL `ILIKE` делает регистронезависимый поиск.

## LIKE

```sql
SELECT *
FROM users
WHERE email LIKE '%@example.com';
```

Найдет email, которые заканчиваются на `@example.com`.

## Шаблоны

| Шаблон | Значение |
|---|---|
| `'Ann%'` | начинается с `Ann` |
| `'%son'` | заканчивается на `son` |
| `'%dev%'` | содержит `dev` |
| `'A_a'` | `A`, любой символ, `a` |

## ILIKE

```sql
SELECT *
FROM users
WHERE name ILIKE 'ann%';
```

`ILIKE` есть в PostgreSQL, но не является универсальным для всех СУБД.

## Производительность

Шаблон с `%` в начале часто мешает обычному B-tree индексу.

```sql
WHERE title LIKE '%node%'
```

Для полноценного текстового поиска лучше использовать full-text search или специальные индексы конкретной СУБД.

## Мини-шпаргалка

- `%` - любая последовательность символов.
- `_` - один символ.
- `LIKE` обычно чувствителен к регистру в зависимости от СУБД и collation.
- `ILIKE` в PostgreSQL игнорирует регистр.
- `LIKE '%text%'` может быть медленным на больших таблицах.
