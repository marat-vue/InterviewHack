# Что такое директива

> [!summary] Коротко
> Директива во Vue - специальный атрибут шаблона с префиксом `v-`, который добавляет реактивное поведение к DOM или компоненту.

## Вопрос

Что такое директива во Vue?

## Базовая идея

Директива связывает HTML с логикой Vue.

```vue
<template>
  <p v-if="isVisible">Виден</p>
  <a v-bind:href="url">Ссылка</a>
  <button v-on:click="save">Сохранить</button>
</template>
```

## Частые директивы

- `v-if` - условно создает или удаляет элемент.
- `v-show` - переключает видимость через CSS.
- `v-for` - рендерит список.
- `v-bind` - привязывает атрибут или prop.
- `v-on` - подписывается на событие.
- `v-model` - создает двустороннее связывание.

## Сокращения

```vue
<a :href="url">Ссылка</a>
<button @click="save">Сохранить</button>
```

`:` - сокращение для `v-bind`, `@` - для `v-on`.

## Аргументы и модификаторы

```vue
<form @submit.prevent="submit">
  <input v-model.trim="name" />
</form>
```

`submit` - аргумент директивы `v-on`, `.prevent` и `.trim` - модификаторы.

## Мини-шпаргалка

- Директивы начинаются с `v-`.
- Они добавляют поведение в шаблон.
- `:` = `v-bind`, `@` = `v-on`.
- Модификаторы уточняют поведение директивы.
