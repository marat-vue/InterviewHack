# Как объединить несколько типов?

> [!NOTE] Коротко
> В TypeScript типы объединяют двумя главными операторами: `|` для "или" и `&` для "и".

## Вопрос

Как объединить несколько типов?

## Union: один из вариантов

`A | B` означает, что значение может быть типа `A` или типа `B`.

```typescript
type Id = string | number;

function printId(id: Id) {
  console.log(id);
}
```

Для доступа к специфичным возможностям нужно сужение типа.

```typescript
function formatId(id: Id): string {
  return typeof id === "number" ? id.toFixed(0) : id.toLowerCase();
}
```

## Intersection: все вместе

`A & B` означает, что значение должно соответствовать и `A`, и `B`.

```typescript
type HasId = { id: string };
type HasName = { name: string };

type User = HasId & HasName;

const user: User = {
  id: "1",
  name: "Анна",
};
```

## Union и intersection вместе

```typescript
type ApiResult =
  | ({ status: "success" } & { data: string[] })
  | ({ status: "error" } & { message: string });
```

## Как выбрать

Union нужен, когда возможны разные варианты. Intersection нужен, когда нужно собрать несколько требований в один тип.

## Мини-шпаргалка

- `A | B` - A или B.
- `A & B` - A и B одновременно.
- Union обычно требует narrowing.
- Intersection часто используют для композиции объектных типов.
