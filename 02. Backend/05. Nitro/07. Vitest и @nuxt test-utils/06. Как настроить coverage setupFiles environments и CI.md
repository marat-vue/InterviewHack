# Как настроить coverage, setupFiles, environments и CI?

> [!NOTE]
> В Vitest coverage показывает, какие строки/branches/functions покрыты тестами. `setupFiles` готовят окружение, `environment` выбирает runtime, а CI запускает tests в воспроизводимом режиме.

## Coverage install

```bash
npm i -D @vitest/coverage-v8
```

## Coverage config

```ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'html', 'lcov'],
      include: [
        'server/**/*.ts',
      ],
      exclude: [
        'server/**/*.test.ts',
        'server/generated/**',
        'prisma/**',
      ],
      thresholds: {
        statements: 80,
        branches: 70,
        functions: 80,
        lines: 80,
      },
    },
  },
});
```

## Scripts

```json
{
  "scripts": {
    "test": "vitest",
    "test:run": "vitest run",
    "test:coverage": "vitest run --coverage"
  }
}
```

## Setup files

```ts
export default defineConfig({
  test: {
    setupFiles: ['./tests/setup.ts'],
  },
});
```

Пример setup:

```ts
// tests/setup.ts
import { afterEach, vi } from 'vitest';

afterEach(() => {
  vi.clearAllMocks();
  vi.unstubAllEnvs();
  vi.unstubAllGlobals();
});
```

## Environments

```ts
export default defineConfig({
  test: {
    environment: 'node',
  },
});
```

Для component tests:

```ts
environment: 'happy-dom'
```

Для Nuxt runtime:

```ts
environment: 'nuxt'
```

при конфигурации через `@nuxt/test-utils`.

## CI workflow idea

```txt
checkout
  -> install dependencies with lockfile
  -> generate Prisma Client
  -> run migrations on test database
  -> run tests
  -> upload coverage
```

Пример scripts:

```json
{
  "scripts": {
    "ci:test": "prisma generate && vitest run --coverage"
  }
}
```

## Test database в CI

Для Prisma integration:

- поднять PostgreSQL service;
- задать `DATABASE_URL`;
- запустить `prisma migrate deploy`;
- очистить data между tests;
- не использовать production database.

## Мини-шпаргалка

- Coverage: `vitest run --coverage`.
- Provider: чаще `v8`.
- `setupFiles` - reset mocks/env/database.
- Backend environment - `node`.
- Nuxt runtime environment - `nuxt`.
- CI должен использовать lockfile и test database.
