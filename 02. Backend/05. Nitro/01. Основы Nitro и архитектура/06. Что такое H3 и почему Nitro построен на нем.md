# Что такое H3 и почему Nitro построен на нем?

> [!NOTE]
> H3 - это небольшой HTTP framework от UnJS. Nitro использует H3 как слой request handlers, event object, routing, middleware и utilities. Если Nitro - это server framework и build/deploy layer, то H3 - это HTTP runtime API внутри handler-ов.

## Простое определение

H3 дает:

- `H3Event`;
- handlers;
- middleware;
- routing;
- request utilities;
- response utilities;
- cookie utilities;
- CORS/session/basic auth helpers;
- proxy helpers;
- Web-compatible response model.

```ts
import { defineHandler, getQuery, readBody } from 'h3';

export default defineHandler(async (event) => {
  const query = getQuery(event);
  const body = await readBody(event);

  return {
    query,
    body,
  };
});
```

## Почему это важно в Nitro?

Nitro routes - это H3-compatible handlers. Поэтому большинство повседневных backend-задач решаются через H3 utilities:

- прочитать body;
- прочитать query;
- прочитать route params;
- поставить cookie;
- сделать redirect;
- бросить HTTP error;
- проверить method;
- обработать CORS;
- создать session;
- прокинуть request во внутренний endpoint.

## Чем H3 отличается от Express API?

В Express часто используют mutable `req/res`:

```ts
app.get('/users', (req, res) => {
  res.status(200).json({ ok: true });
});
```

В H3 чаще возвращают результат:

```ts
export default defineHandler(() => {
  return {
    ok: true,
  };
});
```

Это ближе к Web Fetch model и проще адаптируется под разные runtime.

## Что такое composable utilities?

H3 делает ставку на явные функции:

```ts
const body = await readBody(event);
const query = getQuery(event);
const token = getCookie(event, 'token');
```

Это лучше, чем глобально навешивать много middleware, потому что код handler-а явно показывает, какие части request ему нужны.

## Какие H3 функции нужно знать в Nitro?

Чаще всего нужны:

- `defineHandler` / `defineEventHandler`;
- `getQuery`;
- `readBody`;
- `readValidatedBody`;
- `getRouterParam`;
- `getRouterParams`;
- `getValidatedQuery`;
- `getValidatedRouterParams`;
- `getCookie`;
- `setCookie`;
- `deleteCookie`;
- `createError`;
- `redirect`;
- `noContent`;
- `handleCors`;
- `fetchWithEvent`.

Подробные таблицы по этим функциям есть в разделе `03. H3 utilities и runtime API`.

## Мини-шпаргалка

- H3 - HTTP-layer для Nitro.
- Nitro handlers совместимы с H3 handlers.
- `event` - общий контекст request lifecycle.
- H3 API ближе к Web `Request`/`Response`, чем к Express `req/res`.
- Чем лучше ты знаешь H3 utilities, тем увереннее пишешь Nitro backend.
