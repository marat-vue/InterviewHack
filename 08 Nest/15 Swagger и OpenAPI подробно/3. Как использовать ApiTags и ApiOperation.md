# Как использовать ApiTags и ApiOperation?

> [!summary]
> `@ApiTags` группирует endpoints в Swagger UI, а `@ApiOperation` добавляет summary и description для конкретного route. Это делает документацию понятной для людей, а не только валидной для машин.

## ApiTags

```ts
@ApiTags('users')
@Controller('users')
export class UsersController {}
```

Все endpoints controller попадут в группу `users`.

## ApiOperation

```ts
@ApiOperation({
  summary: 'Create user',
  description: 'Creates a new user with email and name.',
})
@Post()
create(@Body() dto: CreateUserDto) {}
```

## Хороший summary

Пиши summary как действие:

```txt
Create user
Get current session
Update user profile
Delete post
```

## Мини-шпаргалка

- `@ApiTags` группирует routes.
- `@ApiOperation` описывает конкретный endpoint.
- Summary должен быть коротким.
- Description объясняет нюансы.
- Хорошая документация помогает frontend быстрее, чем длинный чат.
