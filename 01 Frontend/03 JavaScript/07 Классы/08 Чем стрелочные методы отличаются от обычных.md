# Чем стрелочные методы отличаются от обычных?

> [!NOTE]
> Обычный метод класса хранится в прототипе и получает `this` при вызове, а стрелочное поле создается на экземпляре и лексически сохраняет `this`.

## Вопрос

Чем стрелочный метод в классе отличается от обычного метода?

## Обычный метод

```javascript
class Button {
  handleClick() {
    console.log(this);
  }
}
```

Такой метод хранится в `Button.prototype`. Он экономит память, потому что все экземпляры используют одну функцию.

## Стрелочное поле

```javascript
class Button {
  handleClick = () => {
    console.log(this);
  };
}
```

Это не метод прототипа, а поле экземпляра. Новая функция создается для каждого объекта.

## Разница с this

```javascript
const button = new Button();
const handler = button.handleClick;

handler();
```

Если `handleClick` - обычный метод, `this` может потеряться. Если это стрелочное поле, `this` останется привязанным к экземпляру.

## Сравнение

| Вариант | Где хранится | `this` | Минус |
| --- | --- | --- | --- |
| обычный метод | prototype | зависит от вызова | можно потерять |
| стрелочное поле | экземпляр | лексически привязан | больше памяти |

## Когда что использовать

- обычные методы - по умолчанию;
- стрелочные поля - для callback-методов, которые часто передаются в обработчики;
- `bind` - если нужно явно привязать обычный метод.

## Мини-шпаргалка

```javascript
class A {
  method() {}       // prototype, dynamic this
  method = () => {} // instance field, lexical this
}
```
