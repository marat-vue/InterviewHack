# Что делает модификатор .trim?

> [!NOTE]
> `.trim` у `v-model` автоматически удаляет пробелы в начале и конце строки перед записью значения в state.

## Вопрос

Что делает модификатор `.trim`?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const username = ref("");
</script>

<template>
  <input v-model.trim="username" />
</template>
```

Если пользователь введет `"  anna  "`, в `username` попадет `"anna"`.

## Где полезно

- Имя пользователя.
- Email.
- Поисковый запрос.
- Текстовые поля, где пробелы по краям не несут смысла.

## Когда не использовать

Если пробелы важны, например в пароле, коде, markdown-тексте или моноширинном вводе, `.trim` может испортить значение.

```vue
<textarea v-model="code" />
```

## Альтернатива

Для сложной нормализации лучше использовать явную функцию.

```typescript
function normalizeName(value: string) {
  return value.trim().replace(/\s+/g, " ");
}
```

## Мини-шпаргалка

- `.trim` вызывает trim для строкового значения.
- Убирает только края строки.
- Хорош для логинов, email и простых имен.
- Не используй там, где пробелы значимы.
