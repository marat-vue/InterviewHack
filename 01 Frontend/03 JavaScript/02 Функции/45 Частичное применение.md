# Частичное применение

> [!NOTE] Коротко
> Частичное применение - прием, когда функции заранее передают часть аргументов и получают новую функцию, ожидающую остальные аргументы.

## Вопрос

Что такое частичное применение (partial application)?

## Базовый пример

```javascript
function sum(a, b, c) {
  return a + b + c;
}

function partialSum(a) {
  return function (b, c) {
    return sum(a, b, c);
  };
}

const add10 = partialSum(10);

add10(2, 3); // 15
```

Мы зафиксировали `a = 10`, а `b` и `c` передали позже.

## Через `bind`

```javascript
function multiply(a, b) {
  return a * b;
}

const double = multiply.bind(null, 2);

double(5); // 10
```

`bind` закрепил первый аргумент.

## Через стрелочные функции

```javascript
const createUrl = (baseUrl) => (path) => `${baseUrl}${path}`;

const apiUrl = createUrl("/api");

apiUrl("/users"); // "/api/users"
apiUrl("/posts"); // "/api/posts"
```

## Отличие от каррирования

Частичное применение фиксирует любое количество аргументов.

```javascript
f(a, b, c) -> g(c)
```

Каррирование превращает функцию в цепочку функций по одному аргументу.

```javascript
f(a, b, c) -> f(a)(b)(c)
```

## Когда использовать

- заранее настроить функцию;
- убрать дублирование;
- создать специализированные обработчики;
- передать функцию в callback с уже известными параметрами.

Пример:

```javascript
const isRole = (role, user) => user.role === role;
const isAdmin = isRole.bind(null, "admin");

users.filter(isAdmin);
```

## Мини-шпаргалка

| Прием | Пример |
| --- | --- |
| partial application | `f(a, b, c) -> g(c)` |
| через замыкание | `const g = (b) => f(a, b)` |
| через `bind` | `f.bind(null, a)` |
| currying | `f(a)(b)(c)` |
