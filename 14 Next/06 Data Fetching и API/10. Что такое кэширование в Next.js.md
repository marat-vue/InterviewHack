# Что такое кэширование в Next.js?

> [!summary]
> Кэширование в Next.js - сохранение данных, RSC payload, HTML/routes и assets, чтобы ускорить ответы и снизить нагрузку. В App Router ключевые темы: Data Cache, Full Route Cache, Router Cache, request memoization, image cache и revalidation.

## Зачем нужен cache?

Без кеша каждый request может заново:

- обращаться к API;
- читать БД;
- рендерить route;
- генерировать изображения;
- ждать медленные сервисы.

Кеш помогает отдавать результат быстрее.

## Основные уровни

| Уровень | Что кеширует |
|---|---|
| Request memoization | одинаковые запросы в рамках render pass |
| Data Cache | результаты `fetch` на сервере |
| Full Route Cache | статический HTML/RSC output route |
| Router Cache | RSC payload на клиенте при навигации |
| Image Optimization Cache | оптимизированные изображения |

## Управление fetch cache

```tsx
await fetch(url, { cache: 'force-cache' })
```

```tsx
await fetch(url, { cache: 'no-store' })
```

```tsx
await fetch(url, { next: { revalidate: 60 } })
```

```tsx
await fetch(url, { next: { tags: ['posts'] } })
```

## Cache не всегда означает "навсегда"

Кеш должен соответствовать данным:

- blog post - можно кешировать;
- dashboard current user - осторожно;
- stock price - короткий revalidate или dynamic;
- cart - user-specific;
- permissions - зависит от auth.

## Что отвечать на собеседовании?

Кеширование в Next.js многоуровневое: есть кеш данных `fetch`, кеш результата route, клиентский Router Cache и кеш оптимизированных изображений. Управление зависит от того, нужны ли свежие данные, персонализация и revalidation.

## Частые ошибки

- Считать, что cache - всегда хорошо.
- Кешировать пользовательские данные как публичные.
- Не инвалидировать данные после mutation.
- Путать Router Cache и Data Cache.
- Не проверять поведение в production build.

## Мини-шпаргалка

- Data Cache - `fetch`.
- Full Route Cache - статический route output.
- Router Cache - клиентская навигация.
- `no-store` - без кеша.
- `revalidate` - обновление по времени.
- `revalidateTag` - обновление по тегу.
