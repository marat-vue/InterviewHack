# Как проводить content audit?

> [!summary]
> Content audit помогает понять, какие страницы работают, какие устарели, какие конкурируют друг с другом и где не закрыт search intent. Это основа для роста без бесконечной публикации новых материалов.

## Что собрать?

Для каждой страницы:

- URL;
- тип страницы;
- title;
- целевой кластер;
- clicks;
- impressions;
- CTR;
- average position;
- organic conversions;
- дата публикации;
- дата обновления;
- backlinks;
- статус индексации.

## Какие решения возможны?

| Ситуация | Решение |
|---|---|
| Страница получает показы, но мало кликов | улучшить title/description |
| Позиции 8-20 | расширить контент, улучшить links |
| Контент устарел | обновить |
| Несколько страниц про одно и то же | объединить или развести intent |
| Нет трафика и нет ценности | удалить, noindex или переработать |

## Что такое keyword cannibalization?

Это когда несколько страниц конкурируют за один intent.

Пример:

```text
/blog/seo-checklist
/blog/technical-seo-checklist
/blog/full-seo-checklist
```

Если все три страницы отвечают на один и тот же запрос, поисковику сложно выбрать лучшую.

## Как улучшать старый контент?

- Обновить факты.
- Добавить примеры.
- Улучшить структуру.
- Добавить внутренние ссылки.
- Обновить title.
- Добавить схемы, таблицы и FAQ.
- Убрать воду.
- Сопоставить с текущей выдачей.

## Мини-шпаргалка

- Content audit ищет точки роста в существующих страницах.
- Не весь старый контент нужно удалять.
- Cannibalization возникает при конфликте intent.
- Обновление сильной страницы часто эффективнее новой слабой статьи.
- Решение должно учитывать трафик, пользу и бизнес-ценность.
