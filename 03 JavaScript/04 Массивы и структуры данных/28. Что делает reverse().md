# `reverse()`

> [!summary] Коротко
> `reverse()` переворачивает порядок элементов массива на месте, мутирует исходный массив и возвращает тот же массив.

## Вопрос

Что делает `reverse()`?

## Пример

```javascript
const arr = [1, 2, 3];

const result = arr.reverse();

console.log(arr);    // [3, 2, 1]
console.log(result); // [3, 2, 1]
console.log(result === arr); // true
```

## Мутация

`reverse()` меняет исходный массив. Это важно, если массив используется еще где-то.

```javascript
const original = [1, 2, 3];
const reversed = original.reverse();

console.log(original); // [3, 2, 1]
```

## Без мутации

Классический способ:

```javascript
const reversed = [...arr].reverse();
```

Современный способ:

```javascript
const reversed = arr.toReversed();
```

`toReversed()` возвращает новый массив и не меняет исходный.

## Строку через массив

```javascript
const reversed = "hello".split("").reverse().join("");

console.log(reversed); // "olleh"
```

## Мини-шпаргалка

| Задача | Код |
| --- | --- |
| перевернуть с мутацией | `arr.reverse()` |
| перевернуть без мутации | `[...arr].reverse()` |
| современно без мутации | `arr.toReversed()` |
| вернуть тот же массив | `reverse()` делает именно это |
