# Как получить доступ к состоянию в Zustand?

> [!summary]
> В компоненте Zustand state читают через store hook и selector. Selector выбирает конкретную часть состояния, на которую компонент должен подписаться.

## Базовое чтение

```jsx
const count = useCounterStore((state) => state.count)
```

Компонент получит `count` и будет обновляться, когда выбранное значение изменится.

## Чтение action

```jsx
const increment = useCounterStore((state) => state.increment)
```

Использование:

```jsx
function CounterButton() {
  const count = useCounterStore((state) => state.count)
  const increment = useCounterStore((state) => state.increment)

  return <button onClick={increment}>{count}</button>
}
```

## Чтение нескольких значений

Можно читать по отдельности:

```jsx
const count = useCounterStore((state) => state.count)
const increment = useCounterStore((state) => state.increment)
```

Это часто проще и помогает избежать лишних ререндеров.

Если вернуть объект:

```jsx
const { count, increment } = useCounterStore((state) => ({
  count: state.count,
  increment: state.increment,
}))
```

на каждом вызове selector создается новый объект. Для такого подхода нужна shallow-сравнение или другой способ стабилизации.

## Доступ вне компонента

У Zustand store hook есть utility methods:

```jsx
useCounterStore.getState()
useCounterStore.setState({ count: 0 })
useCounterStore.subscribe((state) => console.log(state))
```

Это полезно для интеграций, но в UI-компонентах обычно читают через hook.

## Мини-шпаргалка

- В компоненте state читают через `useStore(selector)`.
- Selector выбирает нужную часть state.
- Actions тоже можно читать через selector.
- Несколько значений часто лучше читать отдельными selectors.
- Вне React можно использовать `getState`, `setState`, `subscribe`.
