# SEO checklist перед релизом

> [!summary]
> SEO checklist перед релизом помогает не сломать индексацию, сниппеты, ссылки, скорость и аналитику. Особенно он важен при выпуске новых страниц, редизайне, миграции и изменении routing.

## Индексация

- Важные страницы отдают `200`.
- Нет случайного `noindex`.
- robots.txt не блокирует важные страницы и ресурсы.
- Sitemap обновлен.
- Canonical корректный.
- Ненужные страницы закрыты от индексации.

## Meta и контент

- У каждой важной страницы уникальный title.
- Есть description.
- Есть один понятный H1.
- Headings выстроены логично.
- Контент доступен в HTML или после надежного SSR/рендера.
- Нет placeholder-контента.

## Frontend

- Маршруты имеют стабильные URL.
- Навигационные ссылки сделаны через `<a href>`.
- `404` реально отдает корректный статус.
- Meta tags обновляются при route change.
- Structured data соответствуют странице.
- Проверен rendered HTML.

## Performance

- LCP-элемент оптимизирован.
- Изображения имеют размеры.
- Нет заметного CLS.
- JS не блокирует взаимодействие.
- Сторонние скрипты загружаются осознанно.
- Проверены mobile и desktop.

## Аналитика

- GA4 установлен корректно.
- Конверсии настроены.
- Search Console подключена.
- Sitemap отправлен.
- Важные события проверены.
- Даты релиза зафиксированы.

## Мини-шпаргалка

- Перед релизом проверь status, indexability, canonical и sitemap.
- Для frontend проверь rendered HTML.
- Meta должны быть уникальными.
- Performance проверяется на важных шаблонах.
- После релиза нужен мониторинг Search Console.
