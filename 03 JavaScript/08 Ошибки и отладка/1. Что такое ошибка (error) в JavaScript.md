# Что такое ошибка (error) в JavaScript

> [!summary] Коротко
> Ошибка в JavaScript - объект, который описывает проблему в коде или во время выполнения программы.

## Вопрос

Что такое `Error` в JavaScript?

## Определение

Ошибка - это сигнал о том, что программа столкнулась с проблемой. В JavaScript ошибки обычно представлены объектами `Error` или объектами классов-наследников: `TypeError`, `ReferenceError`, `SyntaxError` и другими.

Когда ошибка возникает, движок выбрасывает исключение. Если его не обработать, выполнение текущего сценария прерывается.

## Пример

```javascript
throw new Error('Something went wrong');
```

Так создается и выбрасывается обычная ошибка.

## Свойства Error

```javascript
const error = new Error('Invalid value');

console.log(error.name);    // 'Error'
console.log(error.message); // 'Invalid value'
console.log(error.stack);   // стек вызовов
```

`stack` помогает понять, где именно возникла ошибка.

## Ошибка как объект

```javascript
try {
  JSON.parse('{ broken json }');
} catch (error) {
  console.log(error instanceof Error); // true
  console.log(error.message);
}
```

В `catch` попадает объект ошибки.

## Мини-шпаргалка

```javascript
const error = new Error('Message');
throw error;
```
