# Как подключить TypeORM к NestJS?

> [!summary]
> TypeORM в NestJS подключают через `@nestjs/typeorm`: `TypeOrmModule.forRoot` настраивает connection, а `TypeOrmModule.forFeature` регистрирует repositories для конкретного module.

## Root config

```ts
@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      url: process.env.DATABASE_URL,
      entities: [User],
      synchronize: false,
    }),
  ],
})
export class AppModule {}
```

## Feature module

```ts
@Module({
  imports: [TypeOrmModule.forFeature([User])],
  providers: [UsersService],
})
export class UsersModule {}
```

## Repository injection

```ts
@Injectable()
export class UsersService {
  constructor(
    @InjectRepository(User)
    private readonly usersRepository: Repository<User>,
  ) {}
}
```

## Мини-шпаргалка

- `forRoot` настраивает database connection.
- `forFeature` регистрирует repositories в module.
- `@InjectRepository` внедряет repository.
- `synchronize: true` опасен для production.
- Миграции лучше, чем автоматическая синхронизация схемы.
