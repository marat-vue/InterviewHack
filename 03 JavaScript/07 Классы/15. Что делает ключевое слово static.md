# Что делает ключевое слово static

> [!summary] Коротко
> `static` создает метод или поле, принадлежащее самому классу, а не его экземплярам.

## Вопрос

Что делает `static` внутри класса?

## Определение

Статические методы и свойства вызываются на классе напрямую. Они не доступны как методы экземпляра.

Их используют для утилит, фабричных методов, настроек класса и логики, которая не зависит от конкретного объекта.

## Пример static method

```javascript
class MathHelper {
  static sum(a, b) {
    return a + b;
  }
}

console.log(MathHelper.sum(2, 3)); // 5
```

Метод вызывается на `MathHelper`, а не на объекте `new MathHelper()`.

## Ошибка при вызове на экземпляре

```javascript
const helper = new MathHelper();

helper.sum(2, 3); // TypeError
```

## Static field

```javascript
class User {
  static defaultRole = 'reader';
}

console.log(User.defaultRole); // 'reader'
```

## Фабричный метод

```javascript
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  static guest() {
    return new User('Guest', 'reader');
  }
}

const guest = User.guest();
```

## Мини-шпаргалка

```javascript
class A {
  static method() {}
  static value = 1;
}

A.method();
```
