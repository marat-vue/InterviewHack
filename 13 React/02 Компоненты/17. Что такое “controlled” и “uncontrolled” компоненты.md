# Что такое controlled и uncontrolled компоненты?

> [!summary]
> Controlled component управляется React-состоянием: значение хранится в state и передается в элемент через prop. Uncontrolled component хранит значение внутри DOM, а React читает его через `ref` при необходимости.

## Controlled input

```jsx
function SearchInput() {
  const [query, setQuery] = useState('')

  return (
    <input
      value={query}
      onChange={(event) => setQuery(event.target.value)}
    />
  )
}
```

Значение input полностью контролируется React state.

## Что дает controlled подход?

- Легкая валидация.
- Маски ввода.
- Условная блокировка кнопок.
- Синхронизация нескольких полей.
- Мгновенное отображение ошибок.
- Предсказуемое состояние формы.

## Uncontrolled input

```jsx
function SearchForm() {
  const inputRef = useRef(null)

  function handleSubmit(event) {
    event.preventDefault()
    console.log(inputRef.current.value)
  }

  return (
    <form onSubmit={handleSubmit}>
      <input ref={inputRef} defaultValue="" />
      <button>Найти</button>
    </form>
  )
}
```

Значение хранится в DOM, а React читает его в момент submit.

## value vs defaultValue

| Prop | Подход |
|---|---|
| `value` | controlled |
| `checked` | controlled |
| `defaultValue` | uncontrolled начальное значение |
| `defaultChecked` | uncontrolled начальное значение |

Если передал `value`, нужно обычно передать и `onChange`.

## Что выбрать?

Controlled:

- сложные формы;
- валидация на каждый ввод;
- зависимые поля;
- данные нужны в state.

Uncontrolled:

- простые формы;
- интеграция с DOM-библиотеками;
- чтение значения только при submit;
- file input.

## Мини-шпаргалка

- Controlled = значение хранится в React state.
- Uncontrolled = значение хранится в DOM.
- `value` и `onChange` идут вместе.
- `defaultValue` задает только начальное значение.
- Controlled формы предсказуемее, uncontrolled иногда проще.
