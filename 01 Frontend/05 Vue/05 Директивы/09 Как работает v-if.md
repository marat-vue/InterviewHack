# Как работает v-if?

> [!NOTE]
> `v-if` условно создает или удаляет элемент из DOM. Если условие ложное, элемента в DOM вообще нет.

## Вопрос

Как работает `v-if`?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const isLoggedIn = ref(false);
</script>

<template>
  <p v-if="isLoggedIn">Добро пожаловать</p>
  <button v-else>Войти</button>
</template>
```

Когда `isLoggedIn` меняется, Vue переключает ветку.

## `v-else-if` и `v-else`

```vue
<template>
  <p v-if="status === 'loading'">Загрузка</p>
  <p v-else-if="status === 'error'">Ошибка</p>
  <p v-else>Готово</p>
</template>
```

Ветки должны идти рядом друг с другом.

## Что происходит с компонентом

Если `v-if` скрывает компонент, он размонтируется. При повторном показе создается заново.

```vue
<UserForm v-if="isFormOpen" />
```

Локальное состояние `UserForm` будет потеряно при размонтировании.

## Когда использовать

`v-if` хорош для редких переключений, тяжелых компонентов и случаев, когда элемент не должен существовать в DOM.

## Мини-шпаргалка

- `v-if` создает и удаляет DOM.
- `v-else-if` и `v-else` должны идти сразу после связанной ветки.
- Компонент под `v-if` монтируется и размонтируется.
- Для частого переключения видимости иногда лучше `v-show`.
