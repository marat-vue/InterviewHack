# Что делает тип any

> [!summary] Коротко
> `any` отключает проверку типов для значения и позволяет делать с ним почти все.

## Вопрос

Почему `any` называют "выключателем TypeScript"?

## Определение

`any` говорит компилятору: "не проверяй это значение". Переменной типа `any` можно присвоить что угодно, у нее можно читать любые свойства, вызывать любые методы и передавать куда угодно.

Это удобно при миграции или работе с очень динамическим кодом, но снижает type safety.

## Пример

```typescript
let value: any = 'hello';

value.toUpperCase();
value = 123;
value.missing.deep.call(); // TypeScript не остановит
```

Код может упасть в runtime, но TypeScript не покажет ошибку.

## Почему опасно

```typescript
function formatPrice(price: any) {
  return price.toFixed(2);
}

formatPrice('100'); // TypeScript пропустит, runtime упадет
```

`any` разрушает проверки не только в одном месте, но и дальше по цепочке.

## Лучше unknown

```typescript
function format(value: unknown) {
  if (typeof value === 'number') {
    return value.toFixed(2);
  }

  throw new TypeError('Expected number');
}
```

`unknown` заставляет проверить значение перед использованием.

## Когда any допустим

- временная миграция с JavaScript;
- плохие или отсутствующие типы сторонней библиотеки;
- быстрый прототип;
- точечный workaround с понятным TODO.

## Мини-шпаргалка

```typescript
let unsafe: any;
let safer: unknown;
```
