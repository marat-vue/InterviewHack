# Что такое сегменты маршрута в Next JS?

> [!summary]
> Сегмент маршрута - часть URL, которая соответствует папке внутри `app`. Сегменты бывают статическими, динамическими, catch-all, optional catch-all, route groups, parallel routes и intercepting routes.

## Простое определение

URL:

```text
/dashboard/settings/profile
```

Сегменты:

```text
dashboard
settings
profile
```

Файловая структура:

```text
app/
  dashboard/
    settings/
      profile/
        page.tsx
```

## Основные типы сегментов

| Синтаксис | Пример | URL |
|---|---|---|
| static | `about` | `/about` |
| dynamic | `[id]` | `/products/42` |
| catch-all | `[...slug]` | `/docs/a/b/c` |
| optional catch-all | optional catch-all segment | `/docs` и `/docs/a` |
| route group | `(marketing)` | не добавляется в URL |
| parallel route | `@modal` | слот, не URL |

## Dynamic segment

```text
app/products/[id]/page.tsx
```

```tsx
export default async function ProductPage({ params }: Props) {
  const { id } = await params
  return <h1>{id}</h1>
}
```

## Catch-all segment

```text
app/docs/[...slug]/page.tsx
```

Для URL `/docs/react/server-components`:

```ts
params.slug // ['react', 'server-components']
```

## Route group

```text
app/(auth)/login/page.tsx
```

URL будет `/login`, а `(auth)` нужен только для структуры.

## Что отвечать на собеседовании?

Route segment - это часть route tree, обычно папка внутри `app`. Статические сегменты напрямую попадают в URL, динамические `[id]` дают params, catch-all `[...slug]` собирает несколько сегментов в массив, route groups `(group)` помогают структуре и не влияют на URL.

## Частые ошибки

- Называть query params сегментами маршрута.
- Путать `[slug]` и `[...slug]`.
- Считать route group частью URL.
- Не учитывать, что parallel routes - это slots.
- Делать catch-all там, где достаточно обычного dynamic segment.

## Мини-шпаргалка

- Segment = часть route tree.
- `about` -> static segment.
- `[id]` -> one param.
- `[...slug]` -> array param.
- optional catch-all -> optional array.
- `(group)` -> structure only.
