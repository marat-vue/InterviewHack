# Vite aliases proxy assets и переменные окружения

> [!summary]
> В рабочих проектах Vite часто настраивают path aliases, API proxy, работу со static assets и env variables. Важно помнить: клиентские переменные окружения должны начинаться с `VITE_`.

## Aliases

```ts
import path from 'node:path'
import { defineConfig } from 'vite'

export default defineConfig({
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

Использование:

```tsx
import { Button } from '@/shared/ui/Button'
```

Для TypeScript нужно синхронизировать alias в `tsconfig`.

## Env variables

`.env`:

```env
VITE_API_URL=https://api.example.com
```

Использование:

```ts
const apiUrl = import.meta.env.VITE_API_URL
```

Важно: в клиентский код попадают только переменные с prefix `VITE_`.

## Built-in env

```ts
if (import.meta.env.DEV) {
  console.log('development')
}

if (import.meta.env.PROD) {
  console.log('production')
}
```

Частые поля:

- `import.meta.env.DEV`;
- `import.meta.env.PROD`;
- `import.meta.env.MODE`;
- `import.meta.env.BASE_URL`.

## Proxy

```ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
      },
    },
  },
})
```

Теперь запрос:

```ts
fetch('/api/users')
```

в dev может проксироваться на backend.

## Assets

```tsx
import logoUrl from './logo.svg'

function Header() {
  return <img src={logoUrl} alt="Logo" />
}
```

Для файлов из `public`:

```tsx
<img src="/favicon.svg" alt="" />
```

`public` подходит для файлов, которые должны быть доступны по стабильному URL.

## Что отвечать на собеседовании?

В Vite aliases настраиваются через `resolve.alias`, env variables читаются через `import.meta.env`, клиентские env должны иметь prefix `VITE_`, dev proxy задается в `server.proxy`, а assets можно импортировать как modules или хранить в `public`.

## Мини-шпаргалка

- Alias: `resolve.alias`.
- TS alias нужно продублировать в `tsconfig`.
- Client env: только `VITE_*`.
- Dev flags: `import.meta.env.DEV`.
- Proxy: `server.proxy`.
- Assets: import или `public`.
