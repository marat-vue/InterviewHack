# Как создать Nitro проект и подключить к Vite?

> [!NOTE]
> Nitro можно создать как отдельное приложение через `create-nitro-app` или добавить в существующий Vite-проект через `nitro/vite`. В Nuxt отдельно ставить Nitro обычно не нужно: он уже является server engine Nuxt.

## Как создать новый Nitro-проект?

Через npm:

```bash
npx create-nitro-app
```

Через pnpm:

```bash
pnpm dlx create-nitro-app
```

Через bun:

```bash
bunx create-nitro-app
```

CLI создаст проект, scripts и базовую структуру. После этого обычно запускают dev server:

```bash
npm run dev
```

## Как добавить Nitro в существующий Vite-проект?

Установи зависимости:

```bash
npm i nitro vite
```

Подключи Nitro plugin:

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import { nitro } from 'nitro/vite';

export default defineConfig({
  plugins: [
    nitro(),
  ],
});
```

Создай `nitro.config.ts`:

```ts
// nitro.config.ts
import { defineConfig } from 'nitro';

export default defineConfig({
  serverDir: './server',
});
```

Теперь Nitro будет искать routes, middleware, plugins и другие server-файлы внутри `server/`.

## Как создать первый endpoint?

```ts
// server/routes/api/test.ts
import { defineHandler } from 'nitro';

export default defineHandler(() => {
  return {
    message: 'Hello Nitro!',
  };
});
```

Файл `server/routes/api/test.ts` станет URL:

```txt
/api/test
```

## Как это выглядит в Nuxt?

В Nuxt Nitro уже включен:

```ts
// server/api/test.ts
export default defineEventHandler(() => {
  return {
    message: 'Hello from Nuxt server API',
  };
});
```

URL:

```txt
/api/test
```

## Какие scripts нужны?

Минимально:

```json
{
  "scripts": {
    "dev": "nitro dev",
    "build": "nitro build",
    "preview": "nitro preview"
  }
}
```

В Nuxt:

```json
{
  "scripts": {
    "dev": "nuxt dev",
    "build": "nuxt build",
    "preview": "nuxt preview"
  }
}
```

## Где настраивать Nitro?

В standalone Nitro:

```txt
nitro.config.ts
```

В Nuxt:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    routeRules: {
      '/api/**': {
        cors: true,
      },
    },
  },
});
```

## Мини-шпаргалка

- Новый проект: `npx create-nitro-app`.
- Existing Vite: `npm i nitro vite` и `nitro()` в `vite.config.ts`.
- Server directory задается через `serverDir`.
- В standalone routes обычно лежат в `server/routes`.
- В Nuxt API routes обычно лежат в `server/api`.
- Для Nuxt отдельный `nitro` пакет руками чаще не нужен.
