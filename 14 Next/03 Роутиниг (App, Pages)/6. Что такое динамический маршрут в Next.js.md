# Что такое динамический маршрут в Next.js?

> [!summary]
> Динамический маршрут - route, где часть URL является параметром. В App Router такой сегмент создается папкой в квадратных скобках, например `[slug]`, а значение доступно через `params`.

## Как создать dynamic route?

```text
app/
  blog/
    [slug]/
      page.tsx
```

Этот route обработает:

```text
/blog/next-js
/blog/react-server-components
/blog/seo-guide
```

## Как получить params в Server Component?

В актуальном App Router `params` может быть Promise:

```tsx
type Props = {
  params: Promise<{ slug: string }>
}

export default async function BlogPostPage({ params }: Props) {
  const { slug } = await params
  const post = await getPost(slug)

  return <Article post={post} />
}
```

В старых примерах можно встретить синхронный `params`. На собеседовании лучше пояснять идею, а синтаксис сверять с версией Next.js.

## Как получить params в Client Component?

```tsx
'use client'

import { useParams } from 'next/navigation'

export function BlogPostClientInfo() {
  const params = useParams<{ slug: string }>()

  return <p>{params.slug}</p>
}
```

## Несколько параметров

```text
app/
  shops/
    [shopId]/
      products/
        [productId]/
          page.tsx
```

Params:

```ts
{
  shopId: '77',
  productId: '42'
}
```

## Что отвечать на собеседовании?

Dynamic route в Next.js создается папкой `[param]`. Значение параметра доступно в `params` у Server Component или через `useParams` в Client Component. Dynamic routes используют для постов, товаров, профилей, заказов и любых страниц, где URL зависит от данных.

## Частые ошибки

- Использовать `useParams` в Server Component.
- Забывать валидировать `params`.
- Не вызывать `notFound()` при отсутствии ресурса.
- Путать path params и search params.
- Делать dynamic route для состояния, которое лучше хранить в query string.

## Мини-шпаргалка

- `[slug]` - dynamic segment.
- Server Component получает `params`.
- Client Component использует `useParams`.
- Для отсутствующего ресурса вызывай `notFound()`.
- Для SSG dynamic routes есть `generateStaticParams`.
