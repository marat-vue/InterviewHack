# Что делает toSorted()

> [!summary] Коротко
> `toSorted()` возвращает новый отсортированный массив и не меняет исходный.

## Вопрос

Как отсортировать массив без мутации оригинала?

## Определение

`toSorted()` - немутирующая версия `sort()`. Метод копирует массив, сортирует копию и возвращает ее как результат.

Если не передать функцию сравнения, элементы сортируются как строки. Для чисел почти всегда нужна функция `(a, b) => a - b`.

## Пример с числами

```javascript
const numbers = [10, 2, 5, 1];

const sorted = numbers.toSorted((a, b) => a - b);

console.log(sorted);  // [1, 2, 5, 10]
console.log(numbers); // [10, 2, 5, 1]
```

## Почему compareFn важна

```javascript
console.log([10, 2, 5].toSorted()); // [10, 2, 5]
```

Без функции сравнения JavaScript приводит элементы к строкам: `"10"` идет раньше `"2"`.

## Сравнение с sort()

```javascript
const values = [3, 1, 2];

values.sort((a, b) => a - b);

console.log(values); // [1, 2, 3] - массив изменен
```

`sort()` мутирует исходный массив, `toSorted()` - нет.

## Мини-шпаргалка

```javascript
arr.toSorted();                 // сортировка как строк
arr.toSorted((a, b) => a - b);   // числа по возрастанию
arr.toSorted((a, b) => b - a);   // числа по убыванию
```
