# Что такое type guard

> [!summary] Коротко
> Type guard - это проверка, после которой TypeScript сужает тип значения. Guard может быть встроенным условием или пользовательской функцией с предикатом `value is Type`.

## Вопрос

Что такое `type guard`?

## Встроенный guard

```typescript
function format(value: string | number): string {
  if (typeof value === "string") {
    return value.trim();
  }

  return value.toFixed(2);
}
```

`typeof value === "string"` выступает guard-ом.

## Пользовательский type guard

```typescript
type Admin = {
  role: "admin";
  permissions: string[];
};

type User = {
  role: "user";
  name: string;
};

function isAdmin(person: Admin | User): person is Admin {
  return person.role === "admin";
}

function render(person: Admin | User) {
  if (isAdmin(person)) {
    console.log(person.permissions);
  }
}
```

Возвращаемый тип `person is Admin` сообщает TypeScript, как сузить переменную при `true`.

## Guard для unknown

```typescript
function isStringArray(value: unknown): value is string[] {
  return Array.isArray(value) && value.every((item) => typeof item === "string");
}
```

## Мини-шпаргалка

- Type guard - проверка, которая уточняет тип.
- Встроенные guard-ы: `typeof`, `instanceof`, `in`.
- Пользовательский guard: `value is Type`.
- Guard особенно полезен для `unknown` и данных из API.
