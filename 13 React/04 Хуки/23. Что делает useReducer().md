# Что делает useReducer?

> [!summary]
> `useReducer` хранит состояние через reducer-функцию. Компонент отправляет actions через `dispatch`, reducer получает текущее state и action, а затем возвращает новое state. Это удобно для сложной логики обновлений.

## Базовый синтаксис

```jsx
const [state, dispatch] = useReducer(reducer, initialState)
```

Reducer:

```jsx
function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 }
    case 'decrement':
      return { count: state.count - 1 }
    default:
      return state
  }
}
```

Компонент:

```jsx
function Counter() {
  const [state, dispatch] = useReducer(reducer, { count: 0 })

  return (
    <>
      <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
      <span>{state.count}</span>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
    </>
  )
}
```

## Что такое action?

Action описывает, что произошло:

```jsx
dispatch({ type: 'fieldChanged', field: 'email', value: 'a@mail.com' })
```

Reducer решает, как это событие изменит state.

## Почему reducer должен быть чистым?

Reducer должен:

- принимать `state` и `action`;
- возвращать новый state;
- не мутировать старый state;
- не делать запросы;
- не писать в localStorage;
- не вызывать случайные side effects.

Плохо:

```jsx
function reducer(state, action) {
  state.count++
  return state
}
```

Правильно:

```jsx
return { ...state, count: state.count + 1 }
```

## Когда useReducer особенно удобен?

- сложные формы;
- wizard-flow;
- список действий;
- несколько связанных полей;
- состояние с переходами;
- нужна тестируемая логика.

## Мини-шпаргалка

- `useReducer` возвращает `[state, dispatch]`.
- `dispatch(action)` отправляет событие.
- `reducer(state, action)` возвращает новый state.
- Reducer должен быть чистым.
- `useReducer` полезен для сложной логики обновлений.
