# Что такое structured data и Schema.org?

> [!summary]
> Structured data - это машинно-читаемое описание сущностей на странице: статьи, товара, организации, хлебных крошек, видео, FAQ и других объектов. Schema.org дает словарь, а поисковые системы используют его для лучшего понимания страницы и возможных rich results.

## Зачем нужны structured data?

Structured data помогают явно сказать:

```text
Это статья. У нее есть автор, дата публикации, заголовок и изображение.
```

Или:

```text
Это товар. У него есть цена, валюта, наличие и отзывы.
```

Без structured data поисковик тоже анализирует страницу, но разметка снижает неоднозначность.

## Что такое Schema.org?

Schema.org - общий словарь типов и свойств:

- `Organization`;
- `WebSite`;
- `BreadcrumbList`;
- `Article`;
- `Product`;
- `Review`;
- `VideoObject`;
- `FAQPage`;
- `LocalBusiness`.

## Какие форматы бывают?

Чаще всего используют JSON-LD:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Example",
  "url": "https://example.com"
}
</script>
```

Также существуют Microdata и RDFa, но JSON-LD обычно удобнее для современных приложений.

## Structured data гарантируют rich results?

Нет. Разметка делает страницу eligible, то есть потенциально подходящей, но поисковик сам решает, показывать ли расширенный результат.

Нужно соблюдать:

- правила поисковой системы;
- соответствие видимому контенту;
- корректный JSON;
- актуальность данных;
- отсутствие спама.

## Мини-шпаргалка

- Structured data описывают сущности на странице.
- Schema.org - словарь типов и свойств.
- JSON-LD - самый удобный формат для большинства проектов.
- Rich result не гарантирован.
- Разметка должна соответствовать видимому содержимому страницы.
