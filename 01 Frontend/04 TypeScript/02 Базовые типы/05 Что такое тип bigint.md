# Что такое тип bigint?

> [!NOTE] Коротко
> `bigint` описывает целые числа произвольной длины, которые могут быть больше безопасного диапазона `number`.

## Вопрос

Когда использовать тип `bigint`?

## Определение

`bigint` - примитивный тип JavaScript для больших целых чисел. Значение `bigint` создают с суффиксом `n` или через функцию `BigInt()`.

## Пример

```typescript
const id: bigint = 9007199254740993n;
const alsoId: bigint = BigInt('9007199254740993');
```

`number` не может безопасно представлять все большие целые числа, а `bigint` может.

## Ошибка смешивания

```typescript
const a = 10n;
const b = 5;

// a + b; // ошибка: bigint и number нельзя смешивать
```

Нужно явно привести типы.

```typescript
const result = a + BigInt(b);
```

## Где используется

- большие идентификаторы;
- криптография;
- финансовые расчеты с целыми единицами;
- низкоуровневые API;
- работа с большими счетчиками.

## Ограничения

`bigint` нельзя использовать с `Math` API напрямую.

```typescript
// Math.max(1n, 2n); // ошибка
```

## Мини-шпаргалка

```typescript
const value: bigint = 123n;
const fromString = BigInt('123');
```
