# Типизация параметров в функции

> [!summary] Коротко
> Параметры функции типизируются после имени параметра через двоеточие: `name: string`. Так TypeScript понимает, какие значения функция умеет принимать.

## Вопрос

Как объявить функцию с типами параметров?

## Базовый синтаксис

```typescript
function createUser(name: string, age: number): User {
  return { name, age };
}
```

Типы параметров проверяются при каждом вызове.

```typescript
createUser("Анна", 28);
// createUser("Анна", "28"); // ошибка
```

## Опциональные и дефолтные параметры

```typescript
function greet(name: string, title?: string): string {
  return title ? `${title} ${name}` : name;
}

function paginate(page = 1, pageSize = 20): string {
  return `page=${page}&pageSize=${pageSize}`;
}
```

`?` означает "может отсутствовать". Параметр со значением по умолчанию получает тип из этого значения.

## Объекты и массивы

```typescript
type UserInput = {
  email: string;
  password: string;
};

function register(input: UserInput, roles: string[]): void {
  console.log(input.email, roles);
}
```

## Callback как параметр

```typescript
function filterUsers(
  users: User[],
  predicate: (user: User) => boolean
): User[] {
  return users.filter(predicate);
}
```

## Мини-шпаргалка

- `param: Type` - тип параметра.
- `param?: Type` - параметр можно не передавать.
- `param = value` - тип обычно выводится из `value`.
- Callback типизируется как `(arg: T) => R`.
