# Для чего используется v-cloak?

> [!NOTE] Коротко
> `v-cloak` помогает скрыть нескомпилированный шаблон до того, как Vue смонтирует приложение. Чаще полезен при подключении Vue без сборщика.

## Вопрос

Для чего используется `v-cloak`?

## Проблема

Если Vue подключен через CDN, пользователь может на мгновение увидеть сырые mustache-выражения.

```html
<div id="app">
  {{ message }}
</div>
```

До монтирования Vue браузер может показать `{{ message }}` как обычный текст.

## Решение

```html
<style>
  [v-cloak] {
    display: none;
  }
</style>

<div id="app" v-cloak>
  {{ message }}
</div>
```

Vue удалит атрибут `v-cloak` после монтирования, и приложение станет видно.

## Когда нужно

В современных проектах на Vite и SFC `v-cloak` обычно не нужен. Он полезнее в страницах, где Vue оживляет серверный HTML или подключается напрямую через script.

## Мини-шпаргалка

- `v-cloak` скрывает шаблон до монтирования Vue.
- Нужен CSS `[v-cloak] { display: none; }`.
- После mount Vue удаляет атрибут.
- В SFC/Vite проектах применяется редко.
