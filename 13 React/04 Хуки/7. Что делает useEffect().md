# Что делает useEffect?

> [!summary]
> `useEffect` - хук для синхронизации компонента с внешними системами: сетью, DOM API, subscriptions, таймерами, localStorage, аналитикой. Если ты не синхронизируешься с внешним миром, эффект, возможно, не нужен.

## Базовый пример

```jsx
import { useEffect } from 'react'

function PageTitle({ title }) {
  useEffect(() => {
    document.title = title
  }, [title])

  return <h1>{title}</h1>
}
```

После commit React выполнит effect и синхронизирует `document.title` с prop `title`.

## Когда useEffect нужен?

`useEffect` подходит для:

- запросов к API;
- подписок;
- таймеров;
- работы с `localStorage`;
- синхронизации с non-React widget;
- аналитики;
- изменения `document.title`;
- подписки на browser events.

Пример подписки:

```jsx
useEffect(() => {
  function handleResize() {
    setWidth(window.innerWidth)
  }

  window.addEventListener('resize', handleResize)
  return () => window.removeEventListener('resize', handleResize)
}, [])
```

## Когда useEffect не нужен?

Не нужен effect для вычислений, которые можно сделать во время render:

```jsx
const fullName = `${firstName} ${lastName}`
```

Не нужен effect для обработки пользовательского события, если код можно выполнить прямо в handler:

```jsx
function handleClick() {
  sendAnalytics('button_click')
}
```

## Как работает cleanup?

Effect может вернуть функцию очистки:

```jsx
useEffect(() => {
  const connection = createConnection(roomId)
  connection.connect()

  return () => {
    connection.disconnect()
  }
}, [roomId])
```

React выполнит cleanup перед следующим effect с новыми зависимостями и при размонтировании компонента.

## Частые ошибки

- Использовать effect для derived state.
- Не указывать зависимости.
- Создавать бесконечный цикл обновлений.
- Забывать cleanup для подписок и таймеров.
- Делать effect слишком большим.

## Мини-шпаргалка

- `useEffect` синхронизирует компонент с внешней системой.
- Effect выполняется после commit.
- Dependencies описывают reactive values, от которых зависит effect.
- Cleanup чистит подписки, таймеры и соединения.
- Если внешней системы нет, effect часто не нужен.
