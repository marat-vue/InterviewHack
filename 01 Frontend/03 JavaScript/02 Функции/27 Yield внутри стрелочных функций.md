# `yield` внутри стрелочных функций

> [!NOTE]
> `yield` нельзя использовать внутри стрелочной функции. Он разрешен только внутри генераторной функции `function*`.

## Вопрос

Можно ли использовать `yield` внутри стрелочной функции?

## Короткий ответ

Нельзя.

```javascript
const gen = () => {
  yield 1; // SyntaxError
};
```

Стрелочных генераторов в JavaScript нет.

## Правильный вариант

```javascript
function* gen() {
  yield 1;
  yield 2;
}

[...gen()]; // [1, 2]
```

Генератор объявляется через `function*`.

## Почему так

Стрелочные функции специально сделаны как компактный синтаксис для обычных функций/callback. У них нет некоторых возможностей обычных функций:

- нет собственного `this`;
- нет собственного `arguments`;
- нет `prototype`;
- нельзя вызвать через `new`;
- нельзя сделать `function*`-аналог со стрелкой.

## Можно ли использовать arrow внутри генератора

Да, если `yield` находится не внутри стрелочной функции.

```javascript
function* gen(numbers) {
  const double = (value) => value * 2;

  for (const number of numbers) {
    yield double(number);
  }
}

[...gen([1, 2, 3])]; // [2, 4, 6]
```

## Подводный пример

```javascript
function* gen() {
  const fn = () => {
    yield 1; // SyntaxError
  };
}
```

Даже если стрелочная функция находится внутри генератора, `yield` внутри нее запрещен.

## Мини-шпаргалка

| Код | Можно? |
| --- | --- |
| `function* gen() { yield 1; }` | да |
| `const gen = function* () { yield 1; }` | да |
| `const gen = () => { yield 1; }` | нет |
| `function* gen() { const f = () => 1; }` | да |
