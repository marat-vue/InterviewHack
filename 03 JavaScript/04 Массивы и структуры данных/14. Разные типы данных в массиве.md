# Разные типы данных в массиве

> [!summary] Коротко
> JavaScript-массивы не типизированы: один массив может хранить числа, строки, объекты, функции, другие массивы и любые другие значения.

## Вопрос

Можно ли хранить разные типы данных в одном массиве?

## Пример

```javascript
const mixed = [
  42,
  "hello",
  true,
  null,
  { name: "Anna" },
  [1, 2, 3],
  () => "JS",
];
```

Это валидный JavaScript.

## Почему так

JavaScript динамически типизирован. Тип принадлежит значению, а не контейнеру.

```javascript
let value = 1;
value = "text";
```

Массив тоже может хранить разные значения.

## Когда это нормально

Иногда смешанные массивы осознанны:

```javascript
const entry = ["name", "Anna"];
```

Например, `Object.entries()` возвращает массив пар `[key, value]`, где типы могут отличаться.

## Когда лучше избегать

Для списков однотипных сущностей лучше держать одинаковую структуру.

```javascript
const users = [
  { id: 1, name: "Anna" },
  { id: 2, name: "Max" },
];
```

Так проще читать, фильтровать, типизировать и поддерживать код.

## TypeScript

В TypeScript можно явно описывать смешанные массивы:

```typescript
const tuple: [string, number] = ["age", 25];
```

Но обычные массивы чаще делают однотипными:

```typescript
const numbers: number[] = [1, 2, 3];
```

## Мини-шпаргалка

| Вопрос | Ответ |
| --- | --- |
| Можно смешивать типы? | да |
| Хорошо ли всегда так делать? | нет |
| Для списков сущностей | лучше одинаковая структура |
| Для пар/tuple | смешение может быть нормальным |
