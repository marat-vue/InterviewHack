# Как обновить элемент массива в состоянии?

> [!summary]
> Массив в state нельзя менять напрямую. Чтобы добавить, удалить или изменить элемент, нужно создать новый массив через spread, `map`, `filter`, `slice` или копию перед сортировкой.

## Добавление элемента

```jsx
const [todos, setTodos] = useState([])

function addTodo(title) {
  const newTodo = {
    id: crypto.randomUUID(),
    title,
    done: false,
  }

  setTodos((todos) => [...todos, newTodo])
}
```

Не используй:

```jsx
todos.push(newTodo)
setTodos(todos)
```

## Удаление элемента

```jsx
function removeTodo(id) {
  setTodos((todos) => todos.filter((todo) => todo.id !== id))
}
```

`filter` возвращает новый массив.

## Обновление одного элемента

```jsx
function toggleTodo(id) {
  setTodos((todos) =>
    todos.map((todo) =>
      todo.id === id
        ? { ...todo, done: !todo.done }
        : todo
    )
  )
}
```

Мы создаем:

- новый массив;
- новый объект только для измененного элемента;
- старые объекты для неизмененных элементов.

## Замена элемента по индексу

Если id нет, но индекс действительно надежен:

```jsx
setItems((items) =>
  items.map((item, index) =>
    index === targetIndex ? newItem : item
  )
)
```

Но для списков с изменяемым порядком лучше иметь стабильный `id`.

## Сортировка

`sort` мутирует массив, поэтому сначала копируй:

```jsx
setUsers((users) =>
  [...users].sort((a, b) => a.name.localeCompare(b.name))
)
```

## Мини-шпаргалка

- Добавление: `[...items, item]`.
- Удаление: `filter`.
- Обновление: `map`.
- Сортировка: сначала копия, потом `sort`.
- Для элементов списка лучше иметь стабильный `id`.
