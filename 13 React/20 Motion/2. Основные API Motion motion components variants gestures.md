# Основные API Motion motion components variants gestures

> [!summary]
> Основные API Motion - `motion` components, animation props, `transition`, variants, gesture props и drag. Они позволяют описывать повторяемые состояния и интерактивные micro-interactions декларативно.

## motion components

```tsx
<motion.div />
<motion.button />
<motion.svg />
<motion.path />
```

Motion поддерживает HTML и SVG элементы.

## Animation props

```tsx
<motion.div
  initial={{ opacity: 0 }}
  animate={{ opacity: 1 }}
  exit={{ opacity: 0 }}
/>
```

| Prop | Зачем нужен |
|---|---|
| `initial` | стартовое состояние |
| `animate` | целевое состояние |
| `exit` | состояние при удалении |
| `transition` | настройки движения |
| `style` | обычные стили и motion values |

## Variants

Variants позволяют назвать состояния:

```tsx
const cardVariants = {
  hidden: { opacity: 0, y: 12 },
  visible: { opacity: 1, y: 0 },
}

function Card() {
  return (
    <motion.article
      variants={cardVariants}
      initial="hidden"
      animate="visible"
    />
  )
}
```

## Stagger children

```tsx
const listVariants = {
  hidden: {},
  visible: {
    transition: {
      staggerChildren: 0.06,
    },
  },
}

const itemVariants = {
  hidden: { opacity: 0, y: 8 },
  visible: { opacity: 1, y: 0 },
}

function List({ items }: Props) {
  return (
    <motion.ul variants={listVariants} initial="hidden" animate="visible">
      {items.map((item) => (
        <motion.li key={item.id} variants={itemVariants}>
          {item.title}
        </motion.li>
      ))}
    </motion.ul>
  )
}
```

## Gestures

```tsx
<motion.button
  whileHover={{ scale: 1.03 }}
  whileTap={{ scale: 0.97 }}
>
  Click
</motion.button>
```

Частые gesture props:

- `whileHover`;
- `whileTap`;
- `whileFocus`;
- `whileInView`;
- `drag`.

## Drag

```tsx
<motion.div
  drag
  dragConstraints={{ left: 0, right: 300, top: 0, bottom: 200 }}
/>
```

Для drag-интерфейсов важно думать не только об анимации, но и о доступности keyboard/touch.

## Что отвечать на собеседовании?

Motion components расширяют обычные DOM/SVG элементы animation props. Variants нужны, чтобы переиспользовать named states и синхронизировать parent/children animations. Gesture props позволяют описывать hover, tap, focus, in-view и drag состояния без ручного управления DOM.

## Мини-шпаргалка

- `motion.div` расширяет div.
- `variants` - именованные состояния.
- `staggerChildren` - каскадная анимация.
- `whileHover` и `whileTap` - micro-interactions.
- `drag` - перетаскивание.
- Для сложного UI думай об accessibility.
