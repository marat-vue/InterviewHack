# Как Vue отслеживает изменения данных

> [!summary] Коротко
> Vue 3 отслеживает изменения через Proxy для объектов и getter/setter-обертку у `ref`. При чтении Vue собирает зависимость, при записи уведомляет эффекты.

## Вопрос

Как Vue отслеживает изменения данных?

## Track и trigger

Реактивность можно представить как две операции:

- `track` - запомнить, кто прочитал значение.
- `trigger` - уведомить зависимых, когда значение изменилось.

```typescript
import { reactive, effect } from "vue";

const state = reactive({ count: 0 });

effect(() => {
  console.log(state.count);
});

state.count++; // эффект запустится снова
```

В прикладном коде `effect` обычно скрыт внутри рендера, `computed` и `watch`.

## Proxy для объектов

```typescript
import { reactive } from "vue";

const user = reactive({ name: "Анна" });

user.name = "Мария";
```

Proxy перехватывает чтение `user.name` и запись нового значения.

## Ref для одиночных значений

```typescript
import { ref } from "vue";

const count = ref(0);
count.value++;
```

У `ref` реактивность завязана на свойство `.value`.

## Мини-шпаргалка

- При чтении Vue собирает зависимость.
- При записи Vue запускает зависимые обновления.
- `reactive` использует Proxy.
- `ref` хранит значение в `.value`.
- Рендер компонента тоже является реактивным эффектом.
