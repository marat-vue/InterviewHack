# Что такое definition список?

> [!NOTE]
> Definition list создается тегом `<dl>` и используется для пар "термин - описание": словари, характеристики, FAQ, метаданные и расшифровки понятий.

## Главное

```html
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки для описания структуры веб-страницы.</dd>

  <dt>CSS</dt>
  <dd>Язык стилей для оформления веб-страницы.</dd>
</dl>
```

`dt` задает термин, а `dd` - описание.

## Когда использовать dl

- Глоссарий.
- Характеристики товара.
- FAQ в формате вопрос-ответ.
- Метаданные профиля.
- Список параметров и значений.

```html
<dl>
  <dt>Автор</dt>
  <dd>Анна Иванова</dd>

  <dt>Дата публикации</dt>
  <dd><time datetime="2026-08-03">3 августа 2026</time></dd>
</dl>
```

## Несколько описаний

У одного термина может быть несколько `dd`.

```html
<dl>
  <dt>JavaScript</dt>
  <dd>Язык программирования для веба.</dd>
  <dd>Может выполняться в браузере и на сервере.</dd>
</dl>
```

## Несколько терминов для одного описания

```html
<dl>
  <dt>JS</dt>
  <dt>JavaScript</dt>
  <dd>Язык программирования для интерактивности веб-страниц.</dd>
</dl>
```

## Мини-шпаргалка

- `dl` - description list.
- `dt` - термин.
- `dd` - описание.
- Подходит для пар "ключ - значение".
- Может содержать несколько `dt` или несколько `dd`.
- Для обычного перечисления лучше `ul` или `ol`.
