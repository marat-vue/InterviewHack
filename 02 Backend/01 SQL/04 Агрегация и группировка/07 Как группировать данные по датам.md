# Как группировать данные по датам?

> [!NOTE]
> Для отчетов часто нужно группировать события по дням, неделям или месяцам. В SQL это делают функциями конкретной СУБД: например, `date_trunc` в PostgreSQL или форматированием даты в других диалектах.

## PostgreSQL date_trunc

```sql
SELECT
  date_trunc('day', created_at) AS day,
  COUNT(*) AS orders_count
FROM orders
GROUP BY date_trunc('day', created_at)
ORDER BY day;
```

## По месяцам

```sql
SELECT
  date_trunc('month', created_at) AS month,
  SUM(total) AS revenue
FROM orders
WHERE created_at >= DATE '2026-01-01'
GROUP BY date_trunc('month', created_at)
ORDER BY month;
```

## Важный нюанс с timezone

Если бизнес-день зависит от timezone пользователя или компании, нельзя бездумно группировать UTC timestamp. Нужно явно договориться, в какой timezone строится отчет.

## Производительность

Функция вокруг колонки может мешать обычному индексу.

```sql
WHERE date_trunc('day', created_at) = DATE '2026-08-01'
```

Для фильтра чаще лучше диапазон:

```sql
WHERE created_at >= TIMESTAMP '2026-08-01'
  AND created_at < TIMESTAMP '2026-08-02'
```

## Мини-шпаргалка

- Для отчетов по датам используют функции даты.
- В PostgreSQL популярен `date_trunc`.
- Для фильтрации timestamp лучше полуоткрытые интервалы.
- Timezone влияет на бизнес-даты.
- Для частых отчетов могут понадобиться expression index или materialized view.
