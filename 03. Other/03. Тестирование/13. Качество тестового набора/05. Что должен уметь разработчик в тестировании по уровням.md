# Что должен уметь разработчик в тестировании по уровням?

> [!summary]
> Освоение тестирования можно разложить по уровням. Junior должен понимать базовые виды тестов и писать простые unit/component tests. Middle умеет выбирать стратегию, мокать зависимости и тестировать integration scenarios. Senior проектирует надежный тестовый набор, CI, contracts и качество на уровне системы.

## Junior

Должен уметь:

- объяснить unit/integration/e2e;
- написать простой тест функции;
- написать простой тест Vue-компонента;
- использовать `describe`, `test`, `expect`;
- проверить form input и click;
- понять, почему тест упал;
- не писать `expect(true).toBe(true)`.

## Middle

Должен уметь:

- выбирать уровень теста;
- использовать mocks/spies/stubs/fakes;
- тестировать async code;
- подключать Vitest/Jest;
- тестировать router/store/forms;
- мокать API через MSW;
- писать backend endpoint tests;
- работать с тестовой БД;
- расследовать flaky tests;
- настраивать базовый CI.

## Senior

Должен уметь:

- проектировать test strategy;
- выстраивать testing pyramid под продукт;
- определять risk based testing;
- организовывать test data management;
- внедрять contract tests;
- разделять smoke/full e2e suites;
- оптимизировать скорость CI;
- договариваться о quality gates;
- обучать команду хорошим testing practices.

## Как понять, что ты готов к собеседованию?

Ты готов, если можешь без заучивания объяснить:

- что именно ты тестируешь;
- почему выбрал этот уровень;
- что замокал и почему;
- какие edge cases важны;
- как тест ведет себя в CI;
- почему тест не должен быть flaky;
- что будет, если API изменится.

## Мини-шпаргалка

- Junior пишет базовые тесты.
- Middle выбирает инструменты и покрывает реальные сценарии.
- Senior строит стратегию качества.
- На интервью важна аргументация, а не только синтаксис.
- Хорошее тестирование начинается с понимания риска.
