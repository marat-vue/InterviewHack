# Что такое “pure function component”?

> [!summary]
> Pure function component - это компонент, который при одинаковых props, state и context возвращает одинаковый JSX и не выполняет побочные эффекты во время render. Такой компонент легче понимать, тестировать и оптимизировать.

## Что значит "чистый"?

Чистая функция:

- не меняет внешние переменные;
- не мутирует входные данные;
- не делает запросы;
- не пишет в DOM;
- не запускает таймеры;
- возвращает одинаковый результат при одинаковом входе.

Для React это особенно важно, потому что render может быть вызван несколько раз, прерван или повторен в development Strict Mode.

## Чистый компонент

```jsx
function Greeting({ name }) {
  return <h1>Hello, {name}</h1>
}
```

При `name="Ada"` компонент всегда возвращает один и тот же UI.

## Нечистый компонент

```jsx
let renderCount = 0

function Greeting({ name }) {
  renderCount += 1
  localStorage.setItem('lastName', name)

  return <h1>Hello, {name}</h1>
}
```

Проблемы:

- render меняет внешнюю переменную;
- render пишет в `localStorage`;
- повторный render выполнит side effect еще раз;
- в Strict Mode это проявится быстрее.

## Куда деть side effects?

В event handlers:

```jsx
function SaveButton({ user }) {
  function handleClick() {
    localStorage.setItem('user', JSON.stringify(user))
  }

  return <button onClick={handleClick}>Save</button>
}
```

Или в `useEffect`, если нужно синхронизироваться с внешней системой:

```jsx
function Page({ title }) {
  useEffect(() => {
    document.title = title
  }, [title])

  return <h1>{title}</h1>
}
```

## Хуки делают компонент нечистым?

Нет. `useState`, `useMemo`, `useCallback`, `useEffect` сами по себе не делают компонент плохим.

Важно, чтобы тело render оставалось чистым:

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

## Мини-шпаргалка

- Чистый компонент не делает side effects в render.
- Одинаковые входные данные дают одинаковый JSX.
- Не мутируй props, state и внешние объекты.
- Side effects выноси в event handlers или effects.
- Чистота render важна для Concurrent Rendering и Strict Mode.
