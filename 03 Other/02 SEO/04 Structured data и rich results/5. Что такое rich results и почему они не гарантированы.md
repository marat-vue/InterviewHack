# Что такое rich results и почему они не гарантированы?

> [!summary]
> Rich results - это расширенные результаты в поиске: хлебные крошки, рейтинг, товарная информация, видео, события и другие элементы. Structured data помогают претендовать на них, но не гарантируют показ.

## Что может быть rich result?

Примеры:

- breadcrumbs;
- product snippets;
- reviews;
- videos;
- recipes;
- events;
- job postings;
- FAQ;
- sitelinks search box.

Набор поддерживаемых возможностей зависит от поисковой системы и типа контента.

## Почему нет гарантии?

Поисковик может не показать rich result, даже если разметка валидна.

Причины:

- страница не соответствует правилам;
- поисковик не доверяет данным;
- результат не нужен для конкретного запроса;
- качество сайта недостаточно;
- разметка не совпадает с видимым контентом;
- rich result для этого типа страницы не поддерживается в регионе или выдаче.

## Что значит eligible?

`Eligible` означает "страница технически может получить rich result".

Это не означает:

```text
валидная разметка = гарантированный расширенный сниппет
```

## Как повысить шанс?

- Использовать подходящий тип Schema.org.
- Следовать документации поисковой системы.
- Показывать размеченные данные на странице.
- Держать данные актуальными.
- Улучшать качество контента.
- Не использовать спам-разметку.

## Мини-шпаргалка

- Rich result - расширенное отображение в выдаче.
- Structured data дают право претендовать, но не гарантию.
- Разметка должна быть честной и видимой.
- Валидность JSON-LD - только первый шаг.
- Качество страницы и соответствие запросу тоже важны.
