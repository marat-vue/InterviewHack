# Что делает meta name="description" content="..."

> [!summary]
> `<meta name="description">` задает краткое описание страницы. Поисковые системы могут использовать его как сниппет в результатах поиска, а разработчики - как понятное резюме содержания документа.

## Главное

```html
<meta
  name="description"
  content="Практический конспект по HTML: структура документа, семантика, формы и доступность."
>
```

Этот текст не отображается на самой странице, но может появиться в поисковой выдаче.

## Для чего нужен description

- Кратко объясняет содержание страницы.
- Помогает пользователю понять результат в поиске.
- Может влиять на кликабельность сниппета.
- Помогает различать страницы сайта.

## Хорошее описание

Хороший `description` конкретен и соответствует содержимому страницы.

```html
<meta
  name="description"
  content="Руководство по HTML-формам: label, input, validation, autocomplete и доступность."
>
```

## Частые ошибки

```html
<!-- слишком общее -->
<meta name="description" content="Лучшая страница">

<!-- не соответствует контенту -->
<meta name="description" content="Купить смартфон" />
```

Если страница на самом деле про HTML-формы, такое описание будет вводить в заблуждение.

## Description не гарантирует сниппет

Поисковая система может показать не meta description, а фрагмент текста со страницы, если считает его более подходящим под запрос пользователя.

## Мини-шпаргалка

- `description` живет в `head`.
- Он кратко описывает страницу.
- Может отображаться в поисковой выдаче.
- Должен быть уникальным для важных страниц.
- Не должен обещать то, чего нет в контенте.
- Это не видимый заголовок страницы.
