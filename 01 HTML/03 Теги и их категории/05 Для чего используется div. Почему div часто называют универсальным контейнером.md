# Для чего используется div. Почему div часто называют универсальным контейнером?

> [!NOTE]
> `<div>` - это нейтральный блочный контейнер без собственного семантического смысла. Его используют для группировки элементов, layout-структуры и стилизации, когда нет более подходящего семантического тега.

## Главное

`div` называют универсальным контейнером, потому что он почти ничего не означает сам по себе и может оборачивать разные части интерфейса.

```html
<div class="card">
  <h2>Тариф Basic</h2>
  <p>Подходит для небольших проектов.</p>
</div>
```

Здесь `div` нужен как оболочка карточки.

## Когда div уместен

- Нужно сгруппировать элементы для CSS Grid или Flexbox.
- Нужна декоративная или техническая обертка.
- Нет подходящего семантического элемента.
- Компоненту нужна внутренняя layout-структура.

```html
<div class="layout">
  <aside>Фильтры</aside>
  <main>Каталог</main>
</div>
```

`div.layout` здесь технически группирует колонки.

## Когда div не подходит

Не стоит заменять `div`-ом элементы с готовым смыслом и поведением.

```html
<!-- плохо -->
<div class="button">Открыть</div>
<div class="link">Профиль</div>

<!-- лучше -->
<button type="button">Открыть</button>
<a href="/profile">Профиль</a>
```

`button` и `a` дают браузеру понятный интерактивный контракт.

## Div против section

Если блок является тематическим разделом и у него есть заголовок, часто подходит `section`.

```html
<section aria-labelledby="faq-title">
  <h2 id="faq-title">Вопросы и ответы</h2>
  ...
</section>
```

Если блок нужен только для сетки или отступов, лучше `div`.

## Мини-шпаргалка

- `div` - нейтральный блочный контейнер.
- Он полезен для layout и стилизации.
- Он не добавляет смысла документу.
- Не заменяй `div`-ом `button`, `a`, `nav`, `main`, `section`.
- Если у блока есть смысл, ищи семантический тег.
