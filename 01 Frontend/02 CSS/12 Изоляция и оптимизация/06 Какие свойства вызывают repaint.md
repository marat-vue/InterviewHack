# Какие свойства вызывают repaint?

> [!NOTE]
> **Repaint** происходит, когда браузеру нужно заново нарисовать пиксели элемента без обязательного пересчета layout. Его часто вызывают изменения цвета, фона, теней, видимости, outline и других визуальных свойств.

## Главное

Если размер и позиция элемента не меняются, но меняется внешний вид, браузеру часто нужен repaint.

```css
.button:hover {
  background-color: #1d4ed8;
}
```

Размер кнопки тот же, но пиксели фона нужно перерисовать.

## Частые свойства

| Категория | Примеры |
| --- | --- |
| Цвет | `color`, `background-color`, `border-color` |
| Фон | `background-image`, `background-position` |
| Тени | `box-shadow`, `text-shadow` |
| Обводка | `outline` |
| Видимость | `visibility` |
| Декор текста | `text-decoration` |

## Repaint vs relayout

```text
relayout -> пересчитать размеры и позиции
repaint  -> заново нарисовать пиксели
```

Изменение `width` может вызвать layout и paint. Изменение `background-color` обычно вызывает paint без layout.

## Дорогие paint-свойства

Тени, фильтры и большие размытые области могут быть дорогими.

```css
.card {
  box-shadow: 0 24px 64px rgb(0 0 0 / 0.24);
}
```

Особенно если таких элементов много или они анимируются.

## Что часто дешевле

Для движения и прозрачности чаще используют:

```css
.modal {
  transform: translateY(0);
  opacity: 1;
}
```

`transform` и `opacity` часто могут обрабатываться на compositing-этапе.

## Мини-шпаргалка

- Repaint перерисовывает пиксели.
- Цвета, фон, тени и outline часто вызывают repaint.
- Repaint обычно дешевле relayout, но не всегда.
- Большие blur/shadow могут быть дорогими.
- Для плавных анимаций чаще выбирают `transform` и `opacity`.
