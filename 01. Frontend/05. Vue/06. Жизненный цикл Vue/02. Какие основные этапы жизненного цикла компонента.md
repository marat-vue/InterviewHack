# Какие основные этапы жизненного цикла компонента?

> [!NOTE]
> Основные этапы жизненного цикла Vue-компонента: создание, монтирование, обновление и размонтирование. На каждом этапе доступны свои хуки.

## Вопрос

Какие основные этапы жизненного цикла компонента?

## Создание

На этом этапе Vue подготавливает компонент, props, state, computed и watchers.

```text
setup / beforeCreate / created
```

В Composition API логика обычно выполняется внутри `setup` или `<script setup>`.

## Монтирование

Компонент впервые рендерится и вставляется в DOM.

```typescript
onMounted(() => {
  console.log("Можно работать с DOM");
});
```

`mounted` часто используют для DOM refs, сторонних виджетов и стартовых side effects.

## Обновление

Когда реактивные зависимости меняются, Vue обновляет компонент.

```typescript
onUpdated(() => {
  console.log("DOM обновился");
});
```

Этот хук вызывается после обновления DOM.

## Размонтирование

Компонент удаляется из DOM, и нужно очистить побочные эффекты.

```typescript
onUnmounted(() => {
  window.removeEventListener("resize", onResize);
});
```

## Мини-шпаргалка

- Create: подготовка компонента.
- Mount: вставка в DOM.
- Update: реакция на изменение state/props.
- Unmount: удаление и очистка.
- Для DOM используй `mounted/onMounted`.
