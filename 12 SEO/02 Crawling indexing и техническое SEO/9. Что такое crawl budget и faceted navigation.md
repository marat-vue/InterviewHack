# Что такое crawl budget и faceted navigation?

> [!summary]
> Crawl budget - это условное количество ресурсов, которое поисковик готов потратить на обход сайта. На маленьких сайтах это редко проблема, но для магазинов, маркетплейсов и каталогов фильтры могут создавать миллионы URL и мешать обходу важных страниц.

## Что такое crawl budget?

Crawl budget зависит от:

- размера сайта;
- скорости сервера;
- количества ошибок;
- частоты обновлений;
- количества дублей;
- качества внутренней перелинковки;
- важности страниц.

Главная идея:

```text
Если робот тратит время на мусорные URL, он хуже обходит важные страницы.
```

## Что такое faceted navigation?

Faceted navigation - это фильтры в каталоге:

```text
/laptops?brand=apple
/laptops?brand=apple&ram=16
/laptops?brand=apple&ram=16&color=silver&sort=price
```

Фильтры полезны пользователям, но могут создавать огромное количество комбинаций.

## Какие URL нужно индексировать?

Индексировать стоит страницы, которые:

- имеют спрос;
- дают уникальную ценность;
- имеют нормальный контент;
- не являются тонкими дублями;
- могут быть посадочными страницами.

Пример полезной страницы:

```text
/laptops/apple
```

Пример мусорной страницы:

```text
/laptops?brand=apple&sort=price_desc&page=7&sessionId=123
```

## Как управлять фильтрами?

Инструменты:

- canonical;
- noindex;
- robots.txt;
- внутренние ссылки только на полезные фильтры;
- sitemap только для нужных посадочных;
- нормализация параметров;
- серверные правила генерации URL.

## Мини-шпаргалка

- Crawl budget важен прежде всего для больших сайтов.
- Фильтры могут создавать миллионы дублей.
- Индексировать нужно не все комбинации, а полезные посадочные.
- Sitemap должен содержать только важные canonical URL.
- Управление фильтрами требует продуктового и SEO-решения, не только кода.
