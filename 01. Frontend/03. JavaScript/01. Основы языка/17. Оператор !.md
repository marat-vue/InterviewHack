# Оператор `!`

> [!NOTE]
> `!` - логическое НЕ. Он приводит значение к boolean и инвертирует результат: truthy становится `false`, falsy становится `true`.

## Вопрос

Что делает оператор `!`?

## Основная идея

Оператор `!` работает в два шага:

1. Приводит значение к boolean.
2. Возвращает противоположное значение.

```javascript
!true;  // false
!false; // true
```

## Truthy и falsy

Falsy-значения:

```javascript
false;
0;
-0;
0n;
"";
null;
undefined;
NaN;
```

Все остальное - truthy.

```javascript
!"hello"; // false
!"";      // true
!1;       // false
!0;       // true
![];      // false
!{};      // false
```

Массивы и объекты truthy, даже если они пустые.

## Типичное использование

Проверка отсутствия значения:

```javascript
if (!user) {
  console.log("Пользователь не найден");
}
```

Переключение boolean:

```javascript
let isOpen = false;

isOpen = !isOpen;

console.log(isOpen); // true
```

Фильтрация:

```javascript
const users = [
  { name: "Anna", blocked: false },
  { name: "Max", blocked: true },
];

const activeUsers = users.filter((user) => !user.blocked);
```

## Важная ловушка

Проверка `!value` сработает не только для `null` и `undefined`, но и для `0`, `""`, `false`, `NaN`.

```javascript
function printCount(count) {
  if (!count) {
    return "Нет значения";
  }

  return `Количество: ${count}`;
}

printCount(0); // "Нет значения" - возможно, это ошибка
```

Если `0` допустим, проверяйте точнее:

```javascript
if (count === null || count === undefined) {
  return "Нет значения";
}
```

## Связь с `!!`

Двойное отрицание приводит значение к boolean без инверсии итогового смысла.

```javascript
!!"hello"; // true
!!"";      // false
```

## Мини-шпаргалка

```javascript
!value;          // инверсия truthy/falsy
!!value;         // приведение к boolean
isOpen = !isOpen; // переключение флага
```
