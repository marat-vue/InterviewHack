# Приватные свойства вне класса

> [!NOTE] Коротко
> К приватному свойству `#field` нельзя обратиться вне класса. Для доступа нужен публичный метод или геттер.

## Вопрос

Можно ли обратиться к приватному свойству вне класса?

## Короткий ответ

Нет. Приватные поля с `#` доступны только внутри тела класса, где они объявлены.

```javascript
class User {
  #password = 'secret';
}

const user = new User();

user.#password; // SyntaxError
```

Это не просто `undefined`: код с таким обращением синтаксически неверен.

## Как дать controlled-доступ

```javascript
class User {
  #password = 'secret';

  checkPassword(value) {
    return value === this.#password;
  }
}

const user = new User();

console.log(user.checkPassword('secret')); // true
```

Внешний код не видит поле напрямую, но может пользоваться публичным методом.

## Геттер для чтения

```javascript
class Counter {
  #value = 0;

  get value() {
    return this.#value;
  }
}

const counter = new Counter();

console.log(counter.value); // 0
```

Геттер позволяет безопасно открыть чтение.

## Почему это полезно

- скрывает внутреннюю реализацию;
- защищает состояние от случайной записи;
- делает публичный API класса понятнее;
- позволяет менять внутренности класса без изменения внешнего кода.

## Мини-шпаргалка

```javascript
class A {
  #value = 1;
  getValue() {
    return this.#value;
  }
}
```
