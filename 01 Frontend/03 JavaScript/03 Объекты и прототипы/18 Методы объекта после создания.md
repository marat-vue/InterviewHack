# Методы объекта после создания

> [!NOTE] Коротко
> В JavaScript объект динамический: после создания в него можно добавить новое свойство, в том числе функцию. Если свойство хранит функцию, его обычно называют методом.

## Вопрос

Можно ли добавить методы после создания объекта?

## Добавление метода конкретному объекту

```javascript
const user = {
  name: "Anna",
};

user.sayHi = function () {
  return `Hi, ${this.name}`;
};

user.sayHi(); // "Hi, Anna"
```

Метод - это обычное свойство, значением которого является функция.

## Через стрелочную функцию

```javascript
const user = {
  name: "Anna",
};

user.sayHi = () => `Hi, ${this.name}`;
```

Так обычно делать не стоит, если нужен `this` объекта. Стрелочная функция не имеет собственного `this`.

Лучше:

```javascript
user.sayHi = function () {
  return `Hi, ${this.name}`;
};
```

## Добавление через `Object.assign`

```javascript
const user = {
  name: "Anna",
};

Object.assign(user, {
  sayHi() {
    return `Hi, ${this.name}`;
  },
  logout() {
    return "logout";
  },
});
```

`Object.assign` мутирует первый аргумент.

## Добавление в прототип

Если нужно добавить метод всем объектам, созданным через конструктор:

```javascript
function User(name) {
  this.name = name;
}

User.prototype.sayHi = function () {
  return `Hi, ${this.name}`;
};

const user = new User("Anna");
user.sayHi(); // "Hi, Anna"
```

Метод будет общим для всех экземпляров.

## Подводные камни

Можно случайно перезаписать существующее свойство:

```javascript
user.name = function () {};
```

Или добавить метод в замороженный объект не получится:

```javascript
const user = Object.freeze({ name: "Anna" });

user.sayHi = function () {}; // не добавится
```

## Мини-шпаргалка

| Способ | Пример |
| --- | --- |
| добавить метод | `obj.method = function () {}` |
| добавить несколько | `Object.assign(obj, { method() {} })` |
| добавить в прототип | `Ctor.prototype.method = function () {}` |
| метод с `this` | обычная функция |
| arrow method | осторожно, нет собственного `this` |
