# Что такое постпроцессор

> [!summary]
> **CSS-постпроцессор** - это инструмент, который обрабатывает уже написанный CSS и преобразует его: добавляет vendor prefixes, минифицирует, проверяет, оптимизирует или расширяет синтаксис.

## Главное

Постпроцессор работает после написания CSS.

```text
CSS source
  -> postprocessor
  -> processed CSS
  -> browser
```

Самый известный пример экосистемы - PostCSS.

## Что может делать постпроцессор

- Добавлять vendor prefixes.
- Минифицировать CSS.
- Проверять синтаксис.
- Поддерживать будущие возможности CSS через плагины.
- Оптимизировать правила.
- Преобразовывать modern CSS под нужные браузеры.

## Autoprefixer

```css
.box {
  user-select: none;
}
```

Autoprefixer может добавить нужные префиксы для выбранных браузеров.

```css
.box {
  -webkit-user-select: none;
  user-select: none;
}
```

## Препроцессор и постпроцессор

```text
preprocessor  -> из SCSS в CSS
postprocessor -> из CSS в обработанный CSS
```

Они решают разные задачи и могут использоваться вместе.

## Мини-шпаргалка

- Постпроцессор обрабатывает CSS после написания.
- PostCSS - популярная платформа для таких задач.
- Autoprefixer добавляет vendor prefixes.
- Минификация уменьшает размер CSS.
- Постпроцессор не заменяет понимание CSS.
