# Что такое “Controlled Component”?

> [!summary]
> Controlled Component - это компонент, значение которого управляется React state через props. Компонент не хранит финальное значение "сам в себе", а получает `value` и сообщает об изменениях через `onChange`.

## Пример с input

```jsx
function EmailField() {
  const [email, setEmail] = useState('')

  return (
    <input
      value={email}
      onChange={(event) => setEmail(event.target.value)}
    />
  )
}
```

Источник истины для `input` - переменная `email` в React state.

## Как работает поток данных?

```text
state -> value prop -> DOM input -> onChange -> setState -> новый value
```

React контролирует отображаемое значение.

## Controlled UI-компонент

Такой подход используют не только для нативных input.

```jsx
function Tabs({ value, onChange, items }) {
  return (
    <div>
      {items.map((item) => (
        <button
          key={item.value}
          aria-selected={item.value === value}
          onClick={() => onChange(item.value)}
        >
          {item.label}
        </button>
      ))}
    </div>
  )
}
```

Использование:

```jsx
function Page() {
  const [tab, setTab] = useState('profile')

  return (
    <Tabs
      value={tab}
      onChange={setTab}
      items={[
        { value: 'profile', label: 'Profile' },
        { value: 'settings', label: 'Settings' },
      ]}
    />
  )
}
```

`Tabs` не решает, какая вкладка активна. Он показывает состояние, которое пришло от родителя.

## Плюсы controlled components

- легко валидировать значение;
- легко сбросить форму;
- легко синхронизировать несколько компонентов;
- удобно сохранять данные;
- удобно подключать form libraries;
- поведение предсказуемо.

## Минусы

- больше кода;
- каждый ввод может вызывать render;
- для больших форм нужна аккуратная оптимизация;
- иногда проще использовать uncontrolled refs.

## Когда использовать?

Controlled components хороши для:

- форм с валидацией;
- фильтров;
- search params;
- wizard forms;
- tabs, accordion, modal state;
- компонентов дизайн-системы.

## Мини-шпаргалка

- Controlled component получает `value` из props.
- Изменения сообщает через `onChange`.
- Источник истины находится у родителя или в state manager.
- Это основной подход для предсказуемых форм.
- Для гибких библиотечных компонентов часто добавляют controlled и uncontrolled режимы.
