# Какие бывают аномалии чтения?

> [!summary]
> Аномалии чтения - некорректные или неожиданные эффекты при параллельных транзакциях. Классические примеры: dirty read, non-repeatable read и phantom read.

## Dirty read

Транзакция читает изменения другой транзакции, которые еще не были закоммичены.

```txt
T1 изменил balance, но не COMMIT
T2 прочитал этот balance
T1 сделал ROLLBACK
```

T2 увидел данные, которых в итоге не существует.

## Non-repeatable read

Транзакция дважды читает одну строку и получает разные значения, потому что другая транзакция успела изменить и закоммитить строку.

## Phantom read

Транзакция повторяет запрос по условию и получает новый набор строк: другая транзакция вставила или удалила строки, подходящие под условие.

## Мини-шпаргалка

- Dirty read - чтение незакоммиченных данных.
- Non-repeatable read - строка изменилась между чтениями.
- Phantom read - изменился набор строк по условию.
- Уровни изоляции уменьшают или запрещают разные аномалии.
- Реальное поведение зависит от СУБД и механизма concurrency control.
