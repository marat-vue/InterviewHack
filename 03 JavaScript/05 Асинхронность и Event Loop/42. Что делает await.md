# Что делает await

> [!summary] Коротко
> `await` ждет завершения промиса внутри async-функции и возвращает его успешное значение.

## Вопрос

Что делает ключевое слово `await`?

## Определение

`await` приостанавливает выполнение текущей `async`-функции до завершения переданного промиса. При этом основной поток JavaScript не блокируется: другие задачи могут продолжать выполняться через Event Loop.

Если промис успешен, `await` возвращает значение. Если промис отклонен, `await` бросает ошибку.

## Пример

```javascript
async function loadUser() {
  const response = await fetch('/api/user');
  const user = await response.json();

  return user;
}
```

Код после первого `await` продолжится только когда завершится `fetch`.

## await с обычным значением

```javascript
const value = await 10;

console.log(value); // 10
```

Обычное значение будет обработано как `Promise.resolve(10)`.

## Ошибка через await

```javascript
try {
  await Promise.reject(new Error('Fail'));
} catch (error) {
  console.error(error.message); // 'Fail'
}
```

## Последовательность и параллельность

```javascript
// Последовательно
const user = await loadUser();
const posts = await loadPosts();

// Параллельно
const [userData, postsData] = await Promise.all([
  loadUser(),
  loadPosts(),
]);
```

## Мини-шпаргалка

```javascript
const value = await promise; // fulfilled value
```
