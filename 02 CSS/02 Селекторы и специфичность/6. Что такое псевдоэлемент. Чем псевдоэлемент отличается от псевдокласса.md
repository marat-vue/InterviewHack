# Что такое псевдоэлемент. Чем псевдоэлемент отличается от псевдокласса

> [!summary]
> **Псевдоэлемент** стилизует виртуальную часть элемента, например первую строку, первую букву или сгенерированный контент. Псевдокласс выбирает состояние элемента, а псевдоэлемент - его часть.

## Главное

Псевдоэлементы обычно пишутся с двумя двоеточиями.

```css
.badge::before {
  content: "New";
}
```

`::before` создает виртуальный фрагмент перед содержимым элемента.

## Частые псевдоэлементы

```css
p::first-line {
  font-weight: 700;
}

p::first-letter {
  font-size: 2em;
}

.tooltip::after {
  content: attr(data-title);
}
```

## Отличие от псевдокласса

```css
button:hover {
  background: #2563eb;
}

button::before {
  content: "";
}
```

| Тип | Что выбирает | Пример |
| --- | --- | --- |
| Псевдокласс | Состояние или условие | `:hover`, `:checked` |
| Псевдоэлемент | Часть элемента | `::before`, `::after` |

## content

Для `::before` и `::after` обычно нужен `content`.

```css
.required::after {
  content: " *";
  color: #b91c1c;
}
```

Без `content` псевдоэлемент может не появиться.

## Мини-шпаргалка

- Псевдоэлемент обычно пишется через `::`.
- `::before` и `::after` создают виртуальный контент.
- Для них чаще всего нужен `content`.
- Псевдокласс выбирает состояние.
- Псевдоэлемент стилизует часть элемента.
- Не стоит класть важный текст только в `content`, если он нужен для доступности.
