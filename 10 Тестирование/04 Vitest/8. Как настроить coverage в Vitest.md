# Как настроить coverage в Vitest?

> [!summary]
> Coverage в Vitest показывает, какие строки, функции и ветки кода были выполнены тестами. Для покрытия нужно установить coverage provider и настроить `coverage` в test config.

## Установка

Для V8 provider:

```bash
npm install -D @vitest/coverage-v8
```

Для Istanbul provider:

```bash
npm install -D @vitest/coverage-istanbul
```

Чаще начинают с V8 provider.

## Конфигурация

```ts
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'html'],
      include: ['src/**/*.{ts,vue}'],
      exclude: ['src/main.ts', 'src/router/**'],
    },
  },
});
```

## Запуск

```bash
npm run coverage
```

или:

```bash
npx vitest run --coverage
```

HTML-отчет удобно открывать локально и смотреть, какие строки и branches не покрыты.

## Thresholds

Можно задать минимальные пороги:

```ts
coverage: {
  provider: 'v8',
  thresholds: {
    lines: 80,
    functions: 80,
    branches: 70,
    statements: 80,
  },
}
```

Порог полезен в CI, но его нельзя превращать в самоцель.

## Мини-шпаргалка

- Coverage показывает выполненный код.
- Для Vitest нужен coverage provider.
- Частый выбор: `@vitest/coverage-v8`.
- `reporter: ['text', 'html']` удобен для локального анализа.
- Thresholds полезны, если не мешают писать осмысленные тесты.
