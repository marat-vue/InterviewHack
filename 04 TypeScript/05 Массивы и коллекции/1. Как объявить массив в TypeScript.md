# Как объявить массив в TypeScript

> [!summary] Коротко
> Массив объявляют как `Type[]` или `Array<Type>`. Обе записи означают массив элементов одного типа.

## Вопрос

Как объявить массив в TypeScript?

## Основной синтаксис

```typescript
const numbers: number[] = [1, 2, 3];
const names: string[] = ["Анна", "Олег"];
```

Полная generic-запись делает то же самое.

```typescript
const numbers: Array<number> = [1, 2, 3];
const names: Array<string> = ["Анна", "Олег"];
```

## Массив объектов

```typescript
type User = {
  id: number;
  name: string;
};

const users: User[] = [
  { id: 1, name: "Анна" },
  { id: 2, name: "Олег" },
];
```

## Массив с несколькими типами

```typescript
const ids: Array<string | number> = ["user-1", 42];
```

## Readonly-массив

```typescript
const readonlyIds: readonly number[] = [1, 2, 3];

// readonlyIds.push(4); // ошибка
```

## Мини-шпаргалка

- `number[]` - массив чисел.
- `Array<number>` - то же самое в generic-форме.
- `(A | B)[]` - массив, где каждый элемент может быть `A` или `B`.
- `readonly T[]` - массив без мутирующих методов.
