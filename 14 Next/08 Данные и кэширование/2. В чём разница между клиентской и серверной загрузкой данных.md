# В чём разница между клиентской и серверной загрузкой данных?

> [!summary]
> Серверная загрузка выполняется до отправки HTML и подходит для SEO, secrets и первого экрана. Клиентская загрузка выполняется в браузере после загрузки JavaScript и подходит для интерактивных, пользовательских и часто меняющихся данных.

## Серверная загрузка

```tsx
export default async function ArticlePage() {
  const article = await getArticle()

  return <Article article={article} />
}
```

Плюсы:

- контент есть в HTML;
- лучше SEO;
- можно читать БД;
- можно использовать server env;
- меньше client JS.

Минусы:

- нужен server runtime;
- можно увеличить TTFB;
- нужно думать о cache;
- нельзя использовать browser-only state.

## Клиентская загрузка

```tsx
'use client'

export function SearchResults({ query }: { query: string }) {
  const { data } = useQuery({
    queryKey: ['search', query],
    queryFn: () => search(query),
  })

  return <Results data={data} />
}
```

Плюсы:

- отлично для интерактивности;
- удобно обновлять после действий;
- хорошо сочетается с TanStack Query;
- не блокирует server render.

Минусы:

- контента может не быть в первом HTML;
- хуже для SEO;
- нужен loading state;
- нельзя использовать secrets.

## Как выбирать?

| Если нужно | Выбор |
|---|---|
| SEO-контент | сервер |
| доступ к БД/secrets | сервер |
| autocomplete | клиент |
| dashboard после login | часто клиент или гибрид |
| первый экран каталога | сервер |
| бесконечная подгрузка | гибрид |

## Что отвечать на собеседовании?

Разница в месте и времени выполнения. Серверная загрузка происходит до отправки HTML, а клиентская - после загрузки JS в браузере. В Next.js часто используют гибрид: первый контент загружается на сервере, а интерактивные обновления - на клиенте.

## Частые ошибки

- Грузить SEO-текст только в `useEffect`.
- Считать client fetching неправильным всегда.
- Дублировать один и тот же запрос на сервере и клиенте.
- Передавать secrets в browser fetch.
- Не делать loading/error states на клиенте.

## Мини-шпаргалка

- Сервер - SEO, secrets, first HTML.
- Клиент - interaction, live UI, user input.
- Server Components - главный App Router паттерн.
- Client fetching часто делает TanStack Query.
- Лучшие Next-страницы часто гибридные.
