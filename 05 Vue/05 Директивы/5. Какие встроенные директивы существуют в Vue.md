# Какие встроенные директивы существуют в Vue

> [!summary] Коротко
> Vue имеет набор встроенных директив для условий, списков, привязки данных, событий, слотов и оптимизации: `v-if`, `v-show`, `v-for`, `v-bind`, `v-on`, `v-model`, `v-slot`, `v-once`, `v-memo` и другие.

## Вопрос

Какие встроенные директивы существуют в Vue?

## Основные директивы

```vue
<p v-if="isVisible">Виден</p>
<p v-show="isOpen">Открыт</p>
<li v-for="item in items" :key="item.id">{{ item.title }}</li>
<a :href="url">Ссылка</a>
<button @click="save">Сохранить</button>
<input v-model="name" />
```

Эти директивы встречаются почти в каждом Vue-приложении.

## Условия

- `v-if` - создает или удаляет элемент.
- `v-else-if` - дополнительная ветка условия.
- `v-else` - ветка по умолчанию.
- `v-show` - переключает CSS-свойство `display`.

## Списки и привязки

- `v-for` - рендерит список.
- `v-bind` или `:` - связывает атрибут или prop.
- `v-on` или `@` - подписывает на событие.
- `v-model` - двусторонняя привязка.

## Слоты и оптимизация

- `v-slot` или `#` - передает слот.
- `v-once` - рендерит один раз.
- `v-memo` - пропускает обновление поддерева, если зависимости не изменились.
- `v-cloak` - скрывает нескомпилированный шаблон.
- `v-pre` - пропускает компиляцию участка шаблона.

## Мини-шпаргалка

- Для условий: `v-if`, `v-else-if`, `v-else`, `v-show`.
- Для списков: `v-for` плюс `:key`.
- Для данных: `v-bind`, `v-model`.
- Для событий: `v-on`.
- Для оптимизации: `v-once`, `v-memo`.
