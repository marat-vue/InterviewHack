# Что такое useFormStatus?

> [!summary]
> `useFormStatus` - хук из `react-dom`, который дает дочернему компоненту формы информацию о последней отправке: `pending`, `data`, `method`, `action`. Он нужен для submit-кнопок, индикаторов загрузки и UI, который должен знать состояние ближайшей родительской формы.

## Импорт

```jsx
import { useFormStatus } from 'react-dom'
```

## Что возвращает useFormStatus?

```jsx
const { pending, data, method, action } = useFormStatus()
```

| Поле | Что означает |
|---|---|
| `pending` | форма сейчас отправляется |
| `data` | `FormData`, которая отправляется |
| `method` | HTTP-метод формы |
| `action` | action-функция, которую запускает форма |

## Базовый пример

`useFormStatus` должен вызываться в компоненте внутри формы:

```jsx
function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button type="submit" disabled={pending}>
      {pending ? 'Sending...' : 'Send'}
    </button>
  )
}

function FeedbackForm({ sendFeedback }) {
  return (
    <form action={sendFeedback}>
      <textarea name="message" />
      <SubmitButton />
    </form>
  )
}
```

Кнопка не принимает `isLoading` через props. Она сама читает статус ближайшей формы.

## Важное правило про родительскую форму

Такой код не сработает как ожидается:

```jsx
function FeedbackForm({ sendFeedback }) {
  const { pending } = useFormStatus()

  return (
    <form action={sendFeedback}>
      <button disabled={pending}>Send</button>
    </form>
  )
}
```

`useFormStatus` читает статус родительской формы, а форма в этом же компоненте не является родителем для самого хука.

Правильно вынести кнопку в дочерний компонент:

```jsx
function SubmitButton() {
  const { pending } = useFormStatus()
  return <button disabled={pending}>Send</button>
}
```

## Как прочитать отправляемые данные?

```jsx
function SubmitButton() {
  const { pending, data } = useFormStatus()
  const email = data?.get('email')

  return (
    <button disabled={pending}>
      {pending ? `Sending ${email ?? ''}...` : 'Subscribe'}
    </button>
  )
}
```

Это удобно, если нужно показать пользователю, что именно отправляется.

## useFormStatus vs useActionState

| Хук | За что отвечает |
|---|---|
| `useFormStatus` | процесс отправки ближайшей формы |
| `useActionState` | состояние, которое вернула action-функция |

Часто их используют вместе:

```jsx
import { useActionState } from 'react'
import { useFormStatus } from 'react-dom'

async function createUser(previousState, formData) {
  const email = formData.get('email')

  if (!email) {
    return { error: 'Email is required' }
  }

  await api.createUser({ email })
  return { error: null }
}

function SubmitButton() {
  const { pending } = useFormStatus()
  return <button disabled={pending}>Create</button>
}

function UserForm() {
  const [state, action] = useActionState(createUser, { error: null })

  return (
    <form action={action}>
      <input name="email" />
      <SubmitButton />
      {state.error && <p>{state.error}</p>}
    </form>
  )
}
```

## Когда использовать?

Используй `useFormStatus`, когда компоненту внутри формы нужно:

- заблокировать submit-кнопку;
- показать pending text;
- показать spinner;
- прочитать отправляемые `FormData`;
- построить reusable form controls.

## Что отвечать на собеседовании?

`useFormStatus` - это React DOM hook для чтения статуса ближайшей родительской формы. Он возвращает `pending`, `data`, `method` и `action`. Чаще всего его используют в дочерней submit-кнопке, чтобы не прокидывать loading state вручную.

## Частые ошибки

- Импортировать из `react`, а не из `react-dom`.
- Вызывать хук в том же компоненте, где форма только создается.
- Путать статус отправки формы с результатом action.
- Использовать вне формы и ожидать `pending: true`.
- Прокидывать `isLoading` вручную там, где проще дочерний submit-компонент.

## Мини-шпаргалка

- Импорт: `react-dom`.
- Работает для ближайшей родительской формы.
- Возвращает `pending`, `data`, `method`, `action`.
- Хорош для submit-кнопок.
- Для результата action используй `useActionState`.
