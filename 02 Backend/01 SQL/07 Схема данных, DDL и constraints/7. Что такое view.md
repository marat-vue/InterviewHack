# Что такое view?

> [!summary]
> View - сохраненный SQL-запрос, к которому можно обращаться как к таблице. View упрощает сложные запросы, скрывает детали схемы и помогает давать ограниченный доступ к данным.

## Пример

```sql
CREATE VIEW active_users AS
SELECT id, email, created_at
FROM users
WHERE deleted_at IS NULL;
```

Использование:

```sql
SELECT *
FROM active_users
WHERE created_at >= DATE '2026-01-01';
```

## View не всегда хранит данные

Обычная view обычно хранит определение запроса, а не результат. При обращении база выполняет запрос.

Материализованная view, если СУБД ее поддерживает, хранит результат физически и требует обновления.

## Когда полезно?

- скрыть сложный join;
- стандартизировать бизнес-фильтр;
- ограничить доступ к колонкам;
- сделать удобный слой для отчетов.

## Мини-шпаргалка

- View - сохраненный запрос.
- К view обращаются как к таблице.
- Обычная view не обязательно хранит данные.
- Materialized view хранит результат.
- View не заменяет хорошую модель данных.
