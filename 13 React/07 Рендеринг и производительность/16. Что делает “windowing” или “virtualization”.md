# Что делает “windowing” или “virtualization”?

> [!summary]
> Windowing, или virtualization, - это техника, при которой приложение рендерит только видимую часть большого списка. Пользователь ощущает список как полный, но в DOM находится маленькое "окно" элементов.

## Простое определение

Обычный список:

```text
10 000 элементов в данных -> 10 000 элементов в DOM
```

Виртуализированный список:

```text
10 000 элементов в данных -> 20-80 элементов в DOM
```

При скролле библиотека меняет, какие строки сейчас находятся в DOM, и позиционирует их так, будто список полный.

## Пример с react-window

```jsx
import { FixedSizeList } from 'react-window'

function UsersList({ users }) {
  return (
    <FixedSizeList
      height={480}
      width={360}
      itemCount={users.length}
      itemSize={48}
    >
      {({ index, style }) => (
        <div style={style}>
          {users[index].name}
        </div>
      )}
    </FixedSizeList>
  )
}
```

`style` обязательно нужно передать на строку. В нем библиотека задает позиционирование элемента внутри виртуального контейнера.

## Что такое overscan?

`overscan` - небольшой запас элементов за пределами видимой области.

```jsx
<FixedSizeList
  height={480}
  itemCount={users.length}
  itemSize={48}
  overscanCount={5}
>
  {Row}
</FixedSizeList>
```

Без overscan при быстром скролле пользователь может увидеть пустые участки. Слишком большой overscan снова увеличивает DOM.

## Когда virtualization особенно полезна?

- таблицы;
- каталоги товаров;
- чаты;
- ленты;
- логи;
- autocomplete с большим количеством вариантов;
- административные панели с тысячами строк.

## Ограничения

Виртуализация усложняет:

- переменную высоту строк;
- keyboard navigation;
- доступность;
- поиск по странице средствами браузера;
- sticky headers;
- SSR;
- сохранение позиции скролла.

Поэтому для маленьких списков ее лучше не использовать.

## Мини-шпаргалка

- Virtualization уменьшает количество DOM-узлов.
- Пользователь видит полный список, но DOM содержит только окно.
- Для одинаковой высоты строк реализация проще.
- `style` строки нельзя игнорировать.
