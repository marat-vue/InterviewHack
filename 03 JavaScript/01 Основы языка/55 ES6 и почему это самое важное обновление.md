# ES6 и почему это важное обновление?

> [!NOTE] Коротко
> ES6, или ES2015, стал большим скачком для JavaScript: появились `let/const`, стрелочные функции, классы, модули, промисы, template literals, destructuring, spread/rest и другие возможности для крупной разработки.

## Вопрос

Почему ES6 считается самым важным обновлением JavaScript?

## Почему ES6 выделяют

До ES6 JavaScript уже был популярным, но язык часто ощущался неудобным для больших приложений. ES6 добавил много возможностей, которые сделали код короче, безопаснее и структурнее.

## `let` и `const`

```javascript
const name = "Anna";
let count = 0;
```

Они дали блочную область видимости и уменьшили количество проблем с `var`.

## Стрелочные функции

```javascript
const double = (value) => value * 2;
```

Они короче обычных функций и не имеют собственного `this`.

## Template literals

```javascript
const message = `Hello, ${name}`;
```

Строки с интерполяцией стали намного удобнее.

## Деструктуризация

```javascript
const user = { name: "Anna", age: 25 };
const { name, age } = user;
```

Позволяет удобно доставать данные из объектов и массивов.

## Spread и rest

```javascript
const copy = [...items];

function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
```

Один синтаксис используется для раскрытия и сбора значений.

## Классы

```javascript
class User {
  constructor(name) {
    this.name = name;
  }
}
```

Классы дали более привычный синтаксис поверх прототипного наследования.

## Модули

```javascript
export function sum(a, b) {
  return a + b;
}

import { sum } from "./math.js";
```

Модули сделали структуру приложений понятнее.

## Промисы

```javascript
fetch("/api/user")
  .then((response) => response.json())
  .then((user) => console.log(user));
```

Промисы стали основой современной асинхронности.

## Мини-шпаргалка

| Возможность ES6 | Зачем нужна |
| --- | --- |
| `let`, `const` | блочная область видимости |
| arrow functions | короткий синтаксис, лексический `this` |
| template literals | удобные строки |
| destructuring | доставать данные из структур |
| spread/rest | копировать, объединять, собирать аргументы |
| classes | синтаксис для объектов с поведением |
| modules | организация кода |
| promises | асинхронные операции |
