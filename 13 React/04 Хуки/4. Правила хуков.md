# Какие правила хуков нужно знать?

> [!summary]
> Главное правило хуков: вызывай их только на верхнем уровне React-компонента или custom hook. Нельзя вызывать хуки в условиях, циклах, вложенных функциях и после раннего `return`, потому что React сопоставляет state хуков по порядку вызовов.

## Правило 1: только верхний уровень

Плохо:

```jsx
function Profile({ isAdmin }) {
  if (isAdmin) {
    const [permissions, setPermissions] = useState([])
  }

  return <div>Профиль</div>
}
```

Если `isAdmin` изменится, порядок вызовов хуков изменится. React не сможет корректно сопоставить state.

Правильно:

```jsx
function Profile({ isAdmin }) {
  const [permissions, setPermissions] = useState([])

  if (!isAdmin) {
    return <div>Нет доступа</div>
  }

  return <AdminPanel permissions={permissions} />
}
```

## Правило 2: только React-функции

Хуки можно вызывать:

- в функциональном компоненте;
- в custom hook.

Нельзя:

```jsx
function formatUser(user) {
  const theme = useContext(ThemeContext)
  return `${user.name} (${theme})`
}
```

Обычная utility-функция не является компонентом или custom hook.

## Почему порядок важен?

React хранит состояние хуков по порядку:

```text
1-й useState -> первое состояние
2-й useEffect -> первый эффект
3-й useState -> второе состояние
```

Если порядок меняется между render, React начинает сопоставлять значения неправильно.

## Как писать условную логику?

Условие помещают внутрь хука:

```jsx
useEffect(() => {
  if (!userId) {
    return
  }

  loadUser(userId)
}, [userId])
```

Хук вызывается всегда, а логика внутри может быть условной.

## Как проверять правила?

Используй ESLint:

```json
{
  "plugins": ["react-hooks"],
  "rules": {
    "react-hooks/rules-of-hooks": "error",
    "react-hooks/exhaustive-deps": "warn"
  }
}
```

В современных React-проектах это почти обязательная защита от тонких ошибок.

## Мини-шпаргалка

- Хуки вызывают только на верхнем уровне.
- Хуки нельзя вызывать в условиях, циклах и вложенных функциях.
- Хуки вызывают только компоненты и custom hooks.
- React сопоставляет хуки по порядку вызовов.
- Условную логику помещай внутрь хука.
