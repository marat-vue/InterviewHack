# Псевдомассив

> [!summary] Коротко
> Псевдомассив (array-like object) - объект с числовыми индексами и `length`, но без методов массива вроде `map`, `filter`, `push`.

## Вопрос

Что такое псевдомассив?

## Пример структуры

```javascript
const arrayLike = {
  0: "a",
  1: "b",
  length: 2,
};
```

Он похож на массив:

```javascript
arrayLike[0];     // "a"
arrayLike.length; // 2
```

Но это не массив:

```javascript
Array.isArray(arrayLike); // false
arrayLike.map;            // undefined
```

## Примеры псевдомассивов

- `arguments`;
- `NodeList`;
- `HTMLCollection`;
- некоторые DOM-коллекции.

```javascript
function demo() {
  Array.isArray(arguments); // false
}
```

## Как преобразовать в массив

```javascript
const arr = Array.from(arrayLike);
```

или:

```javascript
const arr = [...iterable];
```

Важно: spread работает только с iterable. Не каждый array-like является iterable.

## Псевдомассив vs iterable

Array-like:

```javascript
{ 0: "a", length: 1 }
```

Iterable имеет `[Symbol.iterator]`.

```javascript
const iterable = "abc";
```

Строка iterable и array-like по поведению, но обычный объект с `length` - не обязательно iterable.

## Мини-шпаргалка

| Признак | Массив | Псевдомассив |
| --- | --- | --- |
| индексы | да | да |
| `length` | да | да |
| `Array.isArray` | true | false |
| методы массива | да | нет |
| преобразование | уже массив | `Array.from()` |
