# Объектный литерал

> [!summary] Коротко
> Объектный литерал - способ создать объект прямо в коде с помощью `{}` и перечисления свойств.

## Вопрос

Что такое объектный литерал?

## Базовый пример

```javascript
const user = {
  name: "Anna",
  age: 25,
};
```

Это литеральная запись объекта.

## Свойства

```javascript
const product = {
  title: "Book",
  price: 1000,
  available: true,
};
```

Каждое свойство состоит из ключа и значения.

## Методы

В объектном литерале можно объявлять методы.

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};
```

## Сокращенная запись

Если имя свойства совпадает с именем переменной:

```javascript
const name = "Anna";
const age = 25;

const user = {
  name,
  age,
};
```

Это эквивалентно:

```javascript
const user = {
  name: name,
  age: age,
};
```

## Вычисляемые свойства

```javascript
const key = "role";

const user = {
  name: "Anna",
  [key]: "admin",
};
```

## Мини-шпаргалка

```javascript
const obj = {};
const user = { name: "Anna" };
const obj = { [key]: value };
const obj = { method() {} };
const obj = { name, age };
```
