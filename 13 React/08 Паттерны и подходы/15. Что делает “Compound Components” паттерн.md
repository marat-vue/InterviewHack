# Что делает “Compound Components” паттерн?

> [!summary]
> Compound Components - это паттерн, где несколько компонентов работают как единый составной компонент. Родитель хранит общее состояние и контекст, а дочерние части получают нужные данные не через длинную цепочку props, а через композицию.

## Идея

Пример API:

```jsx
<Tabs defaultValue="profile">
  <Tabs.List>
    <Tabs.Trigger value="profile">Profile</Tabs.Trigger>
    <Tabs.Trigger value="settings">Settings</Tabs.Trigger>
  </Tabs.List>

  <Tabs.Panel value="profile">Profile content</Tabs.Panel>
  <Tabs.Panel value="settings">Settings content</Tabs.Panel>
</Tabs>
```

Пользователь компонента сам собирает структуру, но все части связаны общей логикой `Tabs`.

## Реализация через context

```jsx
const TabsContext = createContext(null)

function Tabs({ defaultValue, children }) {
  const [value, setValue] = useState(defaultValue)

  return (
    <TabsContext.Provider value={{ value, setValue }}>
      {children}
    </TabsContext.Provider>
  )
}

function TabsTrigger({ value, children }) {
  const context = useContext(TabsContext)
  const isActive = context.value === value

  return (
    <button
      aria-selected={isActive}
      onClick={() => context.setValue(value)}
    >
      {children}
    </button>
  )
}

function TabsPanel({ value, children }) {
  const context = useContext(TabsContext)

  if (context.value !== value) {
    return null
  }

  return <div>{children}</div>
}

Tabs.Trigger = TabsTrigger
Tabs.Panel = TabsPanel
```

## Зачем это нужно?

Паттерн дает:

- выразительный API;
- гибкую композицию;
- меньше prop drilling;
- удобство для UI-библиотек;
- контроль общего состояния внутри компонента.

## Где применяется?

- `Tabs`;
- `Accordion`;
- `Select`;
- `DropdownMenu`;
- `Modal`;
- `Table`;
- `Form`.

## Важные нюансы

Compound Components часто используют context. Это удобно, но изменение context value может вызывать render всех потребителей. Для тяжелых компонентов надо помнить про разделение context, memoization или селекторы.

Также важно валидировать использование:

```jsx
function useTabsContext() {
  const context = useContext(TabsContext)

  if (!context) {
    throw new Error('Tabs components must be used inside <Tabs>')
  }

  return context
}
```

## Мини-шпаргалка

- Compound Components дают API из связанных подкомпонентов.
- Родитель хранит общее состояние.
- Дочерние части читают состояние через context.
- Паттерн хорош для сложных UI-компонентов.
- Нужно следить за производительностью context.
