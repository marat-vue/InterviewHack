# Как писать meta description?

> [!summary]
> Meta description - это краткое описание страницы в `<head>`. Оно не является прямым "рычагом позиций", но влияет на понимание страницы и может повлиять на клики из выдачи.

## Как выглядит meta description?

```html
<meta
  name="description"
  content="Разбираем SEO для frontend-приложений: SSR, SSG, meta tags, structured data, Core Web Vitals и частые ошибки."
>
```

## Что писать в description?

Описание должно:

- кратко раскрывать пользу страницы;
- соответствовать фактическому контенту;
- включать важные термины естественно;
- отличаться от других страниц;
- помогать пользователю понять, стоит ли переходить.

## Примеры

Плохо:

```text
SEO, продвижение, оптимизация, сайт, заказать, дешево.
```

Лучше:

```text
Пошаговый чеклист SEO-аудита: индексация, sitemap, canonical, скорость, structured data и аналитика.
```

## Всегда ли description показывается в выдаче?

Нет. Поисковик может выбрать фрагмент текста со страницы, если он лучше подходит под конкретный запрос.

Но description все равно нужен:

- как понятное резюме страницы;
- как fallback для сниппета;
- как часть качества шаблона;
- для социальных превью вместе с Open Graph.

## Мини-шпаргалка

- Description должен быть уникальным и полезным.
- Он не должен быть набором ключей.
- Поисковик может переписать сниппет.
- Description должен соответствовать содержанию страницы.
- Для SPA/SSR он должен обновляться на каждом маршруте.
