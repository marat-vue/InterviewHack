# Что такое document

> [!summary] Коротко
> `document` - объект, который представляет текущую HTML-страницу и дает доступ к DOM.

## Вопрос

Что такое `document` в браузере?

## Определение

`document` - глобальный объект браузера, через который JavaScript работает с содержимым страницы. Он представляет DOM-документ и содержит методы для поиска, создания и изменения элементов.

`document` является свойством объекта `window`.

## Поиск элементов

```javascript
const title = document.querySelector('h1');
const buttons = document.querySelectorAll('button');
```

## Создание элементов

```javascript
const message = document.createElement('p');

message.textContent = 'Saved';
document.body.append(message);
```

## Работа с документом

```javascript
console.log(document.title);
console.log(document.body);
console.log(document.documentElement); // html
```

`document.documentElement` указывает на корневой элемент `<html>`.

## Частые методы и свойства

| API | Что делает |
| --- | --- |
| `querySelector()` | ищет первый элемент |
| `querySelectorAll()` | ищет все подходящие элементы |
| `createElement()` | создает элемент |
| `body` | доступ к `<body>` |
| `title` | заголовок страницы |

## Мини-шпаргалка

```javascript
document.querySelector('.item');
document.createElement('div');
document.body.append(element);
```
