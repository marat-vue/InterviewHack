# Вложенные таймеры

> [!NOTE] Коротко
> Вложенные таймеры - это таймеры, которые планируются внутри callback другого таймера. В браузерах для глубокой вложенности может применяться минимальная задержка.

## Вопрос

Как работают вложенные `setTimeout` и почему они могут выполняться не сразу?

## Определение

Вложенный таймер создается, когда новый `setTimeout()` вызывается внутри callback предыдущего. Такой прием часто используют вместо `setInterval`, чтобы планировать следующий запуск только после завершения текущей работы.

## Пример

```javascript
setTimeout(() => {
  console.log('first');

  setTimeout(() => {
    console.log('second');
  }, 0);
}, 0);
```

Второй таймер начнет отсчет только тогда, когда выполнится callback первого таймера.

## Рекурсивный setTimeout

```javascript
function tick() {
  console.log('tick');

  setTimeout(tick, 1000);
}

setTimeout(tick, 1000);
```

Этот вариант удобен, если следующая итерация должна начаться после завершения предыдущей.

## Отличие от setInterval

```javascript
setInterval(() => {
  console.log('tick');
}, 1000);
```

`setInterval` планирует повторяющиеся запуски по интервалу. Если callback тяжелый, интервалы могут начать отставать. Рекурсивный `setTimeout` дает больше контроля.

## Минимальная задержка

Браузеры могут ограничивать слишком частые вложенные таймеры и увеличивать минимальную задержку. Поэтому `setTimeout(fn, 0)` во вложенных цепочках не стоит воспринимать как точный ноль.

## Мини-шпаргалка

```javascript
function loop() {
  doWork();
  setTimeout(loop, delay);
}
```
