# Как описывать handlers в MSW?

> [!summary]
> Handler в MSW описывает, какой запрос нужно перехватить и какой response вернуть. В handler можно читать params, query, body, headers, возвращать status codes, errors и разные сценарии для отдельных тестов.

## GET handler

```ts
import { http, HttpResponse } from 'msw';

export const handlers = [
  http.get('/api/products', () => {
    return HttpResponse.json([
      { id: 1, title: 'Keyboard' },
      { id: 2, title: 'Mouse' },
    ]);
  }),
];
```

## Params

```ts
http.get('/api/users/:id', ({ params }) => {
  return HttpResponse.json({
    id: Number(params.id),
    name: 'Ann',
  });
});
```

## Query params

```ts
http.get('/api/products', ({ request }) => {
  const url = new URL(request.url);
  const search = url.searchParams.get('search');

  return HttpResponse.json({
    items: [{ id: 1, title: search ?? 'Keyboard' }],
  });
});
```

## Request body

```ts
http.post('/api/login', async ({ request }) => {
  const body = await request.json() as { email: string };

  return HttpResponse.json({
    token: 'test-token',
    email: body.email,
  });
});
```

## Error scenario в конкретном тесте

```ts
server.use(
  http.get('/api/users/:id', () => {
    return HttpResponse.json(
      { message: 'User not found' },
      { status: 404 },
    );
  }),
);
```

`server.use` переопределяет handler только для текущего теста, если после теста вызывается `server.resetHandlers()`.

## Мини-шпаргалка

- `http.get`, `http.post`, `http.patch`, `http.delete` описывают REST handlers.
- `HttpResponse.json(data, { status })` возвращает JSON.
- В handler можно читать params, query, body и headers.
- `server.use` задает scenario override.
- После теста очищай overrides через `resetHandlers`.
