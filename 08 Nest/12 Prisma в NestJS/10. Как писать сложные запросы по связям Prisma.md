# Как писать сложные запросы по связям Prisma?

> [!summary]
> Для сложных запросов из нескольких таблиц Prisma использует relation queries: `include`, nested `select`, relation filters `some`, `none`, `every`, а также фильтры по связанным моделям.

## Include nested relations

```ts
const users = await this.prisma.user.findMany({
  include: {
    posts: {
      where: { published: true },
      orderBy: { createdAt: 'desc' },
      select: {
        id: true,
        title: true,
      },
    },
  },
});
```

## Relation filter some

Найти пользователей, у которых есть опубликованные посты.

```ts
const users = await this.prisma.user.findMany({
  where: {
    posts: {
      some: {
        published: true,
      },
    },
  },
});
```

## Relation filter none

Найти пользователей без постов.

```ts
const users = await this.prisma.user.findMany({
  where: {
    posts: {
      none: {},
    },
  },
});
```

## Фильтр по родителю

```ts
const posts = await this.prisma.post.findMany({
  where: {
    author: {
      email: { endsWith: '@example.com' },
    },
  },
});
```

## Count relations

```ts
const users = await this.prisma.user.findMany({
  include: {
    _count: {
      select: { posts: true },
    },
  },
});
```

## Мини-шпаргалка

- `include` подгружает связи.
- Nested `where/orderBy/select` ограничивают relation payload.
- `some` - есть хотя бы одна связанная запись.
- `none` - нет связанных записей.
- `_count` считает связанные записи.
