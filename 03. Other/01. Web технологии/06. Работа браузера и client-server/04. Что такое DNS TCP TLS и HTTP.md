# Что такое DNS, TCP, TLS и HTTP?

> [!summary]
> DNS, TCP, TLS и HTTP - разные уровни сетевого взаимодействия. DNS находит IP, TCP устанавливает надежное соединение, TLS защищает канал, HTTP передает request и response.

## Коротко по слоям

```txt
DNS  -> куда идти?
TCP  -> как установить надежное соединение?
TLS  -> как защитить канал?
HTTP -> что запросить и что вернуть?
```

## DNS

DNS превращает domain name в IP address:

```txt
api.example.com -> 203.0.113.10
```

Если DNS не работает, browser не знает, куда подключаться.

## TCP

TCP обеспечивает надежную доставку байтов между client и server.

Для HTTPS поверх TCP затем запускается TLS handshake.

## TLS

TLS:

- шифрует данные;
- проверяет server certificate;
- защищает от подмены данных в пути;
- создает session keys для защищенного обмена.

## HTTP

HTTP уже внутри соединения передает смысл:

```http
GET /api/users HTTP/1.1
Host: api.example.com
```

HTTP знает methods, headers, status codes, body.

## Где это видно?

В DevTools -> Network -> Timing можно увидеть:

- queueing;
- DNS lookup;
- initial connection;
- SSL/TLS;
- request sent;
- waiting for server response;
- content download.

## Мини-шпаргалка

- DNS ищет IP.
- TCP создает надежное соединение.
- TLS защищает соединение.
- HTTP передает request/response.
- DevTools Timing помогает увидеть, где задержка.
