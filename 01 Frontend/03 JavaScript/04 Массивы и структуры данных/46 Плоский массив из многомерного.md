# Плоский массив из многомерного

> [!NOTE] Коротко
> Чтобы превратить вложенный массив в плоский, используют `flat(depth)`. Для любой глубины часто пишут `flat(Infinity)`.

## Вопрос

Как "расплющить" многомерный массив?

## Определение

Плоский массив - это массив без вложенных массивов. Метод `flat()` создает новый массив, в который поднимает элементы из вложенных массивов на указанную глубину.

## Один уровень вложенности

```javascript
const arr = [1, [2, 3], 4];

console.log(arr.flat()); // [1, 2, 3, 4]
```

По умолчанию `flat()` раскрывает только один уровень.

## Несколько уровней

```javascript
const nested = [1, [2, [3, [4]]]];

console.log(nested.flat(2));        // [1, 2, 3, [4]]
console.log(nested.flat(Infinity)); // [1, 2, 3, 4]
```

## flat() не меняет исходный массив

```javascript
const original = [1, [2]];
const result = original.flat();

console.log(result);   // [1, 2]
console.log(original); // [1, [2]]
```

## Особенность с пустыми слотами

```javascript
const arr = [1, , [2, , 3]];

console.log(arr.flat()); // [1, 2, 3]
```

`flat()` удаляет пустые слоты на раскрываемом уровне.

## Мини-шпаргалка

```javascript
arr.flat();         // раскрыть 1 уровень
arr.flat(2);        // раскрыть 2 уровня
arr.flat(Infinity); // раскрыть полностью
```
