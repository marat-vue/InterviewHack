# Как изучать Tailwind CSS

> [!summary]
> Tailwind CSS стоит изучать как utility-first CSS framework: вместо написания отдельных классов под каждый компонент ты собираешь дизайн из готовых utility-классов прямо в разметке.

## Что такое Tailwind?

Tailwind CSS - utility-first CSS framework.

Обычный CSS-подход:

```tsx
<button className="primary-button">Save</button>
```

```css
.primary-button {
  display: inline-flex;
  border-radius: 0.5rem;
  background: #2563eb;
  padding: 0.5rem 1rem;
  color: white;
}
```

Tailwind-подход:

```tsx
<button className="inline-flex rounded-lg bg-blue-600 px-4 py-2 text-white">
  Save
</button>
```

## Что нужно знать по порядку?

1. Установка с Vite.
2. Utility-классы: spacing, typography, colors, layout.
3. Responsive variants: `sm:`, `md:`, `lg:`.
4. States: `hover:`, `focus:`, `disabled:`.
5. Dark mode: `dark:`.
6. Flex/grid.
7. Переиспользование через компоненты.
8. Конфликты классов и `tailwind-merge`.
9. Дизайн-токены и theme.
10. Когда Tailwind уместен, а когда лучше UI-kit.

## Почему Tailwind популярен?

- быстро прототипировать;
- легко поддерживать консистентные spacing/color scales;
- не нужно придумывать имена CSS-классов;
- стили локально видны рядом с markup;
- production CSS содержит только использованные utilities.

## Главная ловушка

Tailwind не отменяет дизайн-мышление.

Плохой Tailwind:

```tsx
<div className="mt-2 ml-3 text-[13px] text-[#313131] rounded-[11px]">
```

Хороший Tailwind:

```tsx
<div className="mt-2 rounded-md text-sm text-zinc-800">
```

Лучше использовать систему spacing, colors, typography, а не превращать Tailwind в хаотичный inline CSS.

## Что отвечать на собеседовании?

Tailwind - utility-first CSS framework, который позволяет собирать интерфейс из маленьких atomic classes. Он ускоряет разработку и поддерживает дизайн-системность через шкалы spacing, colors, typography и responsive variants. Его нужно использовать дисциплинированно, вынося повторяющиеся паттерны в компоненты.

## Мини-шпаргалка

- `flex`, `grid`, `gap-4` - layout.
- `p-4`, `mt-2`, `space-y-3` - spacing.
- `text-sm`, `font-medium` - typography.
- `hover:`, `focus:`, `disabled:` - states.
- `md:`, `lg:` - responsive.
- `dark:` - dark mode.
