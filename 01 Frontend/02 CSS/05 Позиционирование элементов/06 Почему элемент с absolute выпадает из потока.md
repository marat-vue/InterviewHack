# Почему элемент с absolute выпадает из потока?

> [!NOTE]
> Элемент с `position: absolute` выпадает из нормального потока, потому что его положение рассчитывается отдельно через координаты относительно containing block, а не через обычное расположение соседей.

## Главное

Normal flow раскладывает элементы один за другим. `absolute` говорит браузеру: "не резервируй для меня место, поставь меня по координатам".

```css
.badge {
  position: absolute;
  top: 0;
  right: 0;
}
```

## Пример

```html
<div class="card">
  <span class="badge">New</span>
  <h2>Заголовок</h2>
  <p>Описание карточки.</p>
</div>
```

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

`h2` и `p` не будут отодвинуты размером `.badge`, потому что бейдж не участвует в потоке.

## Что это дает

- Можно накладывать элементы поверх других.
- Можно ставить бейджи и tooltip в углы.
- Можно делать кастомные декоративные слои.
- Можно точно позиционировать элементы внутри компонента.

## Риски

Абсолютные элементы могут перекрывать контент, выпадать за контейнер, ломаться на маленьких экранах и становиться недоступными, если использовать их для основной структуры страницы.

## Мини-шпаргалка

- `absolute` не резервирует место в потоке.
- Положение считается по координатам.
- Соседи не знают размер absolute-элемента.
- Хорош для overlay и декоративных элементов.
- Плох для основной сетки страницы.
- Для layout чаще лучше Flexbox или Grid.
