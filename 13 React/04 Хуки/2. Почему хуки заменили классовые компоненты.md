# Почему хуки заменили классовые компоненты?

> [!summary]
> Хуки не удалили классовые компоненты из React, но сделали функциональные компоненты основным способом разработки. Они позволяют использовать state, effects и переиспользуемую логику без `class`, `this` и lifecycle methods.

## Что было до хуков?

Для state и lifecycle раньше писали классы:

```jsx
class Counter extends React.Component {
  state = { count: 0 }

  componentDidMount() {
    document.title = 'Counter'
  }

  render() {
    return (
      <button onClick={() => this.setState({ count: this.state.count + 1 })}>
        {this.state.count}
      </button>
    )
  }
}
```

## Как стало с хуками?

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  useEffect(() => {
    document.title = 'Counter'
  }, [])

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
```

Код стал короче и не требует `this`.

## Какие проблемы классов решают хуки?

- Сложность `this`.
- Разброс логики по lifecycle methods.
- Трудное переиспользование stateful-логики.
- Wrapper hell через HOC/render props.
- Сложность разделения независимых effects.
- Большие классы, где смешано много задач.

## Переиспользование логики

С хуками можно вынести логику в custom hook:

```jsx
function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth)

  useEffect(() => {
    function handleResize() {
      setWidth(window.innerWidth)
    }

    window.addEventListener('resize', handleResize)
    return () => window.removeEventListener('resize', handleResize)
  }, [])

  return width
}
```

Теперь эту логику можно использовать в разных компонентах.

## Классы все еще нужны?

Классы можно встретить:

- в legacy-коде;
- в старых библиотеках;
- в Error Boundary;
- в проектах, написанных до хуков.

Для нового кода обычно выбирают функциональные компоненты.

## Мини-шпаргалка

- Хуки сделали функциональные компоненты основным стилем React.
- Они заменили большинство сценариев классов.
- Хуки убрали необходимость в `this`.
- Custom hooks упростили переиспользование логики.
- Классы важно уметь читать в legacy-коде.
