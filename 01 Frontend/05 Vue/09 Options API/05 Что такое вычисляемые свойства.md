# Что такое вычисляемые свойства?

> [!NOTE]
> Вычисляемые свойства в Options API объявляются в `computed`. Они зависят от реактивных данных, кэшируются и пересчитываются только при изменении зависимостей.

## Вопрос

Что такое вычисляемые свойства?

## Базовый пример

```vue
<script>
export default {
  data() {
    return {
      firstName: "Анна",
      lastName: "Петрова",
    };
  },
  computed: {
    fullName() {
      return `${this.firstName} ${this.lastName}`;
    },
  },
};
</script>

<template>
  <p>{{ fullName }}</p>
</template>
```

`fullName` пересчитается только при изменении `firstName` или `lastName`.

## Зачем нужны computed

Они помогают не хранить дублирующиеся данные в state.

```javascript
computed: {
  total() {
    return this.price * this.count;
  }
}
```

## Writable computed

```javascript
computed: {
  fullName: {
    get() {
      return `${this.firstName} ${this.lastName}`;
    },
    set(value) {
      [this.firstName, this.lastName] = value.split(" ");
    },
  },
}
```

## Мини-шпаргалка

- `computed` описывает производные значения.
- Результат кэшируется.
- В template используется как свойство, без `()`.
- Side effects лучше делать через `watch`, не через `computed`.
