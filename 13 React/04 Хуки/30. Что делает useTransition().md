# Что делает useTransition?

> [!summary]
> `useTransition` позволяет пометить часть обновлений состояния как transition, то есть менее срочные неблокирующие обновления. Это помогает сохранить интерфейс отзывчивым, когда дорогое обновление может мешать вводу или кликам.

## Базовый синтаксис

```jsx
const [isPending, startTransition] = useTransition()
```

`isPending` показывает, что transition еще выполняется.

`startTransition` помечает state updates как transition:

```jsx
startTransition(() => {
  setTab(nextTab)
})
```

## Пример с вкладками

```jsx
function Tabs() {
  const [tab, setTab] = useState('posts')
  const [isPending, startTransition] = useTransition()

  function selectTab(nextTab) {
    startTransition(() => {
      setTab(nextTab)
    })
  }

  return (
    <>
      <button onClick={() => selectTab('posts')}>Posts</button>
      <button onClick={() => selectTab('comments')}>Comments</button>
      {isPending && <span>Обновляем...</span>}
      <TabContent tab={tab} />
    </>
  )
}
```

Если `TabContent` тяжелый, React может не блокировать более срочные действия пользователя.

## Срочные и несрочные обновления

Срочное:

```text
пользователь печатает в input -> символ должен появиться сразу
```

Transition:

```text
после ввода нужно перерендерить тяжелый список
```

Transition updates могут быть прерваны более срочными обновлениями.

## Чего нельзя делать?

Transition updates нельзя использовать для управления текстовым input:

```jsx
startTransition(() => {
  setInputValue(event.target.value)
})
```

Значение input должно обновляться срочно.

## Мини-шпаргалка

- `useTransition` возвращает `[isPending, startTransition]`.
- Transition - неблокирующее обновление UI.
- Подходит для тяжелых переключений и списков.
- Не используй transition для controlled input value.
- `isPending` помогает показать мягкий индикатор.
