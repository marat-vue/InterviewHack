# Какие уровни кэширования есть в Next.js?

> [!summary]
> В Next.js есть несколько уровней кеширования: request memoization, Data Cache, Full Route Cache, Router Cache, Image Optimization Cache и внешние HTTP/CDN caches. В новых версиях также важно знать `use cache` и Cache Components как развивающуюся модель явного кеширования.

## Request memoization

Убирает дубли одинаковых запросов в рамках одного render pass.

```tsx
const userA = await getUser(id)
const userB = await getUser(id)
```

## Data Cache

Кеширует результаты server `fetch`.

```tsx
await fetch(url, {
  next: { revalidate: 3600 },
})
```

## Full Route Cache

Кеширует результат статического route: HTML и RSC payload.

Подходит для:

- SSG;
- ISR;
- публичного контента;
- routes без request-specific данных.

## Router Cache

Клиентский cache в браузере. Используется при навигации, back/forward и prefetch.

## Image Optimization Cache

`next/image` кеширует оптимизированные изображения.

## use cache и Cache Components

В современной модели Next.js постепенно усиливает явное кеширование через директиву:

```tsx
'use cache'
```

И функции настройки lifetime/tags. На собеседовании полезно знать, что Next.js развивает cache model, но в большинстве проектов все еще встречаются `fetch` options, `revalidatePath` и `revalidateTag`.

## Что отвечать на собеседовании?

Кеширование в Next.js многоуровневое: есть Data Cache для `fetch`, Full Route Cache для статического output, Router Cache на клиенте, request memoization и image cache. Управлять свежестью можно через `revalidate`, tags и on-demand invalidation.

## Частые ошибки

- Путать Data Cache и Router Cache.
- Думать, что `router.refresh()` очищает все server caches.
- Кешировать private данные.
- Не учитывать CDN/browser cache.
- Не знать, что cache model Next.js развивается.

## Мини-шпаргалка

- Request memoization - один render pass.
- Data Cache - server fetch.
- Full Route Cache - route output.
- Router Cache - client navigation.
- Image Cache - optimized images.
- `use cache` - новая явная модель кеширования.
