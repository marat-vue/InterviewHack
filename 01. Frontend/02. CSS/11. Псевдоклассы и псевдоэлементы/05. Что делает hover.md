# Что делает hover?

> [!NOTE]
> `:hover` - это CSS-псевдокласс, который применяет стили к элементу, когда пользователь наводит на него указатель.

## Главное

```css
.button:hover {
  background: #1d4ed8;
}
```

Правило сработает при наведении мыши или другого pointing device.

## Пример со ссылкой

```css
a {
  color: #2563eb;
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}
```

Hover помогает показать, что элемент интерактивный.

## Hover не заменяет focus

Пользователь клавиатуры не использует hover. Для него нужен `:focus-visible`.

```css
.button:hover,
.button:focus-visible {
  background: #1d4ed8;
}
```

Так состояние доступно и мыши, и клавиатуре.

## Touch-устройства

На телефонах hover может работать непредсказуемо или не иметь смысла. Для важных действий нельзя полагаться только на hover.

```css
@media (hover: hover) {
  .card:hover {
    transform: translateY(-2px);
  }
}
```

## Мини-шпаргалка

- `:hover` срабатывает при наведении.
- Подходит для ссылок, кнопок, карточек.
- Не должен быть единственным способом показать важную информацию.
- Для клавиатуры нужен `:focus-visible`.
- Для touch-устройств hover стоит использовать осторожно.
