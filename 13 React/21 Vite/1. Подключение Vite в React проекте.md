# Подключение Vite в React проекте

> [!summary]
> Новый React-проект на Vite создают через `npm create vite@latest`, выбирают React/TypeScript template, устанавливают зависимости и запускают dev server командой `npm run dev`.

## Создание проекта

```bash
npm create vite@latest my-app
```

Дальше выбирают:

```text
Framework: React
Variant: TypeScript
```

Установка зависимостей:

```bash
cd my-app
npm install
npm run dev
```

## Типичная структура

```text
my-app/
  index.html
  package.json
  vite.config.ts
  src/
    main.tsx
    App.tsx
    index.css
```

## main.tsx

```tsx
import { createRoot } from 'react-dom/client'
import './index.css'
import { App } from './App'

createRoot(document.getElementById('root')!).render(<App />)
```

## vite.config.ts

```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

## Основные scripts

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  }
}
```

| Script | Что делает |
|---|---|
| `dev` | запускает dev server |
| `build` | собирает production |
| `preview` | локально показывает production build |

## Что отвечать на собеседовании?

React-проект на Vite создают через `npm create vite@latest`, React support подключается plugin `@vitejs/plugin-react`, входная HTML-точка - `index.html`, приложение монтируется в `src/main.tsx`, а сборка управляется scripts `dev`, `build`, `preview`.

## Мини-шпаргалка

- Create: `npm create vite@latest`.
- React plugin: `@vitejs/plugin-react`.
- Config: `vite.config.ts`.
- Entry HTML: `index.html`.
- React entry: `src/main.tsx`.
- Build: `npm run build`.
