# Как тестировать Vue components через Vitest?

> [!summary]
> Vitest запускает тесты, а Vue Test Utils монтирует Vue-компоненты и дает wrapper для взаимодействия с ними. Вместе они позволяют проверять props, events, slots, forms, router, store и async UI.

## Что нужно установить?

```bash
npm install -D vitest @vue/test-utils jsdom
```

Для Vue/Vite проекта:

```ts
export default defineConfig({
  plugins: [vue()],
  test: {
    environment: 'jsdom',
  },
});
```

## Пример компонента

```vue
<template>
  <button @click="$emit('save')">
    {{ label }}
  </button>
</template>
```

## Тест

```ts
import { mount } from '@vue/test-utils';
import { expect, test } from 'vitest';
import SaveButton from './SaveButton.vue';

test('emits save after click', async () => {
  const wrapper = mount(SaveButton, {
    props: { label: 'Сохранить' },
  });

  await wrapper.get('button').trigger('click');

  expect(wrapper.text()).toContain('Сохранить');
  expect(wrapper.emitted('save')).toHaveLength(1);
});
```

## Что где отвечает?

| Инструмент | Роль |
|---|---|
| Vitest | запускает тесты, дает `test`, `expect`, `vi` |
| Vue Test Utils | монтирует компонент и дает `wrapper` |
| jsdom | дает DOM-окружение |
| Vite config | plugins, aliases, transforms |

## Мини-шпаргалка

- Vitest - runner.
- Vue Test Utils - mount и wrapper.
- Для DOM нужен `environment: 'jsdom'`.
- Проверяй rendered result и events.
- Не обращайся к `wrapper.vm`, если можно проверить поведение.
