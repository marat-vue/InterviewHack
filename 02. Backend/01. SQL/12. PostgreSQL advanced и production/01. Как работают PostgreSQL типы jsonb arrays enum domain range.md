# Как работают PostgreSQL типы jsonb, arrays, enum, domain и range?

> [!NOTE]
> PostgreSQL расширяет стандартный SQL богатыми типами данных. Для backend-разработчика особенно важны `jsonb`, arrays, enums, domains и ranges: они помогают точнее моделировать данные, но требуют понимания индексов и ограничений.

## `jsonb`

`jsonb` хранит JSON в бинарном формате и поддерживает индексацию.

```sql
CREATE TABLE events (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  payload jsonb NOT NULL
);

SELECT *
FROM events
WHERE payload @> '{"type": "user.created"}';
```

Когда использовать:

- event payload;
- flexible metadata;
- integration data;
- редко меняющиеся nested settings.

Когда не использовать:

- вместо всех нормальных колонок;
- для данных с важными foreign keys;
- когда нужны частые JOIN по полям внутри JSON.

## Arrays

```sql
CREATE TABLE posts (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tags text[] NOT NULL DEFAULT '{}'
);

SELECT *
FROM posts
WHERE tags @> ARRAY['nodejs'];
```

Arrays удобны для маленьких списков. Для many-to-many relations чаще лучше отдельная таблица.

## Enum

```sql
CREATE TYPE order_status AS ENUM (
  'pending',
  'paid',
  'cancelled'
);

CREATE TABLE orders (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  status order_status NOT NULL
);
```

Enum хорош, когда набор значений мал и меняется редко. Если значения часто меняются бизнесом, лучше reference table.

## Domain

Domain - reusable type with constraints.

```sql
CREATE DOMAIN email_text AS text
CHECK (VALUE ~* '^[^@]+@[^@]+$');

CREATE TABLE users (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email email_text NOT NULL
);
```

Domain полезен, когда одно правило нужно повторять в разных таблицах.

## Range types

```sql
CREATE TABLE bookings (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  room_id bigint NOT NULL,
  period tstzrange NOT NULL
);

SELECT *
FROM bookings
WHERE period && tstzrange('2026-08-06 10:00Z', '2026-08-06 11:00Z');
```

Range types удобны для расписаний, бронирований, ценовых периодов, validity intervals.

## Мини-шпаргалка

- `jsonb` - гибкий JSON с индексами.
- Arrays - маленькие списки, не замена many-to-many.
- Enum - стабильный набор значений.
- Domain - reusable constraint type.
- Range - интервалы с операторами пересечения.
