# Что такое псевдоэлемент?

> [!NOTE]
> **Псевдоэлемент** - это часть CSS-селектора, которая стилизует виртуальную часть элемента: например контент до или после элемента, первую строку, первую букву или выделение текста.

## Главное

Псевдоэлемент обычно пишется через два двоеточия.

```css
.badge::before {
  content: "";
  width: 8px;
  height: 8px;
  background: #22c55e;
}
```

## before и after

```css
.required::after {
  content: " *";
  color: #b91c1c;
}
```

`::before` и `::after` создают виртуальный inline-потомок внутри элемента. Для их отображения обычно нужен `content`.

## Текстовые псевдоэлементы

```css
p::first-line {
  font-weight: 700;
}

p::first-letter {
  font-size: 2rem;
}
```

Они стилизуют первую строку или первую букву текста.

## Псевдоэлемент vs псевдокласс

```text
:hover   -> состояние элемента
::before -> виртуальная часть элемента
```

Псевдокласс отвечает за условие, псевдоэлемент - за часть.

## Мини-шпаргалка

- Псевдоэлемент обычно начинается с `::`.
- `::before` и `::after` часто требуют `content`.
- Псевдоэлемент не добавляет настоящий HTML-узел.
- Важный текст лучше не прятать только в `content`.
- Псевдокласс выбирает состояние, псевдоэлемент - часть элемента.
