# Как передать JSX внутрь другого компонента?

> [!summary]
> JSX можно передавать в компонент через `children` или через обычные props. `children` подходит для основного вложенного содержимого, а именованные props - для нескольких отдельных областей, например `header`, `footer`, `sidebar`.

## Через children

```jsx
function Modal({ children }) {
  return (
    <div className="modal">
      {children}
    </div>
  )
}

function App() {
  return (
    <Modal>
      <h2>Удалить файл?</h2>
      <p>Это действие нельзя отменить.</p>
    </Modal>
  )
}
```

Так компонент `Modal` не знает заранее, что именно будет внутри.

## Через именованный prop

```jsx
function Page({ header, content, footer }) {
  return (
    <>
      <header>{header}</header>
      <main>{content}</main>
      <footer>{footer}</footer>
    </>
  )
}
```

Использование:

```jsx
<Page
  header={<h1>Профиль</h1>}
  content={<ProfileForm />}
  footer={<SaveButton />}
/>
```

Именованные props удобны, когда у компонента несколько slots.

## Через render prop

Иногда передают функцию, которая возвращает JSX:

```jsx
function DataView({ data, renderItem }) {
  return (
    <ul>
      {data.map((item) => (
        <li key={item.id}>{renderItem(item)}</li>
      ))}
    </ul>
  )
}
```

Использование:

```jsx
<DataView
  data={users}
  renderItem={(user) => <UserLink user={user} />}
/>
```

## Что выбрать?

| Сценарий | Подход |
|---|---|
| Один основной блок внутри | `children` |
| Несколько областей | именованные JSX props |
| Нужно передать данные обратно в разметку | render prop |
| Нужна группа связанных компонентов | composition или compound components |

## Мини-шпаргалка

- JSX можно передавать как обычное значение.
- `children` - главный способ вложить контент.
- Именованные props удобны для нескольких слотов.
- Render prop - функция, которая возвращает JSX.
- Не усложняй API компонента, если достаточно `children`.
