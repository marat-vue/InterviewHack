# `shift()`

> [!NOTE] Коротко
> `shift()` удаляет первый элемент массива, сдвигает остальные элементы влево, мутирует исходный массив и возвращает удаленный элемент.

## Вопрос

Что делает `shift()`?

## Пример

```javascript
const arr = ["a", "b", "c"];

const removed = arr.shift();

console.log(removed); // "a"
console.log(arr);     // ["b", "c"]
```

## Пустой массив

```javascript
const arr = [];

arr.shift(); // undefined
```

## Производительность

`shift()` может быть дороже, чем `pop()`, потому что после удаления первого элемента нужно сдвинуть индексы остальных элементов.

```javascript
["a", "b", "c"];
// после shift:
["b", "c"];
// "b" переехал с индекса 1 на 0
```

Для очередей на больших объемах иногда используют другие структуры или индекс начала.

## Без мутации

Получить массив без первого элемента:

```javascript
const withoutFirst = arr.slice(1);
```

Первый элемент без удаления:

```javascript
const first = arr[0];
```

## Мини-шпаргалка

| Задача | Код |
| --- | --- |
| удалить первый | `arr.shift()` |
| удалить последний | `arr.pop()` |
| получить первый | `arr[0]` |
| копия без первого | `arr.slice(1)` |
| мутирует исходный | да |
