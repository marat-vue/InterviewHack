# Что делает Outlet?

> [!summary]
> `<Outlet />` - это компонент React Router, который показывает совпавший дочерний route внутри родительского route. Если дочерний маршрут не совпал, `Outlet` ничего не отображает или показывает index route, если он описан.

## Пример

```jsx
<Routes>
  <Route path="/account" element={<AccountLayout />}>
    <Route index element={<AccountOverview />} />
    <Route path="security" element={<SecurityPage />} />
    <Route path="billing" element={<BillingPage />} />
  </Route>
</Routes>
```

Родитель:

```jsx
import { Outlet } from 'react-router-dom'

function AccountLayout() {
  return (
    <div>
      <AccountNavigation />
      <Outlet />
    </div>
  )
}
```

## Что увидит пользователь?

| URL | Что рендерится внутри `Outlet` |
|---|---|
| `/account` | `AccountOverview` |
| `/account/security` | `SecurityPage` |
| `/account/billing` | `BillingPage` |

Общий `AccountNavigation` остается на месте.

## Outlet context

Через `Outlet` можно передать context дочерним routes.

```jsx
function AccountLayout() {
  const user = useCurrentUser()

  return <Outlet context={{ user }} />
}
```

В дочернем route:

```jsx
import { useOutletContext } from 'react-router-dom'

function SecurityPage() {
  const { user } = useOutletContext()

  return <h1>Security for {user.email}</h1>
}
```

Для больших приложений не стоит превращать outlet context в глобальный store, но для данных layout он удобен.

## Типичные сценарии

- dashboard layout;
- account settings;
- admin panel;
- nested resource pages;
- tabs через URL;
- master-detail interface.

## Мини-шпаргалка

- `Outlet` показывает дочерний route.
- Без `Outlet` дочерний route не появится на экране.
- `index` route отображается внутри `Outlet` на пути родителя.
- `Outlet context` передает данные вложенным routes.
- Это основа layout routing.
