# Как установить Vue Test Utils с Vitest?

> [!summary]
> Для тестирования Vue 3 компонентов обычно устанавливают `vitest`, `@vue/test-utils` и DOM environment вроде `jsdom`. В Vite-конфиг добавляют Vue plugin и test environment.

## Установка

```bash
npm install -D vitest @vue/test-utils jsdom
```

Если проект уже создан через Vite и Vue, Vue plugin обычно уже установлен:

```bash
npm install -D @vitejs/plugin-vue
```

## Конфиг

```ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()],
  test: {
    environment: 'jsdom',
    globals: true,
  },
});
```

Если TypeScript ругается на `test` в Vite config, добавь types:

```ts
/// <reference types="vitest" />
```

или используй:

```ts
import { defineConfig } from 'vitest/config';
```

## Первый тест

```ts
import { mount } from '@vue/test-utils';
import { expect, test } from 'vitest';
import HelloWorld from './HelloWorld.vue';

test('renders message', () => {
  const wrapper = mount(HelloWorld, {
    props: { msg: 'Привет' },
  });

  expect(wrapper.text()).toContain('Привет');
});
```

## Где хранить тесты?

Популярные варианты:

```text
src/components/Button.vue
src/components/Button.test.ts
```

или:

```text
src/components/__tests__/Button.test.ts
```

Главное - единый стиль в проекте.

## Мини-шпаргалка

- Установи `vitest`, `@vue/test-utils`, `jsdom`.
- Для Vue-компонентов нужен Vue plugin.
- Для DOM-тестов укажи `environment: 'jsdom'`.
- Тестовые файлы часто называют `*.test.ts` или `*.spec.ts`.
- Первый тест обычно проверяет rendering props.
