# Связь данных и UI

> [!summary] Коротко
> Во Vue UI является функцией от состояния: когда данные меняются, шаблон автоматически отображает новое состояние.

## Вопрос

Как связаны данные и UI во Vue?

## Простая модель

Компонент хранит состояние, а шаблон показывает его.

```vue
<script setup>
import { ref } from "vue";

const name = ref("Анна");
</script>

<template>
  <h1>Привет, {{ name }}</h1>
  <input v-model="name" />
</template>
```

Значение `name` связано с текстом и полем ввода. Когда `name` меняется, UI обновляется.

## Данные управляют отображением

```vue
<template>
  <p v-if="isLoading">Загрузка...</p>
  <UserProfile v-else :user="user" />
</template>
```

Состояние определяет, какой фрагмент интерфейса видит пользователь.

## UI отправляет события

Пользователь взаимодействует с интерфейсом, обработчики меняют состояние, а Vue обновляет UI.

```vue
<button @click="count++">{{ count }}</button>
```

## Почему это важно

Не нужно вручную синхронизировать DOM с переменными. Источник правды - состояние, а шаблон является его отображением.

## Мини-шпаргалка

- State хранит данные.
- Template показывает данные.
- Events меняют state.
- Vue обновляет UI после изменения state.
