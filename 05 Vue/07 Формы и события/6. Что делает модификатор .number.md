# Что делает модификатор .number

> [!summary] Коротко
> `.number` у `v-model` пытается привести введенное значение к числу. Это полезно, потому что значения input обычно приходят строками.

## Вопрос

Что делает модификатор `.number`?

## Базовый пример

```vue
<script setup>
import { ref } from "vue";

const age = ref<number | null>(null);
</script>

<template>
  <input v-model.number="age" type="number" />
</template>
```

При вводе `42` в state попадет число `42`, а не строка `"42"`.

## Без .number

```vue
<input v-model="age" type="number" />
```

Даже `type="number"` в DOM не гарантирует, что значение будет числом в JavaScript. Обычно это строка.

## Когда полезно

- Возраст.
- Цена.
- Количество.
- Номер страницы.
- Любые простые числовые поля формы.

## Важный нюанс

Если значение нельзя корректно превратить в число, поведение зависит от введенного значения. Для сложных требований лучше делать явную валидацию.

```typescript
const parsed = Number(input);
const isValid = Number.isFinite(parsed);
```

## Мини-шпаргалка

- `.number` приводит input-value к числу, если возможно.
- `type="number"` сам по себе не равен числу в state.
- Для сложной валидации нужна отдельная проверка.
- Часто сочетается с typed state: `ref<number | null>()`.
