# Spread при вызове функции

> [!summary] Коротко
> Spread `...` при вызове функции раскрывает массив или другой iterable в отдельные аргументы.

## Вопрос

Что делает оператор spread при вызове функции: `func(...arr)`?

## Базовый пример

```javascript
function sum(a, b, c) {
  return a + b + c;
}

const numbers = [1, 2, 3];

sum(...numbers); // 6
```

Это похоже на:

```javascript
sum(numbers[0], numbers[1], numbers[2]);
```

## С `Math.max`

```javascript
const numbers = [5, 10, 2];

Math.max(...numbers); // 10
```

Без spread массив передался бы одним аргументом.

```javascript
Math.max(numbers); // NaN
```

## С массивами и строками

```javascript
console.log(...["a", "b", "c"]);
// a b c
```

Строка тоже iterable:

```javascript
console.log(..."JS");
// J S
```

## Spread vs rest

Spread раскрывает значения при вызове:

```javascript
sum(...numbers);
```

Rest собирает аргументы в массив при объявлении:

```javascript
function sum(...numbers) {}
```

Одинаковый синтаксис `...`, но противоположное направление.

## Подводный камень

Нельзя spread-ить обычный объект в аргументы функции, если он не iterable.

```javascript
const user = { name: "Anna" };

console.log(...user); // TypeError
```

Для объектов spread работает в объектных литералах:

```javascript
const copy = { ...user };
```

## Мини-шпаргалка

```javascript
fn(...array);      // массив -> аргументы
fn(...string);     // строка -> символы как аргументы
Math.max(...nums); // максимум из массива
[...iterable];     // iterable -> массив
```
