# Что такое индекс?

> [!NOTE]
> Индекс - дополнительная структура данных, которая помогает базе быстрее находить строки. Индекс ускоряет чтение, фильтрацию, сортировку и join, но занимает место и замедляет запись.

## Простая идея

Без индекса база может просмотреть всю таблицу.

```sql
SELECT *
FROM users
WHERE email = 'anna@example.com';
```

Если таблица большая, нужен индекс.

```sql
CREATE INDEX idx_users_email
ON users(email);
```

## Индекс как оглавление

Индекс похож на оглавление книги: вместо чтения всех страниц база быстро находит нужный диапазон.

## Цена индекса

Индекс не бесплатен:

- занимает место на диске;
- обновляется при `INSERT`, `UPDATE`, `DELETE`;
- может быть бесполезен, если запросы его не используют;
- слишком много индексов замедляют запись.

## Мини-шпаргалка

- Индекс ускоряет поиск строк.
- Индекс полезен для `WHERE`, `JOIN`, `ORDER BY`.
- Индекс замедляет запись.
- Не индексируй все подряд.
- Индекс выбирают под реальные запросы.
