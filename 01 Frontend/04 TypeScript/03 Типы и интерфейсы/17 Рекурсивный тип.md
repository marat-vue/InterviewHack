# Рекурсивный тип

> [!NOTE]
> Рекурсивный тип ссылается сам на себя. Он нужен для деревьев, вложенных меню, комментариев, JSON-подобных структур и других данных с произвольной глубиной.

## Вопрос

Как сделать рекурсивный тип или интерфейс? Например, для структуры данных "дерево".

## Базовый пример

Самый простой вариант - узел, у которого есть массив дочерних узлов того же типа.

```typescript
interface TreeNode<T> {
  value: T;
  children?: TreeNode<T>[];
}

const tree: TreeNode<string> = {
  value: "root",
  children: [
    { value: "about" },
    { value: "products", children: [{ value: "phones" }] },
  ],
};
```

То же самое можно записать через `type`.

```typescript
type Tree<T> = {
  value: T;
  children?: Tree<T>[];
};
```

## Более строгая модель

Иногда удобно разделить лист и ветку через discriminated union.

```typescript
type FileTree =
  | { kind: "file"; name: string; size: number }
  | { kind: "folder"; name: string; children: FileTree[] };

function countFiles(node: FileTree): number {
  if (node.kind === "file") return 1;

  return node.children.reduce((sum, child) => sum + countFiles(child), 0);
}
```

## Рекурсивные utility-типы

Рекурсия применяется не только к данным, но и к преобразованию типов.

```typescript
type DeepReadonly<T> = {
  readonly [K in keyof T]: DeepReadonly<T[K]>;
};
```

## Осторожно с глубиной

Слишком сложные рекурсивные типы могут привести к ошибке вида "type instantiation is excessively deep". В таком случае тип упрощают или ограничивают глубину.

## Мини-шпаргалка

- Рекурсивный тип ссылается на самого себя.
- Типичный пример: `children?: TreeNode[]`.
- Для разных вариантов узлов хорошо подходит discriminated union.
- Не усложняй рекурсию без необходимости.
