# Что такое класс в JavaScript?

> [!NOTE] Коротко
> Класс в JavaScript - синтаксис для создания объектов по шаблону и работы с прототипным наследованием.

## Вопрос

Что такое `class` и зачем он нужен?

## Определение

`class` - конструкция языка, которая описывает, какие свойства и методы будут у создаваемых объектов. Объекты, созданные через класс, называют экземплярами.

Под капотом классы в JavaScript связаны с прототипами, но дают более читаемый синтаксис для конструкторов, методов, наследования и статических методов.

## Пример

```javascript
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}

const user = new User('Ann');

console.log(user.sayHi()); // 'Hi, Ann'
```

## Экземпляр класса

```javascript
console.log(user instanceof User); // true
```

`user` - экземпляр класса `User`.

## Что обычно описывает класс

- конструктор для начального состояния;
- методы экземпляра;
- статические методы;
- приватные поля;
- наследование через `extends`.

## Важный нюанс

Класс нужно вызывать через `new`.

```javascript
User('Ann'); // TypeError
```

## Мини-шпаргалка

```javascript
class User {
  constructor(name) {
    this.name = name;
  }
}

const user = new User('Ann');
```
