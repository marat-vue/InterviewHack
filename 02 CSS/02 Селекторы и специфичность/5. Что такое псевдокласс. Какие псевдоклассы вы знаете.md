# Что такое псевдокласс. Какие псевдоклассы вы знаете

> [!summary]
> **Псевдокласс** - это часть селектора, которая выбирает элемент в определенном состоянии, положении или логическом условии: например `:hover`, `:focus`, `:checked`, `:first-child`.

## Главное

Псевдокласс начинается с одного двоеточия.

```css
button:hover {
  background: #1d4ed8;
}
```

Это правило применится к кнопке, когда пользователь наведет на нее курсор.

## Псевдоклассы состояний

```css
a:hover {
  text-decoration: underline;
}

button:disabled {
  opacity: 0.5;
}

input:checked {
  accent-color: #2563eb;
}
```

## Фокус

```css
:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 2px;
}
```

`:focus-visible` особенно важен для клавиатурной доступности.

## Структурные псевдоклассы

```css
li:first-child {
  font-weight: 700;
}

li:nth-child(odd) {
  background: #f9fafb;
}
```

Они выбирают элементы по положению в DOM.

## Логические псевдоклассы

```css
.card:not(.is-active) {
  opacity: 0.7;
}

:where(article, section) h2 {
  margin-top: 0;
}
```

`:not()`, `:is()`, `:where()`, `:has()` помогают писать более выразительные селекторы.

## Мини-шпаргалка

- Псевдокласс начинается с `:`.
- Он выбирает состояние или условие.
- Частые: `:hover`, `:focus-visible`, `:disabled`, `:checked`.
- Структурные: `:first-child`, `:last-child`, `:nth-child()`.
- `:not()`, `:is()`, `:where()`, `:has()` помогают комбинировать условия.
