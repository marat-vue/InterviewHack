## Что обязательно покрыто?

- Nitro как самостоятельный backend framework и как серверная основа Nuxt.
- Routing, handlers, middleware, params, query, body, cookies, headers и errors.
- H3 utilities и жизненный цикл request.
- `nitro.config.ts`, presets, runtime config, compatibility date.
- Cache и storage, включая Redis-backed сценарии.
- Built-in database layer и отличие от Prisma.
- OpenAPI/Swagger через route meta и документацию API.
- WebSocket handlers, ограничения runtime и сценарии применения.
- Prisma: подключение, schema, migrations, CRUD, transactions, relations, production.
- Better Auth: конфигурация, handlers, sessions, cookies, middleware, roles.
- Vitest и `@nuxt/test-utils`: установка, настройка, unit/integration/e2e подходы.

## Как проверять актуальность?

1. Начинай с [Nitro Docs](https://nitro.build/docs) и проверяй версию документации.
2. Для методов H3 сверяйся с [H3 Guide](https://h3.dev/guide), потому что часть API живет не в Nitro, а в H3.
3. Для Prisma, Better Auth, Vitest и Nuxt Test Utils проверяй их отдельные официальные сайты: эти библиотеки обновляются независимо от Nitro.
4. Если меняется major version Nitro, отдельно проверь routing, config, OpenAPI, WebSocket, cache и storage.
