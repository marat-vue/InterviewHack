# Как выполнять CRUD через Prisma?

> [!NOTE]
> Prisma Client генерирует методы для каждой модели: `findMany`, `findUnique`, `findFirst`, `create`, `update`, `upsert`, `delete`, `count` и другие. Эти методы типизированы по `schema.prisma`.

## Read

```ts
const users = await this.prisma.user.findMany();
```

```ts
const user = await this.prisma.user.findUnique({
  where: { id: 1 },
});
```

`findUnique` требует уникальный критерий: `id`, `email` или другой unique field.

Если нужно не просто вспомнить название метода, а понять, какой метод выбирать в реальном сервисе, смотри подробный разбор: [[15. Какие методы Prisma Client нужно знать]].

## Create

```ts
const user = await this.prisma.user.create({
  data: {
    email: 'anna@example.com',
    name: 'Anna',
  },
});
```

## Update

```ts
const user = await this.prisma.user.update({
  where: { id: 1 },
  data: { name: 'Ann' },
});
```

## Delete

```ts
await this.prisma.user.delete({
  where: { id: 1 },
});
```

## Upsert

```ts
await this.prisma.user.upsert({
  where: { email: 'anna@example.com' },
  update: { name: 'Anna' },
  create: { email: 'anna@example.com', name: 'Anna' },
});
```

## Мини-шпаргалка

- `findMany` возвращает массив.
- `findUnique` ищет по unique field.
- `findFirst` возвращает первую строку по фильтру.
- `create/update/delete` изменяют данные.
- `upsert` делает create или update.
- Для статистики нужны `count`, `aggregate`, `groupBy`.
- Для атомарных операций нужен `$transaction`.
