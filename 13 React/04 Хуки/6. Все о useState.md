# Что нужно знать о useState?

> [!summary]
> `useState` - базовый хук для локального состояния в функциональном компоненте. Он возвращает текущее значение и setter, который планирует обновление и новый render.

## Базовый синтаксис

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  )
}
```

`count` - текущее значение. `setCount` - функция для обновления.

## Начальное значение

Можно передать значение:

```jsx
const [name, setName] = useState('')
```

Можно передать функцию инициализации:

```jsx
const [settings, setSettings] = useState(() => loadSettings())
```

Функция полезна, если начальное вычисление дорогое.

## Setter не меняет значение мгновенно

```jsx
function handleClick() {
  setCount(count + 1)
  console.log(count)
}
```

`console.log` увидит значение из текущего render. Новое значение появится в следующем render.

## Обновление от предыдущего значения

```jsx
setCount((count) => count + 1)
```

Такой вариант нужен, когда новое значение зависит от старого.

## Объекты и массивы

Объект:

```jsx
setUser((user) => ({
  ...user,
  name: 'Мария',
}))
```

Массив:

```jsx
setTodos((todos) => todos.filter((todo) => todo.id !== id))
```

State нужно обновлять иммутабельно.

## Когда useState не лучший выбор?

Рассмотри `useReducer`, если:

- много связанных полей;
- сложные переходы;
- handlers перегружены логикой;
- нужна явная модель actions;
- reducer удобно тестировать отдельно.

## Мини-шпаргалка

- `useState` возвращает `[value, setter]`.
- Setter планирует render.
- Для зависимых обновлений используй updater function.
- Объекты и массивы обновляй через новое значение.
- Для сложной логики подойдет `useReducer`.
