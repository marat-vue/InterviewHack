# Что такое constraints?

> [!NOTE]
> Constraints - ограничения схемы, которые защищают данные от некорректных значений. Они позволяют базе самой проверять важные бизнес-правила на уровне таблиц и связей.

## Виды constraints

| Constraint | Что гарантирует |
|---|---|
| `NOT NULL` | значение обязательно |
| `UNIQUE` | значение уникально |
| `PRIMARY KEY` | уникальный идентификатор строки |
| `FOREIGN KEY` | ссылка на существующую строку |
| `CHECK` | произвольное условие |

## Пример

```sql
CREATE TABLE products (
  id bigint PRIMARY KEY,
  title text NOT NULL,
  price numeric(10, 2) NOT NULL CHECK (price >= 0),
  sku text UNIQUE
);
```

## Почему constraints лучше только проверки в коде?

Код приложения может иметь баг, несколько сервисов могут писать в одну БД, кто-то может выполнить SQL вручную. Constraint остается последней линией защиты целостности.

## Мини-шпаргалка

- Constraints защищают данные.
- `NOT NULL` полезен почти везде, где значение обязательно.
- `UNIQUE` защищает от дублей.
- `CHECK` описывает правило внутри строки.
- `FOREIGN KEY` защищает связи.
