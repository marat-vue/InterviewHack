# Что происходит при размонтировании компонента?

> [!summary]
> Размонтирование происходит, когда компонент удаляется из React-дерева. React убирает его DOM, сбрасывает refs и выполняет cleanup effects. На этом этапе важно освободить ресурсы, которые компонент создал.

## Когда происходит unmount?

Компонент размонтируется, если:

- условие перестало его показывать;
- изменился route;
- изменился `key`;
- родитель удалился;
- список больше не содержит элемент;
- приложение размонтировало root.

Пример:

```jsx
{isOpen && <Modal />}
```

Когда `isOpen` станет `false`, `Modal` размонтируется.

## Что нужно очищать?

- `setInterval` и `setTimeout`;
- event listeners;
- WebSocket connections;
- subscriptions;
- external store subscriptions;
- fetch через `AbortController`;
- observers;
- imperative widgets.

## Cleanup в useEffect

```jsx
useEffect(() => {
  const connection = createConnection(roomId)
  connection.connect()

  return () => {
    connection.disconnect()
  }
}, [roomId])
```

Cleanup выполнится при unmount и перед новым setup, если `roomId` изменится.

## Class lifecycle

В классовом компоненте для очистки используют:

```jsx
componentWillUnmount() {
  this.connection.disconnect()
}
```

В функциональном компоненте обычно используется cleanup.

## Мини-шпаргалка

- Unmount - удаление компонента из дерева.
- При unmount локальный state теряется.
- React очищает DOM и refs.
- Твои внешние ресурсы нужно закрывать через cleanup.
- Изменение `key` может принудительно размонтировать компонент.
