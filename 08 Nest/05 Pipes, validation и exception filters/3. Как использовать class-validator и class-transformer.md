# Как использовать class-validator и class-transformer?

> [!summary]
> `class-validator` задает правила проверки DTO через decorators, а `class-transformer` помогает преобразовывать входные значения, например строки query params в числа.

## Validation decorators

```ts
export class CreateProductDto {
  @IsString()
  @MinLength(2)
  title: string;

  @IsNumber()
  @Min(0)
  price: number;
}
```

## Transform query values

Query params приходят строками. Для числа нужен transform.

```ts
export class FindProductsQueryDto {
  @Type(() => Number)
  @IsInt()
  @Min(1)
  page = 1;
}
```

## Nested DTO

```ts
export class CreateOrderDto {
  @ValidateNested({ each: true })
  @Type(() => CreateOrderItemDto)
  items: CreateOrderItemDto[];
}
```

Для nested validation нужен `@ValidateNested` и `@Type`.

## Мини-шпаргалка

- `class-validator` проверяет decorators.
- `class-transformer` преобразует plain values.
- Query params изначально строки.
- Для nested DTO нужен `@Type`.
- DTO validation работает только при включенном `ValidationPipe`.
