# Как псевдоклассы влияют на специфичность

> [!summary]
> Большинство псевдоклассов увеличивают специфичность как обычный класс. Например, `:hover`, `:focus-visible`, `:checked` и `:nth-child()` добавляют вес в колонку классов/атрибутов/псевдоклассов.

## Главное

Специфичность часто записывают как:

```text
inline | id | class/attribute/pseudo-class | element/pseudo-element
```

Псевдокласс обычно добавляет `0-0-1-0`.

```css
button:hover {
  color: #2563eb;
}
```

Специфичность:

```text
button:hover -> 0-0-1-1
```

## Примеры

| Селектор | Специфичность |
| --- | --- |
| `a` | `0-0-0-1` |
| `a:hover` | `0-0-1-1` |
| `.button:focus-visible` | `0-0-2-0` |
| `input:checked + label` | `0-0-1-2` |

## Особые случаи

`:is()`, `:not()` и `:has()` берут специфичность самого специфичного аргумента внутри.

```css
:is(.card, #featured) {
  padding: 16px;
}
```

Из-за `#featured` специфичность будет высокой.

## :where()

`:where()` - исключение: его специфичность всегда равна нулю.

```css
:where(.article h2) {
  margin-block-start: 2rem;
}
```

Такое правило легко переопределить обычным классом.

## Мини-шпаргалка

- Большинство псевдоклассов считаются как классы.
- `:hover` добавляет `0-0-1-0`.
- `:is()`, `:not()`, `:has()` берут вес аргументов.
- `:where()` всегда имеет нулевую специфичность.
- Сложные псевдоклассы могут неожиданно поднять приоритет правила.
