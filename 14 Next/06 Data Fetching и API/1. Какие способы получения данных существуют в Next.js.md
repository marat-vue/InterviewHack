# Какие способы получения данных существуют в Next.js?

> [!summary]
> В Next.js данные можно получать в Server Components, Client Components, Route Handlers, Server Actions, Metadata functions и legacy Pages Router функциях. В App Router основной путь - серверная загрузка данных через async Server Components и расширенный `fetch`.

## Основные способы в App Router

| Где | Для чего |
|---|---|
| Server Component | получить данные для HTML |
| Client Component | интерактивные/client-only данные |
| Route Handler | создать HTTP endpoint |
| Server Action | выполнить mutation |
| `generateMetadata` | получить данные для metadata |
| `generateStaticParams` | получить params для static routes |

## Server Component

```tsx
export default async function ProductsPage() {
  const products = await fetch('https://api.example.com/products').then((res) =>
    res.json(),
  )

  return <ProductList products={products} />
}
```

## Client Component

```tsx
'use client'

useEffect(() => {
  fetch('/api/search?q=react')
    .then((res) => res.json())
    .then(setResults)
}, [])
```

Подходит для client-only интерактивности, но хуже для SEO-контента.

## Route Handler

```ts
export async function GET() {
  const products = await db.product.findMany()

  return Response.json(products)
}
```

## Server Action

```ts
'use server'

export async function createProduct(formData: FormData) {
  await db.product.create({
    data: { title: String(formData.get('title')) },
  })
}
```

## Что отвечать на собеседовании?

В App Router данные чаще всего получают на сервере: прямо в async Server Components, Route Handlers, Server Actions и metadata/static params функциях. Client-side fetching оставляют для интерактивных сценариев, где данные не критичны для первого HTML или SEO.

## Частые ошибки

- Загружать весь SEO-контент в `useEffect`.
- Использовать Route Handler там, где Server Component может обратиться к данным напрямую.
- Хранить секреты в Client Component.
- Путать data fetching и mutation.
- Переносить `getServerSideProps` в `app`.

## Мини-шпаргалка

- Server Component - чтение данных для UI.
- Client Component - client-only данные.
- Route Handler - HTTP endpoint.
- Server Action - mutation.
- `generateMetadata` - SEO data.
- `generateStaticParams` - static dynamic routes.
