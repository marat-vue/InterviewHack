# Как flex-wrap влияет на выравнивание элементов

> [!summary]
> Когда `flex-wrap` разрешает перенос, flex-контейнер может иметь несколько линий. Тогда на выравнивание начинают влиять не только `justify-content` и `align-items`, но и `align-content`.

## Главное

```css
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
```

Элементы могут перейти на новую строку, если на main axis не хватает места.

## Одна линия и несколько линий

При `nowrap` flex-контейнер имеет одну линию.

```css
.toolbar {
  display: flex;
  flex-wrap: nowrap;
  align-items: center;
}
```

При `wrap` линий может быть несколько.

```css
.gallery {
  display: flex;
  flex-wrap: wrap;
  align-content: start;
}
```

## align-items и align-content

```text
align-items   -> выравнивает items внутри каждой flex-линии
align-content -> распределяет сами flex-линии по cross axis
```

`align-content` заметен только когда есть несколько линий и свободное место по cross axis.

## Пример

```css
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
  height: 400px;
}
```

Если элементы образуют несколько строк, строки распределятся по высоте контейнера.

## Мини-шпаргалка

- `wrap` создает несколько flex-линий.
- `align-items` работает внутри линии.
- `align-content` распределяет линии.
- `align-content` не виден на одной линии.
- `gap` проще и предсказуемее для расстояний между элементами.
