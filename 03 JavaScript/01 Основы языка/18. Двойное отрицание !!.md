# Двойное отрицание `!!`

> [!summary] Коротко
> `!!value` приводит любое значение к настоящему boolean: `true` или `false`. По смыслу это почти то же самое, что `Boolean(value)`.

## Вопрос

Как работает двойное отрицание `!!`?

## Основная идея

Первый `!` приводит значение к boolean и инвертирует его. Второй `!` инвертирует обратно.

```javascript
!"hello";  // false
!!"hello"; // true
```

То есть:

```javascript
!!value === Boolean(value);
```

## Примеры

```javascript
!!"text";    // true
!!"";        // false
!!1;         // true
!!0;         // false
!!null;      // false
!!undefined; // false
!![];        // true
!!{};        // true
```

## Зачем использовать

### Получить boolean из значения

```javascript
const token = localStorage.getItem("token");
const isAuthorized = !!token;
```

Теперь `isAuthorized` точно boolean, а не строка или `null`.

### Нормализовать результат для API компонента

```javascript
function Button({ disabled }) {
  const isDisabled = !!disabled;

  return { isDisabled };
}
```

## Когда лучше `Boolean(value)`

`!!` коротко и часто встречается в коде, но `Boolean(value)` иногда читается понятнее.

```javascript
const hasItems = Boolean(items.length);
```

Это особенно полезно для новичков в команде или в учебных заметках.

## Ловушка с пустыми структурами

Пустые массивы и объекты truthy.

```javascript
!![]; // true
!!{}; // true
```

Если нужно проверить пустоту массива:

```javascript
const items = [];
const hasItems = items.length > 0;
```

Если нужно проверить пустоту объекта:

```javascript
const user = {};
const hasFields = Object.keys(user).length > 0;
```

## Мини-шпаргалка

| Выражение | Результат |
| --- | --- |
| `!!"hello"` | `true` |
| `!!""` | `false` |
| `!!0` | `false` |
| `!!1` | `true` |
| `!!null` | `false` |
| `!![]` | `true` |
| `Boolean(value)` | то же по смыслу |
