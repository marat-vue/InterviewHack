> [!summary]
> HTML-документ состоит из декларации `<!doctype html>`, корневого элемента `<html>`, служебной части `<head>` и видимой части `<body>`.

## Базовая структура

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет, HTML</h1>
    <p>Это видимое содержимое страницы.</p>
  </body>
</html>
```

## Основные части

| Часть | Назначение |
| --- | --- |
| `<!doctype html>` | Включает современный режим отображения страницы |
| `<html>` | Корневой элемент всего документа |
| `<head>` | Метаданные, заголовок вкладки, подключение CSS и служебных ресурсов |
| `<body>` | Видимый контент страницы |

## Doctype

`<!doctype html>` сообщает браузеру, что документ нужно обрабатывать как современный HTML.

```html
<!doctype html>
```

Без doctype браузер может перейти в quirks mode, где часть CSS и layout-правил работает иначе для совместимости со старыми сайтами.

## Элемент html

`<html>` содержит весь документ. Атрибут `lang` помогает браузеру, поисковикам и скринридерам понять язык страницы.

```html
<html lang="ru">
  ...
</html>
```

## Head

В `<head>` находятся данные о документе, которые обычно не отображаются как контент страницы.

```html
<head>
  <meta charset="UTF-8" />
  <title>Документация</title>
  <link rel="stylesheet" href="/styles.css" />
</head>
```

## Body

В `<body>` находится то, что пользователь видит и с чем взаимодействует.

```html
<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
```

## Мини-шпаргалка

- `doctype` включает современный режим.
- `<html>` - корень документа.
- `<head>` - служебная информация.
- `<body>` - видимый контент.
- `lang` лучше указывать всегда.
- `charset` обычно ставят `UTF-8`.
