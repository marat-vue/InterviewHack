# Что делает элемент body?

> [!NOTE]
> Элемент `<body>` содержит весь видимый контент страницы: текст, изображения, навигацию, формы, кнопки, таблицы и интерактивные элементы.

## Главное

Если пользователь видит элемент на странице или взаимодействует с ним, почти всегда он находится внутри `<body>`.

```html
<body>
  <header>Шапка сайта</header>
  <main>
    <h1>Каталог</h1>
    <p>Выберите товар из списка.</p>
  </main>
  <footer>Контакты</footer>
</body>
```

## Что обычно лежит в body

- `header`, `main`, `footer`;
- заголовки и текст;
- ссылки и меню;
- изображения, видео, аудио;
- формы и поля ввода;
- таблицы и списки;
- корневой элемент SPA-приложения.

## Пример для SPA

В приложениях на Vue, React или Angular в `body` часто есть контейнер, куда монтируется приложение.

```html
<body>
  <div id="app"></div>
  <script type="module" src="/src/main.js"></script>
</body>
```

JavaScript находит `#app` и рендерит внутри него интерфейс.

## Body и семантика

`body` не заменяет семантические элементы. Внутри него все равно стоит использовать понятную структуру.

```html
<body>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</body>
```

Так страница понятнее для браузера, поисковых систем и скринридеров.

## Мини-шпаргалка

- `<body>` содержит видимую часть документа.
- Внутри `body` размещают интерфейс страницы.
- Для SPA внутри `body` часто есть `<div id="app">`.
- Видимый контент не должен находиться в `<head>`.
- Хороший `body` имеет понятную семантическую структуру.
