# Как установить Better Auth и подключить Prisma adapter?

> [!NOTE]
> Для Nitro + Prisma обычно устанавливают `better-auth`, `@prisma/client`, `prisma`, создают Prisma Client, настраивают `betterAuth({ database: prismaAdapter(...) })` и включают нужные auth methods.

## Установка

```bash
npm i better-auth @prisma/client
npm i -D prisma
```

Если Prisma еще не инициализирована:

```bash
npx prisma init
```

## Создание Prisma Client

```ts
// server/utils/prisma.ts
import { PrismaClient } from '@prisma/client';

const globalForPrisma = globalThis as unknown as {
  prisma?: PrismaClient;
};

export const prisma =
  globalForPrisma.prisma ??
  new PrismaClient();

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma;
}
```

## Создание `auth.ts`

```ts
// server/utils/auth.ts
import { betterAuth } from 'better-auth';
import { prismaAdapter } from 'better-auth/adapters/prisma';
import { prisma } from './prisma';

export const auth = betterAuth({
  database: prismaAdapter(prisma, {
    provider: 'postgresql',
  }),
  emailAndPassword: {
    enabled: true,
  },
});
```

Provider укажи под свою БД:

| Provider | Когда использовать |
|---|---|
| `postgresql` | PostgreSQL |
| `mysql` | MySQL |
| `sqlite` | SQLite |
| другие | смотри актуальную документацию adapter |

## Env-переменные

```bash
DATABASE_URL="postgresql://..."
BETTER_AUTH_SECRET="..."
BETTER_AUTH_URL="http://localhost:3000"
```

В production:

```bash
BETTER_AUTH_URL="https://app.example.com"
```

Secret должен быть длинным и случайным.

Better Auth CLI умеет сгенерировать secret:

```bash
npx auth@latest secret
```

## Social providers

```ts
export const auth = betterAuth({
  database: prismaAdapter(prisma, {
    provider: 'postgresql',
  }),
  emailAndPassword: {
    enabled: true,
  },
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
});
```

## Где хранить файл?

Для Nitro:

```txt
server/
  utils/
    auth.ts
    prisma.ts
  routes/
    api/
      auth/
        [...all].ts
```

## Мини-шпаргалка

- Установить: `better-auth`, `@prisma/client`, `prisma`.
- Prisma adapter импортируется из `better-auth/adapters/prisma`.
- Auth instance хранится в `server/utils/auth.ts`.
- Secret и URL задаются через env.
- Email/password включается через `emailAndPassword.enabled`.
- Social providers задаются через `socialProviders`.
