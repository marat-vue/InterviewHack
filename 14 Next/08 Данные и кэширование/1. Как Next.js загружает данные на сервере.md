# Как Next.js загружает данные на сервере?

> [!summary]
> В App Router Next.js загружает данные на сервере через async Server Components, Route Handlers, Server Actions, `generateMetadata` и `generateStaticParams`. Это позволяет отдать HTML уже с контентом, держать secrets на сервере и управлять cache/revalidation.

## Server Component

```tsx
export default async function ProductsPage() {
  const products = await getProducts()

  return <ProductList products={products} />
}
```

Код выполняется на сервере, а браузер получает результат рендера.

## fetch на сервере

```tsx
export default async function PostsPage() {
  const posts = await fetch('https://api.example.com/posts', {
    next: { revalidate: 3600 },
  }).then((res) => res.json())

  return <PostList posts={posts} />
}
```

Next.js расширяет `fetch`, чтобы можно было управлять cache и revalidation.

## Прямой доступ к БД

```tsx
export default async function UsersPage() {
  const users = await db.user.findMany()

  return <UserTable users={users} />
}
```

Такой код нельзя переносить в Client Component.

## Route Handler

```ts
export async function GET() {
  const users = await db.user.findMany()
  return Response.json(users)
}
```

Route Handler нужен, если данные должны быть доступны через HTTP endpoint.

## Что отвечать на собеседовании?

Next.js загружает данные на сервере прежде всего через Server Components. Это отличается от обычного React SPA, где данные часто грузятся после mount. Серверная загрузка улучшает SEO, позволяет использовать secrets и снижает объем клиентского JavaScript.

## Частые ошибки

- Делать запрос из браузера, хотя данные нужны для первого HTML.
- Создавать `/api` endpoint для каждого server component fetch.
- Читать secrets в Client Component.
- Не настраивать cache/revalidate.
- Не обрабатывать ошибки и not found.

## Мини-шпаргалка

- Server Component может быть `async`.
- `fetch` в Next.js умеет cache options.
- ORM/DB можно использовать только на сервере.
- Route Handler нужен для HTTP endpoint.
- Server Action нужен для mutation.
- HTML может прийти уже с данными.
