# sx ThemeProvider createTheme и кастомизация

> [!summary]
> Главные инструменты кастомизации MUI - `sx` для локальных стилей, `createTheme` для дизайн-токенов, `ThemeProvider` для передачи темы и `components` overrides для глобальной настройки компонентов.

## sx prop

`sx` - самый быстрый способ стилизовать один экземпляр компонента:

```tsx
<Button
  sx={{
    borderRadius: 2,
    px: 3,
    py: 1,
    textTransform: 'none',
  }}
>
  Save
</Button>
```

Значения могут использовать theme scale:

```tsx
<Box sx={{ p: 2, bgcolor: 'background.paper', color: 'text.primary' }} />
```

## Responsive sx

```tsx
<Box
  sx={{
    display: 'grid',
    gap: 2,
    gridTemplateColumns: {
      xs: '1fr',
      md: '1fr 1fr',
      xl: 'repeat(4, 1fr)',
    },
  }}
/>
```

## createTheme

```tsx
import { createTheme, ThemeProvider } from '@mui/material/styles'

const theme = createTheme({
  palette: {
    mode: 'light',
    primary: {
      main: '#2563eb',
    },
  },
  typography: {
    fontFamily: 'Inter, system-ui, sans-serif',
  },
  shape: {
    borderRadius: 8,
  },
})

function Root() {
  return (
    <ThemeProvider theme={theme}>
      <App />
    </ThemeProvider>
  )
}
```

## components overrides

```tsx
const theme = createTheme({
  components: {
    MuiButton: {
      defaultProps: {
        disableElevation: true,
      },
      styleOverrides: {
        root: {
          textTransform: 'none',
        },
      },
    },
  },
})
```

Так можно настроить поведение всех `Button` в приложении.

## Когда использовать sx, а когда theme?

| Сценарий | Инструмент |
|---|---|
| разовая правка компонента | `sx` |
| общий цвет/типографика | `createTheme` |
| дефолтные props компонента | `components.defaultProps` |
| глобальный style override | `components.styleOverrides` |
| переиспользуемый custom component | wrapper component |

## Что отвечать на собеседовании?

`sx` используют для локальной стилизации, `ThemeProvider` передает theme через React context, `createTheme` задает palette, typography, spacing, breakpoints и shape, а `components` в theme позволяет задать default props и overrides для компонентов MUI.

## Мини-шпаргалка

- `sx={{ p: 2 }}` использует theme spacing.
- `bgcolor: 'background.paper'`.
- `createTheme({ palette, typography })`.
- `ThemeProvider` должен быть выше MUI-компонентов.
- `components.MuiButton.defaultProps`.
- `components.MuiButton.styleOverrides`.
