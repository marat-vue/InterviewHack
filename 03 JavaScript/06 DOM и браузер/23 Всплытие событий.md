# Всплытие событий

> [!NOTE] Коротко
> Всплытие - фаза события, на которой событие идет от целевого элемента вверх к родителям, `document` и `window`.

## Вопрос

Что такое bubbling в DOM?

## Определение

Когда событие возникает на элементе, оно не остается только на нем. После фазы цели большинство событий всплывает вверх по DOM-дереву: от вложенного элемента к родителю, затем выше.

Именно всплытие делает возможным делегирование событий.

## Пример

```html
<div class="parent">
  <button class="child">Click</button>
</div>
```

```javascript
document.querySelector('.parent').addEventListener('click', () => {
  console.log('parent');
});

document.querySelector('.child').addEventListener('click', () => {
  console.log('child');
});
```

При клике по кнопке вывод будет:

```text
child
parent
```

Событие сначала сработало на цели, затем всплыло к родителю.

## Остановка всплытия

```javascript
button.addEventListener('click', (event) => {
  event.stopPropagation();
});
```

После `stopPropagation()` событие не пойдет дальше вверх.

## Мини-шпаргалка

```text
target -> parent -> document -> window
```
