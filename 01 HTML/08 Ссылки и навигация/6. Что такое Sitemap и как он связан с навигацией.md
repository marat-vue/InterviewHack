# Что такое Sitemap и как он связан с навигацией

> [!summary]
> **Sitemap** - это карта сайта: список важных URL, который помогает поисковым системам находить страницы. С навигацией он связан общей задачей - показать структуру сайта, но предназначен в первую очередь для роботов.

## Два вида sitemap

Есть два разных сценария:

- HTML-карта сайта для пользователей.
- XML sitemap для поисковых систем.

## HTML sitemap

HTML-карта сайта - обычная страница со ссылками на важные разделы.

```html
<main>
  <h1>Карта сайта</h1>
  <ul>
    <li><a href="/catalog">Каталог</a></li>
    <li><a href="/delivery">Доставка</a></li>
    <li><a href="/contacts">Контакты</a></li>
  </ul>
</main>
```

Она может помогать пользователям ориентироваться на большом сайте.

## XML sitemap

XML sitemap обычно лежит по адресу вроде `/sitemap.xml`.

```xml
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/catalog</loc>
  </url>
</urlset>
```

Он помогает поисковым роботам быстрее находить важные страницы.

## Связь с навигацией

Навигация помогает пользователю перемещаться по сайту в интерфейсе. Sitemap помогает поисковикам и иногда пользователям увидеть структуру сайта более полно.

```text
navigation -> visible UI links
sitemap    -> structured list of URLs
```

## Что включать

- Важные публичные страницы.
- Категории и разделы.
- Статьи и товары, которые должны индексироваться.
- Канонические URL.

Не стоит включать закрытые страницы, дубли и технические URL.

## Мини-шпаргалка

- Sitemap - карта URL сайта.
- XML sitemap предназначен для поисковых систем.
- HTML sitemap может помогать пользователям.
- Навигация и sitemap отражают структуру сайта.
- Sitemap не заменяет нормальное меню.
- Закрытые и технические страницы туда обычно не добавляют.
