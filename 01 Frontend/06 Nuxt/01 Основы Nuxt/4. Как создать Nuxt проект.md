# Как создать Nuxt проект?

> [!summary]
> Nuxt-проект обычно создают через `nuxi`, официальный CLI. После создания запускают dev server, изучают `app.vue`, `nuxt.config.ts`, `package.json` и постепенно добавляют `app/pages`, `app/components`, `server/api`.

## Создание проекта

```bash
npx nuxi@latest init my-nuxt-app
```

Потом:

```bash
cd my-nuxt-app
npm install
npm run dev
```

Dev server обычно открывается на:

```text
http://localhost:3000
```

## Базовые scripts

```json
{
  "scripts": {
    "dev": "nuxt dev",
    "build": "nuxt build",
    "generate": "nuxt generate",
    "preview": "nuxt preview"
  }
}
```

Что делают команды:

| Script | Назначение |
|---|---|
| `dev` | разработка |
| `build` | production build |
| `generate` | статическая генерация |
| `preview` | локальный preview production build |

## Минимальная структура

```text
my-nuxt-app/
  app/
    app.vue
  nuxt.config.ts
  package.json
  tsconfig.json
```

Если добавишь:

```text
app/pages/index.vue
app/pages/about.vue
```

Nuxt создаст routes `/` и `/about`.

## Что изучить сразу после создания?

- `nuxt.config.ts`;
- `app/app.vue`;
- `app/pages`;
- `app/components`;
- `app/composables`;
- `server/api`;
- `.nuxt/` как generated directory, которую руками не редактируют.

## Мини-шпаргалка

- Создание: `npx nuxi@latest init my-nuxt-app`.
- Разработка: `npm run dev`.
- Build: `npm run build`.
- Static generation: `npm run generate`.
- `.nuxt/` генерируется Nuxt и не редактируется вручную.
