# Как подключить Vuetify к Vue и Vite?

> [!summary]
> Vuetify подключают как Vue plugin через `createVuetify()`. В Vite-проекте обычно добавляют пакет `vuetify`, стили, icons и при необходимости `vite-plugin-vuetify`.

## Установка

Для нового проекта удобнее использовать официальный scaffolding Vuetify. Для существующего Vue/Vite проекта базовая идея такая:

```bash
npm install vuetify
```

Часто также нужны icons:

```bash
npm install @mdi/font
```

## Файл plugins/vuetify.ts

```typescript
// src/plugins/vuetify.ts
import "vuetify/styles";
import "@mdi/font/css/materialdesignicons.css";

import { createVuetify } from "vuetify";

export const vuetify = createVuetify({
  icons: {
    defaultSet: "mdi",
  },
});
```

## Подключение в main.ts

```typescript
import { createApp } from "vue";
import App from "./App.vue";
import { vuetify } from "./plugins/vuetify";

createApp(App).use(vuetify).mount("#app");
```

## Обязательная оболочка

В корневом компоненте нужен `v-app`:

```vue
<template>
  <v-app>
    <v-main>
      <RouterView />
    </v-main>
  </v-app>
</template>
```

`v-app` задает контекст Vuetify: theme, layout, overlays и базовые стили компонентов.

## Vite plugin

В проектах с Vuetify часто используют `vite-plugin-vuetify` для удобной интеграции и auto-imports:

```typescript
// vite.config.ts
import vue from "@vitejs/plugin-vue";
import vuetify from "vite-plugin-vuetify";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue(),
    vuetify({ autoImport: true }),
  ],
});
```

## Мини-шпаргалка

- Vuetify подключают через `createVuetify`.
- Стили импортируют через `vuetify/styles`.
- `v-app` нужен в корне приложения.
- `v-main` обычно оборачивает основную область.
- Для Vite полезен `vite-plugin-vuetify`.
