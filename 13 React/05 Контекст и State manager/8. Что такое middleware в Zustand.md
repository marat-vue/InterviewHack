# Что такое middleware в Zustand?

> [!summary]
> Middleware в Zustand - это обертка над store creator, которая добавляет store дополнительное поведение: persist, devtools, immer, subscribeWithSelector и другие возможности. Middleware подключают только тогда, когда конкретная задача действительно нужна.

## Простое определение

Middleware расширяет store:

```text
create(store)
create(persist(store))
create(devtools(store))
create(immer(store))
```

То есть базовый store получает дополнительные возможности.

## Пример persist middleware

```jsx
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

const useThemeStore = create(
  persist(
    (set) => ({
      theme: 'light',
      setTheme: (theme) => set({ theme }),
    }),
    {
      name: 'theme-storage',
    }
  )
)
```

Теперь `theme` может сохраняться в storage и восстанавливаться после перезагрузки.

## Какие middleware часто встречаются?

| Middleware | Зачем нужен |
|---|---|
| `persist` | сохранять state в storage |
| `devtools` | подключить Redux DevTools |
| `immer` | писать обновления в императивном стиле через draft |
| `subscribeWithSelector` | подписываться на выбранную часть state вне React |
| `redux` | использовать reducer-like подход |

## Как комбинировать middleware?

```jsx
const useStore = create(
  devtools(
    persist(
      (set) => ({
        count: 0,
        inc: () => set((state) => ({ count: state.count + 1 })),
      }),
      { name: 'counter' }
    )
  )
)
```

Порядок оберток может иметь значение, поэтому его лучше делать осознанно и проверять по документации middleware.

## Когда middleware вреден?

Не стоит подключать middleware "на будущее":

- persist может случайно сохранить чувствительные данные;
- devtools не всегда нужен в production;
- immer добавляет зависимость и другой стиль обновлений;
- subscribeWithSelector нужен только для точечных подписок вне React.

## Мини-шпаргалка

- Middleware расширяет Zustand store.
- `persist` сохраняет state.
- `devtools` помогает отладке.
- `immer` упрощает иммутабельные обновления.
- Middleware нужно подключать под конкретную задачу.
