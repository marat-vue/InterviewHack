# Что такое event loop

> [!summary] Коротко
> Event Loop - механизм среды выполнения, который решает, когда готовые асинхронные задачи попадут в Call Stack.

## Вопрос

Что такое Event Loop и зачем он нужен JavaScript?

## Определение

Event Loop - это цикл, который связывает синхронный JavaScript-код, очереди задач и асинхронные возможности среды выполнения: браузера или Node.js.

JavaScript выполняет код в одном Call Stack. Пока стек занят, никакие callbacks из очередей не выполняются. Когда стек освобождается, Event Loop смотрит на очереди и передает задачи на выполнение.

## Участники процесса

| Часть | Что делает |
| --- | --- |
| Call Stack | выполняет текущий синхронный JS-код |
| Web APIs / Node APIs | берут на себя таймеры, сеть, I/O |
| Microtask Queue | хранит микротаски: `Promise.then`, `queueMicrotask` |
| Task Queue | хранит макротаски: `setTimeout`, события, I/O |
| Event Loop | переносит задачи из очередей в стек |

## Порядок выполнения

1. Выполняется весь синхронный код.
2. Выполняются все микротаски до полного опустошения очереди.
3. Берется одна макротаска.
4. После нее снова выполняются все микротаски.
5. Цикл повторяется.

## Наглядный пример

```javascript
console.log(1);

setTimeout(() => console.log(2), 0);

Promise.resolve().then(() => console.log(3));

console.log(4);

// 1
// 4
// 3
// 2
```

Сначала идет синхронный код: `1`, `4`. Затем микротаска промиса: `3`. Только потом макротаска таймера: `2`.

## Важный вывод

Если Call Stack занят тяжелым синхронным кодом, Event Loop не может взять задачи из очередей. Поэтому таймеры, обработчики кликов и промисы будут ждать.

## Мини-шпаргалка

```javascript
sync code -> microtasks -> one macrotask -> microtasks -> ...
```
