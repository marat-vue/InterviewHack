# Какие свойства вызывают relayout

> [!summary]
> **Relayout** или layout recalculation происходит, когда браузеру нужно заново вычислить размеры и позиции элементов. Его часто вызывают свойства, влияющие на геометрию: `width`, `height`, `margin`, `padding`, `border`, `display`, `position`, `top`, `left`.

## Главное

Браузерный pipeline можно представить так:

```text
style -> layout -> paint -> composite
```

Если изменилось свойство, влияющее на размеры или положение, браузер может заново выполнить layout.

## Частые свойства

| Категория | Примеры |
| --- | --- |
| Размеры | `width`, `height`, `min-width`, `max-height` |
| Отступы | `margin`, `padding` |
| Рамки | `border-width` |
| Layout | `display`, `grid-template-columns`, `flex-basis` |
| Позиция | `position`, `top`, `right`, `bottom`, `left` |
| Текст | `font-size`, `line-height`, `font-family` |
| Overflow | `overflow`, `scrollbar-gutter` |

## Пример

```css
.sidebar {
  width: 320px;
}

.sidebar.is-collapsed {
  width: 64px;
}
```

Изменение ширины может заставить браузер пересчитать соседние элементы.

## Почему это дорого

Layout может затронуть не один элемент, а всю ветку или большую часть страницы.

```text
change parent width
  -> child sizes change
  -> text wrapping changes
  -> positions of following elements change
```

## Что лучше для анимаций

Для движения и появления чаще используют `transform` и `opacity`.

```css
.panel {
  transform: translateX(-100%);
  transition: transform 200ms ease;
}
```

`transform` обычно не требует полного relayout.

## Мини-шпаргалка

- Relayout пересчитывает размеры и позиции.
- Его вызывают свойства геометрии.
- `width`, `height`, `margin`, `padding`, `top`, `left` часто дорогие для анимаций.
- Изменение текста и шрифта тоже может вызвать layout.
- Для анимаций чаще выбирают `transform` и `opacity`.
