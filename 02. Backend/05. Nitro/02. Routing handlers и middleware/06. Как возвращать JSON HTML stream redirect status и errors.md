# Как возвращать JSON, HTML, stream, redirect, status и errors?

> [!NOTE]
> Nitro/H3 автоматически превращает возвращенное из handler значение в HTTP response. Можно возвращать объекты, строки, `Response`, HTML helpers, streams, redirect helpers, empty responses и ошибки.

## JSON

Самый частый вариант - вернуть object или array:

```ts
export default defineHandler(() => {
  return {
    ok: true,
    items: [],
  };
});
```

H3 отдаст JSON response.

## String

```ts
export default defineHandler(() => {
  return 'Hello Nitro';
});
```

Это удобно для healthcheck, text endpoints, robots/sitemap-like routes.

## HTML

```ts
import { html } from 'h3';

export default defineHandler(() => {
  return html`<h1>Hello</h1>`;
});
```

Если вставляешь пользовательский input, он должен быть экранирован. Для доверенного HTML есть `raw`, но его нельзя применять к пользовательским данным.

## Web `Response`

```ts
export default defineHandler(() => {
  return new Response('Created', {
    status: 201,
    headers: {
      'content-type': 'text/plain',
    },
  });
});
```

`Response` полезен, когда нужно полностью контролировать status, headers и body.

## Status code через `event.res`

```ts
export default defineHandler((event) => {
  event.res.status = 201;

  return {
    created: true,
  };
});
```

Для многих случаев проще вернуть `Response`, но `event.res` удобен для staged response metadata.

## Empty response

```ts
import { noContent } from 'h3';

export default defineHandler(() => {
  return noContent();
});
```

Для DELETE часто используют `204 No Content`:

```ts
return noContent(204);
```

## Redirect

```ts
import { redirect } from 'h3';

export default defineHandler(() => {
  return redirect('/login');
});
```

Permanent redirect:

```ts
return redirect('/new-url', 301);
```

Важно: если redirect target приходит от пользователя, проверяй allowlist, иначе будет open redirect vulnerability.

## Redirect back

```ts
import { redirectBack } from 'h3';

export default defineHandler((event) => {
  return redirectBack(event, {
    fallback: '/dashboard',
  });
});
```

`fallback` должен быть доверенным hardcoded path.

## Stream

```ts
import { iterable } from 'h3';

export default defineHandler(() => {
  return iterable(async function* () {
    yield 'start\n';
    yield 'working\n';
    yield 'done\n';
  });
});
```

Streams нужны для:

- long-running reports;
- server-sent progress;
- large text output;
- generated files.

## Errors

```ts
import { createError } from 'h3';

export default defineHandler(() => {
  throw createError({
    statusCode: 404,
    statusMessage: 'User not found',
  });
});
```

Типовые ошибки:

| Статус | Когда использовать |
|---|---|
| `400` | неправильный request |
| `401` | не authenticated |
| `403` | authenticated, но нет прав |
| `404` | ресурс не найден |
| `409` | конфликт состояния |
| `422` | validation/domain error |
| `429` | rate limit |
| `500` | unexpected server error |

## Мини-шпаргалка

- Object/array -> JSON.
- String -> text response.
- `html` -> HTML response.
- `Response` -> полный контроль.
- `noContent` -> пустой response.
- `redirect`/`redirectBack` -> redirects.
- `iterable`/stream -> streaming response.
- `createError` -> HTTP-friendly error.
