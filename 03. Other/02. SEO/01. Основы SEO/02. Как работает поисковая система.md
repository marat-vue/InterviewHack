# Как работает поисковая система?

> [!summary]
> Поисковая система проходит несколько этапов: обнаруживает URL, crawls страницы, рендерит и анализирует контент, индексирует подходящие страницы, а затем выбирает результаты для запроса пользователя.

## Основные этапы

Упрощенно:

```text
Discovery -> Crawling -> Rendering -> Indexing -> Ranking -> Serving
```

## Discovery

Поисковик узнает о URL через:

- ссылки с других страниц;
- sitemap;
- Search Console;
- redirects;
- внешние ссылки;
- внутреннюю навигацию.

Если на страницу никто не ссылается и ее нет в sitemap, поисковику трудно ее найти.

## Crawling

Crawler запрашивает URL:

```http
GET /blog/seo-basics HTTP/1.1
User-Agent: Googlebot
```

На этом этапе важны:

- доступность сервера;
- status code;
- robots.txt;
- скорость ответа;
- отсутствие бесконечных URL.

## Rendering

Для JavaScript-сайтов поисковик может выполнить JS, чтобы увидеть итоговый DOM.

Проблемы возникают, если:

- контент появляется только после долгого client fetch;
- важные links создаются нестабильно;
- страница требует login;
- JS падает;
- server отдает пустой shell.

## Indexing

Indexing - решение сохранить страницу в поисковом индексе.

Страница может не попасть в индекс, если:

- стоит `noindex`;
- контент низкого качества;
- страница duplicate;
- canonical указывает на другую URL;
- есть ошибки доступа;
- страница не представляет ценности.

## Ranking и serving

Когда пользователь вводит запрос, система выбирает результаты с учетом релевантности, качества, локализации, свежести, page experience и множества других факторов.

## Мини-шпаргалка

- Discovery - поисковик узнал URL.
- Crawling - поисковик запросил страницу.
- Rendering - поисковик увидел HTML/DOM.
- Indexing - страница попала в индекс.
- Ranking - страница выбрана для запроса.
- SEO-проблема может возникнуть на любом этапе.
