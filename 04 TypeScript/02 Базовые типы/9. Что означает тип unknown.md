# Что означает тип unknown

> [!summary] Коротко
> `unknown` означает неизвестный тип значения и заставляет сначала проверить значение, прежде чем с ним работать.

## Вопрос

Чем `unknown` лучше, чем `any`?

## Определение

`unknown` - типобезопасный вариант для значений, тип которых заранее неизвестен. В переменную `unknown` можно положить что угодно, но нельзя просто так вызывать методы или читать свойства без проверки.

## Пример

```typescript
let value: unknown;

value = 'hello';
value = 123;
value = { name: 'Ann' };
```

Присвоить можно любое значение.

## Нельзя использовать без проверки

```typescript
function print(value: unknown) {
  console.log(value.toUpperCase()); // ошибка TypeScript
}
```

TypeScript не знает, что `value` точно строка.

## Сужение типа

```typescript
function print(value: unknown) {
  if (typeof value === 'string') {
    console.log(value.toUpperCase());
  }
}
```

После проверки `typeof value === 'string'` TypeScript понимает, что внутри блока `value` является строкой.

## Где использовать

- данные из `JSON.parse`;
- ответы внешних API;
- значения из `localStorage`;
- ошибки в `catch`;
- входные данные неизвестного происхождения.

## unknown vs any

| Тип | Что разрешает |
| --- | --- |
| `any` | делать что угодно без проверок |
| `unknown` | требует сначала сузить тип |

## Мини-шпаргалка

```typescript
function handle(value: unknown) {
  if (typeof value === 'string') {
    value.toUpperCase();
  }
}
```
