# Как работает механизм прилипания при скролле?

> [!NOTE]
> Механизм sticky работает в две фазы: сначала элемент находится в обычном потоке, затем при достижении указанного offset прилипает к границе scroll-контейнера и остается там до конца своего родителя.

## Общая схема

```text
before threshold -> behaves like relative
at threshold     -> sticks to offset
parent ends      -> stops sticking
```

## Пример

```css
.section-title {
  position: sticky;
  top: 0;
  background: white;
  z-index: 1;
}
```

Когда заголовок доходит до верхнего края viewport, он остается сверху, пока его секция продолжает скроллиться.

## Scroll-контейнер

Sticky ориентируется не всегда на окно браузера. Если у родителя есть прокрутка, sticky может работать внутри него.

```css
.panel {
  max-height: 400px;
  overflow: auto;
}

.panel__header {
  position: sticky;
  top: 0;
}
```

Заголовок будет прилипать внутри `.panel`.

## Почему sticky не работает

Частые причины:

- не указан `top`, `bottom`, `left` или `right`;
- родитель недостаточно высокий;
- у предка есть неподходящий `overflow`;
- sticky-элемент выше контейнера;
- ожидается прилипание за пределами родителя.

## Табличные заголовки

```css
th {
  position: sticky;
  top: 0;
  background: white;
}
```

Важно задать фон, иначе под прилипшим заголовком может просвечивать контент.

## Мини-шпаргалка

- Sticky сначала ведет себя как relative.
- После достижения offset элемент прилипает.
- Sticky ограничен родителем или scroll-контейнером.
- Для работы нужен `top` или другой offset.
- Фон и `z-index` часто нужны для читаемости.
- `overflow` у родителей стоит проверять первым.
