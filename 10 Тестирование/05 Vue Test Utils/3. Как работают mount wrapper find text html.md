# Как работают mount, wrapper, find, text и html?

> [!summary]
> `mount` монтирует компонент, `wrapper` представляет результат монтирования, `find` ищет элемент, `text` возвращает видимый текст, `html` возвращает HTML. Эти методы составляют основу тестирования Vue-компонентов.

## `mount`

```ts
const wrapper = mount(UserCard, {
  props: {
    name: 'Ann',
  },
});
```

`mount` рендерит компонент и возвращает wrapper.

## `wrapper.text()`

`text()` возвращает текст компонента:

```ts
expect(wrapper.text()).toContain('Ann');
```

Это часто лучше, чем проверять точный HTML.

## `wrapper.html()`

`html()` возвращает HTML:

```ts
expect(wrapper.html()).toContain('<strong>Ann</strong>');
```

Используй осторожно: тесты на полный HTML часто хрупкие.

## `find` и `get`

`find` возвращает wrapper, который может быть пустым:

```ts
const error = wrapper.find('[data-testid="error"]');

expect(error.exists()).toBe(false);
```

`get` ожидает, что элемент точно есть. Если элемента нет, тест упадет сразу:

```ts
await wrapper.get('button').trigger('click');
```

## `findComponent`

Для поиска дочернего компонента:

```ts
const button = wrapper.findComponent(BaseButton);

expect(button.exists()).toBe(true);
```

## Мини-шпаргалка

- `mount` создает wrapper.
- `wrapper.text()` проверяет видимый текст.
- `wrapper.html()` проверяет HTML, но может быть хрупким.
- `find` подходит, если элемент может отсутствовать.
- `get` подходит, если элемент обязан быть.
- `findComponent` ищет Vue-компонент.
