# Область видимости

> [!NOTE] Коротко
> Область видимости определяет, где в коде доступна переменная или функция. JavaScript использует лексическую область видимости: доступ зависит от места объявления в коде.

## Вопрос

Расскажите про область видимости в JavaScript. Какие типы бывают? Чем они отличаются?

## Основная идея

Когда движок встречает имя переменной, он ищет ее сначала в текущей области, потом во внешней, потом еще выше. Эта цепочка называется scope chain.

```javascript
const globalName = "global";

function outer() {
  const outerName = "outer";

  function inner() {
    const innerName = "inner";
    console.log(innerName, outerName, globalName);
  }

  inner();
}
```

`inner` видит свои переменные, переменные `outer` и глобальные переменные.

## Глобальная область

Глобальные переменные доступны из любого места файла или скрипта.

```javascript
const appName = "Frontend Notes";

function printName() {
  console.log(appName);
}
```

В браузере глобальный `var` становится свойством `window`:

```javascript
var legacyValue = 1;
console.log(window.legacyValue); // 1
```

`let` и `const` так себя не ведут.

## Функциональная область

Переменные, объявленные внутри функции, доступны только внутри этой функции.

```javascript
function calculate() {
  const result = 10 + 5;
  return result;
}

console.log(result); // ReferenceError
```

`var` имеет именно функциональную область видимости:

```javascript
function demo() {
  if (true) {
    var value = 10;
  }

  console.log(value); // 10
}
```

## Блочная область

Блок - это участок кода внутри `{}`. `let` и `const` ограничены блоком.

```javascript
if (true) {
  const message = "inside";
}

console.log(message); // ReferenceError
```

Это делает код безопаснее: переменные не "протекают" наружу.

## Лексическая область

Лексическая область видимости означает, что доступность переменных определяется тем, где функция объявлена, а не тем, где она вызвана.

```javascript
const name = "global";

function createPrinter() {
  const name = "local";

  return function print() {
    console.log(name);
  };
}

const print = createPrinter();
print(); // "local"
```

Функция `print` помнит окружение, в котором была создана. Это основа замыканий.

## Мини-шпаргалка

| Вид области | Где граница | Для чего важно |
| --- | --- | --- |
| Глобальная | весь скрипт или модуль | общие значения, но лучше минимизировать |
| Функциональная | тело функции | поведение `var` |
| Блочная | `{}` | поведение `let` и `const` |
| Лексическая | место объявления | замыкания и поиск переменных |
