# Как использовать pipelines, transactions и scripts в node-redis?

> [!NOTE]
> В Node.js важно различать batching ради скорости, transactions ради последовательного выполнения и Lua scripts ради атомарной условной логики.

## Auto-pipelining через Promise.all

```ts
await Promise.all([
  redis.set('a', '1'),
  redis.set('b', '2'),
  redis.set('c', '3'),
]);
```

Команды, отправленные в один tick, клиент может сгруппировать, уменьшая network round trips.

## Transaction через multi

```ts
const result = await redis
  .multi()
  .set('user:1:name', 'Marat')
  .incr('metrics:user-updates')
  .exec();
```

`exec()` возвращает результаты команд.

## WATCH optimistic locking

```ts
await redis.watch('stock:product:42');

const stock = Number(await redis.get('stock:product:42'));

if (stock <= 0) {
  await redis.unwatch();
  return false;
}

const result = await redis
  .multi()
  .set('stock:product:42', String(stock - 1))
  .exec();

return result !== null;
```

Если watched key изменился, transaction не пройдет.

## Lua через eval

```ts
const script = `
if redis.call("GET", KEYS[1]) == ARGV[1] then
  return redis.call("DEL", KEYS[1])
end
return 0
`;

await redis.eval(script, {
  keys: ['lock:job:42'],
  arguments: [token],
});
```

## Когда что выбрать?

| Нужно | Выбор |
|---|---|
| Ускорить пачку независимых команд | pipeline / `Promise.all` |
| Выполнить несколько команд подряд | `multi().exec()` |
| Optimistic concurrency | `watch()` + `multi()` |
| Conditional atomic logic | Lua `eval()` |

## Мини-шпаргалка

- `Promise.all` хорош для batching.
- `multi().exec()` - transaction.
- `watch()` - optimistic lock.
- `eval()` - server-side atomic logic.
- Большие batch-и дроби на части.
