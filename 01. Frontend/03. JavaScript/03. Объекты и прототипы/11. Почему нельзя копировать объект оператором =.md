# Почему нельзя копировать объект оператором `=`?

> [!NOTE]
> Оператор `=` для объекта копирует не сам объект, а ссылку на него. Поэтому две переменные начинают указывать на одну и ту же структуру в памяти.

## Вопрос

Почему нельзя копировать объект оператором `=`?

## Пример проблемы

```javascript
const user = { name: "Anna" };
const clone = user;

clone.name = "Max";

console.log(user.name); // "Max"
```

`clone` не является независимой копией.

## Что произошло

Упрощенно:

```text
user  ----\
          -> { name: "Anna" }
clone ----/
```

Обе переменные смотрят на один объект.

## Сравнение ссылок

```javascript
const user = { name: "Anna" };
const clone = user;
const realCopy = { ...user };

user === clone;    // true
user === realCopy; // false
```

`realCopy` - новый объект.

## Как копировать правильно

Поверхностно:

```javascript
const copy = { ...user };
```

или:

```javascript
const copy = Object.assign({}, user);
```

Глубоко:

```javascript
const copy = structuredClone(user);
```

## Важная деталь

Даже spread копирует только верхний уровень.

```javascript
const user = { address: { city: "Moscow" } };
const copy = { ...user };

copy.address.city = "Kazan";

console.log(user.address.city); // "Kazan"
```

## Мини-шпаргалка

| Код | Что происходит |
| --- | --- |
| `const b = a` | копируется ссылка |
| `const b = { ...a }` | новый объект верхнего уровня |
| `const b = Object.assign({}, a)` | новый объект верхнего уровня |
| `const b = structuredClone(a)` | глубокая копия |
