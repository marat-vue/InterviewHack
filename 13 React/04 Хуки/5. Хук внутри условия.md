# Можно ли вызывать хук внутри условия?

> [!summary]
> Хуки нельзя вызывать внутри условий, циклов, вложенных функций и после условного `return`. React сопоставляет состояние хуков по порядку вызовов, поэтому порядок должен быть одинаковым при каждом render.

## Плохой пример

```jsx
function Profile({ isAdmin }) {
  if (isAdmin) {
    const [permissions, setPermissions] = useState([])
  }

  return <div>Профиль</div>
}
```

Если `isAdmin` сначала `false`, а потом `true`, порядок вызовов хуков изменится. React не сможет надежно понять, к какому hook state относится.

## Почему порядок важен?

React хранит данные хуков примерно по позиции вызова:

```text
1-й hook -> первое состояние
2-й hook -> второй эффект
3-й hook -> третий ref
```

Если во втором render один hook пропал из-за условия, все следующие хуки "съедут".

## Правильный подход: условие внутри хука

```jsx
function Profile({ userId }) {
  useEffect(() => {
    if (!userId) {
      return
    }

    loadUser(userId)
  }, [userId])

  return <div>Профиль</div>
}
```

Хук вызывается всегда, но логика внутри него выполняется условно.

## Правильный подход: вынести компонент

```jsx
function Page({ isAdmin }) {
  return isAdmin ? <AdminPanel /> : <UserPanel />
}

function AdminPanel() {
  const [permissions, setPermissions] = useState([])
  return <div>Права: {permissions.length}</div>
}
```

Теперь `useState` находится на верхнем уровне компонента `AdminPanel`.

## Что насчет раннего return?

Плохо:

```jsx
function Page({ user }) {
  if (!user) {
    return <LoginPage />
  }

  const [tab, setTab] = useState('profile')
  return <Profile tab={tab} />
}
```

Лучше вызвать хуки до условного return или вынести защищенную часть в отдельный компонент.

## Мини-шпаргалка

- Хуки нельзя вызывать внутри `if`.
- Хуки нельзя вызывать в циклах.
- Хуки нельзя вызывать после условного `return`.
- Условную логику помещают внутрь хука.
- Если hook нужен только в ветке UI, вынеси эту ветку в отдельный компонент.
