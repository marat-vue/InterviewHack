# В чем отличие app от pages router в Next js?

> [!summary]
> `app` - современный App Router с React Server Components, layouts, streaming, Metadata API и новой моделью data fetching. `pages` - старый Pages Router с файлами страниц, `_app`, `_document`, `getStaticProps`, `getServerSideProps` и `pages/api`.

## Главное различие

Pages Router был построен вокруг страниц. App Router построен вокруг route segments, layouts и Server Components.

| Тема | App Router | Pages Router |
|---|---|---|
| Папка | `app` | `pages` |
| Страница | `app/about/page.tsx` | `pages/about.tsx` |
| Layout | `layout.tsx` на любом уровне | обычно `_app.tsx` |
| Server Components | по умолчанию | нет как основной модели |
| Client Components | через `'use client'` | все компоненты фактически клиентские |
| Data fetching | async Server Components, `fetch`, cache | `getStaticProps`, `getServerSideProps` |
| Metadata | Metadata API | `next/head` |
| API | `app/api/users/route.ts` | `pages/api/users.ts` |

## App Router пример

```text
app/
  products/
    [id]/
      page.tsx
```

```tsx
export default async function ProductPage({ params }: Props) {
  const { id } = await params
  const product = await getProduct(id)

  return <ProductView product={product} />
}
```

## Pages Router пример

```text
pages/
  products/
    [id].tsx
```

```tsx
export async function getServerSideProps({ params }) {
  const product = await getProduct(params.id)

  return { props: { product } }
}
```

## Можно ли использовать оба?

Можно, но это обычно временное состояние при миграции. Если есть выбор для нового проекта, лучше начинать с App Router.

## Что отвечать на собеседовании?

App Router - современная архитектура Next.js, где routes состоят из сегментов, layouts могут быть вложенными, компоненты серверные по умолчанию, а данные можно получать прямо в Server Components. Pages Router - более старый подход с `pages`, `getStaticProps`, `getServerSideProps` и `_app`.

## Частые ошибки

- Использовать `getServerSideProps` в `app`.
- Импортировать `useRouter` из `next/router` в App Router.
- Использовать `next/head` вместо Metadata API.
- Думать, что Pages Router полностью удален.
- Мигрировать код без пересмотра Server/Client boundaries.

## Мини-шпаргалка

- Новый проект: App Router.
- `app/about/page.tsx` -> `/about`.
- В `app` нет `getStaticProps`.
- В `app` navigation hooks из `next/navigation`.
- В `pages` navigation hooks из `next/router`.
- Metadata в App Router через Metadata API.
