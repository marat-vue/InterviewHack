# Перечислите все хуки жизненного цикла?

> [!NOTE]
> В Options API основные lifecycle hooks: `beforeCreate`, `created`, `beforeMount`, `mounted`, `beforeUpdate`, `updated`, `beforeUnmount`, `unmounted`. Во Vue 2 вместо `beforeUnmount/unmounted` были `beforeDestroy/destroyed`.

## Вопрос

Перечислите все хуки жизненного цикла Options API.

## Основной список Vue 3

```javascript
export default {
  beforeCreate() {},
  created() {},
  beforeMount() {},
  mounted() {},
  beforeUpdate() {},
  updated() {},
  beforeUnmount() {},
  unmounted() {},
};
```

## Что означает каждый этап

- `beforeCreate` - экземпляр еще почти не инициализирован.
- `created` - state и методы готовы, DOM еще нет.
- `beforeMount` - перед первой вставкой в DOM.
- `mounted` - компонент уже в DOM.
- `beforeUpdate` - перед обновлением DOM.
- `updated` - после обновления DOM.
- `beforeUnmount` - перед удалением.
- `unmounted` - после удаления.

## KeepAlive

```javascript
export default {
  activated() {},
  deactivated() {},
};
```

Эти хуки используются для компонентов внутри `<KeepAlive>`.

## Мини-шпаргалка

- Для DOM чаще нужен `mounted`.
- Для cleanup нужен `unmounted`.
- `created` не имеет доступа к DOM.
- Vue 2 `destroyed` в Vue 3 называется `unmounted`.
