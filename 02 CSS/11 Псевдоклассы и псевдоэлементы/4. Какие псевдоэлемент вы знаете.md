# Какие псевдоэлемент вы знаете

> [!summary]
> В CSS часто используют псевдоэлементы `::before`, `::after`, `::first-line`, `::first-letter`, `::selection`, `::placeholder`, `::marker` и другие.

## Частые псевдоэлементы

| Псевдоэлемент | Что стилизует |
| --- | --- |
| `::before` | Виртуальный контент перед содержимым |
| `::after` | Виртуальный контент после содержимого |
| `::first-line` | Первую строку текста |
| `::first-letter` | Первую букву |
| `::selection` | Выделенный пользователем текст |
| `::placeholder` | Placeholder в поле формы |
| `::marker` | Маркер списка |
| `::backdrop` | Фон за dialog/fullscreen элементом |

## before и after

```css
.link::after {
  content: " ->";
}
```

Они удобны для декоративных иконок, бейджей, разделителей и подсказок.

## selection

```css
::selection {
  background: #bfdbfe;
  color: #111827;
}
```

Меняет стиль выделенного текста.

## placeholder

```css
input::placeholder {
  color: #9ca3af;
}
```

Placeholder должен быть достаточно контрастным, но он не заменяет label.

## marker

```css
li::marker {
  color: #2563eb;
}
```

Позволяет стилизовать маркеры списков.

## Мини-шпаргалка

- `::before` и `::after` создают виртуальный контент.
- `::selection` стилизует выделение текста.
- `::placeholder` стилизует подсказку поля.
- `::marker` стилизует маркер списка.
- `::backdrop` полезен для `<dialog>`.
- Важный смысловой контент лучше держать в HTML.
