# Что такое semi join и anti join?

> [!summary]
> Semi join возвращает строки из левой таблицы, для которых существует совпадение справа. Anti join возвращает строки из левой таблицы, для которых совпадения справа нет. В SQL их часто пишут через `EXISTS` и `NOT EXISTS`.

## Semi join

Найти пользователей, у которых есть заказы:

```sql
SELECT u.*
FROM users u
WHERE EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
);
```

В результате пользователь появится один раз, даже если у него много заказов.

## Anti join

Найти пользователей без заказов:

```sql
SELECT u.*
FROM users u
WHERE NOT EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
);
```

## Альтернатива через LEFT JOIN

```sql
SELECT u.*
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
WHERE o.id IS NULL;
```

Этот вариант тоже распространен, но `NOT EXISTS` часто яснее выражает намерение.

## Почему не обычный JOIN?

Обычный `JOIN` возвращает совпавшие пары строк. Если у пользователя 10 заказов, пользователь появится 10 раз. Semi join отвечает только на вопрос существования.

## Мини-шпаргалка

- Semi join = строки слева, где совпадение справа есть.
- Anti join = строки слева, где совпадения справа нет.
- В SQL часто используют `EXISTS` и `NOT EXISTS`.
- Помогает избежать дублей от one-to-many join.
- Это частый паттерн на собеседованиях.
