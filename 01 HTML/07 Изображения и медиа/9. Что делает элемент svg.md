# Что делает элемент svg

> [!summary]
> Элемент `<svg>` позволяет встроить в HTML векторную графику: иконки, логотипы, схемы, графики и декоративные элементы, которые масштабируются без потери качества.

## Главное

SVG описывает изображение не пикселями, а геометрическими фигурами: линиями, кругами, путями, текстом и группами.

```html
<svg width="120" height="120" viewBox="0 0 120 120" aria-label="Круглая диаграмма">
  <circle cx="60" cy="60" r="48" fill="#e5e7eb" />
  <path d="M60 12 A48 48 0 0 1 108 60" stroke="#2563eb" stroke-width="12" fill="none" />
</svg>
```

## Для чего используют SVG

- Иконки интерфейса.
- Логотипы.
- Простые иллюстрации.
- Схемы и диаграммы.
- Декоративные формы.
- Интерактивную графику.

## viewBox

`viewBox` задает внутреннюю систему координат SVG.

```html
<svg viewBox="0 0 24 24" width="24" height="24">
  <path d="M5 12h14" stroke="currentColor" />
</svg>
```

Благодаря `viewBox` SVG можно масштабировать без потери качества.

## currentColor

Для иконок часто используют `currentColor`, чтобы SVG наследовал цвет текста.

```html
<button class="icon-button">
  <svg viewBox="0 0 24 24" aria-hidden="true">
    <path d="M5 12h14" stroke="currentColor" />
  </svg>
  Назад
</button>
```

## Доступность

Если SVG декоративный, его можно скрыть от assistive technologies.

```html
<svg aria-hidden="true" viewBox="0 0 24 24">
  ...
</svg>
```

Если SVG несет смысл, нужно дать доступное имя через `aria-label` или `<title>`.

## Мини-шпаргалка

- `<svg>` встраивает векторную графику.
- SVG масштабируется без размытия.
- `viewBox` задает систему координат.
- `currentColor` удобен для иконок.
- Декоративный SVG скрывают через `aria-hidden="true"`.
- Смысловой SVG должен иметь доступное имя.
