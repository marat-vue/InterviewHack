# Можно ли вызывать Server Action из Client Component?

> [!summary]
> Да, Server Action можно вызывать из Client Component, но обычно ее выносят в отдельный файл с директивой `'use server'`, импортируют в клиентский компонент и вызывают через form action, event handler или React hooks вроде `useActionState`.

## Базовый паттерн

`actions.ts`:

```ts
'use server'

export async function createComment(formData: FormData) {
  const text = String(formData.get('text'))
  await db.comment.create({ data: { text } })
}
```

Client Component:

```tsx
'use client'

import { createComment } from './actions'

export function CommentForm() {
  return (
    <form action={createComment}>
      <input name="text" />
      <button>Send</button>
    </form>
  )
}
```

## Через event handler

```tsx
'use client'

import { deletePost } from './actions'

export function DeleteButton({ postId }: { postId: string }) {
  return (
    <button
      onClick={async () => {
        await deletePost(postId)
      }}
    >
      Delete
    </button>
  )
}
```

Для форм чаще лучше `<form action={...}>`, потому что это естественный web flow.

## С useActionState

```tsx
'use client'

import { useActionState } from 'react'
import { updateProfile } from './actions'

export function ProfileForm() {
  const [state, formAction, isPending] = useActionState(updateProfile, {
    error: null,
  })

  return (
    <form action={formAction}>
      <input name="name" />
      <button disabled={isPending}>Save</button>
      {state.error && <p>{state.error}</p>}
    </form>
  )
}
```

## Что важно помнить?

- Server Action выполняется на сервере.
- Client Component получает ссылку на action через Next/React protocol.
- Аргументы должны быть сериализуемыми или `FormData`.
- Нельзя считать action приватной.
- Нужно проверять пользователя и права.

## Что отвечать на собеседовании?

Server Action можно вызывать из Client Component, если она определена как server function, обычно в отдельном файле с `'use server'`. Для форм используют `action={serverAction}`, для pending/error state - `useActionState` и `useFormStatus`, а для событий можно вызвать action в обработчике.

## Частые ошибки

- Определять action прямо внутри Client Component.
- Не проверять auth внутри action.
- Передавать несериализуемые объекты.
- Использовать event handler там, где форма проще.
- Не обрабатывать pending/error state.

## Мини-шпаргалка

- Да, из Client Component вызывать можно.
- Action чаще лежит в отдельном `'use server'` файле.
- Формы: `<form action={action}>`.
- Pending state: `useActionState`, `useFormStatus`.
- Auth и validation обязательны.
- Args должны быть сериализуемыми.
