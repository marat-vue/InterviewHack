# Что такое WebSocket gateway в NestJS?

> [!summary]
> WebSocket gateway - class с decorator `@WebSocketGateway()`, который обрабатывает realtime-соединения и сообщения. NestJS поддерживает gateways и применяет к ним многие привычные concepts: DI, guards, pipes, interceptors.

## Пример gateway

```ts
@WebSocketGateway()
export class ChatGateway {
  @SubscribeMessage('message')
  handleMessage(@MessageBody() data: string) {
    return { event: 'message', data };
  }
}
```

## Когда нужен gateway?

- чат;
- realtime уведомления;
- online status;
- collaborative editing;
- live dashboard;
- game events.

## Socket.io и ws

NestJS поддерживает разные WebSocket platforms через adapters. Часто используют socket.io, но можно выбрать `ws`.

## Мини-шпаргалка

- Gateway помечается `@WebSocketGateway`.
- Message handler помечается `@SubscribeMessage`.
- `@MessageBody` достает payload.
- Gateways поддерживают DI.
- Для нескольких инстансов нужен adapter/broker.
