# Что такое feature module на примере users?

> [!summary]
> Feature module - модуль, который собирает код одной предметной области. На примере `users` он хранит `UsersController`, `UsersService`, DTO и связанные providers.

## Структура

```txt
src/users/
  dto/
    create-user.dto.ts
    update-user.dto.ts
  users.controller.ts
  users.service.ts
  users.module.ts
```

## users.module.ts

```ts
@Module({
  controllers: [UsersController],
  providers: [UsersService],
  exports: [UsersService],
})
export class UsersModule {}
```

`exports` нужен только если другие modules должны inject `UsersService`.

## users.controller.ts

```ts
@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Post()
  create(@Body() dto: CreateUserDto) {
    return this.usersService.create(dto);
  }
}
```

## users.service.ts

```ts
@Injectable()
export class UsersService {
  create(dto: CreateUserDto) {
    return { id: 1, ...dto };
  }
}
```

## Мини-шпаргалка

- Feature module собирает код одной фичи.
- Controller и service регистрируются в module.
- DTO лежат рядом с controller/use case.
- `exports` открывает service другим modules.
- Если service нужен только внутри фичи, export не нужен.
