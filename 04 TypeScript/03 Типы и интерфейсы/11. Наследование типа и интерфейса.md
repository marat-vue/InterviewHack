# Наследование типа и интерфейса

> [!summary] Коротко
> Интерфейсы и type aliases могут расширять друг друга, если итоговая форма является объектной.

## Вопрос

Можно ли интерфейсу наследоваться от типа, а типу - от интерфейса?

## Interface extends type

```typescript
type Entity = {
  id: number;
};

interface User extends Entity {
  name: string;
}
```

Это работает, потому что `Entity` описывает объектную форму.

## Type extends interface через intersection

```typescript
interface Entity {
  id: number;
}

type User = Entity & {
  name: string;
};
```

`type` не использует `extends` для композиции объектных форм. Для этого применяют `&`.

## Когда не получится

```typescript
type Status = 'idle' | 'loading';

interface State extends Status {} // ошибка
```

Интерфейс не может расширять union из строковых литералов.

## Практическое правило

Если нужно расширять объектный контракт - можно использовать `interface extends`. Если нужно комбинировать union, intersections, conditional types - чаще удобнее `type`.

## Сравнение

| Задача | Синтаксис |
| --- | --- |
| interface от interface | `interface B extends A {}` |
| interface от object type | `interface B extends A {}` |
| type от interface | `type B = A & {}` |
| type union | `type B = A | C` |

## Мини-шпаргалка

```typescript
interface B extends A {}
type B = A & { extra: string };
```
