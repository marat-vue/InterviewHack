# Что такое асинхронность в JavaScript?

> [!NOTE] Коротко
> Асинхронность позволяет запускать долгие операции и не блокировать выполнение остального JavaScript-кода.

## Вопрос

Зачем JavaScript нужна асинхронность, если он считается однопоточным?

## Определение

Асинхронность - это способ выполнять задачи, результат которых появится позже: сетевые запросы, таймеры, чтение файлов, события пользователя. JavaScript не ждет их завершения на месте, а продолжает выполнять следующий код.

Когда операция готова, ее обработчик попадает в очередь и выполняется через Event Loop.

## Синхронный пример

```javascript
console.log('start');
console.log('middle');
console.log('end');

// start
// middle
// end
```

Синхронный код идет строго сверху вниз.

## Асинхронный пример

```javascript
console.log('start');

setTimeout(() => {
  console.log('timer');
}, 0);

console.log('end');

// start
// end
// timer
```

Таймер не выполняется сразу. Его callback попадет в очередь после завершения текущего синхронного кода.

## Как это связано с Event Loop

1. Синхронный код выполняется в Call Stack.
2. Асинхронная операция передается среде выполнения: браузеру или Node.js.
3. Когда результат готов, callback попадает в очередь.
4. Event Loop переносит задачу в стек, когда стек свободен.

## Формы асинхронности

- callbacks;
- события;
- `Promise`;
- `async/await`;
- таймеры;
- Web API браузера;
- Node.js I/O.

## Мини-шпаргалка

```javascript
setTimeout(fn, 1000); // выполнить позже
fetch(url).then(fn);  // обработать ответ позже
await promise;        // дождаться внутри async-функции
```
