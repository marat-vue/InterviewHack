# Что происходит при обновлении компонента?

> [!summary]
> Обновление компонента происходит, когда меняются state, props, context, external store или обновляется родитель. React заново вызывает компонент, сравнивает новый результат с предыдущим и применяет нужные изменения к DOM.

## Что вызывает update?

- `setState` или setter из `useState`;
- `dispatch` из `useReducer`;
- новые props;
- изменение context;
- обновление external store;
- render родительского компонента.

## Последовательность update

```text
1. Trigger update
2. React вызывает компонент
3. Компонент возвращает новый JSX
4. React сравнивает старое и новое дерево
5. React применяет изменения к DOM
6. Cleanup effects с измененными dependencies
7. Setup новых effects
```

## Пример

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  useEffect(() => {
    document.title = `Count: ${count}`
  }, [count])

  return <button onClick={() => setCount(count + 1)}>{count}</button>
}
```

Клик вызывает update state, затем React обновляет UI и effect синхронизирует `document.title`.

## Render не всегда меняет DOM

Компонент может отрендериться, но DOM останется прежним, если результат не изменился:

```jsx
function Title({ text }) {
  return <h1>{text}</h1>
}
```

Если `text` такой же, React не обязан менять DOM.

## Мини-шпаргалка

- Update запускается изменением state/props/context/store.
- React вызывает компонент заново.
- Render вычисляет новый UI.
- Commit применяет изменения к DOM.
- Effects обновляются по dependencies.
