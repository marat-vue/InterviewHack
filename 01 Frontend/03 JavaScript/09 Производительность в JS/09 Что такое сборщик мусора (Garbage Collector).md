# Что такое сборщик мусора (Garbage Collector)?

> [!NOTE]
> Garbage Collector автоматически освобождает память, удаляя объекты, до которых больше нельзя добраться из работающего кода.

## Вопрос

Что такое сборщик мусора в JavaScript и как он понимает, что объект больше не нужен?

## Определение

Сборщик мусора, GC, - механизм движка JavaScript, который управляет памятью автоматически. Разработчик создает объекты, массивы, функции и замыкания, а движок периодически ищет недостижимые значения и освобождает память.

Главная идея: если до объекта нельзя добраться из корней, значит он больше не нужен.

## Что считается корнями

- глобальный объект;
- текущий Call Stack;
- активные замыкания;
- DOM-объекты, на которые есть ссылки;
- очереди задач и активные callbacks;
- внутренние ссылки движка.

## Пример

```javascript
let user = { name: 'Ann' };

user = null;
```

После `user = null` объект `{ name: 'Ann' }` может быть удален, если на него больше нигде нет ссылок.

## Почему память может не освобождаться

```javascript
const cache = [];

function save(data) {
  cache.push(data);
}
```

Если массив `cache` живет долго и бесконтрольно растет, объекты остаются достижимыми, даже если логике они уже не нужны.

## Mark-and-sweep

Упрощенно GC работает так:

1. отмечает все объекты, достижимые из корней;
2. проходит по ссылкам от них;
3. удаляет все, что не было отмечено.

## Мини-шпаргалка

```text
reachable object -> stays in memory
unreachable object -> can be collected
```
