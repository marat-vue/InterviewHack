# Как добавить Organization, WebSite и Breadcrumb?

> [!summary]
> Organization, WebSite и BreadcrumbList - базовые типы structured data для многих сайтов. Они помогают описать бренд, сайт и навигационный путь страницы.

## Organization

Пример:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Frontend Academy",
  "url": "https://example.com",
  "logo": "https://example.com/logo.png"
}
</script>
```

Используется для описания компании, проекта или организации.

## WebSite

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "Frontend Academy",
  "url": "https://example.com"
}
</script>
```

Иногда добавляют `SearchAction` для поиска по сайту, если на сайте есть полноценный поиск.

## BreadcrumbList

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://example.com"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "SEO",
      "item": "https://example.com/seo"
    }
  ]
}
</script>
```

Хлебные крошки особенно полезны для сайтов с вложенной структурой.

## Что важно?

- Breadcrumb на странице должен совпадать с видимой навигацией.
- URL должны быть абсолютными и каноническими.
- Organization обычно не нужно дублировать на каждой странице разными данными.
- Logo должен быть доступен для поискового робота.

## Мини-шпаргалка

- `Organization` описывает бренд или компанию.
- `WebSite` описывает сайт.
- `BreadcrumbList` описывает путь страницы.
- Разметка должна совпадать с интерфейсом.
- URL в structured data должны быть стабильными и canonical.
