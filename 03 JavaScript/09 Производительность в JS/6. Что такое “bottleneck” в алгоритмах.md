# Что такое “bottleneck” в алгоритмах

> [!summary] Коротко
> Bottleneck в алгоритме - самая дорогая часть вычислений, которая определяет общую скорость работы.

## Вопрос

Что называют узким местом алгоритма?

## Определение

Bottleneck - участок алгоритма, который потребляет больше всего времени или памяти и ограничивает масштабирование. Пока он не исправлен, остальные оптимизации дают мало пользы.

## Пример

```javascript
const result = users.filter((user) => {
  return selectedIds.includes(user.id);
});
```

Если `users` и `selectedIds` большие, узким местом станет `includes`, потому что поиск по массиву выполняется много раз.

## Улучшение

```javascript
const selectedIdsSet = new Set(selectedIds);

const result = users.filter((user) => {
  return selectedIdsSet.has(user.id);
});
```

Мы заменили повторный линейный поиск на быстрые проверки через `Set`.

## Как искать bottleneck

1. Измерить время выполнения.
2. Найти самый дорогой участок.
3. Посмотреть сложность алгоритма.
4. Проверить объем промежуточных данных.
5. Изменить алгоритм или структуру данных.

## Мини-шпаргалка

```text
bottleneck = место, которое сильнее всего ограничивает скорость
```
