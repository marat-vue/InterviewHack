# Анонимные функции

> [!NOTE]
> Анонимная функция - функция без собственного имени в месте объявления. Ее часто используют как callback или присваивают переменной.

## Вопрос

Что такое анонимная функция?

## Пример

```javascript
const sum = function (a, b) {
  return a + b;
};
```

Функция справа не имеет имени. Имя `sum` принадлежит переменной, а не самой функции.

## Callback

Анонимные функции часто передают сразу в другую функцию.

```javascript
setTimeout(function () {
  console.log("Прошла 1 секунда");
}, 1000);
```

С массивами:

```javascript
const doubled = numbers.map(function (number) {
  return number * 2;
});
```

Стрелочный вариант:

```javascript
const doubled = numbers.map((number) => number * 2);
```

## Именованная функция для сравнения

```javascript
function sum(a, b) {
  return a + b;
}
```

Здесь у функции есть имя `sum`.

Named Function Expression:

```javascript
const factorial = function calc(n) {
  if (n <= 1) return 1;

  return n * calc(n - 1);
};
```

## Плюсы анонимных функций

- удобно писать короткие callback;
- не засоряют область видимости лишними именами;
- хорошо подходят для одноразовой логики.

## Минусы

Анонимные функции могут ухудшить читаемость и stack trace.

```javascript
button.addEventListener("click", function () {
  validateForm();
  sendForm();
  showSuccess();
});
```

Если логика растет, лучше дать функции имя.

```javascript
button.addEventListener("click", handleSubmit);

function handleSubmit() {
  validateForm();
  sendForm();
  showSuccess();
}
```

## Мини-шпаргалка

| Вид | Пример |
| --- | --- |
| Анонимная FE | `const f = function () {}` |
| Анонимная arrow | `const f = () => {}` |
| Анонимный callback | `setTimeout(function () {}, 1000)` |
| Именованная функция | `function f() {}` |
| Named FE | `const f = function inner() {}` |
