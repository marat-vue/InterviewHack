# Как изучать TanStack Query

> [!summary]
> TanStack Query нужно изучать как менеджер server state: он отвечает за загрузку, кеширование, refetch, stale state, mutations, invalidation, optimistic updates и синхронизацию UI с сервером.

## Что такое server state?

Server state - данные, источником правды для которых является сервер:

- пользователь;
- список товаров;
- заказы;
- комментарии;
- результаты поиска;
- permissions;
- dashboard metrics.

Эти данные отличаются от обычного client state:

| Client state | Server state |
|---|---|
| живет в браузере | живет на сервере |
| controlled by UI | controlled by backend |
| sidebar, modal, tab | users, posts, orders |
| Zustand/useState | TanStack Query |

## Почему не хватает useEffect?

Без TanStack Query приходится вручную писать:

- `isLoading`;
- `error`;
- `data`;
- retry;
- cache;
- refetch;
- cancellation;
- deduplication;
- pagination;
- invalidation after mutation.

```tsx
useEffect(() => {
  let ignore = false

  async function loadUsers() {
    setLoading(true)

    try {
      const users = await fetchUsers()

      if (!ignore) {
        setUsers(users)
      }
    } finally {
      setLoading(false)
    }
  }

  loadUsers()

  return () => {
    ignore = true
  }
}, [])
```

TanStack Query берет эту инфраструктуру на себя.

## Что нужно знать по порядку?

1. `QueryClient` и `QueryClientProvider`.
2. `useQuery` для чтения данных.
3. `queryKey` и почему это ключ кеша.
4. `queryFn` и работа с ошибками.
5. `staleTime`, `gcTime`, refetch.
6. `useMutation` для изменения данных.
7. `invalidateQueries` после мутации.
8. `setQueryData` для ручного обновления кеша.
9. optimistic updates.
10. pagination и infinite queries.

## Что отвечать на собеседовании?

TanStack Query - библиотека управления server state. Она не просто делает fetch, а кеширует запросы, отслеживает stale/fresh состояние, умеет refetch, retry, invalidation, mutations и optimistic updates. Для client state она не предназначена.

## Мини-шпаргалка

- `useQuery` - чтение данных.
- `useMutation` - создание/изменение/удаление.
- `queryKey` - адрес данных в кеше.
- `invalidateQueries` - пометить данные устаревшими.
- `setQueryData` - вручную обновить кеш.
- `staleTime` - сколько данные считаются свежими.
