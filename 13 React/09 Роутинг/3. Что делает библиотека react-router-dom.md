# Что делает библиотека react-router-dom?

> [!summary]
> `react-router-dom` - это пакет React Router для веб-приложений. Он дает компоненты и хуки для маршрутов, ссылок, программной навигации, параметров URL, вложенных layout и редиректов в браузере.

## Установка

```bash
npm install react-router-dom
```

`react-router` - ядро маршрутизации. `react-router-dom` добавляет DOM/browser-интеграцию: `BrowserRouter`, `HashRouter`, `Link`, формы и хуки для веба.

## Минимальный пример

```jsx
import { BrowserRouter, Link, Route, Routes } from 'react-router-dom'

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
      </nav>

      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
        <Route path="/users/:userId" element={<UserPage />} />
      </Routes>
    </BrowserRouter>
  )
}
```

## Основные инструменты

| Инструмент | Для чего |
|---|---|
| `BrowserRouter` | Роутинг через History API и красивые URL |
| `HashRouter` | Роутинг через `#`, когда сервер нельзя настроить |
| `Routes` | Контейнер для выбора маршрута |
| `Route` | Описание маршрута |
| `Link` | Навигация без reload |
| `NavLink` | Ссылка, которая знает active state |
| `Navigate` | Редирект при render |
| `Outlet` | Место для дочернего маршрута |
| `useNavigate` | Навигация из кода |
| `useParams` | Динамические параметры URL |
| `useSearchParams` | Query string |
| `useLocation` | Информация о текущем location |

## Data routers

В новых подходах React Router умеет работать не только как набор компонентов, но и как data router:

- `loader` для загрузки данных до render;
- `action` для обработки мутаций;
- `redirect` в loaders/actions;
- error boundaries для routes;
- pending UI для навигации.

Но для базового SPA на собеседовании чаще всего спрашивают declarative API: `BrowserRouter`, `Routes`, `Route`, `Link`, `useNavigate`, `useParams`, `Outlet`.

## Мини-шпаргалка

- `react-router-dom` нужен для routing в браузерном React.
- Он связывает URL с компонентами.
- `<Link>` не перезагружает страницу.
- Хуки работают только внутри Router.
- Для сложных приложений стоит знать data routers.
