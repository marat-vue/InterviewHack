# Стрелочные функции против обычных

> [!summary] Коротко
> Стрелочные функции короче и не имеют собственного `this`, `arguments` и `prototype`. Обычные функции подходят для методов, конструкторов и случаев, где важен собственный контекст вызова.

## Вопрос

Чем отличаются стрелочные функции `() => {}` от `function () {}`?

## Синтаксис

Обычная функция:

```javascript
function sum(a, b) {
  return a + b;
}
```

Стрелочная функция:

```javascript
const sum = (a, b) => a + b;
```

Если тело состоит из одного выражения, результат возвращается автоматически.

```javascript
const double = (value) => value * 2;
```

## Главное отличие: `this`

Обычная функция получает `this` в зависимости от способа вызова.

```javascript
const user = {
  name: "Anna",
  sayHi: function () {
    return `Hi, ${this.name}`;
  },
};

user.sayHi(); // "Hi, Anna"
```

Стрелочная функция не имеет собственного `this`. Она берет `this` из внешней области.

```javascript
const user = {
  name: "Anna",
  sayHi: () => {
    return `Hi, ${this.name}`;
  },
};

user.sayHi(); // обычно не "Hi, Anna"
```

Поэтому стрелочные функции не подходят для методов объекта, если нужен `this` самого объекта.

## `arguments`

Обычная функция имеет `arguments`.

```javascript
function showArgs() {
  console.log(arguments);
}

showArgs(1, 2, 3);
```

У стрелочной функции своего `arguments` нет. Используйте rest-параметры.

```javascript
const showArgs = (...args) => {
  console.log(args);
};
```

## Конструктор

Обычную функцию можно вызвать через `new`.

```javascript
function User(name) {
  this.name = name;
}

const user = new User("Anna");
```

Стрелочную функцию нельзя использовать как конструктор.

```javascript
const User = (name) => {
  this.name = name;
};

new User("Anna"); // TypeError
```

## Когда использовать стрелочные функции

Хорошо подходят для callback-функций:

```javascript
const names = users.map((user) => user.name);
```

И для сохранения внешнего `this`:

```javascript
function Timer() {
  this.seconds = 0;

  setInterval(() => {
    this.seconds++;
  }, 1000);
}
```

## Мини-шпаргалка

| Отличие | `function` | arrow function |
| --- | --- | --- |
| `this` | зависит от вызова | берется снаружи |
| `arguments` | есть | нет |
| `prototype` | есть | нет |
| `new` | можно | нельзя |
| краткий возврат | нет | есть |
| методы объекта | часто подходит | часто не подходит |
