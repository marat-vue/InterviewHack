# Типы асинхронных операций

> [!NOTE] Коротко
> В JavaScript асинхронность чаще всего встречается в таймерах, сетевых запросах, событиях, промисах, I/O и worker-потоках.

## Вопрос

Какие типы асинхронных операций есть в JavaScript?

## Таймеры

Таймеры планируют выполнение callback-функции позже.

```javascript
setTimeout(() => console.log('once'), 1000);
setInterval(() => console.log('repeat'), 1000);
```

Обычно callbacks таймеров попадают в очередь макротасок.

## Сетевые запросы

```javascript
const response = await fetch('/api/users');
const users = await response.json();
```

Сеть работает вне основного JS-стека. Продолжение через промис выполняется как микротаска.

## События

```javascript
button.addEventListener('click', () => {
  console.log('clicked');
});
```

Обработчик события выполняется позже, когда событие произойдет и стек будет свободен.

## I/O в Node.js

```javascript
import { readFile } from 'node:fs/promises';

const text = await readFile('file.txt', 'utf8');
```

Асинхронные файловые операции не блокируют основной поток ожиданием диска.

## Промисы и async/await

```javascript
Promise.resolve()
  .then(() => console.log('microtask'));
```

Продолжения промисов попадают в очередь микротасок.

## Workers

```javascript
const worker = new Worker('worker.js');

worker.postMessage({ type: 'START' });
```

Workers нужны для реального выполнения кода в отдельном потоке.

## Мини-шпаргалка

```text
timers/events/I/O -> usually tasks
Promise.then/await -> microtasks
Workers -> separate thread + messages
```
