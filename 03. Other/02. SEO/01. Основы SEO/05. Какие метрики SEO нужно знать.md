# Какие метрики SEO нужно знать?

> [!summary]
> SEO-метрики помогают понимать видимость, спрос, клики, качество страниц и бизнес-результат. Важно не смотреть на одну позицию, а связывать impressions, clicks, CTR, average position, indexed pages, conversions и revenue.

## Search Console метрики

| Метрика | Что показывает |
|---|---|
| Impressions | сколько раз сайт показался в поиске |
| Clicks | сколько кликов получил сайт |
| CTR | доля кликов от impressions |
| Average position | средняя позиция в результатах |
| Indexed pages | сколько страниц в индексе |
| Queries | по каким запросам сайт показывается |

## GA4 метрики

- organic sessions;
- engaged sessions;
- conversions/key events;
- revenue;
- landing pages;
- user acquisition;
- traffic acquisition.

## Technical метрики

- crawl errors;
- index coverage;
- 404/5xx;
- redirect chains;
- Core Web Vitals;
- page speed;
- structured data errors;
- sitemap errors.

## Почему позиция не главная?

Average position может меняться из-за:

- страны;
- устройства;
- персонализации;
- SERP features;
- разных queries;
- изменений выдачи.

Лучше смотреть связку:

```text
query -> page -> impressions -> CTR -> clicks -> conversions
```

## Мини-шпаргалка

- Impressions показывают видимость.
- Clicks показывают фактический трафик.
- CTR показывает привлекательность сниппета.
- Average position полезна, но не абсолютна.
- Конверсии важнее голого трафика.
- Technical errors объясняют, почему страницы не растут.
