# Что делает margin

> [!summary]
> `margin` - это внешний отступ элемента: пространство снаружи border, которое отделяет элемент от соседей.

## Главное

```css
.card {
  margin: 24px;
}
```

`margin` не окрашивается фоном элемента и находится за пределами border.

## Запись по сторонам

```css
.box {
  margin-top: 16px;
  margin-right: 0;
  margin-bottom: 24px;
  margin-left: 0;
}
```

Сокращенная запись:

```css
.box {
  margin: 16px 0 24px;
}
```

Это означает: сверху `16px`, справа/слева `0`, снизу `24px`.

## auto

```css
.container {
  width: 960px;
  margin-inline: auto;
}
```

`margin-inline: auto` часто центрирует блок фиксированной или ограниченной ширины.

## Margin и схлопывание

Вертикальные margin блочных элементов могут схлопываться.

```css
h2 {
  margin-bottom: 24px;
}

p {
  margin-top: 16px;
}
```

Итоговый промежуток может стать не `40px`, а максимальным из двух значений.

## Мини-шпаргалка

- Margin - внешний отступ.
- Находится снаружи border.
- Не окрашивается фоном элемента.
- Может быть `auto`.
- Может быть отрицательным.
- Вертикальные margin иногда схлопываются.
