# Какие папки являются обязательными?

> [!summary]
> В Next.js обязательна только структура, которая нужна выбранному роутеру. Для App Router ключевая папка - `app`, а для старого Pages Router - `pages`. Остальные папки вроде `components`, `lib`, `shared`, `features`, `entities`, `styles` являются архитектурным выбором команды.

## Минимум для App Router

Минимальный проект:

```text
app/
  page.tsx
```

`page.tsx` создает главную страницу `/`.

В реальном проекте почти всегда добавляют root layout:

```text
app/
  layout.tsx
  page.tsx
```

Корневой `layout.tsx` задает `<html>` и `<body>`.

## Пример root layout

```tsx
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ru">
      <body>{children}</body>
    </html>
  )
}
```

## Какие папки не обязательны?

Next.js не требует:

- `components`;
- `shared`;
- `features`;
- `entities`;
- `widgets`;
- `hooks`;
- `lib`;
- `api`;
- `styles`;
- `store`.

Эти папки нужны для организации кода, но не для запуска фреймворка.

## public

`public` тоже не обязателен, но часто используется:

```text
public/
  favicon.ico
  images/
    logo.svg
```

Файл `public/images/logo.svg` доступен по URL `/images/logo.svg`.

## src

Next.js поддерживает структуру с `src`:

```text
src/
  app/
  shared/
  features/
```

Это удобно, чтобы отделить исходный код от конфигов в корне.

## Что отвечать на собеседовании?

Для App Router ключевая папка - `app`, а публичные страницы создаются через `page.tsx`. Root layout практически обязателен в реальном приложении, потому что он задает документ. Все остальные папки являются соглашениями архитектуры, а не требованиями Next.js.

## Частые ошибки

- Считать `components` обязательной папкой.
- Не понимать разницу между `app` и `pages`.
- Класть route files вне `app`.
- Забывать root layout в production-проекте.
- Смешивать архитектурные слои и route segments без правил.

## Мини-шпаргалка

- App Router: `app`.
- Страница: `page.tsx`.
- Root layout: `app/layout.tsx`.
- Static assets: `public`.
- `src` опционален.
- `components/lib/features` - не требования Next.js.
