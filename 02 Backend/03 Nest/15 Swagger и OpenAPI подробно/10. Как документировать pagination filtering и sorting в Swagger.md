# Как документировать pagination, filtering и sorting в Swagger?

> [!summary]
> Pagination, filtering и sorting лучше описывать явно: какие query params доступны, какие значения допустимы, какие defaults используются и какой формат ответа возвращает API.

## Query params

```ts
@ApiQuery({ name: 'page', required: false, example: 1 })
@ApiQuery({ name: 'limit', required: false, example: 20 })
@ApiQuery({ name: 'sort', required: false, enum: ['createdAt', 'email'] })
@ApiQuery({ name: 'search', required: false })
@Get()
findAll() {}
```

## Response

```ts
export class UsersPageDto {
  @ApiProperty({ type: [UserDto] })
  items: UserDto[];

  @ApiProperty({ example: 100 })
  total: number;

  @ApiProperty({ example: 1 })
  page: number;

  @ApiProperty({ example: 20 })
  limit: number;
}
```

## Что обязательно указать?

- default `page`;
- maximum `limit`;
- допустимые sort fields;
- формат search;
- будет ли cursor pagination.

## Мини-шпаргалка

- Query params документируют через `@ApiQuery`.
- Sorting values лучше делать enum.
- Limit maximum должен совпадать с validation.
- Response должен показывать metadata.
- Cursor pagination нужно документировать отдельно от offset.
