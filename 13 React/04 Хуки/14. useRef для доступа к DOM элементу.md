# Как использовать useRef для доступа к DOM-элементу?

> [!summary]
> `useRef` можно передать в JSX prop `ref`, чтобы после commit получить DOM-элемент в `ref.current`. Это нужно для фокуса, прокрутки, управления видео, измерений и интеграции с внешними DOM-библиотеками.

## Фокус на input

```jsx
function SearchForm() {
  const inputRef = useRef(null)

  function focusInput() {
    inputRef.current?.focus()
  }

  return (
    <>
      <input ref={inputRef} />
      <button onClick={focusInput}>Сфокусировать</button>
    </>
  )
}
```

`inputRef.current` будет DOM-элементом `<input>` после монтирования.

## Прокрутка к элементу

```jsx
function Article() {
  const commentsRef = useRef(null)

  function scrollToComments() {
    commentsRef.current?.scrollIntoView({
      behavior: 'smooth',
      block: 'start',
    })
  }

  return (
    <>
      <button onClick={scrollToComments}>К комментариям</button>
      <section ref={commentsRef}>Комментарии</section>
    </>
  )
}
```

## Управление video

```jsx
function VideoPlayer() {
  const videoRef = useRef(null)

  return (
    <>
      <video ref={videoRef} src="/intro.mp4" />
      <button onClick={() => videoRef.current?.play()}>Play</button>
      <button onClick={() => videoRef.current?.pause()}>Pause</button>
    </>
  )
}
```

## Когда не нужен DOM ref?

Не используй ref, если задачу можно решить декларативно:

```jsx
<button className={isActive ? 'active' : ''}>
  Сохранить
</button>
```

Не нужно вручную добавлять класс через DOM API, если это обычное состояние UI.

## SSR-нюанс

На сервере DOM нет. Поэтому код с `window`, `document` и DOM-refs должен выполняться на клиенте: в event handler, `useEffect` или `useLayoutEffect`, а не во время render.

## Мини-шпаргалка

- Передай `ref` в JSX-элемент, чтобы получить DOM node.
- DOM ref доступен после commit.
- Используй ref для focus, scroll, media, measurements.
- Не меняй DOM вручную там, где достаточно state/props.
- На сервере DOM API недоступны.
