# Тип возвращаемого значения

> [!NOTE]
> Тип возвращаемого значения пишется после списка параметров: `function fn(): number`. Он фиксирует, что функция обязана вернуть.

## Вопрос

Как указать тип возвращаемого значения функции?

## Обычная функция

```typescript
function getTotal(price: number, count: number): number {
  return price * count;
}
```

Если вернуть строку вместо числа, TypeScript сразу покажет ошибку.

## Стрелочная функция

```typescript
const formatPrice = (value: number): string => {
  return `${value} ₽`;
};
```

## Объект как результат

Для сложных результатов лучше вынести тип отдельно.

```typescript
type UserDto = {
  id: number;
  name: string;
};

function getUser(): UserDto {
  return { id: 1, name: "Мария" };
}
```

## Специальные случаи

```typescript
function save(): void {
  console.log("saved");
}

function crash(): never {
  throw new Error("Something went wrong");
}

async function load(): Promise<UserDto> {
  return { id: 1, name: "Мария" };
}
```

## Когда указывать явно

TypeScript часто сам выводит return type, но явная аннотация полезна для API, экспортируемых функций и мест, где ошибка возврата должна быть поймана сразу.

## Мини-шпаргалка

- `function fn(): Type` - тип результата.
- У стрелки: `(x): Type => ...`.
- `void` - значимый результат не возвращается.
- `Promise<T>` - результат асинхронной функции.
