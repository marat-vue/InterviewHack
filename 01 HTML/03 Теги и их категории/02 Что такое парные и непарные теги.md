# Что такое парные и непарные теги

> [!summary]
> **Парные теги** имеют открывающую и закрывающую часть, а **непарные** описывают элементы без содержимого и не требуют закрывающего тега.

## Парные теги

Парные теги оборачивают содержимое.

```html
<p>Абзац текста</p>
<h1>Заголовок</h1>
<button type="button">Открыть</button>
```

Открывающий тег начинает элемент, закрывающий - завершает его.

## Непарные теги

Непарные элементы не содержат вложенного контента.

```html
<img src="/photo.jpg" alt="Портрет">
<input type="email" name="email">
<br>
<hr>
<meta charset="UTF-8">
<link rel="stylesheet" href="/styles.css">
```

Их также называют **void elements**.

## Почему это важно

Если закрыть void-элемент как обычный парный или вложить в него контент, браузер может построить DOM не так, как ожидается.

```html
<!-- неправильно по смыслу -->
<input type="text">Имя</input>
```

Для подписи поля нужен `label`.

```html
<label for="name">Имя</label>
<input id="name" type="text" name="name">
```

## XHTML-синтаксис

В HTML можно встретить запись:

```html
<img src="/photo.jpg" alt="Портрет" />
```

В HTML5 слеш в конце void-элемента не обязателен. Он часто остается из привычки или из-за форматтеров.

## Мини-шпаргалка

- Парные теги имеют открытие и закрытие.
- Непарные теги не имеют содержимого.
- `img`, `input`, `br`, `hr`, `meta`, `link` - частые void-элементы.
- Внутрь `input` нельзя положить текст.
- Подпись для поля делают через `label`.
