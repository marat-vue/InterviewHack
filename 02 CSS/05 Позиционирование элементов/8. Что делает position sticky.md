# Что делает position sticky

> [!summary]
> `position: sticky` заставляет элемент вести себя как обычный элемент в потоке, пока при прокрутке он не достигнет заданного порога. После этого он "прилипает" внутри границ своего контейнера.

## Главное

```css
.sidebar {
  position: sticky;
  top: 24px;
}
```

Элемент будет прокручиваться вместе со страницей, а затем прилипнет на расстоянии `24px` от верхнего края viewport.

## Нужен offset

Для sticky нужно указать хотя бы один offset: `top`, `right`, `bottom` или `left`.

```css
.table-header {
  position: sticky;
  top: 0;
}
```

Без `top` или другого порога sticky не проявит себя.

## Sticky остается в потоке

В отличие от `fixed`, sticky-элемент занимает место в normal flow.

```text
normal flow
  -> element scrolls normally
  -> reaches top offset
  -> sticks
  -> stops at parent boundary
```

## Ограничение родителем

Sticky работает внутри границ ближайшего scroll-контейнера или родителя. Когда родитель заканчивается, sticky-элемент перестает прилипать.

## Частые проблемы

- Не указан `top`.
- У родителя стоит `overflow: hidden`, `auto` или `scroll`.
- Родитель слишком низкий.
- Элементу некуда прилипать.
- Ожидали `fixed`, а нужен был sticky или наоборот.

## Мини-шпаргалка

- Sticky сочетает normal flow и fixed-поведение.
- Нужен offset, чаще `top`.
- Элемент занимает место в потоке.
- Прилипает в пределах контейнера.
- Родительский `overflow` может изменить поведение.
- Удобен для боковых панелей и заголовков таблиц.
