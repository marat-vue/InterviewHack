# Что делает Extract

> [!summary] Коротко
> `Extract<T, U>` оставляет из union `T` только те варианты, которые совместимы с `U`.

## Вопрос

Что делает `Extract`?

## Базовый пример

```typescript
type Status = "idle" | "loading" | "success" | "error";

type VisibleStatus = Extract<Status, "loading" | "error">;
// "loading" | "error"
```

`Extract` работает как фильтр: оставляет пересечение union-типов.

## С примитивами

```typescript
type Value = string | number | boolean;

type TextLike = Extract<Value, string>;
// string
```

## С объектными union

```typescript
type Event =
  | { type: "click"; x: number; y: number }
  | { type: "submit"; formId: string }
  | { type: "reset" };

type SubmitEvent = Extract<Event, { type: "submit" }>;
```

Так можно достать конкретный вариант discriminated union.

## Как устроен

```typescript
type MyExtract<T, U> = T extends U ? T : never;
```

## Мини-шпаргалка

- `Extract<T, U>` оставляет совпадающие варианты.
- Удобен для фильтрации union.
- Хорошо работает с discriminated union.
- Обратная операция - `Exclude`.
