# Как использовать useStorage, useLocalStorage и useSessionStorage?

> [!summary]
> `useStorage` создает reactive ref, синхронизированный с Web Storage. `useLocalStorage` и `useSessionStorage` - удобные wrappers для конкретных storage.

## useLocalStorage

```typescript
import { useLocalStorage } from "@vueuse/core";

const theme = useLocalStorage<"light" | "dark">("theme", "light");

theme.value = "dark";
```

Теперь значение сохранится в `localStorage` и переживет reload.

## useSessionStorage

```typescript
const draft = useSessionStorage("article-draft", {
  title: "",
  content: "",
});
```

`sessionStorage` обычно живет в рамках tab/session.

## useStorage с custom storage

```typescript
const settings = useStorage(
  "settings",
  { language: "ru" },
  localStorage,
);
```

Третий аргумент задает storage.

## Когда использовать вместо Pinia Persisted State?

`useLocalStorage` хорош для локального composable/component state:

- theme;
- sidebar open;
- draft;
- last selected tab.

Pinia persisted state лучше, если данные уже являются частью store и нужны многим компонентам.

## Риски

Все, что доступно в `localStorage`, доступно JavaScript. При XSS это может быть украдено. Не храни там секреты без осознанной модели безопасности.

## Мини-шпаргалка

- `useLocalStorage` возвращает reactive ref.
- Изменение ref пишет значение в `localStorage`.
- `useSessionStorage` живет короче.
- `useStorage` позволяет выбрать storage.
- Не храни secrets в Web Storage без threat model.
