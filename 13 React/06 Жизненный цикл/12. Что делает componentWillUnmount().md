# Что делает componentWillUnmount?

> [!summary]
> `componentWillUnmount` - lifecycle method классового компонента, который вызывается перед удалением компонента из DOM. Его используют для очистки подписок, таймеров, соединений и других внешних ресурсов.

## Базовый пример

```jsx
class Clock extends Component {
  componentDidMount() {
    this.timerId = setInterval(() => {
      this.setState({ time: new Date() })
    }, 1000)
  }

  componentWillUnmount() {
    clearInterval(this.timerId)
  }

  render() {
    return <span>{this.state.time.toLocaleTimeString()}</span>
  }
}
```

Если не очистить interval, он продолжит работать после удаления компонента.

## Что очищают?

- timers;
- event listeners;
- subscriptions;
- WebSocket;
- observers;
- pending async operations;
- imperative widgets.

## Аналог в функциональном компоненте

```jsx
function Clock() {
  useEffect(() => {
    const timerId = setInterval(() => {
      console.log('tick')
    }, 1000)

    return () => clearInterval(timerId)
  }, [])

  return <span>Clock</span>
}
```

Cleanup function выполняет роль очистки.

## Важный нюанс

Cleanup в `useEffect` выполняется не только при unmount, но и перед повторным запуском effect при изменении dependencies.

Поэтому cleanup - это не только `componentWillUnmount`, а более общий механизм.

## Мини-шпаргалка

- `componentWillUnmount` вызывается перед удалением компонента.
- Используется для cleanup внешних ресурсов.
- В функциях аналог - cleanup в `useEffect`.
- Cleanup effect шире, чем только unmount.
- Если подписался, отпишись.
