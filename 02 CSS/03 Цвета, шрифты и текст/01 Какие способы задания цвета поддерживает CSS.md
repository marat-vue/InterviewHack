# Какие способы задания цвета поддерживает CSS?

> [!NOTE]
> CSS поддерживает разные способы задания цвета: ключевые слова, HEX, RGB, HSL, современные цветовые функции, прозрачность и специальные значения вроде `currentColor`.

## Основные форматы

```css
.box {
  color: red;
  border-color: #2563eb;
  background: rgb(37 99 235);
  outline-color: hsl(221 83% 53%);
}
```

## HEX

```css
.button {
  background-color: #2563eb;
}
```

HEX часто используют в дизайн-системах и макетах.

## RGB и прозрачность

```css
.overlay {
  background: rgb(0 0 0 / 0.5);
}
```

Современный синтаксис позволяет указать alpha-канал через `/`.

## HSL

```css
.badge {
  background: hsl(142 76% 36%);
}
```

HSL удобен, когда нужно мыслить оттенком, насыщенностью и светлотой.

## currentColor

```css
.icon {
  color: #2563eb;
  border: 1px solid currentColor;
}
```

`currentColor` берет текущее значение свойства `color`.

## CSS-переменные

```css
:root {
  --color-primary: #2563eb;
}

.link {
  color: var(--color-primary);
}
```

Так цвета становятся частью дизайн-токенов.

## Мини-шпаргалка

- Цвет можно задать словом: `red`, `transparent`.
- HEX выглядит как `#2563eb`.
- RGB удобен для числовых каналов и прозрачности.
- HSL удобен для работы с оттенками.
- `currentColor` наследует текущий цвет текста.
- В дизайн-системах цвета часто хранят в CSS-переменных.
