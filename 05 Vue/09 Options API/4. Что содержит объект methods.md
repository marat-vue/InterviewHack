# Что содержит объект methods

> [!summary] Коротко
> `methods` в Options API содержит функции компонента: обработчики событий, действия пользователя, отправку форм и вспомогательную логику, которая не должна кэшироваться.

## Вопрос

Что содержит объект `methods`?

## Базовый пример

```vue
<script>
export default {
  data() {
    return { count: 0 };
  },
  methods: {
    increment() {
      this.count++;
    },
    reset() {
      this.count = 0;
    },
  },
};
</script>

<template>
  <button @click="increment">{{ count }}</button>
  <button @click="reset">Сбросить</button>
</template>
```

Методы доступны в шаблоне и внутри других опций через `this`.

## Когда использовать methods

Методы подходят для действий: обработать клик, отправить форму, вызвать API, изменить состояние, выполнить расчет с аргументами.

```javascript
methods: {
  selectUser(id) {
    this.selectedUserId = id;
  }
}
```

## Чем отличается от computed

Метод выполняется каждый раз при вызове. `computed` кэшируется и лучше подходит для производных значений без аргументов.

## Мини-шпаргалка

- `methods` хранит функции компонента.
- Внутри методов доступен `this`.
- Методы удобно вызывать из template через `@click`.
- Для кэшируемых производных данных используй `computed`.
