# Что такое Better Auth и зачем он нужен в Nitro?

> [!NOTE]
> Better Auth - framework-agnostic auth library для TypeScript-приложений. В Nitro ее используют как готовый auth server: email/password, social login, sessions, cookies, database schema, plugins и server/client API.

## Что решает Better Auth?

Better Auth берет на себя типовые auth-задачи:

- registration;
- sign in;
- sign out;
- session management;
- cookies;
- email/password auth;
- social providers;
- password reset/email verification;
- database tables;
- plugins;
- server API;
- client API.

## Где он находится в Nitro-архитектуре?

```txt
Browser
  -> /api/auth/*
    -> Nitro catch-all route
      -> auth.handler(...)
        -> Better Auth
          -> Prisma adapter
            -> database
```

Обычные protected routes потом обращаются к Better Auth session:

```txt
GET /api/me
  -> requireAuth(event)
    -> auth.api.getSession({ headers })
      -> Better Auth session
```

## Почему не написать auth вручную?

Ручной auth означает, что тебе нужно самому продумать:

- hashing passwords;
- session storage;
- cookies;
- CSRF;
- OAuth callback flows;
- email verification;
- password reset;
- token rotation;
- multi-session behavior;
- database schema;
- revoke sessions;
- plugins/roles.

Better Auth дает готовый framework, который можно настроить, расширить и подключить к Nitro.

## Как выглядит Nitro-интеграция?

```ts
// server/utils/auth.ts
import { betterAuth } from 'better-auth';
import { prismaAdapter } from 'better-auth/adapters/prisma';
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

export const auth = betterAuth({
  database: prismaAdapter(prisma, {
    provider: 'postgresql',
  }),
  emailAndPassword: {
    enabled: true,
  },
});
```

```ts
// server/routes/api/auth/[...all].ts
import { toWebRequest } from 'h3';
import { auth } from '../../../utils/auth';

export default defineEventHandler((event) => {
  return auth.handler(toWebRequest(event));
});
```

Этот catch-all route обслуживает `/api/auth/*`.

## Когда Better Auth подходит?

Подходит, если:

- нужен session-based auth;
- нужен email/password;
- нужны social providers;
- хочется Prisma adapter;
- нужны plugins: admin, organization, 2FA, username, magic link;
- хочется не писать auth endpoints вручную;
- проект на TypeScript.

## Что Better Auth не решает полностью?

Better Auth не заменяет:

- business authorization;
- domain permissions;
- security review;
- rate limiting;
- audit logs;
- threat modeling;
- правильный CORS/cookie setup;
- database migration discipline.

Authentication отвечает на вопрос "кто пользователь?", а authorization - "что ему можно?".

## Мини-шпаргалка

- Better Auth - готовая auth-система для TypeScript.
- В Nitro монтируется через catch-all `/api/auth/[...all].ts`.
- Для БД удобно использовать Prisma adapter.
- Client вызывает `authClient.signIn.email`, `signUp.email`, `useSession`.
- Server routes вызывают `auth.api.getSession`.
- Роли и права нужно проектировать отдельно или через plugins.
