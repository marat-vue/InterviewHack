# Что такое Lazy loading компонентов?

> [!summary]
> Lazy loading компонентов - это отложенная загрузка JavaScript-кода. Компонент попадает в отдельный chunk и загружается только тогда, когда React впервые пытается его отрендерить.

## Зачем это нужно?

Без lazy loading стартовый bundle может стать слишком большим:

```jsx
import AdminPanel from './AdminPanel'
import MarkdownEditor from './MarkdownEditor'
import ChartPage from './ChartPage'
```

Даже если пользователь никогда не откроет админку или редактор, их код может попасть в начальную загрузку.

Lazy loading помогает:

- уменьшить initial bundle;
- ускорить первую загрузку;
- загружать редкие сценарии по требованию;
- разделять приложение по страницам и крупным фичам.

## Как подключить в React?

```jsx
import { lazy, Suspense } from 'react'

const AdminPanel = lazy(() => import('./AdminPanel'))

export function App() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <AdminPanel />
    </Suspense>
  )
}
```

`lazy` принимает функцию, которая возвращает dynamic `import()`. Модуль должен экспортировать компонент как `default`.

```jsx
// AdminPanel.jsx
export default function AdminPanel() {
  return <section>Admin</section>
}
```

## Где чаще всего применять?

По страницам:

```jsx
const HomePage = lazy(() => import('./pages/HomePage'))
const SettingsPage = lazy(() => import('./pages/SettingsPage'))
```

Для тяжелых UI-частей:

```jsx
const RichTextEditor = lazy(() => import('./RichTextEditor'))
const MapWidget = lazy(() => import('./MapWidget'))
const AnalyticsChart = lazy(() => import('./AnalyticsChart'))
```

Для редко открываемых модалок:

```jsx
const ExportModal = lazy(() => import('./ExportModal'))
```

## В чем разница между lazy loading и conditional rendering?

Conditional rendering решает, показывать компонент или нет.

```jsx
{isOpen && <Modal />}
```

Lazy loading решает, когда загружать код компонента.

```jsx
const Modal = lazy(() => import('./Modal'))
```

Часто их используют вместе.

## Что важно помнить?

- `lazy` без `Suspense` приведет к проблеме: React не знает, что показывать во время загрузки.
- `fallback` должен быть легким: skeleton, spinner, короткий placeholder.
- Не стоит лениво загружать все подряд, иначе появится много микрозадержек.
- В SSR лучше использовать возможности фреймворка, например Next.js или Remix, потому что серверный рендер и code splitting требуют интеграции со сборкой.

## Мини-шпаргалка

- Lazy loading уменьшает стартовый bundle.
- `React.lazy(() => import(...))` загружает компонент по требованию.
- Нужен `<Suspense fallback={...}>`.
- Лучше всего подходит для страниц, модалок и тяжелых виджетов.
- Компонент должен быть default export.
