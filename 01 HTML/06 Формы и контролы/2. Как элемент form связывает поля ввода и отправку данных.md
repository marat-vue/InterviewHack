# Как элемент form связывает поля ввода и отправку данных

> [!summary]
> Элемент `<form>` объединяет поля ввода, задает адрес и способ отправки, а при submit браузер собирает значения полей по их `name` и отправляет данные.

## Главное

```html
<form action="/search" method="get">
  <label for="query">Поиск</label>
  <input id="query" name="q" type="search">

  <button type="submit">Найти</button>
</form>
```

При отправке браузер возьмет значение поля `name="q"` и отправит его на `/search`.

## Роль name

`name` - ключ, под которым значение поля попадет в данные формы.

```html
<input name="email" type="email">
```

Если у поля нет `name`, при стандартной отправке формы его значение обычно не попадет в запрос.

## Method GET

```html
<form action="/search" method="get">
```

`GET` добавляет данные в URL.

```text
/search?q=html
```

Подходит для поиска, фильтров и страниц, которыми можно делиться ссылкой.

## Method POST

```html
<form action="/login" method="post">
```

`POST` отправляет данные в теле запроса. Подходит для логина, регистрации, комментариев, заказов и операций, которые меняют состояние.

## Submit-событие

```js
const form = document.querySelector("form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const data = new FormData(form);

  console.log(data.get("email"));
});
```

`FormData` позволяет получить значения полей формы в JavaScript.

## Поля вне form

Поле можно связать с формой через атрибут `form`.

```html
<form id="profile-form"></form>

<input form="profile-form" name="firstName">
```

Это редкий, но полезный сценарий для сложных layout.

## Мини-шпаргалка

- `<form>` группирует поля и управляет отправкой.
- `action` - куда отправлять.
- `method` - как отправлять.
- `name` нужен для ключа данных.
- Submit можно обработать через JavaScript.
- `FormData` помогает читать значения формы.
