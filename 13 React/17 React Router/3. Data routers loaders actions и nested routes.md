# Data routers loaders actions и nested routes

> [!summary]
> Data Router API позволяет связывать route не только с компонентом, но и с загрузкой данных, mutation actions, error boundaries и pending navigation state. Это приближает routing к реальным workflow приложения.

## Nested routes

```tsx
const router = createBrowserRouter([
  {
    path: '/dashboard',
    element: <DashboardLayout />,
    children: [
      { index: true, element: <DashboardHome /> },
      { path: 'settings', element: <SettingsPage /> },
      { path: 'users/:userId', element: <UserPage /> },
    ],
  },
])
```

Layout:

```tsx
function DashboardLayout() {
  return (
    <>
      <Sidebar />
      <Outlet />
    </>
  )
}
```

## loader

Loader загружает данные для route:

```tsx
const router = createBrowserRouter([
  {
    path: '/users/:userId',
    loader: async ({ params }) => {
      return fetchUser(params.userId!)
    },
    element: <UserPage />,
  },
])
```

Компонент:

```tsx
import { useLoaderData } from 'react-router'

function UserPage() {
  const user = useLoaderData() as User

  return <h1>{user.name}</h1>
}
```

## action

Action обрабатывает mutation, например submit формы:

```tsx
{
  path: '/users/new',
  action: async ({ request }) => {
    const formData = await request.formData()
    const user = await createUser(formData)

    return redirect(`/users/${user.id}`)
  },
  element: <CreateUserPage />,
}
```

Форма:

```tsx
import { Form } from 'react-router'

function CreateUserPage() {
  return (
    <Form method="post">
      <input name="name" />
      <button>Create</button>
    </Form>
  )
}
```

## useNavigation

```tsx
function GlobalPendingIndicator() {
  const navigation = useNavigation()

  if (navigation.state === 'idle') {
    return null
  }

  return <p>Loading...</p>
}
```

`useNavigation` помогает показать pending UI при переходе или submit.

## errorElement

```tsx
{
  path: '/users/:userId',
  loader: userLoader,
  element: <UserPage />,
  errorElement: <RouteErrorPage />,
}
```

Route-level error boundary делает ошибки загрузки управляемыми.

## Что отвечать на собеседовании?

Data routers позволяют описывать данные и мутации на уровне маршрута. `loader` загружает данные до route render, `action` обрабатывает submit/mutation, `useLoaderData` читает данные, `Form` интегрируется с action, `useNavigation` показывает pending state, а `errorElement` ловит ошибки route.

## Мини-шпаргалка

- `children` задает nested routes.
- `Outlet` показывает дочерний route.
- `loader` читает данные.
- `action` меняет данные.
- `Form` отправляет данные в action.
- `useNavigation` показывает pending transition.
