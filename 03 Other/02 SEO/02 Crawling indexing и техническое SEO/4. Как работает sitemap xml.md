# Как работает sitemap.xml?

> [!summary]
> Sitemap.xml - это карта важных URL сайта для поисковых систем. Она не гарантирует индексацию, но помогает быстрее находить страницы, понимать структуру сайта и отслеживать проблемы.

## Что кладут в sitemap?

В sitemap обычно добавляют канонические, индексируемые страницы:

- главную;
- категории;
- карточки товаров;
- статьи;
- посадочные страницы;
- важные страницы документации.

Не стоит добавлять:

- URL с `noindex`;
- страницы с ошибками;
- дубликаты;
- служебные страницы;
- URL, закрытые в robots.txt;
- страницы, которые редиректят.

## Пример sitemap

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2026-07-20</lastmod>
  </url>
  <url>
    <loc>https://example.com/blog/vue-seo</loc>
    <lastmod>2026-07-25</lastmod>
  </url>
</urlset>
```

## Что такое sitemap index?

Для больших сайтов используют индекс sitemap:

```xml
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap>
    <loc>https://example.com/sitemap-products.xml</loc>
  </sitemap>
  <sitemap>
    <loc>https://example.com/sitemap-blog.xml</loc>
  </sitemap>
</sitemapindex>
```

Так проще разделять товары, категории, статьи и языковые версии.

## Как сообщить поисковику про sitemap?

Через robots.txt:

```txt
Sitemap: https://example.com/sitemap.xml
```

И через Search Console.

## Частые ошибки

- В sitemap попали `404`.
- В sitemap попали редиректы.
- В sitemap попали страницы с `noindex`.
- Указаны не canonical URL.
- Даты `lastmod` меняются автоматически каждый день без реальных изменений.
- В sitemap нет новых важных страниц.

## Мини-шпаргалка

- Sitemap помогает обнаруживать важные URL.
- Sitemap не гарантирует индексацию.
- В sitemap должны быть чистые canonical URL со статусом `200`.
- Для больших сайтов лучше делить sitemap по типам страниц.
- Search Console помогает проверить, как sitemap обработан.
