# Что делает flex-basis

> [!summary]
> `flex-basis` задает базовый размер flex item по main axis до распределения свободного места через `flex-grow` и `flex-shrink`.

## Главное

```css
.card {
  flex-basis: 240px;
}
```

Если `flex-direction: row`, базовый размер относится к ширине. Если `column` - к высоте.

## Flex-basis и width

```css
.item {
  width: 300px;
  flex-basis: 200px;
}
```

В flex layout `flex-basis` обычно имеет приоритет над `width` для main axis.

## Сокращение flex

```css
.card {
  flex: 1 1 240px;
}
```

Это означает:

```text
flex-grow: 1
flex-shrink: 1
flex-basis: 240px
```

## auto

```css
.item {
  flex-basis: auto;
}
```

`auto` берет за основу размер из `width`/`height` или размер содержимого.

## Практический пример

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 260px;
}
```

Карточки стартуют от `260px`, могут расти и сжиматься, а при нехватке места переносятся.

## Мини-шпаргалка

- `flex-basis` задает базовый размер item.
- Размер считается по main axis.
- Работает до grow/shrink.
- В сокращении `flex` это третье значение.
- `flex: 1 1 240px` - частый паттерн адаптивных карточек.
