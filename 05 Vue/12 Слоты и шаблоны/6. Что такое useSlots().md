# Что такое useSlots()

> [!summary]
> **useSlots()** - это функция Composition API, которая возвращает объект со слотами, переданными в компонент. Она полезна, когда нужно проверить наличие слота или использовать слот в JavaScript-логике.

## Главное

В обычном шаблоне чаще всего достаточно `<slot />`. `useSlots()` нужен внутри `<script setup>` или `setup()`, когда слот влияет на вычисления, классы, условия рендера или render-функцию.

```vue
<script setup>
import { computed, useSlots } from "vue";

const slots = useSlots();

const hasFooter = computed(() => Boolean(slots.footer));
</script>

<template>
  <section class="panel" :class="{ 'panel--with-footer': hasFooter }">
    <div class="panel__body">
      <slot />
    </div>

    <footer v-if="hasFooter" class="panel__footer">
      <slot name="footer" />
    </footer>
  </section>
</template>
```

Если родитель передал `#footer`, компонент добавит футер и специальный класс.

## Как выглядит объект slots

Слоты в Vue представлены как функции. Когда Vue вызывает такую функцию, она возвращает VNode-дерево.

```js
const slots = useSlots();

console.log(slots.default); // функция default-слота или undefined
console.log(slots.header);  // функция слота header или undefined
```

Поэтому слот обычно проверяют на существование:

```js
const hasHeader = Boolean(slots.header);
```

А если нужно получить содержимое программно, слот вызывают как функцию:

```js
const headerNodes = slots.header?.();
```

## Пример: условная разметка

```vue
<!-- AppToolbar.vue -->
<script setup>
import { useSlots } from "vue";

const slots = useSlots();
</script>

<template>
  <div class="toolbar">
    <div v-if="slots.left" class="toolbar__left">
      <slot name="left" />
    </div>

    <div class="toolbar__center">
      <slot />
    </div>

    <div v-if="slots.right" class="toolbar__right">
      <slot name="right" />
    </div>
  </div>
</template>
```

```vue
<AppToolbar>
  <template #left>
    <button>Назад</button>
  </template>

  Настройки

  <template #right>
    <button>Сохранить</button>
  </template>
</AppToolbar>
```

Компонент не рисует пустые зоны, если соответствующие слоты не переданы.

## Важные нюансы

- `useSlots()` можно вызывать только внутри `setup()` или `<script setup>`.
- Для простого вывода контента лучше использовать `<slot>` в шаблоне.
- Объект `slots` не предназначен для хранения состояния.
- Проверка `Boolean(slots.name)` говорит, передан ли слот, но не гарантирует, что внутри есть видимый контент.

## Мини-шпаргалка

- `useSlots()` дает доступ к слотам в JavaScript.
- Слоты внутри объекта являются функциями.
- Частый сценарий: проверить `slots.footer` и условно показать разметку.
- В шаблоне для вывода слота используют `<slot name="..." />`.
- Не стоит усложнять компонент `useSlots()`, если хватает обычного шаблона.
