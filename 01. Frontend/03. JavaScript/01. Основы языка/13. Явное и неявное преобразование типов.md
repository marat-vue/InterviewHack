# Явное и неявное преобразование типов

> [!NOTE]
> Явное преобразование делает разработчик через `Number()`, `String()`, `Boolean()` и похожие приемы. Неявное преобразование JavaScript делает сам во время операций.

## Вопрос

В чем разница между неявным и явным преобразованием типов?

## Явное преобразование

Явное преобразование видно прямо в коде.

```javascript
const age = Number("25");
const id = String(100);
const hasName = Boolean("Anna");
```

Такой код легче читать: понятно, что разработчик специально меняет тип.

## Частые способы явного преобразования

```javascript
Number("42");   // 42
String(42);     // "42"
Boolean(1);     // true
parseInt("10px", 10); // 10
parseFloat("3.14px"); // 3.14
```

Есть короткие формы:

```javascript
+"42";     // 42
"" + 42;   // "42"
!!"text";  // true
```

Они короче, но не всегда понятнее для чтения.

## Неявное преобразование

Неявное преобразование происходит автоматически.

```javascript
"5" * 2;   // 10
"5" + 2;   // "52"
1 == "1";  // true
if ("hi") {
  console.log("truthy");
}
```

JavaScript пытается выполнить операцию, поэтому сам приводит значения к подходящему типу.

## Наглядное сравнение

```javascript
const input = "10";

const explicit = Number(input) + 5;
const implicit = input - 0 + 5;

console.log(explicit); // 15
console.log(implicit); // 15
```

Оба варианта работают, но первый понятнее: `Number(input)` прямо показывает намерение.

## Где неявность опасна

```javascript
const price = "100";
const discount = 20;

price + discount; // "10020"
```

Исправление:

```javascript
Number(price) + discount; // 120
```

## Сравнение

| Вид | Кто делает | Пример | Читаемость |
| --- | --- | --- | --- |
| Явное | разработчик | `Number(value)` | выше |
| Неявное | JavaScript | `value * 1` | ниже |

## Практическое правило

- Для бизнес-логики используйте явные преобразования.
- Для проверок существования можно использовать truthy/falsy, если это не скрывает важные значения вроде `0`.
- Для сравнения почти всегда используйте `===`.

```javascript
if (Number(input) === 0) {
  console.log("Пользователь ввел ноль");
}
```

## Мини-шпаргалка

| Задача | Явный вариант | Неявный вариант |
| --- | --- | --- |
| К числу | `Number(value)` | `+value`, `value * 1` |
| К строке | `String(value)` | `value + ""` |
| К boolean | `Boolean(value)` | `!!value` |
| Сравнить без сюрпризов | `a === b` | не использовать `==` |
