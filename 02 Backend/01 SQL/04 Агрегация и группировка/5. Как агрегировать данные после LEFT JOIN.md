# Как агрегировать данные после LEFT JOIN?

> [!summary]
> При агрегации после `LEFT JOIN` важно считать столбец правой таблицы, а не `COUNT(*)`, иначе строки без совпадений тоже дадут счетчик `1`.

## Проблема

Нужно посчитать количество заказов у каждого пользователя.

```sql
SELECT
  u.id,
  COUNT(*) AS orders_count
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id;
```

Для пользователя без заказов `COUNT(*)` вернет `1`, потому что строка пользователя все равно есть.

## Правильно

```sql
SELECT
  u.id,
  COUNT(o.id) AS orders_count
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id;
```

`COUNT(o.id)` считает только реальные совпавшие заказы, потому что у отсутствующего заказа `o.id` будет `NULL`.

## Сумма

```sql
SELECT
  u.id,
  COALESCE(SUM(o.total), 0) AS total_spent
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
GROUP BY u.id;
```

`COALESCE` превращает `NULL` в `0`.

## Мини-шпаргалка

- После `LEFT JOIN` строка слева остается даже без совпадения.
- `COUNT(*)` считает эту строку.
- Для количества справа используй `COUNT(right.id)`.
- Для суммы часто нужен `COALESCE(SUM(...), 0)`.
- Это частый вопрос на собеседовании.
