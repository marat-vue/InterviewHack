# Что такое Event Loop в Node.js

> [!summary]
> **Event Loop** - это механизм Node.js, который позволяет выполнять неблокирующий I/O и обрабатывать множество асинхронных операций в одном основном JavaScript-потоке.

## Главное

Node.js выполняет JS-код в одном основном потоке, но операции ввода-вывода могут выполняться асинхронно через ОС или thread pool.

```js
import { readFile } from "node:fs/promises";

const text = await readFile("file.txt", "utf8");
console.log(text);
```

Пока файл читается, event loop может обрабатывать другие задачи.

## Упрощенная схема

```text
call stack
  -> async operation starts
  -> callback/promise waits
  -> event loop picks ready tasks
  -> JS callback executes
```

## Зачем это нужно

Сервер не должен простаивать, пока база данных, файл или сеть отвечают.

```text
request A waits for DB
request B can still be processed
request C can still be processed
```

## Что блокирует event loop

Долгий синхронный JavaScript блокирует обработку других событий.

```js
const startedAt = Date.now();

while (Date.now() - startedAt < 5000) {
  // 5 секунд блокировки
}
```

В это время сервер не сможет нормально отвечать на другие запросы.

## Мини-шпаргалка

- Event loop обрабатывает асинхронные события.
- JS-код выполняется в основном потоке.
- I/O не обязан блокировать поток.
- CPU-heavy код блокирует event loop.
- Для тяжелых вычислений используют worker threads или отдельные процессы.
