# Типизация методов класса

> [!NOTE] Коротко
> Метод класса типизируется как обычная функция: у параметров есть типы, после скобок можно указать тип возвращаемого значения.

## Вопрос

Как типизировать методы класса?

## Базовый пример

```typescript
class Calculator {
  add(a: number, b: number): number {
    return a + b;
  }
}
```

`a` и `b` должны быть числами, а метод обязан вернуть число.

## Метод без результата

```typescript
class Logger {
  log(message: string): void {
    console.log(message);
  }
}
```

## Асинхронный метод

```typescript
class UserService {
  async findById(id: number): Promise<User> {
    const response = await fetch(`/users/${id}`);
    return response.json();
  }
}
```

## Generic-метод

```typescript
class Storage {
  get<T>(key: string): T | null {
    const raw = localStorage.getItem(key);
    return raw ? JSON.parse(raw) as T : null;
  }
}
```

## Метод как свойство

Иногда метод объявляют стрелкой, чтобы сохранить `this`.

```typescript
class Counter {
  count = 0;

  increment = (): void => {
    this.count += 1;
  };
}
```

## Мини-шпаргалка

- `method(arg: T): R` - обычная типизация метода.
- `void` - метод ничего значимого не возвращает.
- `Promise<T>` - async-метод.
- Generic-метод может иметь свой `<T>`.
