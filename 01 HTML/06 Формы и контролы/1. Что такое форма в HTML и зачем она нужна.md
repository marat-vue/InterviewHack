# Что такое форма в HTML и зачем она нужна

> [!summary]
> **HTML-форма** - это часть страницы, которая собирает пользовательский ввод и отправляет его на сервер или передает JavaScript-логике.

## Главное

Формы используют для логина, регистрации, поиска, фильтров, оплаты, комментариев, обратной связи и загрузки файлов.

```html
<form action="/login" method="post">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>

  <label for="password">Пароль</label>
  <input id="password" name="password" type="password" required>

  <button type="submit">Войти</button>
</form>
```

## Что входит в форму

- `<form>` - контейнер формы.
- `<label>` - подпись поля.
- `<input>` - поле ввода.
- `<textarea>` - многострочный ввод.
- `<select>` - выбор из списка.
- `<button>` - действие отправки или сброса.

## action и method

```html
<form action="/subscribe" method="post">
  ...
</form>
```

`action` указывает адрес отправки данных, а `method` - HTTP-метод. Чаще встречаются `get` и `post`.

## Форма без JavaScript

HTML-форма может работать сама по себе: браузер соберет значения полей и отправит запрос.

Это важно для прогрессивного улучшения: JavaScript может сделать форму удобнее, но базовый HTML уже задает правильную структуру.

## Форма с JavaScript

```js
const form = document.querySelector("form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log("Отправляем через fetch");
});
```

JS часто перехватывает `submit`, чтобы валидировать данные или отправить их через API без перезагрузки страницы.

## Мини-шпаргалка

- Форма собирает пользовательский ввод.
- `<form>` связывает поля и отправку.
- У полей должен быть `name`, если данные отправляются стандартно.
- `label` улучшает доступность и удобство.
- `button type="submit"` отправляет форму.
- JavaScript может перехватить событие `submit`.
