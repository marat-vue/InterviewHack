# Какие базовые компоненты Vuetify нужно знать?

> [!summary]
> Для уверенной работы с Vuetify нужно знать layout-компоненты, buttons, cards, forms, dialogs, menus, navigation, data tables и feedback components. Главное - понимать их props, events и slots.

## Layout

```vue
<v-app>
  <v-app-bar title="Dashboard" />

  <v-navigation-drawer />

  <v-main>
    <v-container>
      <RouterView />
    </v-container>
  </v-main>
</v-app>
```

Частые layout components:

- `v-app`;
- `v-main`;
- `v-container`;
- `v-row`;
- `v-col`;
- `v-app-bar`;
- `v-navigation-drawer`.

## Buttons и cards

```vue
<v-card>
  <v-card-title>Пользователь</v-card-title>
  <v-card-text>{{ user.email }}</v-card-text>
  <v-card-actions>
    <v-btn color="primary" @click="save">Сохранить</v-btn>
  </v-card-actions>
</v-card>
```

## Forms

```vue
<v-form @submit.prevent="submit">
  <v-text-field
    v-model="email"
    label="Email"
    type="email"
  />

  <v-btn type="submit" color="primary">
    Войти
  </v-btn>
</v-form>
```

Частые form components:

- `v-text-field`;
- `v-textarea`;
- `v-select`;
- `v-checkbox`;
- `v-radio-group`;
- `v-switch`;
- `v-form`.

## Dialogs и menus

```vue
<v-dialog v-model="isOpen" max-width="480">
  <v-card title="Удалить запись?">
    <v-card-actions>
      <v-btn @click="isOpen = false">Отмена</v-btn>
      <v-btn color="error" @click="remove">Удалить</v-btn>
    </v-card-actions>
  </v-card>
</v-dialog>
```

## Feedback

Для состояния интерфейса часто нужны:

- `v-alert`;
- `v-snackbar`;
- `v-progress-circular`;
- `v-skeleton-loader`;
- `v-chip`;
- `v-tooltip`.

## Мини-шпаргалка

- `v-app/v-main` задают основу Vuetify layout.
- `v-container/v-row/v-col` помогают с сеткой.
- `v-card` часто используется для сущностей.
- `v-form` и inputs покрывают формы.
- `v-dialog`, `v-menu`, `v-snackbar` закрывают overlay/feedback сценарии.
- У Vuetify components важно читать props, events и slots.
