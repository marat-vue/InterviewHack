# Что такое content-box

> [!summary]
> `content-box` - это значение `box-sizing`, при котором `width` и `height` задают размер только content area. Padding и border добавляются сверху к итоговому размеру элемента.

## Главное

```css
.box {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 2px solid black;
}
```

Итоговая ширина будет:

```text
300px content
+ 20px left padding
+ 20px right padding
+ 2px left border
+ 2px right border
= 344px
```

## Почему это может удивлять

Если дизайнер ожидает блок шириной `300px`, а CSS добавляет padding и border сверху, элемент становится шире.

```css
.column {
  width: 50%;
  padding: 24px;
}
```

Две такие колонки могут не поместиться в одну строку.

## Когда встречается

`content-box` - историческое значение по умолчанию для большинства элементов.

```css
.box {
  box-sizing: content-box;
}
```

В современных проектах часто глобально переключают элементы на `border-box`.

## Мини-шпаргалка

- `content-box` считает `width` только для content.
- Padding и border увеличивают итоговый размер.
- Это значение по умолчанию для многих элементов.
- Может неожиданно ломать сетки.
- В UI чаще удобнее `border-box`.
