# Как настроить @nuxt/test-utils с Vitest?

> [!NOTE]
> Для Nuxt/Nitro tests ставят `@nuxt/test-utils`, `vitest`, `@vue/test-utils` и DOM environment. Затем подключают `@nuxt/test-utils/module` и используют `defineVitestConfig`.

## Установка

```bash
npm i -D @nuxt/test-utils vitest @vue/test-utils happy-dom playwright-core
```

В зависимости от типа тестов могут понадобиться:

- `happy-dom` или `jsdom` для component tests;
- `playwright-core` для e2e/browser tests;
- `@testing-library/vue` для `renderSuspended`.

## Nuxt config

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: [
    '@nuxt/test-utils/module',
  ],
});
```

## Vitest config

```ts
// vitest.config.ts
import { defineVitestConfig } from '@nuxt/test-utils/config';

export default defineVitestConfig({
  test: {
    environment: 'nuxt',
  },
});
```

## Scripts

```json
{
  "scripts": {
    "test": "vitest",
    "test:run": "vitest run"
  }
}
```

## Runtime test example

```ts
import { describe, expect, it } from 'vitest';
import { mountSuspended } from '@nuxt/test-utils/runtime';
import App from '~/app.vue';

describe('app', () => {
  it('mounts', async () => {
    const wrapper = await mountSuspended(App);

    expect(wrapper.html()).toContain('InterviewHack');
  });
});
```

## E2E test example

```ts
import { describe, expect, it } from 'vitest';
import { setup, $fetch } from '@nuxt/test-utils/e2e';

describe('server api', async () => {
  await setup();

  it('returns health', async () => {
    await expect($fetch('/api/health')).resolves.toMatchObject({
      status: 'ok',
    });
  });
});
```

## Версии и peer dependencies

`@nuxt/test-utils` тесно связан с Nuxt, Vitest и DOM/test runner versions. Если появляются странные ошибки:

- проверь version compatibility;
- обнови Vitest/test-utils вместе;
- проверь наличие `@vue/test-utils`;
- проверь DOM environment;
- проверь, что подключен `@nuxt/test-utils/module`.

## Мини-шпаргалка

- Установи `@nuxt/test-utils`, `vitest`, `@vue/test-utils`.
- Для runtime component tests нужен DOM environment.
- Для e2e/browser tests нужен Playwright.
- В Nuxt config добавь `@nuxt/test-utils/module`.
- В Vitest config используй `defineVitestConfig`.
- Environment для Nuxt runtime: `nuxt`.
