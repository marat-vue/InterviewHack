# Как работать с массивом?

> [!NOTE]
> Массивы создают через литерал `[]`, читают и изменяют по индексу, добавляют и удаляют элементы методами, а для преобразований используют `map`, `filter`, `reduce` и другие методы.

## Вопрос

Как создать и работать с массивом?

## Создание

Лучший вариант по умолчанию:

```javascript
const numbers = [1, 2, 3];
const empty = [];
```

Можно хранить разные типы:

```javascript
const mixed = [1, "text", true, { id: 1 }];
```

## Доступ и изменение

```javascript
const items = ["a", "b", "c"];

items[0]; // "a"
items[1] = "B";

console.log(items); // ["a", "B", "c"]
```

## Добавление и удаление

```javascript
items.push("d");    // добавить в конец
items.pop();        // удалить с конца
items.unshift("x"); // добавить в начало
items.shift();      // удалить из начала
```

## Перебор

```javascript
for (const item of items) {
  console.log(item);
}
```

Или:

```javascript
items.forEach((item) => console.log(item));
```

## Преобразование

```javascript
const doubled = [1, 2, 3].map((number) => number * 2);
const even = [1, 2, 3, 4].filter((number) => number % 2 === 0);
const sum = [1, 2, 3].reduce((total, number) => total + number, 0);
```

## `new Array()`

```javascript
const arr = new Array(3);

console.log(arr); // [empty × 3]
```

Из-за таких нюансов чаще используют литерал `[]`.

## Мини-шпаргалка

| Задача | Метод |
| --- | --- |
| создать | `[]` |
| прочитать | `arr[index]` |
| добавить в конец | `push` |
| удалить с конца | `pop` |
| преобразовать | `map` |
| отфильтровать | `filter` |
| найти | `find` |
| свернуть | `reduce` |
