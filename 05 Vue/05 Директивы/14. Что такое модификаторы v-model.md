# Что такое модификаторы v-model

> [!summary] Коротко
> Модификаторы `v-model` меняют момент или способ обновления значения: `.lazy`, `.trim`, `.number`.

## Вопрос

Что такое модификаторы `v-model`?

## .lazy

```vue
<input v-model.lazy="email" />
```

Обычно `v-model` обновляется на событии `input`. С `.lazy` значение обновится на `change`, часто после потери фокуса или подтверждения ввода.

## .trim

```vue
<input v-model.trim="name" />
```

`.trim` убирает пробелы в начале и конце строки.

## .number

```vue
<input v-model.number="age" />
```

`.number` пытается привести значение к числу. Это полезно, потому что input обычно возвращает строку.

## Комбинация модификаторов

```vue
<input v-model.lazy.trim="title" />
```

Модификаторы можно сочетать, если это имеет смысл.

## На компонентах

В пользовательском компоненте модификаторы можно принять и обработать явно.

```vue
<BaseInput v-model.trim="name" />
```

В Vue 3 компонент может получить информацию о модификаторах через модельный API.

## Мини-шпаргалка

- `.lazy` обновляет значение позже.
- `.trim` обрезает пробелы.
- `.number` приводит к числу, если возможно.
- Модификаторы уменьшают ручную обработку ввода.
