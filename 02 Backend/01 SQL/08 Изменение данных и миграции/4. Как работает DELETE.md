# Как работает DELETE?

> [!summary]
> `DELETE` удаляет строки из таблицы по условию. Как и с `UPDATE`, главное правило безопасности - внимательно проверять `WHERE`.

## Пример

```sql
DELETE FROM sessions
WHERE expires_at < now();
```

Удаляет просроченные сессии.

## DELETE без WHERE

```sql
DELETE FROM users;
```

Удалит все строки таблицы. Это почти всегда опасно.

## Soft delete

В приложениях часто вместо удаления ставят отметку.

```sql
UPDATE users
SET deleted_at = now()
WHERE id = 1;
```

Так данные остаются в базе, но приложение считает их удаленными.

## DELETE и foreign key

Если на строку ссылаются дочерние записи, база может запретить удаление или применить `ON DELETE CASCADE`, если это задано в схеме.

## Мини-шпаргалка

- `DELETE` удаляет строки.
- Всегда проверяй `WHERE`.
- Soft delete хранит `deleted_at`.
- FK может запретить удаление родителя.
- `ON DELETE CASCADE` удаляет зависимые строки.
