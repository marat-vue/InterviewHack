# Когда не использовать стрелочные функции

> [!NOTE]
> Стрелочные функции не подходят, когда нужен собственный `this`, `arguments`, `prototype` или вызов через `new`.

## Вопрос

Когда лучше не использовать стрелочные функции?

## Метод объекта с `this`

Плохо:

```javascript
const user = {
  name: "Anna",
  sayHi: () => `Hi, ${this.name}`,
};

user.sayHi(); // не "Hi, Anna"
```

Стрелочная функция берет `this` из внешней области, а не из объекта.

Хорошо:

```javascript
const user = {
  name: "Anna",
  sayHi() {
    return `Hi, ${this.name}`;
  },
};
```

## Конструктор

Стрелочные функции нельзя вызывать через `new`.

```javascript
const User = (name) => {
  this.name = name;
};

new User("Anna"); // TypeError
```

Используйте обычную функцию или класс:

```javascript
function User(name) {
  this.name = name;
}
```

## Когда нужен `arguments`

```javascript
const fn = () => {
  console.log(arguments); // своего arguments нет
};
```

Используйте rest:

```javascript
const fn = (...args) => {
  console.log(args);
};
```

или обычную функцию, если нужен именно `arguments`.

## Методы прототипа

```javascript
function User(name) {
  this.name = name;
}

User.prototype.sayHi = () => {
  return `Hi, ${this.name}`;
};
```

Такой метод не получит `this` экземпляра. Нужна обычная функция:

```javascript
User.prototype.sayHi = function () {
  return `Hi, ${this.name}`;
};
```

## Обработчики событий

Иногда в обработчике нужен `this` как элемент.

```javascript
button.addEventListener("click", function () {
  console.log(this); // button
});
```

Стрелочная функция возьмет внешний `this`.

```javascript
button.addEventListener("click", () => {
  console.log(this); // не button
});
```

Если элемент нужен, современнее использовать `event.currentTarget`.

## Мини-шпаргалка

| Ситуация | Лучше |
| --- | --- |
| метод объекта с `this` | обычный метод |
| конструктор | `function` или `class` |
| метод прототипа | обычная функция |
| нужен `arguments` | обычная функция или rest |
| callback без своего `this` | arrow function |
