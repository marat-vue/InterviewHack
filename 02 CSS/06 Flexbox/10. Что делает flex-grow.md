# Что делает flex-grow

> [!summary]
> `flex-grow` определяет, как flex item забирает свободное пространство внутри flex-контейнера по main axis.

## Главное

```css
.content {
  flex-grow: 1;
}
```

Если в контейнере есть свободное место, элемент с `flex-grow: 1` может расшириться и занять его.

## Значение по умолчанию

```css
.item {
  flex-grow: 0;
}
```

По умолчанию flex items не растут, даже если в контейнере есть свободное пространство.

## Пример

```css
.layout {
  display: flex;
}

.sidebar {
  width: 240px;
}

.main {
  flex-grow: 1;
}
```

`.main` займет все оставшееся место после sidebar.

## Пропорции

```css
.a {
  flex-grow: 1;
}

.b {
  flex-grow: 2;
}
```

Свободное пространство распределится в пропорции `1:2`.

## Мини-шпаргалка

- `flex-grow` управляет ростом item.
- Значение по умолчанию `0`.
- `1` разрешает занять свободное место.
- Несколько grow-значений работают как пропорции.
- Свободное место считается после базовых размеров items.
