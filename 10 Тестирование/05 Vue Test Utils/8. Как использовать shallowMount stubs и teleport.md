# Как использовать shallowMount, stubs и teleport?

> [!summary]
> `shallowMount` и `stubs` помогают заменить дочерние компоненты, если тесту важен только текущий компонент. Teleport требует отдельного DOM-target или stub, потому что он рендерит контент вне обычного дерева компонента.

## `mount` и `shallowMount`

`mount` рендерит компонент с дочерними компонентами:

```ts
mount(UserPage);
```

`shallowMount` заменяет дочерние компоненты stubs:

```ts
shallowMount(UserPage);
```

Это полезно, если дочерние компоненты сложные и не относятся к проверяемому поведению.

## Stubs

```ts
mount(UserPage, {
  global: {
    stubs: {
      UserAvatar: true,
      RouterLink: true,
    },
  },
});
```

Можно задать свой stub:

```ts
stubs: {
  BaseButton: {
    template: '<button><slot /></button>',
  },
}
```

## Когда не использовать shallow?

Не используй `shallowMount`, если поведение зависит от дочернего компонента:

- form field эмитит value;
- dropdown открывает options;
- child component отвечает за важный UX;
- slot content должен реально отрендериться.

## Teleport

Компонент:

```vue
<Teleport to="#modal-root">
  <div role="dialog">Modal</div>
</Teleport>
```

В тесте:

```ts
beforeEach(() => {
  const el = document.createElement('div');
  el.id = 'modal-root';
  document.body.appendChild(el);
});
```

Или stub:

```ts
global: {
  stubs: {
    teleport: true,
  },
}
```

## Мини-шпаргалка

- `mount` рендерит глубже.
- `shallowMount` заменяет детей stubs.
- `stubs` полезны для тяжелых компонентов и RouterLink.
- Teleport требует target в DOM или stub.
- Не заглушай то, что является частью проверяемого поведения.
