# Какие бывают связи между таблицами?

> [!NOTE]
> Основные связи в реляционной модели: one-to-one, one-to-many и many-to-many. Они определяют, где хранить внешний ключ и нужна ли промежуточная таблица.

## One-to-one

Одна строка связана максимум с одной строкой другой таблицы.

```sql
CREATE TABLE user_profiles (
  user_id bigint PRIMARY KEY REFERENCES users(id),
  bio text
);
```

## One-to-many

Один пользователь может иметь много заказов.

```sql
CREATE TABLE orders (
  id bigint PRIMARY KEY,
  user_id bigint NOT NULL REFERENCES users(id)
);
```

Внешний ключ хранится на стороне "many".

## Many-to-many

Пост может иметь много тегов, тег может быть у многих постов. Нужна таблица-связка.

```sql
CREATE TABLE post_tags (
  post_id bigint REFERENCES posts(id),
  tag_id bigint REFERENCES tags(id),
  PRIMARY KEY (post_id, tag_id)
);
```

## Мини-шпаргалка

- One-to-one: FK часто одновременно PK.
- One-to-many: FK на стороне many.
- Many-to-many: нужна join table.
- Таблица-связка часто имеет составной PK.
- Связи лучше защищать foreign key constraints.
