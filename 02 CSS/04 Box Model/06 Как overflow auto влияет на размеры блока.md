# Как overflow auto влияет на размеры блока?

> [!NOTE]
> `overflow: auto` не увеличивает заданный размер блока. Если контент не помещается, браузер добавляет прокрутку только там, где она нужна.

## Главное

```css
.panel {
  width: 320px;
  height: 160px;
  overflow: auto;
}
```

Если контент помещается, скроллбаров не будет. Если не помещается, появится вертикальная или горизонтальная прокрутка.

## Отличие от visible и hidden

```css
.box-visible {
  overflow: visible;
}

.box-hidden {
  overflow: hidden;
}

.box-auto {
  overflow: auto;
}
```

| Значение | Поведение |
| --- | --- |
| `visible` | Контент может выходить за границы |
| `hidden` | Лишний контент обрезается |
| `auto` | Скролл появляется при необходимости |
| `scroll` | Скроллбар может показываться всегда |

## Размеры и скроллбар

Сам блок сохраняет заданные `width` и `height`, но скроллбар может занять часть внутреннего пространства, особенно в системах с классическими скроллбарами.

## Нужно ограничение размера

`overflow: auto` заметен, когда у блока есть ограничение.

```css
.list {
  max-height: 300px;
  overflow: auto;
}
```

Без высоты или max-height контент может просто растянуть блок.

## Мини-шпаргалка

- `overflow: auto` добавляет скролл при необходимости.
- Не увеличивает заданный размер блока.
- Работает заметно при ограниченной высоте или ширине.
- Скроллбар может занять внутреннее место.
- Для обрезки без скролла используют `overflow: hidden`.
