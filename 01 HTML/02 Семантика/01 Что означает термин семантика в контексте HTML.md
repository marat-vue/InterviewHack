# Что означает термин семантика в контексте HTML?

> [!NOTE]
> **Семантика в HTML** - это использование элементов по их смыслу, а не только ради внешнего вида. Семантическая разметка объясняет структуру страницы браузеру, поисковым системам и assistive technologies.

## Главное

HTML-элемент должен отвечать на вопрос: "Что это за часть контента?"

```html
<!-- менее понятно -->
<div class="title">Новости</div>

<!-- семантически лучше -->
<h1>Новости</h1>
```

Оба варианта можно визуально сделать одинаковыми через CSS, но смысл у них разный.

## Примеры семантических элементов

| Элемент | Смысл |
| --- | --- |
| `<header>` | Вводная часть страницы или секции |
| `<nav>` | Навигация |
| `<main>` | Основное содержимое страницы |
| `<section>` | Тематический раздел |
| `<article>` | Самостоятельная единица контента |
| `<aside>` | Дополнительный контент |
| `<footer>` | Завершающая часть страницы или секции |
| `<button>` | Кнопка действия |

## Почему div и span не всегда подходят

`div` и `span` почти не несут смысла. Они полезны как нейтральные контейнеры, но не должны заменять элементы с готовой семантикой.

```html
<!-- плохо -->
<div class="button">Сохранить</div>

<!-- лучше -->
<button type="button">Сохранить</button>
```

`button` уже умеет получать фокус, реагировать на клавиатуру и понятно называется для скринридера.

## Семантика не про внешний вид

`<h1>` можно сделать маленьким, а `<p>` большим. Но смысл элементов от этого не меняется.

```css
h1 {
  font-size: 20px;
}
```

Выбирать тег нужно по смыслу, а не по дефолтным стилям браузера.

## Мини-шпаргалка

- Семантика - это смысл HTML-разметки.
- Тег выбирают по назначению контента.
- CSS отвечает за внешний вид, HTML - за структуру.
- `div` и `span` нейтральны и не заменяют смысловые элементы.
- Хорошая семантика улучшает доступность, SEO и поддержку кода.
