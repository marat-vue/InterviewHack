# Как задать опциональные поля в интерфейсе или типе?

> [!NOTE]
> Опциональное поле задается через `?` после имени свойства: `name?: string`.

## Вопрос

Как описать поле, которого может не быть в объекте?

## Определение

Опциональное свойство означает, что объект может содержать это поле, но не обязан. Если поле отсутствует, при чтении его значение будет `undefined`.

## В interface

```typescript
interface User {
  id: number;
  name: string;
  email?: string;
}
```

`email` можно не передавать.

```typescript
const user: User = {
  id: 1,
  name: 'Ann',
};
```

## В type

```typescript
type User = {
  id: number;
  name: string;
  email?: string;
};
```

Синтаксис такой же.

## Как читать опциональное поле

```typescript
function printEmail(user: User) {
  if (user.email) {
    console.log(user.email.toLowerCase());
  }
}
```

Перед использованием нужно учесть, что поле может быть `undefined`.

## Опциональное поле vs union с undefined

```typescript
type A = { email?: string };
type B = { email: string | undefined };
```

В `A` поля может не быть. В `B` поле должно быть, но его значение может быть `undefined`.

## Мини-шпаргалка

```typescript
interface Config {
  url: string;
  timeout?: number;
}
```
