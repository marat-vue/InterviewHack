# Как типизировать обработчики событий?

> [!summary]
> React использует Synthetic Events, а в TypeScript обработчики типизируют через `React.MouseEventHandler<T>`, `React.ChangeEventHandler<T>`, `React.FormEventHandler<T>` и похожие alias. Внутри обработчика обычно безопаснее читать `event.currentTarget`, а не `event.target`.

## Два способа типизации

Через тип обработчика:

```tsx
const handleClick: React.MouseEventHandler<HTMLButtonElement> = (event) => {
  event.currentTarget.disabled = true
}
```

Через тип event-параметра:

```tsx
function handleClick(event: React.MouseEvent<HTMLButtonElement>) {
  event.currentTarget.disabled = true
}
```

Оба способа корректны.

## Click

```tsx
const handleClick: React.MouseEventHandler<HTMLButtonElement> = (event) => {
  event.preventDefault()
}

return <button onClick={handleClick}>Save</button>
```

## Change input

```tsx
const handleChange: React.ChangeEventHandler<HTMLInputElement> = (event) => {
  setValue(event.currentTarget.value)
}

return <input value={value} onChange={handleChange} />
```

Для textarea:

```tsx
const handleChange: React.ChangeEventHandler<HTMLTextAreaElement> = (event) => {
  setMessage(event.currentTarget.value)
}
```

Для select:

```tsx
const handleChange: React.ChangeEventHandler<HTMLSelectElement> = (event) => {
  setRole(event.currentTarget.value)
}
```

## Submit формы

```tsx
const handleSubmit: React.FormEventHandler<HTMLFormElement> = (event) => {
  event.preventDefault()

  const formData = new FormData(event.currentTarget)
  const email = formData.get('email')
}

return (
  <form onSubmit={handleSubmit}>
    <input name="email" />
    <button>Submit</button>
  </form>
)
```

## Keyboard events

```tsx
const handleKeyDown: React.KeyboardEventHandler<HTMLInputElement> = (event) => {
  if (event.key === 'Enter') {
    submit()
  }
}
```

## Focus events

```tsx
const handleBlur: React.FocusEventHandler<HTMLInputElement> = (event) => {
  validateEmail(event.currentTarget.value)
}
```

## currentTarget vs target

`currentTarget` - элемент, на котором висит обработчик.

`target` - элемент, с которого событие реально началось. Он может быть вложенным.

```tsx
const handleClick: React.MouseEventHandler<HTMLButtonElement> = (event) => {
  event.currentTarget.disabled = true
}
```

Для типизированных React handlers чаще всего нужен `currentTarget`.

## Тип обработчика в props

```tsx
type ButtonProps = {
  onClick?: React.MouseEventHandler<HTMLButtonElement>
}

function Button({ onClick }: ButtonProps) {
  return <button onClick={onClick}>Save</button>
}
```

Можно взять тип из нативного элемента:

```tsx
type InputProps = {
  onChange?: React.ComponentProps<'input'>['onChange']
}
```

Это удобно для wrapper-компонентов.

## Inline handler

Часто TypeScript сам выводит тип inline:

```tsx
<input
  onChange={(event) => {
    setValue(event.currentTarget.value)
  }}
/>
```

Если вынесли функцию отдельно, тип нужно указать явно.

## Что отвечать на собеседовании?

React events в TypeScript типизируют через `React.*EventHandler<Element>` или через `React.*Event<Element>`. Для input используют `ChangeEventHandler<HTMLInputElement>`, для form - `FormEventHandler<HTMLFormElement>`, для button click - `MouseEventHandler<HTMLButtonElement>`. Обычно читают `event.currentTarget`, потому что он соответствует элементу обработчика.

## Частые ошибки

- Писать `event: any`.
- Использовать `Event` из DOM вместо React event.
- Читать `target.value`, когда нужен `currentTarget.value`.
- Типизировать input как `HTMLDivElement`.
- Забывать `preventDefault` в submit handler.

## Мини-шпаргалка

- Button click: `React.MouseEventHandler<HTMLButtonElement>`.
- Input change: `React.ChangeEventHandler<HTMLInputElement>`.
- Form submit: `React.FormEventHandler<HTMLFormElement>`.
- Keyboard: `React.KeyboardEventHandler<HTMLInputElement>`.
- Props wrapper: `React.ComponentProps<'input'>['onChange']`.
