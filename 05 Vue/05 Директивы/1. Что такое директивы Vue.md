# Что такое директивы Vue

> [!summary] Коротко
> Директивы Vue - специальные атрибуты шаблона с префиксом `v-`, которые связывают DOM с реактивными данными и событиями.

## Вопрос

Что такое директивы Vue?

## Базовый пример

```vue
<template>
  <p v-if="isVisible">Текст виден</p>
  <a v-bind:href="url">Ссылка</a>
  <button v-on:click="save">Сохранить</button>
  <input v-model="name" />
</template>
```

Директивы добавляют поведение к элементам и компонентам.

## Из чего состоит директива

```vue
<button v-on:click.prevent="submit">Отправить</button>
```

- `v-on` - имя директивы.
- `click` - аргумент.
- `.prevent` - модификатор.
- `submit` - выражение.

## Сокращения

```vue
<a :href="url">Ссылка</a>
<button @click="save">Сохранить</button>
```

`:` заменяет `v-bind`, `@` заменяет `v-on`.

## Частые встроенные директивы

- `v-if`, `v-else-if`, `v-else`.
- `v-show`.
- `v-for`.
- `v-bind`.
- `v-on`.
- `v-model`.
- `v-slot`.

## Мини-шпаргалка

- Директива начинается с `v-`.
- Она добавляет реактивное поведение в template.
- Аргумент уточняет цель директивы.
- Модификатор меняет поведение.
- `:` и `@` - самые частые сокращения.
