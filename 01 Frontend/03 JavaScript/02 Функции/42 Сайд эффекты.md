# Side effects

> [!NOTE]
> Side effect - любое действие функции, которое изменяет внешний мир или зависит от него, помимо возврата результата.

## Вопрос

Что такое side effects?

## Простое определение

Функция с side effect не просто вычисляет значение. Она еще что-то делает снаружи или зависит от внешнего состояния.

```javascript
let count = 0;

function increment() {
  count++;
}
```

Функция меняет внешнюю переменную `count`.

## Типичные side effects

- изменение глобальных переменных;
- мутация аргументов;
- запись в DOM;
- `console.log`;
- `alert`;
- сетевой запрос;
- запись в `localStorage`;
- работа с датой и временем;
- случайные значения через `Math.random()`.

## Нечистая функция

```javascript
function saveUser(user) {
  localStorage.setItem("user", JSON.stringify(user));
}
```

Она меняет внешнее хранилище.

## Side effect не всегда плохо

Приложение не может быть полностью без side effects. Нужно уметь их контролировать.

Например, отправка запроса - side effect, но без нее frontend часто бесполезен.

```javascript
async function loadUser(id) {
  const response = await fetch(`/api/users/${id}`);
  return response.json();
}
```

## Как уменьшать вред

Выносить вычисления в чистые функции:

```javascript
function getFullName(user) {
  return `${user.firstName} ${user.lastName}`;
}
```

А side effects держать на краях приложения:

```javascript
console.log(getFullName(user));
```

## Мутация аргументов

```javascript
function activate(user) {
  user.active = true;
  return user;
}
```

Лучше:

```javascript
function activate(user) {
  return {
    ...user,
    active: true,
  };
}
```

## Мини-шпаргалка

| Пример | Side effect? |
| --- | --- |
| `return a + b` | нет |
| `console.log(value)` | да |
| `array.push(item)` | да, если массив пришел извне |
| `fetch(url)` | да |
| `Date.now()` | зависит от внешнего времени |
| `Math.random()` | недетерминированность |
