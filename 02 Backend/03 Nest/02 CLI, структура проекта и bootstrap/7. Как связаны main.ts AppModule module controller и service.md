# Как связаны main.ts, AppModule, module, controller и service?

> [!summary]
> `main.ts` запускает приложение, `AppModule` собирает modules, feature module регистрирует controller и service, controller принимает request, а service выполняет бизнес-действие. Это базовая цепочка почти любого NestJS API.

## Цепочка запуска

```ts
// main.ts
const app = await NestFactory.create(AppModule);
await app.listen(3000);
```

`NestFactory` получает `AppModule` и строит dependency graph.

## Корневой module

```ts
@Module({
  imports: [UsersModule],
})
export class AppModule {}
```

`AppModule` подключает feature modules.

## Feature module

```ts
@Module({
  controllers: [UsersController],
  providers: [UsersService],
})
export class UsersModule {}
```

`UsersModule` говорит NestJS: вот controller фичи и вот service, который можно inject.

## Controller и service

```ts
@Controller('users')
export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  @Get()
  findAll() {
    return this.usersService.findAll();
  }
}
```

## Мини-шпаргалка

- `main.ts` запускает Nest application.
- `AppModule` - корень графа.
- Feature module группирует файлы фичи.
- Controller обрабатывает HTTP.
- Service содержит use case.
