# Как Vue обновляет DOM при изменении данных

> [!summary] Коротко
> Vue отслеживает реактивные зависимости компонента. Когда состояние меняется, компонент планирует обновление, заново вычисляет виртуальное дерево и применяет к реальному DOM только нужные изменения.

## Вопрос

Как Vue обновляет DOM при изменении данных?

## Общая схема

1. Компонент рендерится и читает реактивные данные.
2. Vue запоминает, какие данные использовал компонент.
3. Данные меняются.
4. Vue планирует обновление компонента.
5. Новый Virtual DOM сравнивается со старым.
6. В реальный DOM попадают минимальные изменения.

## Пример

```vue
<script setup>
import { ref } from "vue";

const title = ref("Главная");
</script>

<template>
  <h1>{{ title }}</h1>
  <button @click="title = 'Профиль'">Сменить</button>
</template>
```

После клика меняется `title`, и Vue обновляет текст внутри `h1`.

## Обновления не всегда мгновенные

Vue группирует изменения и применяет их асинхронно в ближайший tick, чтобы не делать лишние перерендеры.

```typescript
import { nextTick, ref } from "vue";

const count = ref(0);
count.value++;

await nextTick(); // DOM уже обновлен
```

## Почему это быстрее ручного подхода

Vue знает зависимости компонента и умеет обновлять только затронутые части дерева. Разработчик не пишет DOM-операции вручную.

## Мини-шпаргалка

- Изменение state не равно немедленному DOM-update.
- Vue группирует обновления.
- Virtual DOM помогает найти минимальные изменения.
- `nextTick` нужен, если DOM надо прочитать после обновления.
