# Что такое отладка?

> [!NOTE]
> Отладка - процесс поиска причины неправильного поведения программы и проверки исправления.

## Вопрос

Что такое debugging в разработке?

## Определение

Отладка - это не просто "посмотреть ошибку в консоли". Это системный процесс: воспроизвести проблему, понять ожидаемое и фактическое поведение, локализовать причину, исправить код и проверить результат.

## Типичный алгоритм

1. Воспроизвести проблему.
2. Сформулировать ожидаемое поведение.
3. Найти место, где поведение расходится с ожиданием.
4. Проверить значения переменных и состояние.
5. Исправить причину, а не только симптом.
6. Проверить сценарий снова.

## Инструменты

- `console.log`;
- breakpoints в DevTools;
- оператор `debugger`;
- Network tab;
- Performance tab;
- stack trace;
- тесты.

## Пример мышления

```javascript
function calculateTotal(items) {
  console.log(items);

  return items.reduce((sum, item) => sum + item.price, 0);
}
```

Лог помогает проверить входные данные, но после отладки такие временные сообщения лучше убрать или заменить нормальным логированием.

## Хорошая отладка

Хорошая отладка отвечает на вопрос "почему это произошло", а не только "где упало".

## Мини-шпаргалка

```text
reproduce -> inspect -> isolate -> fix -> verify
```
