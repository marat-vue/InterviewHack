# Как читать params, query, body, headers и cookies в Nitro?

> [!NOTE]
> В Nitro request читают через `event` и H3 utilities. Главное правило: route params, query, headers и cookies можно читать в любом методе, а body обычно читают в `POST`, `PUT`, `PATCH` или `QUERY`, но не в `GET`.

## Route params

Файл:

```txt
server/routes/api/users/[id].get.ts
```

Handler:

```ts
import { getRouterParam } from 'h3';

export default defineHandler((event) => {
  const id = getRouterParam(event, 'id');

  return {
    id,
  };
});
```

Для нескольких params:

```ts
import { getRouterParams } from 'h3';

export default defineHandler((event) => {
  const params = getRouterParams(event);

  return params;
});
```

## Query string

URL:

```txt
/api/users?page=2&search=anna
```

```ts
import { getQuery } from 'h3';

export default defineHandler((event) => {
  const query = getQuery(event);

  return {
    page: query.page,
    search: query.search,
  };
});
```

`getQuery` возвращает parsed object, но не валидирует типы. Для production API лучше использовать `getValidatedQuery`.

## Body

```ts
import { readBody } from 'h3';

export default defineHandler(async (event) => {
  const body = await readBody(event);

  return {
    received: body,
  };
});
```

Для JSON body:

```bash
curl -X POST http://localhost:3000/api/users \
  -H "content-type: application/json" \
  -d '{"email":"anna@example.com"}'
```

## FormData

```ts
import { readBody } from 'h3';

export default defineHandler(async (event) => {
  const form = await readBody(event, { type: 'formData' });

  return {
    email: form.get('email'),
  };
});
```

## Headers

Через Web Request:

```ts
export default defineHandler((event) => {
  const authorization = event.req.headers.get('authorization');

  return {
    hasToken: Boolean(authorization),
  };
});
```

В Nuxt/H3 также часто используют helper:

```ts
const userAgent = getHeader(event, 'user-agent');
```

## Cookies

```ts
import { getCookie, setCookie, deleteCookie } from 'h3';

export default defineHandler((event) => {
  const theme = getCookie(event, 'theme');

  setCookie(event, 'theme', 'dark', {
    httpOnly: true,
    sameSite: 'lax',
    secure: true,
  });

  return {
    previousTheme: theme,
  };
});
```

Удаление:

```ts
deleteCookie(event, 'session');
```

## Request URL, host, IP, protocol

```ts
import {
  getRequestHost,
  getRequestIP,
  getRequestProtocol,
  getRequestURL,
} from 'h3';

export default defineHandler((event) => {
  return {
    host: getRequestHost(event),
    ip: getRequestIP(event, { xForwardedFor: true }),
    protocol: getRequestProtocol(event, { xForwardedProto: true }),
    url: getRequestURL(event).href,
  };
});
```

Важно: `Host`, `X-Forwarded-Host`, `X-Forwarded-For` и `X-Forwarded-Proto` могут быть spoofed, если reverse proxy/CDN не нормализует их. Не используй их для security-решений без allowlist.

## Мини-шпаргалка

- `getRouterParam` - один route param.
- `getRouterParams` - все params.
- `getQuery` - query string object.
- `readBody` - request body.
- `readValidatedBody` - body + validation.
- `event.req.headers.get()` - header.
- `getCookie`, `setCookie`, `deleteCookie` - cookies.
- Для публичного API не доверяй входным данным без validation.
