# Теория множеств

> [!NOTE] Коротко
> Типы в TypeScript удобно представлять как множества значений. `|` расширяет множество, `&` оставляет пересечение, `never` означает пустое множество.

## Вопрос

Как теория множеств помогает понимать union и intersection?

## Тип как множество значений

Тип `string` - множество всех строк. Тип `"admin"` - множество из одного значения.

```typescript
type Role = "admin" | "user";
```

`Role` содержит два допустимых значения: `"admin"` и `"user"`.

## Union расширяет

```typescript
type Id = string | number;
```

`Id` - множество всех строк плюс множество всех чисел.

## Intersection сужает

```typescript
type Admin = { role: "admin"; permissions: string[] };
type Named = { name: string };

type NamedAdmin = Admin & Named;
```

`NamedAdmin` должен удовлетворять обоим наборам требований.

## `never` как пустое множество

```typescript
type Impossible = string & number;
// never
```

Пустое множество не содержит ни одного значения.

## `unknown` как верхний тип

```typescript
type A = string | unknown; // unknown
type B = string & unknown; // string
```

`unknown` можно представить как множество всех возможных значений.

## Мини-шпаргалка

- Тип = множество допустимых значений.
- `A | B` - объединение множеств.
- `A & B` - пересечение множеств.
- `never` - пустое множество.
- `unknown` - максимально широкое множество.
