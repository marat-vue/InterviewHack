# Что такое Fiber architecture?

> [!summary]
> Fiber - это внутренняя архитектура React, которая позволяет разбивать работу рендеринга на части, расставлять приоритеты обновлений и поддерживать современные возможности вроде concurrent rendering, transitions, Suspense и interruptible rendering.

## Зачем React понадобился Fiber?

Старый подход к reconciliation был более синхронным: если React начал большую работу по обновлению дерева, браузеру было сложнее прерывать ее ради более срочных задач.

Fiber помогает React:

- разбивать render-работу на маленькие единицы;
- приостанавливать и продолжать работу;
- назначать приоритеты обновлениям;
- не блокировать интерфейс дольше необходимого;
- поддерживать concurrent features.

## Что такое fiber?

Упрощенно fiber - это внутренняя структура данных, соответствующая части React-дерева.

Она хранит информацию о:

- типе компонента;
- props;
- state;
- связях с parent/child/sibling;
- работе, которую нужно выполнить;
- эффектах, которые нужно применить.

Это не API для разработчика. С fiber обычно не работают напрямую.

## Как Fiber связан с render и commit?

React-обновление можно грубо разделить на две фазы:

```text
Render phase:
React вычисляет новое дерево. Эта работа может быть прервана.

Commit phase:
React применяет изменения к DOM. Эта фаза синхронная.
```

Fiber особенно важен для render phase.

## Что это дает разработчику?

Разработчик получает возможности:

- `startTransition`;
- `useTransition`;
- `useDeferredValue`;
- Suspense;
- streaming SSR;
- более отзывчивый UI при тяжелых обновлениях.

Но использовать Fiber напрямую не нужно. Нужно понимать его как основу современного планировщика React.

## Как объяснить на собеседовании?

```text
Fiber - внутренняя архитектура React, где дерево представлено как набор fiber-узлов. Она позволяет React разбивать render-работу, приоритизировать обновления и прерывать менее срочную работу ради более важных пользовательских взаимодействий. Commit-фаза при этом остается применением готовых изменений к DOM.
```

## Мини-шпаргалка

- Fiber - внутренняя архитектура React, не публичный API.
- Она помогает разбивать и планировать работу.
- Render phase может быть прервана, commit phase применяет изменения.
- Fiber лежит в основе concurrent возможностей.
- На практике важно понимать эффекты: отзывчивость, Suspense, transitions.
