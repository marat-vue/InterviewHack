# Почему React называют декларативной библиотекой?

> [!summary]
> React называют декларативным, потому что разработчик описывает желаемый результат интерфейса, а не последовательность DOM-операций. Ты говоришь "что показать", а React сам решает "как обновить экран".

## Что значит декларативность?

Декларативный код описывает состояние UI:

```jsx
function Status({ isOnline }) {
  return (
    <p>
      {isOnline ? 'Пользователь онлайн' : 'Пользователь офлайн'}
    </p>
  )
}
```

Здесь мы не говорим:

```text
найди p -> очисти текст -> вставь новый текст -> поменяй класс
```

Мы просто описываем, каким должен быть интерфейс при `isOnline`.

## Императивный подход для сравнения

```js
const status = document.querySelector('.status')

if (isOnline) {
  status.textContent = 'Пользователь онлайн'
  status.classList.add('online')
} else {
  status.textContent = 'Пользователь офлайн'
  status.classList.remove('online')
}
```

Это императивный стиль: мы вручную управляем шагами изменения DOM.

## Почему декларативность удобна?

- Код ближе к описанию результата.
- Меньше ручной работы с DOM.
- Легче понимать состояние интерфейса.
- Компоненты проще тестировать.
- React может оптимизировать обновления.
- UI становится функцией от данных.

Формула:

```text
UI = f(state, props)
```

## Значит ли это, что в React нет императивного кода?

Нет. Императивный код все еще бывает нужен:

- фокус на input;
- работа с canvas;
- управление video/audio;
- интеграция с внешней DOM-библиотекой;
- измерение размеров элемента.

Для этого используют `ref` и эффекты, но основной render должен оставаться декларативным.

## Как объяснить на собеседовании?

```text
React декларативен, потому что компонент описывает, какой UI должен получиться из текущих props и state. Разработчик не пишет вручную DOM-операции для каждого изменения. React вызывает компоненты, сравнивает результат и сам применяет нужные изменения к DOM.
```

## Мини-шпаргалка

- Декларативно = описываем результат.
- Императивно = описываем пошаговые действия.
- В React UI обычно рассматривают как функцию от props и state.
- DOM-операции берет на себя React DOM.
- Императивный код в React нужен точечно, обычно через `ref`.
