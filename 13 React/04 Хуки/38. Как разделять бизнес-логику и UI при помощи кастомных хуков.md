# Как разделять бизнес-логику и UI при помощи кастомных хуков?

> [!summary]
> Кастомные хуки позволяют вынести из компонента получение данных, состояние, подписки и действия, оставив компоненту роль отображения. Это делает UI чище, а логику проще тестировать и переиспользовать.

## Проблема смешанного компонента

```jsx
function UserPage({ userId }) {
  const [user, setUser] = useState(null)
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    setIsLoading(true)
    fetch(`/api/users/${userId}`)
      .then((response) => response.json())
      .then(setUser)
      .finally(() => setIsLoading(false))
  }, [userId])

  if (isLoading) return <p>Загрузка...</p>
  return <UserCard user={user} />
}
```

Компонент одновременно загружает данные и отображает UI.

## Вынос логики в hook

```jsx
function useUser(userId) {
  const [user, setUser] = useState(null)
  const [isLoading, setIsLoading] = useState(true)

  useEffect(() => {
    const controller = new AbortController()

    setIsLoading(true)
    fetch(`/api/users/${userId}`, { signal: controller.signal })
      .then((response) => response.json())
      .then(setUser)
      .finally(() => setIsLoading(false))

    return () => controller.abort()
  }, [userId])

  return { user, isLoading }
}
```

Компонент:

```jsx
function UserPage({ userId }) {
  const { user, isLoading } = useUser(userId)

  if (isLoading) return <p>Загрузка...</p>
  return <UserCard user={user} />
}
```

## Что остается в UI?

UI-компонент должен:

- принимать данные;
- показывать состояния;
- вызывать callbacks;
- описывать разметку;
- не знать деталей API, storage и подписок.

## Что уходит в hook?

В hook можно вынести:

- загрузку данных;
- retry;
- debounce;
- optimistic update;
- derived values;
- работу с URL/browser API;
- business actions;
- синхронизацию с внешним store.

## Важный нюанс

Для server state лучше часто использовать TanStack Query/SWR/фреймворк, а не писать большой слой fetch вручную в custom hooks. Но даже тогда custom hook может дать удобный доменный API:

```jsx
function useCurrentUser() {
  return useQuery({
    queryKey: ['currentUser'],
    queryFn: fetchCurrentUser,
  })
}
```

## Мини-шпаргалка

- Custom hook выносит логику, компонент оставляет UI.
- Hook возвращает данные и действия.
- UI не должен знать детали API.
- Сложный hook можно разбить на маленькие.
- Для server state часто лучше использовать специализированную библиотеку.
