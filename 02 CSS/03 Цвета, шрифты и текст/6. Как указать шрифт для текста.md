# Как указать шрифт для текста

> [!summary]
> Шрифт текста задается свойством `font-family`. Обычно указывают не один шрифт, а цепочку fallback-шрифтов, чтобы браузер мог выбрать запасной вариант, если основной не загрузился.

## Главное

```css
body {
  font-family: Inter, Arial, sans-serif;
}
```

Браузер попробует использовать `Inter`. Если его нет, перейдет к `Arial`, затем к любому доступному `sans-serif`.

## Font stack

Цепочка шрифтов называется font stack.

```css
.article {
  font-family: Georgia, "Times New Roman", serif;
}
```

Если название шрифта содержит пробелы, его пишут в кавычках.

## Generic families

В конце цепочки обычно указывают общее семейство.

| Семейство | Где подходит |
| --- | --- |
| `sans-serif` | Интерфейсы, кнопки, формы |
| `serif` | Длинные тексты, статьи, печатный стиль |
| `monospace` | Код, технические значения |
| `cursive` | Декоративные сценарии |
| `fantasy` | Редкие декоративные сценарии |

## Шрифт для кода

```css
code,
pre {
  font-family: "JetBrains Mono", Consolas, monospace;
}
```

Для кода лучше использовать моноширинный шрифт.

## Подключенный шрифт

Если шрифт не системный, его нужно подключить через `@font-face` или внешний CSS.

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-display: swap;
}
```

После подключения его можно использовать в `font-family`.

## Мини-шпаргалка

- Шрифт задается через `font-family`.
- Лучше указывать цепочку fallback-шрифтов.
- Названия с пробелами пишут в кавычках.
- В конце указывают generic family: `sans-serif`, `serif`, `monospace`.
- Для нестандартного шрифта нужен `@font-face` или подключение внешнего CSS.
