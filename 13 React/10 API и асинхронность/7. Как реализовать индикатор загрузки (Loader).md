# Как реализовать индикатор загрузки (Loader)?

> [!summary]
> Loader показывает пользователю, что данные или код еще загружаются. В React обычно моделируют не один boolean `loading`, а несколько состояний: загрузка, успех, ошибка, пустой результат и фоновое обновление.

## Базовая модель состояния

```jsx
function UsersPage() {
  const [users, setUsers] = useState([])
  const [status, setStatus] = useState('idle')
  const [error, setError] = useState(null)

  useEffect(() => {
    async function loadUsers() {
      try {
        setStatus('loading')
        setError(null)

        const data = await fetchUsers()

        setUsers(data)
        setStatus('success')
      } catch (error) {
        setError(error)
        setStatus('error')
      }
    }

    loadUsers()
  }, [])

  if (status === 'loading') return <UsersSkeleton />
  if (status === 'error') return <ErrorMessage error={error} />
  if (users.length === 0) return <EmptyState />

  return <UsersList users={users} />
}
```

## Loader, skeleton и empty state

Не все загрузочные состояния одинаковые.

| Состояние | Что показывать |
|---|---|
| Initial loading | skeleton или full-page loader |
| Refetching | маленький индикатор, старые данные оставить |
| Empty success | empty state, а не loader |
| Error | fallback с кнопкой retry |

Плохой UX:

```jsx
if (isLoading) return <Spinner />
```

Если данные уже есть и идет фоновое обновление, лучше не прятать весь экран.

## Доступный loader

```jsx
function Loader() {
  return (
    <div role="status" aria-live="polite">
      Loading...
    </div>
  )
}
```

Если loader только декоративный, можно скрывать его от скринридеров:

```jsx
<span aria-hidden="true" className="spinner" />
```

## Loader с TanStack Query

```jsx
function UsersPage() {
  const {
    data: users = [],
    isLoading,
    isFetching,
    error,
    refetch,
  } = useQuery({
    queryKey: ['users'],
    queryFn: fetchUsers,
  })

  if (isLoading) return <UsersSkeleton />
  if (error) return <ErrorMessage error={error} onRetry={refetch} />

  return (
    <>
      {isFetching && <SmallRefreshIndicator />}
      <UsersList users={users} />
    </>
  )
}
```

`isLoading` - первая загрузка без данных. `isFetching` - любой активный fetch, включая фоновый refetch.

## Мини-шпаргалка

- Loader нужен для ожидания, но не должен скрывать полезные старые данные без причины.
- Разделяй initial loading и background refetch.
- Empty state не равен loading.
- Error state должен давать понятный fallback и retry.
- Для доступности используй `role="status"` или `aria-live`.
