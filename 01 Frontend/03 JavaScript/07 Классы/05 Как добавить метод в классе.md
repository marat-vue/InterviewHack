# Как добавить метод в классе?

> [!NOTE]
> Метод класса объявляют внутри тела класса без слова `function`; такие методы попадают в прототип.

## Вопрос

Как добавить метод экземпляра в класс?

## Обычный метод

```javascript
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}

const user = new User('Ann');

console.log(user.sayHi()); // 'Hi, Ann'
```

`sayHi()` находится в `User.prototype`, поэтому все экземпляры используют одну общую функцию.

## Проверка прототипа

```javascript
console.log(User.prototype.sayHi);
console.log(user.hasOwnProperty('sayHi')); // false
```

Метод не хранится отдельно в каждом объекте.

## Метод с параметрами

```javascript
class Counter {
  constructor() {
    this.value = 0;
  }

  add(step = 1) {
    this.value += step;
  }
}
```

## Вызов метода

```javascript
const counter = new Counter();

counter.add();
counter.add(5);

console.log(counter.value); // 6
```

## Мини-шпаргалка

```javascript
class ClassName {
  methodName(arg) {
    return arg;
  }
}
```
