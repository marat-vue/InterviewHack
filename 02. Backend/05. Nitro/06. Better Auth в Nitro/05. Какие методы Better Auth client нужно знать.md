# Какие методы Better Auth client нужно знать?

> [!NOTE]
> Better Auth client предоставляет методы для работы с auth server из браузера: registration, sign in, social login, sign out, session state, user update и plugin-specific методы. В Vue/Nuxt используют client из `better-auth/vue`, чтобы `useSession` возвращал reactive state.

## Создание client в Vue/Nuxt

```ts
// app/lib/auth-client.ts или lib/auth-client.ts
import { createAuthClient } from 'better-auth/vue';

export const authClient = createAuthClient({
  baseURL: 'http://localhost:3000',
});

export const {
  signIn,
  signUp,
  signOut,
  useSession,
} = authClient;
```

Если auth server на том же origin и default path `/api/auth`, `baseURL` часто можно не указывать.

## Основные методы

| Метод | Зачем нужен |
|---|---|
| `authClient.signUp.email(data, options?)` | регистрация через email/password |
| `authClient.signIn.email(data, options?)` | вход через email/password |
| `authClient.signIn.social(data, options?)` | вход через social provider |
| `authClient.signOut(options?)` | выход |
| `authClient.useSession()` | reactive session state |
| `authClient.getSession()` | получить session без hook |
| `authClient.updateUser(data, options?)` | обновить данные пользователя |

Точный набор методов расширяется plugins.

## Sign up

```ts
const { data, error } = await authClient.signUp.email({
  name: 'Anna',
  email: 'anna@example.com',
  password: 'password1234',
  callbackURL: '/dashboard',
});

if (error) {
  console.error(error.message);
}
```

## Sign in

```ts
const { data, error } = await authClient.signIn.email({
  email: 'anna@example.com',
  password: 'password1234',
  rememberMe: true,
  callbackURL: '/dashboard',
});
```

`rememberMe: false` обычно означает session до закрытия браузера.

## Social sign in

```ts
await authClient.signIn.social({
  provider: 'github',
  callbackURL: '/dashboard',
  errorCallbackURL: '/login?error=oauth',
  newUserCallbackURL: '/welcome',
});
```

Provider должен быть настроен на server side в `auth.ts`.

## Sign out

```ts
await authClient.signOut({
  fetchOptions: {
    onSuccess() {
      navigateTo('/login');
    },
  },
});
```

## `useSession`

```ts
const {
  data: session,
  isPending,
  error,
  refetch,
} = authClient.useSession();
```

В Vue-версии значения reactive, поэтому в компонентах их используют как refs/computed в зависимости от API клиента.

## `getSession`

```ts
const { data: session, error } = await authClient.getSession();
```

Подходит для:

- одноразовой проверки;
- composables;
- data fetching;
- не-reactive сценариев.

## Fetch options callbacks

Многие методы принимают callbacks:

```ts
await authClient.signIn.email({
  email,
  password,
}, {
  onRequest() {
    loading.value = true;
  },
  onSuccess() {
    navigateTo('/dashboard');
  },
  onError(ctx) {
    message.value = ctx.error.message;
  },
});
```

## Plugin-specific methods

Если подключен plugin, client получает дополнительные методы.

Пример 2FA client plugin:

```ts
import { twoFactorClient } from 'better-auth/client/plugins';

export const authClient = createAuthClient({
  plugins: [
    twoFactorClient(),
  ],
});
```

После этого появляются методы, связанные с two-factor flow.

## Мини-шпаргалка

- `signUp.email` - регистрация.
- `signIn.email` - вход по email/password.
- `signIn.social` - OAuth/social login.
- `signOut` - выход.
- `useSession` - reactive session.
- `getSession` - session одним запросом.
- `updateUser` - обновление профиля.
- Plugins расширяют client новыми методами.
