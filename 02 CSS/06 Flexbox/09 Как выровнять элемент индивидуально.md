# Как выровнять элемент индивидуально?

> [!NOTE]
> Один flex item можно выровнять индивидуально через `align-self`. Это свойство переопределяет `align-items` для конкретного элемента по cross axis.

## Главное

```css
.item--top {
  align-self: flex-start;
}
```

`align-self` применяется к flex item, а не к flex-контейнеру.

## Пример

```css
.card {
  display: flex;
  align-items: center;
}

.card__badge {
  align-self: flex-start;
}
```

Все элементы карточки выравниваются по центру, но бейдж прижимается к началу cross axis.

## Значения

| Значение | Поведение |
| --- | --- |
| `auto` | Использовать значение `align-items` контейнера |
| `flex-start` | Прижать к началу cross axis |
| `center` | Центрировать |
| `flex-end` | Прижать к концу |
| `stretch` | Растянуть |
| `baseline` | Выровнять по базовой линии |

## Main axis индивидуально

В Flexbox нет прямого `justify-self` для flex items. Для индивидуального сдвига по main axis часто используют auto margins.

```css
.toolbar {
  display: flex;
}

.toolbar__actions {
  margin-left: auto;
}
```

Так actions уедет вправо в строковом flex-контейнере.

## Мини-шпаргалка

- `align-self` выравнивает один flex item.
- Работает по cross axis.
- Переопределяет `align-items`.
- `justify-self` для flex items не работает как в Grid.
- Для сдвига по main axis часто используют `margin-left: auto`.
