# Как использовать routeRules, headers, redirects, proxy, CORS и basicAuth?

> [!NOTE]
> `routeRules` позволяют декларативно задать поведение для route pattern: headers, cache/SWR, static/prerender, redirect, proxy, CORS и basic auth. Это удобно для инфраструктурной логики, которую не хочется писать внутри каждого handler.

## Где задаются route rules?

Standalone Nitro:

```ts
// nitro.config.ts
import { defineConfig } from 'nitro';

export default defineConfig({
  routeRules: {
    '/api/**': {
      cors: true,
    },
  },
});
```

Nuxt:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    routeRules: {
      '/api/**': {
        cors: true,
      },
    },
  },
});
```

## Headers

```ts
routeRules: {
  '/api/**': {
    headers: {
      'x-api': 'true',
      'cache-control': 'no-store',
    },
  },
}
```

Подходит для:

- security headers;
- cache-control;
- custom platform headers;
- API metadata.

## Redirect

```ts
routeRules: {
  '/old-page': {
    redirect: '/new-page',
  },
  '/old-blog/**': {
    redirect: '/blog/**',
  },
}
```

Redirect rules удобны для migrations URL и SEO redirects.

## Proxy

```ts
routeRules: {
  '/proxy/example': {
    proxy: 'https://example.com',
  },
  '/api/legacy/**': {
    proxy: 'https://legacy.example.com/**',
  },
}
```

Proxy полезен для:

- migration со старого API;
- BFF endpoints;
- скрытия backend origin от браузера;
- временного compatibility layer.

## CORS

```ts
routeRules: {
  '/api/public/**': {
    cors: true,
  },
}
```

`cors: true` включает permissive defaults. Для production часто нужен более строгий CORS через middleware/helper:

```ts
import { handleCors } from 'h3';

export default defineEventHandler((event) => {
  const result = handleCors(event, {
    origin: ['https://app.example.com'],
    methods: ['GET', 'POST'],
  });

  if (result !== false) {
    return result;
  }
});
```

## basicAuth

```ts
routeRules: {
  '/admin/**': {
    basicAuth: {
      username: 'admin',
      password: process.env.ADMIN_PASSWORD!,
    },
  },
}
```

Basic auth подходит для:

- dev preview;
- internal dashboards;
- staging endpoints;
- простого закрытия docs.

Для user authentication лучше использовать полноценную auth-систему вроде Better Auth.

## Cache и SWR

```ts
routeRules: {
  '/blog/**': {
    swr: 600,
  },
  '/api/catalog/**': {
    cache: {
      maxAge: 60 * 10,
    },
  },
}
```

`swr` - shortcut для stale-while-revalidate поведения.

## Rule merging

Route rules применяются от менее специфичных к более специфичным. Более конкретное правило может переопределить общее:

```ts
routeRules: {
  '/api/**': {
    cors: true,
    headers: { 'x-api': 'true' },
  },
  '/api/private/**': {
    cors: false,
  },
}
```

## Method-scoped rules

Можно ограничить rule методом:

```ts
routeRules: {
  '/api/**': {
    headers: { 'x-api': 'true' },
  },
  'POST /api/**': {
    basicAuth: {
      username: 'admin',
      password: 'secret',
    },
  },
  'GET /feed': {
    swr: 600,
  },
}
```

## Мини-шпаргалка

- `headers` - добавить response headers.
- `redirect` - перенаправить URL.
- `proxy` - проксировать request.
- `cors` - включить CORS.
- `basicAuth` - закрыть route basic auth.
- `cache` - включить route cache.
- `swr` - shortcut для stale-while-revalidate.
- Более специфичные rules переопределяют общие.
