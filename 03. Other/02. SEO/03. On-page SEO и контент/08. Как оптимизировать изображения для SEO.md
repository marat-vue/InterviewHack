# Как оптимизировать изображения для SEO?

> [!summary]
> Image SEO помогает поисковикам понять изображения, а пользователям - быстрее и удобнее получать визуальный контент. Это не только `alt`, но и размер, формат, lazy loading, контекст и доступность.

## Что важно для изображения?

- Понятный контекст рядом с изображением.
- Описательный `alt`.
- Нормальный filename.
- Подходящий размер.
- Современный формат.
- Сжатие без заметной потери качества.
- Указанные `width` и `height`.
- Responsive images через `srcset`.

## Как писать alt?

`alt` описывает смысл изображения:

```html
<img
  src="/images/lcp-waterfall.png"
  alt="Waterfall загрузки страницы с выделенным LCP-изображением"
  width="960"
  height="540"
>
```

Если изображение декоративное:

```html
<img src="/decor-line.svg" alt="">
```

## Пример responsive image

```html
<img
  src="/images/product-800.webp"
  srcset="/images/product-400.webp 400w, /images/product-800.webp 800w"
  sizes="(max-width: 600px) 400px, 800px"
  alt="Черный рюкзак с отделением для ноутбука"
  width="800"
  height="600"
>
```

Так браузер может выбрать подходящий файл.

## Изображения и Core Web Vitals

Изображения часто влияют на:

- LCP, если главное изображение грузится медленно;
- CLS, если не заданы размеры;
- вес страницы;
- расход трафика на мобильных.

Главное изображение страницы обычно не стоит lazy-load, если оно является LCP-кандидатом.

## Мини-шпаргалка

- `alt` должен описывать смысл, а не набивать ключи.
- Задавай `width` и `height`.
- Используй WebP/AVIF, если подходит.
- Сжимай и отдавай нужные размеры.
- Не lazy-load главное LCP-изображение.
