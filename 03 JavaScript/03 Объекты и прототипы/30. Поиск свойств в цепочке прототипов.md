# Поиск свойств в цепочке прототипов

> [!summary] Коротко
> При чтении свойства JavaScript сначала ищет его в самом объекте, затем в прототипе, затем выше по цепочке до `null`. При записи обычно создается или меняется собственное свойство.

## Вопрос

Как реализован поиск свойств в цепочке прототипов?

## Чтение свойства

```javascript
const proto = { role: "user" };
const user = Object.create(proto);

user.name = "Anna";

user.name; // "Anna"
user.role; // "user"
```

Алгоритм:

1. искать в `user`;
2. если нет - искать в `proto`;
3. если нет - идти выше;
4. если дошли до `null` - вернуть `undefined`.

## Собственное или унаследованное

```javascript
Object.hasOwn(user, "name"); // true
Object.hasOwn(user, "role"); // false

"role" in user; // true
```

`role` доступен, но не является собственным свойством `user`.

## Запись свойства

```javascript
user.role = "admin";

user.role; // "admin"
proto.role; // "user"
```

Обычно запись создает собственное свойство и затеняет свойство прототипа.

## Исключение: setter

Если в прототипе есть setter, запись может вызвать его.

```javascript
const proto = {
  set role(value) {
    this._role = value;
  },
};

const user = Object.create(proto);

user.role = "admin";

user._role; // "admin"
```

## Удаление

`delete` удаляет только собственные свойства.

```javascript
delete user.role;

user.role; // снова "user" из proto
```

Если собственного свойства нет, прототипное останется.

## Мини-шпаргалка

| Операция | Поведение |
| --- | --- |
| `obj.prop` | ищет по цепочке |
| `obj.prop = value` | обычно создает own property |
| `delete obj.prop` | удаляет только own property |
| `Object.hasOwn(obj, key)` | проверяет own property |
| `key in obj` | проверяет всю цепочку |
