# Чем DELETE отличается от TRUNCATE?

> [!summary]
> `DELETE` удаляет строки и может использовать `WHERE`, а `TRUNCATE` быстро очищает всю таблицу целиком. `TRUNCATE` относится к DDL/utility-операциям и часто имеет более жесткое поведение с транзакциями и блокировками в зависимости от СУБД.

## DELETE

```sql
DELETE FROM logs
WHERE created_at < now() - interval '30 days';
```

Можно удалить часть строк.

## TRUNCATE

```sql
TRUNCATE TABLE logs;
```

Очищает таблицу целиком.

## Отличия

| Операция | Можно WHERE | Обычно для |
|---|---|---|
| `DELETE` | да | выборочное удаление |
| `TRUNCATE` | нет | полная очистка таблицы |

## Что помнить?

`TRUNCATE` может сбрасывать счетчики identity/sequence, быстрее освобождать место и требовать более сильные блокировки. Точное поведение зависит от СУБД.

## Мини-шпаргалка

- `DELETE` удаляет выбранные строки.
- `TRUNCATE` очищает всю таблицу.
- `TRUNCATE` обычно быстрее для полной очистки.
- У `TRUNCATE` нет `WHERE`.
- В production сначала проверь транзакционность и блокировки своей СУБД.
