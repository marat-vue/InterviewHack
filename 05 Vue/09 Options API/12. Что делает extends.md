# Что делает extends

> [!summary] Коротко
> `extends` в Options API позволяет компоненту расширить другой компонент и унаследовать его опции. Это похоже на mixin, но используется для одного базового компонента.

## Вопрос

Что делает `extends` в Options API?

## Базовый пример

```javascript
const BaseList = {
  data() {
    return {
      page: 1,
    };
  },
  methods: {
    nextPage() {
      this.page++;
    },
  },
};

export default {
  extends: BaseList,
};
```

Компонент получает опции из `BaseList`.

## Чем отличается от mixins

`extends` задает один базовый компонент. `mixins` позволяют смешать несколько объектов.

```javascript
export default {
  extends: BaseComponent,
  mixins: [loadingMixin, permissionsMixin],
};
```

## Почему используют редко

Наследование компонентов делает поведение менее явным. Часто проще использовать композицию компонентов, slots или composables.

## Когда может встретиться

`extends` можно увидеть в старом Vue-коде, UI-библиотеках или legacy-компонентах с общей базовой логикой.

## Мини-шпаргалка

- `extends` расширяет один компонент.
- Наследует Options API опции.
- Может скрывать источник логики.
- В новом коде чаще лучше composables или композиция компонентов.
