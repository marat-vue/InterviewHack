# Генераторы

> [!NOTE]
> Генератор - функция `function*`, выполнение которой можно ставить на паузу через `yield` и продолжать через `.next()`. Генераторы возвращают iterable iterator.

## Вопрос

Расскажите про функции-генераторы в JavaScript. В чем особенности, когда использовать?

## Синтаксис

```javascript
function* generateNumbers() {
  yield 1;
  yield 2;
  yield 3;
}

const generator = generateNumbers();
```

Вызов генераторной функции не выполняет тело сразу. Он возвращает объект-генератор.

```javascript
generator.next(); // { value: 1, done: false }
generator.next(); // { value: 2, done: false }
generator.next(); // { value: 3, done: false }
generator.next(); // { value: undefined, done: true }
```

## `yield`

`yield` возвращает значение наружу и ставит генератор на паузу.

```javascript
function* demo() {
  console.log("start");
  yield "A";
  console.log("middle");
  yield "B";
  console.log("end");
}
```

Каждый `.next()` продолжает выполнение с места последней паузы.

## Генератор является iterable

```javascript
function* generateNumbers() {
  yield 1;
  yield 2;
  yield 3;
}

for (const number of generateNumbers()) {
  console.log(number);
}
```

Можно использовать spread:

```javascript
[...generateNumbers()]; // [1, 2, 3]
```

## Бесконечная последовательность

Генераторы удобны для ленивого получения значений.

```javascript
function* createIds() {
  let id = 1;

  while (true) {
    yield id++;
  }
}

const ids = createIds();

ids.next().value; // 1
ids.next().value; // 2
```

Значения создаются по запросу, а не заранее.

## `return` в генераторе

```javascript
function* gen() {
  yield 1;
  return 2;
}

const g = gen();

g.next(); // { value: 1, done: false }
g.next(); // { value: 2, done: true }
```

Значение `return` завершает генератор. При `for...of` оно не попадает в перебор.

## `yield*`

`yield*` делегирует генерацию другому iterable.

```javascript
function* gen() {
  yield 1;
  yield* [2, 3];
  yield 4;
}

[...gen()]; // [1, 2, 3, 4]
```

## Когда использовать

- ленивые последовательности;
- обход структур данных;
- генерация id;
- кастомные iterable-объекты;
- сценарии, где нужно паузить и продолжать выполнение.

## Мини-шпаргалка

```javascript
function* gen() {
  yield value;
}

const iterator = gen();
iterator.next(); // { value, done }
[...gen()];      // собрать значения
for (const x of gen()) {}
```

| Понятие | Значение |
| --- | --- |
| `function*` | объявляет генератор |
| `yield` | пауза и значение наружу |
| `.next()` | продолжить выполнение |
| `done: false` | генератор не завершен |
| `done: true` | генератор завершен |
| `yield*` | делегирование другому iterable |
