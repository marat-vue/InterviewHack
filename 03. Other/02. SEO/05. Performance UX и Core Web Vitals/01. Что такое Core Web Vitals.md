# Что такое Core Web Vitals?

> [!summary]
> Core Web Vitals - это набор пользовательских метрик качества страницы. Они измеряют загрузку, отзывчивость и визуальную стабильность: LCP, INP и CLS.

## Какие метрики входят?

| Метрика | Что измеряет |
|---|---|
| LCP | когда загрузился главный видимый контент |
| INP | насколько быстро страница реагирует на взаимодействия |
| CLS | насколько сильно элементы неожиданно сдвигаются |

## Почему это важно для SEO?

Core Web Vitals связаны с page experience. Они не заменяют релевантность и качество контента, но плохой UX может мешать пользователям и снижать конкурентоспособность страницы.

Простая мысль:

```text
Полезная страница должна не только существовать, но и нормально открываться, читаться и реагировать.
```

## Field data и lab data

| Тип данных | Что значит |
|---|---|
| Field data | реальные пользователи |
| Lab data | тест в контролируемых условиях |

Search Console и CrUX показывают полевые данные, а Lighthouse обычно дает лабораторную диагностику.

## Что значит good?

Обычно ориентиры такие:

- LCP до 2.5 сек;
- INP до 200 мс;
- CLS до 0.1.

Важно смотреть не только среднее, а опыт большинства пользователей.

## Мини-шпаргалка

- Core Web Vitals = LCP + INP + CLS.
- Это метрики UX, а не просто "балл скорости".
- Field data важнее для реальной оценки.
- Lighthouse помогает искать причины.
- Оптимизация должна улучшать пользовательский опыт, а не только цифры.
