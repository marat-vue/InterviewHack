# Наследование в интерфейсах

> [!summary] Коротко
> Интерфейс может наследоваться от другого интерфейса через `extends`, добавляя новые поля к существующему контракту.

## Вопрос

Как наследовать интерфейс от другого?

## Определение

`interface Child extends Parent` создает новый интерфейс, который включает все поля родителя и добавляет свои.

## Пример

```typescript
interface Entity {
  id: number;
}

interface User extends Entity {
  name: string;
}

const user: User = {
  id: 1,
  name: 'Ann',
};
```

`User` обязан иметь и `id`, и `name`.

## Наследование методов

```typescript
interface Logger {
  log(message: string): void;
}

interface FileLogger extends Logger {
  filePath: string;
}
```

## Переопределение поля

Интерфейс-наследник не может произвольно изменить поле на несовместимый тип.

```typescript
interface A {
  id: number;
}

interface B extends A {
  id: string; // ошибка
}
```

Тип должен быть совместим с родительским контрактом.

## Когда использовать

- расширение базовой модели;
- общие поля вроде `id`;
- контракты компонентов;
- классы с `implements`;
- публичные API.

## Мини-шпаргалка

```typescript
interface Child extends Parent {
  extra: string;
}
```
