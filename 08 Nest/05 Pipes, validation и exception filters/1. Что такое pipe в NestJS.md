# Что такое pipe в NestJS?

> [!summary]
> Pipe - класс, который выполняется перед route handler и может преобразовать или провалидировать входные данные. Если pipe выбрасывает exception, controller method не выполняется.

## Две основные задачи pipe

| Задача | Пример |
|---|---|
| Transformation | превратить `id` из string в number |
| Validation | проверить DTO и выбросить `BadRequestException` |

## Пример built-in pipe

```ts
@Get(':id')
findOne(@Param('id', ParseIntPipe) id: number) {
  return this.usersService.findOne(id);
}
```

`ParseIntPipe` преобразует строковый path param в number или выбросит ошибку.

## Где применяются pipes?

- на параметре;
- на методе controller;
- на controller;
- глобально для всего приложения.

## Мини-шпаргалка

- Pipe работает перед controller method.
- Pipe валидирует или трансформирует input.
- Ошибка pipe попадает в exception layer.
- `ValidationPipe` - самый важный pipe для API.
- Built-in pipes решают частые задачи parsing.
