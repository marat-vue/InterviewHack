# Какие преимущества дает центральный стор?

> [!NOTE]
> Центральный стор дает единый источник правды для общих данных приложения, уменьшает prop drilling и делает изменения состояния более предсказуемыми.

## Вопрос

Какие преимущества дает центральный стор?

## Единый источник правды

Если текущий пользователь хранится в store, разные компоненты читают одно и то же состояние.

```typescript
const auth = useAuthStore();

if (auth.user) {
  console.log(auth.user.name);
}
```

Не нужно держать копии пользователя в нескольких местах.

## Меньше prop drilling

Без store общие данные приходится передавать через промежуточные компоненты.

```text
App -> Layout -> Header -> UserMenu
```

Store позволяет `UserMenu` получить данные напрямую.

## Предсказуемые изменения

Actions задают понятные точки изменения данных.

```typescript
const cart = useCartStore();

cart.addItem(product);
cart.removeItem(product.id);
```

## Devtools и отладка

State manager обычно хорошо интегрируется с Vue Devtools: видно состояние, stores и изменения.

## Мини-шпаргалка

- Store снижает дублирование общего state.
- Убирает длинный prop drilling.
- Делает изменения более явными через actions.
- Удобен для debug и shared data.
- Особенно полезен в больших SPA.
