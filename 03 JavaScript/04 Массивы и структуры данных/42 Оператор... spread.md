# Оператор ... spread

> [!NOTE] Коротко
> Spread `...` распаковывает элементы итерируемого объекта: массива, строки, `Set` и других структур.

## Вопрос

Что делает оператор `...` при работе с массивом?

## Определение

Spread-синтаксис берет элементы из массива или другого итерируемого объекта и вставляет их в новое место: в массив, аргументы функции или объект.

Важно: при копировании массивов spread делает поверхностную копию.

## Копирование массива

```javascript
const numbers = [1, 2, 3];
const copy = [...numbers];

console.log(copy); // [1, 2, 3]
console.log(copy === numbers); // false
```

## Объединение массивов

```javascript
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];

console.log(result); // [1, 2, 3, 4]
```

## Передача аргументов

```javascript
const values = [4, 8, 15];

console.log(Math.max(...values)); // 15
```

## Поверхностная копия

```javascript
const users = [{ name: 'Ann' }];
const copy = [...users];

copy[0].name = 'Bob';

console.log(users[0].name); // 'Bob'
```

Новый массив создан, но вложенный объект остался тем же самым.

## Мини-шпаргалка

```javascript
[...arr]          // копия массива
[...a, ...b]      // объединение
fn(...args)       // передача как аргументы
[...'hello']      // ['h', 'e', 'l', 'l', 'o']
```
