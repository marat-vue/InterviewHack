# Что такое Nitro в Nuxt?

> [!summary]
> Nitro - server engine Nuxt. Он отвечает за server routes, API endpoints, middleware, server plugins, caching, deployment presets и сборку server output под разные платформы.

## Простое определение

Nuxt app состоит из двух больших частей:

```text
Vue/Nuxt app -> pages, components, SSR
Nitro server -> API, middleware, server runtime, deployment
```

Nitro позволяет Nuxt работать как full-stack framework.

## Что делает Nitro?

- запускает server API;
- обрабатывает server middleware;
- дает h3 event handlers;
- умеет server plugins;
- поддерживает route rules;
- собирает server output;
- адаптируется под Node, serverless, edge и другие presets;
- поддерживает caching/storage utilities.

## Где Nitro код?

```text
server/
  api/
  routes/
  middleware/
  plugins/
  utils/
```

## Пример

```ts
// server/api/health.get.ts
export default defineEventHandler(() => {
  return {
    status: 'ok',
  };
});
```

URL:

```text
/api/health
```

## Мини-шпаргалка

- Nitro - серверный движок Nuxt.
- `server/api` создает API endpoints.
- Nitro использует h3 event handlers.
- Route rules и caching работают через Nitro.
- Deployment output Nuxt зависит от Nitro preset.
