# Какие типы компонентов существуют в React?

> [!summary]
> В React чаще всего говорят о функциональных и классовых компонентах. В современной разработке основным вариантом являются функциональные компоненты с хуками, а классовые встречаются в старом коде и в некоторых специальных случаях вроде Error Boundary.

## Функциональный компонент

```jsx
function Button({ children, onClick }) {
  return (
    <button onClick={onClick}>
      {children}
    </button>
  )
}
```

Это обычная JavaScript-функция, которая принимает props и возвращает JSX.

## Компонент со стрелочной функцией

```jsx
const Button = ({ children, onClick }) => {
  return (
    <button onClick={onClick}>
      {children}
    </button>
  )
}
```

Оба варианта рабочие. Function declaration часто удобнее для stack traces и читаемости, но стиль зависит от проекта.

## Классовый компонент

```jsx
import { Component } from 'react'

class Counter extends Component {
  state = {
    count: 0,
  }

  render() {
    return (
      <button onClick={() => this.setState({ count: this.state.count + 1 })}>
        {this.state.count}
      </button>
    )
  }
}
```

До хуков классы были основным способом использовать state и lifecycle methods.

## Какие компоненты бывают по роли?

| Тип по роли | Смысл |
|---|---|
| Presentational | отвечает за внешний вид |
| Container | получает данные и управляет логикой |
| Controlled | значение контролируется React state |
| Uncontrolled | значение хранится в DOM |
| HOC | функция, которая оборачивает компонент |
| Compound components | группа компонентов с общим контекстом |

Это не разные API React, а архитектурные подходы.

## Что использовать сейчас?

В новых проектах обычно используют:

- функциональные компоненты;
- хуки;
- composition;
- custom hooks;
- Error Boundary как class component или библиотечный wrapper, если нужен.

## Мини-шпаргалка

- Основной современный тип - функциональный компонент.
- Классовые компоненты важны для чтения legacy-кода.
- Хуки работают только в функциональных компонентах и custom hooks.
- Типы вроде container/presentational описывают роль, а не синтаксис.
- Error Boundary исторически пишут классом.
