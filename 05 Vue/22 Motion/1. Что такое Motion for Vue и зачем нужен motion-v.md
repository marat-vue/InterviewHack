# Что такое Motion for Vue и зачем нужен motion-v?

> [!summary]
> Motion for Vue - библиотека анимаций для Vue из экосистемы Motion. Пакет `motion-v` помогает декларативно создавать enter/exit animations, hover/press/drag gestures, layout animations, scroll animations и управляемые анимации через composables.

## Зачем нужна отдельная animation library?

CSS transitions отлично подходят для простых эффектов:

```css
.button {
  transition: background-color 0.2s ease;
}

.button:hover {
  background-color: #2563eb;
}
```

Но CSS быстро становится неудобным, когда нужно:

- анимировать появление и удаление компонентов;
- прерывать анимации при изменении state;
- связывать анимацию с Vue props/state;
- делать drag gestures;
- делать shared layout animation;
- строить scroll-linked progress/parallax;
- координировать parent/children animations;
- учитывать `prefers-reduced-motion`.

Motion закрывает эти сценарии через Vue-friendly API.

## Что умеет motion-v?

| Возможность | Для чего нужна |
|---|---|
| `<motion.div>` | декларативная анимация элемента |
| `initial` | начальное состояние |
| `animate` | состояние, к которому анимируем |
| `transition` | duration, easing, spring |
| `whileHover` | состояние при hover |
| `whilePress` | состояние при press/tap |
| `drag` | draggable элементы |
| `whileInView` | scroll-triggered animation |
| `layout` | анимация layout changes |
| `AnimatePresence` | exit animations |
| `v-motion` | directive без wrapper component |
| `useAnimate` | ручное управление анимацией |
| `useScroll` | scroll-linked animation |
| `useReducedMotion` | accessibility для reduced motion |

## Когда Motion лучше CSS?

Motion особенно полезен для:

- animated modals;
- dropdowns/popovers;
- page transitions;
- cards hover/press;
- sortable/reorderable UI;
- animated lists;
- drag interactions;
- scroll reveal;
- progress bars tied to scroll;
- micro-interactions в продуктовых интерфейсах.

## Когда CSS лучше?

Для простого `hover:bg-blue-700`, underline transition, color transition или маленького opacity effect CSS/Tailwind часто проще и дешевле.

Не нужно ставить Motion на каждую кнопку, если эффект решается одной CSS transition.

## Мини-шпаргалка

- `motion-v` - Motion for Vue package.
- Motion нужен для сложных и управляемых анимаций.
- CSS лучше для простых self-contained effects.
- Основной API: `<motion.div>`, `v-motion`, `AnimatePresence`, hooks.
- Хорошая анимация должна помогать UX, а не отвлекать.
