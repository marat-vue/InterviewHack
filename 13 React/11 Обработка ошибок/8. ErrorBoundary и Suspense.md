# ErrorBoundary и Suspense

> [!summary]
> `Suspense` отвечает за состояние ожидания, а Error Boundary - за состояние ошибки. В связке они позволяют показать loading fallback, пока код или данные загружаются, и error fallback, если загрузка или render завершились ошибкой.

## Главное различие

```text
Suspense      -> что показывать, пока ресурс не готов
ErrorBoundary -> что показывать, если произошла ошибка
```

`Suspense` не является обработчиком ошибок.

Error Boundary не является loader.

## Типичная композиция

```jsx
<ErrorBoundary fallback={<ProfileError />}>
  <Suspense fallback={<ProfileSkeleton />}>
    <Profile />
  </Suspense>
</ErrorBoundary>
```

Сценарии:

- `Profile` загружает lazy chunk - показывается `ProfileSkeleton`;
- lazy import завершился ошибкой - показывается `ProfileError`;
- данные suspend - показывается `ProfileSkeleton`;
- Suspense-enabled data source бросил error - показывается `ProfileError`.

## Пример с React.lazy

```jsx
const SettingsPage = lazy(() => import('./SettingsPage'))

function App() {
  return (
    <ErrorBoundary fallback={<p>Failed to load settings</p>}>
      <Suspense fallback={<p>Loading settings...</p>}>
        <SettingsPage />
      </Suspense>
    </ErrorBoundary>
  )
}
```

Если chunk грузится, сработает Suspense. Если chunk не загрузился, ошибка попадет в Error Boundary.

## Несколько независимых зон

```jsx
function Dashboard() {
  return (
    <>
      <ErrorBoundary fallback={<ChartError />}>
        <Suspense fallback={<ChartSkeleton />}>
          <Chart />
        </Suspense>
      </ErrorBoundary>

      <ErrorBoundary fallback={<FeedError />}>
        <Suspense fallback={<FeedSkeleton />}>
          <Feed />
        </Suspense>
      </ErrorBoundary>
    </>
  )
}
```

Так падение графика не ломает всю страницу.

## В каком порядке оборачивать?

Чаще всего:

```jsx
<ErrorBoundary>
  <Suspense>
    <Component />
  </Suspense>
</ErrorBoundary>
```

Но границы можно комбинировать по смыслу. Важно, чтобы у зоны были оба сценария: loading и error.

## Мини-шпаргалка

- Suspense ловит ожидание, а не ошибку.
- Error Boundary ловит ошибку, а не ожидание.
- Для lazy components нужны оба.
- Boundaries лучше ставить вокруг независимых частей UI.
- Suspense fallback и error fallback должны быть разными состояниями.
