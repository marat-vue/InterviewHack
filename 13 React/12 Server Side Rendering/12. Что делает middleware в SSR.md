# Что делает middleware в SSR?

> [!summary]
> Middleware в SSR - это промежуточный серверный слой, который выполняется до render страницы. Он может проверить авторизацию, сделать redirect, выбрать locale, применить rewrite, отдать cache или подготовить request context.

## Где находится middleware?

```text
HTTP request -> middleware -> route/data loading -> React SSR -> HTML response
```

Middleware должен быть быстрым. Его задача - не рендерить UI, а принять раннее решение по request.

## Типичные задачи

- auth guard;
- redirect;
- rewrite URL;
- locale detection;
- A/B testing;
- bot detection;
- rate limiting;
- cache lookup;
- добавление request id;
- подготовка context.

## Пример auth redirect

```ts
export function middleware(request) {
  const session = request.cookies.get('session')
  const pathname = request.nextUrl.pathname

  if (pathname.startsWith('/admin') && !session) {
    return redirect('/login')
  }

  return next()
}
```

Идея: если пользователь не авторизован, не нужно тратить ресурсы на SSR страницы admin.

## Пример locale rewrite

```ts
export function middleware(request) {
  const pathname = request.nextUrl.pathname

  if (pathname === '/') {
    const language = request.headers
      .get('accept-language')
      ?.split(',')[0]
      ?? 'en'

    return rewrite(`/${language}`)
  }

  return next()
}
```

## Middleware vs server component/page loader

Middleware:

- быстрый;
- работает до route render;
- не должен делать тяжелые запросы;
- принимает ранние решения.

Page/server loader:

- загружает данные страницы;
- знает route;
- может обращаться к БД/API;
- готовит props/model для render.

## Важные ограничения

В некоторых фреймворках middleware может выполняться на Edge Runtime, где недоступны обычные Node.js API. Поэтому нельзя автоматически считать, что там есть файловая система, долгие соединения с БД или любые Node-пакеты.

## Мини-шпаргалка

- Middleware работает до SSR render.
- Хорош для redirect, auth, locale, rewrite и cache.
- Не стоит класть туда тяжелую бизнес-логику.
- Middleware может сэкономить серверный render.
- Runtime middleware зависит от фреймворка и платформы.
