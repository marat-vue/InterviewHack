# Как делать пагинацию в SQL?

> [!summary]
> Пагинацию можно делать через `LIMIT/OFFSET` или через cursor/keyset pagination. `OFFSET` проще, но на больших страницах может быть медленным и нестабильным при изменении данных.

## LIMIT/OFFSET

```sql
SELECT *
FROM posts
ORDER BY created_at DESC, id DESC
LIMIT 20 OFFSET 40;
```

Просто и удобно для небольших списков.

## Проблемы OFFSET

- большая страница требует пропустить много строк;
- новые записи могут сдвигать страницы;
- при удалениях можно пропустить или повторить элементы.

## Cursor pagination

```sql
SELECT *
FROM posts
WHERE (created_at, id) < (TIMESTAMP '2026-08-01 10:00:00', 123)
ORDER BY created_at DESC, id DESC
LIMIT 20;
```

Cursor хранит позицию последней записи предыдущей страницы.

## Мини-шпаргалка

- `LIMIT/OFFSET` прост, но плохо масштабируется на глубоких страницах.
- Cursor pagination быстрее для бесконечной ленты.
- Сортировка должна быть стабильной.
- Добавляй уникальный tie-breaker, например `id`.
- Индекс должен соответствовать сортировке.
