# Реактивность VS связывание данных

> [!summary] Коротко
> Реактивность - внутренний механизм отслеживания изменений. Связывание данных - способ использовать этот механизм в шаблоне через интерполяции, `v-bind`, `v-model` и другие директивы.

## Вопрос

Чем реактивность отличается от связывания данных?

## Реактивность

Реактивность знает, какие части кода зависят от данных.

```typescript
import { computed, ref } from "vue";

const count = ref(1);
const doubled = computed(() => count.value * 2);

count.value = 2; // doubled станет 4
```

Это работает даже без шаблона.

## Связывание данных

Связывание данных показывает реактивные значения в UI.

```vue
<template>
  <p>{{ count }}</p>
  <button :disabled="count === 0">Удалить</button>
  <input v-model="name" />
</template>
```

Интерполяция, `v-bind` и `v-model` связывают состояние с DOM.

## Главное отличие

Реактивность - "как Vue узнает об изменениях". Связывание данных - "как данные подключены к шаблону".

## Пример вместе

```vue
<script setup>
import { ref } from "vue";

const name = ref("");
</script>

<template>
  <input v-model="name" />
  <p>{{ name }}</p>
</template>
```

`ref` дает реактивность, `v-model` и `{{ name }}` дают binding.

## Мини-шпаргалка

- Реактивность - механизм отслеживания.
- Binding - связь данных с шаблоном.
- `ref/reactive/computed/watch` относятся к реактивности.
- `{{ }}`, `v-bind`, `v-model` относятся к связыванию.
