# Метрики для оценки производительности

> [!NOTE] Коротко
> Производительность оценивают не "на глаз", а через метрики: время загрузки, отклик интерфейса, длительность задач, память и сетевые показатели.

## Вопрос

Какие метрики используют для оценки производительности JavaScript и веб-страницы?

## Основная идея

Производительность - это не только "код быстро выполняется". Для пользователя важны загрузка, отзывчивость, плавность интерфейса и стабильность.

Поэтому метрики делят на несколько групп.

## Метрики загрузки

| Метрика | Что показывает |
| --- | --- |
| FCP | когда появился первый контент |
| LCP | когда загрузился главный видимый контент |
| TTFB | как быстро сервер начал отвечать |
| Load time | когда страница полностью загрузилась |

## Метрики отзывчивости

| Метрика | Что показывает |
| --- | --- |
| INP | насколько быстро страница реагирует на действия |
| Long Tasks | задачи дольше 50 мс в main thread |
| Event handler duration | сколько работает обработчик события |

## Метрики памяти

- рост потребления памяти;
- количество DOM-узлов;
- удержанные объекты;
- detached DOM nodes;
- частота и длительность сборки мусора.

## Пример измерения времени

```javascript
const start = performance.now();

heavyTask();

const end = performance.now();

console.log(`Duration: ${end - start}ms`);
```

`performance.now()` точнее, чем `Date.now()` для измерений производительности.

## Мини-шпаргалка

```text
loading -> FCP, LCP, TTFB
responsiveness -> INP, long tasks
memory -> heap, leaks, detached nodes
```
