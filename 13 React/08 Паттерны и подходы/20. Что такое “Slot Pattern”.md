# Что такое “Slot Pattern”?

> [!summary]
> Slot Pattern позволяет компоненту задавать структуру, а родителю - передавать содержимое в заранее определенные места. В React слоты обычно реализуют через `children`, именованные props или compound components.

## Базовая идея

Компонент отвечает за layout:

```jsx
function Modal({ header, body, footer }) {
  return (
    <section className="modal">
      <header>{header}</header>
      <div>{body}</div>
      <footer>{footer}</footer>
    </section>
  )
}
```

Родитель отвечает за содержимое:

```jsx
<Modal
  header={<h2>Delete user</h2>}
  body={<p>This action cannot be undone.</p>}
  footer={<button>Confirm</button>}
/>
```

## Чем это отличается от обычного children?

Обычный `children` дает один неименованный слот:

```jsx
function Card({ children }) {
  return <section>{children}</section>
}
```

Named slots дают несколько зон:

```jsx
function Card({ title, actions, children }) {
  return (
    <section>
      <header>
        <h2>{title}</h2>
        <div>{actions}</div>
      </header>
      <div>{children}</div>
    </section>
  )
}
```

Использование:

```jsx
<Card
  title="Orders"
  actions={<button>Create</button>}
>
  <OrdersTable />
</Card>
```

## Slot Pattern через compound components

Более выразительный API:

```jsx
<Modal>
  <Modal.Header>Delete user</Modal.Header>
  <Modal.Body>This action cannot be undone.</Modal.Body>
  <Modal.Footer>
    <button>Cancel</button>
    <button>Delete</button>
  </Modal.Footer>
</Modal>
```

Такой вариант удобен для UI-библиотек, но реализация сложнее.

## Когда использовать?

- модалки;
- карточки;
- layout-компоненты;
- таблицы;
- формы;
- sidebars;
- сложные компоненты дизайн-системы.

## На что обратить внимание?

Слишком большое количество slot props может сделать API неудобным:

```jsx
<Widget headerLeft={} headerRight={} bodyTop={} bodyBottom={} footerLeft={} />
```

В таком случае лучше подумать о `children`, composition или compound components.

## Мини-шпаргалка

- Slot Pattern разделяет структуру и содержимое.
- `children` - один слот.
- Props вроде `header`, `footer`, `actions` - именованные слоты.
- Compound Components дают более декларативный slot API.
- Паттерн особенно полезен в layout и UI-kit компонентах.
