# Что измеряет Core Web Vitals

> [!summary] Коротко
> Core Web Vitals измеряют пользовательский опыт страницы через LCP, INP и CLS: загрузку, отзывчивость и визуальную стабильность.

## Вопрос

Какие метрики входят в Core Web Vitals и что они показывают?

## Определение

Core Web Vitals - набор ключевых метрик Google для оценки качества пользовательского опыта на странице. Они ориентированы на реальные ощущения пользователя: быстро ли появился главный контент, быстро ли страница реагирует и не прыгает ли layout.

## Актуальные метрики

| Метрика | Что измеряет | Хорошее значение |
| --- | --- | --- |
| LCP | скорость появления главного контента | до 2.5 с |
| INP | отзывчивость на взаимодействия | до 200 мс |
| CLS | визуальную стабильность | до 0.1 |

Оценка обычно смотрится по 75-му перцентилю реальных посещений.

## LCP

Largest Contentful Paint показывает, когда в viewport отрисовался крупнейший значимый элемент: изображение, блок текста, hero-картинка.

## INP

Interaction to Next Paint измеряет, насколько быстро страница визуально реагирует на действия пользователя: клик, ввод, нажатие клавиш.

## CLS

Cumulative Layout Shift измеряет неожиданные сдвиги layout. Например, если кнопка уехала вниз из-за поздно загруженной картинки.

## Как измерять

- PageSpeed Insights;
- Lighthouse;
- Chrome DevTools;
- Chrome User Experience Report;
- RUM-аналитика через библиотеку `web-vitals`.

## Мини-шпаргалка

```text
LCP -> loading
INP -> responsiveness
CLS -> visual stability
```
