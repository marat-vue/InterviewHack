# Массив в JavaScript

> [!NOTE]
> Массив - упорядоченная коллекция значений с доступом по индексу. Индексация начинается с `0`, а свойство `length` показывает длину массива.

## Вопрос

Что такое массив в JavaScript?

## Базовый пример

```javascript
const numbers = [10, 20, 30];

numbers[0]; // 10
numbers[1]; // 20
```

Первый элемент имеет индекс `0`.

## Массив может хранить разные типы

```javascript
const mixed = [1, "text", true, { id: 1 }, [10, 20]];
```

JavaScript-массивы не ограничены одним типом.

## `length`

```javascript
const items = ["a", "b", "c"];

items.length; // 3
items[items.length - 1]; // "c"
```

`length` - не просто счетчик, а специальное свойство массива.

## Массив - объект

```javascript
typeof []; // "object"
```

Проверять массив нужно так:

```javascript
Array.isArray([]); // true
```

## Частые операции

```javascript
items.push("d");      // добавить в конец
items.pop();          // удалить с конца
items.map((x) => x);  // преобразовать
items.filter(Boolean);// отфильтровать
```

## Мини-шпаргалка

| Особенность | Массив |
| --- | --- |
| порядок | есть |
| доступ | по индексу |
| первый индекс | `0` |
| длина | `length` |
| проверка | `Array.isArray(value)` |
| тип через `typeof` | `"object"` |
