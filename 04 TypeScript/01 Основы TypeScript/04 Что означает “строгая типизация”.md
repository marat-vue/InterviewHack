# Что означает “строгая типизация”?

> [!NOTE] Коротко
> Строгая типизация означает, что язык не позволяет свободно смешивать несовместимые типы без явного намерения разработчика.

## Вопрос

Что значит строгая типизация в TypeScript?

## Определение

Строгая типизация помогает не выполнять операции между значениями, которые не подходят друг другу по типу. TypeScript проверяет такие ситуации и требует уточнить, преобразовать или правильно описать тип.

## Пример

```typescript
let age: number = 25;

age = '25'; // ошибка TypeScript
```

Переменная объявлена как `number`, поэтому строку присвоить нельзя.

## Строгий режим TypeScript

В `tsconfig.json` есть опция `strict`, которая включает набор строгих проверок.

```json
{
  "compilerOptions": {
    "strict": true
  }
}
```

Она включает проверки вроде `strictNullChecks`, `noImplicitAny`, `strictFunctionTypes` и другие.

## Строгая типизация vs статическая типизация

| Понятие | Смысл |
| --- | --- |
| Статическая типизация | когда проверяются типы |
| Строгая типизация | насколько строго проверяются несовместимости |

## Почему это полезно

- меньше неявных ошибок;
- понятнее контракты функций;
- безопаснее работа с `null` и `undefined`;
- проще рефакторить код.

## Мини-шпаргалка

```typescript
let count: number = 1;
count = 'one'; // нельзя
```
