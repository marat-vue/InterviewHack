# Как работает Passport в NestJS?

> [!summary]
> Passport - популярная auth-библиотека Node.js. NestJS интегрирует ее через `@nestjs/passport`, strategies и guards, чтобы проверять credentials или tokens и добавлять пользователя в request.

## Strategy

```ts
@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: 'secret',
    });
  }

  validate(payload: JwtPayload) {
    return { userId: payload.sub, email: payload.email };
  }
}
```

`validate` возвращает объект, который попадет в `request.user`.

## Guard

```ts
export class JwtAuthGuard extends AuthGuard('jwt') {}
```

Использование:

```ts
@UseGuards(JwtAuthGuard)
@Get('profile')
getProfile(@Request() req) {
  return req.user;
}
```

## Мини-шпаргалка

- Passport работает через strategies.
- NestJS подключает Passport через guards.
- `validate` возвращает user object.
- `AuthGuard('jwt')` запускает JWT strategy.
- Secrets нельзя хардкодить в production.
