# Реактивность и декларативность

> [!summary] Коротко
> Декларативность описывает, каким должен быть UI при текущих данных. Реактивность делает так, чтобы UI автоматически обновлялся, когда эти данные меняются.

## Вопрос

Как связаны реактивность и декларативность?

## Декларативность отвечает за описание

```vue
<template>
  <p v-if="isLoading">Загрузка</p>
  <UserCard v-else :user="user" />
</template>
```

Шаблон говорит: если загрузка активна, показываем текст; иначе показываем карточку.

## Реактивность отвечает за обновление

```vue
<script setup>
import { ref } from "vue";

const isLoading = ref(true);

setTimeout(() => {
  isLoading.value = false;
}, 1000);
</script>
```

Когда `isLoading` изменится, Vue автоматически обновит отображение.

## Вместе они дают модель UI

```text
state changes -> Vue reacts -> template shows new UI
```

Разработчик не управляет DOM пошагово, а работает с состоянием и правилами отображения.

## Пример с вычислением

```typescript
import { computed, ref } from "vue";

const firstName = ref("Анна");
const lastName = ref("Петрова");

const fullName = computed(() => `${firstName.value} ${lastName.value}`);
```

`fullName` декларативно описывает зависимость, а реактивность пересчитывает ее.

## Мини-шпаргалка

- Декларативность = описание результата.
- Реактивность = автоматическая реакция на изменения.
- Вместе они убирают ручные DOM-операции.
- `computed` хорошо показывает связь этих идей.
