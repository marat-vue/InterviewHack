# Что такое covering index и index only scan?

> [!summary]
> Covering index содержит все данные, нужные запросу, поэтому база иногда может ответить по индексу без чтения строк таблицы. Такой план часто называют index only scan.

## Пример

```sql
CREATE INDEX idx_orders_user_created_total
ON orders(user_id, created_at DESC, total);
```

Запрос:

```sql
SELECT created_at, total
FROM orders
WHERE user_id = 42
ORDER BY created_at DESC
LIMIT 10;
```

Индекс содержит `user_id`, `created_at` и `total`, поэтому базе может не понадобиться читать таблицу отдельно.

## Зачем это нужно?

Чтение только индекса может быть быстрее, потому что индекс меньше таблицы и уже отсортирован нужным образом.

## Цена

Не стоит добавлять в индекс все возможные колонки. Большой индекс:

- занимает больше места;
- медленнее обновляется;
- хуже помещается в память;
- может быть бесполезен для других запросов.

## Мини-шпаргалка

- Covering index покрывает все поля запроса.
- Index only scan может читать только индекс.
- Особенно полезно для частых lightweight queries.
- Большие покрывающие индексы имеют цену.
- Эффект нужно проверять через `EXPLAIN`.
