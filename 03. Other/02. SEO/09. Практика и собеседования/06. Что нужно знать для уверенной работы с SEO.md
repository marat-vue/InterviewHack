# Что нужно знать для уверенной работы с SEO?

> [!summary]
> Для уверенной работы с SEO нужно понимать путь страницы от URL до выдачи, уметь проектировать индексируемые страницы, не ломать сайт релизами, читать аналитику и отличать устойчивые практики от манипуляций.

## Минимальный набор знаний

Ты должен уметь объяснить:

- crawling, indexing, ranking, serving;
- robots.txt, noindex, sitemap;
- canonical и duplicate content;
- redirects и status codes;
- title, description, headings;
- search intent и helpful content;
- internal linking;
- structured data;
- Core Web Vitals;
- JavaScript SEO;
- SSR/SSG/CSR;
- Search Console и GA4;
- безопасное продвижение.

## Практический набор навыков

Ты должен уметь:

- проверить status code;
- найти `noindex`;
- прочитать robots.txt;
- проверить sitemap;
- найти canonical;
- посмотреть rendered HTML;
- проверить title/meta;
- проверить structured data;
- прочитать отчет PSI;
- сформулировать SEO-задачу для разработки;
- объяснить риск миграции URL.

## Как мыслить на проекте?

```text
1. Может ли поисковик найти страницу?
2. Может ли он ее обойти?
3. Можно ли ее индексировать?
4. Понятно ли, о чем страница?
5. Закрывает ли она intent?
6. Удобна ли она пользователю?
7. Есть ли доверие и внешние сигналы?
8. Можем ли мы измерить результат?
```

## Хороший итоговый ответ на собеседовании

```text
SEO - это не один набор тегов, а система: техническая доступность, понятный контент, соответствие intent, доверие, производительность, структурированные данные, продвижение и аналитика. Во frontend я особенно слежу за рендерингом, URL, ссылками, meta, status codes и Core Web Vitals.
```

## Мини-шпаргалка

- SEO требует системного мышления.
- Сначала доступность и индексация, потом контент и продвижение.
- Frontend-решения могут сильно повлиять на organic traffic.
- Любая гипотеза должна измеряться.
- Устойчивое SEO строится на пользе и доверии.
