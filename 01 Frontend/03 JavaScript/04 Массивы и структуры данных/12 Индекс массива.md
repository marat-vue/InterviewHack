# Индекс массива

> [!NOTE] Коротко
> Индекс массива - позиция элемента. В JavaScript индексация начинается с `0`, поэтому последний индекс равен `arr.length - 1`.

## Вопрос

Что такое индекс массива?

## Пример

```javascript
const items = ["a", "b", "c"];

items[0]; // "a"
items[1]; // "b"
items[2]; // "c"
```

Первый элемент находится по индексу `0`.

## Последний элемент

```javascript
const last = items[items.length - 1];

console.log(last); // "c"
```

Современный способ:

```javascript
items.at(-1); // "c"
```

## Изменение по индексу

```javascript
items[1] = "B";

console.log(items); // ["a", "B", "c"]
```

## Несуществующий индекс

```javascript
items[10]; // undefined
```

Ошибки нет, если просто прочитать несуществующий индекс.

## Индекс как свойство

Массивы технически являются объектами, а индексы - специальные строковые ключи.

```javascript
Object.keys(["a", "b"]); // ["0", "1"]
```

## Мини-шпаргалка

| Задача | Код |
| --- | --- |
| первый элемент | `arr[0]` |
| второй элемент | `arr[1]` |
| последний индекс | `arr.length - 1` |
| последний элемент | `arr[arr.length - 1]` |
| последний через `at` | `arr.at(-1)` |
| несуществующий индекс | `undefined` |
