# Что делает оператор debugger?

> [!NOTE]
> `debugger` ставит программную точку остановки: если DevTools открыты, выполнение кода остановится на этой строке.

## Вопрос

Для чего нужен оператор `debugger`?

## Определение

`debugger` - инструкция JavaScript, которая сообщает отладчику остановить выполнение программы. Это похоже на breakpoint, но записанный прямо в коде.

## Пример

```javascript
function calculateTotal(items) {
  debugger;

  return items.reduce((sum, item) => sum + item.price, 0);
}
```

Если DevTools открыты, браузер остановится на строке `debugger`.

## Что можно сделать на паузе

- посмотреть переменные;
- пройти код пошагово;
- проверить call stack;
- выполнить выражения в консоли;
- понять, откуда пришел вызов.

## Когда использовать

- когда неудобно искать файл в Sources;
- когда breakpoint должен быть в конкретной ветке кода;
- когда нужно быстро поймать момент выполнения.

## Важный нюанс

`debugger` не стоит оставлять в production-коде. Перед коммитом его обычно удаляют или ловят линтером.

## Мини-шпаргалка

```javascript
debugger; // pause here if DevTools is open
```
