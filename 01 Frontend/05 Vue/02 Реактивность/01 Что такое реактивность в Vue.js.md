# Что такое реактивность в Vue.js?

> [!NOTE] Коротко
> Реактивность во Vue - механизм, который отслеживает чтение и изменение данных, а затем автоматически обновляет зависящий от них UI и вычисления.

## Вопрос

Что такое реактивность в Vue.js?

## Простая идея

Ты меняешь состояние, а Vue обновляет все места, которые от него зависят.

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

`count` реактивен: изменение значения запускает обновление шаблона.

## Как Vue понимает зависимости

Во время рендера компонент читает реактивные значения. Vue запоминает эти чтения и связывает компонент с данными.

```typescript
import { computed, ref } from "vue";

const price = ref(100);
const count = ref(2);

const total = computed(() => price.value * count.value);
```

`total` зависит от `price` и `count`, поэтому пересчитается при их изменении.

## Зачем это нужно

Реактивность убирает ручную синхронизацию: не нужно самому искать DOM-узлы и менять текст, классы или атрибуты.

## Мини-шпаргалка

- Реактивность связывает данные и зависимый код.
- `ref` делает реактивным одно значение.
- `reactive` делает реактивным объект.
- `computed` пересчитывается при изменении зависимостей.
- `watch` запускает side effect при изменении данных.
