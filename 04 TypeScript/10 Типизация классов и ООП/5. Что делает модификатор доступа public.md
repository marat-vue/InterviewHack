# Что делает модификатор доступа public

> [!summary] Коротко
> `public` означает, что свойство или метод класса доступен отовсюду: внутри класса, в наследниках и снаружи через экземпляр.

## Вопрос

Что делает модификатор доступа `public`?

## Базовый пример

```typescript
class User {
  public name: string;

  constructor(name: string) {
    this.name = name;
  }
}

const user = new User("Анна");
console.log(user.name);
```

## `public` по умолчанию

Если модификатор не указан, член класса считается `public`.

```typescript
class User {
  name = "Анна"; // public
}
```

## В параметрах конструктора

```typescript
class User {
  constructor(public name: string) {}
}
```

Это короткая запись для объявления поля и присваивания значения из конструктора.

## Когда писать явно

Обычно `public` можно не писать. Но явная запись бывает полезна в командах, где принято показывать намерение для всех членов класса.

## Мини-шпаргалка

- `public` доступен везде.
- Это модификатор по умолчанию.
- В constructor-параметре создает публичное поле.
- Не дает дополнительной runtime-защиты.
