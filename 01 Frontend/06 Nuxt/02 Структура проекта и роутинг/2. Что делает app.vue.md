# Что делает app.vue?

> [!summary]
> `app.vue` - корневой Vue-компонент Nuxt-приложения. В нем обычно размещают общую оболочку, `<NuxtLayout />`, `<NuxtPage />`, глобальные providers, transitions и элементы, которые должны быть на всех страницах.

## Минимальный `app.vue`

```vue
<template>
  <NuxtPage />
</template>
```

`<NuxtPage />` показывает текущую страницу из `app/pages`.

## С layout

```vue
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

`<NuxtLayout>` применяет layout из `app/layouts`.

## Что обычно кладут в `app.vue`?

- общий layout wrapper;
- global modals/toasts;
- providers;
- базовые transitions;
- глобальный loading indicator;
- элементы, которые есть на всех страницах.

## Чего лучше избегать?

Не стоит превращать `app.vue` в огромный компонент:

- не пиши всю навигацию и бизнес-логику прямо там;
- не делай тяжелые запросы без необходимости;
- не смешивай layout всех страниц в одном файле.

Лучше выносить:

- header/footer в components;
- page shell в layouts;
- логику в composables.

## Мини-шпаргалка

- `app.vue` - корневой компонент.
- `<NuxtPage />` рендерит текущую page.
- `<NuxtLayout>` применяет layout.
- Глобальные элементы можно положить в `app.vue`.
- Большую логику лучше выносить.
