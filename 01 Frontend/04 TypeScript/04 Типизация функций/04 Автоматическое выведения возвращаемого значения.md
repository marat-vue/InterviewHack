# Автоматическое выведения возвращаемого значения

> [!NOTE]
> TypeScript умеет сам определить тип результата функции по выражениям `return`. Это называется inference, или вывод типов.

## Вопрос

Как TypeScript выводит тип возвращаемого значения автоматически?

## Один вариант возврата

Если функция возвращает значение одного типа, результат выводится напрямую.

```typescript
const double = (value: number) => value * 2;
// тип: (value: number) => number
```

## Несколько вариантов

Если ветки возвращают разные типы, TypeScript строит union.

```typescript
function getLabel(id: number) {
  if (id === 0) {
    return "guest";
  }

  return id;
}

// тип результата: string | number
```

## Нет `return`

Если функция не возвращает значение, результат будет `void`.

```typescript
function log(message: string) {
  console.log(message);
}

// тип результата: void
```

## `async` всегда возвращает Promise

```typescript
async function getCount() {
  return 10;
}

// тип результата: Promise<number>
```

## Когда inference недостаточно

Для публичных функций лучше писать тип явно, чтобы случайное изменение `return` не поменяло контракт.

```typescript
function getUserName(user: User): string {
  return user.name;
}
```

## Мини-шпаргалка

- TS смотрит на все `return`.
- Разные типы в ветках дают union.
- Нет `return` - будет `void`.
- `async` оборачивает результат в `Promise`.
