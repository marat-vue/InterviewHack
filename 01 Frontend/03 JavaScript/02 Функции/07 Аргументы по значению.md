# Аргументы по значению

> [!NOTE]
> В JavaScript аргументы всегда передаются по значению. Для примитивов копируется само значение, для объектов копируется значение ссылки на объект.

## Вопрос

Что означает передача аргументов "по значению" или "по ссылке"?

## Примитивы

Когда в функцию передают примитив, функция получает копию значения.

```javascript
function change(value) {
  value = 100;
}

let count = 10;
change(count);

console.log(count); // 10
```

Изменение параметра `value` не влияет на переменную `count`.

## Объекты

Когда в функцию передают объект, копируется ссылка на этот объект.

```javascript
function rename(user) {
  user.name = "Max";
}

const user = { name: "Anna" };
rename(user);

console.log(user.name); // "Max"
```

Функция не получила саму внешнюю переменную `user`, но получила ссылку на тот же объект.

## Переназначение параметра

Если внутри функции переназначить параметр, внешняя переменная не изменится.

```javascript
function replace(user) {
  user = { name: "Max" };
}

const user = { name: "Anna" };
replace(user);

console.log(user.name); // "Anna"
```

Параметр `user` внутри функции начал ссылаться на новый объект, но внешняя переменная осталась прежней.

## Наглядная разница

Мутация объекта влияет снаружи:

```javascript
function update(user) {
  user.name = "Max";
}
```

Переназначение параметра не влияет:

```javascript
function update(user) {
  user = { name: "Max" };
}
```

## Как избежать мутаций

Возвращайте новый объект:

```javascript
function rename(user, name) {
  return {
    ...user,
    name,
  };
}

const user = { name: "Anna", age: 25 };
const updatedUser = rename(user, "Max");
```

## Мини-шпаргалка

| Что передаем | Что получает функция | Мутация видна снаружи |
| --- | --- | --- |
| `number`, `string`, `boolean` | копию значения | нет |
| `object` | копию ссылки | да, если менять объект |
| `array` | копию ссылки | да, если менять массив |
| функция | копию ссылки | да, если менять свойства функции |
