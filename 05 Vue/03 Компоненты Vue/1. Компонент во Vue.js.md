# Компонент во Vue.js

> [!summary] Коротко
> Компонент во Vue - независимый блок интерфейса, который объединяет шаблон, состояние, поведение, props, события и стили.

## Вопрос

Что такое компонент во Vue.js?

## Базовая идея

Компоненты позволяют разбить приложение на маленькие части: кнопки, формы, карточки, страницы и layout-ы.

```vue
<script setup>
defineProps<{
  title: string;
}>();
</script>

<template>
  <section class="panel">
    <h2>{{ title }}</h2>
    <slot />
  </section>
</template>
```

Компонент можно переиспользовать с разным контентом и props.

## Single File Component

Во Vue часто используют `.vue` файлы:

```vue
<script setup>
// логика компонента
</script>

<template>
  <!-- разметка -->
</template>

<style scoped>
/* стили компонента */
</style>
```

## Компонент как функция от состояния

Шаблон показывает состояние, а события меняют его.

```vue
<button @click="count++">{{ count }}</button>
```

## Мини-шпаргалка

- Компонент = строительный блок UI.
- SFC хранит `script`, `template`, `style` в одном файле.
- Props передают данные внутрь.
- Emit отправляет события наружу.
- Slots позволяют передавать шаблон.
