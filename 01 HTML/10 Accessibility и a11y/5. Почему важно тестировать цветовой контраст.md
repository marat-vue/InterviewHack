# Почему важно тестировать цветовой контраст

> [!summary]
> Цветовой контраст важно проверять, чтобы текст, кнопки, ссылки и состояния интерфейса оставались читаемыми для людей с разным зрением, на разных экранах и в разных условиях освещения.

## Главное

Если контраст низкий, пользователь может не прочитать текст или не заметить важное состояние.

```html
<button class="button button--disabled">
  Продолжить
</button>
```

Даже disabled-состояние должно быть достаточно понятным визуально.

## Кого это затрагивает

- Людей со сниженным зрением.
- Пользователей с дальтонизмом.
- Людей на улице при ярком солнце.
- Пользователей плохих экранов.
- Людей с усталостью глаз.

## Что проверять

- Основной текст.
- Второстепенный текст.
- Ссылки.
- Кнопки.
- Ошибки формы.
- Placeholder и подсказки.
- Фокус и hover-состояния.

## Не полагаться только на цвет

```html
<p class="error">
  Ошибка: заполните email
</p>
```

Ошибка должна быть понятна не только по красному цвету, но и по тексту, иконке или другой форме сигнала.

## Пример CSS

```css
.error {
  color: #b91c1c;
  font-weight: 600;
}

.field:focus-visible {
  outline: 3px solid #2563eb;
}
```

Контраст касается не только текста, но и видимого фокуса.

## Инструменты

- Lighthouse.
- axe DevTools.
- Contrast checker.
- Figma-плагины для accessibility.
- Ручная проверка на реальных экранах.

## Мини-шпаргалка

- Контраст влияет на читаемость.
- Проверять нужно текст, ссылки, кнопки и состояния.
- Ошибки нельзя обозначать только цветом.
- Видимый фокус тоже должен быть контрастным.
- Автоматические инструменты помогают, но ручная проверка тоже нужна.
