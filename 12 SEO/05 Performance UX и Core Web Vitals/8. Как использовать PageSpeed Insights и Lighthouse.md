# Как использовать PageSpeed Insights и Lighthouse?

> [!summary]
> PageSpeed Insights и Lighthouse помогают диагностировать производительность, доступность, best practices и SEO. Их важно использовать не как игру в 100 баллов, а как инструменты поиска конкретных причин проблем.

## Чем отличаются инструменты?

| Инструмент | Что дает |
|---|---|
| PageSpeed Insights | field data из CrUX и lab data Lighthouse |
| Lighthouse | лабораторный аудит страницы |
| Search Console | группы URL и реальные проблемы сайта |
| Chrome DevTools | глубокое профилирование |

## Как читать PageSpeed Insights?

Смотри:

- реальные данные пользователей;
- mobile отдельно от desktop;
- LCP, INP, CLS;
- opportunities;
- diagnostics;
- конкретный LCP-элемент.

Не стоит чинить все подряд. Начинай с того, что влияет на пользователей и важные страницы.

## Как использовать Lighthouse?

Lighthouse полезен для локальной диагностики:

- performance;
- accessibility;
- best practices;
- SEO;
- PWA, если актуально.

Но Lighthouse - один прогон в лабораторных условиях. Он не заменяет реальные данные.

## Как оформлять задачи?

Плохо:

```text
Сделать Lighthouse 100.
```

Лучше:

```text
На шаблоне product page LCP 4.8s. LCP-элемент - hero image 2.4 MB. Нужно отдать WebP 1200px, добавить preload/fetchpriority и проверить mobile PSI.
```

## Мини-шпаргалка

- PSI показывает и field data, и lab data.
- Lighthouse помогает найти причины, но не заменяет реальный UX.
- Смотри mobile отдельно.
- Оптимизируй важные шаблоны страниц.
- Превращай аудит в конкретные задачи.
