# Что такое alias?

> [!summary]
> Alias - временное имя для столбца, выражения или таблицы внутри SQL-запроса. Он делает результат понятнее и помогает писать короткие ссылки при `JOIN`.

## Alias столбца

```sql
SELECT
  email AS user_email,
  created_at AS registered_at
FROM users;
```

В результате столбцы будут называться `user_email` и `registered_at`.

## Alias выражения

```sql
SELECT
  price * quantity AS total
FROM order_items;
```

Без alias результат выражения может получить неудобное имя.

## Alias таблицы

```sql
SELECT u.email, o.total
FROM users AS u
JOIN orders AS o ON o.user_id = u.id;
```

Alias таблицы особенно полезен, когда в запросе несколько таблиц.

## Когда alias обязателен?

Alias почти обязателен для производных таблиц и CTE-результатов с вычисляемыми колонками, чтобы последующие части запроса были читаемыми.

## Мини-шпаргалка

- Alias дает временное имя.
- `AS` часто можно опускать, но с ним понятнее.
- Alias таблицы сокращает длинные запросы.
- Alias выражения делает результат удобным.
- Не используй слишком короткие имена без причины.
