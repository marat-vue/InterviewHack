# Модификаторы доступа

> [!NOTE]
> Модификаторы доступа управляют тем, откуда можно обращаться к полям и методам класса: `public`, `private`, `protected`.

## Вопрос

Что такое модификаторы доступа?

## `public`

`public` доступен отовсюду. Это значение по умолчанию.

```typescript
class User {
  public name = "Анна";
}

const user = new User();
console.log(user.name);
```

## `private`

`private` доступен только внутри класса.

```typescript
class Account {
  private balance = 0;

  deposit(amount: number): void {
    this.balance += amount;
  }
}

const account = new Account();
// account.balance; // ошибка
```

## `protected`

`protected` доступен внутри класса и наследников.

```typescript
class Animal {
  protected name = "Animal";
}

class Dog extends Animal {
  bark(): string {
    return `${this.name} says woof`;
  }
}
```

## TypeScript `private` и JavaScript `#private`

`private` проверяется TypeScript-компилятором. `#field` - настоящий приватный синтаксис JavaScript на runtime.

```typescript
class Counter {
  #value = 0;
}
```

## Мини-шпаргалка

- `public` - доступно везде.
- `private` - только внутри класса.
- `protected` - внутри класса и наследников.
- `#field` - runtime-приватность JavaScript.
