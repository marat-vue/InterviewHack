# Подключение Motion и первая анимация

> [!summary]
> Motion подключается через пакет `motion`, а в React компоненты импортируются из `motion/react`. Базовая анимация строится через `motion.div`, `initial`, `animate` и `transition`.

## Установка

```bash
npm install motion
```

## Импорт

```tsx
import { motion } from 'motion/react'
```

## Первая анимация

```tsx
function WelcomeCard() {
  return (
    <motion.section
      initial={{ opacity: 0, y: 16 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.3, ease: 'easeOut' }}
    >
      <h1>Welcome</h1>
    </motion.section>
  )
}
```

## Что можно анимировать?

Чаще всего:

- `opacity`;
- `x`, `y`;
- `scale`;
- `rotate`;
- `width`, `height`;
- colors;
- layout position.

```tsx
<motion.button
  whileHover={{ scale: 1.04 }}
  whileTap={{ scale: 0.96 }}
>
  Save
</motion.button>
```

## transition

```tsx
<motion.div
  animate={{ x: 100 }}
  transition={{
    type: 'spring',
    stiffness: 300,
    damping: 24,
  }}
/>
```

Частые настройки:

| Опция | Что делает |
|---|---|
| `duration` | длительность |
| `delay` | задержка |
| `ease` | easing |
| `type: 'spring'` | spring-анимация |
| `stiffness` | жесткость spring |
| `damping` | затухание spring |

## Что отвечать на собеседовании?

Motion добавляет специальные components вроде `motion.div`, которые принимают animation props. Начальное состояние задают через `initial`, целевое через `animate`, а поведение движения - через `transition`. Для hover/tap можно использовать gesture props.

## Мини-шпаргалка

- Установка: `npm install motion`.
- Импорт: `import { motion } from 'motion/react'`.
- `initial` - откуда стартуем.
- `animate` - куда приходим.
- `transition` - как движемся.
- `whileHover`, `whileTap` - gestures.
