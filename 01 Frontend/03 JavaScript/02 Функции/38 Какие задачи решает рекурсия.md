# Какие задачи решает рекурсия?

> [!NOTE] Коротко
> Рекурсия хорошо подходит для задач, которые естественно состоят из похожих подзадач: деревья, вложенные структуры, обход графов, парсинг и математические рекуррентные формулы.

## Вопрос

Какие задачи решает рекурсия?

## Математические задачи

Факториал:

```javascript
function factorial(n) {
  if (n === 0) return 1;

  return n * factorial(n - 1);
}
```

Степень:

```javascript
function pow(base, exponent) {
  if (exponent === 0) return 1;

  return base * pow(base, exponent - 1);
}
```

## Вложенные структуры

Например, дерево комментариев:

```javascript
function countComments(comments) {
  let total = 0;

  for (const comment of comments) {
    total += 1;
    total += countComments(comment.replies);
  }

  return total;
}
```

Каждый комментарий может содержать такие же комментарии внутри.

## Обход дерева DOM

```javascript
function findByTag(node, tagName) {
  if (node.tagName === tagName) return node;

  for (const child of node.children) {
    const result = findByTag(child, tagName);
    if (result) return result;
  }

  return null;
}
```

DOM - древовидная структура, поэтому рекурсия естественна.

## Парсинг и вложенные данные

Рекурсия полезна для:

- JSON-подобных структур;
- меню с подменю;
- файловых деревьев;
- AST;
- организационных структур;
- категорий товаров.

## Когда рекурсия не лучший выбор

Для простого перебора массива цикл обычно проще.

```javascript
let total = 0;

for (const number of numbers) {
  total += number;
}
```

Если глубина может быть очень большой, рекурсия может привести к переполнению стека.

## Мини-шпаргалка

| Тип задачи | Почему подходит рекурсия |
| --- | --- |
| дерево | каждый узел содержит узлы |
| вложенные массивы | структура повторяется |
| файловая система | папки содержат папки |
| комментарии | ответы содержат ответы |
| математические формулы | задача сводится к меньшей |
| парсинг | вложенные грамматики |
