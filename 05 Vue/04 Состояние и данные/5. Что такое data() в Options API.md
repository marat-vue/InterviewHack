# Что такое data() в Options API

> [!summary] Коротко
> `data()` в Options API - функция, которая возвращает начальное локальное состояние компонента. Возвращенные поля Vue делает реактивными.

## Вопрос

Что такое `data()` в Options API?

## Базовый пример

```vue
<script>
export default {
  data() {
    return {
      count: 0,
      isLoading: false,
      user: null,
    };
  },
};
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>
```

## Почему это функция

Компонент может быть создан много раз. Если `data` возвращает новый объект для каждого экземпляра, их состояния не смешиваются.

```javascript
export default {
  data() {
    return { isOpen: false };
  },
};
```

## Начальные значения

Хорошо заранее описывать все основные поля состояния.

```javascript
data() {
  return {
    user: null,
    error: null,
    isSaving: false,
  };
}
```

Так компонент легче читать, а шаблон не зависит от случайно появляющихся полей.

## Мини-шпаргалка

- `data()` возвращает объект state.
- Поля state реактивны.
- В template поля доступны напрямую.
- В methods/computed/watch - через `this`.
- Для каждого экземпляра создается отдельный state.
