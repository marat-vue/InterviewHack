# Как установить и настроить Playwright?

> [!summary]
> Playwright устанавливают через `npm init playwright@latest`. Он добавляет test runner, конфиг, пример теста и браузеры. В конфиге настраивают baseURL, browsers, retries, trace, webServer и parallelization.

## Установка

```bash
npm init playwright@latest
```

Команда задаст вопросы и создаст структуру вроде:

```text
playwright.config.ts
tests/
  example.spec.ts
```

## Запуск

```bash
npx playwright test
```

UI mode:

```bash
npx playwright test --ui
```

Headed mode:

```bash
npx playwright test --headed
```

## Конфиг

```ts
import { defineConfig, devices } from '@playwright/test';

export default defineConfig({
  testDir: './e2e',
  use: {
    baseURL: 'http://localhost:5173',
    trace: 'on-first-retry',
  },
  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox', use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit', use: { ...devices['Desktop Safari'] } },
  ],
  webServer: {
    command: 'npm run dev',
    url: 'http://localhost:5173',
    reuseExistingServer: !process.env.CI,
  },
});
```

## Что такое `webServer`?

`webServer` говорит Playwright, как поднять приложение перед тестами.

Это удобно: CI запускает тесты, Playwright сам стартует frontend dev server или preview server.

## Мини-шпаргалка

- Установка: `npm init playwright@latest`.
- Запуск: `npx playwright test`.
- UI mode: `npx playwright test --ui`.
- `baseURL` позволяет писать `page.goto('/login')`.
- `webServer` поднимает приложение перед тестами.
- `trace: 'on-first-retry'` помогает debug в CI.
