# Какую роль играет libuv в Node.js?

> [!NOTE]
> libuv - библиотека, которая дает Node.js event loop, кроссплатформенную работу с I/O, таймерами, сетевыми событиями, файловыми операциями и thread pool. Благодаря libuv Node.js может эффективно обрабатывать много I/O-задач.

## Зачем libuv нужен Node.js?

Node.js должен одинаково работать на Windows, macOS и Linux. У разных ОС разные механизмы событий и асинхронного ввода-вывода. libuv скрывает эти различия за единым слоем.

## Что дает libuv?

| Возможность | Зачем нужна |
|---|---|
| Event loop | Управление асинхронными callback-функциями |
| Timers | `setTimeout`, `setInterval` |
| TCP/UDP | сетевые соединения |
| File system | часть операций `fs` |
| Thread pool | выполнение некоторых блокирующих задач вне JS-потока |

## Thread pool

Некоторые операции не могут быть полностью неблокирующими на уровне ОС. Тогда libuv использует пул потоков.

```js
import { pbkdf2 } from 'node:crypto';

pbkdf2('password', 'salt', 100000, 64, 'sha512', (error, key) => {
  if (error) throw error;
  console.log(key.toString('hex'));
});
```

Такие задачи не блокируют JS-поток напрямую, но могут занять потоки libuv.

## Важное ограничение

libuv помогает с I/O и некоторыми native-задачами, но не спасает от тяжелого синхронного JavaScript-кода.

```js
while (true) {
  // блокирует основной JS-поток
}
```

## Мини-шпаргалка

- libuv дает Node.js event loop.
- libuv абстрагирует различия ОС.
- Сеть в Node.js работает через неблокирующие механизмы ОС.
- Некоторые операции идут через thread pool.
- Тяжелый JS-код все равно блокирует event loop.
