# Для чего нужны именованные слоты?

> [!NOTE] Коротко
> Именованные слоты нужны, когда компонент имеет несколько областей для вставки контента: header, body, footer, actions, sidebar.

## Вопрос

Для чего нужны именованные слоты?

## Базовый пример

```vue
<!-- BaseModal.vue -->
<template>
  <section class="modal">
    <header><slot name="title" /></header>
    <main><slot /></main>
    <footer><slot name="actions" /></footer>
  </section>
</template>
```

```vue
<BaseModal>
  <template #title>Удалить файл?</template>

  Это действие нельзя отменить.

  <template #actions>
    <button>Отмена</button>
    <button>Удалить</button>
  </template>
</BaseModal>
```

## Почему не один слот

Один слот подходит для простого контента. Но если у компонента несколько зон, именованные слоты делают структуру явной.

## Частые имена

- `header`
- `default`
- `footer`
- `actions`
- `sidebar`
- `empty`

## Мини-шпаргалка

- Именованный слот задается `name`.
- Передается через `#name`.
- Default slot используется без имени.
- Подходит для layout-ов, modal, table, card.
