# Способы создать объект

> [!NOTE]
> Чаще всего объект создают через литерал `{}`. Также можно использовать `new Object()`, функцию-конструктор, класс, `Object.create()` и фабричную функцию.

## Вопрос

Как создать объект в JavaScript?

## Объектный литерал

Самый распространенный способ.

```javascript
const user = {
  name: "Anna",
  age: 25,
};
```

Подходит для большинства обычных объектов.

## `new Object()`

```javascript
const user = new Object();

user.name = "Anna";
```

Работает, но используется редко. Литерал `{}` короче и привычнее.

## Функция-конструктор

```javascript
function User(name) {
  this.name = name;
}

const user = new User("Anna");
```

Такой стиль часто встречается в старом коде.

## Класс

```javascript
class User {
  constructor(name) {
    this.name = name;
  }
}

const user = new User("Anna");
```

Класс - современный синтаксис для объектов с общим поведением.

## `Object.create`

Создает объект с указанным прототипом.

```javascript
const proto = {
  sayHi() {
    return `Hi, ${this.name}`;
  },
};

const user = Object.create(proto);
user.name = "Anna";
```

## Фабричная функция

```javascript
function createUser(name) {
  return {
    name,
    sayHi() {
      return `Hi, ${name}`;
    },
  };
}

const user = createUser("Anna");
```

Не требует `new`.

## Мини-шпаргалка

| Способ | Пример | Комментарий |
| --- | --- | --- |
| литерал | `{}` | основной способ |
| `new Object()` | `new Object()` | редко нужен |
| конструктор | `new User()` | legacy/прототипы |
| класс | `new User()` | современный ООП-синтаксис |
| `Object.create()` | `Object.create(proto)` | контроль прототипа |
| фабрика | `createUser()` | объект без `new` |
