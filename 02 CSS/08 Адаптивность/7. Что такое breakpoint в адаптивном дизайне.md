# Что такое breakpoint в адаптивном дизайне

> [!summary]
> **Breakpoint** - это точка, при которой layout или стили интерфейса меняются, чтобы лучше подходить под размер экрана или контейнера.

## Главное

Breakpoint обычно реализуют через media query.

```css
@media (min-width: 768px) {
  .layout {
    grid-template-columns: 240px 1fr;
  }
}
```

На ширине от `768px` layout становится двухколоночным.

## Breakpoint выбирают по контенту

Не стоит думать только категориями "phone/tablet/desktop". Лучше смотреть, где конкретный layout начинает ломаться.

```text
card becomes too narrow
  -> add breakpoint
navigation no longer fits
  -> add breakpoint
table becomes unreadable
  -> add breakpoint
```

## Mobile-first breakpoints

```css
.cards {
  display: grid;
  gap: 16px;
}

@media (min-width: 640px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1024px) {
  .cards {
    grid-template-columns: repeat(4, 1fr);
  }
}
```

## Не все нужно решать breakpoints

Иногда лучше fluid-решение.

```css
.cards {
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
}
```

Так сетка адаптируется без ручных точек.

## Мини-шпаргалка

- Breakpoint - точка изменения стилей.
- Обычно задается через media query.
- Хороший breakpoint выбирают по контенту.
- Mobile-first использует `min-width`.
- Не стоит плодить breakpoints без необходимости.
- Grid/Flex и `clamp()` могут снизить их количество.
