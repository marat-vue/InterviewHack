# Что такое композиция компонентов?

> [!summary]
> Композиция компонентов - это подход, при котором сложный UI собирается из маленьких компонентов через вложенность, props и children. В React композиция часто предпочтительнее наследования.

## Простое определение

Композиция отвечает на вопрос:

```text
Как собрать большой интерфейс из маленьких независимых частей?
```

Пример:

```jsx
function ProductCard({ product }) {
  return (
    <Card>
      <ProductImage product={product} />
      <ProductTitle product={product} />
      <ProductPrice product={product} />
      <AddToCartButton productId={product.id} />
    </Card>
  )
}
```

Каждая часть отвечает за свою задачу.

## Композиция через children

```jsx
function Card({ children }) {
  return <section className="card">{children}</section>
}

<Card>
  <h2>React</h2>
  <p>Библиотека для создания UI.</p>
</Card>
```

`Card` отвечает за оболочку, а содержимое передается снаружи.

## Композиция через props

```jsx
function Layout({ sidebar, children }) {
  return (
    <div className="layout">
      <aside>{sidebar}</aside>
      <main>{children}</main>
    </div>
  )
}
```

Использование:

```jsx
<Layout sidebar={<Navigation />}>
  <Dashboard />
</Layout>
```

## Почему не наследование?

В React редко создают иерархии наследования компонентов. Вместо:

```text
BaseButton -> PrimaryButton -> LargePrimaryButton
```

часто лучше:

```jsx
<Button variant="primary" size="large" />
```

или композиция нескольких частей.

## Признаки хорошей композиции

- Компоненты маленькие.
- Ответственность ясная.
- Общая оболочка не знает слишком много о содержимом.
- Поведение передается через props.
- Повторяющиеся паттерны выделены, но не переабстрагированы.

## Мини-шпаргалка

- Композиция = сборка UI из компонентов.
- `children` - главный инструмент композиции.
- React предпочитает композицию наследованию.
- Layout-компоненты часто принимают JSX внутрь.
- Хорошая композиция делает UI гибким и читаемым.
