# Прототип

> [!summary] Коротко
> Прототип - объект, от которого другой объект наследует свойства и методы. У объекта есть внутренняя ссылка `[[Prototype]]`, которую обычно читают через `Object.getPrototypeOf()`.

## Вопрос

Что такое прототип?

## Основная идея

Если свойства нет в самом объекте, JavaScript ищет его в прототипе.

```javascript
const user = {
  name: "Anna",
};

user.toString; // найдено в Object.prototype
```

## `[[Prototype]]`

У каждого обычного объекта есть внутренняя ссылка на прототип.

```javascript
const user = {};

Object.getPrototypeOf(user) === Object.prototype; // true
```

Исторически есть `__proto__`, но в современном коде лучше использовать `Object.getPrototypeOf`.

## Свой прототип

```javascript
const userProto = {
  sayHi() {
    return `Hi, ${this.name}`;
  },
};

const user = Object.create(userProto);
user.name = "Anna";

user.sayHi(); // "Hi, Anna"
```

`sayHi` не лежит в `user`, но доступен через прототип.

## `prototype` у функции

Важно не путать:

- `obj.[[Prototype]]` - прототип конкретного объекта;
- `Constructor.prototype` - объект, который станет прототипом экземпляров при `new`.

```javascript
function User(name) {
  this.name = name;
}

const user = new User("Anna");

Object.getPrototypeOf(user) === User.prototype; // true
```

## Мини-шпаргалка

| Термин | Значение |
| --- | --- |
| `[[Prototype]]` | внутренняя ссылка объекта |
| `Object.getPrototypeOf(obj)` | получить прототип |
| `Object.create(proto)` | создать объект с прототипом |
| `Constructor.prototype` | прототип будущих экземпляров |
| `Object.prototype` | верхний прототип обычных объектов |
