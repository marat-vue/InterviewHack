# Как mobile friendliness влияет на SEO?

> [!summary]
> Mobile friendliness означает, что страницей удобно пользоваться на мобильном устройстве. Для SEO это критично, потому что поисковые системы ориентируются на мобильную версию страницы при обходе и оценке пользовательского опыта.

## Что проверять?

- Контент помещается в viewport.
- Текст читается без zoom.
- Кнопки и ссылки удобно нажимать.
- Нет горизонтального скролла.
- Основной контент одинаково доступен на mobile и desktop.
- Модальные окна не перекрывают страницу.
- Навигация работает без hover.
- Формы удобны для ввода.

## Пример viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Без этого мобильная верстка может отображаться неправильно.

## Почему mobile-first важен?

Если desktop-версия богаче, а mobile-версия урезана, поисковик может увидеть меньше контента.

Плохой подход:

```text
На desktop есть полный текст, отзывы и FAQ.
На mobile оставили только hero и кнопку.
```

Лучше, чтобы важный контент был доступен на всех устройствах.

## Частые ошибки

- Скрывают SEO-важный текст на mobile.
- Делают маленькие кликабельные элементы.
- Используют горизонтальные таблицы без адаптации.
- Показывают навязчивый interstitial.
- Загружают слишком тяжелые изображения.

## Мини-шпаргалка

- Mobile UX влияет на восприятие страницы.
- Важный контент должен быть доступен на mobile.
- Навигация должна работать без hover.
- Формы и кнопки должны быть удобны пальцем.
- Проверяй страницы на реальных viewport, а не только в макете.
