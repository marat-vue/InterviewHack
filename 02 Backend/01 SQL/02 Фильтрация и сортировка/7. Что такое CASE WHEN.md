# Что такое CASE WHEN?

> [!summary]
> `CASE WHEN` - условное выражение в SQL. Оно позволяет вернуть разные значения в зависимости от условий, примерно как `if/else`, но внутри запроса.

## Простой пример

```sql
SELECT
  id,
  total,
  CASE
    WHEN total >= 1000 THEN 'large'
    WHEN total >= 100 THEN 'medium'
    ELSE 'small'
  END AS order_size
FROM orders;
```

Каждая строка получает категорию по сумме заказа.

## CASE в агрегатах

`CASE` часто используют для условных счетчиков.

```sql
SELECT
  COUNT(*) AS total_orders,
  SUM(CASE WHEN status = 'paid' THEN 1 ELSE 0 END) AS paid_orders
FROM orders;
```

## CASE в ORDER BY

Можно задать кастомный порядок.

```sql
SELECT *
FROM tasks
ORDER BY
  CASE priority
    WHEN 'critical' THEN 1
    WHEN 'high' THEN 2
    WHEN 'normal' THEN 3
    ELSE 4
  END;
```

## Важный нюанс

`CASE` возвращает выражение, а не выполняет отдельный SQL-блок. Его можно использовать в `SELECT`, `ORDER BY`, иногда в `WHERE` и других частях запроса.

## Мини-шпаргалка

- `CASE WHEN` - условное выражение.
- Завершается через `END`.
- `ELSE` задает fallback.
- Часто используется для условных агрегатов.
- У результата `CASE` должен быть совместимый тип значений.
