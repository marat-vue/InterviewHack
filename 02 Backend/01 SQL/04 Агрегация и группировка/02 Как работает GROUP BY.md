# Как работает GROUP BY?

> [!NOTE]
> `GROUP BY` объединяет строки в группы по одному или нескольким выражениям, а агрегатные функции считают значения внутри каждой группы.

## Пример

```sql
SELECT
  status,
  COUNT(*) AS orders_count
FROM orders
GROUP BY status;
```

Запрос вернет количество заказов по каждому статусу.

## Группировка по нескольким полям

```sql
SELECT
  user_id,
  status,
  COUNT(*) AS count
FROM orders
GROUP BY user_id, status;
```

Группа определяется парой `(user_id, status)`.

## Правило SELECT

Если запрос содержит `GROUP BY`, то в `SELECT` можно выводить:

- поля из `GROUP BY`;
- агрегатные выражения;
- выражения, функционально зависящие от группы, если СУБД это поддерживает.

Плохой пример:

```sql
SELECT status, id, COUNT(*)
FROM orders
GROUP BY status;
```

`id` не является ни группировкой, ни агрегатом.

## Мини-шпаргалка

- `GROUP BY` формирует группы строк.
- Агрегаты считаются внутри группы.
- Все обычные столбцы в `SELECT` должны соответствовать группировке.
- Группировать можно по нескольким полям.
- `WHERE` работает до группировки.
