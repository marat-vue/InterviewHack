# Что такое Nitro plugins?

> [!summary]
> Nitro plugins - server-side plugins, которые выполняются в Nitro runtime. Они лежат в `server/plugins` и позволяют расширять серверное поведение: логирование, hooks, monitoring, database clients, server context.

## Пример

```ts
// server/plugins/nitro.ts
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('request', (event) => {
    console.log('Request:', event.path);
  });
});
```

Такой plugin работает на стороне Nitro server.

## Чем отличается от Nuxt plugin?

Nuxt plugin:

```text
app/plugins/api.ts
```

Работает в Nuxt app context.

Nitro plugin:

```text
server/plugins/nitro.ts
```

Работает в server runtime.

## Когда использовать Nitro plugin?

- server request logging;
- database connection setup;
- monitoring;
- custom Nitro hooks;
- server-only initialization;
- integration with server storage/cache.

## Чего не делать?

Не пытайся использовать browser APIs:

```ts
window.localStorage;
```

Nitro plugin выполняется на сервере.

## Мини-шпаргалка

- Nitro plugins лежат в `server/plugins`.
- Создаются через `defineNitroPlugin`.
- Они работают в server runtime.
- Не путай с `app/plugins`.
- Хороши для server-only инфраструктуры.
