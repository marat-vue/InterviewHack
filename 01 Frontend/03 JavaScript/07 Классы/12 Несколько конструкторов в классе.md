# Несколько конструкторов в классе

> [!NOTE]
> В JavaScript-классе может быть только один `constructor`. Перегрузки конструкторов, как в некоторых других языках, нет.

## Вопрос

Можно ли иметь несколько конструкторов в классе?

## Определение

В теле класса разрешен только один метод `constructor`. Если объявить два конструктора, код не запустится из-за синтаксической ошибки.

```javascript
class User {
  constructor(name) {}
  constructor(name, age) {} // SyntaxError
}
```

## Как заменить несколько конструкторов

В JavaScript обычно используют один конструктор с опциональными параметрами, объектом настроек или статическими фабричными методами.

## Вариант 1: параметры по умолчанию

```javascript
class User {
  constructor(name = 'Guest', age = 0) {
    this.name = name;
    this.age = age;
  }
}

const guest = new User();
const ann = new User('Ann', 25);
```

## Вариант 2: объект настроек

```javascript
class User {
  constructor({ name = 'Guest', age = 0 } = {}) {
    this.name = name;
    this.age = age;
  }
}

const user = new User({ age: 30 });
```

Так удобнее, если аргументов много.

## Вариант 3: статические фабрики

```javascript
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  static guest() {
    return new User('Guest', 'reader');
  }

  static admin(name) {
    return new User(name, 'admin');
  }
}
```

Фабричные методы делают разные сценарии создания понятными по названию.

## Мини-шпаргалка

```javascript
class A {
  constructor(options = {}) {}
}
```
