# Анонимная функция как обработчик

> [!NOTE]
> Анонимный обработчик удобно добавить, но его нельзя удалить через `removeEventListener()`, если не сохранить ссылку на функцию.

## Вопрос

Как удалить обработчик, если он был объявлен как анонимная функция?

## Проблема

`removeEventListener()` удаляет только ту же самую функцию, которая была передана в `addEventListener()`.

```javascript
button.addEventListener('click', () => {
  console.log('clicked');
});

button.removeEventListener('click', () => {
  console.log('clicked');
});
```

Удаление не сработает, потому что это две разные функции.

## Правильный вариант

```javascript
function handleClick() {
  console.log('clicked');
}

button.addEventListener('click', handleClick);
button.removeEventListener('click', handleClick);
```

Нужно сохранить ссылку на обработчик.

## Вариант с переменной

```javascript
const handleClick = () => {
  console.log('clicked');
};

button.addEventListener('click', handleClick);
button.removeEventListener('click', handleClick);
```

## Если обработчик нужен один раз

```javascript
button.addEventListener(
  'click',
  () => {
    console.log('only once');
  },
  { once: true }
);
```

Опция `once` автоматически удалит обработчик после первого вызова.

## Мини-шпаргалка

```javascript
const handler = () => {};

element.addEventListener('click', handler);
element.removeEventListener('click', handler);
```
