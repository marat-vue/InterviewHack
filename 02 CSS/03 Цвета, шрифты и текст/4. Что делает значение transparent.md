# Что делает значение transparent

> [!summary]
> `transparent` - это CSS-значение для полностью прозрачного цвета. Его можно использовать там, где свойство ожидает цвет: `background-color`, `border-color`, `color`, `outline-color` и других.

## Главное

```css
.button {
  background-color: transparent;
}
```

Так фон кнопки становится прозрачным: через него будет виден фон родителя или страницы.

## Transparent и альфа-канал

По смыслу `transparent` близок к полностью прозрачному цвету.

```css
.box {
  background: transparent;
}
```

Можно записать похожее поведение через alpha:

```css
.box {
  background: rgb(0 0 0 / 0);
}
```

Оба варианта дают полностью прозрачный фон.

## Где часто используется

```css
.ghost-button {
  background: transparent;
  border: 1px solid currentColor;
  color: #2563eb;
}
```

`transparent` часто встречается в ghost-кнопках, сбросе фона, прозрачных рамках и hover-состояниях.

## Прозрачная рамка

Иногда прозрачную рамку используют, чтобы layout не прыгал при hover.

```css
.card {
  border: 1px solid transparent;
}

.card:hover {
  border-color: #2563eb;
}
```

Толщина рамки есть всегда, меняется только цвет.

## Transparent не удаляет элемент

Прозрачный фон или цвет не делает элемент невидимым полностью и не убирает его из layout.

```css
.box {
  background: transparent;
}
```

Элемент по-прежнему занимает место, может иметь текст, размеры и обработчики событий.

## Мини-шпаргалка

- `transparent` означает полностью прозрачный цвет.
- Его используют в свойствах, где ожидается цвет.
- Это не то же самое, что `display: none`.
- Прозрачная рамка помогает избежать скачков layout.
- Для частичной прозрачности используют alpha: `rgb(... / 0.5)`.
