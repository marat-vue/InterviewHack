# Что делает React Query (TanStack Query)?

> [!summary]
> TanStack Query - это библиотека для server state: загрузки, кеширования, фонового обновления, инвалидации и мутаций данных с сервера. Она заменяет много ручного кода на `useEffect + fetch + loading + error + cache`.

## Что такое server state?

Server state отличается от обычного UI state:

- живет на сервере;
- может устареть без действий пользователя;
- требует загрузки;
- может иметь ошибки;
- должен кешироваться;
- может обновляться в фоне;
- часто используется несколькими компонентами.

Пример UI state:

```jsx
const [isModalOpen, setIsModalOpen] = useState(false)
```

Пример server state:

```jsx
const { data } = useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
})
```

## Подключение

```jsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'

const queryClient = new QueryClient()

createRoot(document.getElementById('root')).render(
  <QueryClientProvider client={queryClient}>
    <App />
  </QueryClientProvider>,
)
```

## Базовый useQuery

```jsx
function UserPage({ userId }) {
  const {
    data: user,
    isLoading,
    isFetching,
    error,
    refetch,
  } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
    staleTime: 60_000,
  })

  if (isLoading) return <UserSkeleton />
  if (error) return <ErrorMessage error={error} onRetry={refetch} />

  return (
    <>
      {isFetching && <SmallLoader />}
      <UserProfile user={user} />
    </>
  )
}
```

## queryKey

`queryKey` должен полностью описывать данные.

```jsx
useQuery({
  queryKey: ['products', { page, sort, filters }],
  queryFn: () => fetchProducts({ page, sort, filters }),
})
```

Если `page` или `filters` меняются, это уже другой запрос и другая запись кеша.

## staleTime и gcTime

`staleTime` - сколько данные считаются свежими.

```jsx
useQuery({
  queryKey: ['countries'],
  queryFn: fetchCountries,
  staleTime: 24 * 60 * 60 * 1000,
})
```

`gcTime` - как долго неиспользуемые данные остаются в кеше перед сборкой мусора.

## useMutation

```jsx
function CreateUserForm() {
  const queryClient = useQueryClient()

  const mutation = useMutation({
    mutationFn: createUser,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['users'] })
    },
  })

  return (
    <button onClick={() => mutation.mutate({ name: 'Ada' })}>
      Create
    </button>
  )
}
```

`useMutation` используют для операций, которые меняют данные: `POST`, `PUT`, `PATCH`, `DELETE`.

## Главные возможности

- cache по query keys;
- request deduplication;
- background refetch;
- refetch on window focus;
- refetch on reconnect;
- retries;
- mutations;
- optimistic updates;
- infinite queries;
- devtools;
- invalidation.

## Мини-шпаргалка

- TanStack Query управляет server state.
- `useQuery` нужен для чтения данных.
- `useMutation` нужен для изменения данных.
- `queryKey` - адрес данных в кеше.
- После мутаций обычно делают `invalidateQueries`.
