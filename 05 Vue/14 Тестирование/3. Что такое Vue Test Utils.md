# Что такое Vue Test Utils

> [!summary]
> **Vue Test Utils** - официальная утилита для тестирования Vue-компонентов. Она позволяет монтировать компоненты, передавать props, работать со слотами, эмитами и проверять результат рендера.

## Главное

Vue Test Utils используется вместе с test runner: например, с Vitest. Сам по себе он не запускает тесты, а дает инструменты для работы с Vue-компонентами.

```text
Vitest runs test
  -> Vue Test Utils mounts component
  -> test interacts with wrapper
  -> assertions check behavior
```

## mount

`mount` создает полноценный экземпляр компонента.

```js
import { mount } from "@vue/test-utils";
import CounterButton from "./CounterButton.vue";

test("increments counter", async () => {
  const wrapper = mount(CounterButton);

  await wrapper.get("button").trigger("click");

  expect(wrapper.text()).toContain("1");
});
```

## Props

```js
const wrapper = mount(UserBadge, {
  props: {
    name: "Анна",
    status: "online",
  },
});

expect(wrapper.text()).toContain("Анна");
```

Так можно проверить, как компонент реагирует на входные данные.

## Emits

```js
const wrapper = mount(BaseModal);

await wrapper.get('[data-test="close"]').trigger("click");

expect(wrapper.emitted("close")).toHaveLength(1);
```

`wrapper.emitted()` показывает события, которые компонент отправил наружу.

## Slots

```js
const wrapper = mount(BaseCard, {
  slots: {
    default: "<p>Контент карточки</p>",
    footer: "<button>Ок</button>",
  },
});

expect(wrapper.text()).toContain("Контент карточки");
expect(wrapper.text()).toContain("Ок");
```

Так проверяют компоненты-обертки, layout-компоненты и модальные окна.

## shallowMount

`shallowMount` монтирует компонент, но заменяет дочерние компоненты заглушками.

```js
import { shallowMount } from "@vue/test-utils";

const wrapper = shallowMount(ProfilePage);
```

Это полезно, если нужно проверить текущий компонент без глубокого рендера всей вложенной структуры.

## Хорошая практика

Старайся проверять публичное поведение:

- что отображается пользователю;
- какие события эмитятся;
- как компонент реагирует на props;
- что происходит после клика или ввода.

Не стоит тестировать приватные методы и внутренние детали, если они не являются частью контракта компонента.

## Мини-шпаргалка

- Vue Test Utils монтирует Vue-компоненты в тестах.
- `mount` рендерит компонент полноценно.
- `shallowMount` заглушает дочерние компоненты.
- `props` передают входные данные.
- `slots` помогают тестировать компоненты-обертки.
- `emitted()` проверяет события компонента.
