# Проверка на массив

> [!NOTE]
> Надежный способ проверить массив - `Array.isArray(value)`. `typeof` для массива возвращает `"object"`, а `instanceof Array` может ошибаться между разными окнами браузера.

## Вопрос

Как проверить, является ли объект массивом?

## Лучший способ

```javascript
Array.isArray(value);
```

Пример:

```javascript
Array.isArray([1, 2, 3]); // true
Array.isArray([]);        // true
Array.isArray({});        // false
Array.isArray("hello");   // false
```

Это стандартный и самый надежный способ.

## Почему не `typeof`

```javascript
typeof []; // "object"
typeof {}; // "object"
```

Массивы в JavaScript являются объектами, поэтому `typeof` не отличает массив от обычного объекта.

## Почему осторожно с `instanceof`

```javascript
[] instanceof Array; // true
```

Обычно это работает. Но в браузере массив, созданный в другом iframe или window, может иметь другой конструктор `Array`.

```javascript
arrayFromIframe instanceof Array; // может быть false
```

`Array.isArray` решает эту проблему.

## Проверка перед работой с массивом

```javascript
function getFirstItem(value) {
  if (!Array.isArray(value)) {
    return undefined;
  }

  return value[0];
}

getFirstItem([10, 20]); // 10
getFirstItem("text");   // undefined
```

## Проверка похожих на массив значений

Некоторые значения похожи на массивы, но массивами не являются:

```javascript
const nodeList = document.querySelectorAll("div");

Array.isArray(nodeList); // false
```

Их можно преобразовать:

```javascript
const elements = Array.from(nodeList);
```

## Мини-шпаргалка

| Проверка | Результат |
| --- | --- |
| `Array.isArray([])` | `true` |
| `Array.isArray({})` | `false` |
| `typeof []` | `"object"` |
| `[] instanceof Array` | обычно `true`, но менее надежно |
| `Array.from(value)` | преобразует iterable/array-like в массив |
