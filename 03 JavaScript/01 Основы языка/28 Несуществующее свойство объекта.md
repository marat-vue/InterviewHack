# Несуществующее свойство объекта

> [!NOTE] Коротко
> Если обратиться к несуществующему свойству объекта, JavaScript вернет `undefined`. Ошибка появится, если попытаться читать свойство уже у `undefined` или `null`.

## Вопрос

Что произойдет, если обратиться к несуществующему свойству объекта?

## Простое обращение

```javascript
const user = {
  name: "Anna",
};

user.age; // undefined
```

Ошибки нет. JavaScript просто сообщает, что такого свойства у объекта нет.

## Когда появляется ошибка

Ошибка возникает при попытке пойти глубже:

```javascript
const user = {};

user.address;      // undefined
user.address.city; // TypeError
```

Почему:

```javascript
user.address === undefined;
undefined.city; // нельзя
```

То же самое будет с `null`.

## Безопасный доступ

Используйте optional chaining:

```javascript
const city = user.address?.city;
```

Если `address` равен `null` или `undefined`, результатом будет `undefined`, а не ошибка.

Для глубокой структуры:

```javascript
const city = user?.profile?.address?.city;
```

## Значение по умолчанию

С `??` можно задать fallback:

```javascript
const city = user?.profile?.address?.city ?? "Город не указан";
```

Это лучше, чем `||`, если пустая строка или `0` могут быть нормальными значениями.

## Проверка наличия свойства

Если важно отличить "свойства нет" от "свойство есть, но значение `undefined`":

```javascript
const user = { name: undefined };

user.name; // undefined
"name" in user; // true
"age" in user;  // false
```

## Мини-шпаргалка

```javascript
obj.missing;           // undefined
obj.missing.value;     // TypeError
obj.missing?.value;    // undefined
obj.missing ?? "x";    // "x"
"missing" in obj;      // проверка ключа
```
