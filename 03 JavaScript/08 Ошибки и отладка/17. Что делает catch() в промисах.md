# Что делает catch() в промисах

> [!summary] Коротко
> `.catch()` обрабатывает отклонение промиса и ошибки, возникшие в предыдущих звеньях цепочки.

## Вопрос

Как работает `promise.catch()`?

## Определение

`promise.catch(onRejected)` вызывается, когда промис перешел в состояние `rejected`, или когда ошибка была выброшена в предыдущем `.then()`.

По сути это сокращение для `.then(null, onRejected)`.

## Пример rejected Promise

```javascript
Promise.reject(new Error('Network error'))
  .catch((error) => {
    console.log(error.message); // 'Network error'
  });
```

## Ошибка в then

```javascript
Promise.resolve('{ broken }')
  .then((text) => JSON.parse(text))
  .catch((error) => {
    console.log(error.name); // 'SyntaxError'
  });
```

`.catch()` ловит ошибку из предыдущего `.then()`.

## Восстановление цепочки

```javascript
Promise.reject(new Error('No data'))
  .catch(() => {
    return [];
  })
  .then((items) => {
    console.log(items); // []
  });
```

Если `catch` возвращает значение, следующий `.then()` получает успешный результат.

## Проброс ошибки дальше

```javascript
promise.catch((error) => {
  logError(error);
  throw error;
});
```

Если ошибка не решена, ее стоит пробросить дальше.

## Мини-шпаргалка

```javascript
promise
  .then(handleSuccess)
  .catch(handleError);
```
