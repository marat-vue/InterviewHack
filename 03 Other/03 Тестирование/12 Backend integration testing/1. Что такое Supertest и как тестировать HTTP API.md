# Что такое Supertest и как тестировать HTTP API?

> [!summary]
> Supertest - библиотека для тестирования HTTP servers в Node.js. Она позволяет отправлять запросы к Express/Nest/Fastify приложению и проверять status code, headers, response body и side effects.

## Зачем нужен Supertest?

Supertest удобен, когда нужно проверить API endpoint:

```text
POST /users -> validation -> controller -> service -> response
```

Он работает вместе с Jest, Vitest, Mocha и другими runners.

## Пример

```ts
import request from 'supertest';

test('creates user', async () => {
  await request(app.getHttpServer())
    .post('/users')
    .send({ email: 'ann@example.com', password: 'secret123' })
    .expect(201)
    .expect(({ body }) => {
      expect(body.email).toBe('ann@example.com');
      expect(body.password).toBeUndefined();
    });
});
```

## Что проверять?

- method и URL;
- request body;
- status code;
- response body;
- headers;
- cookies;
- database side effects;
- auth/permissions;
- validation errors.

## Supertest в NestJS

В NestJS часто используют testing module:

```ts
const moduleRef = await Test.createTestingModule({
  imports: [AppModule],
}).compile();

const app = moduleRef.createNestApplication();
await app.init();

await request(app.getHttpServer()).get('/health').expect(200);
```

## Мини-шпаргалка

- Supertest тестирует HTTP servers.
- Подходит для Express, NestJS, Fastify через HTTP server.
- Проверяй status, body, headers и side effects.
- Для auth добавляй `.set('Authorization', 'Bearer token')`.
- После тестов закрывай приложение и подключения.
