# С помощью какого тега можно подключить JS код к HTML-странице

> [!summary]
> JavaScript подключают к HTML-странице с помощью тега `<script>`. Скрипт можно написать прямо внутри тега или подключить отдельным файлом через атрибут `src`.

## Подключение внешнего файла

```html
<script src="/app.js" defer></script>
```

Это основной способ для реальных проектов: JavaScript хранится в отдельном файле, а HTML только подключает его.

## Inline-скрипт

```html
<script>
  console.log("Страница загружена");
</script>
```

Такой вариант подходит для маленьких примеров, но в приложениях код обычно выносят в отдельные файлы.

## defer

`defer` говорит браузеру скачать скрипт параллельно с HTML, но выполнить его после парсинга документа.

```html
<script src="/app.js" defer></script>
```

Это хороший вариант для обычных скриптов, которым нужен DOM.

## async

`async` скачивает скрипт параллельно и выполняет сразу после загрузки.

```html
<script src="/analytics.js" async></script>
```

Порядок выполнения async-скриптов не гарантирован. Обычно так подключают независимые скрипты: аналитику, виджеты, внешние интеграции.

## type="module"

Для ES modules используют `type="module"`.

```html
<script type="module" src="/src/main.js"></script>
```

Модульные скрипты по умолчанию ведут себя отложенно: не блокируют парсинг HTML как обычный синхронный скрипт.

## Мини-шпаргалка

- JS подключают через `<script>`.
- `src` указывает внешний файл.
- `defer` подходит для большинства обычных скриптов.
- `async` подходит для независимых скриптов.
- `type="module"` используют для ES modules.
- Обычный `<script>` без `defer` может блокировать парсинг HTML.
