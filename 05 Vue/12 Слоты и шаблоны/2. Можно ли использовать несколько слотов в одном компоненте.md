# Можно ли использовать несколько слотов в одном компоненте

> [!summary] Коротко
> Да, в одном компоненте можно использовать несколько слотов. Для этого применяют именованные слоты: `header`, `default`, `footer` и любые другие имена.

## Вопрос

Можно ли использовать несколько слотов в одном компоненте?

## Базовый пример

```vue
<!-- BaseLayout.vue -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</template>
```

```vue
<!-- Parent.vue -->
<template>
  <BaseLayout>
    <template #header>Заголовок</template>
    Основной контент
    <template #footer>Подвал</template>
  </BaseLayout>
</template>
```

`slot` без имени - default slot.

## Когда это полезно

Несколько слотов нужны для layout-ов, модальных окон, карточек, таблиц и сложных wrapper-компонентов.

## Fallback для каждого слота

```vue
<slot name="footer">Стандартный подвал</slot>
```

Каждый слот может иметь свой fallback.

## Мини-шпаргалка

- Несколько слотов делать можно.
- Именованный слот объявляется через `name`.
- Передача: `<template #name>`.
- Без имени используется default slot.
