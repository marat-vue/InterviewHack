# Что делает сервер до отправки HTML клиенту?

> [!summary]
> При SSR сервер не просто отдает файл. Он принимает HTTP-запрос, определяет route, проверяет контекст пользователя, загружает данные, рендерит React в HTML, безопасно сериализует initial data, добавляет assets и отправляет HTML-ответ.

## Полная цепочка

```text
Request
-> middleware
-> routing
-> auth/session
-> data fetching
-> render React
-> serialize data
-> inject assets
-> send HTML
```

## 1. Принять request

Сервер читает:

- URL;
- HTTP method;
- cookies;
- headers;
- language;
- user agent;
- query params.

```text
GET /products/42?currency=usd
Cookie: session=...
Accept-Language: ru
```

## 2. Выполнить middleware

Middleware может:

- сделать redirect;
- проверить auth;
- определить locale;
- выбрать A/B variant;
- отдать cache;
- переписать URL.

Если redirect уже понятен, нет смысла запускать React render.

## 3. Определить route

Фреймворк сопоставляет URL с компонентом страницы:

```text
/products/:id -> ProductPage
```

## 4. Загрузить данные

Сервер может загрузить:

- product;
- current user;
- permissions;
- translations;
- feature flags;
- SEO metadata.

## 5. Отрендерить React в HTML

```jsx
import { renderToString } from 'react-dom/server'

const appHtml = renderToString(
  <App initialData={initialData} url={request.url} />,
)
```

В streaming SSR используют `renderToPipeableStream` или `renderToReadableStream`.

## 6. Передать initial data клиенту

Клиенту нужны те же данные для hydration.

```html
<script id="initial-data" type="application/json">
  ...
</script>
```

Данные нужно сериализовать безопасно, чтобы не получить XSS.

## 7. Отправить документ

```html
<!doctype html>
<html>
  <head>
    <title>Product</title>
    <script src="/client.js" defer></script>
  </head>
  <body>
    <div id="root">...</div>
  </body>
</html>
```

## Мини-шпаргалка

- SSR-сервер обрабатывает request до React render.
- Middleware может остановить цепочку redirect/cache.
- Данные должны быть готовы до render или стримиться через Suspense.
- Initial data должна совпасть на сервере и клиенте.
- Сериализация данных - зона безопасности.
