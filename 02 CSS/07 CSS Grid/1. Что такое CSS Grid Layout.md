# Что такое CSS Grid Layout

> [!summary]
> **CSS Grid Layout** - это двумерная модель CSS-layout, которая позволяет строить сетки по строкам и колонкам одновременно.

## Главное

Grid включается на контейнере.

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  gap: 24px;
}
```

Прямые дети контейнера становятся grid items.

```html
<div class="layout">
  <aside>Фильтры</aside>
  <main>Каталог</main>
</div>
```

## Почему Grid двумерный

Flexbox в основном работает вдоль одной оси, а Grid управляет строками и колонками сразу.

```text
Grid:
  column 1 | column 2 | column 3
  row 1
  row 2
```

## Что умеет Grid

- Создавать колонки и строки.
- Управлять расстояниями через `gap`.
- Размещать элементы по линиям.
- Создавать именованные области.
- Делать адаптивные сетки через `repeat()`, `minmax()`, `auto-fit`.
- Строить layout без лишних оберток.

## Пример карточной сетки

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}
```

Карточки автоматически перестраиваются под доступную ширину.

## Мини-шпаргалка

- Grid включается через `display: grid`.
- Grid работает со строками и колонками.
- `grid-template-columns` задает колонки.
- `grid-template-rows` задает строки.
- `gap` задает расстояния.
- Для одномерного layout часто проще Flexbox.
