# Всплытие

> [!summary] Коротко
> Всплытие - это поведение, при котором объявления переменных и функций обрабатываются до выполнения кода. Важно помнить: всплывает объявление, а не присваивание.

## Вопрос

Что такое всплытие (hoisting)? Как это работает с `var`, `let`, `const`? Как ведет себя всплытие с функциями?

## Основная идея

Перед запуском кода JavaScript создает окружение выполнения и регистрирует объявления.

Поэтому такой код не падает:

```javascript
console.log(name); // undefined
var name = "Anna";
```

Но это не значит, что строка `var name = "Anna"` буквально переносится вверх. Правильнее думать так:

```javascript
var name;
console.log(name); // undefined
name = "Anna";
```

## `var`

Для `var` создается переменная со значением `undefined`.

```javascript
function demo() {
  console.log(value); // undefined
  var value = 10;
}
```

Еще одна особенность: `var` ограничен функцией, а не блоком.

```javascript
if (true) {
  var visible = true;
}

console.log(visible); // true
```

## `let` и `const`

`let` и `const` тоже всплывают, но до строки объявления находятся в TDZ.

```javascript
console.log(value); // ReferenceError

let value = 10;
```

Это сделано специально: JavaScript не дает использовать переменную до явного объявления.

## Function Declaration

Объявление функции всплывает целиком, поэтому функцию можно вызвать до объявления.

```javascript
sum(2, 3); // 5

function sum(a, b) {
  return a + b;
}
```

## Function Expression и стрелочные функции

Если функция лежит в переменной, всплытие зависит от способа объявления переменной.

```javascript
multiply(2, 3); // ReferenceError

const multiply = (a, b) => a * b;
```

С `var` будет не `ReferenceError`, а `TypeError`:

```javascript
multiply(2, 3); // TypeError

var multiply = function (a, b) {
  return a * b;
};
```

Переменная есть, но ее значение пока `undefined`, а `undefined` нельзя вызвать как функцию.

## Типичная ошибка

```javascript
if (isReady) {
  var status = "ready";
}

console.log(status);
```

Если `isReady` равно `false`, переменная `status` все равно существует, но будет `undefined`. С `let` такая ошибка была бы заметнее.

## Мини-шпаргалка

| Конструкция | Что всплывает | Доступ до объявления |
| --- | --- | --- |
| `var x` | объявление | `undefined` |
| `let x` | объявление | нельзя, TDZ |
| `const x` | объявление | нельзя, TDZ |
| `function f() {}` | объявление и тело | можно |
| `const f = () => {}` | переменная | нельзя, TDZ |
