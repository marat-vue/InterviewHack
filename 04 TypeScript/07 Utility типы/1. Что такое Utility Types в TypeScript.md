# Что такое Utility Types в TypeScript

> [!summary] Коротко
> Utility Types - это встроенные типы-помощники, которые преобразуют уже существующие типы: делают поля опциональными, выбирают часть полей, исключают варианты union и так далее.

## Вопрос

Что такое Utility Types в TypeScript?

## Зачем они нужны

Utility-типы позволяют не дублировать похожие типы вручную.

```typescript
type User = {
  id: number;
  name: string;
  email: string;
};

type UserDraft = Partial<User>;
type UserPreview = Pick<User, "id" | "name">;
```

Если исходный `User` изменится, производные типы обновятся автоматически.

## Популярные utility-типы

```typescript
type OptionalUser = Partial<User>;
type RequiredUser = Required<User>;
type ReadonlyUser = Readonly<User>;
type UserName = Pick<User, "name">;
type UserWithoutEmail = Omit<User, "email">;
```

## Utility для union

```typescript
type Status = "idle" | "loading" | "success" | "error";

type Finished = Exclude<Status, "idle" | "loading">;
// "success" | "error"

type OnlyLoading = Extract<Status, "loading" | "pending">;
// "loading"
```

## Utility для функций

```typescript
function createUser(name: string, age: number) {
  return { name, age };
}

type Params = Parameters<typeof createUser>;
type Result = ReturnType<typeof createUser>;
```

## Мини-шпаргалка

- Utility Types преобразуют существующие типы.
- `Partial`, `Required`, `Readonly` меняют свойства.
- `Pick`, `Omit`, `Record` помогают собирать объектные типы.
- `Exclude`, `Extract`, `ReturnType`, `Parameters` работают с union и функциями.
